## 摘要
将多模态基础模型集成到企业生态系统中，带来了一个根本性的软件架构挑战。架构师必须平衡相互竞争的质量属性：视觉语言动作（VLA）模型的高延迟和非确定性，与企业控制回路所要求的严格确定性和实时性能。在本研究中，我们提出了一种用于视觉智能体的架构模式语言，它将快速、确定性的反射与缓慢、概率性的监督分离开来。该语言包含四种架构设计模式：（1）混合可供性集成，（2）自适应视觉锚定，（3）视觉层次合成，以及（4）语义场景图。

## Abstract
Integrating multimodal foundation models into enterprise ecosystems presents a fundamental software architecture challenge. Architects must balance competing quality attributes: the high latency and non-determinism of vision language action (VLA) models versus the strict determinism and real-time performance required by enterprise control loops. In this study, we propose an architectural pattern language for visual agents that separates fast, deterministic reflexes from slow, probabilistic supervision. It consists of four architectural design patterns: (1) Hybrid Affordance Integration, (2) Adaptive Visual Anchoring, (3) Visual Hierarchy Synthesis, and (4) Semantic Scene Graph.

#### **2. 方法论：核心思想与关键技术**
*   **核心思想**：**“摊销推理”**。将昂贵的、概率性的VLA推理（System 2）作为“监督者”，仅在被调用时修复和更新廉价的、确定性的反射层（System 1）。绝大多数操作由快速反射层完成，从而分摊智能成本。
*   **关键技术/四大架构模式**：
    1.  **混合可供性集成**：通过并行运行轻量级UI对象检测器和OCR引擎，并融合其结果，解决单模态感知的歧义问题，为下游提供可靠的、多模态验证的界面元素信息。
    2.  **自适应视觉锚定**：建立**快速反射环**（基于缓存模板、视觉特征等的确定性匹配）与**慢速监督环**（VLA）之间的桥梁。当反射环因UI漂移导致匹配置信度低于阈值时，触发监督环进行语义定位并更新反射环的缓存，实现自愈。
    3.  **视觉层次合成**：将感知得到的扁平化UI元素列表，依据格式塔原则（如包含、对齐）合成为**层次化的UI结构表示**。这使得规划器可以使用相对寻址（如`点击(“提交”, “登录表单”)`），而非绝对坐标，从而对UI布局平移具有鲁棒性。
    4.  **语义场景图**：基于层次化UI表示，构建一个静态、可查询的**语义场景图**。节点是语义实体，边表示功能与空间关系。该图为高风险决策提供可验证的上下文，增强了系统的可解释性和安全性。
