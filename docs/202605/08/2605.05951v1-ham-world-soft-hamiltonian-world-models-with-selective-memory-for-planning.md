## 摘要
世界模型通过学习到的潜在动力学实现基于模型的规划，但随着规划视野的扩展或动力学分布的变化，想象推演会变得不稳定。我们认为这种不稳定性反映了面向规划器的潜在空间中缺失的两种结构：用于近似马尔可夫完备性的历史条件记忆，以及分离构型、动量和任务语义的几何组织。我们提出了HaM-World（HMW），一种结构化世界模型，它将潜在状态分解为规范（q, p）子空间和上下文子空间c，同时使用Mamba选择性状态空间记忆作为历史条件输入到相同的潜在动力学中。在此接口内，（q, p）通过能量导出的哈密顿向量场加上可学习的残差/控制动力学进行演化，而c捕获语义、耗散和非保守因素。这为规划器提供了一个由动力学预测、奖励/价值估计、想象推演和CEM动作搜索共享的单一潜在状态。在四个DeepMind Control Suite任务上，HaM-World达到了最高的平均AUC（117.9，+9.5%），将长视野推演误差降低到强基线模型的45%，并在{3,5,7} MSE单元中赢得11/12。在涵盖动力学偏移、动作延迟和观测掩码的12个OOD扰动下，HaM-World在每种条件下都实现了最高回报，在Finger Spin任务上平均OOD回报增益为10.2%，在Reacher Easy任务上为13.6%。机制诊断进一步显示了有界的无动作哈密顿能量漂移、策略推演下的结构化能量变化以及连贯的控制诱导能量转移，支持了所设计的软哈密顿动力学。

## Abstract
World models enable model-based planning through learned latent dynamics, but imagined rollouts become unstable as the planning horizon grows or the dynamics distribution shifts. We argue that this instability reflects two missing structures in planner-facing latents: history-conditioned memory for approximate Markov completeness, and geometric organization that separates configuration, momentum, and task semantics. We propose HaM-World (HMW), a structured world model that decomposes the latent state into a canonical (q, p) subspace and a context subspace c, while using Mamba selective state-space memory as the history-conditioned input to the same latent dynamics. Within this interface, (q, p) evolves through an energy-derived Hamiltonian vector field plus learnable residual/control dynamics, while c captures semantic, dissipative, and non-conservative factors. This gives the planner a single latent state shared by dynamics prediction, reward/value estimation, imagined rollouts, and CEM action search. On four DeepMind Control Suite tasks, HaM-World reaches the highest Avg. AUC (117.9, +9.5%), reduces long-horizon rollout error to 45% of a strong baseline model, and wins 11/12 k in {3,5,7} MSE cells. Under 12 OOD perturbations spanning dynamics shifts, action delay, and observation masking, HaM-World achieves the highest return in every condition, with average OOD-return gains of 10.2% on Finger Spin and 13.6% on Reacher Easy. Mechanism diagnostics further show bounded action-free Hamiltonian-energy drift, structured energy variation under policy rollouts, and coherent control-induced energy transfer, supporting the intended Soft-Hamiltonian dynamics design.

    1.  **输入侧**：部分可观测性和动作延迟使得单帧潜在状态不足以构成马尔可夫状态，需要历史条件记忆来实现近似马尔可夫完备性。
    2.  **输出侧**：单一的、未分解的潜在表示将系统构型、动量趋势和任务语义纠缠在一起，使得多步推演缺乏物理一致的结构性约束，容易发散。
*   **整体目标**：提出一个结构化的世界模型，将**记忆（解决输入问题）** 与**几何先验（解决输出问题）** 耦合到一个统一的、面向规划器的潜在动力学接口中，以同时提升样本效率、长视野推演稳定性和分布外泛化能力。

### **2. 论文提出的方法论**
*   **核心思想**：HaM-World 构建了一个结构化的潜在状态 `z_t = [q_t, p_t, c_t]`，并为其配备了一个统一的动力学模型，该模型同时被用于训练、想象推演和规划（CEM）。
*   **关键技术细节**：
    1.  **q/p/c 潜在分解**：
        *   `(q, p)`：**规范子空间**，旨在模拟物理系统中的广义坐标和动量，受到软哈密顿动力学的约束。
        *   `c`：**上下文子空间**，用于捕获与任务语义、摩擦、接触等非保守或耗散因素相关的信息。
    2.  **软哈密顿动力学**：
        *   为 `(q, p)` 学习一个标量能量函数 `H_φ(q, p)`。
        *   动力学更新是数据驱动的网络更新与哈密顿向量场 `(∂H/∂p, -∂H/∂q)` 的加权混合（通过混合系数 α），并额外添加一个可学习的控制项 `G_t * a_t`。这使其既能偏向能量守恒的几何结构，又能灵活拟合受控的、非保守的真实系统动力学。
    3.  **Mamba 选择性记忆**：
        *   使用 Mamba 选择性状态空间模型作为**记忆模块**，其输出 `h_t` 作为历史条件输入到核心动力学函数中。
        *   关键设计：记忆**不**构成一个独立的推演路径，而是用于增强主潜在状态 `z_t` 的马尔可夫性，确保规划器始终与同一个潜在动力学接口交互。
    4.  **训练目标**：
        *   包含表征对齐、一步动力学、奖励/价值预测等标准损失。

### **6. 论文的主要结论与发现**
*   **性能领先**：HaM-World 取得了最高的平均训练 AUC（117.9），比次优的 TD-MPC2 高 **+9.5%**，显示出更优的样本效率。

*   **泛化能力强**：在全部 **12 个** 分布外扰动条件下，HaM-World 的回报均**排名第一**，平均 OOD 回报增益显著（如 Reacher Easy +13.6%）。
*   **机制有效**：诊断实验证实了模型表现出预期的行为：无动作时能量近似守恒，有策略控制时能量发生结构化变化，控制输入沿能量梯度方向做功。
*   **结构必要**：消融实验表明，**记忆是性能的基础**（无记忆则模型崩溃），而**软哈密顿几何结构则在已有记忆的基础上，进一步提升了长视野推演稳定性和 OOD 泛化的上限**。

### **7. 优点**
*   **概念创新**：清晰地将规划器面临的挑战分解为“输入记忆”和“输出结构”两个耦合问题，并提出了统一的解决方案。
*   **方法集成巧妙**：不是简单拼接 Mamba 和哈密顿网络，而是通过 `q/p/c` 分解和共享接口，使二者协同工作，共同服务于一个面向规划器的潜在动力学。
*   **评估全面深入**：超越了仅报告最终回报的常规做法，从**任务性能、推演误差、分布外泛化、内部机制**四个层次提供了令人信服的证据链。
*   **消融分析深刻**：消融实验不仅验证了组件有效性，还揭示了“记忆是必要条件，几何结构是充分条件”的贡献层次，分析深入。

### **8. 不足与局限**
*   **任务与输入局限**：实验仅限于 **4 个** DMC 任务，且使用相对简单的**状态观测**，而非更具挑战性的**像素输入**。在更复杂形态、存在剧烈不连续接触（如机器人抓取）的场景中的有效性尚未验证。
*   **物理先验的局部性**：论文强调其“软”哈密顿先验是局部有效的引导，而非全局严格的物理约束。机制诊断支持了其行为符合设计，但并未证明学习到的动力学在全局意义上是一个真正的哈密顿系统。
*   **扩展性未验证**：方法尚未在更大规模、多任务或基于视觉的复杂环境中进行测试，其可扩展性有待未来工作探索。
*   **计算成本**：引入 Mamba 和额外的结构化损失可能会增加单次迭代的计算开销（尽管在总样本步数下仍高效）。
