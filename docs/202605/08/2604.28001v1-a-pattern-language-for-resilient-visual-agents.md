## 摘要
将多模态基础模型集成到企业生态系统中，带来了一个根本性的软件架构挑战。架构师必须平衡相互竞争的质量属性：视觉语言行动（VLA）模型的高延迟和非确定性，与企业控制回路所要求的严格确定性和实时性能。在本研究中，我们提出了一种用于视觉智能体的架构模式语言，它将快速、确定性的反射与缓慢、概率性的监督分离开来。该语言包含四种架构设计模式：（1）混合可供性集成，（2）自适应视觉锚定，（3）视觉层次合成，以及（4）语义场景图。

## Abstract
Integrating multimodal foundation models into enterprise ecosystems presents a fundamental software architecture challenge. Architects must balance competing quality attributes: the high latency and non-determinism of vision language action (VLA) models versus the strict determinism and real-time performance required by enterprise control loops. In this study, we propose an architectural pattern language for visual agents that separates fast, deterministic reflexes from slow, probabilistic supervision. It consists of four architectural design patterns: (1) Hybrid Affordance Integration, (2) Adaptive Visual Anchoring, (3) Visual Hierarchy Synthesis, and (4) Semantic Scene Graph.

### 2. 方法论
*   **核心思想**：借鉴行为机器人学中的**分层包容架构**和认知心理学中的**双系统理论**，提出一个**分层参考架构**，将快速、确定性的“反射”层（System 1）与慢速、概率性的“监督”层（System 2）解耦，实现**摊销推理**——即昂贵的高层智能仅在必要时（如遇到未知或失败时）被调用，以修复和更新低层的快速反射。
*   **关键技术细节（四种架构模式）**：
    1.  **混合可供性集成模式**：解决多模态感知冲突（如视觉识别为按钮，OCR识别为版本号）。通过**并行运行**轻量级目标检测和OCR模型，进行**几何融合**与**冲突消解**，生成带有置信度的、统一的“可供性”接口，作为下游处理的基础。
    2.  **自适应视觉锚定模式**：解决速度与适应性的“漂移-延迟”困境。建立**快速反射环**（使用缓存的视觉模板/特征进行毫秒级匹配）与**慢速监督环**（VLA模型）之间的**故障切换连接器**。当反射环匹配置信度低于阈值时，触发监督环进行语义定位并更新缓存，之后继续由反射环高效执行。
    3.  **视觉层次合成模式**：解决平面感知元素列表缺乏上下文关系的问题。通过**布局解析**和**格式塔分组原则**（如包含、对齐），将平面检测结果**聚合为层次化的UI表示**（如表单、表格），使规划器能够使用**相对寻址**（如`点击(“登录_表单”内的“提交”)`），从而获得对UI平移的鲁棒性。
    4.  **语义场景图模式**：为长期规划和安全性验证提供显式的世界模型。基于前一个模式的输出，构建一个**静态、可查询的语义场景图**。节点是语义实体，边代表功能与空间关系。在执行高风险动作前，代理可遍历此图进行**前置条件验证**，提高可靠性和可解释性。
