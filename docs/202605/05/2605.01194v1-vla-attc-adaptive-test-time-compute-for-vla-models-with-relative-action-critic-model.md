## 摘要
视觉-语言-动作（VLA）模型在具身操作中展现出卓越的能力和泛化性。然而，其决策依赖于快速、本能的处理过程，缺乏深思熟虑。在面对需要更多考量的复杂或模糊场景时，这种策略常导致次优或灾难性动作。本文提出\textbf{VLA-ATTC}框架，为VLA模型赋予自适应测试时计算（TTC）能力。VLA-ATTC采用基于不确定性的“认知离合器”，在必要时动态从反射式执行切换到TTC深思阶段。在TTC阶段，新颖的\textbf{相对动作评判器}（RAC）模型通过成对比较从生成的候选动作中识别最优动作。这一相对机制取代了不稳定的绝对值估计，显著简化了学习目标。此外，我们引入了一种高效采样策略以分摊计算成本，以及一个无需人工标注即可整理偏好对的自动化数据流水线。在LIBERO-LONG基准测试中，VLA-ATTC将SOTA模型PI0.5的失败率降低了超过50%。我们将开源所有代码和权重。

## Abstract
Vision-Language-Action (VLA) models have demonstrated remarkable capabilities and generalization in embodied manipulation. However, their decision-making relies on a fast, instinctive process that lacks deliberation. This strategy often leads to suboptimal or catastrophic actions when facing complex or ambiguous scenarios that require greater consideration. In this paper, we introduce \textbf{VLA-ATTC}, a framework that endows VLA models with adaptive test-time compute (TTC). VLA-ATTC employs an uncertainty-based ``cognitive clutch'' to dynamically transition from reflexive execution to a TTC deliberation phase when necessary. During TTC phase, a novel \textbf{Relative Action Critic} (RAC) model identifies the optimal action from generated candidates via pairwise comparisons. This relative mechanism replaces unstable absolute value estimation, significantly simplifying the learning objective. Furthermore, we introduce an efficient sampling strategy to amortize computational costs and an automated data pipeline that curates preference pairs without manual annotation. On the LIBERO-LONG benchmark, VLA-ATTC reduces the failure rate of the SOTA model PI0.5 by over 50\%. We will open-source all the code and weights.

*   **核心问题**：如何为VLA模型设计一个**实用、高效且无需修改基础模型**的测试时深思框架，使其能**自适应地**在简单场景快速执行，在困难场景深入思考。

### 2. 论文提出的方法论
*   **核心思想**：VLA-ATTC是一个“即插即用”框架，通过**自适应触发**的测试时计算（TTC）来增强VLA模型的决策可靠性。其核心是**按需深思**，而非全程深思。
*   **关键技术细节**：
    1.  **不确定性量化的“认知离合器”**：
        *   **目的**：判断当前状态是否需要触发深思。
        *   **方法**：在每一时间步，使用相同的视觉语言上下文但不同的随机种子，通过基础VLA的动作头并行生成两个动作序列。
        *   **度量**：计算这两个动作序列之间的**动态时间规整（DTW）距离**作为不确定性分数。距离越大，表明模型对当前状态越不确定。
        *   **触发**：设定一个阈值（如离线数据不确定性分数的第80百分位数）。当不确定性超过阈值时，激活TTC深思阶段；否则，直接执行第一个动作。
    2.  **高效的测试时深思阶段**：
        *   **并行候选动作生成**：利用VLA模型推理中“视觉语言编码”成本高、“动作解码”成本低的特点，**仅进行一次昂贵的视觉语言编码（预填充）**，然后基于此共享的上下文并行采样生成N个候选动作，大幅摊销计算成本。
        *   **基于相对动作评判器（RAC）的锦标赛选择**：
            *   **模型设计**：RAC是一个轻量级Transformer，其核心任务是进行**成对偏好比较**（“动作A是否优于动作B？”），而非给出不稳定的绝对分数。它接收两个候选动作、它们的差值、当前本体感觉状态以及从VLM主干提取的上下文特征（通过可学习的查询令牌蒸馏得到）。
            *   **架构**：RAC采用**多分支注意力机制**，在每个Transformer层融合来自自身特征的自注意力、来自VLM原始特征的交叉注意力和来自蒸馏查询特征的交叉注意力，从而高效利用上下文信息。
            *   **选择过程**：采用锦标赛（单败淘汰制）方式，RAC对候选动作两两比较，胜者进入下一轮，直至选出最优动作。
    3.  **自动化的偏好对数据流水线**：
        *   **问题**：训练RAC需要大量（动作A， 动作B， 偏好）数据对，人工标注成本极高。
        *   **方法**：利用基于流匹配（Flow-Matching）的VLA动作头的特性。通过**改变ODE求解器的积分步数**来生成质量不同的动作：多步生成高质量动作，少步生成低质量动作。从而自动构建出（专家动作， 低质动作）和（高质动作， 低质动作）等清晰的偏好对，无需任何人工标注。
