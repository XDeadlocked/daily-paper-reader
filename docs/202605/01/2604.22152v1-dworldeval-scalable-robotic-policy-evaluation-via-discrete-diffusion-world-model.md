## 摘要
使用现有方法在数千个环境和数千个任务中评估机器人策略是不可行的。这促使我们需要一种可扩展的机器人策略评估新方法。在本文中，我们提出了dWorldEval，它使用离散扩散世界模型作为机器人策略的可扩展评估代理。具体而言，dWorldEval将所有模态——包括视觉、语言和机器人动作——映射到一个统一的令牌空间中，并通过一个基于Transformer的去噪网络对它们进行建模。基于此架构，我们采用稀疏关键帧记忆来保持时空一致性。我们还引入了一个指示任务完成度的进度令牌。在推理时，该模型联合预测未来观测和进度令牌，当进度达到1时自动判定成功。大量实验表明，dWorldEval在LIBERO、RoboTwin和多个真实机器人任务上显著优于先前的方法，即WorldEval、Ctrl-World和WorldGym。它为大规模机器人评估构建世界模拟器的新架构范式铺平了道路。

## Abstract
Evaluating robotics policies across thousands of environments and thousands of tasks is infeasible with existing approaches. This motivates the need for a new methodology for scalable robotics policy evaluation. In this paper, we propose dWorldEval, which uses a discrete diffusion world model as a scalable evaluation proxy for robotics policies. Specifically, dWorldEval maps all modalities - including vision, language, and robotic actions - into a unified token space, modeling them via a single transformer-based denoising network. In this paper, we propose dWorldEval, using a discrete diffusion world model as a scalable evaluation proxy for robotics policy. Specifically, it maps all modalities, including vision, language, and robotics action into a unified token space, then denoises them with a single transformer network. Building on this architecture, we employ a sparse keyframe memory to maintain spatiotemporal consistency. We also introduce a progress token that indicates the degree of task completion. At inference, the model jointly predicts future observations and progress token, allowing automatically determine success when the progress reaches 1. Extensive experiments demonstrate that dWorldEval significantly outperforms previous approaches, i.e., WorldEval, Ctrl-World, and WorldGym, on LIBERO, RoboTwin, and multiple real-robot tasks. It paves the way for a new architectural paradigm in building world simulators for robotics evaluation at scale.

#### **1. 核心问题与整体含义**
*   **研究背景**：随着通用机器人操作策略的快速发展，如何高效、可扩展地评估这些策略的性能成为一个关键挑战。传统的真实世界测试或基于物理的仿真成本高昂，难以覆盖海量任务和环境。
*   **核心问题**：现有的基于生成式世界模型（尤其是视频扩散模型）的评估方法存在**两大根本缺陷**：
    1.  **动作可控性差**：模型通常基于成功演示数据训练，当遇到分布外（OOD）或次优动作时，倾向于“幻觉”出成功结果，无法忠实反映策略的真实失败。
    2.  **时空不一致性**：在长时程推演中，模型会产生物体扭曲、消失等不真实的视觉伪影，导致评估失真。
*   **整体含义**：本文提出了一种新的世界模型架构范式，旨在构建一个**可靠、可控、可扩展**的机器人策略评估代理，通过“想象”而非真实执行来大规模评估策略性能。

#### **2. 方法论**
*   **核心思想**：采用**掩码离散扩散（Masked Discrete Diffusion, MDD）** 从头训练一个世界模型，将所有模态（视觉、语言、动作）视为平等的离散令牌，通过统一的Transformer架构进行联合建模，从而增强动作信号的影响力。
*   **关键技术细节**：
    1.  **统一令牌序列实现动作控制**：使用专用分词器（MAGVIT-v2, LLaDA, FAST）将RGB观测、语言指令和连续动作块映射到统一的离散令牌空间，并展平为单一序列。这使得动作令牌能通过自注意力机制直接影响视觉令牌的生成，确保预测结果忠实于输入动作。
    2.  **稀疏关键帧记忆保持时空一致性**：维护一个由最近K个低分辨率关键帧（如俯视图）组成的滑动窗口记忆。这些关键帧被编码并与其他令牌拼接，同时嵌入绝对时间索引以保持时序。这为长时程推演提供了全局上下文锚点，防止场景漂移。
    3.  **离散进度令牌实现自动成功检测**：在训练时，使用视觉语言模型（如SEED-1.5VL）为观测帧标注离散化的任务进度分数（如0.0, 0.2, ..., 1.0），并将其作为额外的文本令牌加入目标序列。在推理时，模型**联合生成**未来视觉观测和进度令牌，当最终进度令牌为“1.0”时即判定任务成功，无需外部奖励函数或VLM进行二次评估。
*   **流程**：给定当前观测、历史、语言指令和未来动作序列，模型通过MDD的迭代并行解码，同时去噪（预测）出未来的视觉令牌和进度文本令牌，进而重构出未来帧并得到进度分数。

#### **3. 实验设计**
*   **数据集/场景**：

*   **Benchmark（评估指标）**：
    *   **动作可控性**：提出 **∆-LPIPS**，衡量状态**变化**的感知保真度，而非静态外观。

4.  **统一架构有效**：将动作作为一等公民（令牌）与视觉、语言统一建模的架构，是解决现有世界模型动作可控性差问题的关键。

#### **7. 优点**
1.  **架构创新**：提出“统一令牌空间”的核心设计，从根本上提升了动作在生成过程中的控制力，解决了现有方法将动作作为弱条件信号的弊端。
2.  **评估一体化**：将视觉生成与成功判断（进度预测）统一在一个模型中完成，实现了端到端的自动评估，减少了模块间的不一致和额外开销。
3.  **指标创新**：提出 **∆-LPIPS** 作为衡量动作可控性的专用指标，比传统LPIPS更能反映动态变化的保真度，并验证了其作为评估可靠性诊断工具的有效性。
4.  **验证全面**：实验设计严谨，覆盖仿真与真实机器人、单视角与多视角、同构与异构策略，充分证明了方法的有效性和泛化能力。

#### **8. 不足与局限**
1.  **计算成本**：基于大型Transformer和扩散模型，训练和推理（1.5秒/帧）仍需可观的算力，可能影响其作为轻量级评估工具的普及。

4.  **模拟与现实的差距**：虽然在真实机器人数据上进行了训练和测试，但模型本质上仍是“视觉世界模型”，其物理交互的逼真度与基于物理的仿真器仍有差距，对于极度依赖精确物理接触的任务评估可能存在偏差。
