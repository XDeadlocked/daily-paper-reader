## 摘要
世界动作模型（WAMs）通过联合预测场景演变与机器人动作来增强视觉-语言-动作策略，但现有方法通常将预测的世界表示为整体图像、视频标记或全局潜在表示。当指令涉及特定对象时，这些表示难以被动作解码器定位，尤其是在场景变化导致对象身份与上下文纠缠的情况下。我们提出OA-WAM，一种面向鲁棒机器人操作的对象可寻址世界动作模型。OA-WAM将每一帧分解为N+1个槽位状态，包括一个机器人槽位和N个对象槽位。每个槽位包含一个持久地址向量和一个时变内容向量，并与文本、图像、本体感知及历史动作标记在块因果序列中融合。世界头预测下一帧槽位状态，而流匹配动作头在同一前向过程中解码16步连续动作块。可寻址性通过仅基于地址的键进行跨槽注意力路由，并在每个Transformer层重置地址切片来实现，从而将“对哪个对象操作”与“该对象当前状态”分离，无需添加额外标记。OA-WAM在LIBERO（97.8%）和SimplerEnv（79.3%）上达到强VLA和WAM基线水平，在LIBERO-Plus最相关的几何轴上取得最先进性能，并在七轴综合指标上保持竞争力。因果槽位干预测试显示交换绑定余弦相似度为0.87，而整体基线最高仅为0.09。这些结果表明，可寻址对象状态为场景扰动下的鲁棒世界动作建模提供了有效接口。

## Abstract
World Action Models (WAMs) enhance Vision-Language-Action policies by jointly predicting scene evolution and robot actions, but existing methods usually represent the predicted world as holistic images, video tokens, or global latents. These representations are difficult for an action decoder to address when an instruction refers to a particular object, especially under scene shifts where object identity is entangled with context. We propose OA-WAM, an Object-Addressable World Action Model for robust robot manipulation. OA-WAM decomposes each frame into N+1 slot states, with one robot slot and N object slots. Each slot contains a persistent address vector and a time-varying content vector, and is fused with text, image, proprioception, and past-action tokens in a block-causal sequence. A world head predicts next-frame slot states, while a flow-matching action head decodes a 16-step continuous action chunk in the same forward pass. Addressability is enforced by routing cross-slot attention through address-only keys and resetting the address slice at every transformer layer, separating which object to act on from what that object currently is without adding extra tokens. OA-WAM matches strong VLA and WAM baselines on LIBERO (97.8%) and SimplerEnv (79.3%), reaches state-of-the-art performance on the most relevant LIBERO-Plus geometric axes, and remains competitive on the seven-axis aggregate. A causal slot-intervention test yields a swap-binding cosine of 0.87, versus at most 0.09 for holistic baselines. These results suggest that addressable object states provide an effective interface for robust world-action modeling under scene perturbations.

*   **核心主张**：为了实现鲁棒的操作，世界模型不仅需要预测未来，更应该提供一个**稳定、可查询的对象级接口**。论文将这种能力定义为 **“对象可寻址性”** ，即模型应能在张量层面将“对哪个物体操作”与“该物体当前状态如何”分离开。

### 2. 方法论：OA-WAM
*   **核心思想**：将每一帧场景**分解**为一组对象槽位，并为每个槽位构建一个**身份地址**与**时变内容**分离的表示。通过修改Transformer的注意力机制，**强制**所有跨槽位的交互仅基于固定的身份地址进行路由，从而保证动作解码器对目标对象的“寻址”不受场景内容变化的影响。
*   **关键技术细节**：
    1.  **对象槽位表示**：每个槽位令牌是一个320维向量，由四部分组成：
        *   `addr_k`：32维**身份地址**。在任务开始时根据语言标签和初始视觉特征计算一次，并在整个任务周期内**冻结**。
        *   `cnt_tk`：256维**时变内容**。每帧根据当前的外观、位姿等信息更新。
        *   `π_t`：16维时间位置编码。
        *   `ρ_k`：16维角色嵌入。
    2.  **多模态序列构建**：将文本、图像VQ令牌、对象槽位、本体感觉、历史动作等六种令牌流，按块因果顺序组装成一个序列，末尾附加一个可学习的动作查询令牌`[ACT_Q]`。
    3.  **对象可寻址注意力**：这是实现可寻址性的**核心机制**。在每个Transformer层中，对于槽位间的注意力计算，**键的投影输入被限制为仅使用`addr_k`部分**。同时，在前向传播后，通过一个钩子将残差流中槽位的`addr`切片**重置**回其缓存的原值。这两项操作共同确保了跨槽注意力路由**仅依赖于冻结的身份地址**。
    4.  **预测头**：
        *   **世界头**：读取槽位隐藏状态，预测下一帧每个槽位的内容和位姿，作为辅助监督。
        *   **动作头**：一个基于流匹配的MLP，读取`[ACT_Q]`的隐藏状态，并行解码一个16步的连续动作块。

1.  **性能匹配**：OA-WAM在标准基准（LIBERO: 97.8%）和视觉匹配基准（SimplerEnv: 79.3%）上达到或超越了现有最佳模型。

4.  **核心结论**：显式地将世界模型组织为可寻址的对象状态，是提升模型在场景几何扰动下鲁棒性的有效途径。

### 7. 优点
1.  **概念清晰，架构创新**：明确提出了“对象可寻址性”这一核心问题，并通过巧妙的**地址-内容分离**与**注意力路由约束**这一相对简洁的架构修改予以实现，而非增加复杂模块。
2.  **强归纳偏置**：OA约束是一种**结构性的归纳偏置**，直接针对OOD鲁棒性失败模式，而非依赖大量扰动数据。
3.  **实验设计扎实**：不仅汇报性能提升，更通过精心设计的消融和干预实验，提供了**因果性证据**，深入验证了其提出的机制。
4.  **兼容性与高效性**：基于现有大型多模态主干，通过LoRA等方式高效微调，保持了较好的实用性。

### 8. 不足与局限
1.  **仿真局限**：所有验证均在仿真环境中进行，尚未在真实机器人上部署验证，其宣称的鲁棒性有待现实世界检验。
2.  **感知模块脆弱性**：模型的性能**严重依赖上游感知模块**的准确性。在传感器噪声扰动下性能下降明显（-17.1%），论文承认这是因SAM3/DINOv3在图像质量受损时分割/特征提取失败所致，而非策略层问题。
3.  **假设限制**：干扰物一致性损失等部分设计基于“目标与干扰物弱耦合”的假设，在干扰物物理阻挡目标等复杂情况下可能失效。
4.  **实时性挑战**：尽管策略网络高效，但每帧138ms的感知开销（SAM3+DINOv3+Qwen3-VL）对实时控制构成挑战。
5.  **泛化对象类型**：对透明、反光、严重遮挡或运动模糊的小物体，当前感知流水线可能失效。
