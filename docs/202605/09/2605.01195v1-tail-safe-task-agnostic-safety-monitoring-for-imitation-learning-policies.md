## 摘要
近期模仿学习算法，如流匹配和扩散策略，在学习复杂操作任务方面展现出卓越性能。然而，这些策略即使在训练分布内运行时也常会失败，原因在于对初始条件的极端敏感以及导致复合漂移的不可约近似误差。这使得在分布外场景普遍存在的实际环境中部署模仿学习策略变得不安全。安全部署的一个前提是使策略能够判断其是否能以从演示中学到的方式执行任务。本文提出TAIL-Safe，一种原则性方法，用于为训练好的模仿学习策略识别一个安全集，在该集合中策略经验上能成功完成所学任务。我们提出一个利普希茨连续的Q值函数，该函数基于三个与任务无关的短期标准——可见性、可识别性和可抓取性——将状态-动作对映射到长期安全分数。该函数的零超水平集刻画了状态-动作对上的经验控制不变集。当名义策略提出一个位于该集合之外的动作时，我们应用一种受Nagumo定理启发的恢复机制，该机制通过对Q函数进行梯度上升来引导策略返回安全区域。为了学习该Q函数，我们使用高斯泼溅构建了一个高保真数字孪生，从而能够系统性地收集故障数据而无需冒物理硬件风险。在Franka Emika机器人上的实验表明，在运行时扰动下会失败的流匹配策略，在TAIL-Safe的引导下能够实现一致的任务成功。

## Abstract
Recent imitation learning (IL) algorithms such as flow-matching and diffusion policies demonstrate remarkable performance in learning complex manipulation tasks. However, these policies often fail even when operating within their training distribution due to extreme sensitivity to initial conditions and irreducible approximation errors that lead to compounding drift. This makes it unsafe to deploy IL policies in the field where out-of-distribution scenarios are prevalent. A prerequisite for safe deployment is enabling the policy to determine whether it can execute a task the way it was learned from demonstrations. This paper presents TAIL-Safe, a principled approach to identify, for a trained IL policy, a safe set from where the policy empirically succeeds in completing the learned task. We propose a Lipschitz-continuous Q-value function that maps state-action pairs to a long-term safety score based on three short-term task-agnostic criteria: visibility, recognizability, and graspability. The zero-superlevel set of this function characterizes an empirical control invariant set over state-action pairs. When the nominal policy proposes an action outside this set, we apply a recovery mechanism inspired by Nagumo's theorem that uses gradient ascent to the Q-function to steer the policy back to safety. To learn this Q-function, we construct a high-fidelity digital twin using Gaussian Splatting that enables systematic collection of failure data without risk to physical hardware. Experiments with a Franka Emika robot demonstrate that flow-matching policies, which fail under run-time perturbations, achieve consistent task success when guided by the proposed TAIL-Safe.

#### **1. 核心问题与整体含义**
*   **研究背景**：以流匹配、扩散策略为代表的模仿学习算法在复杂操作任务上表现出色，但其部署面临严重安全挑战。这些策略对初始条件极度敏感，且存在不可约的近似误差，导致即使在训练分布内也可能因“复合漂移”而失败。在现实世界中，分布外扰动不可避免，这使得模仿学习策略的鲁棒部署存在风险。
*   **核心问题**：如何为**预训练好的、黑盒式的**模仿学习策略，提供一个**任务无关的**安全监控与恢复机制，使其在运行时能判断自身状态是否安全，并在即将失败时自主纠正，从而提供“任务成功保证”。

#### **2. 方法论**
*   **核心思想**：学习一个能够预测长期任务成功率的“安全Q函数”，其零值以上区域构成一个“经验安全集”。在策略运行时实时监控，若其动作落在安全集内则放行，若落在安全集外则触发基于Q函数梯度的恢复控制器，将系统拉回安全区域。
*   **关键技术细节**：
    1.  **任务无关的安全准则**：定义了三个短期、可计算的准则作为安全信号的基础：
        *   **可见性**：目标物体是否在相机视野内。
        *   **可识别性**：当前视觉观测与专家演示分布的特征距离（基于策略编码器与马氏距离）。
        *   **可抓取性**：当前末端执行器姿态与高质量抓取姿态的匹配度。
    2.  **上下文感知的奖励融合**：通过一个名为 **WeightNet** 的小型网络，动态融合上述三个准则的分数。它能够根据任务阶段（如接近、抓取）自适应调整各准则的权重，而非使用固定加权和。
    3.  **安全Q函数的学习**：
        *   **目标定义**：采用“到达-避免”范式，Q值定义为从当前状态-动作对开始，未来轨迹上遇到的最小安全奖励。`Q(s,a) >= 0` 意味着从该点出发能始终保持安全直至任务完成。
        *   **数据收集**：利用**高斯泼溅技术**快速（约20分钟）构建高保真“数字孪生”仿真环境。在其中对策略施加扰动（物体位移、旋转、噪声），系统性地收集成功与失败的轨迹数据，避免了在真实机器人上收集危险故障数据的风险。
        *   **网络设计**：Q函数是一个4层MLP，通过**谱归一化**强制其具有利普希茨连续性，确保梯度平滑稳定。
        *   **能量地形塑造**：在训练中增加额外损失项，使Q函数在专家动作附近形成“有界山峰”状的能量地形，确保在安全集边界处梯度方向明确、幅度足够，以支持有效的梯度上升恢复。
    4.  **恢复控制器**：当检测到 `Q(s,a) < 0` 时，对策略提议的动作 `a` 执行投影梯度上升：`a’ = a + η * ∇aQ / ||∇aQ||`，迭代直至 `Q >= 0` 或达到最大步数。此设计灵感来源于控制理论中的Nagumo定理。

*   TAIL-Safe能够为模仿学习策略建立一个有效的**经验安全集**，并实现可靠的**实时安全监控与恢复**。

*   **数据收集安全**：利用高斯泼溅数字孪生安全、高效地收集关键的失败数据。
*   **理论启发**：将控制理论中不变集和Nagumo定理的思想与深度学习结合，设计出可解释的恢复机制。

#### **8. 不足与局限**
*   **策略类型限制**：目前仅适用于**确定性策略**（如流匹配）。扩展到随机策略（如扩散）需要额外设计，可能增加计算开销。
*   **安全集是静态的**：Q函数离线学习，无法在线适应训练分布之外的新型扰动或环境变化。

*   **提供的是经验保证而非形式化保证**：安全保证依赖于Q函数对训练数据的拟合精度，而非严格的数学证明。
