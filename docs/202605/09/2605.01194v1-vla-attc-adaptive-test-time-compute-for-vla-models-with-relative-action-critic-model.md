## 摘要
视觉-语言-动作（VLA）模型在具身操作中展现出卓越的能力和泛化性。然而，其决策依赖于快速、本能的处理过程，缺乏深思熟虑。在面对需要更多考量的复杂或模糊场景时，这种策略常导致次优或灾难性动作。本文提出\textbf{VLA-ATTC}框架，为VLA模型赋予自适应测试时计算（TTC）能力。VLA-ATTC采用基于不确定性的“认知离合器”，在必要时动态从反射式执行切换到TTC深思阶段。在TTC阶段，新颖的\textbf{相对动作评判器}（RAC）模型通过成对比较从生成的候选动作中识别最优动作。这一相对机制取代了不稳定的绝对值估计，显著简化了学习目标。此外，我们引入了一种高效采样策略以分摊计算成本，以及一个无需人工标注即可整理偏好对的自动化数据流水线。在LIBERO-LONG基准测试中，VLA-ATTC将SOTA模型PI0.5的失败率降低了超过50%。我们将开源所有代码和权重。

## Abstract
Vision-Language-Action (VLA) models have demonstrated remarkable capabilities and generalization in embodied manipulation. However, their decision-making relies on a fast, instinctive process that lacks deliberation. This strategy often leads to suboptimal or catastrophic actions when facing complex or ambiguous scenarios that require greater consideration. In this paper, we introduce \textbf{VLA-ATTC}, a framework that endows VLA models with adaptive test-time compute (TTC). VLA-ATTC employs an uncertainty-based ``cognitive clutch'' to dynamically transition from reflexive execution to a TTC deliberation phase when necessary. During TTC phase, a novel \textbf{Relative Action Critic} (RAC) model identifies the optimal action from generated candidates via pairwise comparisons. This relative mechanism replaces unstable absolute value estimation, significantly simplifying the learning objective. Furthermore, we introduce an efficient sampling strategy to amortize computational costs and an automated data pipeline that curates preference pairs without manual annotation. On the LIBERO-LONG benchmark, VLA-ATTC reduces the failure rate of the SOTA model PI0.5 by over 50\%. We will open-source all the code and weights.

*   **核心问题**：这种“本能”决策在面对复杂、模糊或需要多步推理的场景时，容易产生次优甚至灾难性的动作。现有为VLA模型增加“深思”（Deliberation）能力的方法（如思维链或并行采样+绝对评分）通常成本高昂、需要额外标注或模型微调，且对所有场景一视同仁，不切实际。
*   **整体含义**：本文旨在为VLA模型引入一种**自适应**的测试时计算（Test-Time Compute, TTC）机制，使其能够在必要时（即模型自身不确定时）从快速反射模式切换到成本可控的深思模式，从而在**不修改基础模型**的前提下，显著提升其在困难场景下的决策鲁棒性和成功率。

### 2. 方法论
*   **核心思想**：设计一个“即插即用”的框架，在VLA模型的标准推理流程外，增加一个由不确定性触发的、高效的测试时深思模块。
*   **关键技术细节**：
    1.  **不确定性量化（认知离合器）**：在每个时间步，使用**不同的随机种子**让VLA的动作头生成两个动作序列，计算两者之间的**动态时间规整（DTW）距离**作为不确定性度量。若不确定性低于预设阈值，则执行第一个动作（快速模式）；若高于阈值，则触发深思模式。
    2.  **高效并行候选动作生成**：利用VLA模型推理中“视觉语言编码（预填充）”成本高、“动作解码”成本低的特点，在触发深思时，**共享一次预填充的计算**，并行采样生成N个候选动作，极大分摊了多候选生成的开销。
    3.  **相对动作评判器（RAC）模型**：
        *   **任务**：不直接给单个动作打绝对分（难以定义且不稳定），而是进行**成对比较**，判断给定两个动作中哪一个更优。
        *   **输入**：两个候选动作、它们的差值、当前本体感知状态。
        *   **架构**：一个轻量级Transformer，通过**多分支注意力**机制融合信息：1) 自注意力；2) 与VLM主干同层原始特征的交叉注意力；3) 与VLM中可学习查询（用于提炼高层语义）特征的交叉注意力。
        *   **选择机制**：采用**锦标赛式淘汰**，RAC对候选动作两两比较，胜者进入下一轮，直至选出最优动作。
    4.  **自动化偏好对数据流水线**：为训练RAC，提出无需人工标注的自动化方法。利用基于流匹配（Flow-Matching）的VLA动作头特性，通过**调整ODE求解步数**来生成质量不同的动作对（高步数动作 vs. 低步数动作），从而自动构建“好-坏”动作偏好对数据集。
*   **算法流程（文字说明）**：
    1.  输入当前图像和指令，通过VLM主干进行一次预填充，得到上下文特征。
    2.  用两个不同随机种子生成两个动作，计算DTW距离作为不确定性。
    3.  若不确定性低于阈值，执行第一个动作。
    4.  若不确定性高于阈值，进入深思阶段：
        a. 基于共享的上下文特征，批量并行生成N个候选动作。
        b. 当候选动作数量大于1时，进行锦标赛选择：将候选动作两两配对，输入RAC模型判断哪个更优，保留优者进入下一轮。
        c. 重复步骤b，直到只剩一个动作，将其作为最终执行动作。

3.  **方法组件有效**：相对评判（RAC）优于绝对评分；自动化生成的数据能有效训练RAC；增加候选动作数量（N）能提升性能，但存在收益递减；RAC的所有设计组件（可学习查询、动作差值输入等）都对最终性能有贡献。

### 7. 优点
1.  **即插即用**：无需对基础VLA模型进行任何微调或修改，具有良好的通用性和易用性。
2.  **自适应计算**：通过“认知离合器”实现按需计算，在效率与性能间取得优雅平衡，是核心创新点。
3.  **相对评判机制**：将困难的绝对评分问题转化为更稳健的成对比较问题，降低了评判模型的学习难度和容量需求。
4.  **计算效率高**：利用VLA模型预填充成本高的特点，通过共享计算实现候选动作的廉价批量生成，是工程上的巧妙设计。
5.  **数据自动化**：提出的自动化偏好对生成流水线，避免了昂贵且主观的人工标注，使方法易于扩展。

### 8. 不足与局限
1.  **阈值依赖**：“认知离合器”的触发依赖于预设的不确定性阈值（τ），该阈值需要在一个离线数据集上计算百分位来设定。这可能对数据分布敏感，且需要额外的校准步骤。
2.  **额外计算开销**：尽管通过自适应和共享计算大幅降低了开销，但引入RAC模型和额外的动作采样仍会增加一定的计算负担，在极端资源受限的边缘设备上部署可能仍有挑战。
3.  **评判器泛化能力**：RAC模型的性能依赖于其训练所用的偏好数据。虽然自动化流水线提供了数据，但该数据源于特定VLA模型（流匹配动作头）的生成特性。当基础VLA模型架构或训练数据分布发生较大变化时，RAC可能需要重新训练或调整。
4.  **序列决策的长期性**：当前方法主要针对单步决策的不确定性进行优化。对于需要长期规划的任务，如何将这种测试时深思与更宏观的序列决策（如子目标规划）相结合，是未来的挑战。
5.  **实验范围**：虽然涵盖了仿真和真实机器人，但任务类型主要集中在桌面物体操作领域。在更动态、非结构化或需要与人类紧密交互的场景中的有效性有待进一步验证。
