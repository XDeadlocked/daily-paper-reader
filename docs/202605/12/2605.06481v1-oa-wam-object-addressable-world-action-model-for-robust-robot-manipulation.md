## 摘要
世界动作模型（WAMs）通过联合预测场景演变与机器人动作来增强视觉-语言-动作策略，但现有方法通常将预测的世界表示为整体图像、视频标记或全局潜在表示。当指令涉及特定对象时，这些表示难以被动作解码器定位，尤其是在场景变化导致对象身份与上下文纠缠的情况下。我们提出OA-WAM，一种面向鲁棒机器人操作的对象可寻址世界动作模型。OA-WAM将每帧分解为N+1个槽状态，包括一个机器人槽和N个对象槽。每个槽包含一个持久地址向量和一个时变内容向量，并与文本、图像、本体感知及历史动作标记在块因果序列中融合。世界头预测下一帧槽状态，而流匹配动作头在同一前向过程中解码16步连续动作块。通过仅地址键路由跨槽注意力，并在每个Transformer层重置地址切片，强制实现可寻址性，从而将“对哪个对象操作”与“该对象当前状态”分离，无需添加额外标记。OA-WAM在LIBERO（97.8%）和SimplerEnv（79.3%）上匹配强VLA和WAM基线，在最具相关性的LIBERO-Plus几何轴上达到最先进性能，并在七轴聚合指标上保持竞争力。因果槽干预测试显示交换绑定余弦相似度为0.87，而整体基线最高仅为0.09。这些结果表明，可寻址对象状态为场景扰动下的鲁棒世界动作建模提供了有效接口。

## Abstract
World Action Models (WAMs) enhance Vision-Language-Action policies by jointly predicting scene evolution and robot actions, but existing methods usually represent the predicted world as holistic images, video tokens, or global latents. These representations are difficult for an action decoder to address when an instruction refers to a particular object, especially under scene shifts where object identity is entangled with context. We propose OA-WAM, an Object-Addressable World Action Model for robust robot manipulation. OA-WAM decomposes each frame into N+1 slot states, with one robot slot and N object slots. Each slot contains a persistent address vector and a time-varying content vector, and is fused with text, image, proprioception, and past-action tokens in a block-causal sequence. A world head predicts next-frame slot states, while a flow-matching action head decodes a 16-step continuous action chunk in the same forward pass. Addressability is enforced by routing cross-slot attention through address-only keys and resetting the address slice at every transformer layer, separating which object to act on from what that object currently is without adding extra tokens. OA-WAM matches strong VLA and WAM baselines on LIBERO (97.8%) and SimplerEnv (79.3%), reaches state-of-the-art performance on the most relevant LIBERO-Plus geometric axes, and remains competitive on the seven-axis aggregate. A causal slot-intervention test yields a swap-binding cosine of 0.87, versus at most 0.09 for holistic baselines. These results suggest that addressable object states provide an effective interface for robust world-action modeling under scene perturbations.

*   **研究背景**：视觉-语言-动作模型在标准机器人操作基准上表现出色，但其鲁棒性在场景扰动（如视角、布局变化）下会急剧下降。现有世界动作模型通常将未来场景预测为整体图像或全局潜在表示，导致语言指令中指定的“目标对象”身份与视觉上下文信息在表示中纠缠。
*   **核心问题**：这种“整体式”表示缺乏**对象可寻址性**——即模型内部缺乏一个稳定、明确的接口，让动作解码器能够始终如一地定位并操作语言所指的特定对象。当场景几何布局发生变化时，目标对象虽仍可见，但其在整体表示中的“身份信号”已被周围环境干扰，导致动作选择漂移到错误对象。
*   **整体含义**：本文认为，为实现鲁棒操作，世界模型不仅应预测未来，更应提供稳定、可查询的**对象级状态**。论文旨在通过**架构层面的设计**，而非仅依赖数据增强，来强制实现对象身份与动态内容的解耦，从而提升策略在分布外几何扰动下的泛化能力。

### 2. 方法论
*   **核心思想**：将场景分解为可寻址的**对象槽**，并在Transformer的注意力机制中，强制规定**跨槽交互只能通过对象的固定身份地址（address）进行路由**，从而将“对哪个对象操作”（由地址决定）与“该对象当前状态如何”（由内容决定）在张量层面分离。
*   **关键技术细节**：
    1.  **对象槽令牌化**：利用冻结的SAM3（分割）、DINOv3（特征提取）和Qwen3-VL（语言解析）基础模型，将每帧图像分解为N个对象槽和1个机器人槽。每个槽令牌由四部分组成：**固定的32维身份地址**（由初始语言标签和视觉特征生成，贯穿整个episode不变）、**时变的256维内容向量**、时间位置编码和角色编码。
    2.  **多模态序列构建**：将文本、图像VQ令牌、槽令牌、本体感觉和过去动作令牌组装成一个**块因果序列**，末尾附加一个可学习的动作查询令牌`[ACT_Q]`。
    3.  **对象可寻址注意力约束**：
        *   **仅地址键投影**：在Transformer每一层，对于槽令牌之间的注意力，**键（K）的投影输入被限制在地址向量的前32维**。这意味着一个槽去“注意”其他哪个槽，仅由各自的身份地址决定。
        *   **每层地址流重置**：在每个Transformer层的前向传播后，通过一个钩子（hook）将槽令牌隐藏状态中的地址部分**重置回其缓存的原值**，防止地址信息在残差连接中被内容信息污染。
    4.  **并行预测头**：模型单次前向传播同时输出：
        *   **世界头**：预测下一帧每个槽的内容和姿态（作为辅助监督）。
        *   **动作头**：一个基于流匹配的MLP，以`[ACT_Q]`的隐藏状态为条件，解码未来16步的连续动作块。

### 3. 实验设计

*   OA-WAM在标准基准（LIBERO 97.8%, SimplerEnv 79.3%）上达到了领先水平，证明其对象分解设计未牺牲分布内性能。

*   **工程实现详尽**：论文附录提供了极其详细的实现细节、训练配方、算力消耗和模块参数量，复现性高。

### 8. 不足与局限
*   **仿真局限**：所有验证均在仿真中进行，未在真实机器人上部署，其宣称的“鲁棒性”尚未经过现实世界复杂性的检验。

*   **假设简化**：方法假设目标对象与干扰物之间是“弱耦合”的，对于严重遮挡或需要移动干扰物才能操作目标的复杂情况，可能失效。
