## 摘要
世界模型通过观测与动作预测未来状态。现有研究主要聚焦于图像生成。而基于视觉特征的世界模型则预测未来视觉特征而非原始视频像素，提供了一种更高效且不易产生幻觉的替代方案。然而，当前基于特征的方法依赖直接回归，在复杂交互中会导致模糊或坍缩的预测，同时高维特征空间中的生成建模仍具挑战性。本研究发现，一种新型潜在动作表示——我们称之为*残差潜在动作*——可从DINO残差中轻松学习。我们还证明RLA具有预测性、可泛化性并能编码时间进程。基于RLA，我们提出*RLA世界模型*，通过流匹配预测RLA值。RLA-WM在仿真和真实世界数据集上均优于当前最先进的基于特征和视频扩散的世界模型，且速度比视频扩散快数个数量级。此外，我们开发了两种利用RLA-WM改进策略学习的机器人学习技术：其一是基于RLA的简约世界动作模型，可从无动作演示视频中学习；其二是首个完全在仅从离线视频学习的世界模型内部训练的视觉强化学习框架，使用视频对齐奖励，无需在线交互或人工设计奖励。项目页面：https://mlzxy.github.io/rla-wm

## Abstract
World models predict future transitions from observations and actions. Existing works predominantly focus on image generation only. Visual feature-based world models, on the other hand, predict future visual features instead of raw video pixels, offering a promising alternative that is more efficient and less prone to hallucination. However, current feature-based approaches rely on direct regression, which leads to blurry or collapsed predictions in complex interactions, while generative modeling in high-dimensional feature spaces still remains challenging. In this work, we discover that a new type of latent action representation, which we refer to as *Residual Latent Action* (RLA), can be easily learned from DINO residuals. We also show that RLA is predictive, generalizable, and encodes temporal progression. Building on RLA, we propose *RLA World Model* (RLA-WM), which predicts RLA values via flow matching. RLA-WM outperforms both state-of-the-art feature-based and video-diffusion world models on simulation and real-world datasets, while being orders of magnitude faster than video diffusion. Furthermore, we develop two robot learning techniques that use RLA-WM to improve policy learning. The first one is a minimalist world action model with RLA that learns from actionless demonstration videos. The second one is the first visual RL framework trained entirely inside a world model learned from offline videos only, using a video-aligned reward and no online interactions or handcrafted rewards. ### 论文总结：Learning Visual Feature-Based World Models via Residual Latent Action

#### 1. 核心问题与整体含义
*   **研究背景**：世界模型是机器人学习中的关键组件，用于预测给定动作后的未来状态。当前主流方法基于视频（像素）生成，但存在**计算开销大**和**容易产生与现实不符的“幻觉”** 两大问题。
*   **研究动机**：基于视觉特征（如DINO token）预测未来是一种更高效、更不易幻觉的替代方案。然而，现有特征级方法（如DINO-WM）使用直接回归，在复杂3D交互中会导致**预测模糊或坍缩**；若改用生成模型（如扩散模型）直接在超高维特征空间中进行，则**计算挑战巨大**，丧失了特征方法的效率优势。本文旨在解决这一矛盾，寻求一种**既高效又精确**的视觉特征世界模型，并将其有效应用于下游策略学习。

#### 2. 提出的方法论
*   **核心思想**：不直接回归或生成未来的高维视觉特征，而是学习一个紧凑的、能表征**状态间变化**的潜在表示——**残差潜在动作**，并在此低维空间中进行动态预测。
*   **关键技术细节**：
    1.  **残差潜在动作**：定义当前帧与未来帧的DINO特征残差 `s_{t+h} - s_t`。设计一个**RLA自编码器**，其编码器 `f_enc` 将该残差压缩为一个低维向量 `z`（即RLA），解码器 `f_dec` 利用当前状态 `s_t` 和 `z` 重建未来状态 `s_{t+h}`。训练仅使用一个回归损失。
    2.  **RLA的三个关键属性**：
        *   **预测充分性**：`z` 包含足够信息，使解码器能单次前向传播高保真重建未来特征。
        *   **可泛化性**：在任务无关数据上训练的RLA编码器，能泛化到未见过的任务和场景。
        *   **时间拓扑性**：在RLA潜在空间中进行线性插值，可以解码出近似中间时刻的状态。
    3.  **RLA世界模型**：基于RLA构建动态模型。给定当前状态 `s_t` 和动作序列 `a_{t:t+h}`，模型的目标是预测RLA `z`。具体采用**流匹配**方法：将 `s_t` 和编码后的动作作为条件，学习一个从高斯噪声 `ϵ` 到目标RLA `z` 的概率路径。预测时，在**紧凑的RLA空间**（而非原始高维特征空间）中迭代求解ODE，得到预测的 `z`，最后通过 `f_dec` 得到 `s_{t+h}`。这大幅降低了生成过程的计算量。

#### 6. 主要结论与发现
*   RLA是一种有效的动态紧凑表示，具备预测性、泛化性和时间拓扑性。
*   **RLA-WM在预测精度上显著优于所有SOTA基线**（包括特征方法和视频扩散方法），同时在计算效率上比视频扩散模型快数个数量级，仅略慢于直接回归方法。
*   RLA能够作为高质量的**动作替代**，使简约的策略网络能够从大量无动作视频中学习，提升模仿学习性能。
*   首次实现了**完全在离线视频学习的世界模型内部进行视觉强化学习**，无需在线交互或人工奖励，并能稳定提升策略性能。

#### 7. 优点
*   **方法创新**：RLA的概念简单而有效，巧妙地将高维动态预测问题转化为紧凑残差空间的生成问题，平衡了精度与效率。
*   **应用价值**：不仅提升了世界模型本身，还衍生出两个具有实用价值的机器人学习新范式（无监督模仿学习、离线世界模型内RL），展示了强大的下游应用潜力。
*   **实验严谨**：考虑了仿真与真实数据，进行了大规模评估以验证强化学习效果的鲁棒性，并公开了代码和模型，有利于复现。

#### 8. 不足与局限
*   **对无关运动敏感**：RLA编码的是两帧间的所有视觉变化，包括任务无关的背景运动或相机抖动，这可能浪费表示能力并影响质量。
*   **缺乏历史建模**：当前RLA仅基于单帧对 `(s_t, s_{t+h})` 学习，无法处理需要长时序推理的情况（如物体被遮挡后重现）。
*   **仅限于视觉状态**：当前世界模型仅预测视觉特征，未包含本体感知状态，限制了其在需要精确关节信息任务中的应用。
*   **特定场景下的性能下降**：在Panda机械臂的某些任务上，世界模型内强化学习的效果不如行为克隆，作者归因于其更高的自由度、特定视角和演示数据多样性不足。
*   **数据规模**：实验主要在中等规模数据集上进行，虽有利于突出方法本身增益，但将其扩展到互联网规模开放世界数据的能力尚未验证。
