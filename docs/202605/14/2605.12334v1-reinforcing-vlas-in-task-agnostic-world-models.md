## 摘要
通过在已学习的世界模型中通过强化学习（RL）对训练后的视觉-语言-动作（VLA）模型进行微调，已成为适应新任务而无需昂贵真实世界交互的有效策略。然而，尽管使用想象轨迹降低了策略训练的样本复杂度，现有方法仍严重依赖任务特定数据来微调世界模型和奖励模型，从根本上限制了其向未见任务的可扩展性。为克服此问题，我们认为世界模型和奖励模型应捕捉可迁移的物理先验，以实现零样本推理。我们提出RAW-Dream（任务无关世界梦境中的VLA强化），这是一种全新的范式，将世界模型学习与下游任务依赖完全解耦。RAW-Dream利用在多样化无任务行为上预训练的世界模型来预测未来轨迹，并利用现成的视觉-语言模型（VLM）生成奖励。由于这两个组件均与任务无关，VLA可以完全在此零样本想象中轻松微调以适应任何新任务。此外，为减轻世界模型的幻觉，我们引入了双重噪声验证机制以过滤不可靠的轨迹。在仿真和真实环境中的大量实验证明了一致的性能提升，表明广义物理先验能有效替代昂贵的任务依赖数据，为VLA适应提供了高度可扩展的路线图。

## Abstract
Post-training Vision-Language-Action (VLA) models via reinforcement learning (RL) in learned world models has emerged as an effective strategy to adapt to new tasks without costly real-world interactions. However, while using imagined trajectories reduces the sample complexity of policy training, existing methods still heavily rely on task-specific data to fine-tune both the world and reward models, fundamentally limiting their scalability to unseen tasks. To overcome this, we argue that world and reward models should capture transferable physical priors that enable zero-shot inference. We propose RAW-Dream (Reinforcing VLAs in task-Agnostic World Dreams), a new paradigm that completely disentangles world model learning from downstream task dependencies. RAW-Dream utilizes a world model pre-trained on diverse task-free behaviors for predicting future rollouts, and an off-the-shelf Vision-Language Model (VLM) for reward generation. Because both components are task-agnostic, VLAs can be readily finetuned for any new task entirely within this zero-shot imagination. Furthermore, to mitigate world model hallucinations, we introduce a dual-noise verification mechanism to filter out unreliable rollouts. Extensive experiments across simulation and real-world settings demonstrate consistent performance gains, proving that generalized physical priors can effectively substitute for costly task-dependent data, offering a highly scalable roadmap for VLA adaptation.

### 2. 方法论：RAW-Dream
*   **核心思想**：提出一个完全**任务无关**的VLA后训练范式。它结合一个在广泛、无任务行为数据上预训练的世界模型，和一个现成的、提供零样本奖励的视觉语言模型（VLM），使VLA策略能够完全在“想象”中针对新任务进行强化学习优化。
*   **关键技术细节**：
    1.  **任务无关世界模型**：
        *   **架构**：基于WAN 2.1视频生成扩散Transformer（DiT），通过自适应层归一化（AdaLN）注入动作条件，并采用因果掩码确保时序一致性。
        *   **训练数据**：使用多样化的、无任务目标的交互数据（如游戏数据、带噪声的探索轨迹）进行训练，迫使模型学习通用物理动力学而非特定任务语义。
        *   **推理优化**：针对零样本迁移中的“首帧鬼影”问题，提出了**渐进噪声**技术，在自回归生成过程中逐渐增加首帧锚点的扩散噪声，以平衡场景一致性与动态生成的可靠性。
    2.  **任务无关奖励**：直接使用冻结的、现成的VLM（如Qwen3-VL）作为零样本成功分类器。给定想象出的视频轨迹和任务指令，VLM输出二进制成功奖励。
    3.  **双噪声验证（DNV）**：
        *   **目的**：缓解任务无关世界模型在未见任务上产生“幻觉成功”轨迹的风险。
        *   **机制**：对于任何被VLM判定为成功的想象轨迹，使用**独立重采样的扩散噪声**在WM中重新生成一次。如果两次生成的VLM奖励判断不一致（成功 vs 失败），则认为初始的成功是幻觉，并将该轨迹从策略更新的可靠集合中剔除。
*   **算法流程**：
    1.  **准备阶段**：预训练一个任务无关的世界模型（WM）；选定一个现成的VLM作为奖励函数。
    2.  **适应新任务**：
        *   **语义锚定**：使用极少量（如1-3条）新任务的专家演示，对VLA策略进行轻量级监督微调（SFT）。
        *   **想象中强化学习**：在**冻结的**任务无关WM中，让策略与环境交互，生成想象轨迹。
        *   **奖励与验证**：使用VLM评估轨迹奖励，并应用DNV机制过滤不可靠的成功轨迹。
        *   **策略更新**：使用GRPO等策略优化算法，基于可靠的轨迹和奖励更新VLA策略。整个过程**无需收集任何新任务下的真实机器人交互数据**。

### 6. 主要结论与发现
*   **核心结论**：**通用的、任务无关的物理先验可以有效替代昂贵的任务特定数据**，用于驱动VLA策略的高效后训练。
*   **关键发现**：
    1.  在广泛数据上预训练的世界模型，即使零样本使用，也能对未见任务产生相当可靠的模拟（除物体完全新颖的Object套件）。
    2.  **RAW-Dream范式显著高效**：使用零样本WM和VLM奖励的RL，其性能已优于消耗500条真实轨迹的在线RL；仅用10条演示联合微调WM，其性能可逼近消耗2500条真实轨迹的在线RL。

    4.  **零样本VLM奖励优于少量样本微调奖励**：在目标域数据极少时，基础VLM的常识推理比用少量演示微调的分类器更可靠，后者容易过拟合。

    6.  **范式可迁移至真实世界**：仅用游戏数据训练的世界模型和零样本VLM奖励，能成功在真实机器人上提升策略性能（相对3-shot SFT提升21.7%）。

### 7. 优点
1.  **范式创新**：首次系统性地提出并验证了“完全任务无关的世界模型+零样本奖励”的VLA后训练范式，具有高度的**可扩展性**和**实用性**。
2.  **双噪声验证（DNV）**：设计巧妙，利用WM生成的不确定性和VLM的语义判断来检测幻觉，方法轻量且有效，解决了模型基于RL中的一个关键难题。
3.  **实验设计严谨**：评估协议严格，在仿真和真实环境中进行了全面、多层次的验证，消融实验深入，结论可信度高。
4.  **工程实现扎实**：基于现有强模型（WAN 2.1, OpenVLA-OFT, Qwen3-VL）进行集成与创新，并解决了实际推理中的问题（如首帧鬼影）。

### 8. 不足与局限
1.  **世界模型零样本能力的边界**：当目标域与预训练分布差异极大时（如**引入全新物体**，LIBERO-Object套件），零世界模型的模拟质量会急剧下降，导致RL改进有限。这表明物理先验的泛化能力仍有边界。
2.  **VLM奖励的质量瓶颈**：零样本VLM奖励并非完美，其在某些任务套件（如LIBERO-Goal）上的判断质量下降，会成为策略性能提升的**天花板**。
3.  **计算开销**：DNV机制需要对成功轨迹进行二次生成，增加了约30%的推理时间成本。自回归长视频生成本身计算量也较大。
4.  **依赖基础模型性能**：范式的效果上限依赖于所使用的世界模型和VLM的基础能力。文中未对更庞大或更专精的基础模型进行广泛测试。
5.  **任务范围**：实验主要集中在桌面物体操作任务，对于更复杂的移动操作、动态环境或需要更强推理的任务，该范式的有效性有待进一步验证。
