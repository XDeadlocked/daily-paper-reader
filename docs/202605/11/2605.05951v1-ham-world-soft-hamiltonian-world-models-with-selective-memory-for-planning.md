## 摘要
世界模型通过学习到的潜在动力学实现基于模型的规划，但随着规划视野的扩展或动力学分布的变化，想象推演会变得不稳定。我们认为这种不稳定性反映了面向规划器的潜在空间中缺失的两种结构：用于近似马尔可夫完备性的历史条件记忆，以及分离构型、动量和任务语义的几何组织。我们提出HaM-World（HMW），一种结构化世界模型，它将潜在状态分解为规范(q, p)子空间和上下文子空间c，同时使用Mamba选择性状态空间记忆作为历史条件输入到相同的潜在动力学中。在此接口内，(q, p)通过能量导出的哈密顿向量场加上可学习的残差/控制动力学进行演化，而c捕获语义、耗散和非保守因素。这为规划器提供了一个由动力学预测、奖励/价值估计、想象推演和CEM动作搜索共享的单一潜在状态。在四个DeepMind Control Suite任务上，HaM-World达到了最高的平均AUC（117.9，+9.5%），将长视野推演误差降低至强基线模型的45%，并在{3,5,7} MSE单元中赢得11/12。在涵盖动力学偏移、动作延迟和观测掩码的12个OOD扰动下，HaM-World在每种条件下都实现了最高回报，在Finger Spin任务上平均OOD回报增益为10.2%，在Reacher Easy任务上为13.6%。机制诊断进一步显示了有界的无动作哈密顿能量漂移、策略推演下的结构化能量变化以及连贯的控制诱导能量转移，支持了所设计的软哈密顿动力学。

## Abstract
World models enable model-based planning through learned latent dynamics, but imagined rollouts become unstable as the planning horizon grows or the dynamics distribution shifts. We argue that this instability reflects two missing structures in planner-facing latents: history-conditioned memory for approximate Markov completeness, and geometric organization that separates configuration, momentum, and task semantics. We propose HaM-World (HMW), a structured world model that decomposes the latent state into a canonical (q, p) subspace and a context subspace c, while using Mamba selective state-space memory as the history-conditioned input to the same latent dynamics. Within this interface, (q, p) evolves through an energy-derived Hamiltonian vector field plus learnable residual/control dynamics, while c captures semantic, dissipative, and non-conservative factors. This gives the planner a single latent state shared by dynamics prediction, reward/value estimation, imagined rollouts, and CEM action search. On four DeepMind Control Suite tasks, HaM-World reaches the highest Avg. AUC (117.9, +9.5%), reduces long-horizon rollout error to 45% of a strong baseline model, and wins 11/12 k in {3,5,7} MSE cells. Under 12 OOD perturbations spanning dynamics shifts, action delay, and observation masking, HaM-World achieves the highest return in every condition, with average OOD-return gains of 10.2% on Finger Spin and 13.6% on Reacher Easy. Mechanism diagnostics further show bounded action-free Hamiltonian-energy drift, structured energy variation under policy rollouts, and coherent control-induced energy transfer, supporting the intended Soft-Hamiltonian dynamics design.

#### **1. 核心问题与整体含义**
*   **研究动机**：基于模型强化学习（MBRL）中的世界模型在**长时程规划**或面临**分布外（OOD）动力学变化**时，其想象推演（rollout）会变得不稳定、误差累积严重。这限制了规划器的有效视野和泛化能力。
*   **根本原因**：作者认为，现有模型缺乏两种对规划器至关重要的潜在状态结构：
    1.  **输入侧**：缺乏**历史条件记忆**，无法在部分可观测、存在动作延迟的环境中形成近似的马尔可夫状态。
    2.  **输出侧**：缺乏**几何结构组织**，将构型、动量、任务语义等不同物理属性的信息纠缠在单一潜在变量中，导致多步推演缺乏物理一致的约束。

#### **2. 提出的方法论**
*   **核心思想**：为规划器设计一个**结构化、统一的潜在状态接口**，该接口同时耦合了**选择性记忆**（解决输入侧马尔可夫性）和**软哈密顿几何**（解决输出侧稳定性）。
*   **关键技术细节**：
    *   **结构化潜状态分解**：将编码器输出的潜在状态 `z_t` 显式分解为三部分：**规范对 `(q_t, p_t)`** （模拟物理系统的广义坐标与动量）和**上下文变量 `c_t`** （捕获语义、耗散、非保守因素）。
    *   **Mamba选择性记忆**：使用Mamba选择性状态空间模型作为**历史编码器**，其输出 `h_t` 作为条件输入到动力学中，为当前潜在状态提供历史上下文，使其对规划器而言近似马尔可夫。
    *   **软哈密顿动力学**：`(q, p)` 的更新是**哈密顿向量场**（由可学习的能量函数 `H(q,p)` 导出）与一个**可学习的残差/控制网络更新**的**凸组合**（混合系数 α）。同时，在动量 `p` 的更新中显式加入一个由网络生成的控制项 `G_t a_t`。这种“软”设计允许模型在保持能量场结构偏置的同时，灵活拟合摩擦、接触等非保守效应。
    *   **统一规划接口**：动力学模型、奖励预测器、价值函数以及规划时使用的交叉熵方法（CEM）都**共享并操作于同一个潜在状态 `z_t = [q_t, p_t, c_t]`** 上，无需为规划维护单独的状态。

    *   **评估指标**：
        1.  **控制性能**：最终回报、训练曲线下面积（AUC）。
        2.  **规划相关稳定性**：k步（k ∈ {3,5,7}）潜在状态推演的均方误差（MSE）。

#### **7. 优点**
*   **概念创新**：清晰地将规划器面临的问题分解为“输入侧记忆”和“输出侧几何”两个耦合阶段，并提出了统一的解决方案。
*   **结构设计优雅**：`(q,p,c)`的分解与软哈密顿更新机制，在引入物理归纳偏置的同时保持了模型的表达能力和灵活性。

*   **实用性**：模型为规划器提供了单一、稳定的接口，无需在训练和规划时切换不同的状态表示。

#### **8. 不足与局限**
*   **任务规模有限**：仅在DMC的4个中等复杂度、状态观测的任务上验证。尚未扩展到**像素观测**、更复杂的机器人形态或具有**剧烈不连续接触**（如弹跳、抓取）的领域。
