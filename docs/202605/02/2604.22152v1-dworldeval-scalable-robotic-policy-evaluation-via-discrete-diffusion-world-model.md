## 摘要
使用现有方法在数千个环境和数千个任务中评估机器人策略是不可行的。这促使我们需要一种可扩展的机器人策略评估新方法。在本文中，我们提出了dWorldEval，它使用离散扩散世界模型作为机器人策略的可扩展评估代理。具体来说，dWorldEval将所有模态（包括视觉、语言和机器人动作）映射到一个统一的标记空间，并通过一个基于Transformer的去噪网络对它们进行建模。基于此架构，我们采用稀疏关键帧记忆来保持时空一致性。我们还引入了一个指示任务完成度的进度标记。在推理时，模型联合预测未来观测和进度标记，当进度达到1时自动判定成功。大量实验表明，在LIBERO、RoboTwin和多个真实机器人任务上，dWorldEval显著优于先前的方法，即WorldEval、Ctrl-World和WorldGym。它为大规模机器人评估的世界模拟器构建开辟了新的架构范式。

## Abstract
Evaluating robotics policies across thousands of environments and thousands of tasks is infeasible with existing approaches. This motivates the need for a new methodology for scalable robotics policy evaluation. In this paper, we propose dWorldEval, which uses a discrete diffusion world model as a scalable evaluation proxy for robotics policies. Specifically, dWorldEval maps all modalities - including vision, language, and robotic actions - into a unified token space, modeling them via a single transformer-based denoising network. In this paper, we propose dWorldEval, using a discrete diffusion world model as a scalable evaluation proxy for robotics policy. Specifically, it maps all modalities, including vision, language, and robotics action into a unified token space, then denoises them with a single transformer network. Building on this architecture, we employ a sparse keyframe memory to maintain spatiotemporal consistency. We also introduce a progress token that indicates the degree of task completion. At inference, the model jointly predicts future observations and progress token, allowing automatically determine success when the progress reaches 1. Extensive experiments demonstrate that dWorldEval significantly outperforms previous approaches, i.e., WorldEval, Ctrl-World, and WorldGym, on LIBERO, RoboTwin, and multiple real-robot tasks. It paves the way for a new architectural paradigm in building world simulators for robotics evaluation at scale.

#### **1. 核心问题与整体含义**
*   **研究动机**：随着通用机器人操作策略的快速发展，对其能力进行大规模、可靠的评估成为一个关键挑战。传统的真实世界测试成本高昂，而基于物理的仿真器又需要大量资产。生成式世界模型被视为一种有潜力的数据驱动替代方案，但现有方法（多基于视频生成模型改造）存在严重缺陷：
    1.  **动作可控性差**：模型通常在成功演示数据上训练，当遇到分布外（OOD）或错误的动作时，容易“幻觉”出成功的未来状态，无法忠实反映策略执行的失败。
    2.  **时空不一致性**：长时程推演中会出现物体扭曲、消失等不符合物理规律的现象。
*   **核心论点**：上述问题的根本原因是**架构缺陷**。现有方法将机器人动作作为弱条件（如通过交叉注意力）注入到以视觉生成主导的预训练模型中，导致强大的视觉先验经常覆盖掉动作信号。因此，需要一种**原生为机器人评估设计**的世界模型架构。

#### **2. 方法论**
*   **核心思想**：提出 **dWorldEval**，一个基于**掩码离散扩散（Masked Discrete Diffusion, MDD）** 的世界模型，旨在通过统一的标记化序列建模，将动作提升为与视觉、语言平等的“一等公民”，从而确保动作可控性和长时程一致性，并实现自动化的策略评分。
*   **关键技术细节**：
    1.  **统一标记序列与动作控制**：使用专用标记器（MAGVIT-v2 for 视觉， LLaDA for 语言， FAST for 动作）将所有模态（当前观测、历史、语言指令、未来动作）映射到统一的离散标记空间，并展平为单一序列。通过Transformer的自注意力机制，视觉标记可以直接关注动作标记，实现细粒度的动作控制。
    2.  **稀疏关键帧记忆**：为保持长时程推演中的时空一致性，维护一个稀疏的历史关键帧记忆（如最近K=4帧，低分辨率）。这些关键帧被标记化后与当前观测序列拼接，并添加绝对时间索引标记以保持时序。这为模型提供了全局场景锚点，防止累积漂移。
    3.  **离散进度标记**：为实现自动成功检测，在训练时，使用视觉语言模型（如SEED-1.5VL）为观测帧标注离散化的任务进度分数（如0.0, 0.2, ..., 1.0），并将其作为额外的文本标记加入目标序列。在推理时，模型**联合生成**未来视觉观测和进度标记，当最终进度标记为“1.0”时即判定任务成功。
    4.  **训练与推理**：采用掩码离散扩散进行训练，随机掩码目标序列（未来视觉和进度标记）的一部分，让模型重建。推理时使用迭代并行解码，在给定上下文（历史、当前状态、指令、动作）的条件下，采样生成完整的未来序列。

#### **3. 实验设计**
*   **数据集/场景**：
    1.  **LIBERO**：桌面操作基准，包含Object、Spatial、Goal、100四个任务套件。使用了同步的第三人称和腕部视角数据，并**增广了失败轨迹数据**以提升模型对失败情况的感知。
    2.  **RoboTwin**：接触丰富的餐具操作模拟基准（ARX双臂配置），包含10个任务（如堆叠、精准放置）。
    3.  **真实机器人**：双六自由度AgileX双臂平台，配备三个同步RGB-D相机，包含5个任务（清理桌子、放置杯子、递送积木等），收集了包含失败轨迹的数据。
*   **评测基准（Benchmark）**：模型作为策略评估代理的**可靠性**，即其预测的成功率与真实世界执行成功率的**相关性**和**排名准确性**。
*   **对比方法**：与当前基于视频扩散的世界模型方法对比，包括 **WorldEval**、**WorldGym** 和 **Ctrl-World**。确保所有方法使用相同的数据划分进行公平比较。

#### **5. 实验数量与充分性**
*   实验围绕五个研究问题（RQ）展开，设计全面：

    3.  **RQ3（自动成功检测）**：验证进度标记的判别能力，对比模型自动评分、人工对生成图像的评分、真实执行成功率。
    4.  **RQ4（评估可靠性）**：核心实验。在多个数据集（LIBERO单/多视角、RoboTwin、真实世界）和异构策略上，计算模型评估成功率与真实成功率的皮尔逊相关系数（r）和排名违规指标（MMRV）。
    5.  **RQ5（诊断指标）**：验证Δ-LPIPS作为动作可控性诊断指标的有效性。

#### **6. 主要结论与发现**
*   **动作可控性**：dWorldEval在失败数据上的Δ-LPIPS显著优于基线（0.352 vs. 0.416-0.701），能忠实渲染错误动作导致的失败，而非产生成功幻觉。

*   **自动评估可靠性**：模型预测的进度标记与人工判断高度一致，其自动评估的成功率与**真实执行成功率高度相关**（皮尔逊r ≈ 0.9），并能准确排名不同策略，显著优于所有基线方法。
*   **跨领域通用性**：在模拟（LIBERO, RoboTwin）和真实世界任务中均表现出一致的高保真度和评估可靠性。

#### **7. 优点**
*   **架构创新**：提出“动作作为标记”的统一序列建模范式，从根本上提升了动作在生成过程中的影响力，解决了现有方法动作信号被淹没的核心问题。
*   **设计精巧**：稀疏关键帧记忆以较低计算成本有效维持了长时程一致性；将进度预测作为生成目标的一部分，实现了与视觉结果内在一致的无外部依赖的自动评估。
*   **评估深入**：不仅比较最终评估指标，还提出了**Δ-LPIPS**这一针对**状态转移**而非静态外观的新评估指标，能更精准地诊断动作可控性，并通过动作打乱实验验证了模型的因果依赖性。
*   **验证全面**：在多个主流模拟基准和真实的双手机器人平台上进行了广泛验证，证明了方法的有效性和泛化能力。

#### **8. 不足与局限**
*   **任务范围**：虽然涵盖了桌面操作和双臂协调任务，但尚未涉及更复杂的移动操作、非刚性物体交互或动态变化环境。
*   **数据依赖**：模型的性能依赖于训练数据的质量和覆盖范围，特别是需要包含一定比例的失败轨迹来学习对错误动作的响应。对于全新的、数据分布差异极大的任务，其评估可靠性可能下降。
*   **计算成本**：尽管比真实物理仿真快，但基于扩散模型的逐帧生成推理速度（1.5秒/帧）对于需要超长时程或大量并行评估的场景仍可能成为瓶颈。
*   **物理精确性**：作为生成模型，它学习的是视觉外观的分布，而非精确的物理定律。对于极度依赖精确物理交互（如力控装配、柔性物体形变）的任务，其预测的物理合理性可能存在局限。
*   **进度标记的泛化**：进度标记依赖于任务特定的里程碑定义和VLM标注，对于定义模糊或难以分阶段的任务，该方法的适用性需要进一步验证。
