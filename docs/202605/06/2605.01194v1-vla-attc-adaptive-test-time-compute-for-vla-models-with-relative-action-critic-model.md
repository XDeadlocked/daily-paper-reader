## 摘要
视觉-语言-动作（VLA）模型在具身操作中展现出卓越的能力和泛化性。然而，其决策依赖于快速、本能的处理过程，缺乏深思熟虑。在面对需要更多考量的复杂或模糊场景时，这种策略常导致次优或灾难性动作。本文提出\textbf{VLA-ATTC}框架，为VLA模型赋予自适应测试时计算（TTC）能力。VLA-ATTC采用基于不确定性的“认知离合器”，在必要时动态从反射式执行切换到TTC深思阶段。在TTC阶段，新颖的\textbf{相对动作评判器}（RAC）模型通过成对比较从生成的候选动作中识别最优动作。这一相对机制取代了不稳定的绝对值估计，显著简化了学习目标。此外，我们引入一种高效采样策略以分摊计算成本，以及一个无需人工标注即可整理偏好对的自动化数据流程。在LIBERO-LONG基准测试中，VLA-ATTC将SOTA模型PI0.5的失败率降低了超过50%。我们将开源所有代码和权重。

## Abstract
Vision-Language-Action (VLA) models have demonstrated remarkable capabilities and generalization in embodied manipulation. However, their decision-making relies on a fast, instinctive process that lacks deliberation. This strategy often leads to suboptimal or catastrophic actions when facing complex or ambiguous scenarios that require greater consideration. In this paper, we introduce \textbf{VLA-ATTC}, a framework that endows VLA models with adaptive test-time compute (TTC). VLA-ATTC employs an uncertainty-based ``cognitive clutch'' to dynamically transition from reflexive execution to a TTC deliberation phase when necessary. During TTC phase, a novel \textbf{Relative Action Critic} (RAC) model identifies the optimal action from generated candidates via pairwise comparisons. This relative mechanism replaces unstable absolute value estimation, significantly simplifying the learning objective. Furthermore, we introduce an efficient sampling strategy to amortize computational costs and an automated data pipeline that curates preference pairs without manual annotation. On the LIBERO-LONG benchmark, VLA-ATTC reduces the failure rate of the SOTA model PI0.5 by over 50\%. We will open-source all the code and weights.

### **论文总结：VLA-ATTC: Adaptive Test-Time Compute for VLA Models with Relative Action Critic Model**

#### **1. 核心问题与整体含义**
*   **研究动机**：当前先进的视觉-语言-动作（VLA）模型（如PI0、PI0.5）在具身操作任务中依赖快速、直觉式的推理（类似“系统1”），这在简单场景下高效，但在复杂、模糊的场景中容易导致次优甚至灾难性的失败。模型缺乏一个根据场景难度进行“深思熟虑”（类似“系统2”）的机制。
*   **核心目标**：为VLA模型引入一种**自适应**的测试时计算（TTC）框架，使其能够在模型自身不确定时，动态切换到更耗时的深思模式，从而在不显著牺牲实时性的前提下，大幅提升在困难任务中的决策鲁棒性和成功率。

#### **2. 方法论**
*   **核心思想**：提出一个即插即用（plug-and-play）的框架VLA-ATTC，它不修改基础VLA模型，而是通过一个外部机制动态管理推理过程。
*   **关键技术细节**：
    1.  **不确定性量化（认知离合器）**：
        *   在每个时间步，使用相同的视觉-语言上下文但不同的随机种子，并行生成两个动作序列。
        *   使用**动态时间规整（DTW）** 距离计算这两个序列之间的差异，作为模型不确定性的度量。差异越大，不确定性越高。
        *   设定一个阈值（如不确定度分布的80%分位数）。当不确定性低于阈值时，执行第一个动作（快速模式）；当高于阈值时，触发“测试时计算”（TTC）深思阶段。
    2.  **TTC深思阶段**：
        *   **高效候选动作生成**：利用VLA模型推理中“视觉语言编码”成本高、“动作解码”成本低的特点，**共享一次编码结果**，并行批量生成N个（如16个）候选动作，以分摊主要计算开销。
        *   **相对动作评判器（RAC）**：
            *   **任务**：不直接给单个动作打分（绝对评估不稳定），而是判断给定两个动作`A`和`B`，在当前的视觉语言上下文和本体感知状态下，哪个更优（相对评估）。
            *   **架构**：一个轻量级Transformer。输入包括两个动作、它们的差值、当前状态。通过可学习的查询（Learnable Queries）从VLM主干中提取高层语义特征。采用**多分支注意力机制**，融合自注意力、与VLM原始特征的交叉注意力、与蒸馏查询特征的交叉注意力，实现高效且上下文感知的评判。
            *   **选择机制**：采用**锦标赛式淘汰**。RAC对候选动作两两比较，胜者进入下一轮，直至选出最优动作。
    3.  **自动化数据构建**：
        *   为了训练RAC，需要大量（动作A， 动作B， 偏好）数据对。
        *   提出一种**无需人工标注**的自动化流程：利用基于流匹配（Flow-Matching）的VLA动作生成模型，通过改变ODE求解器的步数（`N_steps`）来生成质量不同的动作。例如，用多步（高质量）和少步（低质量）生成动作对，天然构成“好-坏”偏好对。
