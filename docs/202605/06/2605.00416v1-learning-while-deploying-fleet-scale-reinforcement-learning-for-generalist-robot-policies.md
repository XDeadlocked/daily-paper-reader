## 摘要
通用机器人策略日益受益于大规模预训练，但仅靠离线数据不足以实现稳健的现实世界部署。部署中的机器人会遇到分布偏移、长尾故障、任务变化以及人工纠正机会，这些是固定的演示数据集无法完全捕捉的。我们提出了“部署中学习”（LWD），这是一个面向通用视觉-语言-动作（VLA）策略持续后训练的舰队级离线到在线强化学习框架。从预训练的VLA策略出发，LWD通过利用在机器人舰队中收集的自主运行数据和人工干预，实现了部署、共享物理经验、策略改进和重新部署之间的闭环。为了从异构、稀疏奖励的舰队数据中稳定学习，LWD结合了用于鲁棒价值估计的分布隐式价值学习（DIVL）和用于基于流的VLA动作生成器中策略提取的通过伴随匹配的Q学习（QAM）。我们在由16台双臂机器人组成的舰队上，在八项真实世界操作任务（包括语义化杂货补货和3-5分钟的长时程任务）中验证了LWD。随着舰队经验的积累，单一通用策略不断改进，平均成功率达到了95%，在长时程任务上提升最为显著。

## Abstract
Generalist robot policies increasingly benefit from large-scale pretraining, but offline data alone is insufficient for robust real-world deployment. Deployed robots encounter distribution shifts, long-tail failures, task variations, and human correction opportunities that fixed demonstration datasets cannot fully capture. We present Learning While Deploying (LWD), a fleet-scale offline-to-online reinforcement learning framework for continual post-training of generalist Vision-Language-Action (VLA) policies. Starting from a pretrained VLA policy, LWD closes the loop between deployment, shared physical experience, policy improvement, and redeployment by using autonomous rollouts and human interventions collected across a robot fleet. To stabilize learning from heterogeneous, sparse-reward fleet data, LWD combines Distributional Implicit Value Learning (DIVL) for robust value estimation with Q-learning via Adjoint Matching (QAM) for policy extraction in flow-based VLA action generators. We validate LWD on a fleet of 16 dual-arm robots across eight real-world manipulation tasks, including semantic grocery restocking and 3--5 minute long-horizon tasks. A single generalist policy improves as fleet experience accumulates, reaching an average success rate of 95%, with the largest gains on long-horizon tasks.

#### 1. 核心问题与整体含义
*   **研究动机**：大规模离线预训练的通用视觉-语言-动作（VLA）机器人策略，在真实世界部署时，仍会面临**分布偏移、长尾故障、任务变化**等挑战。固定的预训练数据集无法覆盖所有部署中遇到的情况，导致策略鲁棒性不足。
*   **核心思想**：将**部署本身转化为持续学习的引擎**。提出“部署中学习”（LWD）框架，通过一个机器人舰队在真实任务中自主运行并收集数据（包括成功、失败和人工干预），形成一个**数据飞轮**，持续地对一个共享的通用策略进行离线到在线的强化学习后训练，从而使其在部署中不断自我改进。

#### 2. 提出的方法论
*   **整体流程**：分为两个阶段。
    1.  **离线预训练阶段**：在一个混合了专家演示、历史策略运行数据（含成败）和人工探索数据的离线缓冲区上，初始化策略、评论家和价值函数。
    2.  **在线持续训练阶段**：将策略部署到机器人舰队执行任务，异步收集在线交互数据（含自主运行和必要的人工干预）至在线缓冲区。学习器从**混合的离线与在线缓冲区**中采样，更新模型，并定期将改进后的策略同步回舰队，形成闭环。
*   **关键技术一：分布隐式价值学习（DIVL）**
    *   **问题**：舰队数据异构、奖励稀疏，同一状态-动作对的回报可能呈多模态或重尾分布。传统的标量价值函数会将这些不同结果平均化，模糊掉罕见但成功的高回报模式。
    *   **解决方案**：学习一个**状态条件下的回报分布模型**，而非单一标量。通过最小化负对数似然来拟合这个分布。在计算时序差分目标时，使用该分布的 **τ-分位数** 作为自举目标，保留了隐式Q学习中对高价值数据动作的乐观偏向原则。
    *   **自适应τ**：根据学习到的价值分布的熵（不确定性）动态调整τ值。分布不确定时使用更保守的τ，确定时使用更乐观的τ，以校准自举目标的乐观程度。
*   **关键技术二：通过伴随匹配的Q学习（QAM）进行策略提取**
    *   **问题**：预训练的VLA策略通常是基于流匹配的生成模型，直接通过多步去噪过程反向传播评论家梯度来计算策略梯度，在计算上昂贵且数值不稳定。
    *   **解决方案**：采用QAM方法。将策略更新目标（一个用评论家加权的KL正则化目标）转化为沿**参考流轨迹**的局部回归损失。具体而言，利用评论家对最终生成动作的梯度来设置**伴随状态**的终端条件，然后反向求解伴随动力学，为流模型的向量场提供逐点的监督信号，从而实现稳定、高效的政策更新。

#### 7. 优点
*   **系统层面**：实现了从“部署即终点”到“部署即学习源”的理念转变，构建了可行的**大规模机器人数据飞轮**，对现实世界机器人学习具有重要实践意义。
