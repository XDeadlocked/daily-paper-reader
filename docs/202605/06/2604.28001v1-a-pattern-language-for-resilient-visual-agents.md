## 摘要
将多模态基础模型集成到企业生态系统中，带来了根本性的软件架构挑战。架构师必须平衡相互竞争的质量属性：视觉语言行动（VLA）模型的高延迟和非确定性，与企业控制回路所要求的严格确定性和实时性能。在本研究中，我们提出了一种用于视觉智能体的架构模式语言，它将快速、确定性的反射与缓慢、概率性的监督分离开来。该语言包含四种架构设计模式：（1）混合可供性集成，（2）自适应视觉锚定，（3）视觉层次合成，以及（4）语义场景图。

## Abstract
Integrating multimodal foundation models into enterprise ecosystems presents a fundamental software architecture challenge. Architects must balance competing quality attributes: the high latency and non-determinism of vision language action (VLA) models versus the strict determinism and real-time performance required by enterprise control loops. In this study, we propose an architectural pattern language for visual agents that separates fast, deterministic reflexes from slow, probabilistic supervision. It consists of four architectural design patterns: (1) Hybrid Affordance Integration, (2) Adaptive Visual Anchoring, (3) Visual Hierarchy Synthesis, and (4) Semantic Scene Graph.

### 2. 方法论：核心思想与关键技术
*   **核心思想**：**分层控制与摊销推理**。将智能体架构划分为三个异步控制回路（反射、结构、监督），并引入**系统1（快速、直觉）和系统2（慢速、推理）** 的类比。核心思想是让廉价的、确定性的反射层（系统1）处理绝大多数常规操作，仅在遇到不确定性、UI漂移或失败时，才触发昂贵、概率性的VLA监督层（系统2）进行修复和指导，从而“摊销”智能推理的成本。
*   **关键技术细节（四大模式）**：
    1.  **混合可供性集成模式**：解决多模态感知冲突（如视觉检测到按钮，OCR读出非操作文本）。通过**并行运行**轻量级UI对象检测器和OCR引擎，进行**几何融合与冲突消解**，生成带有置信度分数的、归一化的“可供性”接口，作为下游世界模型的清洁数据源。
    2.  **自适应视觉锚定模式**：解决**漂移-延迟困境**。在反射层维护一个**视觉锚点（模板/特征）缓存**用于快速（<50ms）定位。当匹配置信度低于安全阈值时，触发异常，由监督层的VLA模型进行语义重定位，并**更新缓存**。这实现了“以脚本的速度运行，保留LLM的适应性”。
    3.  **视觉层次合成模式**：解决**引用歧义问题**（如区分数据网格中不同行的相同按钮）。将平坦的感知输出，通过**基于格式塔原则（包含、对齐）的布局解析算法**，合成为**层次化的UI表示**（如表单、表格、模态框）。这使得规划器可以使用**相对寻址**（如 `click(“Submit”, “Login_Form”)`），从而对UI平移具有鲁棒性。
    4.  **语义场景图模式**：为**长视野规划和安全性验证**提供支持。将层次化UI表示进一步构建为**静态、可查询的语义场景图**。节点是语义实体，边表示功能和空间关系。在执行高风险操作前，智能体可以遍历此图来显式验证前置条件，提高决策的可靠性和可解释性。
