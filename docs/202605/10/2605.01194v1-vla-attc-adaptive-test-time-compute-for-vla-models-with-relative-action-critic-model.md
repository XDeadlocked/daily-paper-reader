## 摘要
视觉-语言-动作（VLA）模型在具身操作中展现出卓越的能力和泛化性。然而，其决策依赖于快速、本能的处理过程，缺乏深思熟虑。在面对需要更多考量的复杂或模糊场景时，这种策略常导致次优或灾难性动作。本文提出\textbf{VLA-ATTC}框架，为VLA模型赋予自适应测试时计算（TTC）能力。VLA-ATTC采用基于不确定性的“认知离合器”，在必要时动态从反射式执行切换到TTC深思阶段。在TTC阶段，新颖的\textbf{相对动作评判器}（RAC）模型通过成对比较从生成的候选动作中识别最优动作。这一相对机制取代了不稳定的绝对值估计，显著简化了学习目标。此外，我们引入了一种高效采样策略以分摊计算成本，以及一个无需人工标注即可整理偏好对的自动化数据流水线。在LIBERO-LONG基准测试中，VLA-ATTC将SOTA模型PI0.5的失败率降低了超过50%。我们将开源所有代码和权重。

## Abstract
Vision-Language-Action (VLA) models have demonstrated remarkable capabilities and generalization in embodied manipulation. However, their decision-making relies on a fast, instinctive process that lacks deliberation. This strategy often leads to suboptimal or catastrophic actions when facing complex or ambiguous scenarios that require greater consideration. In this paper, we introduce \textbf{VLA-ATTC}, a framework that endows VLA models with adaptive test-time compute (TTC). VLA-ATTC employs an uncertainty-based ``cognitive clutch'' to dynamically transition from reflexive execution to a TTC deliberation phase when necessary. During TTC phase, a novel \textbf{Relative Action Critic} (RAC) model identifies the optimal action from generated candidates via pairwise comparisons. This relative mechanism replaces unstable absolute value estimation, significantly simplifying the learning objective. Furthermore, we introduce an efficient sampling strategy to amortize computational costs and an automated data pipeline that curates preference pairs without manual annotation. On the LIBERO-LONG benchmark, VLA-ATTC reduces the failure rate of the SOTA model PI0.5 by over 50\%. We will open-source all the code and weights.

### **论文总结：VLA-ATTC: Adaptive Test-Time Compute for VLA Models with Relative Action Critic Model**

#### **1. 核心问题与整体含义**
*   **研究动机**：当前主流的视觉-语言-动作（VLA）模型（如PI0, PI0.5）在推理时采用快速、本能的“系统1”模式，缺乏在复杂、模糊场景下所需的审慎“系统2”式思考。这导致模型在面对需要精细规划的任务时，容易产生次优甚至灾难性的动作。
*   **核心目标**：为VLA模型引入一种**自适应**的测试时计算（TTC）机制，使其能够在“不确定”时切换到深思模式，从而在不显著牺牲实时性的前提下，大幅提升决策的鲁棒性和成功率。

#### **2. 方法论**
*   **核心思想**：设计一个“即插即用”的框架，在不修改基础VLA模型的前提下，为其增加一个按需触发的审慎决策层。
*   **关键技术细节**：
    1.  **不确定性量化（认知离合器）**：
        *   在每一步，使用**同一视觉-语言上下文**但**不同随机种子**生成两个动作序列。
        *   计算这两个序列之间的**动态时间规整（DTW）距离**作为不确定性度量。距离越大，表明模型对当前状态越不确定。
        *   设定一个阈值（如离线数据不确定度分布的80%分位数），当不确定性超过阈值时，触发TTC深思阶段。
    2.  **高效测试时计算（TTC）阶段**：
        *   **并行候选动作生成**：利用VLA模型推理中“视觉-语言编码”成本高、“动作解码”成本低的特点，**仅预填充一次视觉-语言上下文**，然后并行采样生成N个候选动作，分摊主要计算开销。
        *   **锦标赛式相对优选**：使用**相对动作评判器（RAC）** 对候选动作进行迭代的成对比较（锦标赛），选出最终动作。RAC回答“动作A是否优于动作B？”，这比直接预测绝对分值更稳定、更容易学习。
    3.  **相对动作评判器（RAC）模型**：
        *   **输入**：两个待比较的动作序列、它们的差值、当前本体感知状态。
        *   **架构**：一个轻量级Transformer，其深度与基础VLM对齐。核心是**多分支注意力机制**，同时关注：RAC自身特征（自注意力）、VLM的原始特征（原始交叉注意力）、以及通过可学习查询从VLM中提取的浓缩语义特征（查询交叉注意力）。这种设计使其既能理解动作细节，又能充分感知任务上下文。
    4.  **自动化数据流水线**：
        *   为训练RAC，需要大量（动作A， 动作B， 偏好）数据对。
        *   利用基于流匹配（Flow-Matching）的VLA动作头特性：**使用不同数量的ODE求解步数**生成同一状态下的动作。步数多的动作质量高（接近专家），步数少的动作质量低但语义大致正确。由此自动构建出高质量偏好对，无需人工标注。

#### **3. 实验设计**
*   **数据集/场景**：
    *   **仿真**：LIBERO-LONG基准测试（10个长视野、多阶段的复杂物体操纵任务）。
    *   **真实世界**：使用Agilex Piper机械臂执行3个任务（堆叠积木、倒水、清扫垃圾）。
*   **基准模型**：以当前SOTA VLA模型 **PI0** 和 **PI0.5** 作为基础策略。
*   **对比方法**：
    *   **基线**：原始PI0/PI0.5。
    *   **代表性并行深思方法**：**Robomonkey**（使用大型外部评判器进行绝对评分）。
    *   **自身变体**：VLA-ATTC (Full)（始终触发深思，无认知离合器）。

#### **6. 主要结论与发现**
*   **性能显著提升**：在LIBERO-LONG上，VLA-ATTC将PI0的平均成功率从82.8%提升至90.6%（+7.8%），将PI0.5从90.6%提升至94.0%（+3.4%）。在最具挑战性的任务上（“Both pots on stove”），将PI0的失败率降低了近一半（从60%失败降至42%失败）。
*   **高效实时性**：通过“认知离合器”和高效并行采样，VLA-ATTC仅将控制频率从基线的23.3 Hz降至20.8 Hz，远高于Robomonkey的1.5 Hz，满足实时机器人控制需求。
*   **方法有效性验证**：
    *   “认知离合器”能有效识别稀疏的困难状态。
    *   相对评判（RAC）优于绝对评分。
    *   自动化数据生成管道是有效的。

#### **7. 优点**
*   **即插即用**：无需对基础VLA模型进行微调或修改。
*   **自适应计算**：“认知离合器”实现了计算资源的动态、按需分配，平衡了性能与效率。
*   **稳定高效的评判机制**：RAC模型的**相对比较**设计避免了难以定义的绝对评分问题，且结构轻量、上下文感知能力强。
*   **数据获取自动化**：提出的数据生成管道**完全无需人工标注**，解决了偏好学习的数据瓶颈，具有良好的可扩展性。
*   **工程实现优化**：利用VLA模型推理的**计算不对称性**，通过单次预填充、并行采样的方式，极大降低了多候选动作生成的开销。

#### **8. 不足与局限**
*   **阈值依赖**：不确定性阈值τ需要基于离线数据设定，可能对任务分布敏感，缺乏完全的自适应性。
*   **RAC训练依赖**：RAC模型的性能依赖于自动化管道生成的数据质量。虽然论文验证了其有效性，但在分布外或极端复杂场景下的泛化能力仍需进一步检验。
*   **计算开销增加**：尽管通过自适应触发控制了频率，但在触发深思时，生成N个候选动作并进行log₂(N)轮RAC评估，仍会引入额外的计算延迟，在极端资源受限的边缘设备上应用可能面临挑战。
*   **仿真到现实的差距**：虽然在真实机器人上进行了测试，但任务数量（3个）相对有限，需要在更广泛、更复杂的真实世界任务中验证其鲁棒性和泛化能力。
*   **不确定性度量的普适性**：当前使用DTW距离度量动作不确定性，对于其他类型的动作表示（如离散动作、符号指令）是否同样有效，未做探讨。
