## 摘要
动作标签告诉视觉-语言-动作（VLA）策略要模仿哪些机器人命令，但不告诉这些命令如何改变3D世界。对齐的演示片段包含这种缺失的监督，因为其K帧转换记录了在相应K个动作期间产生的几何、运动、可见性和相机变化。我们提出Track4Action，一个将这种已实现的转换从冻结的世界中心3D追踪器蒸馏到当前观测VLA策略的框架。在训练期间，Track4World将片段V_{t:t+K}编码为池化的追踪器特征。可学习的追踪查询从当前VLA隐藏状态推断此特征，在共享空间中匹配它，并通过特征级门控调节流匹配动作头。追踪器特征仅定义对齐目标，因此在部署时既不使用片段也不使用追踪器。Track4Action在零样本LIBERO-Plus上达到82.3%，比无对齐变体提高7.6个百分点，比LaMP提高3.0个百分点。在干净和随机化的RoboTwin 2.0分割上分别获得80.44%和81.48%的准确率，并在四个物理双臂任务上平均成功率达到67.5%，比无对齐变体高出25.0个百分点。在仿真和物理任务上的收益支持动作对齐的3D追踪器特征作为无追踪器VLA部署的特权监督。我们的项目页面可在https://wing0night.github.io/track4action-project-page获取。

## Abstract
Action labels tell a vision-language-action (VLA) policy which robot commands to imitate, but not how those commands change the 3D world. The aligned demonstration clip contains this missing supervision because its $K$ frame transitions record the geometry, motion, visibility, and camera change produced during the corresponding $K$ actions. We introduce Track4Action, a framework that distills this realized transition from a frozen world-centric 3D tracker into a current-observation VLA policy. During training, Track4World encodes the clip $V_{t:t+K}$ into a pooled tracker feature. Learnable track queries infer this feature from current VLA hidden states, match it in a shared space, and condition a flow-matching action head through a feature-wise gate. The tracker feature only defines the alignment target, so neither the clip nor the tracker is used at deployment. Track4Action reaches 82.3% on zero-shot LIBERO-Plus, improving the alignment-free variant by 7.6 points and LaMP by 3.0 points. It obtains 80.44% and 81.48% on the clean and randomized RoboTwin 2.0 splits, and 67.5% average success across four physical bimanual tasks, 25.0 points above the alignment-free variant. The gains across simulation and physical tasks support action-aligned 3D tracker features as privileged supervision for tracker-free VLA deployment. Our project page is available at https://wing0night.github.io/track4action-project-page.

## 一、核心问题与研究动机

- **核心问题**：视觉-语言-动作（VLA）策略的动作标签只告诉机器人“执行什么命令”，却未揭示“这些命令如何改变3D世界”。同一个末端执行器位移可能穿越自由空间、搬运物体或改变相机视角，而这些语义差异直接决定任务成败，但动作标签本身并不编码。
- **研究动机**：演示视频中与动作块（action chunk）对齐的K帧片段，恰好记录了该段动作所引发的几何、运动、可见性与相机变化。作者的核心洞察是：**将这种“已实现的世界转换”作为特权监督信号**（privileged supervision），在训练时引导VLA策略学习动作相关的世界动态表征，而在部署时完全不依赖片段或追踪器。
- **整体含义**：通过将“空间智能”（3D追踪器理解场景如何演化）与“语义智能”（VLA理解任务意图）结合，使当前观测条件下的VLA策略具备对4D场景动态的隐式感知能力。

## 二、方法论：Track4Action

### 2.1 总体框架

Track4Action 将训练过程拆分为两条路径：

1. **教师分支（训练专用）**：冻结的 Track4World 追踪器读取与动作块对齐的主视角片段，提取世界中心3D追踪特征。
2. **学生分支（训练+部署）**：VLA骨干处理当前观测，通过可学习的“追踪查询”（track queries）推断教师特征，并将其门控融合进动作头。

### 2.2 关键步骤

1. **动作对齐样本构建**：在时间步t，策略预测K步动作块 $\hat{A}_t = (a_t, \dots, a_{t+K-1})$；训练时配套的主视角片段 $V_{t:t+K} = (o_t, \dots, o_{t+K})$ 恰好覆盖这K个动作对应的K帧转换。
2. **教师特征构建**：冻结的 Track4World 处理切片，输出场景、运动、可见性与相机等token，经池化得到紧凑的追踪特征：
   \[
   f^{\text{trk}}_t = \text{sg}[\text{Pool}(T(V_{t:t+K}))]
   \]
   其中sg表示停止梯度。
3. **学生特征推断**：VLA骨干编码当前图像与指令 $H_t = E_\theta(l, I_t)$；可学习的追踪查询Q通过交叉注意力读取 $H_t$，得到 $Z_t = D_\theta(Q, H_t)$。
4. **对齐损失**：将 $Z_t$ 与 $f^{\text{trk}}_t$ 映射到共享空间后计算L2距离：
   \[
   \mathcal{L}_{\text{align}} = \|\bar{z}_t - \bar{f}^{\text{trk}}_t\|_2^2
   \]
5. **门控融合与动作生成**：将 $Z_t$ 通过特征级门控（feature-wise gate）融合回VLA序列，形成动作条件 $H^{\text{cond}}_t$；教师特征 $f^{\text{trk}}_t$ 仅作为对齐目标，不直接参与动作生成。动作头采用流匹配（flow matching）目标 $\mathcal{L}_{\text{act}}$，总损失为：
   \[
   \mathcal{L} = \lambda_{\text{act}}\mathcal{L}_{\text{act}} + \lambda_{\text{align}}\mathcal{L}_{\text{align}}
   \]
6. **部署时免追踪器**：推理时只需计算 $H_t, Z_t, H^{\text{cond}}_t$，动作块从噪声中流式生成；追踪器、片段、对齐分支全部丢弃。

### 2.3 关键设计决策

- **时间对齐**：追踪目标与动作块严格对应同一段K帧转换，使目标描述的是“该动作特有的世界变化”而非泛化的视频内容。
- **动作面向的表征**：追踪查询既是对齐损失的载体，也是动作头的输入，避免了“辅助解码器与动作生成脱节”的问题。
- **兼容性**：不改变VLA的输入输出接口，可与不同骨干（backbone）和动作解码器搭配。

## 六、主要结论与发现

1. **特权监督的有效性**：动作对齐的3D追踪特征可以作为免追踪器的特权监督，显著提升VLA策略的控制性能。
2. **跨域一致增益**：在LIBERO平均97.0%（+2.8分 vs 无对齐）、LIBERO-Plus平均82.3%（+7.6分）、RoboTwin 2.0干净80.44% / 随机化81.48%（+约39-42分 vs 无对齐）、物理任务平均67.5%（+25.0分）上均有一致提升。
3. **长时程任务收益最大**：LIBERO-Long提升9.6分（95.8% vs 86.2%），表明追踪监督在需要跨阶段保持任务状态时最有价值。
4. **零样本鲁棒性全面改善**：7个扰动维度全部优于无对齐变体，Camera（+18.3）、Noise（+9.0）、Robot（+8.7）增幅最大，说明增益非单一维度驱动。
5. **部署零负担**：教师特征、片段与追踪器在部署时全部移除，仅保留追踪查询与门控通路。

## 七、方法优点

- **创新性**：首次将世界中心3D追踪器的稠密追踪表征提炼为VLA的动作面对齐目标，而非直接预测轨迹或图像。
- **部署友好**：特权监督只在训练阶段使用，推理时无额外计算与模型依赖。
- **架构通用**：不修改VLA输入输出接口，可适配不同骨干与动作头。
- **设计合理**：追踪查询同时承担“对齐学生”和“动作条件”双重角色，避免了辅助分支与策略脱节的问题。
- **实验覆盖面广**：从饱和基准到零样本OOD、50任务大规模双臂、真实物理操作，既有受控消融也有标杆对比。

## 八、不足与局限

- **数据要求**：需要时间有序的演示片段（K+1帧对齐K个动作），单帧图像-动作对无法提供这种监督。
- **关联脆弱性**：场景中存在独立移动物体时，命令与场景变化之间的对应关系可能被削弱。
- **表征粒度**：池化后的段级特征可能丢失局部接触对应关系（如抓取点的精细运动）。
- **教师误差继承**：Track4World在遮挡或快速运动时的误差会被蒸馏进学生。
- **视角限制**：仅使用主摄像机视角，未利用多视角一致性。
- **物理评估覆盖有限**：仅1个双臂平台、4个任务、3种视觉偏移；变形操作（折叠毛巾）成功率仅40%，仍明显落后于π0.5的70%，说明可变形物体操控仍是显著短板。
- **计算资源未披露**：论文未报告具体GPU型号、数量与训练时长，可复现性与成本评估不便。
