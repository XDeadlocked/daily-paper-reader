## 摘要
最近的视觉-语言-动作（VLA）模型几乎普遍将机器人本体感觉状态作为输入，但以不兼容的方式接入——序列化为文本提示、投影到视觉-语言前缀中，或直接馈送到动作专家——并且几乎总是作为单帧当前状态。三个问题仍然悬而未决：（1）当前状态是否以及在哪些任务上真正改善了闭环控制；（2）状态历史有多大帮助，其益处是否反映真实的时序变化而非额外的条件化能力；（3）状态应在模型的哪个位置进入——视觉-语言主干还是动作生成模块。我们通过在流匹配VLA上进行受控实验来回答这些问题，全程固定主干网络、训练数据、动作表示和评估协议。我们在匹配的实现细节下实现了五种代表性接口——离散状态提示、VLM前缀、动作前缀、状态专家和特征调制——并在跨越三个任务族共45个原子任务以及20个复合任务上进行了评估；然后我们将状态历史长度从1帧扫描到96帧，以考察历史状态信息如何影响模型性能。实验为所有三个问题提供了系统性的答案，并凝练为可测试的、面向状态感知VLA的设计原则。

## Abstract
Recent Vision-Language-Action (VLA) models almost universally take robot proprioceptive state as input, yet wire it in incompatible ways -- serialized into text prompts, projected into the vision-language prefix, or fed directly to the action expert -- and almost always as a single current frame. Three questions remain open: (1) whether, and on which tasks, current state actually improves closed-loop control; (2) how much state history helps, and whether its benefit reflects genuine temporal variation rather than added conditioning capacity; and (3) where state should enter the model -- the vision-language backbone or the action-generation module. We answer these questions through controlled experiments on a flow-matching VLA, fixing the backbone, training data, action representation, and evaluation protocol throughout. We implement five representative interfaces -- discrete state prompt, VLM prefix, action prefix, state expert, and feature modulation -- under matched implementation details, and evaluate them on 45 atomic tasks spanning three task families plus 20 composite tasks; we then sweep the state-history length from 1 to 96 frames to examine how historical state information affects model performance. The experiments yield systematic answers to all three questions, distilled into testable design principles for state-aware VLAs.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景现状**：近年来，大规模训练的视觉-语言-动作（VLA）模型已在机器人操作任务上展现出强大的泛化能力。受生物运动控制中本体感觉（proprioception）的重要作用启发，研究者自然期望机器人自身的本体感觉状态（关节角度、末端执行器位姿、夹爪开度等）能为VLA提供平滑、稳健的控制信号。
- **核心矛盾**：尽管几乎所有VLA模型都将本体感觉状态作为输入，但不同的模型在接入方式上差异极大且不兼容——π0.5将状态离散化为文本token串联进语言提示，OpenVLA-OFT连续投影到语言模型序列，GR00T N1则直接将状态嵌入馈送到动作头。这些设计差异又与主干网络、预训练、数据、动作表示等混杂在一起，导致彼此之间无法直接比较。
- **三个悬而未决的问题（RQ）**：
  1. **RQ1（是否用）**：当前状态是否真正改善闭环控制？在哪些任务上有效？
  2. **RQ2（用多少）**：状态历史能提供多大帮助？该帮助是否反映真实时序变化，而非只是额外条件化容量？
  3. **RQ3（放哪里）**：状态应注入视觉-语言主干（VLM侧）还是动作生成模块（动作侧）？
- **论文的定位**：这是首次在固定一切其他因素的统一框架下，系统比较状态信号在不同接口、不同历史深度和不同注入路径中的效果。

### 3. 实验设计（数据集、基准、对比方法）

#### 3.1 Benchmark
- **RoboCasa365**（基于RoboCasa仿真平台）：包含多样厨房场景、机器人初始配置、物体实例和操作任务。
- 视觉输入：左外部相机、右外部相机、腕部相机三个视角。

#### 3.2 原子任务基准
- 将45个原子任务按主导操作语义预划分为三个任务族（每族15个任务）：
  - **族A：重排/抓放**（Rearrangement/pick-and-place）——大范围末端执行器和移动基座定位
  - **族B：铰接物体交互**（Articulation）——持续接触和运动阶段建模
  - **族C：旋钮/开关精确控制**（Precision）——小工作空间对高局部精度的要求
- 每个任务族训练单独的类别专家。每个任务用固定 seed 调度执行50次闭环 rollout。

#### 3.3 复合任务基准
- 采用`lifelong_learning_phase2`设置：20种任务类型，每个任务在一个回合内串联2-3个原子子目标。
- 每个接口在20种任务上联合训练一个策略；评估仅保留新episodes，衡量分布内复合控制能力。
- 除默认末端执行器位姿状态外，还使用关节角度状态重复关键复合任务比较（动作空间仍为末端执行器增量）。

#### 3.4 对比方法
- **无状态基线（NS）** + 五种状态接口（sp/vp/ap/se/fm）
- 历史长度扫描：1, 4, 8, 16, 32, 48, 64, 96帧
- **槽匹配对照实验**：将当前状态重复填充到相同数量的槽位（repeat-current control），用于隔离"真实时序内容"与"额外条件化容量"的效应。

### 6. 论文的主要结论与发现

#### 结论1（RQ1）：当前状态有选择性收益，任务相关的接口排序反转
- 总体上，五种接口的宏平均成功率均超过无状态基线（54.6%），增益+1.1至+3.1个百分点。sp达到57.7%，是唯一配对bootstrap 95%置信区间排除零的接口。
- **不存在任务无关的最优接口**：
  - 族A（重排）：sp最优（68.7%，+7.0）
  - 族B（铰接）：vp最优（68.8%，+6.1），se和fm紧随其后
  - 族C（旋钮/开关）：se最优（42.8%，+3.3），vp是唯一低于基线的接口（-1.2）
- 性能与成本需要权衡：sp收益最大但边际成本最高；se和fm几乎达到相同宏平均（57.6%）但成本只是零头。

#### 结论2（RQ2）：短历史有帮助，长原始历史有害
- 非单调趋势：短历史（K=4~16）优于单帧模型，长历史（K≥32）无额外收益甚至退化。
- 族C对长历史最敏感，VLM前缀注入时退化最为严重。
- **K=8作为实用默认值**：在原子任务上增益最强且最一致。
- **槽匹配对照证实**：K=8的真实历史显著优于"重复当前状态"的对照（复合任务AP上+8.2个点），说明增益来自真实时序变化而非额外token容量。
- 该结论在关节角度状态表示下同样成立，表明鲁棒于状态坐标系选择。

#### 结论3（RQ3）：注入路径偏好随历史长度切换
- **单帧（K=1）**：VLM侧更优。复合任务上vp1为34.4%，而ap1仅28.2%；关节角度状态也呈现相同方向。
- **短历史（K=8）**：偏好翻转至动作侧。AP从K=1到K=8提升+10.8（EEF状态）和+4.8（关节角度），而同样历史注入VLM前缀仅-0.6和+2.2。
- **设计规则**：*将当前状态帧注入VLM，将多帧历史路由到动作头*。
- 探针实验提供了数据流解释：VLM侧状态显著改变生成前的多模态上下文（语言到图像注意力重分配+17.3%/22.0%），动作前缀状态则直接在动作专家内部影响生成；AP8的状态条件化校正与专家残差的对齐从0.079提升到0.270。

#### 结论4（案例研究补充）
- PrepareToast案例表明：AP8的优势集中在后期"返回关闭橱柜"阶段（S3达到率+26个百分点）；固定策略对真实历史vs重复当前状态的敏感性在动作阶段边界处是阶段内的5.2倍。

### 7. 优点（方法与实验设计亮点）

1. **严格的控制变量方法**：首次在固定骨干/数据/动作表示/评估协议的统一框架下比较状态接口，使性能差异可归因于状态设计本身。
2. **槽匹配对照实验设计精巧**：通过"重复当前状态"控制条件化容量，干净地分离时序内容与容量效应，排除了"更多token"这一混淆解释。
3. **任务族预划分**：基于控制语义而非模型表现划分三类任务，使结论具有可解释性——不同接口在不同控制需求下的表现反转模式非常有说服力。
4. **多层级证据链**：系统级闭环成功率 + 固定checkpoint探针（注意力分布、流轨迹校正方向）+ 案例研究（里程碑分析、条件化反事实动作距离）三者互补，形成了从行为到机制的证据闭环。
5. **计算成本分析透明**：附录C给出详细的分析推导，区分了active token数、参数量、吞吐量三个易混淆的概念。
6. **结论实用且可操作**：提炼为"单帧进VLM、短历史进动作头"的设计默认值，对工程实践有直接指导意义。

### 8. 不足与局限

1. **缺乏真实机器人验证**：所有实验均在RoboCasa365仿真环境中进行，缺少物理平台的验证。
2. **状态模态有限**：仅研究纯运动学状态（EEF位姿/关节角度/夹爪），未覆盖力、触觉、本体感觉以外的模态。
3. **统计证据强度有限**：绝大多数接口的增益置信区间包含零；主要结论（如ap在K=8的优势）基于单种子点估计，作者也承认这属于定向模式而非统计排序。
4. **公平性瑕疵**：se和fm由于硬件分配原因训练的名义样本暴露量略低（不用于容量匹配的声明）；不同接口的投影宽度和参数量存在天然差异（vp为d=2048，其余连续接口为d=1024），这使接口比较不能完全分离拓扑与容量的效应。
5. **历史扫描未校正多重比较**：深度扫描被标注为探索性分析。
6. **路由规则的适用范围**：VLM侧单帧与动作侧短历史之间的偏好切换，在关节角度状态K=8时两路线已收敛（36.2% vs 35.8%），且探针证据为描述性而非因果性。
7. **类别专家vs统一策略**：原子任务按族分别训练专家，复合任务才联合训练，原子与复合任务的训练策略不完全一致，可能影响跨基准的结论推演。
