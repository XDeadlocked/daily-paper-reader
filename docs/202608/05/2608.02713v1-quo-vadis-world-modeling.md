## 摘要
持续改进的智能体需要超越静态监督的动态交互反馈，然而直接与真实环境交互成本高昂、速度缓慢、存在安全风险且难以并行化。世界建模提供了一种自然的中间代理，使智能体在采取真实行动之前，能够查询成本更低、更可控的反馈。经典世界模型主要通过未来物理状态预测来实例化这一代理，这种表述对需要超出原始状态转换的可操作反馈的智能体而言虽有用但较为狭窄。在本工作中，我们提出了“智能体中心交互式世界代理”这一概念，将基本范式从物理状态转移转变为智能体可用信息转移，例如执行结果、检索到的经验或技能以及验证信号，从而拓宽世界建模的范围，为持续改进的智能体提供多功能反馈。为了系统性地映射这一设计空间，我们根据反馈模态将世界代理组织为六种功能形式：动力学代理、空间代理、执行代理、记忆/经验代理、技能代理和奖励/验证代理，它们共同刻画了世界建模服务于智能体改进的主要方式。我们进一步分析了这些代理如何在三个递进层面上赋能智能体：L.1 推理时引导，其中代理输出丰富上下文信息以优化决策；L.2 训练时优化，其中代理输出产生奖励、批评或合成轨迹用于策略学习；以及 L.3 智能体-代理协同进化，其中真实环境证据持续更新代理和智能体以实现共同进化。最终，本工作将世界建模重塑为智能体中心范式，为构建能够赋能智能体更好规划、更快学习并持续进化的世界代理奠定了路线图。

## Abstract
Continually improving agents require dynamic interaction feedback beyond static supervision, yet direct real-environment interaction is costly, slow, unsafe, and hard to parallelize. World modeling offers a natural intermediate proxy that allows agents to query lower-cost, more controllable feedback before committing to real actions. Classical world models instantiate this proxy primarily through future physical-state prediction, a formulation useful yet narrow for agents that require actionable feedback beyond raw state transitions. In this work, we conceptualize Agent-Centric Interactive World Proxies, shifting the fundamental paradigm from physical state transitions to agent-usable information transitions, such as execution outcomes, retrieved experiences or skills, and verification signals, broadening the scope of world modeling to provide versatile feedback for continually improving agents. To systematically map this design space, we organize world proxies into six functional forms based on their feedback modalities: dynamics, spatial, execution, memory/experience, skill, and reward/verification proxies, which together characterize the primary ways world modeling serves agent improvement. We further analyze how these proxies empower agents across three progressive levels: L.1 Inference-Time Guidance, where proxy outputs enrich in-context information for superior decisions; L.2 Training-Time Optimization, where proxy outputs yield rewards, critiques, or synthetic rollouts for policy learning; and L.3 Agent-Proxy Co-Evolution, where real-environment evidence continuously updates both the proxy and the agent for co-evolution. Ultimately, this work recasts world modeling into an agent-centric paradigm, establishing a roadmap for building world proxies that empower agents to plan better, learn faster, and evolve continually.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：持续改进的智能体（agent）需要超越静态监督数据的动态交互反馈，但直接与真实环境交互面临四大瓶颈——**成本高昂、存在风险、反馈滞后（缺乏前瞻性）、难以并行化**。世界模型传统上被定义为"物理状态转移预测器"（$\hat{s}_{t+1} = \mathcal{WM}(s_t, a_t)$），只能回答"下一个状态是什么"，无法为智能体提供执行结果、经验检索、技能推荐、验证信号等**可直接行动的信息**。
- **核心论点**：世界建模不应只追求预测物理世界，而应转向**服务智能体**——提出"智能体中心交互式世界代理"（Agent-Centric Interactive World Proxies）范式，将世界建模从"状态转移预测"扩展为"智能体可用信息转移预测"，以低成本、可控、可并行的方式为智能体提供持续改进所需的多维反馈。

## 2. 方法论：核心思想、关键技术细节与形式化

### 2.1 范式转变：从世界模型到世界代理

经典世界模型沿三个轴进行广义化：

| 转变维度 | 从 | 到 |
|---|---|---|
| 时间步 | 物理时间步 $t \to t+1$ | 交互步 $\ell \to \ell+1$ |
| 输出类型 | 状态转移 $s_t \to \hat{s}_{t+1}$ | 信息转移（新观察、执行结果、记忆/技能、奖励/验证等） |
| 交互方式 | 外部给定条件 | **智能体主动发起的查询/动作/干预** |

### 2.2 正式定义

> **智能体中心世界代理**是一个环境接地（environment-grounded）的代理机制，建模或预测**以智能体发起交互为条件的信息转移**，旨在为智能体改进提供信息增益。

形式化表达：
$$\hat{s}_{\ell+1} = \mathcal{WP}(s_\ell, u^\mathcal{F}_\ell), \quad s_\ell \in \mathcal{S}$$

- $\ell$：交互步（非物理时间步）
- $\mathcal{S}$：广义信息状态空间（物理状态、观察、记忆、知识、执行结果、验证等）
- $\mathcal{F}$：代理函数（动力学、空间、执行、记忆、技能、奖励/验证六类之一）
- $u^\mathcal{F}_\ell$：智能体主动提出的查询/动作/干预
- $\hat{s}_{\ell+1}$：代理返回的反馈

### 2.3 智能体在环闭环流程（四步循环）

1. **智能体提出交互**：根据当前目标与上下文状态发起查询
2. **世界代理预测信息转移**：基于当前信息状态与交互条件生成反馈
3. **反馈返回智能体**：未来状态、观察、执行结果、检索的指导或验证结果
4. **智能体利用反馈改进**：用于规划、决策、策略学习或持续改进

### 2.4 优秀世界代理的五个标准

- **接地性（Groundedness）**：依赖真实环境数据/规则/轨迹，而非脱离现实的生成
- **可控性（Controllability）**：支持智能体主动查询与干预
- **反馈有用性（Feedback Usefulness）**：确实改善规划、决策、学习
- **成本与可扩展性（Cost & Scalability）**：降低真实交互成本且可安全扩展
- **前瞻性（Forward-Looking）**：能在真实执行前预判结果、反事实与风险

### 2.5 三个赋能层级（L1–L3）

- **L.1 推理时引导**：世界代理不修改智能体参数，仅通过检索记忆/技能、模拟执行、验证反馈来增强上下文 → 更好的决策。公式：$s^{agent+}_\ell = s^{agent}_\ell \oplus \hat{s}^{guide}_{\ell+1}$
- **L.2 训练时优化**：世界代理充当奖励模型、批评者、验证器或模拟器，生成训练信号（奖励、批评、偏好、合成轨迹），通过 SFT/DPO/PPO/GRPO 等目标优化智能体策略 → 更好的策略。公式：$agent^+ = Train(agent, \hat{s}^{opt}_{\ell+1})$
- **L.3 智能体-代理协同进化**：真实环境证据（真实轨迹、失败案例、新发现）更新世界代理；锐化的代理再指导、验证和训练智能体，二者共同演化 → 持续闭环改进。公式：$(agent^+, \mathcal{WP}^+) = CoEvolve(agent, \mathcal{WP}, \hat{s}^{proxy}_{\ell+1}, s^{env}_{\ell+1})$

### 2.6 六种功能代理形式

| 代理类型 | 回答的问题 | 典型实例 |
|---|---|---|
| 动力学代理 | 执行某动作后环境如何变化？ | 视频预测、动作条件生成、机器人动力学、基于模型的RL |
| 空间代理 | 从另一视角/位置会看到什么？ | NeRF、3D Gaussian Splatting、导航世界模型、新视角合成 |
| 执行代理 | 执行代码/命令/API调用/点击后返回什么？ | 浏览器模拟器、GUI模拟器、代码执行预测器、工具响应模拟器 |
| 记忆/经验代理 | 过去有哪些相关经验、失败案例或约束？ | 经验记忆、反思记忆、失败记忆检索 |
| 技能代理 | 当前任务可复用哪些技能或行为先验？ | 技能库、工具使用例程、可复用行为模块 |
| 奖励/验证代理 | 该行为是否正确、安全、可行？ | 奖励模型、验证器、评论家、LLM-as-Judge |

## 6. 主要结论与发现

1. **范式命题**：世界建模应当从"预测世界"转向"服务智能体"——最有价值的未来世界模型将**不是以生成逼真度评判，而是以它让查询它的智能体变得多好来评判**。
2. **统一框架**：六种功能代理（动力学、空间、执行、记忆、技能、奖励/验证）共同构成了智能体持续改进所需的信息反馈生态，功能性差异本质上是"回答的问题类型"不同。
3. **递进赋能路径**：L1（推理引导）→ L2（训练优化）→ L3（协同进化）构成了承诺递增的三级阶梯；能力增强的同时，对代理可信度的要求也在提高。
4. **开放挑战**：
   - 生成模型的**保真度与长程误差累积**问题（需要校准的不确定性而非更锐利的像素）；
   - 智能体在线的**信任判断**问题（何时相信代理反馈、何时回到真实环境）；
   - L2 层级的**奖励黑客与安全风险**；
   - 需要**智能体中心评估基准**——衡量"反馈是否帮助智能体规划/学习/改进"，而非孤立地评测代理的现实感/保真度。
