## 摘要
长时程手术机器人操作具有挑战性，因为任务奖励稀疏，而有意义的交互变化以不规则间隔发生。现有的世界模型智能体通常以原始步骤分辨率进行想象，使得可变持续时间的任务进展隐含其中。手动指定的阶段可以提供中间结构，但其任务特定边界难以与状态相关的交互转换对齐。我们提出了S2-HWM，一种稀疏事件结构分层世界模型，它从原始潜在轨迹中学习稀疏事件证据，以协调事件级管理器和原始步骤工作器。事件证据调度管理器目标更新，每个选定的潜在目标对工作器的原始动作进行条件化，直到下一次更新。学习到的事件证据还为事件转换模型（ETM）形成可变持续时间段，该模型预测下一个边界随机状态、段持续时间和累积段奖励。将这些事件级预测链接起来，为管理器学习提供超出原始想象范围的变时长延续，而工作器保留原始步骤的Actor-Critic学习。在基于SurRoL的PegTransfer任务中，S2-HWM的成功率达到98.7%，比扁平化的GAS DreamerV3基线高出22.7个百分点。

## Abstract
Long-horizon surgical robot manipulation is challenging because task rewards are sparse, while meaningful interaction changes occur at irregular intervals. Existing world-model agents typically imagine at primitive-step resolution, leaving variable-duration task progress implicit. Manually specified stages can provide intermediate structure, but their task specific boundaries are difficult to align with state-dependent interaction transitions. We propose S2-HWM, a Sparse Event-Structured Hierarchical World Model that learns sparse event evidence from primitive latent trajectories to coordinate an event-level manager and a primitive-step worker. The event evidence schedules manager goal updates, and each selected latent goal conditions the worker's primitive actions until the next update. The learned event evidence also forms variable-duration segments for an Event Transition Model (ETM), which predicts the next?boundary stochastic state, segment duration, and accumulated segment reward. Chaining these event-level predictions provides a variable-duration continuation beyond the primitive imagination horizon for manager learning, while the worker retains primitive-step actor-critic learning. On a SurRoL-based PegTransfer task, S2-HWM achieves a success rate of 98.7%, outperforming the flat GAS DreamerV3 baseline by 22.7 percentage points.

  1. 传统方法依赖**手动指定的阶段结构**（如阶段奖励、子任务分解），其边界是预先固定、任务专属的，难以与状态依赖的实际交互变化对齐。

- **核心问题**：如何让智能体**自主地从交互经验中学习稀疏的事件边界**，并以这些事件为中间结构组织分层控制，从而应对长时程稀疏奖励的手术操作任务。
- **整体意义**：S2-HWM 将“事件证据”作为联系底层控制与高层决策的共享接口，为稀疏奖励下的长时程手术机器人操作提供了新的可行范式。

## 二、论文提出的方法论

### 2.1 核心思想
S2-HWM（Sparse Event-Structured Hierarchical World Model）的核心是**从原始潜轨迹中学习稀疏事件证据（event evidence）**，并用该证据同时完成两件事：
- **调度事件级管理器（Manager）的目标更新**：在事件边界处更新高层潜在目标。
- **构造变时长训练片段**：用于训练事件转移模型（ETM），实现事件级预测与想象。

### 2.2 总体架构（两条时间尺度）
整个系统由**事件级管理器**和**原始步工作器（Worker）** 组成分层策略：
- 每个原始步上，Worker 根据当前潜特征 `f_t` 和激活的管理器目标 `η_i` 采样动作。
- 在管理器更新点 `τ_i` 处，Manager 基于边界特征 `F_i = f_τi` 采样离散代码 `c_i`，通过码本 `E` 映射为潜在目标 `η_i`，该目标持续到下一个更新点。

策略公式为：

```
c_i ~ πM(· | F_i),  η_i = E(c_i),
a_t ~ πW(· | f_t, η_i),  t ∈ [τ_i, τ_{i+1})
```

### 2.3 底层世界模型
- 采用 **DreamerV3 的循环状态空间模型（RSSM）** 作为原始步世界模型。
- 每个时刻的潜特征由确定性状态 `h_t`、随机状态 `z_t` 和**持久交互上下文（context）`m_t`** 共同构成：

```
f_t = [z_t, h_t, m_t]
```

### 2.4 稀疏上下文动态与事件边界学习
- 引入一个**上下文模型 `Φ_ctx`**，根据历史预测候选上下文更新 `m̃_t` 和软门控 `ρ_t`：

```
(m̃_t, ρ_t) = Φ_ctx(z_{t-1}, a_{t-1}, m_{t-1})
m_t = ρ_t ⊙ m̃_t + (1 - ρ_t) ⊙ m_{t-1}
g_t = ST(ρ_t)
```

- 通过**直通估计器（Straight-Through）二值化**得到稀疏的逐维激活 `g_t`，作为事件证据。
- 管理器调度和 ETM 段构造各自使用不同的**接受规则（acceptance rule）** 对同一事件证据进行处理，因此两者的边界不一定相同。
- ETM 边界的相邻接受点定义变长片段：

```
e_i = [τ_i, τ_{i+1}),  Δ_i = τ_{i+1} - τ_i,  x_ei = [z_τi, m_τi]
```

### 2.5 事件转移模型（ETM）
- ETM **以事件分辨率**建模相邻边界之间的转移，一次预测跨整个变长片段，**无需逐步递归展开中间原始状态**。
- 引入内部**分类转移模式 `u_i`** 来表示同一开始状态下不同转移结果的变异性；训练时用后验 `q_θ(u_i | x_ei, z_ei+1)` 推断，想象时用先验 `p_θ(u_i | x_ei)` 预测。
- ETM 在给定事件状态和转移模式下预测三件事：

```
(ẑ_ei+1, Δ̂_i, R̂_i) = M_eθ(x_ei, u_i)
```

即：下一边界随机状态、段持续时间、累积段奖励。

### 2.6 事件扩展的管理器引导（Event-Extended Manager Bootstrap）
- **短视界分支**：RSSM 和分层策略生成原始步想象轨迹 `f̃_0:H`，由管理器价值函数给出 `B_short = V_M(f̃_H)`。
- **事件延续分支**：从 `f̃_H` 出发，串联 K 次 ETM 转移，预测后续事件边界的状态、时长和段奖励，以时长折扣 `γ^{Δ̂_j}` 累积，得到 `B_event`。
- **最终管理器引导目标**为两者的加权组合：

```
B_M = (1 - ω) B_short + ω B_event
```

- Worker 仍保持原始步的 Actor-Critic 学习。

## 六、论文主要结论与发现

1. **S2-HWM 显著优于平级世界模型**：在单次转移任务上取得 **98.7% ± 2.3%** 的成功率，比 GAS-DreamerV3 高出 **22.7 个百分点**；PPO 与 DreamerV2 在预算内完全无法解决该任务。
2. **事件证据 + 分层策略缺一不可**：仅学习稀疏事件表示并不足以提升控制性能（w/o Hierarchical Policy 退化最大，降至 68.0%）；事件证据必须经由 Manager 转化为持久潜在目标、并由 Worker 执行才能发挥作用。
3. **事件对齐的更新时机比固定周期更好**：固定 K=15 步更新导致成功率降至 80.7% 且方差显著增大；事件对齐的更新可以自适应不同阶段（接近、抓取、搬运、放置）的变长持续时间。
4. **ETM 提供增量但重要的收益**：去除 ETM 在单次转移上降低 7.4 个百分点，但在重复转移（-16.6 点）和扰动条件（-20.7 点）下差距更大——任务越长、中断越多，事件级延续的价值越明显。
5. **ETM 预测误差增长更慢**：多事件归一化预测误差显示，ETM 经过 3 个事件转移后仍接近一步参考误差，而 RSSM 滚动误差增长更快，支持事件级延续用于管理器引导的合理性。
6. **管理器代码确实对应结构化的工人行为**（无需语义标签）：后验分组显示不同管理器代码区间对应明显不同的原始动作倾向（如抓取时纵向调整和夹爪动作突出、举升时向上运动主导、放置时侧向修正主导）。

## 七、优点

1. **无需语义标签的自主事件发现**：事件证据完全从潜轨迹中学习，不需要人工标注阶段，突破了手动定义阶段边界的关键瓶颈。
2. **统一的共享事件接口**：同一事件证据同时驱动管理器调度和 ETM 训练，架构设计简洁而统一。
3. **变长时段的显式建模**：通过事件边界显式表达“事件何时结束、持续多久、段内奖励多少”，弥补了现有世界模型在变长任务进度表达上的缺失。
4. **双时间尺度想象策略**：原始步想象保留局部动态（Worker 学习），事件级 ETM 延续扩展高层引导视野（Manager 学习），兼顾局部精度与全局视野。
5. **理论动机清晰**：ETM 将多个递归原始步压缩为单次事件转移，既减少了递归次数，也限制了误差累积，实验证实了这一点。
6. **评估体系较完整**：主对比、消融、压力测试、诊断分析相互印证，结论的可信度相对较高。
7. **与现有 GAS 工作高度兼容**：直接继承 DSA 前端与动作接口，便于社区复现和后续扩展。
