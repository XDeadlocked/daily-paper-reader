## 摘要
我们提出了 \textbf{DreamX-Phi 1.0}，一个用于机器人操作的动作条件视频世界模型。给定观察帧、语言指令以及由末端执行器姿态和夹爪状态组成的预设动作序列，该模型预测由此产生的未来观察。然而，仅凭真实感并不能保证保真度：一个令人信服的推演仍可能移动错误的手臂或丢失被操作的对象。为了确保预测尊重每条手臂的命令路径，我们通过\textbf{PRoPE式几何编码}将每只手臂的$\mathrm{SE}(3)$变换注入注意力机制，从而保留手臂身份和刚体运动结构。仅凭动作控制并不能完全约束场景几何或小型被操作物体的演化。因此，我们增加了一个轻量级\textbf{深度分支}用于场景级几何，并使用\textbf{SAM3掩码}结合冻结的\textbf{V-JEPA教师}来在抓取过程中保持物体一致性。我们进一步通过分布匹配蒸馏将多步生成器蒸馏为少步学生模型，以实现高效部署。在撰写本文时，\model{}在WorldArena 2.0挑战赛的Track 1和Track 2中分别获得第一名和第二名。我们的模型和代码将公开发布。

## Abstract
We present \textbf{DreamX-Phi 1.0}, an action-conditioned video world model for robotic manipulation that, given an observed frame, a language instruction, and a prescribed action sequence comprising end-effector poses and gripper states, predicts the resulting future observations. Yet realism alone does not guarantee faithfulness: a convincing rollout can still move the wrong arm or lose the manipulated object. To ensure the prediction respects each arm's commanded path, we inject per-arm $\mathrm{SE}(3)$ transformations into attention via \textbf{PRoPE-style geometric encoding}, preserving arm identity and rigid-motion structure. Action control alone does not fully constrain scene geometry or the evolution of small manipulated objects. We therefore add a lightweight \textbf{depth branch} for scene-level geometry and use \textbf{SAM3 masks} with a frozen \textbf{V-JEPA teacher} to maintain object consistency throughout grasping. We further distill the multi-step generator into a few-step student via distribution-matching distillation for efficient deployment. At the time of writing, \model{} achieves first place on Track~1 and second place on Track~2 of the WorldArena~2.0 Challenge. Our model and code will be publicly available.

### 2. 论文提出的方法论

#### 2.1 核心思想

DreamX-Phi 1.0 基于 **Wan2.2-TI2V-5B** 视频扩散 Transformer，采用**流动匹配（flow-matching）目标**建模未来帧分布。其核心设计是三种互补机制的融合：

1. **PRoPE 几何控制**：将手臂级 SE(3) 变换直接注入注意力机制，保留刚体运动结构。
2. **辅助深度监督**：增强场景级 3D 结构感知。
3. **物体中心物理一致性约束**：通过掩码加权的 RGB 损失和 V-JEPA 关系正则化，保持被操作物体在交互过程中的视觉一致性。

#### 2.2 PRoPE 控制（双臂动作条件化）

- **动作表示**：每只手臂在时刻 t 表示为位置 p、四元数 q（转为旋转矩阵 R）和夹爪值 g。通过统一坐标系构造 SE(3) 齐次变换矩阵 G，并以手臂 1 的初始姿态作为参考系进行归一化。
- **尺度归一化**：使用单一的运动幅度因子 sγ 归一化平移量，避免双臂间的静态距离主导尺度，得到归一化框架 ˜G。
- **几何注意力机制**：将注意力头划分为固定的组（每组对应一只手臂），对同一潜在帧内所有 patch 共享变换矩阵。对 token 应用查询/键/值的相对变换：Q' = DᵀQ, K' = D⁻¹K, V' = D⁻¹V，输出经 D 变换后与预训练自注意力输出相加。该机制保证 token 对之间通过**相对运动**耦合，而非绝对坐标系。
- **夹爪状态注入**：夹爪开度是标量，无法表示为 SE(3) 元素，故作为**每手臂注意力头的偏置**注入（即 b = Wg·g + bg）。夹爪适配器和输出投影初始化为零，保持残差分支初始不干扰预训练路径。

#### 2.3 辅助深度监督

- 引入轻量级深度分支，复刻 RGB Transformer 的最后 M 个块（共享前 N−M 块作为主干）。
- 深度目标通过冻结的 VAE 将单通道深度图编码为潜在表示 zd，以潜在空间 MSE（Ldepth）监督。
- **单向交叉注意力设计**：深度分支可读取 RGB 特征，但 RGB 分支不消费深度特征，从而保持推理时深度分支可选，不改变 RGB 前向计算路径。

#### 2.4 物体中心物理一致性

- **SAM3 掩码加权 RGB 损失**：离线用 SAM3 生成被操作物体的二值掩码（仅用于训练监督），对物体区域 token 赋予更高权重（λm>1），并对权重做归一化以稳定损失规模。这使得接触局部误差（如漏抓、渗透）不会被大面积静态背景淹没。
- **V-JEPA 关系对齐**：使用冻结的 V-JEPA 教师，对采样得到的掩码物体 token 计算学生与教师的 **Gram 矩阵** L1 距离作为关系正则化（LJEPA）。该目标捕获物体在时空上的关系结构，防止身份、形状和状态漂移。样本需满足最小掩码 token 数和最大噪声阈值条件才贡献损失。项目器初始阶段仅更新自身，随后线性打开梯度传播至视频模型参数。

#### 2.5 少步后训练（DMD2 蒸馏）

- 将多步教师生成器蒸馏为 N 步学生模型，目标函数包含**分布匹配 KL 散度项**（DKL 等价于分布匹配损失）和**非饱和 GAN 对抗损失**的组合。
- 条件元组 y = (x₀, a₁:T, c) 在蒸馏过程中保持固定，梯度仅通过采样步传播。

- **动作忠实性可实现**：通过 PRoPE 式 SE(3) 注入 + 机器人专用光流提示，模型能正确遵循双臂命令路径，避免“移动错误手臂”问题。

### 7. 优点

- **几何结构保持的设计理念**：不同于 token 化或特征调制的隐式动作编码，PRoPE 直接保留 SE(3) 相对变换，物理上更自然，且与全局坐标系无关（相对运动解耦）。
- **多层面物理一致性的互补监督**：RGB 掩码加权识别“哪里重要”，V-JEPA 关系正则化约束“物体如何演化”，深度分支约束“场景几何”——三者形成互补，针对视频生成中“背景主导损失”的病灶。
- **训练-推理不对称的工程智慧**：深度分支是单向信息流，SAM3 掩码仅在训练时使用，均不增加推理负担。
- **数据策略细致**：保留失败轨迹、过滤移动基座/灵巧手、多视角拼接 + 统一 LeRobot 格式、DreamX-Refiner 超分，体现对数据质量的精心把控。
- **高效部署导向**：DMD2 蒸馏使模型适配少步推理，实用性突出。

### 8. 不足与局限

- **实验覆盖有限**：评估限于 WorldArena / RoboTwin 环境，Track 2 仅有 Adjust Bottle 单一任务；未在真实机器人上验证，跨任务/跨具身泛化能力未知。
- **缺少消融实验**：无法把 60.65 / 67.19% / 76.88 等分数的提升归因于 PRoPE、深度分支、SAM3 加权、V-JEPA 正则等特定组件，削弱了方法论证的严谨性。
- **系统级 vs 组件级混淆风险**：leaderboard 分数评估的是完整系统，模型体积（5B 级）和训练语料规模等变量未被控制，可能引入表现偏差。
- **模型本身不作为决策者**：DreamX-Phi 仅做前向动力学预测（FDM），不生成动作，不能作为闭环控制器使用；Track 2 中的策略训练只是展示了其作为环境模拟器的能力。
- **潜在偏差风险**：语料中仿真数据（InternData-A1、RoboTwin 等）占比很大（3,747h + 25k clips），真实数据虽存在但占比相对较小；仿真-真实分布差异未被显式分析。
- **算力信息缺失**：未报告能耗、训练资源等，可复现性和工程成本难以评估。
