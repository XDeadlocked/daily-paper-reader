## 摘要
扩散变换器文本到视频模型在合成质量上取得了显著成果，但细粒度的空间可控性仍是一个重大挑战。现有的免训练方法在空间锚定生成（即在指定位置放置特定对象）方面取得了整体良好的结果，然而它们依赖基于梯度的优化技术，这带来了巨大的计算开销，并且这一瓶颈在现代大规模架构中被进一步放大。为解决这一局限，我们提出了无梯度解析轨迹优化视频生成（GATO-Vid），一种新颖的免训练、免梯度方法，用于精确的空间引导。我们不依赖昂贵的反向传播，而是引入一种替代的交叉注意力分数，并通过解析方法获得精确的闭式解。为了利用我们的解析解，我们提出了一种针对变换器潜空间拓扑流形定制的实时注入机制。实验表明，GATO-Vid在定位精度上显著优于现有基线，同时引入了极小的计算开销。

## Abstract
Diffusion Transformer Text-to-Video models have achieved remarkable synthesis quality, yet fine-grained spatial controllability remains a significant challenge. While existing training-free methods produce solid overall results in spatially grounded generation, \ie, placing a specific object in a designated location, they rely on gradient-based optimization techniques that incur prohibitive computational overhead, a bottleneck amplified in modern large-scale architectures. To address this limitation, we present Gradient-free Analytical Trajectory Optimization Video Generation (GATO-Vid), a novel training-free and gradient-free approach for precise spatial guidance. Rather than relying on costly backward passes, we introduce an alternative cross-attention score and solve it analytically to obtain an exact, closed-form solution. To use our analytical solution, we propose an on-the-fly injection mechanism tailored to the topological manifold of the transformer's latent space. Our experiments demonstrate that GATO-Vid significantly outperforms existing baselines in localization accuracy while introducing minimal computational overhead.

## 1. 核心问题与整体含义

- **研究背景**：扩散 Transformer（DiT）类文本到视频（T2V）模型已能生成高质量、连贯且语义对齐的视频，但文本提示难以精确控制对象的空间位置。现有空间可控生成的训练免费方法主要依赖梯度优化（即反向传播），通过最大化交叉注意力图与目标位置的相似度来实现定位。
- **核心问题**：梯度-based 方法在现代大规模 DiT 架构（如 Wan2.2）上计算开销极大，需要大量显存（甚至超过单张 80GB GPU），难以在消费级硬件上部署。已有的免梯度方法（如硬掩码、区域提示）往往只适用于 3D-UNet 架构，迁移到 DiT 后定位效果显著下降。
- **研究目标**：提出一种训练免费、梯度免费的空间锚定 T2V 生成方法，在不修改模型权重、不进行反向传播的前提下，实现精确的对象位置控制，并保持极小计算开销。

## 2. 方法论

### 核心思想
- 利用交叉注意力机制进行对象定位，但不直接优化注意力图，而是构造一个**可解析求解的替代分数**（surrogate score），推导出查询向量的全局最优调整方向，从而避免梯度计算。
- 通过**在线注入机制**将解析解应用到 DiT 各层的 query 上，同时保持原模型 RMSNorm 的几何流形，使扰动不破坏网络内部表示。

### 关键技术细节

1. **分数函数设计**：  
   原始交叉注意力依赖 softmax，而非线性 softmax 难以解析优化。作者改用**预 softmax 的 logits**（即 QK⊤）作为代理，定义了一个包含三项的分数 `s`：
   - (i) 增大目标区域 `M` 与目标词 `T` 的内积；
   - (ii) 减小目标区域 `M` 与非目标词 `T^c` 的内积；
   - (iii) 减小目标区域外 `M^c` 与目标词 `T` 的内积。

2. **解析闭式解**：  
   通过对 `s` 进行因式分解，将分数转化为两个向量点积，得到每个区域的最优更新方向：
   - 正偏置 `b+` 正比于 `K(T) − K(T^c)`；
   - 负偏置 `b−` 正比于 `−K(T)`。  
   其中 `K(T)`、`K(T^c)` 分别是对应文本 token 的 key 平均向量。

3. **几何感知的注入机制**：  
   由于 DiT 中的 query 经过 RMSNorm 归一化到超椭球面，不能直接加偏置，而是采用：
   - 对目标区域内的 query：`q ← q + λ+‖q‖·b+`；
   - 对背景区域的 query：`q ← q + λ−·P(b−‖q‖, q)`，其中 `P` 是正交投影，确保偏置只改变方向、不覆盖原始特征；
   - 最后重新投影到 RMSNorm 椭球面，保持分布一致。

4. **空间平滑**：  
   为避免目标区域内注意力分布过于均匀，引入 2D 高斯调制，使引导强度在边界框中心最大，向边缘递减。

5. **算法流程**（对应文中 Algorithm 1）：
   - 前向提取当前步的 query、key、value；
   - 在指定 transformer 块（前 20 块）和前 15% 采样步内，计算 b+、b−；
   - 修改 query 并重新归一化；
   - 通过修改后的 query 执行交叉注意力，其余层与采样步保持不变。

## 3. 实验设计

### 数据集与 benchmark
- 自建两组评测集:
  - **Set 1**：由 Gemini 生成 25 个自然场景提示，用 Wan2.2 生成 4 个参考视频，并用 SAM 3 提取目标对象参考边界框。评估时每个 prompt-框配置使用 4 个随机种子，共 400 个生成视频。
  - **Set 2**：由 ChatGPT 生成 100 个提示，并合成不同大小、形状、运动模式（直线、螺旋、圆形、Z/N 形等）的边界框，同样每个配置 4 个种子，共 400 个视频，难度更高。
- 指标：
  - 定位：IoU（交并比）、Center Distance (CD)、Success Rate (SR，基于 SAM 3 检测是否成功生成目标对象)。
  - 质量：VBench 的五个子指标——主题一致性 (SC)、背景一致性 (BC)、动态程度 (DD)、美学质量 (AQ)、成像质量 (IQ)。

### 对比方法
- 基线：Peekaboo、VideoTetris、SwitchCraft（三个训练免、梯度免方法），以及原始无引导的 Wan2.2 T2V。
- 所有基线均被重新实现/适配到 Wan2.2 架构，并进行了超参数搜索以保证公平比较。

## 6. 主要结论与发现

- GATO-Vid 在当前主流 DiT 架构（Wan2.2）上取得了显著优于现有训练免费/梯度免费方法的定位精度：
  - Set 1：CD 从 0.138 降至 0.059，IoU 从 0.154 提升至 0.363；
  - Set 2：CD 从 0.198 降至 0.121，IoU 从 0.124 提升至 0.324；
  - SR 与原始模型相当，表明没有牺牲对象生成成功率。
- 计算开销几乎可以忽略，使空间可控 T2V 生成在消费级 GPU 上成为可能。
- 空间控制增强通常以生成质量（特别是动态程度 DD 和美学 AQ）下降为代价，背景一致性也会略有降低。
- 对 DiT 架构中的注意力分布分析表明：早期 transformer 块和早期采样步对布局结构起主要作用，因此仅在“前 20 块 + 前 15% 步”注入偏差就已足够。

## 7. 优点

- **方法创新性**：将交叉注意力定位问题转换为可解析求解的分数优化，得到闭式解，彻底绕开反向传播；同时考虑 RMSNorm 椭球面，保证了注入的几何合理性。
- **高效性**：推理开销极低（0.4%），内存需求小，适合消费级硬件，实用性强。
- **实验完整性**：自建两个不同难度的数据集，包含自然场景和合成轨迹；采用 SAM 3 自动评估，减少人工偏差；设有成功率指标，避免“对象未生成但定位指标虚高”的问题。
- **消融分析深入**：通过逐项消融证明正偏置、负偏置、高斯调制和几何重投影各自的作用，尤其揭示了负偏置（抑制目标词在背景区域的注意力）的重要性。

## 8. 不足与局限

- **质量权衡**：空间控制以降低动态程度和美学质量为代价，部分视频背景退化、场景显得静态，说明方法在保持视觉自然度方面仍有欠缺。
- **适用性有限**：仅基于 Wan2.2 验证，未在其他大型 DiT 或 UNet 模型上测试，泛化性未知。
- **与梯度-based 方法的比较缺失**：由于显存限制，未能直接与目前最有效的梯度引导方法进行定量对比，只能通过推理时间数据侧面说明。
- **依赖文本与掩码质量**：方法需要准确的 target word 与时空掩码；SAM 3 的检测失败会导致指标计算偏差（尤其是 SR）。
