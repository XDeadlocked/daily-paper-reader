## 摘要
无人机视觉语言导航（UAV-VLN）要求智能体在复杂环境中将视觉观察和语言指令转化为可靠的飞行动作。尽管最近的端到端无人机视觉-语言-动作（UAV-VLA）策略减少了对独立设计的感知、规划和控制模块的依赖，但其行为克隆目标为交互式闭环执行提供的纠正性监督有限。强化学习（RL）提供了一种有前景的解决方案，但其有效性受到样本利用效率低、长尾场景分布以及优化过程中策略分布偏移的制约。为此，我们提出了RecoverFly，一个用于端到端UAV-VLA策略的故障感知强化学习后训练框架。具体而言，RecoverFly采用词元级强化学习以稳定优化语法约束的自回归无人机动作，重新审视未解决的故障案例以加强纠正性学习和样本利用，并将两阶段长尾场景课程与参考策略正则化相结合，以提高场景适应性同时保留已获得的能力。在TravelUAV基准上的实验表明，RecoverFly在已见、未见地图和未见对象划分上均取得了最佳性能。此外，与AerialVLA初始化相比，在约占总训练集大小30%的总回滚预算下，RecoverFly将成功率提高了3.12至8.37个百分点，验证了其有效性、鲁棒性和泛化能力。

## Abstract
Unmanned aerial vehicle vision-language navigation (UAV-VLN) requires agents to translate visual observations and language instructions into reliable flight actions in complex environments. Although recent end-to-end UAV vision-language-action (UAV-VLA) policies reduce reliance on separately designed perception, planning, and control modules, their behavior-cloning objectives provide limited corrective supervision for interactive closed-loop execution. Reinforcement learning (RL) offers a promising solution, while its effectiveness is constrained by inefficient use of samples, long-tailed scene distributions, and policy distribution shift during optimization. To this end, we propose RecoverFly, a failure-aware RL post-training framework for end-to-end UAV-VLA policies. Specifically, RecoverFly adapts token-level RL for stable optimization of grammar-constrained autoregressive UAV actions, revisits unresolved failure cases to strengthen corrective learning and sample utilization, and combines a two-stage long-tail scene curriculum with reference-policy regularization to improve scene adaptation while preserving acquired capabilities. Experiments on the TravelUAV benchmark demonstrate that RecoverFly achieves the best performance on the seen, unseen-map, and unseen-object splits. Moreover, compared to the AerialVLA initialization, RecoverFly improves success rate by 3.12 to 8.37 percentage points under a total rollout budget of about 30\% of the training-set size, validating its effectiveness, robustness, and generalization capabilities.

### 1. 核心问题与整体含义（研究动机与背景）

- **任务背景**：无人机视觉语言导航（UAV-VLN）要求智能体将视觉观察和自然语言指令转化为可靠的飞行动作（前进、高度、偏航、着陆决策）。与室内地面 VLN 不同，UAV-VLN 处于大规模三维户外环境，面临快速变化的视角、遮挡、长航程轨迹等问题。
- **现有方法的局限**：端到端 UAV-VLA 策略（如 AerialVLA）将观测和指令直接映射为可执行动作，减少了对模块化感知/规划/控制的依赖，但其训练主要依赖行为克隆（BC），缺乏对闭环执行中自身错误（碰撞、漂移、过早着陆、超时等）的纠正性监督。在测试时遇到专家演示之外的错误状态，行为克隆策略容易犯错并导致误差累积。
- **RL 的潜力与瓶颈**：强化学习可以利用交互式奖励改善策略，但直接用于自回归动作策略会面临四大问题：
  1. 失败事件可能源于先前动作，而非当前瞬时动作，归因困难；
  2. 高学习价值的未解决失败案例会在后续采样中迅速消失，样本利用效率低；
  3. 场景分布不平衡使优化聚焦于频繁场景，忽视罕见场景；
  4. 无约束的策略更新可能退化已获得的导航能力（策略漂移）。
- **整体意义**：本文提出 RecoverFly，将细粒度动作优化、故障感知学习、长尾场景适应和稳定策略更新统一到一个后训练框架中，为端到端无人机 VLA 策略提供了一种可行的强化学习后训练方案。

### 2. 方法论

RecoverFly 是一个故障感知的在线强化学习后训练框架，总体目标是在保持预训练文本动作接口的前提下，利用闭环交互反馈优化端到端 UAV-VLA 策略。主要包含四个关键组件：

**（1）文本化无人机策略与在线 RL 目标**

- **文本动作表示**：策略以自回归方式生成动作 token 序列 `zt = (zt,1, ..., zt,Kt)`，遵循 AerialVLA 的动作语法（3 个数值控制 token + 可选 LAND token），解码为 3-DoF 控制量 `at = ⟨Δxt, Δzt, Δψt⟩`（前进、垂直、偏航）。每个控制维度均匀量化到 99 个 bin。解码失败映射为安全 no-op 并施加无效动作惩罚。
- **事件感知奖励**：
  ``` 
  rt = clip(κp(Dt−1 − Dt), r_prog_min, r_prog_max) + Σ_e∈E Re·I[et = e]
  ```
  结合密集距离进度奖励（D_t 为到目标的欧氏距离）和稀疏事件奖励（E = {成功、碰撞、卡住、远离、过早停止、超时}）。
- **GAE 优势估计**：使用广义优势估计（GAE）将延迟回报传播到先前的动作，同时维护一个价值头 V_φ(h_t)。
- **Token 级 PPO**：标准连续动作 PPO 不适用于 token 概率策略；序列级 PPO 对整个动作序列施加单一重要性权重和裁剪决定。RecoverFly 对每个有效动作 token 分别计算重要性比率 ρ_t,k(θ)，并使用共享的动作级优势值 Â_t，实现 token 级裁剪目标：
  ```
  J_token PPO(θ) = E_t[ (1/M_t) Σ_k m_t,k · min(ρ_t,k(θ) Â_t, clip(ρ_t,k(θ), 1−ε, 1+ε) Â_t) ]
  ```

**（2）动态失败回放（Dynamic Failure Replay）**

- 维护一个动态失败池 M = {ξ_i}，每个条目为 `ξi = (idi, ci, fi, σi, ni)`，分别记录任务 ID、场景、失败类型、活动状态（active/solved/dropped）和失败重试次数。
- 在线重置时，按回放比例 η 混合采样新任务和失败任务。每轮 rollout 后，新失败任务加入池中或重新激活；成功回放标记为已解决；连续 N_max 次失败则标记为丢弃。
- 与 Hindsight Experience Replay 和 Prioritized Level Replay 不同，RecoverFly 存储的是**任务初始化而非旧轨迹**，每次用当前策略重新生成 rollout，从而保持 on-policy PPO 的有效性，同时反复学习有信息的失败案例。

**（3）两阶段长尾场景课程**

- **阶段 I**：按原始经验分布采样场景，`P1(c) = Nc / Σ Nc'`，训练基础导航能力。
- **阶段 II**：从阶段 I 策略继续，改为每个场景等配额采样（equal quota），增加稀有场景的训练频率，防止少数场景主导采样。
- 课程作用于场景频率而非轨迹难度，与失败回放耦合以改善长尾场景的泛化。

**（4）参考策略 KL 正则化**

- 阶段 I 的参考策略为初始 VLA 策略，阶段 II 的参考策略为阶段 I 的最终策略，保持冻结。
- Token 级 KL 损失：
  ```
  L_KL(s) = E_t[ (1/M_t) Σ_k m_t,k · D_KL(p_θ,t,k ∥ p_ref(s),t,k) ]
  ```
- 总训练目标：
  ```
  L(θ, φ) = −J_token PPO(θ) + cv·LV(φ) + β·L_KL(s)
  ```
- 两阶段锚定机制缓解跨阶段策略漂移，平衡"适应新分布"与"保留已有能力"之间的取舍。

### 6. 主要结论与发现

- RecoverFly 在 TravelUAV 全部三个测试分割上均取得最佳综合性能，主实验给出各数据集上的 SR 提升。
- RL 后训练对硬长轨迹（Hard）的效果优于短轨迹，说明其核心价值在于纠正长时域误差累积。
- 失败回放能有效将稀疏失败反馈转化为可复用的纠正性经验，但单独使用会重新分配性能而非全面提升，需与长尾场景课程配合。
- 两阶段课程通过"先原始分布、后平衡场景"的方式，优于直接均匀采样或全程原始分布，且增益不能仅用额外训练步数解释。
- KL 正则化能限制策略过度偏移、保留初始 VLA 策略的可迁移能力，特别对未见地图泛化有帮助。

### 7. 优点

- **问题意识强**：明确了"BC 缺乏纠正信号 + 标准 RL 忽略罕见失败 + 场景长尾 + 策略漂移"四重耦合问题，并系统性回应。
- **方法完整性**：token 级 PPO 适配自回归动作空间的细节设计（有效 token 掩码、动作级优势共享、非法动作惩罚）比简单的序列级 PPO 更合理。
- **失败回放设计的独特性**：存储"任务初始化"而非"旧轨迹"的方式，既保留了 on-policy 性质，又反复获得新鲜纠正经验。
- **课程与正则化结合**：两阶段长尾场景课程配合阶段式 KL 锚定，提供了"适应新分布"与"保留旧能力"之间的显式平衡机制，实验表明这优于均匀采样等朴素方案。
- **效率出色**：仅用约 30% 训练集规模的 rollout 预算即取得显著提升，成本相对可控。

### 8. 不足与局限

- **基准单一**：仅在 TravelUAV（AirSim 仿真）上评估，缺少公开的跨数据集验证或多环境验证，泛化结论的普适性有限。
- **对比不完整**：未与 HTNav（阶段式模仿+RL）、FlightGPT（监督微调+GRPO）等同样利用强化学习的 UAV-VLN 方法直接比较，难以定位 RecoverFly 在"所有 RL 后训练方法"中的相对位置。
- **存在仿真-现实差距**：实验完全依赖 AirSim 仿真环境，未涉及真实飞行器部署验证，若在真实环境中测试可能面临感知域差异、传感噪声、控制延迟等问题。
- **消融统计严格性**：主实验使用 3 个种子而消融实验仅使用种子 1，未报告消融设定的方差，统计置信度不完整。
