## 摘要
真实世界部署视觉-语言-动作（VLA）模型常常受到效率-性能权衡、跨实体泛化和执行平滑性的瓶颈制约。我们提出NebulaVLA，一种异步双频架构，将高层语义推理与低层动作控制解耦，优化计算资源和模块化。为了弥合异构机器人之间的语义鸿沟，我们引入了GESTURE-7，一种统一的基于语言的动作表示。此外，我们的引导动作算法通过基于掩码的平滑性约束来保证运动学连续性。全面评估表明，NebulaVLA显著优于同步基线，在LIBERO-Plus上实现了85.5%的平均成功率，并将动作生成加速约2.7倍。这种异步设计为实际机器人应用实现了高效且响应迅速的控制。

## Abstract
Real-world deployment of Vision-Language-Action (VLA) models is often bottlenecked by efficiency-performance trade-offs, cross-embodiment generalization, and execution smoothness. We present NebulaVLA, an asynchronous dual-frequency architecture that decouples high-level semantic reasoning from low-level action control, optimizing computational resources and modularity. To bridge semantic gaps across heterogeneous robots, we introduce GESTURE-7, a unified language-grounded action representation. Furthermore, our Guide Action algorithm enforces kinematic continuity via mask-based smoothness constraints. Comprehensive evaluations demonstrate that NebulaVLA significantly outperforms synchronous baselines, achieving an 85.5\% average success rate on LIBERO-Plus and accelerating action generation by \textasciitilde 2.7$\times$. This asynchronous design enables highly efficient and responsive control for practical robotics.

## 1. 论文的核心问题与整体含义

- **研究动机**：视觉-语言-动作（VLA）模型在真实机器人部署中面临三大瓶颈：
  1. **效率-性能权衡**：传统同步单频架构无法同时满足低频语义推理的需求和高频电机控制对低延迟的要求。
  2. **跨实体泛化不足**：不同机器人形态（如灵巧手、平行夹爪）的动作空间差异大，现有离散/连续动作表征难以统一语义。
  3. **执行平滑性差**：异步推理与动作块生成之间的时间错位会导致轨迹抖动和块间不连续。
- **整体含义**：论文提出 NebulaVLA，通过异步双频架构将高层语义规划与低层动作控制解耦，并设计统一动作表征与引导动作机制，试图在不牺牲性能的情况下提升效率、泛化能力和执行平滑度，为实际机器人操控提供可行的部署方案。

## 2. 论文提出的方法论

### 核心思想
- 采用“快慢系统”认知范式：
  - **System 2（慢系统，约10 Hz）**：基于 Qwen3-VL 大语言模型，进行高层语义规划，输出抽象动作引导。
  - **System 1（快系统，约20 Hz）**：基于 Diffusion Transformer（DiT），结合高频视觉输入和引导动作，输出执行动作。
- 两个系统通过显式数据流解耦，支持分布式部署，降低交互延迟。

### 关键技术细节
1. **GESTURE-7 统一动作表示**：
   - 将末端执行器状态编码为 7 维向量：`[x, y, z, r, p, w, gesture]`。
   - 前 6 维为笛卡尔位置和欧拉角（量化到整数厘米/度），第 7 维为自然语言手势关键词（如 `grasp`、`push`）。
   - 不同形态机器人执行相同动作时共享相同关键词，从而实现跨实体动作语义统一，并天然支持语言条件强化学习。

2. **三阶段训练流程**：
   - **Stage 1（System 2 SFT）**：监督微调，任务包括姿态回归、关键点回归、2D 路点预测、3D 轨迹预测、思维链（CoT）子任务分解。
   - **Stage 2（System 2 RL）**：基于 GRPO 进行强化学习，奖励函数包含 GESTURE-7 距离、关键点定位、路点、轨迹和格式奖励。
   - **Stage 3（System 1 SFT）**：使用加权流匹配损失联合微调 System 1 与 System 2，损失仅计算新生成动作区域。

3. **Guide Action 机制**：
   - 灵感来自图像外扩（Image Outpainting）。
   - 生成下一动作块时，以上一动作块中未执行的动作为先验条件，并通过二进制掩码 `M` 在去噪过程中强制保留已知动作（锚点区），确保块边界连续。
   - 去噪过程建模为条件概率模型，并采用掩码约束：
     ```
     A^{t-1}_full = M ⊙ A^{t-1}_prior + (1-M) ⊙ A^{t-1}_noisy
     ```
   - 训练时引导动作点数随机采样 0~3，以适应不同推理延迟。

## 6. 论文的主要结论与发现

- **仿真性能**：NebulaVLA 在 LIBERO-Plus 总体成功率达 **85.5%**，优于 InternVLA-M1（81.3%）、OpenVLA-OFT+（79.6%）、GR00T N1.5（59.0%）和 π0.5（58.0%）。
- **真实性能**：在两项真实任务上成功率最高（92.08% 和 92.5%），平均推理延迟 42 ms，比同构频率变体（115 ms）和 InternVLA-M1（81 ms）显著更低，且优于 InternVLA-M1。
- **Guide Action 有效性**：平均关节加加速度降低 **25.6%**，其中 Joint 12、13 分别降低 41.2% 和 45.1%，有效消除块间抖动。
- **异步双频架构**：将动作生成加速约 2.7 倍，同时提升成功率，表明解耦语义推理与动作控制可兼顾效率与性能。

## 7. 优点

- **架构创新**：异步双频设计（10 Hz 语义 + 20 Hz 动作）在 VLA 领域具有可扩展性和工程部署优势，支持分布式计算。
- **统一动作表征**：GESTURE-7 利用自然语言关键词统一异构机器人动作语义，降低表示复杂度并支持 RL，思路简洁且实用。
- **训练流程完备**：三阶段（SFT + RL + SFT）渐进优化，从感知、规划到控制形成闭环，且 RL 奖励函数设计多样。
- **平滑机制内生**：Guide Action 将平滑约束嵌入扩散生成过程，避免后处理，创新性地类比图像外扩，针对性极强。
- **实验验证扎实**：仿真基准维度丰富，真实平台验证了实际部署效果，消融实验覆盖关键组件。

## 8. 不足与局限
