## 摘要
长时程机器人操作要求机器人既能可靠地执行单个技能，又能在扩展任务中连贯地将它们序列化。大多数分层视觉-语言-动作（VLA）模型通过单次前向传播做出每个此类决策，没有机制为困难或关键选择分配额外计算。我们提出了$τ_0$-VLA，一种分层机器人基础模型，通过世界模型引导的测试时计算，将高层子任务生成表述为一个可扩展计算量的推理问题。在每个推理步骤中，高层策略使用执行记忆生成子任务，并在必要时在提交输出之前搜索替代方案。然后，低层策略在多种机器人实体上执行生成的子任务。该策略在40,115小时异构真实世界数据上通过多模态协同训练进行训练。在领域内和分布偏移场景中，分配额外的测试时计算显著提高了下一个子任务预测的准确性，并且这些增益转化为长时程机器人操作任务中更高的闭环成功率。

## Abstract
Long-horizon robot manipulation requires a robot to both execute individual skills reliably and sequence them coherently over extended tasks. Most hierarchical vision-language-action (VLA) models make each such decision with a single forward pass, leaving no mechanism to allocate additional computation to difficult or consequential choices. We introduce $τ_0$-VLA, a hierarchical robot foundation model that formulates high-level subtask generation as a compute-scalable inference problem through world-model-guided test-time computation. At each inference step, the high-level policy uses execution memory to generate a subtask and, when needed, searches over alternatives before committing to its output. A low-level policy then executes the generated subtask across multiple robot embodiments. The policy is trained on 40,115 hours of heterogeneous real-world data with multimodal co-training. Across in-domain and distribution-shifted settings, allocating additional test-time computation substantially improves next-subtask prediction accuracy, and these gains translate into higher closed-loop success on long-horizon robot manipulation tasks.

# τ₀-VLA 论文详细中文总结

## 1. 核心问题与研究动机

- **核心问题**：长时程（long-horizon）机器人操作任务要求机器人既能够可靠执行单个技能，又能在整个任务过程中连贯地排序这些子任务。现有分层 VLA（Vision-Language-Action）模型的高层策略在每次决策时仅通过单次前向传播输出结果，没有机制将额外的推理计算分配到关键或困难的选择上。
- **关键瓶颈**：子任务级别的选择错误无法通过更精确的底层控制来纠正——机器人可能完美执行了错误的子任务。传统方法往往要等到错误决策已经改变环境之后才能被发现和纠正，此时重规划无法挽回已失败的承诺。
- **核心思想**：将"生成下一个子任务"明确建模为**推理时的计算可扩展问题**，即借鉴语言模型中 test-time computation（TTC）的思路，让计算量随决策难度动态扩展，在提交执行之前对候选子任务进行**后果评估**。

## 2. 方法论

### 2.1 系统架构
τ₀-VLA 是一个两层级联系统：
- **高层策略（High-Level Policy）**：负责执行记忆维护、子任务生成、以及按需触发测试时计算（TTC）。由四个模型组成：
  - **提议模型 P**（Proposal Model）：接收上下文 \( h_t = (\ell, M_{t-1}, z^*_{t-1}, o_t) \)，更新执行记忆并生成直接子任务提议。
  - **世界模型 W**（World Model）：预测候选子任务执行完成后的终端头戴相机图像，即 \( \hat{o} = W(\tilde{o}, z) \)。
  - **价值模型 V**（Value Model）：基于任务指令、候选子任务和预测图像评估候选质量，即 \( v = V(\ell, z, \hat{o}) \)。
  - **反思模型 F**（Reflective Model）：基于保留的分支摘要和真实上下文生成最终子任务。
- **低层策略（Low-Level Policy）**：耦合 Qwen3.5-2B 视觉语言骨干与 Mixture-of-Transformers（MoT）动作专家，在统一的 40 维状态/动作空间上通过条件流匹配（conditional flow matching）学习动作生成，支持固定基座、双机械臂和移动全身控制。
- **统一动作空间**：40 维向量涵盖左右末端执行器位置/旋转（Rot6D）、夹爪、腰部、移动基座以及双臂关节。每样本的掩码选择有效通道，控制元数据 η 指定实施例与控制参数化。

### 2.2 测试时计算（TTC）流程
核心是**提议-预测-评估（propose-predict-evaluate）循环**的波束搜索：

1. **自适应路由**：提议模型输出 token 置信度统计量（平均生成概率和 logit 边际），若低于阈值则触发 TTC；否则直接使用提议作为最终子任务。
2. **波束搜索**：
   - 在每个深度 d，对每条保留分支独立调用提议模型 N 次，生成候选子任务；
   - 世界模型预测每个候选的终端图像；
   - 价值模型对预测结果打分；
   - 全局按累计分数保留 Top-B 分支；
   - 递归扩展到深度 D。
3. **反思提交**：搜索结束后，反思模型基于保留分支的路径、预测图像和累计分数生成最终子任务，输出不限于候选集。

### 2.3 训练策略
- **低层策略三阶段训练**：知识隔离协同训练（KI）→ 端到端协同训练 → 任务特定微调。
- **高层策略数据自动构建**：从已有的任务/阶段/子任务标注和分割演示中自动生成监督信号，无需额外人工标注。
- **记忆纠错训练**：通过扰动演示中的记忆（滞后、超前、矛盾三种情况）训练策略自我修复记忆，对应四种实例族（within-subtask、transition、catch-up、rollback、error-think）。
- **世界模型训练**：从真实轨迹中提取子任务对齐的起点/终点帧对进行监督，并用模拟 rollout 训练价值模型和反思模型。

## 7. 方法优点

- **新颖的决策范式**：将子任务生成从固定计算量的单次前向转化为可扩展的搜索问题，让"关键决策多花算力"成为可能。
- **搜索的物理落地**：通过世界模型将语言子任务映射为可预测的视觉后果，再以价值模型量化任务进展，实现了语言推理与物理世界的桥接。
- **反思模型的设计**：输出不限定于候选集，允许模型在搜索信息的基础上产生更优的新子任务。
- **执行记忆的可纠错性**：通过无标注的扰动训练，使记忆机制具备自我修复能力，避免记忆漂移在长时程任务中累积。
- **统一的多实体低层接口**：40 维统一动作空间 + 掩码流匹配，让 VLA 策略跨固定基座、双机械臂和移动平台复用，无需特定输出头。
- **数据自动标注管线**：高层训练数据从现有标注中自动派生并通过程序化过滤器去污，避免了昂贵的人工标注。
- **置信度路由机制**：利用已有前向的 token 统计信息决定是否触发 TTC，简单高效不增加额外推理。
