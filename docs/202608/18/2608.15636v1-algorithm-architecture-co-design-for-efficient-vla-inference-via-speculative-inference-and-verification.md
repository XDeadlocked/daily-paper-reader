## 摘要
视觉-语言-动作（VLA）模型在具身智能领域展现了卓越的能力，但其高计算成本和有限的预测动作长度阻碍了实时部署。尽管已提出了面向高效具身智能的专用加速器 Dadu-Corki，但它并未利用机器人与环境之间的固有交互模式，导致预测动作长度相对较短。我们观察到，机器人环境自然地在活跃状态（精确动作至关重要）与非活跃状态（动作对任务成功影响有限）之间交替。这一洞察带来了一种新的调度机会：在非活跃状态进行长动作长度推测预测，并在活跃状态进行选择性验证。我们提出了 SpecVLA，一种算法-系统协同设计框架，能够自适应地平衡动作长度、推理延迟和任务可靠性。在算法方面，SpecVLA 引入了一种状态感知的 VLA 推理执行范式，并利用差分残差和分块混合精度量化，构建了一种硬件友好的较小验证模型（sVLA）。在系统方面，我们开发了一种由 GPU 和机器人专用硬件模块组成的异构架构，并设计了一种通过并行执行将 VLA 和 sVLA 解耦的推测数据流。在 LIBERO 和 ManiSkill 基准上对 OpenVLA 和 RDT 进行的全面评估表明，SpecVLA 显著降低了端到端延迟，同时保持了任务成功率。通过实现长动作长度推测预测与及时验证，SpecVLA 实现了既高效又可靠的实时机器人操作。

## Abstract
Vision-Language-Action (VLA) models have demonstrated remarkable capabilities in the field of embodied AI, but their high computational cost and limited predicted action length hinder real-time deployment. Although Dadu-Corki, a dedicated accelerator for efficient embodied AI, has been introduced, it does not exploit the inherent interaction patterns between the robot and its environment, which results in a relatively short predicted action length. We observe that robotic environments naturally alternate between active states-where precise actions are crucial-and inactive states-where actions have limited impact on task success. This insight enables a new scheduling opportunity: long-action-length speculative prediction in inactive states, paired with selective verification in active states.   We propose SpecVLA, an algorithm-system co-design framework that adaptively balances action length, inference latency, and task reliability. On the algorithm side, SpecVLA introduces a state-aware VLA inference execution paradigm and a hardware-friendly construction of a smaller verification model (sVLA) using differential residuals and block-wise mixed-precision quantization. On the system side, we develop a heterogeneous architecture consisting of a GPU and a robotic-specific hardware module, along with a speculative dataflow that decouples VLA and sVLA through parallel execution. Comprehensive evaluations on OpenVLA and RDT across LIBERO and ManiSkill benchmarks show that SpecVLA reduces end-to-end latency significantly while preserving task success rate. By enabling long-action-length speculative prediction with timely verification, SpecVLA achieves real-time robotic manipulation with both high efficiency and reliability.

## 1. 论文的核心问题与整体含义

- **研究背景**：视觉-语言-动作（VLA）模型在具身智能中表现出很强的理解和泛化能力，但其推理延迟通常超过 600ms，无法满足实时机器人控制需求。已有加速器（如 Dadu-Corki）通过异构系统（GPU 服务器 + FPGA 平台）隐藏通信与推理延迟，但仍未利用机器人-环境交互的固有模式，导致单次推理只能预测较少动作（<4 个），性能潜力未被充分挖掘。
- **核心观察**：
  - 机器人环境天然存在两种状态：**活跃状态**（如抓取、对齐、放置，需要精确控制）与**非活跃状态**（如单纯移动夹爪到目标位置，中间动作对最终结果影响有限）。
  - 相邻环境帧具有高时间冗余性，因此一个量化的小型 VLA（sVLA）可以以较低计算成本产出较高质量的动作预测，但 sVLA 在长动作序列下精度显著下降。
- **研究意义**：本文提出 SpecVLA，一种算法-系统协同设计框架，通过“非活跃状态长动作推测 + 活跃状态选择性验证”来在保持任务成功率的同时大幅降低端到端延迟，实现实时、可靠的机器人操作。

## 2. 论文提出的方法论

### 2.1 核心思想
SpecVLA 根据机器人环境状态自适应调整动作预测长度：
- **非活跃状态**：直接由完整 VLA 一次预测较长动作序列（如 8 个），不加验证，以摊销推理成本。
- **活跃状态**：VLA 先预测长动作序列，然后由轻量级 sVLA 在每步执行前进行动作验证；若验证不通过，则回滚并重新调用 VLA 生成新动作序列。

### 2.2 关键技术细节

#### (1) 环境状态预测（算法 1）
- 计算机械臂与每个物体之间的欧氏距离 \(D_i = \sum_{k=1}^{3} (G_c[k] - O_i^c[k])^2\)。
- 如果距离小于阈值 \(T_d\)，或机械臂处于非张开状态（\(G_s \neq -1\)），则判定为**活跃状态**；否则为**非活跃状态**。

#### (2) 动作验证
- 通过 sVLA 推理得到期望动作 \(A'\)，与 VLA 的预测动作 \(A\) 计算**加权 L1 距离**。
- 先对各维度进行 min-max 归一化：\(\tilde{A}[k] = (A[k] - A_{low}[k]) / (A_{high}[k] - A_{low}[k])\)。
- 加权 L1 距离：\(L_1(\tilde{A}, \tilde{A}') = \sum_{k=1}^{7} w[k] \cdot |\tilde{A}[k] - \tilde{A}'[k]|\)，其中 \(w[k] = 1/\sigma[k]\)，\(\sigma[k]\) 为该维度的标准差，以此平衡不同维度对误差的敏感性。
- 距离小于阈值 \(T_s\) 则接受该预测动作，否则拒绝并触发重新预测。

#### (3) sVLA 的构建——基于差分的硬件友好量化
- 对连续帧特征计算残差：\(\Delta X_i = X_i - X_{i-1}\)，利用残差分布更窄的特点进行混合精度量化。
- **分块量化**：将残差矩阵划分为固定大小块，根据块内元素绝对值之和与两个阈值 \(T_z\)、\(T_h\)（\(T_z < T_h\)）的关系，将块量化为 0-bit（清零）、4-bit（低精度）或 8-bit（高精度）。
- **分块拆分**：高精度块被拆分为高比特分量和低比特分量，使所有块都能在统一的低精度 SIMD PE 阵列上计算，简化硬件控制。
- 最终输出通过累积上一层残差输出得到。

#### (4) 推测数据流
- 为解耦 VLA 与 sVLA 的依赖，采用**推测执行**：GPU 上的 VLA 提前进行下一轮动作序列预测，机器人专用硬件上的 sVLA 同时进行动作验证；若验证通过，则提前终止 VLA 的投机计算；若失败，则让 VLA 继续完成剩余计算。同时将机器人动作执行与两模型计算并行化，并设计回滚机制（最多一个运动原语）保证状态可恢复。

### 2.3 硬件架构
- **异构系统**：GPU（全精度 VLA 推理）+ 机器人专用硬件模块（sVLA 推理、预处理、状态预测）。
- **专用硬件模块**：
  - SIMD-based PE 阵列，支持低精度块级矩阵乘，通过 block-label 区分低精度块、高精度块的低/高比特分量。
  - **可重构状态预测器**：统一环境状态预测和动作验证的距离计算流水线，复用减法组、值计算单元、加法树和比较器，减少硬件开销。
  - **预处理模块**：集成残差生成、分块量化、标签生成，减少数据搬运。

## 7. 优点

1. **新颖的算法-架构协同思想**：利用环境活跃/非活跃状态的自适应推断，结合推测执行与验证，为 VLA 实时部署提供了新思路。
2. **轻量验证模型的可硬件化设计**：通过差分残差和分块混合精度量化，sVLA 在保持精度的同时大幅降低计算量，并设计成便于 SIMD 统一处理的 block-label 机制。
3. **异构系统与投机数据流**：GPU 与机器人专用硬件并行执行 VLA/sVLA，并通过提早终止/继续计算的投机策略隐藏延迟，结合回滚机制保障安全性。
4. **可重构状态预测器**：统一环境状态预测和动作验证的距离计算路径，降低硬件面积和功耗。
5. **实验全面且细致**：从算法成功率、推测效率、量化效率、硬件开销、能量效率、设计空间等多维度评估，并做了丰富的消融与参数灵敏度分析。

## 8. 不足与局限

1. **硬件结果基于模拟与综合**：机器人专用硬件模块未进行流片或真实 FPGA 原型验证，精度与功耗评估依赖 28nm 综合和 CACTI 估计，可能与实际存在偏差。
2. **实验环境为仿真基准**：LIBERO 和 ManiSkill 均为仿真平台，未在真实物理机器人上验证，考虑传感器噪声也是模拟而非真实物理条件，实际部署效果仍有待证明。
3. **对比公平性存疑**：SpecVLA 的端到端加速比主要来自专用硬件；在纯 GPU 上的对比（如表 3 中的算法加速方法）并不公平，因为 SpecVLA 使用了额外硬件资源。
4. **阈值与超参数依赖人工调节**：\(T_s, T_d, T_z, T_h\) 和预测长度 \(L\) 通过启发式一维搜索确定，未进行全局联合优化，可能不是最优组合；最优参数可能随任务变化而需重调。
5. **长期任务累积误差风险**：推测验证的模式虽然引入回滚机制，但若回滚无法完全恢复物理状态（如物体已被碰倒），成功率可能受影响；论文仅讨论了“至多一个运动原语”的假设，未深入探讨极端场景。
6. **基线能力限制**：RDT 在 PlugCharger 任务上基线成功率仅为 2%，说明该任务难度过高，SpecVLA 仅能保持微弱优势，无法逆转模型本身的泛化缺陷。
