## 摘要
世界动作模型（WAMs）通过联合建模动作和未来观测来改进机器人策略学习。然而，仅将未来预测条件设置为任务提示和观测上下文，可能会捕捉到通用任务进程，而非所执行动作的具体后果。我们引入了SelfWAM，一种基于模态专长混合Transformer（MoT）架构的统一自接地WAM，该模型联合预测动作、动作条件下的未来RGB帧和机器人自掩码，从而将未来预测扎根于机器人的可见身体及其动作引起的运动。在联合训练期间，SelfWAM允许未来视觉查询关注演示动作的干净副本，将视频分支转变为动作特定后果模型，同时保持仅动作的快速推理路径不变。为了将视频学习聚焦于动作相关的视觉变化，我们使用针对未来机器人自掩码预测的提示特定目标，该目标移除了外观细节，并提供了一个其时间演化与条件动作紧密耦合的目标。总之，干净动作条件和未来自掩码监督使未来预测更直接地反映执行动作如何改变机器人的可见运动及周围场景。在RoboTwin 2.0和真实世界操作任务上的实验表明，SelfWAM生成了对动作更敏感的未来，并保持了快速策略推理，同时提升了策略性能。

## Abstract
World Action Models (WAMs) improve robot policy learning by jointly modeling actions and future observations. However, conditioning future prediction only on the task prompt and observation context risks capturing generic task progression rather than the action-specific consequences of the executed action. We introduce SelfWAM, a unified self-grounded WAM built on a modality-specialized Mixture-of-Transformers (MoT) architecture that jointly predicts actions, action-conditioned future RGB frames, and robot self-masks, thereby grounding future prediction in the robot's visible body and its action-induced motion. During joint training, SelfWAM allows future visual queries to attend to a clean copy of the demonstrated action, turning the video branch into an action-specific consequence model while leaving the fast action-only inference path unchanged. To focus video learning on action-relevant visual changes, we use prompt-specific objectives for future robot self-mask prediction, which removes appearance details and provides a target whose temporal evolution is tightly coupled with the conditioning action. Together, clean-action conditioning and future self-mask supervision make future predictions more directly reflect how the executed action changes the robot's visible motion and the surrounding scene. Experiments on RoboTwin 2.0 and real-world manipulation tasks show that SelfWAM produces more action-sensitive futures and preserves fast policy inference, while improving policy performance.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：世界动作模型（World Action Model, WAM）通过联合建模机器人动作与未来视觉观测来提升策略学习，但现有WAM（如FastWAM）在预测未来视频时仅以当前观测和任务指令为条件，**未显式利用产生该未来的演示动作**。这导致未来预测倾向于捕捉"通用任务进展"（generic task progression），而非"特定动作引发的具体视觉后果"，从而削弱了世界模型对策略学习的辅助价值。
- **动机**：在机器人操作任务中，同一观测下可能存在多个合理动作，每个动作会导向不同的未来。政策面向的世界模型应当能够回答"如果我执行某个动作，世界将如何变化"。这要求未来预测是**动作条件化（action-conditioned）**的，并且要明确建模**机器人自身可见身体**及其动作诱导的运动（self-grounded）。
- **整体含义**：论文提出SelfWAM，统一了动作预测与动作条件化的未来建模，既保持FastWAM的高效纯动作推理路径，又使未来预测成为真正"动作特定的后果模型"，并引入未来机器人自掩码预测来强化对动作相关视觉变化的监督。

### 2. 论文提出的方法论

#### 核心思想
- 在FastWAM的"双流混合Transformer（MoT）"架构基础上，增加一条**干净演示动作条件路径**：未来视觉查询可以关注该干净动作，而动作预测查询不能，从而在不泄露目标、不改变部署路径的前提下，实现"动作条件化的未来预测"。
- 额外引入**未来机器人自掩码序列预测**作为辅助目标，通过掩码消除外观和背景差异，将世界模型的学习聚焦于机器人自身可见运动。

#### 关键技术细节
- **架构**：模态专长混合Transformer（MoT），包含：
  - **视频流**：预训练视频扩散骨干（WAN2.2-5B），处理当前观测+带噪未来视频潜变量；
  - **动作流**：轻量级动作专家（权重由视频骨干参数插值初始化），处理带噪未来动作 token；
  - 两个流通过**混合注意力（mixed attention）**耦合，保留各自模态专用投影和前馈层。
- **信息流设计（训练时注意力掩码）**：
  - 带噪未来动作查询 → 只能关注当前上下文和自身（保持不变，与部署一致）；
  - 未来视觉查询 → 可关注当前上下文、自身视觉 token、**干净动作副本**（新增）；
  - 干净动作查询 → 只关注当前上下文和自身。
  - 干净动作采用**零噪声时间步（t=0）**和与带噪动作相同的时序位置编码，形成"去噪终点"语义。
- **自掩码预测**：同一视频骨干，通过不同输出提示词（prompt）区分RGB预测与自掩码预测。掩码与RGB共享相同的时空布局、噪声调度和位置编码，但掩码目标只包含机器人自身区域，剔除外观与背景信息。RGB与自掩码训练实例抽样比例为9:1。
- **损失函数**：
  - L = λ_act · L_act + λ_video · L_rgb/mask，λ_act = λ_video = 1；
  - 自掩码实例不参与动作去噪损失，只贡献L_mask。
- **部署路径**：推理时省略干净动作路径和未来视频生成，只保留"当前上下文编码 + 轻量动作专家迭代去噪"的快速闭环控制路径；可选地，可将候选动作插入干净动作路径，用于未来RGB或自掩码的滚动预测（rollout）。

### 3. 实验设计

#### 仿真场景：RoboTwin 2.0
- **Benchmark**：大规模双臂协调操作基准，涵盖50+任务。
- **训练数据**：27,500条演示（2,500条干净环境 + 25,000条场景随机化环境）。
- **评估方式**：每任务100次仿真rollout，分别在干净（Clean）与随机化（Random）设置下报告成功率。
- **对比方法**：
  - VLA基线：π0、π0.5；
  - WAM基线：Motus、GigaWorld-Policy、FastWAM。
- **结果**：SelfWAM平均成功率92.62%，优于FastWAM（91.84%）、GigaWorld-Policy（85.70%）、Motus（87.84%）、π0.5（79.75%）、π0（62.16%）。

#### 真实机器人场景：AgileX ALOHA双臂平台
- **数据集**：约17K episode、955万 transition 的桌面操作数据；离线用RobotSeg生成机器人自掩码作为训练目标。
- **任务**：4项真实拿放任务（棕色杯子放木架、黑笔插入蓝杯、黑鼠标放灰色鼠标垫、纸球丢桌面收纳盒）。
- **对比方法**：FastWAM 与 π0.5。
- **结果**：SelfWAM平均成功率95%，高于FastWAM（85%）和π0.5（90%）。

#### 未来预测质量评估
- 均匀采样275条轨迹，比较FastWAM（无动作条件）与SelfWAM（动作条件）的未来预测质量。
- 指标：LPIPS、PSNR、FVD-I3D。
- 结果：SelfWAM显著改善（LPIPS 0.0636→0.0429，PSNR 29.24→32.79，FVD-I3D 45.92→34.55）。

#### 动作敏感性实验
- **方向性动作扰动**：在关节空间施加方向偏移，保持观测、指令和采样噪声固定，验证预测未来随动作方向变化。
- **连续性动作插值**：从"保持"动作插值到演示动作，验证预测未来的连续性变化。
- **WorldArena指标**：Action Following（动作跟随度，SelfWAM 0.0184 vs FastWAM 0.0）及主体/背景/光度一致性。

#### 消融实验
- 三个变体：FastWAM（无干净动作条件、无自掩码）；Ours w/o self-mask（仅动作条件）；SelfWAM（动作条件+自掩码）。
- 结果：动作条件单独带来约1个百分点的性能回落（92.16/93.08 → 90.80/90.80），加上自掩码后反超FastWAM，说明自掩码是提升策略性能的关键补充。

### 6. 论文的主要结论与发现

- 干净动作条件化使未来预测从"观察者视角"转变为"行动者视角"，生成对未来帧的预测对动作变化更敏感、更一致。
- 未来机器人自掩码预测提供了与外观无关的、紧耦合于动作的监督信号，进一步强化自接地，并带来策略性能提升。
- SelfWAM在RoboTwin 2.0和真实机器人任务上，策略性能优于或持平所有基线，同时保持几乎不变的推理时延（+0.97%）和峰值内存（0.00%）。
- 方向扰动与插值实验证明，SelfWAM的未来预测具有方向对齐性和局部连续性，而动作无条件基线几乎不随动作变化。
- 干净动作路径和带噪动作路径在零噪声点处表示一致（最大NRMSE≈1e-5），说明两条路径语义统一，不存在架构不一致问题。

### 8. 不足与局限

- **未建模接触/力/遮挡交互**：论文只预测RGB和自掩码，不显式建模接触力、隐藏交互，对接触丰富任务适用性受限（作者在附录F也承认这一点）。

- **动作扰动实验为定性/半定量**：方向扰动和插值结果以图示展示，缺乏定量比较的显著性检验。
- **训练成本较高**：64块A800、30小时、5B视频骨干的设定，对一般研究团队复现门槛较高。
