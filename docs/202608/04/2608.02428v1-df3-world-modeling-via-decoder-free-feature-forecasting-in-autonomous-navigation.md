## 摘要
从视频序列预测未来状态是自主机器人系统面临的关键挑战，也是世界建模的基本目标。先前在像素级运作的生成方法不可避免地过度强调与任务无关的细节，导致计算开销过高。虽然基于潜在空间的方法试图通过直接预测特征来缓解这一问题，但为了从状态到任务的映射而持续依赖重型解码器仍然是一个计算瓶颈。在这项工作中，我们提出了无解码器特征预测（DF³），这是一个全新的框架，完全在潜在空间内建模世界演化，并直接生成任务输出，从而完全消除了对解码器的需求。具体来说，DF³ 将可学习的空间查询注入到冻结视觉基础模型的末端块中，以直接提取未来状态表示。通过采用一种轻量级、统一的运动感知上下文融合（MACF）机制，该机制无缝结合了粗粒度光流扭曲与细粒度潜在互相关，这些查询与历史令牌表示交互，以显式对齐并预测下一帧的特征。随后，一组专门的任务查询探测这些预测特征以用于下游任务。在公共基准测试和机器人模拟器中的零样本部署上进行的大量实验表明，DF³ 实现了与最先进方法相当的性能，同时为集成感知与控制提供了更高的效率和灵活性。

## Abstract
Forecasting future states from video sequences is a critical challenge for autonomous robotic systems and a fundamental objective of world modeling. Prior generative methods operating at the pixel level inevitably overemphasize task-irrelevant details, leading to prohibitive computational overhead. While latent-based approaches attempt to mitigate this by predicting features directly, the persistent reliance on heavy decoders for state-to-task mapping remains a computational bottleneck. In this work, we propose Decoder-Free Feature Forecasting (DF$^3$), a novel framework that models world evolution entirely within the latent space and directly derives task outputs, completely eliminating the need for a decoder. Specifically, DF$^3$ injects learnable spatial queries into the terminal blocks of a frozen vision foundation model to extract future state representations directly. By employing a lightweight, unified Motion-Aware Context Fusion (MACF) mechanism that seamlessly integrates coarse flow warping with fine-grained latent cross-correlation, these queries interact with historical token representations to explicitly align and forecast the feature of the next frame. Subsequently, a specialized set of task queries probes these forecasted features for the downstream task. Extensive experiments on public benchmarks and zero-shot deployment in a robotic simulator demonstrate that DF$^3$ achieves performance comparable to state-of-the-art methods while offering superior efficiency and flexibility for integrated perception and control.

## 2. 方法论

### 2.1 核心思想

- DF³ 的核心思想是**“查询注入 + 冻结编码器复用”**：将可学习的预测查询与任务查询直接注入冻结 ViT 的末端块，通过自注意力与历史上下文交互，在编码器内部同时完成未来特征预测和任务输出提取，全程无需解码器，也无需微调预训练骨干。

### 2.2 整体流程

- 历史帧 {I₁,…,I_T} 分别经过冻结 DINO-based ViT 的**早期层（L1）**得到上下文特征 F_L1（包含 patch tokens 和 prefix tokens：CLS 与 register tokens）。
- 一组可学习的**预测查询 Q_pred** 与所有历史上下文特征拼接，共同经过冻结 ViT 的**末端块（L2）**；末端块输出中对应于 Q_pred 的 token 经 **MACF 模块**细化后重组为预测的未来特征 \hat{F}_{L1}(I_{T+1})（patch + prefix tokens）。
- 预测特征再作为下一帧的表示，与一组**任务查询 Q_task** 拼接后再次注入末端块（L2），使任务查询通过自注意力聚合预测特征中的任务相关信息；输出 token 经过轻量 MLP 头即可生成语义分割结果。

### 2.3 结构化查询注意力（Structured Query Attention）

- 在末端块自注意力中施加**非对称注意力掩码**：上下文 token 之间可以自由互相注意，但**禁止上下文 token 回看预测查询**（对应 logit 置为 −∞）；预测查询则可以看到所有 token。这一因果设计防止信息泄漏，确保上下文表征不被注入查询污染。

### 2.4 运动感知上下文融合（MACF）

MACF 由两个并行分支加一个动态融合门控组成：

- **Flow-based Warp 分支（粗粒度）**：由中间预测查询 q_patch 经 MLP 预测稠密潜流场 Δp，将最近历史特征 f_{L1}(I_T) warp 到未来姿态，再用 warp 结果与 q_patch 的差异经 MLP 得到提议更新方向 M_warp。
- **Latent Cross-Correlation 分支（细粒度）**：在潜空间中计算 f_{L1}(I_{T-1}) 与 f_{L1}(I_T) 的局部软匹配（局部窗口半径 r 内余弦相似度加权），得到历史语义速度 V_hist（当前特征与软匹配前一帧特征之差），经 MLP 得到历史运动注入 M_xcorr。
- **动态融合**：两个分支的更新量拼接后经 MLP 融合，Sigmoid 门控 G 根据查询状态动态调节残差权重，叠加到初始查询上得到最终预测特征 \hat{f}_{L1}(I_{T+1}) = q_patch + G ⊙ MLP_fuse([M_warp, M_xcorr])。

### 2.5 训练目标

- 无需下游任务联合训练，仅靠**特征级监督**：对所有历史时间步 t，最小化预测特征 \hat{F}_{L1}(I_{t+1}) 与真实冻结编码器特征 F_{L1}(I_{t+1}) 之间的损失，包含余弦相似度项 + Huber 损失项，patch tokens 与 prefix tokens 均参与监督。

## 6. 主要结论与发现

- DF³ 在保持与潜空间 SOTA 方法（DINO-Foresight）相当预测精度的前提下（短期 mIoU 69.9 vs. 71.8；MO-mIoU 68.7 vs. 71.7），实现了显著效率提升：**FLOPs 降低 36%，延迟降低 70%（971ms→292ms），峰值显存降低 67%，参数量降低 41%**。
- **消融结果**：仅有朴素拼接（59.9 mIoU）或全局注意力（63.0）不够，显式运动建模是关键；warp 分支与 xcorr 分支互补，两者结合（69.9）显著优于任一单独分支（63.6 / 65.7）；搜索半径 r={1,2,4,8} 最优，过大（含16）反而损害性能。
- 零样本 MATRiX 四足机器人部署证明了 DF³ 学到的潜空间特征具备**跨视角、跨实体迁移能力**：Cityscapes 训练的模型直接驱动四足机器人轨迹规划，预测轨迹与 Oracle 轨迹空间对齐良好。
- 核心结论：无解码器潜空间预测范式是可行的——在冻结 VFM 内部通过查询注入和轻量运动融合即可完成高质量未来特征预测与任务输出，是实时自动驾驶感知的有效方案。

## 7. 优点

- **彻底消除解码器瓶颈**：预报和任务映射均发生在冻结 ViT 内部，架构简洁高效，是第一个完全在冻结 VFM 特征空间内完成 forecasting + task probing 的工作。
- **冻结骨干、不微调预训练权重**：大幅降低训练成本，同时保留 VFM 的语义泛化能力，有利于数据高效训练与复用。
- **MACF 设计精巧且轻量**：粗粒度光流 warp 与细粒度潜空间互相关互补，既有强运动归纳偏置，又避免了重型时空 Transformer；门控融合提供了动态自适应能力。
- **特征级训练目标简洁**：仅用 cosine + Huber 即可获得良好训练信号，无需复杂的对抗或扩散目标。
- **工程实用性强**：显著降低延迟和显存（292ms/帧，3.1GB），为车载嵌入式实时部署提供可能；查询式设计天然支持任务解耦与即插即用。

## 8. 不足与局限

- **仅支持观察性预测（observation-only）**：框架不支持动作条件预测，无法模拟“执行某动作后环境会如何变化”，这是闭环控制与交互规划的关键短板，作者在 Limitation 中也明确承认。
- **帧率仍不足**：292ms/帧约合 3.4 FPS，对于高速自动驾驶仍偏低，尚未达到严格的实时要求（如 10–30 FPS），需要更轻的骨干或推理优化。
- **实验覆盖有限**：只训练和评测了 Cityscapes 单数据集；与基线（DINO-Foresight）之外缺少与 DINO-WM、像素级生成方法的对比；多数据集泛化与多任务扩展（如目标检测、深度估计）尚未验证。
- **空间精度损失**：冻结 ViT 的降采样特征空间导致预测结果的边界粗糙、薄结构细节丢失（文中自己承认 over-smoothing），虽然不影响宏观规划，但限制了精细感知需求。
- **零样本部署是仿真验证**：MATRiX 是模拟器，真实四足机器人/实车上的鲁棒性尚未验证；Cityscapes 汽车视角到四足机器人地面视角的域差异较大，实际部署效果需要更多证据。
- **未明确披露全部训练细节**（batch size、GPU 训练时长、具体优化超参数等），可复现性有一定折扣；对比实验中的速度优势部分来自模型设计，也部分来自算法便利，需注意量化口径。
