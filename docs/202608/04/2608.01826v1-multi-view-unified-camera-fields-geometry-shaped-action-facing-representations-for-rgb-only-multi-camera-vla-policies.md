## 摘要
视觉-语言-动作（VLA）模型在机器人操作中展现出强大的泛化能力，然而复杂的接触密集任务通常受益于多相机观测，这些观测能够联合捕捉遮挡情况下的末端执行器、物体和目标。现有的多相机VLA通常拼接视图标记，导致动作表示在度量深度上较弱，且在不同相机之间不一致。我们引入了多视图统一相机场（MVUCF），这是一个仅训练框架，跨视图构建共享的动作朝向潜在场。坐标查询深度目标使度量深度可恢复，而预处理感知对应目标则对齐从不同相机观察到同一物理点的标记。两者直接塑造动作模块所消费的隐藏状态。在几何注入后，深度、相机标定和辅助头被移除，因此部署时使用原始仅RGB图，不增加额外推理FLOPs。保留探针证实了更强的深度恢复和跨视图匹配。在匹配的GR00T-N1.6设置下，MVUCF在LIBERO上达到98.9%，在LIBERO-Plus上提高22.4个百分点，并在涵盖触摸、移动放置和接触交互三个动作家族的六个RoboTwin任务上将成功率提高23.3个百分点。真实世界的人形机器人实验进一步提供了其在仅RGB部署下实际有效性的证据。

## Abstract
Vision-Language-Action (VLA) models have shown strong generalization in robotic manipulation, yet complex contact-rich tasks often benefit from multi-camera observations that jointly capture the end effector, objects, and targets under occlusion. Existing multi-camera VLAs usually concatenate view tokens, leaving action representations weak in metric depth and inconsistent across cameras. We introduce Multi-View Unified Camera Fields (MVUCF), a training-only framework that forms a shared action-facing latent field across views. A coordinate-query depth objective makes metric depth recoverable, while a preprocessing-aware correspondence objective aligns tokens observing the same physical point from different cameras. Both directly shape the hidden states consumed by the action module. After geometry injection, depth, camera calibration, and auxiliary heads are removed, so deployment uses the original RGB-only graph with no extra inference FLOPs. Held-out probes confirm stronger depth recovery and cross-view matching. Under matched GR00T-N1.6 settings, MVUCF reaches 98.9% on LIBERO, improves LIBERO-Plus by 22.4 points, and raises success by 23.3 points across six RoboTwin tasks spanning three action families: touch, move-and-place, and contact interaction. Real-world humanoid experiments further provide evidence of its practical effectiveness under RGB-only deployment.

## 1. 核心问题与研究动机

- **背景**：VLA（视觉-语言-动作）模型在机器人操作中表现出强泛化能力，但接触密集任务对视觉感知要求极高。单相机难以同时捕捉末端执行器、物体、目标及其空间关系（尤其存在遮挡时），因此多相机观测被广泛引入。
- **现有方法的缺陷**：主流多相机 VLA 策略仅将各视角的视觉 token 简单拼接，存在两大问题：
  1. **度量深度弱**：VLA 骨干初始化自以 2D 语义为主预训练的视觉-语言模型，隐藏状态难以可靠恢复度量深度和 3D 空间结构（实验显示原生骨干深度 MAE 高达 4.3 cm）。
  2. **跨视图不一致**：简单拼接不显式鼓励同一物理点在多相机视角下的特征一致性，跨视图检索近乎随机（Hit@1 仅 0.4%，接近随机水平 0.3%）。
- **现有工作的割裂**：几何感知策略（如 SpatialVLA、Spatial Forcing、GeoVLA）与跨视图一致性方法（如 Selfi）分别解决单一前提，机制差异大，无法简单模块化组合。论文因此提出一个**统一框架**，同时注入跨视图一致性与 3D 结构。

## 2. 方法论

### 2.1 核心思想
MVUCF 是一个**仅训练阶段**的框架：在动作训练之前，通过两个互补的辅助目标（坐标查询深度目标 + 预处理感知对应目标）直接塑造"动作朝向"的骨干隐藏状态（layer 15 的 token 网格），形成跨视图共享的潜在场（latent field）。几何注入完成后，辅助头、深度输入、相机标定全部移除，部署时保留原始 RGB-only 推理图，**零额外推理 FLOPs**。

### 2.2 模型整体流程
- 输入：同步多相机 RGB 观测 {oᵢ}、语言指令 l，策略预测动作 aₜ ~ πθ(·|O≤t, l)。
- 阶段一（几何注入）：仅更新 VLM 层 8–15 及两个辅助头（视觉编码器与层 0–7 冻结），以深度损失和跨视图损失训练 50k 步。
- 阶段二（动作训练）：移除辅助头，冻结几何塑形后的骨干，仅用 RGB 观测训练原生动作模块。Base 与 Ours 的动作数据、头、调度、检查点规则完全一致，唯一差异是几何注入。

### 2.3 跨视图目标构建（关键细节）
- **投影链**：源像素 u_raw_i 结合深度 z*、内参 Kᵢ、相机位姿 Tᵢ→w 反投影到 3D，再重投影到目标视角 j：Pw = Tᵢ→w π⁻¹(u_raw_i, z*, Kᵢ)，u_raw_j = π(Tw→j Pw, Kⱼ)。
- **有效性检查**：目标像素在图像内、目标帧深度有效且在 [0.05, 5.0] m、z-buffer 一致性条件 |Zⱼ − z*ⱼ(u_raw_j)| < 0.10 m，剔除遮挡或深度不一致的对应。
- **预处理感知映射**：使用复合变换 T_img→grid（letterbox → 缩放 → 裁剪 → smart-resize → patchification(14) → pixel-unshuffle(2)）将原始像素映射到 token 网格坐标，**先投影再预处理**，避免直接缩放原始像素导致的坐标错配。
- 软标签：以投影 token 中心 q* 为中心的高斯分布（σ=0.75），而非离散 one-hot，以容忍亚 token 级投影误差。

### 2.4 坐标查询深度目标
- 深度头在连续网格坐标 q=(x,y) 预测度量深度 ẑᵢ(q) = g_φ(Fᵢ, q)。
- 每视图 3072 个查询：50% 均匀采样，50% 重要性采样（集中于近表面和深度不连续处）。
- 查询特征：GridTrunk（LN 2048→Linear 1024→GELU→Conv 3×3）→ 双线性特征查找（1024 维）拼接局部 x/y 差（各 1024 维）和亚单元相位 φ(q)（2 维）= 3074 维；**不输入绝对位置**。
- 两个分支：MLP → Softplus 预测度量深度；MLP → clamp[−6,6] 预测对数方差。
- 损失：L_depth = 0.5 L_silog + 1.25 L_inv + 1.0 L_grad + 0.1 L_seam + 0.05 L_unc（梯度项为度量深度一阶差分匹配，防止常数深度坍缩）。所有权重跨数据集固定。

### 2.5 跨视图对应目标
- 共享投影器：LN 2048 → Linear 2048→128 → L2 归一化（无隐藏层/激活），保证 VLM 隐藏状态本身线性可读。
- 匹配 logits：ℓ_mn = 10 (e_s_m)ᵀ e_t_n。
- 损失：L_cv = L_softCE + 0.1 L_hnce + 0.1 L_margin（L_hnce 为硬负样本 InfoNCE，负样本包括空间环、批内、交替视图；L_margin 为铰链间隔损失，γ=0.2）。
- 局部 3×3 分支解决亚 token 邻域；外层 CV 损失权重 40k 步内从 1.0 线性退火到 0.1，早期强调对齐、后期放宽约束。

### 2.6 与现有方法的区别
- 区别于 Spatial Forcing（仅做特征对齐，不直接强制度量深度可恢复性和同点对应）；区别于 VGGT（深层特征在全局注意力混合后丢失 token 级判别力，不保证跨视图一致性）；区别于 Selfi（面向重建/新视角合成，非动作表示）。

## 3. 实验设计

### 3.1 诊断性实验
- **外部几何特征充分性诊断**：评估 VGGT 各层作为蒸馏目标的可行性。浅层特征保持跨视图 token 身份，深层特征接近随机检索（全局注意力混合后判别力退化），证明"深层几何特征 ≠ 统一的相机场"，需要在动作朝向的 VLA 网格上显式监督。
- **表征诊断（held-out）**：几何注入后，深度 MAE 从 4.9 cm 降至 0.44 cm，2 cm 内预测比例从 44% 升至 97%；跨视图检索 Hit@1 从近随机提升至 64%，真匹配与随机对明显分离（Cohen's d 提升）；注意力可视化显示注入后动作-to-图像注意力更集中于操作对象和目标。

### 3.2 仿真基准
| 基准 | 结果 |
|---|---|
| **LIBERO（标准）** | 平均成功率 98.9%（Base 97.4%），长时程 LIBERO-10 提升 +4.1 点 |
| **LIBERO-Plus（鲁棒性）** | 零样本 +22.4 点（42.8→65.2），7 个扰动类别全部提升（相机 +3.2、机器人 +13.9、语言 +37.9、光照 +29.7、背景 +15.5、噪声 +33.5、布局 +23.6） |
| **RoboTwin（6 任务）** | 总成功率 +23.3 点（38.6→61.9），覆盖 Touch（+11.0）、Move/Place（+30.5）、Contact（+28.5）三个动作家族，6 个任务全部提升 |

- **对比方法**：OpenVLA、Octo、π0、Diffusion Policy、TraceVLA、Dita、CoT-VLA、π0-FAST、UniVLA、OpenVLA-OFT、Spatial Forcing、SpatialVLA、GeoVLA、3D-CAVLA、Evo-Depth（并发工作）。
- **公平性设计**：Base 和 Ours 共享动作数据、动作头、调度、检查点规则和推理图，几何注入是唯一受控差异；"published systems 只提供上下文，归因归功于匹配的 GR00T 对照对"。

### 3.3 消融实验（LIBERO-10）
- Depth only：+1.12 点（均值 94.00%）
- Cross-view only：+1.33 点（均值 94.21%）
- **Full：+4.12 点（均值 97.00%）**
- 证明两个目标互补：各自单独提升均值，联合使用增益最大。

### 3.4 真实机器人实验
- 平台：智元机器人 Expedition A2 人形机器人；2 个任务（双蛋糕放置、杯子嵌套），每个任务 100 条遥操作示范。
- 结果：60 次试验中 Ours 成功 49/60（81.7%），Base 40/60（66.7%）；两个任务均提升（17/30→21/30，23/30→28/30）。置信区间有重叠，属于"试点级可行性证据"。

## 4. 资源与算力

- **GPU**：LIBERO 实验使用 2 块 NVIDIA H100；RoboTwin 实验使用 4 块 NVIDIA H100。
- **全局批大小**：128（几何注入和动作训练一致）。

- **动作训练**：LIBERO 60k 步；RoboTwin 六任务联合 180k 步（每任务等效 30k 步）。
- **优化器**：AdamW，初始学习率 10⁻⁴，权重衰减 10⁻⁵，前 5% 步数线性预热。
- **检查点**：统一使用预声明的终止检查点（50k/60k/180k），无验证集或下游成功率筛选。
- **说明**：几何注入仅增加离线训练成本，最终部署图不增加任何参数或 FLOPs。

## 6. 讨论与结论

### 6.1 主要贡献
- 提出 **MVUCF**，首个仅训练阶段、统一几何塑形框架，同时将**度量深度可恢复性**与**跨视图对应一致性**注入 VLA 骨干的固定 token 网格。
- 揭示 VLA 骨干（GR00T-N1.6）的隐藏状态在默认状态下的两个核心缺陷：深度 MAE 高达 4.3–4.9 cm、跨视图 Hit@1 接近随机；并给出可操作的诊断协议。
- 通过精心设计的投影链 + 预处理感知映射 + 软标签，实现无需渲染、无需 3D 监督的辅助目标，训练后完全移除几何模块，**部署零额外开销**。
- 在 LIBERO、LIBERO-Plus、RoboTwin 及真实人形机器人上取得一致提升，特别是鲁棒性扰动场景（+22.4 点）与接触密集任务（+23.3 点）。

### 6.2 局限与未来工作
- **受限于骨干选择**：所有实验基于 GR00T-N1.6，未验证在更小/更大 VLM（如 7B、72B）上的可迁移性；几何注入深度（layer 8–15）可能需按骨干结构重新搜索。
- **需要相机标定**：几何注入阶段需要已知内外参与深度真值，这在真实世界大规模数据上难以获得；论文通过 z-buffer 与深度有效性检查缓解，但仍依赖模拟器或 RGB-D 传感器。
- **多相机间基线**：假设相机位姿与同步已由外部系统提供；未处理相机漂移、不同步或标定误差的鲁棒性。
- **动作表示未直接显式建模**：跨视图一致性在 token 特征层面建立，但未显式对齐到机器人动作空间；对非刚体形变、工具使用等场景的效果仍属未知。
- **理论解释有限**：为何几何注入能在动作 head 上带来泛化增益，缺乏理论分析（如与隐式神经场、世界模型的关系）。

### 6.3 总体评价
- **创新性**：高。将几何感知与跨视图一致性纳入**统一、可插拔**的框架，而非堆砌机制；训练后剪枝的设计使部署成本完全不变。
- **实验严谨性**：高。受控对照（Base 与 Ours 唯一差异）是少见的规范做法；诊断实验量化了“几何缺陷”本身，而不是只看最终成功率；消融证明两个目标互补。
- **实用性**：中高。真实机器人提升幅度可观（+15 个百分点），但试点规模限制了结论强度；需要更多平台与任务验证。
- **写作与可复现性**：论文详细描述了投影链、损失权重、超参数与算力配置，但**未提供代码/权重**，复现门槛较高。
