## 摘要
移动操作是具身智能的关键能力，使机器人能够在开放世界环境中完成复杂的多阶段任务。然而，移动操作对视觉-语言-动作（VLA）策略提出了两个关键挑战：在数据层面，高质量全身演示的高效采集需要对移动底盘和机械臂进行协调控制；在模型层面，现有VLA模型主要依赖局部相机观测，其有限的视野阻碍了全局空间理解。为解决这些挑战，我们开发了一套全身遥操作系统和一种全景感知VLA策略。该系统通过单一VR接口实现对轮式双臂机器人的协调控制，并支持获取包含5.5小时多模态演示的真实世界移动操作数据集。在此数据集基础上，我们提出了PanoVLA，一种用于移动双臂操作的全景感知视觉-语言-动作策略。基于混合Transformer架构，PanoVLA通过专门的全景编码和融合模块引入全局空间上下文，使全景观测能够与语言指令和机器人状态有效集成以生成动作。在四个真实世界移动操作任务上的评估表明，PanoVLA实现了91.3%的平均阶段完成率和73.4%的端到端成功率，显著优于局部视图基线。这些结果表明，融入全景空间上下文能够提升移动机器人的空间理解能力和闭环操作性能。

## Abstract
Mobile manipulation is a key capability for embodied intelligence, enabling robots to accomplish complex multi-stage tasks in open-world environments. However, mobile manipulation poses two key challenges for vision-language-action (VLA) policies: At the data level, the efficient collection of high-quality whole-body demonstrations demands the coordinated control of both the mobile base and the robotic arms; at the model level, existing VLA models predominantly rely on local camera observations, whose limited field of view hinders global spatial understanding. To address these challenges, we develop a whole-body teleoperation system and a panoramic-aware VLA policy. The system enables coordinated control of a wheeled bimanual robot through a single VR interface and supports the acquisition of a real-world mobile manipulation dataset comprising 5.5 hours of multimodal demonstrations. Building upon this dataset, we propose PanoVLA, a panorama-aware vision-language-action policy for mobile bimanual manipulation. Built upon a Mixture-of-Transformers architecture, PanoVLA introduces global spatial context through dedicated panorama encoding and fusion modules, enabling effective integration of panoramic observations with language instructions and robot states for action generation. Evaluation on four real-world mobile manipulation tasks demonstrates that PanoVLA achieves an average stage completion rate of 91.3\% and an end-to-end success rate of 73.4\%, substantially outperforming local-view baselines. These results demonstrate that incorporating panoramic spatial context improves spatial understanding and closed-loop manipulation performance in mobile robots.

## 1. 核心问题与研究动机

- **背景**：移动操作是具身智能机器人的核心能力之一，要求机器人在开放环境中完成目标搜索、移动接近、双臂/单臂操作等多阶段复杂任务。近年来视觉-语言-动作（VLA）模型在大规模数据和预训练视觉表征的推动下取得了显著进展，但该进展主要集中于桌面（tabletop）操作场景。
- **两大挑战**：
  - **数据层面**：高效采集高质量的"全身演示"（whole-body demonstrations）要求操作者同时协调移动底盘、双机械臂和夹爪的运动。若移动和操作使用分离的控制接口（如键盘/操纵杆+遥操作手柄），演示的流畅性和质量会显著下降。
  - **模型层面**：现有VLA模型主要依赖前视相机和腕部相机等局部观测，视野有限。在长时程移动操作中，基座的平移/旋转和机械臂的自遮挡经常导致目标物体、地标或目标区域从局部视野中消失，阻碍了机器人形成以自身为中心的全局空间理解能力。
- **研究切入点**：全景成像（panoramic imaging）天然提供环绕机器人的全方位观测，但全景图像存在非透视畸变，与预训练视觉编码器的分布存在较大域差距，直接应用标准视觉表征会导致特征质量下降。因此需要针对全景影像专门设计的编码与融合架构。

## 2. 方法论

### 2.1 全身遥操作数据采集系统

- 操作者佩戴VR头显（6-DoF头部追踪）、双手持控制器（手部姿态+夹爪指令）、腰部及双踝共三个身体追踪器，构成稀疏人体运动捕捉接口。
- 系统将稀疏追踪流实时重建为SMPL人体模型，提取骨盆位姿、双手位置/姿态和下肢运动线索作为重定向输入。
- 采用**通用运动重定向（General Motion Retargeting, GMR）**框架将人体运动映射到轮式双臂机器人（RANGER MINI 3移动底盘 + 两个6-DoF PIPER机械臂 + 平行夹爪）。
- 机器人配置参数化为 q = (x_b, y_b, θ_b, q_L, q_R)，其中 (x_b, y_b, θ_b) 为平面底盘位姿，q_L、q_R 为左右臂关节配置。
- 每步通过最小化加权目标函数获得最优机器人配置：

  q* = argmin_q [λ_pos·L_pos + λ_rot·L_rot + λ_base·L_base + λ_reg·L_reg]

  - L_pos / L_rot：对齐操作者手部与机器人末端执行器的位置/朝向；
  - L_base：将平面底盘运动耦合到操作者骨盆位移和朝向；
  - L_reg：抑制关节极限越界和过大位形变化。
- 移动底盘被建模为**3-DoF平面虚拟浮动基座**，与双臂关节联合优化，可动态调整底盘平移和偏航以扩展臂的工作空间。
- 提出**成本驱动模式切换策略**（cost-driven mode-switching）：每控制周期评估三种运动模式（spin、ackermann转向、斜向平移）与目标平移/旋转的匹配成本，选择最优模式执行，并周期性重新决策。

### 2.2 PanoVLA 模型架构

- **整体框架**：基于Mixture-of-Transformers（MoT）架构，在π0.5双专家骨干基础上插入**全景专家（Panorama Expert）**，形成三专家结构：VLM专家、全景专家、动作专家。
- **输入定义**：观测 o_t = {I_loc_t, I_pano_t, s_t}，其中 I_loc_t 为局部视觉观测（前视+双腕相机），I_pano_t 为全景观测（车顶360°相机），s_t 为自身状态；策略 π_θ 输出长度为 H 的连续动作序列。
- **全景编码器（Panorama Encoder）**：
  - 球面重投影：将双目鱼眼视图映射到公共球面并栅格化为等距柱状投影（ERP）图像；
  - 特征提取：使用全景基础模型 **MTPano** 的中间特征，融合分割分支（语义）与深度分支（几何）的密集特征；
  - 令牌适配：通过自适应平均池化压缩为固定空间分辨率，再经轻量MLP映射到全景专家的隐维度，得到全景令牌序列 Z_pano_t = A_ψ(E_p(Π_sph(I_pano_t)))。
- **全景专家（Panorama Expert）**：以全景令牌为输入，在块状因果注意力掩码下，与VLM缓存 C_vlm_t 进行联合自注意力，生成任务条件化的全景缓存 C_pano_t，用于下游动作预测。
- **KV缓存融合**：VLM专家从局部观测、语言指令和本体状态生成VLM缓存；动作专家基于拼接缓存 C_t = [C_vlm_t; C_pano_t] 联合利用局部细粒度操作线索和以机器人中心的全景全局上下文。
- **动作预测**：采用条件流匹配（Conditional Flow Matching），最小化速度场损失：

  L = E[||v_act_θ(x_τ, τ | C_t) − u(x_τ | a)||²]

- **动作表示**：17维向量（双臂14维+底盘3维速度指令），夹爪动作单独为二值开/关，预测32步动作块（动作块相对于当前本体状态表示）。

## 3. 实验设计

### 3.1 数据集

- 利用遥操作系统采集**4个真实世界移动操作任务**的演示数据，每个任务200条轨迹，共800条成功轨迹，总时长约5.5小时，以25Hz记录，约50万同步帧。
- 每个时间步包含：局部数据（前视+腕部RGB）、全景数据（顶部360°相机，以ERP格式存储）、本体状态（双臂绝对关节位置、夹爪状态、底盘相对位姿）、17维全身动作指令。
- **任务类型**（见表I）：
  - **Move Pen**：将笔放入笔架，目标方向：前/左/右；
  - **Move Block**：将积木转移到前方区域，目标方向：左/右/两侧；
  - **Open Curtain**：打开两侧窗帘，需要顺序双侧交互；
  - **Wipe Table**：沿长桌擦拭污渍并归还毛巾，工作空间范围大、多阶段。

### 3.2 基线方法（控制变量设计）

- **π0.5**：仅使用局部相机视图（SigLIP编码），输入语言指令和本体状态；
- **π0.5 w/ Pano**：将ERP全景图作为额外图像输入，由与局部视图相同的SigLIP编码，无专门全景分支；
- **π0.5 w/ Stacked Pano**：将全景重投影为三个光轴间隔120°的透视视图并拼接为组合图像，作为额外视觉输入；
- **PanoVLA**：本文方法，MTPano全景编码 + 全景专家融合。

### 3.3 评估协议

- 每个方法在每个任务上进行**15次闭环真实机器人试验**，每次试验为不中断的完整 rollout，不允许手动重置失败阶段。
- 两个指标：**成功率（SR，端到端二元指标）** 和**阶段完成率（SCR，各阶段完成比例的平均）**。

### 3.4 消融实验

- 在Move Pen任务上进行15次闭环真实机器人试验：
  - **全景专家规模**：50M vs 100M vs 200M vs 300M；
  - **全景编码器选择**：SigLIP vs MTPano。

## 6. 主要结论与发现

- PanoVLA在四个真实任务上取得**平均SCR 91.3%、SR 73.4%**，显著优于原生π0.5（SCR 58.6%，SR 30.0%）和其他全景基线。
- 加入全景观测可普遍改善性能，但**收益取决于全景几何结构的建模方式**：直接使用ERP图+SigLIP（π0.5 w/ Pano）vs 透视重投影拼接（π0.5 w/ Stacked Pano）在不同任务上各有优劣，两种方法均不如PanoVLA稳定。
- 在需要多阶段状态跟踪和长时程空间一致性的任务（如Wipe Table）中，PanoVLA的优势最为明显：原始全景基线在最后阶段失败率高（SR仅20.0%），而PanoVLA将SR提升至46.7%，表明全景专家能更有效地跟踪任务状态转换并保持全局空间一致性。
- 全景编码器实验表明：MTPano（针对全景设计）远优于SigLIP（针对透视图像预训练），验证了全景专用几何感知表征的必要性。
- 全景专家规模存在最优区间：100M参数时效果最佳，过小容量不足、过大则在有限数据下难以充分微调。

## 7. 优点

- **问题定位准确**：同时解决数据采集和模型感知两个层面的核心瓶颈，形成"数据—模型—实验"的完整闭环。
- **遥操作方案具创新性**：用单一VR接口实现底盘+双臂+夹爪的全身协调控制，通过GMR优化和模式切换策略消除对独立移动控制器的依赖，显著降低演示采集的操作负担。
- **数据集质量高**：时间同步的多模态数据（局部视图+全景+本体状态+全身动作）为学习提供了丰富的感知层次。
- **模型设计有针对性**：采用MTPano的语义+深度融合特征处理全景畸变问题，通过全景专家与VLM缓存进行任务条件化融合，使全景信息能直接参与动作生成。
- **实验设计严谨**：三个基线只在全景观测处理方式上变化，控制变量明确；分解SCR和SR两个指标，支持细粒度失败分析。
- **消融实验覆盖关键设计决策**：编码器选择和专家规模均做了真实机器人验证。
