## 摘要
视觉-语言-动作（VLA）模型在机器人操作中表现出色，但当规范指令被简单改写时，其性能会急剧下降。尽管这种脆弱性通常通过高成本的数据扩展来解决，但我们的探测揭示其根源在于架构而非缺乏语义理解。具体而言，我们证明当前的VLA模型在内部能够成功保留正确的任务身份。失败实际上源于动态视觉观测与文本的联合编码，这会引入系统性的特征偏移。由于下游动作策略对这些变化高度敏感，它无法将保留的语义转化为正确的控制命令。为解决这一结构性瓶颈，我们提出了接地语义重绑定（GSR），一种优雅的干预方法，通过将独立提取的任务语义与原生视觉特征显式融合，从零开始训练一个完全重新初始化的动作专家，从而绕过不稳定的联合路由。这一针对性干预仅使用规范演示即可显著恢复改写不变性。在LIBERO-Para基准上，GSR将成功率提升了高达44.6个百分点。它使轻量级模型能够与大规模扩展的基线相媲美，并将最先进的模型推至新的PRIDE得分纪录70.4，在指令生成能力上超越了最近引入的大规模预训练模型Xiaomi-Robotics-0。基于这些见解，我们还引入了ParaVLA，一种原生解耦的0.33B参数模型，对指令改写表现出近乎完美的鲁棒性。最终，我们的工作证明，通过优雅的结构设计可以实现鲁棒的语义接地，从而绕过低效的暴力数据扩展范式。

## Abstract
Vision-Language-Action (VLA) models excel in robotic manipulation but suffer catastrophic performance drops when canonical instructions are simply paraphrased. Although this brittleness is typically addressed through costly data scaling, our probing reveals that the root cause is architectural rather than a lack of semantic understanding. Specifically, we demonstrate that current VLAs successfully retain the correct task identity internally. The failure actually stems from the joint encoding of dynamic visual observations and text, which introduces systematic feature shifts. Because the downstream action policy is highly vulnerable to these variations, it fails to translate the preserved semantics into correct control commands. To resolve this structural bottleneck, we propose Grounded Semantic Re-binding (GSR), an elegant intervention that bypasses unstable joint routing by explicitly fusing independently extracted task semantics with native visual features to train a completely re-initialized action expert from scratch. This targeted intervention dramatically restores paraphrastic invariance using only canonical demonstrations. On the LIBERO-Para benchmark, GSR improves success rates by up to 44.6 percent. It enables lightweight models to rival massively scaled baselines and pushes state-of-the-art models to a new record PRIDE score of 70.4, outperforming the recently introduced large-scale pretrained model Xiaomi-Robotics-0 in instruction generation capabilities. Building on these insights, we also introduce ParaVLA, a natively decoupled 0.33B-parameter model exhibiting near-perfect robustness to instruction rewording. Ultimately, our work proves that robust semantic grounding can be achieved through elegant structural design, bypassing the inefficient brute-force data scaling paradigm.

- **研究结论的含义**：传统方案通过大规模数据扩展（如收集海量改写指令）来提升鲁棒性，但这既昂贵又低效——既然模型已经“知道”任务是什么，问题出在“用不出来”，那么应该用结构设计修复语义传递路径，而非盲目堆数据。该工作证明了优雅的结构干预可以替代暴力数据缩放范式。

## 2. 方法论：Grounded Semantic Re-binding（GSR）

**核心思想**：绕过不稳定的原生联合语言路由，用外部稳定语义源（冻结的T5-large）独立提取任务语义，显式地注入到模型的视觉、状态与动作生成路径中，并完全重新初始化动作专家从头训练，从而修复“语义保留”与“动作利用”之间的断链。

**关键技术细节**：
- 冻结T5-large作为稳定语言编码器，输入为真实任务指令，输出token级特征；T5不接收任何图像或机器人状态，确保语义完全稳定。
- 根据架构不同，T5语义注入方式有差异：
  - **VLA-Adapter**：将投影后的T5特征作为sidecar K/V源，供给Bridge-Attention策略每个MLPResNetBlock_Pro使用；同时将原生Qwen的语言输入替换为固定中性句“perform the task”，使模型完全依赖T5语义；动作头从随机初始化训练，采用L1回归损失。
  - **SmolVLA**：将投影后的T5特征与SmolVLM原生语言槽位做8头grounding attention深度融合，然后继续通过SmolVLM原生多模态计算，再进入flow-matching专家；原生指令同样替换为中性句。
  - **π0.5**：保留原生PaliGemma真实指令（因为其已经可靠），将T5作为补充语义信号，在PaliGemma任务token位置进行grounding；动作专家重新初始化，以flow-matching目标训练。
- 训练数据仅用LIBERO-Goal规范演示，不使用任何改写指令或人工paraphrase。

**核心公式/指标**（用于诊断）：
- 归一化动作：$\bar{a} = \frac{a - \mu}{\max(\|a - \mu\|_2, 10^{-8})}$，距离 $D(a,b) = \|\bar{a} - \bar{b}\|_2$
- Retrieval@1 指标：判断paraphrase产生的动作是否最接近正确规范指令的动作
- 语义保留度：$R = \frac{\Delta_{wrong} - \Delta_{para}}{\Delta_{wrong} + \Delta_{para}}$（正值代表paraphrase更接近目标任务而非错误任务）

  - π0.5：73.60% → 75.59%

- **结构设计可替代暴力数据缩放**：轻量模型VLA-Adapter GSR可与大规模模型π0.5的原生性能接近，证明架构修复比数据堆叠更高效。

## 8. 局限性与潜在风险

- **成功判据的潜在宽化风险**：在LIBERO-Para的改写中，部分动作改写可能把成功判据界定得更宽松（例如“打开”与“稍微打开”），这理论上会轻微抬高改写指令下的成功率。作者虽在附录中尝试排除此类样本，但并未给出重新评估后的完整指标，因此改写集的难度一致性仍有讨论空间。
- **任务语义的上限依赖T5**：GSR的所有增益都建立在T5-large能正确理解指令的前提上。对于超出T5能力的复杂指令（如长链空间关系、常识推理），GSR的注入并不会带来比T5语义更强的表达；文中并未报告T5本身在LIBERO-Para上的语言理解准确率，因此无法量化这条上限。
- **真实机器人验证规模偏小**：6个任务×每条件5次试验的规模不足以支撑统计显著的结论；且实验场景为同一桌面上的区分性任务，未涉及动态场景、多步长程操作或干扰物。
- **对训练分布之外指令的泛化**：GSR虽恢复了“改写不变性”，但所有改写仍属于LIBERO原任务空间的浅层语言变换。对于分布外指令（如未见过的动词组合、金属性变化、否定推理），GSR是否仍然优于原生模型并未验证。
- **π0.5的规范指令性能下降未被完全解释**：GSR在π0.5上牺牲了规范的3.86%成功率，作者用双倍训练量恢复，但未给出流匹配目标下“为什么语义更稳却动作稍差”的机理分析；这可能是注入位置对原生PaliGemma路径的干扰，也可能是训练预算不足。
- **词性子空间消融的机制说明不够深入**：文中通过旋转指出方向性，但“为什么词性方向存在于T5特征中”“为什么移除后影响动作”仍只停留在行为层面，缺乏对特征几何的定量解释。

## 9. 对领域的影响与启示

- **对VLA评测方式的修正意义**：现有VLA基准（LIBERO、RLBench、CALVIN）几乎都采用固定指令模板，模型可能通过捷径依赖语言模板的浅层统计特征；LIBERO-Para和本文的诊断方法（Retrieval@1、语义保留度R、分层替换）提供了一套可复用的“改写鲁棒性评测协议”，有望推动VLA评估从“单一句式通过”转向“等效语义覆盖”。
- **对架构设计的范式启示**：本工作将“语言理解”与“语言-动作对齐”分离，证明了主流VLA的瓶颈不在语义编码而在语义路由。这支持一个更普遍的设计哲学：**多模态融合的稳定性优先于融合的早发性**——越早融合并不总是越好，关键是让动作策略以一种不变的方式获得任务语义。
- **对数据扩增策略的成本替代**：文中以轻量架构（VLA-Adapter GSR，约1B规模）逼近大规模模型（π0.5）原生性能，说明替换注入路径比采集数万条paraphrase数据更为经济和有效。这为资源受限的机器人实验室提供了新思路：先修复结构，再堆数据。
- **对开源社区的实际贡献**：除代码开源外，GSR的架构感知方法论（评估原生语言路径可靠性→决定是否中性化→选择注入节点）可作为不同VLA适配的通用操作手册，降低后续研究者移植到新模型的门槛。

## 10. 总结评价

这是一篇诊断、解释与修复并重的机器人学习论文。它的核心贡献不是一次性能提升，而是**一个问题定位的范式转变**：VLA在改写指令下的失败，并非“不懂”，而是“用不出来”。作者用严格的因果干预证实了这一点，并给出了一套结构优雅、无需额外数据的修复方法GSR。该方法在三个架构上的一致性与ParaVLA的解耦极限充分支撑了其结论。虽然在真实机器人规模、分布外泛化和机制解释上仍有未竟之处，但瑕不掩瑜，这篇工作在评测方法论与架构设计层面都具有值得延续的影响，建议VLA研究者、多模态融合设计者和机器人基准构建者精读。
