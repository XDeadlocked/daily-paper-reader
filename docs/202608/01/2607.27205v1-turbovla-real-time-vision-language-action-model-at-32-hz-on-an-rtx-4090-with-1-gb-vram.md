## 摘要
视觉-语言-动作（VLA）模型通常采用以LLM为中心的V→L→A路径，即先将视觉观测投影到大型语言模型的表示空间，再解码为机器人动作。尽管这种方法有效，但每次策略调用都会产生大量的计算和内存开销。在这项工作中，我们提出了TurboVLA，一种新的VLA范式，将传统的V→L→A路径重构为直接的V+L→A映射。TurboVLA不再使用大型语言模型作为感知与动作之间的中央接口，而是独立编码视觉观测和语言指令，通过轻量级双向视觉-语言交互直接在它们之间交换信息，并使用紧凑的解码器预测连续动作块。这种简单设计直接从视觉和语言特征构建任务条件表示，显著降低了VLA推理的计算和内存成本。在LIBERO上，TurboVLA仅用0.2B参数、31.2毫秒推理延迟和0.9 GB推理显存（在消费级RTX 4090上）就实现了97.7%的平均成功率，与规模大得多的VLA策略相当或更优。这些结果使TurboVLA成为主流以LLM为中心的VLA范式的一种简单有效的替代方案，为如何连接视觉、语言和动作以实现高效机器人操作提供了新视角。代码可在 https://github.com/H-EmbodVis/TurboVLA 获取。

## Abstract
Vision-language-action (VLA) models commonly adopt an LLM-centric $V \to L \to A$ pathway, where visual observations are projected into the representation space of a large language model before being decoded into robot actions. Although effective, this design incurs substantial computation and memory overhead at every policy invocation. In this work, we introduce TurboVLA, a new VLA paradigm that reformulates the conventional $V \to L \to A$ pathway as a direct $V + L \to A$ mapping. Instead of using a large language model as the central interface between perception and action, TurboVLA independently encodes visual observations and language instructions, directly exchanges information between them through lightweight bidirectional vision-language interaction, and predicts continuous action chunks with a compact decoder. This simple design constructs task-conditioned representations directly from visual and linguistic features, significantly reducing the computational and memory costs of VLA inference. On LIBERO, TurboVLA achieves 97.7% average success with only 0.2B parameters, 31.2 ms inference latency, and 0.9 GB inference VRAM on a consumer-grade RTX 4090, matching or outperforming substantially larger VLA policies. These results establish TurboVLA as a simple and effective alternative to the prevailing LLM-centric VLA paradigm, offering a new perspective on how vision, language, and action can be connected for efficient robotic manipulation. Code is available at https://github.com/H-EmbodVis/TurboVLA.

## 2. 方法论：核心思想、技术细节与算法流程

### 2.1 核心思想
- **直接映射而非间接推理**：传统路径为 `V → L → A`（视觉投影到 LLM 空间，经 LLM 整合后再解码动作）；TurboVLA 改为 `V + L → A`（视觉与语言分别编码，通过轻量交互直接构造**控制导向表征**，再并行解码连续动作块）。
- **关键认识**：执行级操作不需要 LLM 的开放生成能力，只需指令中的**语义线索（物体、属性、空间关系）** 来引导视觉特征。轻量文本编码器足以提供这些语义。

### 2.2 模型架构（见图 3）
模型由三部分组成：

1. **多模态特征编码**
   - **视觉编码器**：使用 DINOv3 ViT-B/L 提取空间视觉特征，投影到共享维度 *d* = 256，并添加**位置编码**与**相机视角编码**；多相机（K 路）特征拼接为一个序列。
   - **文本编码器**：使用 BERT（或 T5-small、SigLIP 作为消融对比），提取**token 级**指令特征（保留完整 token 序列而非池化向量，以保留细粒度语义）。
   - **状态编码器**：轻量投影网络，仅输入到动作解码器阶段，不参与视觉-语言交互。

2. **视觉-语言交互模块**
   - 采用 **N=6 层** 双向交叉注意力（受 Grounding DINO 启发），每层包含：层归一化、**视觉→指令交叉注意力**（注入场景上下文）与**指令→视觉交叉注意力**（条件化视觉特征）、FFN 与残差连接。
   - 两流特征（视觉特征 *V*、指令特征 *L*）逐层交替更新，最终**拼接**为融合表征：
     \[
     Z_{vl}^n = [V_N^n;\; L_N^n]
     \]
   - 公式化：
     \[
     \tilde{Z}_v = Z_v + \text{Attn}(Q_v, K_l, V_l)
     \]
     \[
     \tilde{Z}_l = Z_l + \text{Attn}(Q_l, K_v, V_v)
     \]

3. **连续动作块解码器（ACT-style）**
   - 使用 **H 个可学习动作查询**（action queries），经轻量 Transformer 解码器，结合融合表征与机器人状态，**单次前向** 并行预测 H 步连续动作块（无自回归 token 生成）：
     \[
     \hat{A}_n = D_\theta\left(Q_a,\; [Z_{vl}^n;\; Z_s^n]\right) \in \mathbb{R}^{H \times d_a}
     \]
   - 训练目标：**行为克隆 + ℓ1 损失**，无任何辅助语言建模损失。

### 2.3 算法流程（文字描述）
1. 输入当前多相机观测、语言指令、机器人本体状态；
2. 分别用 DINOv3 提取视觉特征、BERT 提取指令特征，经线性投影统一到 *d* 维；
3. 视觉特征与指令特征经 N=6 层双向交叉注意力模块交替更新，拼接为动作就绪特征；
4. 将融合特征与状态特征送入 ACT 风格解码器，利用 H 个查询并行解码出连续动作块；
5. 推理时单次前向输出整段动作块，无需逐步生成，实现 **32 Hz** 在线控制频率。

## 6. 主要结论与发现

1. **执行级控制不需要 LLM 中心接口**：TurboVLA 用 0.2B 参数达到 97.7% LIBERO 平均成功率，匹配 π0.5（3.4B）的 96.9%，且延迟从 93.6 ms 降至 31.2 ms，证明直接 `V + L → A` 路径可行且高效。
2. **性能-效率前沿大幅改善**：在单臂（LIBERO）和双臂（RoboTwin 2.0）两个基准上均实现更优或相当的操控性能，同时显著减少参数、延迟和显存（<1 GB）。
3. **延迟与显存是实际部署的关键约束**：多数大模型 VLA 需数 GB 显存且延迟 >100 ms，TurboVLA 在消费级 GPU 上即可达到 32 Hz 在线控制频率，验证了边缘部署可行性。
4. **每个组件均有贡献**：语义语言条件（+26.9% 平均成功率 vs 无语言）、BERT token 级特征、双向交互（+2.5% vs 无交互）、N=6 层交互、H=12 动作块分别是最优配置。
5. **真实世界有效**：在 AgileX Piper 上的 4 个任务成功率为 92.5%、80%、90%、87.5%，均优于 π0.5。

## 7. 优点
