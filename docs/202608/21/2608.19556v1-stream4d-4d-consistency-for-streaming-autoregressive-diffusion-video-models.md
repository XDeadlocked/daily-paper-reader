## 摘要
流式自回归扩散模型能够实现实时、长时程的视频生成，但其训练目标优化的是局部帧预测，而非一致世界的几何与动态：长序列生成会累积几何漂移，并退化为静态或不自然的运动。近期的双向方法利用基于3D高斯泼溅重建的奖励信号来解决这一问题。然而，单一的刚性3D重建无法建模动态场景，因此该评判器会将真实物体运动视为重建误差，并通过冻结视频来最大化奖励。这种捷径在自回归（AR）设置中尤为有害，因为每个片段都可能传播已经静态的配置。在本工作中，我们提出了Stream4D，用前馈4D重建奖励替代静态评判器，显式建模场景动态，使连贯运动能够获得高一致性奖励。为进一步引导运动的幅度与质量，我们加入了一个运动先验，该先验奖励自然的场景流幅度，同时惩罚抖动和非刚性伪影。我们的最终方案将这两项与一个轻量级感知锚点相结合。在多种自回归视频骨干网络和不同生成时程下，Stream4D提升了4D重建质量，更有效地保持运动，并获得了更高的人类对齐偏好。项目页面：https://banyuanhao.github.io/Stream4D/

## Abstract
Streaming autoregressive diffusion models enable real-time, long-horizon video generation, but their training objectives optimize local frame prediction rather than the geometry and dynamics of a coherent world: long rollouts accumulate geometric drift and degrade into static or unnatural motion. Recent bidirectional approaches address this problem using rewards signals built upon 3D Gaussian-Splatting reconstruction. However, a single rigid 3d reconstruction cannot model a dynamic scene, so this critic penalizes genuine object motion as reconstruction error and is maximized by freezing the video. This shortcut is especially detrimental in the AR setting, where each chunk can propagate an already-static configuration. In this work, we propose Stream4D, which replaces the static critic with a feed-forward 4D reconstruction reward that explicitly models scene dynamics, allowing coherent motion to receive high consistency rewards. To further guide motion magnitude and quality, we add a motion prior that rewards natural scene-flow magnitude while penalizing jitter and non-rigid artifacts. Our final recipe combines these two terms with a lightweight perceptual anchor. Across various autoregressive video backbones and various generation horizons, Stream4D improves 4D reconstruction quality, preserves motion more effectively, and achieves higher human-aligned preference. ## 1. 论文的核心问题与整体含义（研究动机和背景）

流式自回归（AR）扩散视频模型能够以分块（chunk-by-chunk）方式生成视频，结合少步蒸馏骨干网络后，可在实时流式生成场景中应用（如具身智能体、模拟器和交互式应用）。然而，现有训练目标只优化局部帧预测，缺乏对长期场景几何与动态一致性的显式约束，导致长序列生成中累积几何漂移、物体身份丢失和运动退化等问题。

近期方法（如 World-R1、VideoGPA）尝试使用基于静态 3D 高斯泼溅（3D-GS）重建的奖励信号来提升几何一致性，但存在根本性缺陷：**单一刚性 3D 重建无法表达动态场景**，任何物体真实运动都会被误判为重建误差并受到惩罚，因此奖励最大化反而倾向于冻结场景。这一缺陷在自回归环境中尤为严重——因为模型只能参考已生成帧，缺少足够的时间上下文，一旦早期帧运动被抑制，后续分块就会持续传播已静态的配置，形成恶性循环。

Stream4D 的核心洞察是：用前馈 4D 高斯泼溅模型（MoVieS）替代静态 3D 重建，显式建模场景的空间-时间动态，使连贯运动获得高一致性奖励，而非被惩罚。

## 2. 论文提出的方法论：核心思想、关键技术细节与算法流程

论文提出 Stream4D，一个基于强化学习（RL）的训练框架，目标是将 4D 一致性先验与自然运动先验蒸馏进流式自回归视频模型中。总体方法包含以下关键组件：

**（1）4D 重建一致性奖励 \(R_{\text{recon}}\)**

- 对采样得到的候选视频片段 \(W^{(i)}\)，先用 StreamVGGT 估计每帧相机参数，再用前馈 4D-GS 模型 MoVieS 进行动态场景重建。
- 从估计相机位姿重新渲染重建后的视频帧 \(\tilde{W}_t\)，将其与原生成帧 \(W_t\) 逐帧计算 LPIPS 感知距离，作为 4D 一致性分数：
  \[
  R_{\text{recon}} = \text{clip}\!\left(1 - \frac{1}{T}\sum_{t} \text{LPIPS}(\tilde{W}_t, W_t),\, 0,\, 1\right)
  \]
- 该奖励高的视频意味着其可以被一个连贯的动态 4D 场景完整解释，而几何不一致、物体身份漂移、无法组织成稳定动态场景的运动都会导致低分。

**（2）门控运动联合奖励 \(R_{\text{mot}}\)**

- 4D 重建器本身不惩罚运动，但低运动片段在重建上仍略微占优（存在 Spearman ρ = −0.27 的弱相关性），因此需要显式运动引导。
- \(R_{\text{mot}}\) 由三个因子相乘组成：运动高斯门控 \(g(m)\)、时域平滑因子 smooth、空间刚性因子 rigid：
  \[
  R_{\text{mot}} = g(m) \cdot \text{smooth} \cdot \text{rigid}
  \]
- 运动门控 \(g(m) = \exp\!\left(-\frac{(m - m_{\text{nat}})^2}{2\sigma^2}\right)\) 以自然运动幅度 \(m_{\text{nat}}\) 为峰值，同时惩罚静态坍缩和过度模糊运动。
- smooth 惩罚相邻帧间场景流加速度过大；rigid 惩罚空间相邻像素的运动速度差异过大（对应撕裂、抖动、融化等非刚性伪影）。
- 所有运动量均从 MoVieS 输出的每像素 3D 场景流 P 和置信图 conf 计算得到，且用置信度加权的动态掩码（速度最快的 top-20% 像素）提取统计量。

**（3）轻量级感知锚点 \(R_{\text{hpsv2}}\)**

- 使用 HPSv2 直接对生成帧质量打分，约束单帧外观与人类审美偏好对齐，防止 4D 重建与运动约束之外出现视觉质量退化。

**（4）奖励组合与优化**

- 三个轴各自做组内 z-score 标准化后加权求和：
  \[
  R(W^{(i)}) = w_{\text{recon}}\tilde{z}[R_{\text{recon}}] + w_{\text{mot}}\tilde{z}[R_{\text{mot}}] + w_{\text{hpsv2}}\tilde{z}[R_{\text{hpsv2}}]
  \]
- 在组内计算中心化优势 A，并通过 clip 仿射归一化映射到 [0,1] 区间作为 DiffusionNFT 的奖励信号。
- 优化使用前向过程 DiffusionNFT 损失：对参考模型和当前模型的 velocity 预测做正负向插值，再按归一化奖励加权优化。

**训练流程**：采用 LoRA 适配器（冻结基础模型），每步从提示库采样一批提示，为每个提示解码 G=24 个候选回滚，滚动窗口 L=21、帧沉 S=3；对每个回滚执行一次 StreamVGGT + MoVieS 前向以同时提取重建和运动信息；使用选择性 KL 惩罚和带条件重置的参考策略来稳定训练。

## 6. 论文的主要结论与发现

1. **4D 一致性大幅提升**：Stream4D 将三个骨干上的 4D-PSNR 从 16.88 / 15.44 / 17.44 提升至 20.34 / 20.97 / 24.20，分别各 +3.46 / +5.53 / +6.76 dB；SSIM 和 LPIPS 在全部三个骨干上均有改善。
2. **4DGT 交叉验证有效**：在架构与数据完全不同的 4DGT 重建器下，Stream4D 仍取得每骨干最优 PSNR 和 SSIM，领先 World-R1 达 +0.7 / +1.1 / +2.5 dB，说明增益不是 MoVieS 特有偏置导致的。
3. **运动保持显著优于静态-3D 奖励方法**：视觉-LLM 评判的 Motion 分数在 SF / CF / LL 上达到 0.83 / 0.77 / 0.71，为所有方法中最高；一致性胜率分别达 82.2% / 73.9% / 74.2%，全面超过 World-R1 的 75.9% / 69.1% / 54.0%。
4. **VideoReward 偏好胜出**：Overall 胜率在三个骨干上分别为 66.2% / 76.0% / 84.4%，均超过 World-R1 的 61.8% / 74.8% / 78.2%，且在运动质量头上优势最大。
5. **人类偏好确认**：LongLive 上对照 World-R1 和 VideoGPA，Stream4D 的 Overall 胜率分别为 76% 和 80%，显著受人类偏好。
6. **三个奖励轴各司其职**：去掉运动项会导致运动坍缩和一致性分数崩盘；去掉重建项虽能产生最多运动但一致性崩溃；去掉感知锚点会造成视觉质量下降。
7. **随机子集上只有 Stream4D 能在三重骨干上同时击败基础模型**：在低运动主导的随机子集上，冻结派方法虽能用低运动换取重建分数与 VideoReward 优势，但在运动感知评判下输给基础模型；Stream4D 是唯一保持运动并提升一致性的方法。

## 7. 优点

1. **问题识别精准**：明确指出静态 3D 重建奖励在 AR 设置下导致“冻结场景”捷径的根本机制，并给出实验证据（运动幅度与 4D-PSNR 的 Spearman 相关分析）。
2. **方法转移性强**：同一配方（仅调整三个奖励轴权重）可迁移至三种不同架构（Self-Forcing、Causal-Forcing、LongLive），并同时改善短时（5 秒）与长时（10.3 秒）生成。
3. **奖励设计精巧**：运动门控的高斯峰值形状同时惩罚不足与过度运动；smooth 和 rigid 因子在乘法组合下防止策略通过抖动或非刚性伪影“走捷径”；动态掩码加入置信度加权增强了鲁棒性。
4. **评估严谨**：使用与训练奖励不同的 4DGT 重建器做交叉验证；LLM 评判器采用双序位去偏机制且不可见奖励；一致性评判要求“保留运动”为前提，使冻结视频无法通过一致性测试得分；人类评估含质量受控测试。
5. **计算资源效率考量**：单次 MoVieS 前向在重建与运动轴之间共享，运动质量项边际成本极低；LoRA 微调开销适中（约 635–770 GPU-hours），在可行范围内。
6. **对失败模式的深层分析**：消融实验中给出了“高重建/低运动”（冻结）和“高运动/低重建”（不连贯）两类失败模式，并在重构-运动平面上将部署配方定位于前沿。

## 8. 不足与局限

1. **评估指标范围的局限**：LLM 评判器仅使用单模型（Gemini-3.5-Flash），虽经过去偏处理但依赖单一评判器的可靠性；没有报告其他 LLM 评估器的交叉验证。
2. **几何精度不保证**：论文明确指出 4D-PSNR 的增益“不必然certify metric-accurate geometry”——高重建分数不等于绝对准确的几何结构（见附录 D 的精确说明）。
3. **4DGT 交叉验证仍共享组件**：4DGT 虽在架构、权重和数据上与 MoVieS 完全独立，但两者仍共用 StreamVGGT 相机估计器，无法完全排除相机估计偏差对结果的影响。
4. **对比方法由作者自行复现**：World-R1 和 VideoGPA 面向双向 T2V 场景，无公开的 AR 设置检查点，对比方法均为作者基于同一训练器自行复现，存在复现偏差的可能（论文已声明会随代码发布复现配置）。
5. **人类评估范围有限**：人类评估仅在 LongLive 一个骨干上完成（50 提示，150 判断）；虽然这有设计理由（长时程中漂移最严重），但对 Self-Forcing 和 Causal-Forcing 的人类偏好未获直接验证。
6. **训练提示为随机采样**：训练提示从 VidProM 随机采样，未进行面向运动突显性（motion prominence）的专门筛选，可能影响策略与训练子集的对齐度，尽管作者在附录 G 中讨论了泛化性。
7. **运动门控目标依赖基础模型校准**：峰值 m_nat 设置为 0.020，从基础模型回滚的中位值标定而来，依赖基础模型当前的输出分布；作者在表 5 中给出了敏感性分析，但不同骨干可能需要的“自然运动强度”存在差异。
8. **4D 重建器的时间跨度限制**：MoVieS 为前馈 4D-GS 模型，其时间感受野可能无法覆盖 LongLive 的 10.3 秒原生全部窗口（论文结论中提及下一步工作是“流式 4D 重建器以匹配 LongLive 原生时程”）。
