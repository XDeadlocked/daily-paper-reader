## 摘要
长时程人形视觉-语言-动作（VLA）控制中，头戴式立体相机要求视觉界面既能利用互补视图，又能保持与预训练表示的兼容性。现有界面常常丢弃互补的立体证据，或在未保留原生主视图通路及根据机器人具身形态调整辅助信息的情况下融合额外观测。我们提出EATR-Stereo——一种具身感知的令牌路由框架，它保留主视图令牌，并通过查询同步的辅助视图令牌序列构建主视图对齐的跨视图辅助令牌（CVAT）。一个基于身体分割的本体感觉编码器进一步根据机器人配置历史对令牌级辅助使用进行条件化，使得在动作生成过程中能够选择性地纳入立体证据。路由后的辅助流增强了预训练VLA的语言和主视觉上下文，同时保持其视觉-语言模型冻结。在一台具有37维本体感觉状态的33自由度物理人形机器人上，我们在超过100次搜索-接近-抓取-放置-返回任务中评估了九种配置。EATR-Stereo实现了60.0%的全任务成功率、100.0%的抓取成功率和80.0%的阶段成功率。在严重不对称遮挡下，它将恢复率提高到80%，而单独使用CVAT时仅为30%。消融研究进一步表明，保留主令牌并将跨视图辅助特征与结构化本体感觉路由相结合的重要性。这些结果表明，选择性路由的成对立体证据改善了空间接地，从而实现可靠的长时程人形VLA控制。

## Abstract
Long-horizon humanoid vision--language--action (VLA) control with head-mounted stereo cameras requires visual interfaces that can exploit complementary views while maintaining compatibility with pretrained representations. Existing interfaces often discard complementary stereo evidence or fuse additional observations without preserving the native primary-view pathway and adapting auxiliary information to robot embodiment. We present EATR-Stereo, an embodiment-aware token-routing framework that retains primary-view tokens and constructs primary-aligned Cross-View Auxiliary Tokens (CVATs) by querying the synchronized auxiliary-view token sequence. A body-segmented proprioceptive encoder further conditions token-wise auxiliary usage on robot configuration history, enabling selective incorporation of stereo evidence during action generation. The routed auxiliary stream augments the language and primary-visual context of a pretrained VLA while keeping its vision--language model frozen. On a 33-DoF physical humanoid with a 37-D proprioceptive state, we evaluate nine configurations in over-100-s search--approach--grasp--place--return tasks. EATR-Stereo achieves 60.0% full-task success, 100.0% grasp success, and 80.0% stage success. Under severe asymmetric occlusion, it improves recovery to 80% compared with 30% for CVAT alone. Ablation studies further show the importance of preserving primary tokens and combining cross-view auxiliary features with structured proprioceptive routing. These results demonstrate that selectively routed paired stereo evidence improves spatial grounding for reliable long-horizon humanoid VLA control.

### 一、核心问题与整体含义（研究动机与背景）

- **研究背景**：视觉-语言-动作（VLA）模型已从桌面机械臂操作扩展到人形机器人全身控制。但人形机器人在真实双足部署中面临独特挑战：步态和躯干扰动传递至头戴相机、头部和腰部运动持续改变视角、手臂和手的运动导致配置相关的自遮挡。在长时程任务中，某一阶段的视觉信息缺失会沿着任务链条传播放大，造成不可逆的失败。
- **核心问题**：现有 VLA 视觉接口未能有效利用头戴式同步立体相机的**成对互补证据**。具体表现为：
  - 单目输入既无双目视差，也无法提供被遮挡区域的替代视角；
  - 独立 token 拼接（如 GR00T 双图输入）保留了两张图像，但未强制跨视图一致的空间推理；
  - StereoPolicy 虽显式关联左右视图，但其 VLA 变体用融合后的立体表示替换了原始图像 token，**破坏了预训练的单目 token 结构**；
  - SpatialVLA 依赖单目深度估计，但头戴双足感知场景中单目深度可能时间不一致，且步态会扰动相机。
- **论文含义**：论文主张同步立体视觉的有效信号在于**成对关系**（correspondence + 互补可见性），而非“图像数量的增加”。因此，需要一种能够保留主视图原生语义、同时按机器人具身状态选择性利用辅助视图证据的接口。

### 二、方法论：核心思想与关键技术细节

**1. 总体架构**
- 输入为同步立体图像对 (I_L, I_R)、语言指令 ℓ 和最近 K 帧本体感觉历史 S_t。
- 策略预测 H 步连续动作块：\hat{Y}_t = π_θ(I_L, I_R, ℓ, S_t)。
- 核心设计原则：**冻结预训练 VLM，以轻量级接口增强其视觉上下文**。

**2. 跨视图辅助令牌（CVAT）构建**
- 固定主视图/辅助视图分配（左为主、右为辅），训练和部署保持一致。
- 冻结的 Cosmos VLM 分别编码主视图 M_t 和辅助视图 A_t，二者共享同一隐藏空间。
- **主查询跨视图注意力**：主视图 token 作为 Query，辅助视图 token 作为 Key 和 Value（遵循 StereoPolicy 的多头跨视图注意力设计），经 softmax 注意力加权聚合后，通过 MLP 残差块得到主对齐的 CVAT 流 C_t。
- 主视图 token M_t 沿原生视觉通路**原封不动地保留**，CVAT 是独立于主 token 流的辅助流。

**3. 身体分割的本体感觉路由（Body-Segmented Proprioceptive Routing）**
- 将 37 维本体感觉状态划分为 G = 5 个语义组：腿（legs）、手臂（arms）、头（head）、腰（waist）、机器人位姿（pose）。
- 每个分组的 K 帧历史经 Flatten → LayerNorm → 分组专用 MLP → 段类型嵌入，得到段表示 z_{t,g}。
- 段表示通过注意力加权池化和均值池化拼接，得到共享的本体感觉条件 h_s_t。
- **令牌级路由**：对每个 CVAT token，路由器联合使用主 token、CVAT token、二者的绝对差与逐元素乘积、以及本体感觉条件，通过轻量 MLP 预测一个 (0,1) 标量门控 r_{t,i}，对 CVAT token 缩放：\tilde{C}_{t,i} = r_{t,i} · C_{t,i}。
- **关键点**：路由器只缩放辅助流，主 token 仅参与路由描述符计算，不被修改。

**4. VLA 集成与训练**
- 路由后的辅助 token 与语言 token、主视图 token 拼接：E_VLA = [L_t; M_t; \tilde{C}_t]。
- 该上下文输入 GR00T1.7 流匹配动作专家，采用 flow-matching 目标函数 L_FM 训练。
- 冻结 Cosmos VLM，联合优化 CVAT 模块、段编码器、token 路由器和 GR00T 动作专家。
- 部署时采用异步动作块预测 + 局部三次 B-Spline 拼接（保证动作连续性）+ 外部 VLM 慢速任务编排（子任务完成检测与指令切换）。

### 三、实验设计

**1. 物理人形实验（主实验）**
- **平台**：33 自由度 HONOR Omega 1.0 人形机器人，BeyondMimic 全身控制；37 维本体感觉状态（33 关节 + 4 维基座四元数）；头戴同步立体相机（240×320）。
- **任务**：搜索→接近→抓取→语言条件放置（指定颜色篮子）→返回原位，单任务时长超 100 秒。
- **数据**：1000 段分段任务演示；训练 60,000 步，全局 batch size 512。
- **测试协议**：180 次物理试验，9 种配置各 20 次，均匀分为演示覆盖位置（ID）和未见位置（OOD）。
- **安全协议**：允许每次试验最多两次干预。
- **对比方法**：GR00T1.7-Mono、GR00T-Wide（宽高比图像）、GR00T 默认双图拼接、StereoPolicy（适配同骨干）、Main-XAttn（主流交叉注意力）、CVAT（无状态路由）、CVAT-Flat（扁平状态编码）、Stereo-Route（以 StereoPolicy 融合替换 CVAT）、EATR-Stereo。

**2. 仿真实验（辅助验证）**
- **基准**：RoboCasa365，18 个任务，Franka 臂。
- **规模**：3600 次 rollout（每任务 20 次 × 每配置 18 任务）。
- **采集设置**：排除腕部相机，仅保留同步左右 agent 视图，以隔离配对视图建模效果。
- **额外基线**：QwenPI0.5（π_0.5 框架 + Qwen-2B）。

**3. 专项分析**
- **严重不对称遮挡**：主视图完全遮挡瓶子、辅助视图部分可见；10 次试验，90 秒超时；对比 CVAT、CVAT-Flat、EATR-Stereo。
- **训练成本对比**：对比 GR00T 和基于 Depth Anything V3 的估计深度 VLA（微调 4 层 VLM）。
- **动作块连续性**：定性展示 B-Spline 拼接效果。

- **训练步数与批量**：60,000 步，全局 batch size 512。

- **实验规模**：9 种配置 × 20 次物理试验 = 180 次真机试验；3600 次仿真 rollout；严重遮挡专项 30 次试验（3 种方法 × 10 次）；训练成本对比 3 种方法。
- **消融设计**：覆盖了主视图保留（Main-XAttn vs CVAT）、辅助流存在性（CVAT vs Stereo-Route）、路由状态编码方式（CVAT-Flat vs EATR-Stereo）三个关键设计维度，验证了各组件的独立贡献。

### 六、主要结论与发现

1. **主实验性能**：EATR-Stereo 实现 60.0% 全任务成功率、100.0% 抓取成功率、80.0% 阶段成功率，全面超过所有基线。相比 StereoPolicy 全任务提升 15.0 pp，相比 GR00T 提升 25.0 pp。
2. **泛化能力**：EATR-Stereo 是唯一在 ID 和 OOD 位置均实现 100% 抓取成功的方法，ID-OOD 差距为零；OOD 阶段成功率较 StereoPolicy 高 20.0 pp，表明配对视图集成提供了更强的空间接地。
3. **遮挡鲁棒性**：严重不对称遮挡下，EATR-Stereo 恢复率达到 80%（8/10），显著高于 CVAT-Flat 的 60% 和 CVAT 的 30%；平均恢复时间 22.4 秒，比 CVAT-Flat 降低 46.3%。
4. **消融结论**：主视图 token 保留（+30.0 pp）、跨视图辅助建模、身体分割的本体感觉路由三个组件相互补充，各自贡献增益。
5. **效率优势**：EATR-Stereo 在冻结 VLM 的情况下达到与微调 4 层 VLM 的深度估计方法相同的阶段成功率（80.0%），但训练时间仅为后者的约 1/4（10.95h vs 41.80h）。
6. **语义保持**：立体集成在提升空间泛化的同时不损害语言条件行为（左/右 100%、颜色 80% 的语义合规）。

### 七、优点

- **方法设计亮点**：
  - 保留主视图原生 token 路径，避免破坏预训练表示，体现“最小侵入式接口”设计哲学；
  - 将本体感觉状态按身体语义分组并用于视觉证据路由，将“视觉特征与机器人自身构型的关系”纳入决策，是具身感知（embodiment-aware）理念的直接落地；
  - 路由器联合主/辅 token 关系（差、积）与本体感觉状态，信息丰富且计算轻量；
  - CVAT 构建与 VLM 冻结解耦，训练成本极低，易于适配现有 VLA 系统。
- **实验设计亮点**：
  - 真实人形平台长时程任务（>100 s）验证，贴近实际部署场景；
  - 系统性地覆盖了 ID/OOD 泛化、语义合规、遮挡恢复、训练成本等维度；
  - 仿真+真机双重验证，且仿真中排除腕部相机以隔离配对视图效应，实验设计克制且目标明确；
  - 消融配置设计精巧，能清晰分离“表示保留”“辅助建模”“路由方式”三者的贡献。

### 八、不足与局限

- **平台与任务覆盖有限**：仅在 HONOR Omega 1.0 单一平台上评估，任务类型仅有“搜索-接近-抓取-放置-返回”一类，缺乏多任务、多形态人形的验证。作者也在结论中承认这一点。
- **绝对成功率偏低**：全任务成功率 60% 仍有较大提升空间；尽管相对基线优势明显，但剩余 40% 失败模式未做详细分类分析（如哪一阶段失败最多、失败原因是什么）。
- **安全辅助协议的干扰**：允许最多两次人工干预，虽然提高了实验安全性，但也可能影响结果的纯净性——读者无法区分“无干预完成”和“经干预后完成”的试验。
- **语言能力测试较为简单**：语义合规仅涉及左/右和颜色两种指令类型，未测试更复杂、更具挑战性的语言理解（如空间关系、多对象属性组合等）。
- **仿真任务绝对成功率低**：RoboCasa365 上最高仅 43.33%，作者归因于排除腕部相机后的观测受限，但这也意味着仿真验证的判别力可能有限。
- **遮挡实验样本量较小**：严重遮挡专项仅 10 次试验/方法，统计显著性有限。
- **路由机制的可解释性不足**：论文未提供路由权重的可视化或分布分析，无法直观理解路由器在什么情况下选择使用或抑制辅助证据。
- **对照方法适配有限**：对 StereoPolicy 等基线的适配方式可能未达到其原生最优性能，对比公平性存在一定争议空间。
