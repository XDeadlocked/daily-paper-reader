## 摘要
尽管在大规模机器人数据集上预训练的视觉-语言-动作（VLA）模型为机器人操作提供了坚实基础，但在针对有限任务特定演示的新任务进行适应时，其性能可能会下降。检索提供了一种重用现有演示以实现数据高效适应的实用方法，但现有方法通常依赖于视觉相似性、状态-动作表示或任务级语言匹配。这些方法可能忽视长视野操作任务的分层结构，其中完整的任务匹配很少见，而可重用的技能往往很丰富。为解决这一挑战，我们提出了分层技能检索（HSR），一种用于数据高效VLA适应的检索框架。具体来说，HSR首先将目标任务分解为候选技能序列。它基于语义合理性和从先前数据集估计的技能可靠性来评估每个计划。选定的分解随后用于混合检索。这结合了子任务级语言检索与行为特征重排序，以识别既语义相关又与目标任务兼容的演示。最后，我们通过两阶段预训练和微调流程来调整策略，该流程将通用技能获取与任务特定适应分开。在LIBERO基准和几项真实世界机器人操作任务上的实验表明，HSR在平均成功率上分别比最强基线提高了10.3%和21.3%。这些结果证明了结构化技能级检索对数据高效VLA适应的有效性。视频和代码可在 https://hoar012.github.io/HSR-Project 获取。

## Abstract
While Vision-Language-Action (VLA) models pretrained on large-scale robot datasets provide a strong foundation for robot manipulation, their performance can degrade when adapted to new tasks with limited task-specific demonstrations. Retrieval offers a practical way to reuse existing demonstrations for data-efficient adaptation, but existing methods often rely on visual similarity, state-action representations, or task-level language matching. These approaches may overlook the hierarchical structure of long-horizon manipulation tasks, where complete task matches are rare but reusable skills are often abundant. To address this challenge, we propose Hierarchical Skill Retrieval (HSR), a retrieval framework for data-efficient VLA adaptation. Specifically, HSR first decomposes a target task into candidate skill sequences. It evaluates each plan based on both semantic plausibility and skill reliability estimated from the prior dataset. The selected decomposition is then used for hybrid retrieval. This combines subtask-level language retrieval with behavior-feature reranking to identify demonstrations that are both semantically relevant and compatible with the target task. Finally, we adapt the policy through a two-stage pretraining and finetuning pipeline, which separates general skill acquisition from task-specific adaptation. Experiments on the LIBERO benchmark and several real-world robot manipulation tasks show that HSR improves the average success rate by 10.3% and 21.3% over the strongest baseline, respectively. These results demonstrate the effectiveness of structured skill-level retrieval for data-efficient VLA adaptation. Videos and code are available at https://hoar012.github.io/HSR-Project.

## 2. 方法论

### 2.1 核心思想

提出 **分层技能检索框架（Hierarchical Skill Retrieval, HSR）**，将目标长程任务分解为可复用的技能序列，并在技能层级上从先验数据集中检索相关演示，以支持数据高效的 VLA 策略适应。

### 2.2 技术细节与流程

**（1）分层任务分解与方案评估**

- 使用 K-means 对先验数据集中的所有任务指令文本嵌入进行聚类，得到 **K 个语义连贯的技能簇**（如 Find、Pick up、Pour 等），构成可用技能集合 S。
- 使用 LLM（Qwen3-VL-4B）在给定目标任务和可用技能集合的条件下，生成多组候选分解计划 p = (u₁, u₂, …, uₙ)。
- 为使 LLM 的计划锚定在策略的实际能力上，引入 **技能置信度分数 C(sᵢ)**：
  - 将先验数据集划分为训练/验证集，用训练集微调 VLA 模型得到 π′θ；
  - 计算验证轨迹上的行为克隆（BC）损失 L_traj(τ) 和轨迹长度 H(sᵢ)；
  - 经 min-max 归一化后定义：**C(sᵢ) = exp(−α·L̃_val(sᵢ) − β·H̃(sᵢ))**，其中 α=0.6，β=0.8，用以代理技能的可学习性与可靠性。
- 对每个候选计划计算综合评分：**Score(p) = S_sem(p) · Πⱼ C(s(uⱼ))**，其中 S_sem(p) 为 LLM 给出的语义合理性分数。选择得分最高的分解作为最终方案。

**（2）混合技能检索**

- **语言级检索**：对每个子任务，用文本嵌入相似度从先验数据集中检索语义相关的前 M% 个轨迹片段。
- **行为特征重排序**：训练 VAE 编码器提取帧级行为特征，对候选帧与目标任务演示的潜在特征计算负距离相似度 s(f) = maxⱼ(−‖z_f − z_tⱼ‖²)，仅保留相似度最高的前 F% 帧，以过滤语义相关但行为不兼容的样本。

**（3）两阶段策略适应**

- **第一阶段（技能预训练）**：在语言检索得到的全部演示数据 D_lang 上预训练策略，以获取通用可迁移技能。
- **第二阶段（任务微调）**：在目标任务演示 D_t 与特征重排序后的检索数据 D_rerank 上联合微调，进行任务特定适应。
- 与单阶段联合训练方式相比，该策略将通用技能获取与任务特定适应解耦，避免大量嘈杂检索数据对目标任务的偏置。

## 3. 实验设计

### 3.1 仿真环境（LIBERO Benchmark）

- **数据集**：LIBERO-10 长程任务子集作为目标任务（10 个复合操作任务）；LIBERO-90 作为先验数据集 D_prior（90 个任务，每任务 50 条演示）。
- **目标数据规模**：每个目标任务仅 5 条演示（few-shot 场景）。
- **检索设置**：第一阶段检索先验数据集中前 10% 的轨迹；重排序后保留前 30%，约相当于先验数据集 3% 的帧。
- **评估**：每任务 50 次评估，3 个随机种子，报告平均成功率与标准差。

### 3.2 真实机器人环境

- **平台**：7 自由度 xArm 机械臂。
- **任务**：4 个真实操作任务——
  - Drawer（子任务数 1：关抽屉）
  - Trashcan（子任务数 2：捡起纸团投入垃圾桶）
  - Cup-Drawer（子任务数 3：将杯子放入抽屉并关上）
  - Cup-Tea（子任务数 4：将茶包放在杯子旁并倒水）
- **目标数据规模**：每任务 20 条演示。
- **先验数据集**：从 DROID 数据集中随机采样 10k 条轨迹。
- **评估**：每任务 20 次试验，不同初始状态，各模型共享相同初始状态集合以确保公平。

### 3.3 对比方法

| 类别 | 方法 |
|---|---|
| 目标仅微调 | BC（Behavior Cloning） |
| 朴素数据混合 | Random（随机采样 10% 先验数据）、All Data（全部先验数据） |
| 语言检索 | Language |
| 视觉/运动检索 | FR（Flow Retrieval，光流相似性）、STRAP（子轨迹动态时间规整） |
| 状态-动作表征检索 | BR（Behavior Retrieval，VAE 潜空间相似性）、IWR（重要性加权检索） |

## 6. 主要结论与发现

- **仿真 Benchmark 结果**：HSR 在 LIBERO 上平均成功率 43.5%，相比最强基线 BR（33.2%）提升 10.3 个百分点；相比 STRAP（31.9%）和 IWR（32.5%）亦有显著提升。
- **复杂任务增益更明显**：
  - Mug-M 任务上超过最强对比方法 STRAP 27.3 个百分点；
  - Bowl-C 任务上是唯一超越纯 BC 的方法（67.3% vs 22.7%）；这源于该任务需要“拿碗+关抽屉”两类技能的混合。
- **真实世界结果**：HSR 在 4 个真实任务上的总体成功率为 48/80，较最强基线 IWR（31/80）提升 21.3%；Cup-Tea 任务（4 子任务的长程操作）从 BC 的 3/20 提升至 9/20。
- **消融分析关键发现**：
  - **任务分解**不可缺失——直接用完整任务指令检索在复杂指令任务（如 Mug-P、Moka-M）上性能显著下降；
  - **特征重排序**进一步过滤语言检索中的低行为兼容性样本，提升任务上下文对齐；
  - **两阶段训练优于单阶段联合训练**——联合训练易被规模更大、噪声更高的检索数据主导，导致次优；
  - **技能置信度引导的规划**优于纯 LLM 分解，且与人工规划质量相当（43.5% vs 44.9%）。
- **检索数据质量可视化**：与传统检索方法相比，HSR 检索到的演示在子任务级别上更贴合任务的每一步需求（如既检索到“放杯子”的演示，也检索到“关微波炉”的演示）。

## 7. 优点

- **问题切入角度新颖**：将检索从任务级下沉至技能级，契合长程操作任务天然的分层结构，弥补了现有视觉/运动相似性检索忽视语义层级关系的空白。
- **方法设计完整闭环**：从任务分解 → 方案评估 → 混合检索 → 两阶段训练，形成了一套端到端的数据高效适应框架；利用 LLM 规划的同时，通过数据集估计技能置信度来“锚定”LLM 计划，避免其脱离实际策略能力（呼应 SayCan 的接地问题）。
- **轻量且实用的技能评估策略**：使用验证集 BC 损失作为技能可靠性的 rollout-free 代理指标，避免了昂贵的环境 rollout，显著提升方法实用性。
- **混合检索思路合理**：语言相似性保证语义对齐，行为特征重排序保证低层执行兼容性，有效过滤跨环境不匹配样本。
- **两阶段训练设计有洞见**：显式区分“通用技能获取”与“任务特定适应”，避免了单阶段联合训练中检索数据对目标任务优化的干扰。
- **实验验证较全面**：覆盖仿真 + 真实世界、多类检索基线、多组消融实验，并且对检索数据分布进行了定性可视化分析，有助于理解方法的内在机制。
- **开源开放**：提供代码与视频演示，便于复现。

## 8. 不足与局限

- **实验覆盖范围有限**：
  - 仅在操作任务上评估，未涵盖移动操作、灵巧手操作等其他机器人任务类型；
  - 仅使用单一 VLA 骨干（SmolVLA-450M），未验证方法在其他架构（如 OpenVLA、π0、RT-2 等）上的通用性；
  - 真实实验仅涉及单一机械臂平台（xArm），且任务数量较少。
- **跨实体差距处理的策略不够普适**：
  - 在真实实验中，因 DROID 数据与 xArm 平台差距过大，第二阶段直接丢弃检索数据、仅用目标任务微调，本质上放弃了检索数据在任务特定阶段的利用；这说明 HSR 在跨实体场景下仍存在局限，尚未实现真正的跨实体协同训练。
- **LLM 规划的集成深度有限**：
  - LLM 仅用于训练期的离线任务分解，未参与部署期的闭环控制、在线重规划或失败恢复。
- **超参敏感性与人工设定**：
  - 技能置信度公式中的 α、β 权重、聚类数 K=10、检索保留比例（10%、30%）、LLM 计划生成数量等超参均为固定选择，缺乏系统敏感性分析。
- **技能聚类依赖语言指令的质量**：
  - 技能簇基于任务指令的文本嵌入聚类。若先验数据集指令语义粒度不一致或存在噪声标签，聚类质量可能受影响。
- **评估统计量有限**：
  - 真实实验结果未提供多次运行的标准差或显著性检验；部分 LIBERO 任务的标准差较大（如 18.1%），需要更多随机种子以增强结论稳健性。
