## 摘要
视觉-语言导航智能体通常根据其遵循路线式指令到达固定目标的能力进行评估。然而，真实的导航指令往往依赖于观察到的环境状态：如果某个条件成立，则沿着一条路径前进；否则，走另一条路径。这类指令要求智能体评估场景证据、选择正确的逻辑分支，并执行相应的导航行为。现有的评估对条件分支执行的控制有限，难以确定智能体失败是由于感知、语言接地、导航还是逻辑决策。我们引入 CondVLN，一个基于场景图的基准，用于诊断视觉-语言导航中的条件分支。CondVLN 程序化生成指令，其分支条件基于可验证的 3D 场景图谓词，并在分支深度、依赖链长度、空间组成、证据可观察性和指令范围方面进行受控变化。CondVLN 在 AI2-THOR、Matterport3D、Gibson 和 ReplicaCAD 中包含超过 11,500 条生成的条件指令，并使用标准 VLN 指标和分支特定诊断指标（分支选择准确率和条件成功率）来评估智能体。对四种最先进的 VLN 智能体（VLN-Zero、NaVid、NaVILA 和 Open-Nav）的评估表明，条件分支暴露了仅凭标准成功率或路径长度无法捕获的失败：智能体可能在导航上看似合理，但提交的分支与观察到的场景条件不一致。我们还提出了一个轻量级的神经符号分支选择模型，将条件接地与导航执行分离，使性能提升 2 倍。CondVLN 提供了一个可复用的测试平台，用于衡量具身智能体是否不仅能遵循指令，还能在正确条件下遵循正确的指令。

## Abstract
Vision-language navigation agents are often evaluated on their ability to follow route-like instructions toward a fixed goal. Yet, real navigation instructions often depend on observed states of the environment: if a condition holds, then follow one path, otherwise take another. Such instructions require an agent to evaluate scene evidence, select the correct logical branch, and execute the corresponding navigation behavior. Existing evaluations provide limited control over conditional branch execution, making it difficult to determine whether agents fail because of perception, grounding, navigation, or logical decision-making. We introduce CondVLN, a scene-graph-grounded benchmark for diagnosing conditional branching in vision-language navigation. CondVLN programmatically generates instructions whose branch conditions are grounded in verifiable 3D scene-graph predicates, with controlled variation in branch depth, dependency chain length, spatial composition, evidence observability, and instruction horizon. CondVLN contains over 11,500 generated conditional instructions across AI2-THOR, Matterport3D, Gibson, and ReplicaCAD, and evaluates agents using standard VLN metrics and branch-specific diagnostics: Branch Selection Accuracy and Conditional Success Rate. Evaluating four state-of-the-art VLN agents (VLN-Zero, NaVid, NaVILA, and Open-Nav) shows that conditional branching exposes failures that are not captured by standard success rate or path length alone: agents can navigate plausibly while committing to a branch inconsistent with the observed scene condition. We also present a lightweight neurosymbolic branch-selection model that separates condition grounding from navigation execution, improving performance by 2x. CondVLN provides a reusable testbed for measuring whether embodied agents can not only follow instructions, but follow the right instruction under the right condition.

现有视觉-语言导航（VLN）评估体系存在重要的认知盲区：

## 2. 方法论：CondVLN基准的构建

论文提出 **CondVLN**，一个基于**场景图（Scene Graph）**程序化生成的可验证条件导航基准。

### 2.1 核心思想

将“条件指令”的生成建立在**符号化、可验证的3D场景图谓词**之上，使每条指令的条件的真值（True/False）在生成时即为已知，从而允许对失败进行精确归因。

### 2.2 数据集生成流程

1. **场景层级抽象**：将不同数据源（AI2-THOR、MP3D、Gibson、ReplicaCAD）的异构标注统一转换为“房间→对象”的层级表示，每个对象记录语义标签ℓᵢ和3D中心坐标cᵢ。
2. **关系图生成**：对同房对象对计算距离（优先级为AABB距离 → 球面距离 → 中心距离），生成八方位角（东/东北/北…）+ 三高度（上/平/下）的**规范方向谓词**，以及“near/far/higher/lower/above/below”等**语义谓词**。
3. **条件指令合成**：
   - 模板结构：`IF condition THEN action ELSE action`；
   - 条件为对象存在性查询（如“如果厨房里有咖啡桌”）；
   - 动作指向由场景图锚定的目标对象；
   - 通过**嵌套（nesting）**和**链式（chaining）** 控制复杂度，形成6类指令（见表1）。
4. **VLN-CE封装**：将生成的指令转换为Habitat兼容的VLN-CE episodes（含起点、目标、参考路径、测地距离），可直接接入现有评估框架。

### 2.3 指令复杂度分类（Table 1）

| 类别 | 深度（嵌套） | 链长（分支数） | 描述 |
|---|---|---|---|
| Simple | 1 | 1 | 单层IF-ELSE |
| Nested | 2 | 1 | IF内嵌IF |
| Deep Nested | 3 | 1 | 多层嵌套 |
| Chain | 1 | 2 | IF / ELSE IF |
| Long Chain | 1 | 3 | 多分支链 |
| Nested Chain | 2 | 2 | 嵌套+链式 |

### 2.4 新评估指标

- **Branch Selection Accuracy (BSA)**：智能体按序完成正确分支子目标的比例（允许部分分数），用于衡量分支选择的正确性。
- **Conditional Success Rate (CSR)**：要求BSA=1**且**最终导航成功，是严格的条件任务完成率。
- 两者共同将“选对了分支但未到达”和“到达了目标但选错了分支”区分开来。

### 2.5 神经符号 Oracle 基线

- 在评估时将条件指令用构建时记录的真实场景图信息**重写为线性导航指令**（消除if-then-else结构），从而隔离“分支选择”与“下游导航执行”的贡献。
- 该Oracle不改变导航目标、子目标、参考路径或基础模型，仅替换代理指令文本，是一种**确定性诊断变换**而非新导航架构。

## 6. 主要结论与发现

1. **现有VLN模型在条件分支下表现大幅退化**，尤其NaVid和NaVILA在许多环境中CSR低至0.0%，表明当前训练范式难以泛化到结构化条件决策；
2. **标准指标会掩盖条件推理失败**：智能体可能SR非零（导航路径合理），但BSA/CSR远低（选错了分支），说明到达“看起来合理”的目标 ≠ 正确执行了条件逻辑；
3. **复杂度是主要失效因素**：深度（嵌套）和链长（顺序分支）的增加都导致BSA/CSR一致下降，尤其从d=2到d=3变化显著；
4. **显式符号结构有价值**：Open-Nav（LLM链式思维）和VLN-Zero（场景图）优于纯VLM类模型；
5. **Oracle解耦有效**：在复杂设置（如d=3, ℓ=1 和 d=1, ℓ=2）下，显式符号分支选择比Open-Nav提升约2倍，证明“先选对分支、再执行导航”的分解策略在困难场景中尤为关键。

## 7. 优点与亮点

- **可验证性**：所有条件指令均由场景图谓词生成，真值已知、语义无歧义，使错误归因成为可能；
- **受控复杂度**：深度/链长/空间组合/指令范围多轴可控，是目前少有的针对条件逻辑的精细评测工具；
- **跨环境兼容**：统一的场景抽象层和VLN-CE封装，可无缝迁移到现有生态，无需大规模基础设施改造；
- **诊断型指标设计巧妙**：BSA允许部分分数，CSR要求严格完成，两者结合可区分“感知-推理-执行”不同环节的失败；
- **Oracle诊断方法干净**：仅改写指令文本而不改动导航底层，科学地分离了“逻辑推理”与“运动控制”两个变量；
- **对社区有启发价值**：论文明确定义了条件分支作为VLN评测的独立维度，为神经符号推理的落地提供测试床。

## 8. 不足与局限

- **场景类型受限**：仅覆盖室内VLN-CE环境，未涉及室外、开放世界或动态场景；
- **Oracle假设过强**：分支选择使用构建时的完整场景图真值，现实中智能体面对的是不完整、有噪声的观测，因此Oracle性能提供了“上限参考”而非可实现水平；
- **固定几何阈值**：near/far/above等关系使用手动设定的固定阈值，可能在不同场景分布间泛化不足；
- **指令语言多样性有限**：程序化模板生成的自然语言较为机械，缺少真实人类指令的多样性和语用模糊性；
- **继承原始数据噪声**：MP3D/Gibson的扫描和语义标注带有噪声，会影响感知验证环节；
- **缺乏统计稳健性报告**：未说明多次运行方差、随机种子或显著性检验；
- **模型覆盖范围有限**：未评测近期更新的VLN模型（如OmniVLA、NavGPT-2等）以及强化学习训练的专门模型。

## 总结

CondVLN 将条件逻辑推理作为 VLN 评测的受控轴引入，通过场景图驱动的程序化生成，提供了兼具可验证性和复杂度可调的诊断基准。其核心贡献在于提出“分支选择准确率”和“条件成功率”这对指标，揭示了当前 SOTA 智能体在条件分支下的隐藏失败，并证明显式符号分解（Oracle 基线）在复杂推理场景中具有显著优势。该工作为神经符号推理与具身智能导航的交叉研究提供了高质量的可复用测试平台，但在场景覆盖、指标稳健性和基线泛化性方面仍留有拓展空间。
