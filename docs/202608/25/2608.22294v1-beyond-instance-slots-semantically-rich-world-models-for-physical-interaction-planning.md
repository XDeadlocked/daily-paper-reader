## 摘要
用于物理交互的世界模型通常被训练来预测未来的观测或潜在特征；然而，面向规划的模型必须回答一个根本不同的问题：候选动作是否能在保持基本关系的同时产生与任务一致的未来。整体状态表示模糊了底层实体，而标准的实例级对象槽仅识别“存在什么”，而不指定每个实体在任务情境中扮演“什么角色”。为弥合这一差距，我们提出了语义丰富世界模型（SR-WM），一种以任务为条件的世界模型，围绕五个功能角色构建：夹爪、目标、目的、关系和阶段。在SR-WM中，视觉实体编码器从预训练的补丁特征中提取软实体假设，使得分割掩码可以作为可选提议先验，而不强制它们作为所需的状态表示或推理输入。随后，角色绑定器将这些假设映射到任务特定角色，而动作条件动力学模型则预测角色转移以及细粒度语义，包括抓取/接触、谓词建立、关系保持、夹具状态和阶段变化。关键的是，这种统一的角色状态为下游的多候选动作生成、阶段感知重排序和违规感知后缀重采样提供了基础。我们的综合评估协议涵盖所有四个LIBERO模拟套件、跨套件迁移、感知诊断和动作敏感性分析。最终，这种表述将对象中心预测转化为一个语义接口，将视觉动态与面向规划的决策制定连接起来。

## Abstract
World models for physical interaction are typically trained to predict future observations or latent features; however, a planning-oriented model must answer a fundamentally different question: whether a candidate action produces a task-consistent future while preserving essential relations.Monolithic state representations obscure the underlying entities, while standard instance-level object slots merely identify \emph{what} is present without specifying \emph{what role} each entity plays in the task context. To bridge this gap, we present the Semantically Rich World Model (SR-WM), a task-conditioned world model structured around five functional roles: gripper, target, goal, relation, and phase.Within SR-WM, a visual entity encoder extracts soft entity hypotheses from pretrained patch features, allowing segmentation masks to serve as optional proposal priors without mandating them as required state representations or inference inputs.A role binder subsequently maps these hypotheses to task-specific roles, while an action-conditioned dynamics model predicts role transitions alongside fine-grained semantics, including grasp/contact, predicate establishment, relation preservation, fixture state, and phase change.Crucially, this unified role state grounds downstream multi-candidate action generation, stage-aware reranking, and violation-aware suffix resampling.Our comprehensive evaluation protocol spans all four LIBERO simulation suites, cross-suite transfer, perception diagnostics, and action-sensitivity analysis.Ultimately, this formulation transforms object-centric prediction into a semantic interface linking visual dynamics with planning-oriented decision making.

### 1. 论文的核心问题与整体含义

**研究动机与背景**

- 传统世界模型（World Models）通常以预测未来观测或潜在特征为目标，但是低预测误差并不能保证对决策有用——一个看似合理、预测误差很低的未来，可能在语义上完全没有意义。例如：动作可能接近了错误的对象、丢失了抓取、撤销了已打开的夹具、或过早释放物体。
- 现有基于目标（goal-conditioned）的世界模型（如DINO-WM、LeWM、RC-aux）虽然将预测与规划对齐，但并未显式表示"一个动作必须建立或保持的谓词（predicates）"。
- 对象中心（object-centric）方法（如Slot Attention、FOCUS、Slot-MPC等）将场景分解为实体，提升了鲁棒性和探索效率，但**实体身份不等于任务角色**。一个胡萝卜和容器并不能揭示哪个是目标（target）、哪个是目的（goal）、抓取是否稳定、需要满足什么谓词、何时应释放等。同一个实体在不同指令下可能扮演目标、目的或干扰物的角色，可交换的实例槽将任务绑定和进度判断留给了下游策略。

**论文的核心观点**

- 规划导向的世界模型需要回答的根本问题不是"未来会怎样"，而是"候选动作是否能产生与任务一致的未来，同时保持已满足的关键关系"。
- 为此，论文提出将对象中心预测转化为**语义接口**，连接视觉动态与规划导向决策，明确区分"实体假设"与"任务角色状态"。

### 2. 论文提出的方法论

**方法论总览**

论文提出 **语义丰富世界模型（SR-WM, Semantically Rich World Model）**，围绕五个功能角色构造任务条件状态：
- **Gripper（夹爪）**：末端执行器位姿、开合度、运动、接触与抓取状态。
- **Target（目标）**：任务相关对象或关节部件及其几何信息。
- **Goal（目的）**：容器、表面、目的地或期望的夹具状态。
- **Relation（关系）**：夹爪–目标、目标–目的之间的几何与符号谓词。
- **Phase（阶段）**：任务进度（接近、抓取、搬运、对齐、释放、完成）。

**核心技术细节**

1. **轻量级LeWM基础**：SR-WM 基于 15M 参数（5M ViT-Tiny 编码器 + 10M transformer 预测器）的 LeWM 构建，保留其预训练目标，不引入额外的大规模视觉主干。
2. **视觉实体编码器与软实体**：
   - 每个实体表示为 `(外观, 几何, 运动, 置信度)` 四元组，支持后续角色查询按功能使用相应证据。
   - 实体是"软"的，不必与标注掩码一一对应；被遮挡或不确定的对象可分散注意力到多个 patch。
   - 可选分割先验：Grounding DINO + SAM/SAM2 的提议仅作为注意力加性偏置（`λ_seg M`），完整 patch 上下文始终保留；推理时可设 `λ_seg = 0` 实现无掩码推理。
3. **任务条件角色绑定**：
   - 语言条件角色查询以交叉注意力方式将软实体映射到五个角色，实现"同一实体在不同指令下绑定到不同角色"。
   - 绑定过程直接定义了 SR-WM 的预测与规划状态空间，而非事后语义分类器。
4. **动作条件角色动力学**：
   - 将每个动作块划分成 J 个有序子段，预测中间转移状态，便于定位违规发生边界。
   - 使用残差门控更新：`Δz = Dθ(Z, Ea(A), ℓ)`, `ẑ = z + σ(g) ⊙ Δz`，门控可保持不受影响的角色状态不变。
5. **语义转移监督**：预测接触/稳定抓取、目标–目的谓词建立、已建立谓词的保持/违规、合取条件满足、阶段身份与转移有效性、运动学夹具状态。
6. **硬负样本动作判别**：通过打乱片段、反转接近–抓取顺序、替换其他轨迹、扰动释放时机构建硬负样本，使用边际损失训练排序。
7. **候选生成、选择与修复**：
   - **角色条件 Flow Matching（FM）**：以角色状态 Zt 为条件，从噪声采样 K 个动作块。
   - **阶段感知语义选择器**：结合阶段上下文、接触/抓取置信度、谓词建立与保持、夹具有效性和预测不确定性进行打分。
   - **违规感知后缀修复**：若选中候选分数低于阈值或预测到违规，保留有效前缀，仅从最早违规边界开始重采样后缀。

**训练目标**：共 11 项损失，分为三组：
- **L_rep**（表示层）：保留 LeWM 预测目标 + 角色绑定损失 + 状态动力学损失。
- **L_sem**（语义层）：接触/抓取、谓词建立、关系保持、阶段、夹具状态损失。
- **L_policy**（策略层）：Flow Matching 动作损失 + 硬负样本排序损失 + 后缀修复（掩码动作修复）损失。

### 6. 论文的主要结论与发现

1. **角色条件生成优于潜在条件生成**：使用 SR-WM 角色状态替代单块潜在表示，使 Candidate 0 成功率从 45.5% 提升至 62.8%，Oracle@4 覆盖率从 68.0% 提升至 89.5%。表明角色结构不仅改进了事后排序，还提升了动作生成质量和可行候选覆盖率。
2. **语义选择与修复有效转化覆盖率为部署性能**：阶段感知语义选择器将覆盖率转化为 75.3% 的 top-1 成功率；后缀修复进一步提升至 83.0%，将与 Oracle@4 之间的差距从 14.2 个百分点缩小到 6.5 个百分点。
3. **显式语义监督是因果判别力的关键**：去除语义头后排序准确率从 78.2% 跌落到 60.8%；去除硬负样本训练后决策边际坍塌至 0.018，准确率降至接近随机（53.7%）。
4. **结构化的角色设计带来单调增益**：从五个无结构实例槽（55.0%）到完整 SR-WM（83.0%）的逐组件消融呈现稳定的性能提升，证明显式的角色结构比隐式语言全局上下文更有效。
5. **对分割掩码的依赖很弱**：无掩码 patch-only 推理达到 72.6% 成功率，损坏掩码下仅轻微下降至 70.8%，Oracle 掩码上界为 78.4%——说明可训练的分 patch 表示本身已保留任务关键语义几何，分割仅是可选的结构先验。
6. **角色表示具有良好的跨任务迁移性**：预训练角色绑定显著加速目标套件的数据高效适应（如 Goal 套件上适应 74.6% vs 从头 66.3%）。

### 7. 优点

**方法论亮点**：
- **实体与角色分离**：将可交换的实体假设与任务条件角色状态解耦，解决了实例槽无法表达任务角色的关键缺陷，且无需为每个任务重新学习实体编码器。
- **轻量高效**：在 15M 参数 LeWM 基座上扩展，完整系统仅 45.4M 参数，生成+评分延迟约 37 ms（K=4），适用于实际控制频率。
- **弱分割依赖设计**：通过提议 dropout、注意力偏置而非掩码替换，实现了无掩码推理，同时保留分割带来的性能增益空间，设计上具有良好鲁棒性。
- **规划导向的语义预测**：不仅预测未来状态，更预测任务关键事件（接触、谓词建立/保持、阶段转移），并支持违规定位与选择性修复，而不是简单的整块重规划。
- **严格的实验控制意识**：区分生成质量（Candidate 0）、覆盖率上界（Oracle@K）与部署性能（Selected@K）；明确规定 Oracle@K 不可部署；对信息访问边界有清晰审计（训练标签 vs 推理输入）。
- **对因果顺序敏感的训练**：硬负示例构造（打乱、反转、替换）使模型学习动作顺序与因果，而非静态视觉特征。

**实验设计亮点**：
- 覆盖全四个 LIBERO 套件，跨套件迁移、感知诊断、动作敏感性和效率分析层次完整。
- 对 checkpoint 选择设置了明确验收标准（shuffle margin 阈值、短验证 rollout），避免测试集泄漏。

### 8. 不足与局限

**表示能力限制**：
- **固定五角色本体论**：适用于单臂、目标导向操作任务，但可能不足以应对双臂交互、多同时目标、可变形物体、工具使用等场景。论文明确承认这些局限性。
- **关系/阶段为隐式聚合状态**：关系与阶段不是物理实体槽而是聚合表示，可能不如显式关系图表达能力强。

**标注与依赖问题**：
- 谓词和阶段监督在模拟器中便宜易得，但在物理机器人上需要仔细的标注或估计，部署成本可能较高。
- 可选分割虽减弱了对特定分割器的依赖，但**并未消除感知失败**——严重遮挡时实体编码器仍可能丢失目标的精确几何中心，导致谓词建立被提前预测（见定性错误分析）。

**实验覆盖的局限**：
- 仅在 **LIBERO 模拟环境**中验证，尚无物理真实机器人实验。
- 实验套件集中于桌面单臂抓取/放置类任务，缺乏对双臂、可变形物体、长时域复杂工具操作的验证。
- 跨套件迁移中适应 vs 从头训练的比较并未控制总计算量或总历史数据（仅控制目标数据与更新次数），论文对此有明确声明但仍是解释上的边界。
- 对候选生成多样性的度量（去重、有效覆盖率）在正文中未做详细定量报告。

**推理效率与安全**：
- 后缀修复增加了额外推理调用，且论文明确指出**不适用于安全关键场景**（缺乏碰撞检查与底层保护机制）。
- 高频控制场景下，离散的阶段监督可能滞后于连续的精细控制变化，导致释放时机过迟或过早（定性错误分析中的"粒度阶段错位"）。

**评估偏差风险**：
- 部分消融（如表 5 中的状态构成）同时改变状态参数化和预测监督内容，论文承认无法完全分解两者的贡献。
- 论文引用的部分参考文献时间戳为 2026 年（如 Maes et al. 2026, Goswami et al. 2026 等），属于未来的预印本，这可能影响其可信度或复制性。
