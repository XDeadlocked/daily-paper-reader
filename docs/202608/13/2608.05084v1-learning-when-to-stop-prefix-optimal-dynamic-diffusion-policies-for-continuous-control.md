## 摘要
扩散策略是连续控制中一类强大的策略，但其迭代去噪过程造成了巨大的计算瓶颈。降低这一成本需要在保持任务性能的同时，根据每个动作的难度调整去噪步数。我们提出了前缀最优生成策略（POGP），该框架通过在去噪链上进行贝尔曼式递归，在每个中间去噪步骤学习一个前缀值函数。前缀值函数有两个用途：它提供了一个辅助训练目标，鼓励中间输出成为高质量动作；同时，它实现了一种测试时停止规则，在额外步骤不太可能产生有意义改进时终止去噪。在四个MuJoCo环境以及与12个基线的比较中，POGP在保持接近完整任务性能的同时，将所需的去噪迭代次数减少了约2.7倍。与最先进的动态扩散基线相比，前缀训练还将最终任务性能提高了约3.5%。这些结果表明，对中间去噪步骤进行监督不仅有助于自适应早停，而且作为辅助目标也能改进学习到的策略。

## Abstract
Diffusion policies are a powerful policy class for continuous control, but their iterative denoising process creates a substantial computational bottleneck. Reducing this cost requires adapting the number of denoising steps to the difficulty of each action while preserving task performance. We introduce Prefix-Optimal Generative Policies (POGP), a framework that learns a prefix value function at every intermediate denoising step through a Bellman-style recursion over the denoising chain. The prefix value function serves two purposes: it provides an auxiliary training objective that encourages intermediate outputs to become high-quality actions, and it enables a test-time stopping rule that terminates denoising when additional steps are unlikely to produce meaningful improvement. Across four MuJoCo environments and comparisons with 12 baselines, POGP reduces the required number of denoising iterations by approximately 2.7-fold while retaining near-full task performance. Compared with state-of-the-art dynamic diffusion baselines, prefix training also improves final task performance by approximately 3.5%. These results indicate that supervising intermediate denoising steps is useful not only for adaptive early stopping, but also as an auxiliary objective that improves the learned policy.

### 一、论文的核心问题与整体含义（研究动机和背景）

扩散策略（Diffusion Policies）在连续控制领域已成为一种强大的策略类别，它通过一个 K 步去噪链（denoising chain）将随机噪声逐步细化为最终动作。但其**主要计算瓶颈**在于：每个动作的生成都需要完整执行 K 次顺序的神经网络前向传播（即 K 次去噪迭代），而且无论任务难度如何，计算开销都是固定的。

在真实世界中，机器人/智能体在轨迹上的大部分动作是常规且明确的，仅需少数去噪步骤即可确定；而少数情况（如接触丰富的动力学转换、外部扰动恢复、模式切换等）则需要更多的细化步骤。然而，现有扩散策略框架无法区分这两类情况，而是对所有动作均匀地消耗计算资源——这不利于实时和边缘部署。

论文的核心洞察是：**去噪深度应该随任务难度的变化而动态调整**，就像大语言模型推理时在难题上投入更多 token 一样。但现有方法要么固定步数减少，要么训练一个与策略脱节的独立适配器来预估所需步骤数，这些方法都忽略了中间去噪步骤本身的质量。论文提出的 POGP 旨在将**变长去噪深度**作为策略优化的第一类对象，而非部署后的启发式补偿手段。

### 二、论文提出的方法论

#### 2.1 核心思想

POGP 通过联合训练一个**前缀值函数（Prefix Value Function, PVF）**，对去噪链上每个中间步骤的动作进行价值评估。该值函数具有双重功能：

1. **辅助优化目标**：在训练时引导中间去噪输出成为可执行且高质量的候选动作；
2. **测试时早停信号**：在推理时判断继续去噪是否还会带来有意义的性能提升，从而动态决定何时提前终止。

#### 2.2 前缀值函数的定义

给定环境状态 \(s\) 和中间动作 \(a_t\)（\(t\) 为去噪步数，\(t=K\) 为噪声，\(t=0\) 为终态动作），前缀值定义为：

\[
V^\pi_t(s, a_t) := Q^\pi(s, \pi_{\text{full}}(s, a_t))
\]

其中 \(\pi_{\text{full}}(s, a_t)\) 表示从步骤 \(t\) 继续去噪直到第 0 步所得到的终态动作。直观地，\(V_t\) 回答的问题是："如果从这个中间动作继续完成去噪，最终能得到多大的回报？"

#### 2.3 Hazard Bellman 递归

为避免朴素实现对每个前缀值都需要完整跑完链的 \(O(K^2)\) 计算开销，论文利用去噪链的时间结构，提出一个**Hazard Bellman 递归**：

\[
V_t(s, a_t) = h \cdot Q(s, a_0) + (1-h) \cdot V_{t-1}(s, \pi_\theta(s, a_t, t))
\]

边界条件为 \(V_0(s, a_0) = Q(s, a_0)\)。其中 \(h \in (0,1]\) 称为**风险系数（hazard coefficient）**，用于平衡终态动作价值锚点和后续步骤的引导估计。作者在全部实验中使用均匀风险 \(h = 1/K = 0.05\)（K=20）。论文证明该算子满足 \(\ell_\infty\) 压缩映射（收缩率 \(1-h\)），因此具有唯一不动点。

#### 2.4 三种网络的联合优化

POGP 同时训练三个组件：

- **环境评论器（Q）**：在环境转移 \((s,a,r,s')\) 上做标准 Double Q-learning；
- **前缀评论器（V）**：通过共享去噪链，对前缀值函数施加 TD 风格的更新，目标为 \(y_V = h \min_i Q_{\phi'_i}(s, a_0) + (1-h) V_{\psi'}(s, a_{t-1}, t-1)\)；
- **扩散 actor（π）**：使用 gated loss，结合终态动作 Q 值最大化和前缀值最大化，权重通过余弦调度逐步开启（先固定为 0，等 V 的 RMSE 稳定后再激活）。

#### 2.5 测试时早停规则

训练完成后的前缀值函数天然提供了停止判据。第 \(t\) 步的边际增益为：

\[
\Delta_t = V_\psi(s, a_{t-1}, t-1) - V_\psi(s, a_t, t)
\]

当连续 \(m=2\) 步满足 \(\Delta_t \leq \epsilon \cdot |V_\psi(s, a_t, t)|\)（其中 \(\epsilon=0.01\)）时，停止去噪。该停止规则不需要任何额外参数或独立的停止网络。

#### 2.6 完成映射（Completion Map）

由于提前停止时中间动作 \(a_t\) 仍含残余噪声，POGP 还训练了一个轻量级单层 MLP \(g_\omega(s, a_T, T)\)，用于将截断动作映射回可执行空间，最小化与终态动作 \(a_0\) 的均方误差。论文给出了理论误差界（基于 Lipschitz 常数和期望投影误差），并在实验中验证了投影误差随截断时间 \(T\) 呈 \(\mathcal{O}(\sqrt{T})\) 增长。

- **累积回报（Return）**：每个环境的原始分数

### 六、论文的主要结论与发现

1. **前缀训练提升全链性能**：POGP 使用完整的 20 步去噪链时，在四个 MuJoCo 环境上的 IQM 为 0.942（95% CI [0.908, 0.97]），超过所有 12 个基线的点估计。相比最接近的扩散基线 SDAC，平均提高约 9.5 分；相比动态扩散基线 D3P，平均提高约 5 分（全链对比时）。

2. **自适应早停带来显著的效率提升**：POGP 平均每个动作仅需 6.8–8.6 个去噪步骤，相比固定 20 步链减少约 66%（约 2.7–2.9× 加速），同时保留 98–99% 的自身全链性能。在同样的自适应设置下，POGP 比 D3P 使用 18.2% 更少的迭代次数而性能高出约 3.5%。

3. **计算预算的智能分配**：在 HalfCheetah 的扰动实验中，POGP 在常规步态下只用 3–5 步去噪，受到外力扰动时动态提升到 15–20 步，扰动移除后恢复低计算模式——这验证了 PVF 能够以环境状态和动作难度为依据在运行时分配计算。

4. **中间监督作为正则化器**：全链性能的改善说明前缀监督不仅对提前停止有用，还作为辅助目标/正则化器提升了最终动作质量。

5. **扩展性趋势**：当链长 K 从 5 增加到 20 时，POGP 保持 97–99% 的半链保留率，而基线 SDAC 从约 96% 降至约 82%——POGP 的优势随链长增长而扩大。

### 七、论文的优点

1. **思想新颖且自然**：将"何时候止"的学习从独立的启发式模块转变为策略优化中价值函数的第一类对象，写作上也与自适应计算和推理时缩放趋势建立了清晰联系。

2. **理论支撑扎实**：Hazard Bellman 算子有压缩映射证明；完成映射误差有 Lipschitz 界的理论推导；共享链的梯度方差有正式分析。理论和实验相互印证。

3. **实验覆盖率高且控制良好**：12 个基线、10 个种子、多层消融、灵敏度扫描、链长扫描、OOD 测试、故障模式分析——覆盖面在同类论文中相当全面。

4. **计算效率与性能双赢**：不同于很多加速方法以牺牲性能换取速度，POGP 在降低计算量的同时还在最终性能上获得提升。

5. **实现的简洁性**：停止规则不需要额外参数（直接用 \(\epsilon=0.01, m=2\) 在所有任务间通用），复杂度低且易于部署。

### 八、不足与局限

1. **实验范围有限**：仅在四个 MuJoCo 运动控制环境上评估，尚未涉及机器人操作、导航或真实硬件上更复杂、长视界的任务。论文自述这一基线范围的局限。

2. **确定性去噪器假设**：所有实验使用 DDIM 风格确定性去噪器。随机去噪器（如 DDPM 风格）需要修改 MDP 定义和收缩分析，论文将随机情况留给未来工作。

3. **链长覆盖不足**：最大链长只有 K=20，尚未验证 K=50 或 K=100 等长去噪链（如图像生成中常见）下前缀学习的可扩展性。作者指出这可能需要对前缀评论器进行架构修改（如跨层级注意力）。

4. **种子敏感性**：一个种子（seed 100）因为门控打开过晚而未充分受益于前缀训练，性能低于中位数约 12 分。虽然论文提供了诊断和缓解思路（用梯度对齐替代 RMSE 门控），但这表明门控机制对初始训练动态有一定敏感性。

5. **完成映射的局限**：投影误差随截断时间约 \(\mathcal{O}(\sqrt{T})\) 增长，在动作空间维度较高时（如 Ant 的 8 维动作）误差更大。虽然性能保留仍在可接受范围内，但在更高维动作空间与复杂接触任务上的表现尚未验证。

6. **无多风险训练扩展**：论文理论学习中提出统一风险分布训练泛化的保证，但实际实验只使用均匀风险 \(h=1/K\)，未充分测试学习到的或状态自适应风险函数的效果。

7. **计算成本相对较高**：POGP 训练时因共享链生成而比普通扩散基线稍慢（1.0–1.2 小时 vs 0.7–0.9 小时每百万步），虽然推理时大幅加速，训练侧存在一定开销。

### 总结

POGP 通过前缀值函数将对去噪链中间状态的监督和测试时早停统一在一个框架下，同时具有严格的理论保证（Bellman 收缩）和实证验证（12 基线、多环境、强消融），是该领域中一种兼具学术深度和工程实用性的方法。其核心贡献——中间监督作为性能提升因素——超越了单纯的效率优化，也为后续扩散策略的设计提供了新的思路与方法论参考。
