## 摘要
最近的视觉-语言-动作（VLA）方法通过将其表示与3D场景几何对齐来提升泛化能力。然而，这些方法从根本上是指令无关的：表示均匀地对齐整个场景，而忽略了由语言指令指定的特定目标对象的3D几何。这导致在细粒度操作和目标遮挡任务中出现失败，而这类任务的成功取决于对目标对象而非整个场景的精确3D理解。为解决这一问题，我们提出了Mind-VLA，一种面向VLA模型的指令感知空间表示对齐方法。具体而言，Mind-VLA首先获取语言指令指定的目标对象，然后准备其目标对象三视图，并提取相应的VAE和VGGT特征。最后，将VLA模型的潜在表示与这些特征对齐，以实现指令感知的3D理解。Mind-VLA在LIBERO上达到93.9%，在CALVIN上达到4.47，且采用了紧凑的345M参数骨干网络。在具有目标遮挡的真实机器人任务中，Mind-VLA实现了54%的平均成功率，在真实机器人对比中比表现最佳的指令无关方法高出32个百分点。代码将公开提供。

## Abstract
Recent Vision-Language-Action (VLA) methods improve generalization by aligning their representations with 3D scene geometry. However, these methods are fundamentally instruction-agnostic: the representations align the entire scene uniformly, neglecting the 3D geometry of the specific target object designated by the language instruction. This causes failures on fine-grained manipulation and target occlusion tasks, where success depends on accurate 3D understanding of the target object rather than the entire scene. To address this, we present Mind-VLA, an instruction-aware spatial representation alignment method for VLA models. Specifically, Mind-VLA first obtains the target object specified by the language instruction, then prepares its target-object tri-view and extracts the corresponding VAE and VGGT features. Finally, the latent representation of the VLA model is aligned with these features to enable instruction-aware 3D understanding. Mind-VLA reaches 93.9% on LIBERO and 4.47 on CALVIN with a compact 345M-parameter backbone. On real-robot tasks with target occlusion, Mind-VLA reaches 54% average success, outperforming the best-performing instruction-agnostic method in real-robot comparison by 32 percentage points. Code will be publicly available.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：视觉-语言-动作（VLA）模型已成为通用机器人操作的重要方法，将语言指令和视觉观测直接映射为机器人动作。然而，许多操作任务要求模型超越 2D 视觉识别，理解物体的形状、姿态、空间关系与遮挡情况。
- **现有方法的局限**：近期 3D 感知 VLA 方法（如 Spatial Forcing、GLaD 等）通过在训练时将 VLA 表示与 3D 场景特征对齐来提升空间理解，但存在一个根本性问题——**指令无关（instruction-agnostic）**：
  - 3D 监督信号来自整幅场景，均匀地对齐整个场景，而非语言指令指定的目标对象；
  - 目标物体、干扰物体和背景结构被编码在一起，削弱了指令与 3D 表示之间的关联；
  - 在细粒度操作和目标遮挡任务中，成功高度依赖目标物体而非整幅场景的 3D 理解，因此这类方法容易失败。
- **本文意义**：提出 Mind-VLA，首次将 3D 监督信号**按指令条件化**，聚焦于语言指令指定的目标物体的 3D 几何，而不是场景级几何，从而显著提升目标级 3D 理解能力和遮挡鲁棒性。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想
- **指令感知空间表示对齐**（Instruction-Aware Spatial Representation Alignment）：在训练阶段，将 VLA 模型的潜在表示与"语言指令指定目标对象"的三视图 3D 特征对齐，而非与全场景特征对齐。
- 辅助分支**仅在训练时使用**，推理时全部移除，不增加部署成本。

### 2.2 基础 VLA 框架（Preliminaries）
- **输入与 Token 化**：双 RGB 图像（主相机 + 腕部相机，224×224×3）经冻结视觉编码器编码；语言指令经冻结 CLIP 文本编码器编码；本体感觉状态 st∈R⁸ 经线性投影编码。所有 token 加上可学习的动作查询（action queries）输入因果 Transformer。
- **动作预测**：扩散动作头（DiT）基于动作查询输出预测未来 Ta 步 7 维动作，训练损失为噪声预测损失：
  - **Lact** = E[‖ε − εθ(√ᾱτ At + √(1−ᾱτ)ε, τ, Hat)‖²]（公式 1）
  - 推理时用 DDIM 采样。
- **场景级辅助监督**：LVLA = Lact + λaux Laux，其中 Laux 包括逐 patch RGB 重建（Lobs）和密集 2D 运动预测（Ltraj），用于保留工作空间外观与短期动态。

### 2.3 指令感知空间对齐（核心贡献）
- **目标物体三视图（Target-object tri-view）**：为每个目标物体准备 top/front/side 三个正交视角，离线预生成：
  - 仿真中：从物体 mesh 渲染正交投影；
  - 真实机器人：手持相机从三个近似规范视角各拍一次，无需标定装置。
- **三视图 VAE 潜在预测（Tri-view prediction）**：
  - 用冻结的 Stable Diffusion VAE 将三视图编码为潜在特征 Zm(ℓ)（体积缩小 48 倍）；
  - 新增物体查询 token qtri_t，经小型 MLP 解码为预测潜在表示 Ẑt；
  - 损失：**Ltri** = (1/K)Σ‖Ẑt − Zm(ℓ)‖²（公式 3），将语言指令与对应物体几何绑定。
- **多层级 VGGT 特征对齐（Multi-level alignment with VGGT）**：
  - 对 4 个中间 Transformer 层分别配对一个 VGGT 层；
  - 将目标物体三视图的 VGGT 特征（跨视角和空间位置均值池化）与对应层图像 token 特征对齐；
  - 损失：**Lgeo** = (1/4K)ΣΣ[1 − cos(ϕj(h̄t,j), gm(ℓ),j)]（公式 4），余弦相似度距离。
- **最终训练目标**：**LMindVLA = LVLA + λtri·Ltri + λgeo·Lgeo**（公式 5）
- **推理时**：VAE、VGGT 和所有辅助解码器全部移除，仅保留辅助查询 token 带来的轻微计算开销。

## 6. 主要结论与发现

- **仿真性能**：LIBERO 平均成功率 93.9%（Spatial 98.0 / Object 98.0 / Goal 92.0 / Long 87.5），以 345M 参数骨干匹敌 π0（94.2%）和 GLaD（94.1%）等 7B 级模型；CALVIN ABC-D 平均完成任务长度 4.47，超过 VPP（4.29）、Seer（4.28）和大型 π0（3.92）。
- **消融结论**：
  - 场景级轨迹预测 +1.8 pp，目标物体三视图潜在预测进一步 +1.2 pp；
  - 目标物体三视图 VGGT 对齐（93.9%）优于场景图像 VGGT 对齐（92.8%），在 LIBERO-Object 上差距最大（+4.0 pp）；
  - "物体聚焦"贡献约 +2.5 pp，"规范视角先验"贡献约 +1.5 pp——聚焦在干净仿真中贡献主导，规范视角在观测不完整时（真实遮挡）起决定性作用。
- **真实机器人鲁棒性**：正常条件下 Mind-VLA 平均成功率 69%（5 任务），比 scene-image 消融高 11 pp、比 Seer 高 19 pp；25% 遮挡条件下成功率 54%，仅下降 13 pp，而 scene-image 消融下降 29 pp（57→28）、Seer 下降 23 pp、OpenVLA 下降 21 pp——验证了目标物体三视图监督（而非单纯物体聚焦）是遮挡鲁棒性的来源。

## 7. 优点

1. **问题洞察精准**：指出已有 3D 感知 VLA 方法"指令无关"这一被忽视的关键缺陷，切中细粒度操作与遮挡任务的核心痛点。
2. **方法设计优雅**：训练时对齐、推理时零模块开销，保持标准 RGB+语言+状态接口不变，部署成本极低。
3. **参数效率突出**：以 345M 紧凑骨干达到 7B 级模型的性能，验证了"指令感知监督"可部分替代模型容量。
4. **消融设计严谨**：通过 scene-image vs. target-object tri-view VGGT 的对照，干净地隔离了"对齐目标"的因果贡献；SAM crop 变体进一步分解出聚焦与视角先验的各自贡献。
5. **真实验证有说服力**：在目标遮挡条件下相比指令无关方法展现出显著鲁棒性优势（+32 pp vs. Seer），且关键消融在真实场景中放大并验证了仿真中的结论。
6. **实现代价低**：真实物体的三视图拍摄仅需手持相机、每个物体不到一分钟，无需标定装置。

## 8. 不足与局限

1. **物体词汇受限，无法零样本部署**：每个目标物体需一次性三视图准备（仿真中渲染、真实中拍摄），限制了任意新物体的零样本泛化；论文明确承认这一特权监督（privileged supervision）的局限。
2. **长时序任务表现有短板**：LIBERO-Long 上 87.5%，低于 DreamVLA（89.5%）；长链任务可能受益于场景级全局建模，而当前方法只映射单一目标物体，对后续链式目标缺乏建模。
3. **真实实验覆盖窄**：仅 3 类任务、2 个目标物体、单一操作平台，30 trials/条件统计功效有限；未涉及多物体交互、动态干扰等复杂场景。
4. **算力与训练细节披露不足**：未报告训练时长、总迭代数、超参（λtri/λgeo）设置及敏感性，复现门槛较高。
5. **对"指令到目标物体"的对应假设较强**：依赖任务定义将指令与固定三视图配对，未处理同一指令指代多物体、指代消歧失败等实际歧义情况。
6. **仿真消融覆盖不完整**：CALVIN 上无逐组件消融；LIBERO-Long 上三视图对齐反而不如场景级对齐，说明方法在特定任务类型上存在适用边界，论文未深入分析原因。
