## 摘要
当前的视觉-语言-行动（VLA）模型的主流构建方式是将预训练的VLM与单独训练的流匹配动作专家相结合。这使VLM成为上下文编码器而非决策者。我们提出G0.5，一种预训练的自回归VLA模型，其中单个Transformer解码器在单一目标下生成推理和行动token。三个组件使其在基础模型规模下可行：一个可学习的跨具身动作分词器，将异构机器人动作映射到共享词汇表；一个原生思维链流，将任务分解、对象接地和行动提示与动作token交错；以及一个视觉记忆模块，通过视觉编码器注入多秒历史信息。由于推理和行动共享同一组权重，预训练VLM的能力得以迁移到物理行为中：模型紧密遵循指令，且提示可直接引导动作粒度、任务范围以及分布外场景处理，无需额外训练。G0.5在大量机器人数据集和VQA样本上预训练，在7个独立场景中超越最先进模型：在R1lite和R1pro机器人上的真实世界微调（76.7%对比π_{0.5}的53.3%和GR00T-N1.7的24.4%）；2025年BEHAVIOR挑战赛中使用通用策略的50个长时程家庭移动操作任务（31.4%对比π_{0.5}的26.3%和挑战赛冠军的26.1%）；DROID后训练后零样本迁移至未见环境和物体（82.5%）；语言跟随的抓取-放置基准；LIBERO（98.9%）；RoboTwin 2.0（93.3%）；以及SimplerEnv-Bridge（87.3%）。

## Abstract
The prevailing recipe for Vision-Language-Action (VLA) models couples a pretrained VLM with a separately trained flow-matching action expert. This makes the VLM a context encoder rather than a decision-maker. We introduce G0.5, a pretrained autoregressive VLA in which a single transformer decoder emits reasoning and action tokens under a single objective. Three components make this tractable at foundation-model scale: a learnable cross-embodiment action tokenizer that maps heterogeneous robot actions into a shared vocabulary; a native chain-of-thought stream interleaving task decomposition, object grounding, and action hints with action tokens; and a visual memory module that injects multi-second history through the vision encoder. Because reasoning and action share a single set of weights, the pretrained VLM's capabilities carry over to physical behavior: the model follows instructions closely, and prompts directly steer action granularity, task horizon, and out-of-distribution scene handling without further training. Pretrained on a large collection of robot datasets together with VQA samples, G0.5 surpasses state-of-the-art models across 7 independent regimes: real-world fine-tuning on R1lite and R1pro robots (76.7\% vs.\ 53.3\% for $π_{0.5}$ and 24.4\% for GR00T-N1.7), the 2025 BEHAVIOR Challenge on 50 long-horizon household mobile manipulation tasks using a generalist policy (31.4\% vs.\ 26.3\% for $π_{0.5}$ and 26.1\% for the challenge winner), DROID post-training followed by zero-shot transfer to an unseen environment and objects (82.5\%), a language-following Pick-and-Place benchmark, LIBERO (98.9\%), RoboTwin 2.0 (93.3\%), and SimplerEnv-Bridge (87.3\%).

## 1. 论文的核心问题与整体含义

- **背景**：当前视觉-语言-行动（VLA）模型的主流构建范式，是将预训练的视觉-语言模型（VLM）与单独训练的流匹配（flow-matching）动作专家相结合。
- **核心问题**：这种范式中VLM仅扮演上下文编码器的角色，而非真正的决策者，导致模型的决策能力和动作生成质量受限于动作专家的表达能力，VLM本身的推理与理解能力未能充分迁移到物理行为上。
- **本文主张**：提出G0.5，一种预训练的自回归VLA模型，仅用一个Transformer解码器、在统一的下一token预测目标下同时生成推理token与动作token，让预训练VLM的能力直接贯通至机器人行为决策，实现"推理即行动、行动即推理"的统一架构。

## 2. 论文提出的方法论

- **核心思想**：不采用VLM+动作专家的两阶段/两模型架构，而是将推理与动作生成置于同一个自回归Transformer解码器中，服从同一个训练目标。模型的输入为多模态token序列（文本指令、视觉观测、动作token），输出为推理文本和动作token的联合序列。
- **关键组件一：可学习的跨具身动作分词器（Cross-Embodiment Action Tokenizer）**：将不同机器人本体、不同动作空间（如关节角度、末端执行器位姿、移动速度指令等）的异构动作数据，映射到一个共享动作词汇表。该分词器是可学习的，使G0.5能在多种机器人平台上统一训练和推理，实现跨本体迁移。
- **关键组件二：原生思维链流（Native Chain-of-Thought Stream）**：将任务分解、物体接地（object grounding）和动作提示（action hints）等推理内容，以文本token的形式与动作token在序列上交错排列。模型在生成动作之前，先产生中间推理步骤，从而使推理过程直接参与动作决策，形成"思考-行动"交织的自回归生成流。
- **关键组件三：视觉记忆模块（Visual Memory Module）**：通过视觉编码器将多秒历史观测内容注入当前决策，使模型具备时间维度的视觉记忆——这是移动操作和长时程任务中判断物体运动、历史状态和任务进度的关键能力。
- **统一目标与训练流程**：全部token（文本、视觉、动作）在同一个自回归目标下联合训练。预训练在大型机器人数据集和VQA（视觉问答）样本上完成，之后可在任务数据上进行微调。由于推理与动作共享同一组权重，预训练VLM的指令跟随、场景理解和推理能力可以直接迁移到动作生成上。
- **提示机制即可控机制**：由于模型本身是统一的指令跟随生成器，用户或系统提示可直接调节动作粒度（粗粒度子技能或细粒度关节控制）、任务范围（单步还是长时程）以及分布外（OOD）场景的处理策略，无需为每种设置重新训练。
