## 摘要
从人类视频中学习操作技能对于可扩展的机器人学习很有前景。然而，人类与机器人之间的具身差异使得这一任务具有挑战性。一种有前景的解决方案是学习与具身无关的、以物体为中心的可操作可供性。在这项工作中，我们提出了一个框架，利用第一人称人类视频以及最先进的3D运动恢复结构和手部网格重建技术，来提取可操作可供性，如视觉可供性、抓取可供性和轨迹可供性，这些可供性明确编码了交互位置、抓取方式和移动方式。我们构建了EgoAffordance，这是一个大规模数据集，包含204K个片段，5.6M个视觉可供性和11.6M个抓取与轨迹可供性。在此基础上，我们提出了VLAff，一个基于大型视觉-语言模型的统一基础模型，学习所有可操作可供性之间的跨模态相关性。给定视觉观察和指令，VLAff生成视觉可供性热图、抓取姿态和轨迹，然后利用3D场景信息将其转换为可直接执行的动作。通过大量实验，我们证明VLAff不仅在视觉可供性预测上达到了最先进的性能，而且还能有效应用于真实机器人应用，如零样本操作和可供性引导的机器人学习。

## Abstract
Learning manipulation skills from human videos is promising for scalable robot learning. However, the embodiment mismatch between humans and robots makes this challenging. One promising solution is to learn object-centric actionable affordances that are embodiment-agnostic. In this work, we propose a framework that leverages egocentric human videos with state-of-the-art 3D Structure-from-Motion and hand mesh reconstruction to extract actionable affordances such as visual, grasp, and trajectory affordances that explicitly encode where to interact, how to grasp, and how to move. We construct EgoAffordance, a large-scale dataset comprising 204K episodes with 5.6M visual affordances and 11.6M grasp and trajectory affordances. Building on this, we introduce VLAff, a large vision-language model-based unified foundation model that learns cross-modal correlations across all actionable affordances. Given a visual observation and instruction, VLAff generates visual affordance heatmaps, grasp poses, and trajectories, which are then converted into directly executable actions by utilizing 3D scene information. Through extensive experiments, we demonstrate that VLAff not only achieves state-of-the-art performance on visual affordance prediction, but can also be effectively applied to real robot applications such as zero-shot manipulation and affordance-guided robot learning.

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想
构建大规模第一人称视频可供性数据集，并训练一个基于大视觉语言模型（VLM）的**统一基础模型VLAff**，同时预测视觉热图、抓取姿态和轨迹，利用3D场景信息转化为可执行动作。

### 关键技术细节

#### （1）可供性提取流程
- 输入：第一人称（egocentric）视频片段及语言描述。
- 使用大VLM（如GPT-4）筛选交互关键帧、动作标签、物体类别、交互手部。
- 手-物交互提取：
  - 手物检测器、分割模型（如SAM2）、手部关键点提取；
  - 接触区域通过指尖关键点与物体掩码的交集确定；
  - 3D手部重建使用MANO参数（WiLOr）。
- 场景处理：
  - 第一人称视角分割与修复（inpainting）以消除视觉偏差；
  - 单目深度估计、相机内参估计、视觉SLAM（DROID-SLAM）进行3D场景重建；
  - 结合深度和相机位姿追踪3D手部轨迹，提取接触前后的运动模式。

#### （2）VLAff模型架构
- 基础VLM：Qwen2.5-VL（处理图像+语言指令）。
- 额外视觉编码器：DINOv2，提供细粒度视觉特征，增强空间定位能力。
- 特殊标记（token）：
  - `<SEG>` 用于生成视觉可供性热图（通过分割解码器，类似LISA）；
  - `<GRASP>` 用于输出96维MANO手部参数（6D旋转表示）；
  - `<p0>`…`<pN-1>` 用于自回归生成轨迹token（轨迹空间经空间分箱离散化为6D位姿）。
- 解码器：视觉解码器融合DINOv2特征与`<SEG>`嵌入生成热图；抓取解码器将`<GRASP>`嵌入解码为手部参数；轨迹解码器自回归生成轨迹token序列。

#### （3）训练损失
- 视觉可供性损失：Soft Dice Loss（处理类别不平衡）：
  \[
  L_{visual} = 1 - \frac{2 \sum (A^p_{pred} \cdot A^p_{gt}) + s}{\sum (A^p_{pred}) + \sum (A^p_{gt}) + s}
  \]
  其中 \(p=1.5\)，\(s=1.0\)。
- 抓取姿态损失：Smooth L1 Loss（96维参数）。
- 轨迹损失：标准交叉熵（自回归token预测）。
- 总损失：\(L_{total} = \lambda_v L_{visual} + \lambda_g L_{grasp} + \lambda_t L_{traj}\)。

#### （4）轨迹采样策略（推理时）
- **上下文轨迹引导**：利用GPT等高能力VLM提供粗略3D方向向量 \([d_x,d_y,d_z]\)，约束在 \(\{−1,0,1\}\)，对第一个轨迹token施加高斯采样：\(p_1 \sim N(p_{contact} + s\cdot d_{guide}/\|d_{guide}\|, \sigma^2 I)\)。
- **基于采样的轨迹选择**：使用nucleus采样生成K个候选轨迹，通过体素化碰撞检测和方向对齐目标函数选择最优者。
