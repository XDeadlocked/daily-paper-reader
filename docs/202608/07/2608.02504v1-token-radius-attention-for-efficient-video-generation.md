## 摘要
视频扩散Transformer（VDiT）能够实现高保真生成，但密集的3D自注意力带来了二次方成本。现有的头级和块级稀疏方法在查询之间共享计算预算，忽略了令牌特定的注意力需求。我们观察到，保留密度因查询而异，但与注意力熵呈对数线性相关，而主要交互形成以查询为中心的邻域，其半径依赖于令牌。基于这些发现，我们提出了令牌半径注意力（TRA），这是一个无需训练的框架，它将查询熵映射为解析令牌预算，并将其转换为随时间衰减的半径，无需显式的键排序。融合熵提取、预热重用和块稀疏掩码构建进一步降低了开销。在Wan2.1、Wan2.2和HunyuanVideo的七个T2V/I2V配置中，TRA仅保留9%-19%的注意力交互，实现了1.56倍至2.05倍的加速，同时保持了有竞争力的生成质量。代码可在https://github.com/IF-LAB-PKU/Token-Radius-Attention获取。

## Abstract
Video Diffusion Transformers (VDiTs) enable high-fidelity generation but incur quadratic cost from dense 3D self-attention. Existing head- and block-level sparse methods share computation budgets across queries, overlooking token-specific attention demand. We observe that retained density varies across queries yet correlates log-linearly with attention entropy, while dominant interactions form query-centered neighborhoods with token-dependent radii. Based on these findings, we propose Token Radius Attention (TRA), a training-free framework that maps query entropy to an analytic token budget and converts it into a temporally decayed radius without explicit key ranking. Fused entropy extraction, warm-up reuse, and block-sparse mask construction further reduce overhead. Across seven Wan2.1, Wan2.2, and HunyuanVideo T2V/I2V configurations, TRA retains only 9-19% of attention interactions and achieves 1.56x-2.05x speedup with competitive generation quality. Code is available at https://github.com/IF-LAB-PKU/Token-Radius-Attention.

## 1. 论文的核心问题与整体含义

论文针对**视频扩散Transformer（VDiT）**中密集3D自注意力带来的**O(N²)二次方计算成本**问题，提出了一种名为**Token Radius Attention（TRA）**的免训练稀疏注意力框架。

**研究动机与背景：**
- VDiT是当前高质量视频生成的主流架构，但自注意力层成为推理性能瓶颈，严重制约了长视频、高分辨率场景的部署。
- 现有稀疏注意力方法（头级、块级）通常在多个查询之间共享单一的计算预算分配，这与自注意力按行独立归一化的本质相冲突：
  - 注意力集中的查询只需要少量键（key）即可达到目标注意力质量；
  - 注意力分散的查询则需要更多键。
- 因此，统一的预算分配要么在集中型查询上浪费计算，要么在分散型查询上遗漏重要键，导致生成质量下降。

**整体含义：** TRA的核心主张是，注意力分配的原子单位是**单个查询令牌**而非整个头或块，需要一种既能保持令牌级自适应性、又能满足硬件高效执行的结构化稀疏方案。

## 2. 论文提出的方法论

TRA遵循一条**“熵→预算→半径”（Entropy-to-Budget-to-Radius）**的流水线，将在下文逐步说明。

### 核心思想

TRA建立在两个经验观察之上：
- **Insight I（令牌特定注意力稀疏性）**：在数据集上进行实验分析后，测试集上保留了密度在不同查询之间差异可达数量级，但保留密度的对数与注意力熵呈近似线性关系（R²=0.940–0.966）。
- **Insight II（令牌半径注意力模式）**：高注意力键围绕查询形成近似圆形的空间邻域，且归一化注意力概率随二维空间距离近似指数衰减（R²=0.791）。领域半径因查询、头、层而异。

### 关键技术细节

**（1）熵-预算映射（Entropy-to-Budget Mapping）**
- 每个查询i的注意力熵定义为：Hi = −Σ pij log pij。
- 利用熵等价均匀支撑近似，推导出连续有效支撑大小：meff_i = exp(Hi)。
- 在统一支撑假设下，达到目标注意力质量τ所需的键数估算为：**bKτi = ⌈τ exp(Hi)⌉**，对应的令牌预算为：**bBτi ≈ τ exp(Hi) / N**。
- 该映射是解析式、单调的、无需训练，低熵查询获得小预算，高熵查询获得大预算。

**（2）预算-半径掩码构建（Budget-to-Radius Mask Construction）**
- 采用时间距离衰减规则：ϕ(δ) = exp(−γδ)，将预算转换为时间衰减的空间半径。
- 通过连续面积近似初始化基础半径ri，再用离散网格精确计数校正，选择满足目标键数的最小候选半径。
- 掩码定义为：Mij = I[ds(i,j) ≤ ri·ϕ(|fj−fi|)]，即查询中心圆形区域在时间衰减下的并集。

**（3）高效半径掩码与熵提取（Efficient Radius Masking and Entropy）**
- 设计**Flash Radius Mask内核**：将视频帧划分为tile并按tile-major顺序重排令牌，融合距离计算、半径比较、块剪枝和令牌投票，一步构造块稀疏掩码，供FlashInfer后端执行。
- 设计**融合注意力熵内核**：利用恒等式 Hi = log Zi − Σ pij sij，在在线softmax过程中同时累计熵，无需显式物化完整注意力矩阵。
- **预热复用策略**：仅在去噪过程前25%的密集步骤中计算熵，后续稀疏步骤直接复用已有的预算、半径和掩码，大幅降低决策开销。

## 6. 论文的主要结论与发现

1. **令牌特定稀疏性**：视频注意力中，保留密度因查询而异，与注意力熵存在稳定的对数线性关系，提出了新的令牌级稀疏注意力机制。
2. **TRA的有效性**：在全部七个配置上，TRA均取得了稀疏方法中最好的VBench Overall分数，且获得最高的加速比。
3. **大幅降低计算开销**：仅保留**9%–19%**的注意力交互，即可实现**1.56×–2.05×**的端到端加速比。
4. **质量保持**：TRA在多个模型上接近密集注意力的生成质量（如Wan2.1-14B上TRA 87.39 vs Dense 87.41），同时实现1.75×加速。
5. **内核效率**：Flash Radius Mask和Fused Attention Entropy分别实现10.35×和12.34×的自身加速。
6. **普适性验证**：熵-预算关系和令牌半径注意力模式在HunyuanVideo模型上同样成立，R²=0.978–0.993，证明了发现的一般性。

## 8. 不足与局限

### 模式限制
- TRA的稀疏支撑仍被约束为**预定义的、基于距离的模式**（圆形邻域+固定时间衰减率），无法捕捉内容相关的非局域交互（如远距离物体对应关系、非局域运动、场景相关的注意力结构）。
- 使用固定的时间衰减因子，无法自适应不同场景的动态特性。

### 内核效率瓶颈
- TRA目前仍通过**块稀疏后端**间接执行令牌级稀疏，块内存在冗余计算；论文承认，缺乏专门的令牌级稀疏注意力内核限制了实际性能提升空间。

### 实验覆盖的局限
- 实验集中在**Wan系列和HunyuanVideo**，对其他主流视频生成模型（如CogVideoX、Seedance等）的验证不足。
- 分辨率仅在720×1280下测试，更高分辨率或更长时间视频的泛化能力尚未验证。

### 对比公平性
- Radial方法的对比设置（较低分辨率与帧数）造成了不完全公平的比较条件。
- 对SVG/SVG2超参数可能未充分调优，存在对比偏差风险。

### 熵复用的潜在风险
- 熵估计仅在预热阶段计算并后续全程复用，虽然证明了跨步稳定性（最小余弦相似度0.945），但极端长序列或内容剧烈变化的场景下，熵的相对分布可能漂移，影响预算估计准确性。
