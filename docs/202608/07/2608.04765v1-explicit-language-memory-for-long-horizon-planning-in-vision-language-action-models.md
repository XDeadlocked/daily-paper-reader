## 摘要
视觉-语言-动作（VLA）模型为连接视觉感知、语言理解和机器人控制提供了统一范式。然而，现有VLA模型在长时程任务中仍面临重大挑战：稀疏的专家示范限制了跨任务的组合泛化；长时程任务的非马尔可夫性质使得仅以当前观测为条件的策略难以维持时间一致性；有限的闭环纠错能力导致执行误差不断累积；端到端的动作微调可能削弱视觉-语言模型（VLM）骨干网络的高层语义表示。为解决这些问题，我们提出了一种带有显式语言记忆模块的分层长时程VLA架构。其核心思想是将离散的时间观测转换为具有时间逻辑的连贯文本记忆序列。该系统被解耦为高层VLM和低层VLA：高层VLM通过视觉问答训练范式进行语义推理，而低层VLA在子任务指令和视觉观测的条件下执行精确的连续控制。高层VLM利用先前的记忆作为上下文锚点，递归更新语言记忆和子任务指令，从而在长时程执行过程中实现持续的时间跟踪和动态纠正。我们在多个仿真环境中评估了所提出的方法，并在真实机器人平台上进行了仿真到现实的实验。结果表明，显式语言记忆提高了VLA模型在复杂长时程任务中的成功率和鲁棒性，同时为决策过程提供了可解释的语义说明。

## Abstract
Vision-language-action (VLA) models provide a unified paradigm for connecting visual perception, language understanding, and robotic control. However, existing VLA models still face major challenges in long-horizon tasks: sparse expert demonstrations constrain cross-task compositional generalization; the non-Markovian nature of long-horizon tasks makes it difficult for policies conditioned only on current observations to maintain temporal consistency; limited closed-loop error correction allows execution errors to accumulate; and end-to-end action fine-tuning may weaken the high-level semantic representations of vision-language model (VLM) backbones. To address these issues, we propose a hierarchical long-horizon VLA architecture with an explicit language-memory module. The central idea is to convert discrete temporal observations into a coherent textual memory sequence with temporal logic. The system is decoupled into a high-level VLM and a low-level VLA: the high-level VLM performs semantic reasoning through a visual question answering training paradigm, while the low-level VLA executes precise continuous control conditioned on subtask instructions and visual observations. The high-level VLM recursively updates both language memory and subtask instructions using the previous memory as a contextual anchor, enabling persistent temporal tracking and dynamic correction during long-horizon execution. We evaluate the proposed method in multiple simulation environments and conduct sim-to-real experiments on a real robotic platform. The results demonstrate that explicit language memory improves the success rate and robustness of VLA models on complex long-horizon tasks while providing an interpretable semantic account of the decision process.

## 2. 方法论

### 2.1 核心思想

将策略分解为**高层语义规划**与**低层动作生成**两个解耦分支，中间通过**递归更新的语言记忆**连接：

- 高层 VLM 读取全局指令、当前观测和上一时刻的记忆，输出**更新后的记忆**和**当前子任务指令**；
- 低层 VLA 接收当前观测和子任务指令，生成固定视界（H = 30）的连续动作块；
- 语言记忆采用**滚动压缩机制**：未完成的子任务保留细节（目标对象属性、位置等），完成后压缩为过去式摘要，注意力转移至下一阶段。

### 2.2 公式与算法流程

策略分解形式为：

\[
\pi(a_{t:t+H}, s_t, m_t \mid o_t, m_{t-1}, l) = \pi_{LL}(a_{t:t+H} \mid o_t, s_t) \cdot \pi_{HL}(s_t, m_t \mid o_t, m_{t-1}, l)
\]

- \(\pi_{HL}\)（高层）：递归更新记忆 \(m_t\) 并预测子任务 \(s_t\)；
- \(\pi_{LL}\)（低层）：以子任务为条件生成连续动作块。

训练目标分为两部分：

- **高层分支**：自回归预测记忆与子任务的对数似然损失；
- **低层分支**：基于流匹配（flow matching）的动作生成损失（仿照 π0.5 的动作专家）。

### 2.3 自动监督标注管线

为了获得可训练的记忆与子任务标注：

- 将专家视频按时间戳切分为帧，并匹配技能级标注；
- 使用通用 VLM（Gemini 3.5 Flash API 或本地 Qwen3.5-9B）为每一帧生成两段输出：
  1. 简洁的子任务（格式为“动作 + 目标对象 + 上下文”）；
  2. 第一人称语言记忆（完成技能用过去式、下一技能用未来式表述）；
- 提示词中明确要求避免使用“帧/序列/索引”等实现术语。

### 2.4 闭环推理

推理时记忆初始化为空，循环执行：获取观测 → 高层更新 \((m_t, s_t)\) → 低层生成动作块 → 执行 → 直至高层判断任务完成。由于记忆与子任务均为可见文本，整个过程可生成**可解释的决策日志**。

## 6. 主要结论

- 显式语言记忆在多个场景下**稳定提升了阶段平均成功率**：
  - 打开收音机：30.0% → 40.0%；
  - 单包裹分拣：41.7% → 63.9%；
  - 连续包裹分拣：31.3% → 46.9%；
  - 真实 XLeRobot：62.5% → 66.3%。
- 记忆约束了**阶段转换的一致性**：基线经常提前推进到下一阶段（如漏掉按钮按压、跳过扫码），而记忆模型只有在观测证据支持当前里程碑完成时才推进。
- 记忆提供了**可解释性**：可以通过文本日志定位决策失败发生的环节；
- 记忆支持了**上下文内失败恢复**：真实机器人上观察到“抓取失败 → 记录失败状态 → 重新尝试抓取”的行为模式；
- **语义记忆与运动控制能力是互补的**：记忆能解决“该做什么”，但无法改善接触丰富动作（如按按钮）的几何对齐与力控精度。

## 7. 优点

- **架构设计清晰**：将高层语义决策与低层连续控制解耦，两个分支独立优化，避免了多目标联合训练的困难；
- **记忆表示紧凑可解释**：以自然语言为记忆载体，天然支持人机交互、失败诊断和事后审计；
- **自动标注管线实用**：利用通用 VLM（Gemini / Qwen）自动生成帧级记忆与子任务监督信号，降低了人工标注成本；
- **滚动压缩机制合理**：只保留有助于当前/下一步决策的信息，记忆长度有界，避免视觉历史拼接带来的上下文与计算成本；
- **跨场景验证**：覆盖两种仿真环境与真实机器人平台，初步验证了方法的可迁移性；
- **问题定性准确**：明确指出语言记忆的适用边界——不能替代低层控制精度，有助于后续研究聚焦。

## 8. 不足与局限

- **真实实验规模有限**：仅 25 条训练轨迹、20 次评估；任务只有 4 个阶段，未验证数分钟级、多对象、多交互的复杂长时程任务；
- **统计报告不完整**：无置信区间、无多种子方差、无显著性检验；
- **对比方法单一**：仅与 π0.5 比较，未与 RT-2、OpenVLA、MemoryVLA、HAMLET 等现有带记忆机制的方法横向对比；
- **消融不足**：未单独验证“记忆的有无可解释差异”之外的因素（如记忆长度、高层模型规模、VQA 训练范式 vs. 其他监督形式）；
- **计算开销增加**：推理时每次决策前需额外调用一次高层 VLM，增加了延迟与部署复杂度；
- **接触丰富任务仍困难**：PressOn 阶段成功率仅 10%，说明语义记忆无法弥补低层控制的不足；
- **恢复能力依赖数据**：失败恢复的案例是偶然观察而非系统性的演示覆盖，实际可靠性未经量化评估；
- **语言记忆的信息损失**：文本压缩可能丢失某些视觉细节（如物体精确位姿、空间关系），对需要精确定位的操纵任务可能存在潜在瓶颈。
