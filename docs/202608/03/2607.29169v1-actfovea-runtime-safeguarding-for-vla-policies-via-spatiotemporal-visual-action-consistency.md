## 摘要
视觉-语言-动作（VLA）策略在机器人操作中表现出强大性能，但仍易受运行时扰动影响，这些扰动会破坏视觉观测、机器人状态与执行动作之间的时间对齐。我们提出ActFovea，一种即插即用的防护框架，无需重新训练或修改底层VLA策略即可检测并缓解此类故障。ActFovea利用机器人运动学、本体感觉状态和近期动作来构建动作条件化的中央凹区域，该区域保留接触相关区域和预测运动走廊，同时抑制与任务无关的视觉内容。它通过评估视觉运动与观测新鲜度是否与几何、本体感觉及动作转换保持一致来检测运行时风险。对于可恢复的扰动，ActFovea构建扰动特定的候选观测，并在验证所得动作块后接受恢复。当陈旧或重放的观测使得可靠恢复不可能时，它调用有界的安全失败程序。在跨多个LIBERO套件的π0闭环评估中，ActFovea将局部视觉叠加下的成功率从49.3%提高到90.3%，缩小了与干净性能差距的93.7%。在动作漂移和视觉延迟情况下，它分别将成功率提高了7.0和9.8个百分点，同时保持干净任务性能。在冻结观测重放下，ActFovea在所有试验中均触发及时的安全失败，无未受保护失败。这些结果表明，时空视觉-动作一致性为VLA策略的运行时防护提供了有效基础。

## Abstract
Vision-language-action (VLA) policies achieve strong performance in robotic manipulation but remain vulnerable to runtime disturbances that break the temporal alignment among visual observations, robot states, and executed actions. We introduce ActFovea, a plug-and-play safeguarding framework that detects and mitigates such failures without retraining or modifying the underlying VLA policy. ActFovea uses robot kinematics, proprioceptive states, and recent actions to construct action-conditioned foveated regions that retain contact-relevant areas and predicted motion corridors while suppressing task-irrelevant visual content. It detects runtime risks by evaluating whether visual motion and observation freshness remain consistent with geometric, proprioceptive, and action transitions. For recoverable disturbances, ActFovea constructs disturbance-specific candidate observations and accepts a recovery only after verifying the resulting action chunk. When stale or replayed observations make reliable recovery impossible, it invokes a bounded safe-failure procedure. In closed-loop evaluations of $π_0$ across multiple LIBERO suites, ActFovea increases success under localized visual overlays from 49.3\% to 90.3\%, closing 93.7\% of the gap to clean performance. It further improves success under action drift and visual delay by 7.0 and 9.8 percentage points, respectively, while preserving clean-task performance. Under frozen-observation replay, ActFovea triggers timely safe failure in all trials, with no unprotected failures. These results demonstrate that spatiotemporal visual-action consistency provides an effective basis for runtime safeguarding of VLA policies.

## 2. 论文提出的方法论

### 2.1 核心思想

- 将空间视觉损坏、时间错位、动作轨迹漂移和观测重放统一建模为**对时空视觉-动作一致性的违背**。
- 构建**动作条件化中央凹区域（action-conditioned foveated regions）**：根据机器人运动学、本体感觉状态和动作历史，预测接触关键区域和运动走廊，仅对该区域保留高保真视觉信息，抑制与任务无关的背景视觉内容。
- 通过**一致性监控**检测风险；对可恢复扰动构建**扰动条件化的候选观测**，并在**验证动作块**后执行恢复；对不可恢复状态（如冻结重放），触发**有界安全失败**。

### 2.2 关键技术细节

#### ① 动作条件化中央凹与一致性监控

- 对每个摄像头视角 $v$，基于正运动学（或常速度外推）估计接触中心 $c_t^v$ 和运动走廊 $\Gamma_t^v$。
- 生成保留掩模：$M_t^v = \text{Dilate}(M_{c,t}^v \lor M_{\Gamma,t}^v, r_m)$，保留接触区域和运动走廊，其余背景做模糊/灰度化处理（公式3）。
- 一致性监控综合以下证据：
  - 几何一致性（观测中心与投影接触中心的距离）；
  - 动态一致性（预测与观测的图像位移方向、大小是否一致）；
  - 时间证据（时间戳健康度、缺失局部运动、滞后估计、全局重放相似度）；
  - 动作-本体感觉一致性。
- 最终风险分数：$R_t = \text{clip}(\beta\bar r_t + (1-\beta)r_t + p_t^{cam} + p_t^{lag} + p_t^{cal}, 0, 1)$（公式4）。
- 一个确定性路由器（deterministic router）基于上述证据将状态分类为：一致、可恢复（空间/时间/动作侧）、未知、不可恢复。

#### ② 一致性引导的恢复与动作验证

- **候选观测库**：对可恢复扰动，构建候选观测（原始/中央凹化后/有限视觉延迟的时间对齐版本）。对视觉覆盖，使用从干净参考帧估计的混合模式 $\hat Q_t^v$ 和混合系数 $\hat\alpha_t^v$ 进行重建（公式5）。
- **动作块验证**：每个候选观测输入策略后，验证得分 $V_k = \text{clip}(w^\top u_k + b_k, 0, 1)$（公式6），其中 $u_k$ 包含首次动作方向、端点方向、运动幅度、平滑度、水平、块漂移等一致性指标。
- 仅在验证通过后，才接受恢复后的动作块。原始动作作为保守回退选项。

#### ③ 风险自适应执行与安全失败

- 两级仲裁：一致性监控决定保留/阻尼/缩短/保持等模式，动作验证进一步选择正常执行/短水平执行/伺服恢复/安全失败。
- 最终动作执行：$\hat a_{t,i}^{mot} = \lambda_t^{mon} \lambda_t^{ver} a_{t,i}^{\star, mot}$，并取较短的水平 $h_t = \min(h_t^{mon}, h_t^{ver})$（公式7）。
- 当冻结重放等不可恢复状态被确认，触发**有界安全失败**（保守运动抑制），而非无限期执行无效动作。

## 6. 论文的主要结论与发现

1. **统一防护可行**：同一套ActFovea流程可同时应对空间视觉损坏、有限时间错位和动作轨迹漂移，无需针对每种扰动单独设计规则。
2. **显著恢复性能**：
   - 局部视觉叠加下，成功率从 **49.3% → 90.3%**（+41.0个百分点，恢复93.7%的性能损失）。
   - 视觉延迟下，成功率从76.2% → 86.0%（+9.8个百分点）。
   - 动作漂移下，成功率从83.1% → 90.1%（+7.0个百分点）。
3. **干净性能保持**：未扰动场景下成功率与Base VLA持平甚至略高（93.8% vs 93.0%）。
4. **有界安全失败有效**：冻结观测重放下的2000个episodes全部实现及时安全失败（100%），无未受保护失败，且后检测动作数从259.2降至2.0，累计运动范数降低99.87%。
5. **组件分工明确**：
   - **观测恢复**（恢复库、候选扩展）是空间覆盖修复的主要机制；
   - **动作验证**是时间与动作侧恢复的核心保障；
   - **威胁类型识别**对视觉延迟场景至关重要。

## 7. 优点

- **即插即用**：不修改或重训练底层VLA策略，通过观测-动作接口进行防护，部署成本低。
- **统一框架**：将多类异构扰动纳入一个基于“时空视觉-动作一致性”的通用框架，而非堆叠多个专用模块。
- **可恢复性感知**：区分可恢复与不可恢复状态，避免对每种异常都做保守响应（过度抑制）或无限期尝试恢复（失控风险）。
- **有界安全失败**：在证据不足时触发受控的运动抑制，以有界终止替代不可控行为，并设计了等待/释放机制。
- **消融分析完整**：清楚地分离了各组件在不同扰动下的贡献，帮助理解机制的工作方式。

## 8. 不足与局限

- **模型泛化有限**：仅使用π0（虽然π0是强VLA代表），未在多模型上验证，框架是否对其他VLA架构（如OpenVLA、RT-2系列、Octo等）同样有效未能说明。
- **环境覆盖有限**：实验仅在LIBERO仿真基准上完成，未在真实机器人平台验证；对真实世界中的噪声、校准误差、动态遮挡等会否影响效果不明确。
- **扰动类型有限**：每类扰动只设置了一种实现方式（如固定3帧延迟、单一叠加模式）；被“扰动标签与参数不可见”的设定是可取的，但扰动参数本身的多样性有限。
- **依赖固定常量**：多个加权参数（β、风险分数权重、验证分数权重w和偏置b_k）为固定实现常量，其在不同任务族或不同模型上的最优配置是否变化未做敏感性分析。
- **应用范围限制**：论文明确承认“形式化碰撞避免保证不在本机制范围内”；安全失败仅代表保守运动抑制，在动态环境中可能不足以保证安全。
- **延迟开销**：在验证最高优先级候选失败后会扩展搜索（多次策略调用），其引起的推理延迟在实时部署中的影响未被定量评估。
