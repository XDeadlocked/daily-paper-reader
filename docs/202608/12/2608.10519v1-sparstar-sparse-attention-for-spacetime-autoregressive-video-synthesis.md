## 摘要
InfinityStar通过一系列图像和片段金字塔将视觉自回归生成扩展到视频。然而，其不断变化的尺度和跨片段上下文使得后期尺度的注意力成本高昂，并且使得从扩散模型或图像VAR模型复用的稀疏模式变得不可靠。我们提出了SparSTAR，一种针对此场景定制的免训练块稀疏注意力方法。在每个高开销的尺度和注意力头上，SparSTAR从当前的查询和键激活中对连续的键块进行评分，保留所需的条件上下文，并通过仅前向的稀疏路径执行选中的块。我们分析了片段内的跨尺度一致性、跨片段边界的模式持续性，以及随着复用范围扩展到越来越远的尺度时的质量退化。在这些分析中，重要的键块发生偏移，表明在每个目标尺度重新计算块选择比复用迁移的掩码更可靠。在720p文本到视频和图像到视频生成任务上，SparSTAR保留了每个token和细化尺度，同时提供约1.6倍的端到端加速，并保持VBench和成对输出重建保真度接近密集的InfinityStar。

## Abstract
InfinityStar extends visual autoregressive generation to video through a sequence of image and clip pyramids. Its changing scale and cross-clip context, however, leave late-scale attention costly and make sparse patterns reused from diffusion or image VAR models unreliable. We introduce SparSTAR, a training-free block-sparse attention method tailored to this setting. At each expensive scale and attention head, SparSTAR scores contiguous key blocks from the current query and key activations, retains required conditioning context, and executes the selected blocks through a forward-only sparse path. We analyze cross-scale consistency within a clip, pattern persistence across clip boundaries, and quality degradation as reuse spans increasingly distant scales. Across these analyses, important key blocks shift, showing that recomputing block selection at each target scale is more reliable than reusing a transferred mask. On 720p text-to-video and image-to-video generation, SparSTAR preserves every token and refinement scale while providing about a 1.6x end-to-end speedup and maintaining VBench and paired-output reconstruction fidelity close to dense InfinityStar.

## 一、核心问题与研究动机

- **背景**：InfinityStar 将视觉自回归（VAR）生成范式扩展到视频，通过"图像金字塔 + 片段（clip）金字塔"逐步细化生成。尽管其 Spacetime Sparse Attention（SSA）已通过限制历史视觉上下文来降低 KV 累积，但在高分辨率（如 720p）下，当前片段每个尺度的注意力仍需密集计算，最终尺度单帧就包含 72,000 个 token，注意力成本依然极为高昂。
- **核心问题**：从扩散模型或图像 VAR 模型迁移来的稀疏注意力模式（如静态能量衰减先验、跨尺度掩码迁移）在 InfinityStar 中并不可靠。其原因是：视频 VAR 的每个自回归尺度只被评估一次，token 分辨率、数量与 KV 组成随尺度动态变化；跨片段边界时上下文也发生改变。
- **整体含义**：需要一种专门针对 STAR（Spacetime AutoRegressive）视频生成模型的、免训练的稀疏注意力方法，既要降低后期高成本尺度的注意力开销，又要避免因复用旧掩码造成的质量损失。

## 二、方法论：SparSTAR 的提出

### 2.1 核心思想

SparSTAR 的核心在于**在每个目标尺度、每个注意力头上，基于当前的 Query（Q）与 Key（K）激活动态构建块稀疏掩码**，而不是将稀疏模式从一个尺度迁移到另一个尺度。模型权重不变，所有 token 和细化尺度均被保留。

### 2.2 关键技术细节

- **原始顺序块划分**：将 Q 和 K 按注意力核执行顺序划分为连续的候选块（每块 b=128 token），保持时空栅格光栅顺序，与分块执行粒度对齐。
- **聚合 Query–Key 块评分器**：对每个块内 token 向量做均值池化，得到块级向量 $\bar{q}_i$ 和 $\bar{k}_j$，计算块间兼容性分数 $S_{ij} = \tau \bar{q}_i^\top \bar{k}_j$（其中 $\tau = D^{-1/2}$）。分数仅用于排序，而非近似 softmax 后的注意力质量。
- **Clip 相关的保留/可select块策略**：
  - Clip 1：文本块和最终图像金字塔块保持稠密，只对当前尺度块打分。
  - Clip ≥ 2：仅文本块保持稠密；前一 clip 的最终尺度参考块与当前尺度块在统一预算下联合排序。
  - 形式化：保留集 $J_{\text{keep}}^{(c)}$ 与可select集 $J_{\text{sel}}^{(c)}$，每个查询块的保留键块集合为 $A_i = J_{\text{keep}}^{(c)} \cup \text{TopKIdx}_{j \in J_{\text{sel}}^{(c)}}(S_{ij}, k_{c,s})$。
- **尺度相关密度调度**：采用递减密度策略（如 720p 下四个稀疏化尺度 s26–s29 的密度为 0.625、0.1875、0.1875、0.09375），对 token 数最少的较快尺度保留较大密度，对开销最高的 72,000-token 最终尺度施加最激进的稀疏率。
- **前向仅执行路径（FastFlex）**：基于 FlexAttention 实现，仅写前向所需的 `kv_num_blocks` 和 `kv_indices`，省略后向才需要的 `q_num_blocks` 和 `q_indices`，避免构建推理阶段永不消费的反向索引结构。
- **开销**：选择器算术约为稠密 QK 点积的 0.016%；选择与掩码构建的端到端开销低于 1.7%。

## 六、主要结论与发现

1. **跨尺度模式复用不可靠**：直接复用决策尺度的稀疏模式可使注意力质量平均损失约 35.6%，甚至低于朴素 Sliding Window；而每个尺度重新计算块 Top-K 仅损失 4.64%。
2. **跨 clip 边界模式部分失效**：15% 参考上下文预算下，新鲜选择保留 85% 注意力质量，而复用旧 clip 的模式仅保留 56%。
3. **尺度距离影响显著**：每个尺度重新计算模式比单次迁移 PSNR 提升 1.73 dB，仅增加 0.30 s 延迟；说明动态重计算带来的收益远超其额外开销。
4. **SparSTAR 主结果**：720p T2V 加速 1.60×、I2V 1.62×，VBench 与稠密模型差距仅 0.04–0.08 分；重建保真度显著优于已发布的加速基线（T2V PSNR 比 FastSTAR 高 2.92 dB、I2V 高 2.31 dB）。
5. **密度调度方向**：递减密度（早期尺度保留较多连接、后期尺度激进稀疏）是最优策略；后期尺度虽 token 多，但其错误局部化，早期结构错误的破坏性更强。
6. **组合加速可行性**：与 CFG 分支跳过（Guidance-off）组合可达 2.50× 加速，且质量保持优于直接跳过细化尺度的方案。

## 七、方法亮点与优点

- **免训练、即插即用**：无需微调或改变模型权重，可直接应用于推理管线。
- **保留完整生成轨迹**：区别于 token 剪枝/合并类方法，所有 token 和所有细化尺度都被保留，只是减少注意力连接，因此输出更接近稠密参考。
- **充分的实证分析驱动设计**：论文以三项系统性分析（片段内一致性、跨片段持续性、尺度距离效应）作为方法论基础，设计决策有据可依。
