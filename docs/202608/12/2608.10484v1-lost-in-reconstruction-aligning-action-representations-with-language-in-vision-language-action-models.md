## 摘要
动作动词不仅描述动作的物理结果，还描述这些动作是如何执行的。然而，视觉-语言-动作模型（VLA）中的动作表征通常是在原始动作空间中通过L1/L2损失进行重建优化的，其中数值接近性未必反映语言上有意义的区别。在BridgeV2上，我们表明动作轨迹包含超出视觉状态变化的动词基础信息，并且仅重建的离散分词会系统地侵蚀这些信息。为了解决这个问题，我们引入了SALT，一种语义对齐的动作分词器，它通过一个辅助目标增强VQ-VAE风格的分词器，要求冻结的视觉-语言模型从量化后的动作潜变量中恢复出剧集指令。使用SALT训练的策略在SimplerEnv中实现了71.9%的平均成功率，而仅重建的VQ-VAE分词器为42.7%，FAST为31.2%。SALT还发展了动词专用代码，同时保持重建保真度。这些结果表明，机器人动作轨迹提供了语言基础的一个来源，并且在动作表征中保留这种结构可以显著改善语言条件控制。

## Abstract
Action verbs describe not only the physical outcomes of actions, but also how those actions are performed. Yet action representations in vision-language-action models (VLAs) are typically optimized for reconstruction under L1/L2 losses in raw action space, where numerical proximity need not reflect linguistically meaningful distinctions. On BridgeV2, we show that action trajectories contain verb-grounding information beyond visual state changes, and that reconstruction-only discrete tokenization systematically erodes this information. To address this problem, we introduce SALT, a Semantically ALigned action Tokenizer that augments a VQ-VAE-style tokenizer with an auxiliary objective requiring a frozen vision-language model to recover the episode instruction from quantized action latents. Policies trained with SALT achieve 71.9% average success in SimplerEnv, compared with 42.7% for a reconstruction-only VQ-VAE tokenizer and 31.2% for FAST. SALT also develops verb-specialized codes while maintaining reconstruction fidelity. These results show that robot action trajectories provide a source of language grounding and that preserving this structure in action representations can substantially improve language-conditioned control.

## 1. 核心问题与整体含义（研究动机与背景）

- **语言接地问题**：语言如何从具身经验中获得意义？具体而言，动作模态是否为动词提供了视觉输入无法提供的额外接地信号？
- **现有 VLA 的缺陷**：视觉-语言-动作模型（VLA）通常将语言仅作为目标条件（如指定物体颜色、形状、位置），动作表征通过 L1/L2 损失在原始动作空间中进行重建优化，**数值上的接近并不等同于语言上有意义的区分**。
- **核心矛盾**：动词既描述动作目标（结果的视觉变化），也描述运动动力学（动作如何执行，如轨迹形状、接触模式、夹爪时机）。仅重建目标的动作表征在设计上没有明确与语言抽象对齐，形成**语言–控制之间的瓶颈**。
- **核心论断**：机器人动作轨迹本身是语言接地的重要来源；若在动作表征中保留这种语言相关结构，可以显著改善语言条件下的机器人控制。

## 2. 方法论：SALT（Semantically ALigned action Tokenizer）

### 核心思想
- **在分词器训练阶段注入语义对齐压力**：仅改变动作词汇表的生成方式，不改变下游 VLA 训练流程和策略对 token 的使用方式。
- 利用**生成式对齐目标**——让冻结的预训练语言模型（pLM）从量化后的动作潜变量中生成相应的任务指令，从而迫使动作表征保留对语言有意义的信息。

### 技术细节
- **基础架构**：残差 VQ-VAE（residual VQ-VAE）动作分词器，8 步动作块（chunk），7 个残差组，每组 256 个码字，即每个 chunk 产生 7 个 token ID。
- **量化潜变量**：对每个动作块，将 K 个码本向量求和得到量化潜变量 $q_i = \sum_{k=1}^K e^{(k)}_{z_{i,k}}$。
- **对齐目标**（核心创新）：
  - 一个 episode 分为 M 个动作块，得到量化潜变量 $q_{1:M}$。
  - 将潜变量维度匹配 LM 嵌入维度，转化为 soft prefix embedding：$p_i = g \cdot q_i + PE(i)$（g 为学习标量增益，PE 为位置编码）。
  - 前缀序列 P 与文本提示 s 一起输入冻结的 pLM，使其预测 episode 的指令 $w_{1:L}$。
  - 对齐损失：$L_{align} = -\frac{1}{L}\sum_{t=1}^L \log p_{LM}(w_t | w_{<t}, P, s)$
- **总训练目标**：$L = L_{recon} + L_{VQ} + \lambda L_{align}$，其中 $L_{recon}$ 为动作重建损失，$L_{VQ}$ 为码本与承诺损失（VQ-VAE 标准项）。
- **梯度传播**：LM 保持冻结，梯度经直通估计器（straight-through estimator）传播到分词器编码器和码本。
- **无需预定义动词清单**：直接对自由形式指令操作，不需要文本编码器或对比学习的负样本对。
- **推理时**：分词器训练完成后 LM 被丢弃，分词器冻结；下游 VLA 正常预测离散码本索引，经解码器转为连续动作。

## 3. 实验设计

### 数据集
- **BridgeV2**（Walke et al., 2023）：遥操作真实机器人操作数据集，配备自由形式自然语言指令（WidowX 250 六自由度机械臂 + 平行夹爪）。
- 经 SpaCy 依存解析提取指令动词，词形还原后过滤，保留 **17 个动词类别**，覆盖 **27,271 个 episode**（90/10 划分训练/验证）。
- 类别高度不均衡：move 和 put 占 65% 的 episode。

### 评估环境（Benchmark）

- 使用 8 步动作块的开环执行。

## 6. 主要结论与发现

1. **动作轨迹包含视觉无法捕捉的动词接地信息**：在 BridgeV2 上，运动动态对动词信息贡献约 0.059 bits（超出视觉目标变化），视觉目标贡献约 0.282 bits（超出运动动态）；move、put、push 等动词的"方式"信息仅存在于轨迹中。
2. **仅重建的分词会侵蚀动词信息**：Bin、VQ-VAE、FAST 分词器的动词互信息均低于连续轨迹参考值（1.26 bits），且压缩越强损失越大；下游策略训练无法完全恢复丢失结构。
3. **SALT 显著提升下游任务性能**：SimplerEnv 平均成功率 71.9%（VQ-VAE 42.7%、FAST 31.2%），在全部 4 个任务上均领先。
4. **语义结构在下游迁移**：SALT 的 token ID 探针达到 58.7% 准确率，与连续动作参考（58.0%）持平；策略动作嵌入中也保留较高动词可解码性。
5. **语义对齐不牺牲重建保真度**：SALT 的重建误差（0.088）与 VQ-VAE（0.080）接近。
6. **动词专用代码涌现**：SALT 的码字呈现高选择性（如 flip 的代码 98% 对应翻转动作），而 VQ-VAE 和 FAST 的码字语义混杂；SALT 还能将同义不同措辞的指令（如 "lever vertical to front" 与 turn）归为同一类别。

## 7. 优点

- **问题切入精准**：揭示了对 VLA 研究中被忽视的"动作接口"语义对齐问题，而不仅是视觉-语言对齐。
- **方法轻量且克制**：SALT 仅在分词器训练阶段介入，不改变下游 VLA 架构，即插即用（drop-in）。
- **无需额外标注**：直接利用已有的自由形式指令，不需要动词清单、文本编码器或对比学习负样本。
- **诊断方法严谨**：使用互信息估计、控制任务、分层交叉验证、R² 共同性分解等多种手段交叉验证；匹配的 Transformer 探针在三种模态条件下保证公平比较。
- **评估隔离变量**：SALT vs VQ-VAE 的唯一差异就是对齐损失，因果归因清晰。
- **效果全面**：不仅提升任务成功率，还产生更可解释的动作词汇表；重建保真度、特征运动学签名保持良好。

## 8. 不足与局限

- **语言多样性有限**：BridgeV2 过滤后仅 17 个动词类别，且分布严重偏斜（move+put 占 65%），难以全面测试语义分词在更丰富语言下的收益。
- **适用范围受限**：SALT 仅适用于具有可学习潜变量的分词器（如 VQ-VAE）；对固定离散化方法（Bin）或信号处理方法（FAST）的扩展仍是开放问题。
- **实验规模有限**：仅使用 0.5B 的小型 VLA、单一训练数据集、SimplerEnv 模拟评估，缺少大规模多本体预训练和真实机器人部署验证。
- **因果机制未建立**：语义对齐改善了任务表现并产生更可解释的词汇表，但两者之间的因果机制（语义化动作码如何影响策略学习）尚未明确证明。
- **分类器探针的固有风险**：探针仅反映线性可分离的信息，可能低估或高估实际语言对齐程度。
- **动词信息的操作化定义**：以视觉首尾帧变化作为"动作目标"、以 7-DoF 轨迹作为"运动动态"，可能未完全涵盖动词语义的全部维度（如力、物体语义等）。
