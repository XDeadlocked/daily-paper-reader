## 摘要
视觉-语言-动作（VLA）模型在机器人操作中展现出有效性，然而如pi0.5等最先进的模型仍运行于单帧范式下，这限制了其保留历史观察并发展精确空间感知的能力。本文提出StreamPI，一种流式多模态时序建模框架，在不引入任何额外参数的情况下，赋予单帧VLA时序推理能力。核心设计之一是指令锚定的时序建模。它将每个（视觉观察，语言指令）对视为一个原子时序单元：对内的双向注意力实现跨模态融合，而跨对的因果注意力保持自回归流式推理。这确保了语言指令在整个任务执行过程中作为持久的语义锚点。为弥合同步训练与异步真实机器人部署之间的差距，我们引入一种随机间隔流式训练策略：适当的帧间间隔（如每3帧）可实现更快更平滑的动作执行。此外，随机化间隔进一步提高了对帧时序扰动的鲁棒性，支持实际中的异步部署。进一步地，借助LLM骨干的长度外推能力，StreamPI无缝继承预训练的单帧权重，并支持灵活的单帧与多帧推理。在涵盖记忆依赖与精确感知场景的真实机器人任务以及仿真基准LIBERO上的实验表明，StreamPI在多种任务上优于pi0.5。

## Abstract
Vision-Language-Action (VLA) models have demonstrated effectiveness in robot manipulation, yet state-of-the-art models such as pi0.5 operate under a single-frame paradigm, limiting their ability to retain past observations and develop precise spatial perception. In this paper, we propose StreamPI, a streaming multimodal temporal modeling framework that equips single-frame VLA with temporal reasoning capability without introducing any additional parameters. One core design is instruction-anchored temporal modeling. It treats each (visual observation, language instruction) pair as an atomic temporal unit: bidirectional attention within each pair enables cross-modal fusion, while causal attention across pairs preserves autoregressive streaming inference. This ensures the language instruction serves as a persistent semantic anchor throughout task execution. To bridge the gap between synchronous training and asynchronous real-robot deployment, we introduce a andom-interval streaming training strategy: a proper inter-frame interval (e.g., every 3 frames) enables faster and smoother action execution. Beyond this, randomizing the interval further improves robustness to frame-timing perturbations, supporting asynchronous deployment in practice. Furthermore, by leveraging the length extrapolation capability of the LLM backbone, StreamPI seamlessly inherits pretrained single-frame weights and supports flexible single-frame and multi-frame inference. Experiments on real-robot tasks spanning memory-dependent and precise perception scenarios, as well as the simulation benchmark LIBERO, demonstrate that StreamPI outperforms pi0.5 across diverse tasks.

## 1. 论文的核心问题与整体含义（研究动机与背景）

- **背景**：视觉-语言-动作（VLA）模型已成为通用机器人操作的主流范式，将感知、语言理解与动作生成统一在端到端框架中。然而，主流的强 VLA 模型（如 π0、π0.5）采用**单帧推理范式**——每一步仅基于当前单张图像预测动作，不访问任何历史上下文。
- **核心问题**：单帧范式本质上缺失两方面的关键能力：
  1. **时序记忆**：无法基于历史观测进行记忆推理，例如推断物体被藏在哪个杯子下、追踪动态目标。
  2. **精确空间感知**：无法利用多帧聚合产生精确 3D 空间理解（类似自动驾驶中对多帧融合提升 3D 感知的既有共识）。
- **现有多帧方案的不足**：窗口式 VLA 方法（如拼接 K 帧）面临四大挑战——
  1. 计算开销随序列长度线性增长，无法满足实时控制；
  2. 语言指令作为固定 token 被不断增加的视觉 token 稀释，导致"指令遗忘"；
  3. 训练采用固定间隔采样，与真实机器人异步、变帧率的观测流不匹配；
  4. 引入视频编码器等新参数会破坏 VLA 预训练模型的特征分布，导致表示退化。
- **整体含义**：论文旨在为强单帧 VLA 基础模型（π0.5）补充高效、鲁棒的时序推理能力，同时不引入任何额外参数，使模型既能保持预训练表征的完整性，又能同时支持单帧与多帧推理。

## 2. 论文提出的方法论

### 2.1 核心思想：指令锚定的流式时序建模（Instruction-Anchored Temporal Modeling）

- 将每个时间步的输入定义为**原子时序单元**：`u_t = (V_t, l_t)`，其中 `V_t` 为多视角视觉观测，`l_t` 为语言指令。
- 语言指令**持续地与每个观测绑定**，作为整个执行过程中的语义锚点，从机制上防止"指令遗忘"。
- 输入序列由最近的 T 个原子单元构成：`U = [u_{t−T+1}, ..., u_t]`。

### 2.2 注意力结构（两层设计）

- **对内双向注意力（Intra-pair Bidirectional Attention）**：在每个原子单元内部，视觉 token 与文本 token 互相完全可见，充分实现跨模态融合，得到语义落地的表示 `h_τ`。
- **跨对因果注意力（Inter-pair Causal Attention）**：跨时间步的单元之间采用因果注意力，保持自回归流式推理结构，防止未来帧泄露到过去表示。
- **Attention Mask 实现**：通过重构注意力掩码，在既有 VLA 骨干上实现上述层次化注意力模式，不引入新参数。

### 2.3 参数自由的时序扩展

- 借助 LLM 骨干的**长度外推能力**，无缝继承 π0.5 的全部预训练权重，无需任何修改或新增参数。
- 仅需扩展输入 token 序列（多帧输入）、分配扩展位置编码，并用"对内双向 + 跨对因果"掩码约束。
- 同时天然支持测试时的灵活单帧与多帧推理切换。

### 2.4 随机间隔流式训练策略（Random-Interval Streaming Training）

- **随机间隔采样**：给定基础帧间间隔 `δ̄`，添加随机扰动 `ϵ ∼ U(−∆, +∆)`，得到扰动间隔 `δ = δ̄ + ϵ`，裁剪到 `[δ_min, δ_max]`。训练过程中在每个采样步随机化间隔，使模型暴露于多样的时间间距分布，提升对异步部署的鲁棒性。
- **时序掩码（Temporal Masking）**：从全序列中随机掩蔽最早的 k 帧（k ∈ {0, ..., T−1}），模拟流式推理中观测逐步到达的模式。
- **流式推理**：初始时刻编码当前帧并缓存 KV 表示；后续时刻仅编码新到达帧，通过交叉注意力访问缓存的过去表示，消除重复计算。缓存更新为追加新表示，适用于长时程操作。

- **StreamPI 可显著提升单帧 VLA 的时序能力**，且不引入任何额外参数，仅通过重构注意力掩码实现。

- **推理效率**：5 帧流式推理仅比单帧慢 9.2 ms（103.6 ms vs 94.4 ms），满足实时操作需求。

## 7. 优点

- **零额外参数**：完全继承 π0.5 预训练权重，避免新模块带来的表征损坏风险，并保持部署简单性。
- **机制设计巧妙**：将"（观察，指令）"作为原子时序单元是对 VLA 时序建模中"指令遗忘"问题的直接回应；对内双向 + 跨对因果的掩码设计在数学上等价于一种分块因果注意力，兼顾跨模态融合与自回归流式推理。
- **训练-部署一致性**：随机间隔训练 + 时序掩码明确针对真实机器人异步观测流，体现了问题意识上的务实性。
- **推理高效**：KV cache 流式方案使计算开销与时间跨度解耦，支持长时程操作。
- **灵活推理**：借助长度外推，单帧与多帧推理可无缝切换，且跨帧泛化实验表明模型对推理时帧数变化具有鲁棒性。
- **实验覆盖较广**：真实机器人 + 两大仿真基准 + 详细消融 + 推理延迟测量，证据链相对完整。

## 8. 不足与局限

- **训练成本随帧数增长**：训练时需要同时加载所有帧，长时程（如 >100 帧）训练的显存与算力开销将不可接受；论文也将其列为第一项局限。
- **极端异步仍未解决**：随机间隔训练提升了鲁棒性，但无法完全覆盖真实部署中的极端帧时序扰动。
- **LIBERO 基准饱和**：在当前几乎所有方法都超过 95% 的套件上，性能区分度有限；LIBERO-Spatial 的零增益提示时序建模并非对所有任务类型都有益。
