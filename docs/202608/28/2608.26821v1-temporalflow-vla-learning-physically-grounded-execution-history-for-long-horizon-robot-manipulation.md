## 摘要
视觉-语言-动作（VLA）模型利用预训练的视觉-语言表示进行机器人控制，但简单地添加历史帧并不能可靠地捕捉近期的物理变化。这在多阶段操作中尤其成问题，因为视觉上相似的状态可能根据先前的执行情况需要不同的动作。为解决这一挑战，我们提出了TemporalFlow-VLA，它通过物理基础的时间监督来学习紧凑的执行历史。利用记录的机器人状态、机器人几何结构和标定相机，我们构建机器人-表面时间流作为仅训练目标，并监督两个执行对齐的时间查询，为动作专家提供结构化的历史信息。几何监督路径在部署时不进行评估。TemporalFlow-VLA在LIBERO上实现了97.63±0.26%的平均成功率，其中在LIBERO Long上为96.60±0.87%，在12个RoboTwin任务上实现了85.5%/84.2%的清洁/随机化成功率。在更长时程、多阶段操作中，它相比先前方法显示出最明显的优势。受控历史干预表明，动作预测既依赖于历史内容也依赖于时间顺序。通过异步特征缓存，时间条件在无额外历史编码开销的情况下保持了单帧级服务器端采样延迟。总体而言，TemporalFlow-VLA提供了一种紧凑、物理基础的接口，用于利用有序执行历史，而无需在部署时进行显式运动估计或几何处理。

## Abstract
Vision-language-action (VLA) models leverage pretrained vision-language representations for robot control, yet simply adding historical frames does not reliably capture recent physical change. This is especially problematic in multi-stage manipulation, where visually similar states may require different actions depending on prior execution. To address this challenge, we present TemporalFlow-VLA, which learns compact execution history through physically grounded temporal supervision. Using recorded robot states, robot geometry, and calibrated cameras, we construct robot-surface temporal flow as a training-only target and supervise two execution-aligned temporal queries that provide structured history to the action expert. The geometric supervision path is not evaluated at deployment. TemporalFlow-VLA achieves 97.63 +/- 0.26% average success on LIBERO, including 96.60 +/- 0.87% on LIBERO Long, and 85.5%/84.2% Clean/Randomized success across 12 RoboTwin tasks. It shows its clearest advantage over prior methods on longer-horizon, multi-stage manipulation. Controlled history interventions show that action prediction depends on both historical content and temporal order. With asynchronous feature caching, temporal conditioning maintains single-frame-level server-side sampling latency without additional historical-encoding overhead. Overall, TemporalFlow-VLA provides a compact, physically grounded interface for exploiting ordered execution history without explicit motion estimation or geometric processing at deployment.

## 2. 方法论

**核心设计思想：** 在预训练的 π0.5 风格 VLA 策略中，引入一个并行的时域路径。利用机器人运动学、URDF 几何和相机标定，**离线生成机器人表面时间流**（robot-surface temporal flow）作为训练的监督信号，监督两个执行对齐的时间查询（temporal queries）Q8 与 Q15。动作专家只能通过这两个紧凑查询获得历史信息，不能直接访问历史图像块。部署时，几何渲染器和流重构头均不参与，仅保留时间查询与动作生成的运算。

**（1）运动学接地的机器人-表面时间流**

- 对每个历史间隔 ρ ∈ {8, 15}，记 s = t − ρ 为源时刻，qτ 为关节配置，T_l→B(qτ) 为链路到基座的齐次前向运动学变换，T_C←B 为基座到相机的标定变换。
- 通过仅含机器人的渲染器获得每个可见源像素 p 的基座系表面交点 X_B^s(p) 及所属连杆 l(p)。
- 利用式(1)–(3)将对应点从连杆系变换到目标时刻，再投影到目标图像平面：
  - x_l(p)(p) = [T_l(p)→B(q_s)]⁻¹ X̄_B^s(p)
  - X̄_B^t(p) = T_l(p)→B(q_t) x̄_l(p)(p)
  - ũ_t(p) = Π_K(T_C←B X̄_B^t(p))
- 最近邻查找建立对应关系，要求投影在界内、属于同一连杆、3-D 残差 ≤ 5 mm。
- 位移经图像尺寸归一化得到每像素的流 f_ρ(p)；在非重叠 14×14 区域内取掩码算术平均，形成 16×16×2 的目标张量。c_ρ(k) 衡量有效机器人支撑占整个 patch 面积的比例，阈值 0.1 用来生成掩码 M_ρ（门控损失但不作为损失权重）。
- 机器人-表面限制仅作用于辅助目标；时间路径仍接收完整 RGB，场景和物体变化仍可用于动作目标。

**（2）层级时间查询与联合注意力**

- 可学习的时域令牌 q8、q15 追加到标准 π0.5 前缀 P_std(V0, L, s) 之后，形成序列 P0 = [P_std; V15; V8; q8; q15]，其中 V15、V8 为历史图像令牌（带学习的位置/帧身份嵌入），V0、L、s 分别表示当前图像令牌、语言令牌和机器人状态。
- 通过定向查询掩码实现层级结构：
  - Q8 只能读语言令牌、t−8 观测、当前观测及自身 → 专门负责近期运动。
  - Q15 可额外读 t−15 观测和 Q8 → 在近期运动摘要之上整合更长时间的上下文。
  - Q8 → Q15 为单向路径，保持两个时间尺度各自独立。
- 令 z_ρ 为 Qρ 的最终状态，V_ρ 为源帧的空间特征，查询条件解码器通过 FiLM 调制源空间状态、经逐点两层 MLP 预测流（式11–12）；两个间隔的解码器不共享参数。
- 流损失采用 Huber 损失，仅在 M_ρ = 1 处计算（式13–14）；时间损失为两个间隔的平均。
- 时间信息通过已有的联合掩码自注意力进入动作专家：动作令牌保留原 VLA 上下文，并额外暴露 Q8 和 Q15，但直接屏蔽 V8 和 V15（式15–18）。历史视觉信息必须先被压缩进流监督的查询表征，才能影响动作生成。
- 最终目标：L = L_action + λ_temp·L_temp，λ_temp 在所有主实验中设为 1.0。

**（3）异步历史特征缓存**

- 若同步编码 t−15、t−8、t 三个观测，每次重规划需要三次视觉编码，耗时显著。
- 方案：机器人执行当前动作块期间，后台进程异步编码历史帧并存入带时间戳的环形缓冲区；重规划时直接取用缓存特征，仅当前帧同步编码。
- 延时公式对比：
  - 无缓存：T_naive ≈ 3·T_vision + T_joint + T_action
  - 带缓存：T_cache ≈ T_vision + T_joint + T_action
- 在片段开始处，历史不足时以最早观测填充并标记无效，跳过缓存直至所需历史帧就绪；过期特征被逐出窗口。

## 6. 主要结论与发现

**性能结果：**
- **LIBERO**：平均成功率 97.63 ± 0.26%，其中 LIBERO Long 为 96.60 ± 0.87%，比最强的已发表方法均值高 2.1 个百分点；在已饱和的短时程套件上保持接近最优。
- **RoboTwin 2.0**：Clean 平均 85.5%，Randomized 平均 84.2%；随机化设置下比最佳已发表基线高 8.0 个百分点。
- **按任务组分析**：H=1 平均不是最优；H=2 的随机化平均为 80.8%（领先 5.5 点）；H=3 的随机化平均为 87.5%（领先 14.5 点）。**优势明确地随操作时程增加而扩大**，与"显式历史对多阶段操作最有用"的动机一致。

**消融与诊断发现：**
- 打乱历史顺序比移除历史更能增大动作损失（5/6 任务），说明动作预测依赖历史内容和时间顺序两个维度；但未受控的基线模型对顺序不敏感（图2），这是引入结构化监督的关键依据。
- 仅查询瓶颈而不加流监督（2Q w/o Flow）已优于多帧基线，而流监督进一步在 H=2 上带来 3.7/1.5 个百分点的提升；Q8 单独优于 Q15，但双尺度联合最优，说明更长范围上下文具有互补性。
- 异步缓存将平均采样延迟从 68.10 ms 降至 62.78 ms（每次重规划节省 5.32 ms），15 次重规划段累计节省 79.8 ms（7.8%）。

**真实机器人：**
- Three-Cup Stacking 成功率从 57.8% 提升至 77.8%（+20.0 点）；Two-Bottle Packing 从 86.7% 提升至 97.8%（+11.1 点）。物理世界中的优势同样在更需要跨阶段维持进度的任务上更大。

**总结判断：**
- 显式监督"近期机器人运动如何在视觉观测中呈现"，比直接提供多帧历史或未经监督的潜在记忆更有效，且部署时更高效（无额外几何/运动计算、单帧级延迟）。

## 7. 优点

- **物理接地的训练监督**：利用机器人状态、URDF 几何和相机标定，从运动学确定性推导机器人表面在像素平面上的时间流，免去人工标注和部署时传感器；监督信号具有可解释性，直接对应"物理变化如何在 RGB 中显现"。
- **训练-部署不对称的设计智慧**：密集时间流只作为训练目标，部署时移除几何渲染器和流解码器路径，不增加推理负担；历史信息被压缩到两个紧凑查询中，动作专家接口简洁高效。
- **层级查询设计清晰**：Q8（近尺度）与 Q15（远尺度）通过单向掩码形成层级，明确各令牌的时间尺度和语义职责；查询与流解码器的联结使潜在表征有明确的物理目标，避免了自由历史潜在变量可能出现的漂移。
- **保持原策略架构的兼容性**：历史信息通过已有联合掩码自注意力进入，无需额外跨注意力模块或历史专用残差门，保留动作专家原有的 AdaRMS 残差调节。
- **工程化思考成熟**：异步历史特征缓存将历史编码移出关键路径，保持单帧级采样延迟；时间流标签离线预计算，训练开销增量（约 20%）可控。
- **实验覆盖全面且诊断到位**：离线扰动诊断直接证明顺序敏感性问题，在线消融逐层剥离变量，真实机器人验证物理迁移，延时实验验证部署效率；RoboTwin 对比数据来源标注规范，避免误导。

## 8. 不足与局限

- **固定历史窗口未系统探索**：仅采用 t−15 与 t−8 两个历史时刻，未系统研究历史帧数量与时间间隔对表征学习的影响；不同操作任务可能具有不同的最优时间视界与采样粒度。论文明确将其列为未来方向。
- **指令与流监督的耦合有限**：时间流仅基于机器人表面运动，不含物体交互的显式信息；虽时间路径仍接收完整 RGB 保留物体变化，但监督信号本身对"物体如何变化"不提供直接物理目标，在物体状态对比更重要的任务中可能覆盖不足。
- **对比方法的复现口径差异**：RoboTwin 中部分基线数据引自其他论文的复评结果，并非统一训练条件下重新复现的对照，横向比较需谨慎解读。
- **真实机器人验证规模有限**：仅 2 个任务、每条件 45 次试验，未报告逐轮和跨轮的标准差；在更多任务、更多随机场景和不同实体上的推广性仍有待验证。
- **基准确认饱和的统计分辨力**：LIBERO 的 Spatial/Object/Goal

从“基准确认饱和的统计分辨力”被截断处继续补全如下：

- **基准确认饱和的统计分辨力**：LIBERO 的 Spatial/Object/Goal 等短时程套件已高度饱和（平均成功率普遍在 95% 以上），各方法之间的数值差距较小，TemporalFlow-VLA 在这些套件上的领先幅度也较小，统计上的区分度有限；因此主要说服力仍集中在 Long 套件与 RoboTwin 的长时程结果上。对于希望迁移到更复杂真实场景的读者而言，这种“饱和基准上的小幅提升”是否足以支撑“时间流监督具有普适价值”的结论，仍需要更长时程、更细粒度的基准来佐证。

- **未报告完整的失败模式分析**：论文给出了成功率提升，但对失败案例（如抓取不稳定性、阶段切换错误、历史信息被误用导致的错误动作）缺乏系统性的分类与可视化分析，难以判断时间路径在哪些具体环节仍然不足。

- **历史信息与动作目标的连接仍属隐式**：动作专家仅通过两个查询令牌获取历史信息，查询表征虽受流监督约束，但没有显式监督“动作专家应当如何解读该查询”，二者之间的语义对齐依赖端到端学习，对训练数据多样性的依赖较高。

## 9. 关键概念与术语澄清

| 术语 | 含义与澄清 |
|------|-----------|
| **机器人表面时间流（robot-surface temporal flow）** | 由机器人运动学、URDF 几何与相机标定离线推导出的稠密像素位移场，描述机器人表面点在两个时刻之间在图像平面上的运动，仅作为训练监督信号。 |
| **时间查询（temporal queries）Q8 / Q15** | 两个可学习的紧凑令牌，携带从历史观测中提取的时间上下文；Q8 负责近期（t−8）运动，Q15 负责较远（t−15）运动并整合 Q8 的摘要，通过掩码实现单向层级。 |
| **流掩码 M_ρ** | 基于机器人支撑区域占 patch 面积比例（阈值 0.1）生成的二值掩码，用于门控 Huber 流损失的参与区域，避免背景或非机器人区域干扰监督。 |
| **异步历史特征缓存** | 后台进程在机器人执行动作块期间异步编码历史帧并存入环形缓冲区；重规划时直接从缓存读取历史特征，仅当前帧需同步编码，保持单帧级延迟。 |
| **H=1 / H=2 / H=3** | RoboTwin 2.0 中按任务执行步数分组的任务类别，分别代表短、中、长时程操作，用于检验方法在不同任务长度下的增益模式。 |
| **训练-部署不对称** | 密集时间流监督与几何渲染器仅在训练阶段使用，部署时移除，只保留时间查询参与动作生成；即“训练时信息丰富、部署时接口精简”的设计范式。 |

## 10. 可复现性要素

**数据与代码：**
- 论文使用公开基准 LIBERO 与 RoboTwin 2.0；真实机器人任务在 AgiBot A3 上采集，每任务 280 条演示，但演示数据是否开放未明确说明。
- 对比方法结果均来自已发表论文，并标注了来源（如 LingBot-VA 复评的 π0/π0.5 数据，GigaWorld-Policy 复评的 X-VLA†）；GR00T N1.7 的 LIBERO 结果由官方成功计数量新计算，口径有说明。
- 论文未明确说明代码与预训练权重是否开源。

**实验设置的确定性：**
- LIBERO 在 3 个种子（0/2/5）下联合训练 30k 步，每套件 500 次 rollout，提供了均值与标准差。
- RoboTwin 12 任务联合训练 60k 步，每任务 100 次 rollout，但未报告 rollout 的逐种子方差。
- 真实机器人试验未报告轮间标准差。
- 超参数方面：λ_temp = 1.0；历史间隔固定为 8 与 15 帧；流损失为 Huber；14×14 非重叠 patch 聚合；训练 batch size 为 32。训练步数、batch size、GPU 数量等已给出，但总墙钟小时数未报告。

**可复现性的整体评估：**
- 由于方法仅依赖机器人状态、URDF 与相机标定，不需要额外的运动传感器或人工标注，理论上在不同机器人平台上有直接适配的潜力。
- 但时间流标签的生成代码、异步缓存的具体实现细节以及真实机器人实验的操作协议未充分披露，第三方复现仍需依赖论文附录或后续开源。

## 11. 潜在扩展方向

- **自适应时间尺度选择**：将固定的历史间隔（8、15）扩展为可学习或多尺度采样，使模型根据任务阶段动态选择最优历史视界；也可尝试密度更高的历史帧序列以捕捉更精细的运动模式。
- **显式物体-机器人联合流**：在机器人表面流的基础上，引入物体的光流或掩码变化作为额外监督，使时间路径对“物体状态如何因机器人动作而改变”有更直接的物理目标。
- **与视觉基础模型的时间表征融合**：对比或结合冻结视频编码器（如多帧 DINO）所提供的时间特征，研究物理接地的流监督与自监督时间表征的互补性。
- **跨实体与跨相机泛化的系统验证**：在多种机器人构型、多视角相机和多光照条件下验证时间流表征的迁移能力，探索是否需要重标定或微调。
- **更长时程的层级扩展**：在 Q8/Q15 之上增加第三层更远时间尺度的查询（如 Q30），或引入层级式的阶段级隐变量，以支撑更长任务链的进度推理。
- **流监督的复杂度可控释放**：在训练后期逐步降低流损失的权重或稀疏化监督，考察模型能否在监督减弱后仍保持时间敏感性。

## 12. 总体评价与适用场景

**总体评价：**
TemporalFlow-VLA 针对多阶段长时程操作中“仅凭当前观测无法区分同视觉状态”的痛点，提出了一种物理接地、训练-部署不对称的时间信息注入方案。其核心贡献不在于引入新的多帧输入方式，而在于**重新定义了历史信息应如何被组织——不是原始帧的堆叠，而是以机器人表面物理运动为显式监督、压缩进少量查询令牌的结构化表征**。设计上兼具严谨性与工程性：掩码注意力构建层级查询，流监督赋予潜在表征可解释目标，异步缓存保证部署效率。实验覆盖仿真与真实机器人，既有性能对比又有消融诊断，证据链较为完整。

**主要适用场景：**
- 多阶段、按顺序执行的日常操作任务（如叠杯子、装箱、厨具整理）。
- 视觉状态高度混淆、但机器人自身运动史可区分的场景（如抓取前后、接近与携带）。
- 对部署延迟敏感、无法承受多次视觉编码或在线光流计算的真实机器人系统。

**不太适用的场景：**
- 纯静态单步任务（历史信息基本无用，基线已达饱和）。
- 以物体状态变化为主要线索、机器人自身运动几乎不提供区分信息的任务（本方法的流监督覆盖有限）。
- 没有可靠相机标定或 URDF 模型的低成本平台（时间流标签的生成依赖这些条件）。
