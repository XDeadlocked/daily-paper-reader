## 摘要
多臂协作正成为具身操作中的核心能力。最近的视觉-语言-动作（VLA）模型整合了感知、语言和控制，但大多数模型将语言表示为单一的全局指令，并未提供显式机制来分配和组合各机械臂特定行为。这种设计限制了模型向与训练期间观察到的协作模式不同的情境迁移。我们提出MA-VLA，一种通过原子动作分配实现多臂协作的统一框架。MA-VLA将协作行为分解为中层原子提示，并将其分配给各个机械臂，从而实现显式子目标指定和跨任务的组合重用。为减少对固定执行角色的依赖，我们引入Arm Shuffle，即训练时对每个机械臂的观测、状态和分配的原子提示进行排列。这种排列强制实现角色无关的指令遵循，并支持重组为未见过的协调模式，我们称之为多臂组合泛化。我们还构建了一个基准，其中测试时的协作模式在训练集中不存在。在仿真和真实世界评估中，先前最先进的VLA模型在这些未见过的协作下大多失败，而MA-VLA则持续成功。这些结果表明，结构化的、逐臂原子动作分配为多臂具身系统中的可扩展泛化提供了一条实用途径。代码、模型和数据可在https://github.com/zhangzaibin/future-robots获取

## Abstract
Multi-arm collaboration is becoming a core capability in embodied manipulation. Recent vision-language-action (VLA) models integrate perception, language, and control, but most represent language as a single global instruction and do not provide an explicit mechanism for assigning and composing arm-specific behaviors. This design limits transfer to collaboration patterns that differ from those observed during training. We present MA-VLA, a unified framework for multi-arm collaboration via atomic action assignment. MA-VLA decomposes cooperative behavior into mid-level atomic prompts and allocates them to individual arms, enabling explicit subgoal specification and compositional reuse across tasks. To reduce reliance on fixed execution roles, we introduce Arm Shuffle, a training-time permutation of the observation, state, and assigned atomic prompts for each arm. This permutation enforces role-agnostic instruction following and supports recomposition into unseen coordination patterns, which we term multi-arm compositional generalization. We also construct a benchmark in which test-time collaboration patterns are absent in training set. Across simulation and real-world evaluations, prior state-of-the-art VLAs largely fail under these unseen collaborations, while MA-VLA consistently succeeds. These results indicate that structured, per-arm atomic action assignment offers a practical route to scalable generalization in multi-arm embodied systems. Code, models, and data are available at https://github.com/zhangzaibin/future-robots

## 2. 论文提出的方法论

### 2.1 核心思想
MA-VLA 将多臂协作分解为**原子动作分配**的层次化框架：先由高层的视觉-语言模型（VLM）规划器将用户指令分解为逐臂、分阶段的原子提示（atomic prompts），再由底层的 VLA 执行器将这些提示接地为具体的连续控制动作。

### 2.2 关键技术细节

- **VLM 规划器（Planner）**：
  - 使用现成的 VLM（GPT-4.1），输入高层的语言指令 `l` 和视觉观测 `I`，从预定义的原子提示集合 `A` 中选出各臂各阶段的提示序列：
    ```
    l → (p₁,…,pT),  pt = (p₁ᵗ,…,pNᵗ)
    ```
  - 每个 `pᵢᵗ` 是赋给第 i 个臂在第 t 阶段的原子指令（如"抓取物体""拿住碗""放置方块"）。
  - 规划器只输出语言提示，不做微调、不直接输出控制信号，保证可解释性和灵活性。

- **VLA 执行器（Executor）**：
  - 将所有臂的原子提示拼接为一条统一指令字符串 `ut`：
    ```
    ut = "Arm0: p0ᵗ, Arm1: p1ᵗ, …, ArmN: pNᵗ"
    ```
  - 执行器输入：多视角观测（全局视角 + 各臂手腕视角）、所有臂的 proprioception 状态、统一指令字符串。
  - 输出：所有臂的联合动作向量 `[a₁ᵗ,…,aNᵗ]`，通过单个前向传播同时推理所有臂的动作，以捕捉臂间依赖。
  - 动作生成采用 flow-matching 架构（借鉴 pi0），并添加多投影层将共享潜在表示分离到各臂专属的动作头，保证平滑和物理一致的轨迹。

- **Arm Shuffle（训练时正则化策略）**：
  - 以概率 `p_shuffle` 随机置换各臂对应的观测、状态、提示和动作：
    ```
    (sᵢ, vᵢ, pᵢ, aᵢ) → (sσ(i), vσ(i), pσ(i), aσ(i))
    ```
  - 这一策略防止模型将行为绑定到固定的机械臂身份或空间位置，强制模型依据语义内容而非结构位置来理解指令，从而支持角色无关的指令跟随和组合复用。

- **View Dropout**：
  - 以概率 `p_drop` 随机遮蔽部分相机视角（置零），增强模型对冗余视觉线索的利用和多视角推理的鲁棒性，提升在视觉干扰下的泛化能力。

- **训练目标**：
  - 两种策略都是在训练时作用于数据的随机增强，不改变行为克隆（BC）目标函数：
    ```
    L(θ) = E[ Σᵢ ℓ(πθ(Ĩt, sᵢᵗ, pᵢᵗ), aᵢᵗ) ]
    ```
  - 训练时不固定某一种策略，而是按概率采样应用，隐式地促进排列不变协调和多视角鲁棒感知。

### 3.1 基准与场景

- 每个仿真任务采集 150 条专家演示，使用基于规则的解析器从轨迹中自动生成帧级的原子动作提示。

## 6. 论文的主要结论与发现

1. **原子动作条件化显著提升 in-domain 多臂协作表现**：在 RoboFactory 2 臂任务中，MA-VLA 的平均成功率（83.5%）明显优于 DP（27.5%）和 Pi0-FAST（57.5%），并超过 Pi0（80.3%）；在 3–4 臂任务中优势更大（MA-VLA 83.3% vs Pi0 76.5% vs DP 15.3%）。
2. **在强视觉扰动下仍然保持鲁棒**：RoboTwin 2.0 (Hard) 中，MA-VLA 平均 49.0%，显著优于 Pi0（41.1%）和所有其他基线，尤其在需要双手协作与操作的任务（如 Handover Block 46% vs Pi0 27%）上提升明显。
3. **组合泛化能力是核心突破**：在训练中未出现的协作模式（新堆叠顺序、反向堆叠、新传递顺序）下，DP、Pi0-FAST 和 Pi0 全部失败（成功率 0%），而 MA-VLA 达到 28% / 9% / 9% / 9% / 10%（平均 13.0%）。消融表明 **Arm Shuffle 是从 0% 泛化到非零泛化的关键组件**，View Dropout 在此基础上进一步提升。
4. **真实世界验证**：在 SO101 上，MA-VLA 在 in-domain 上均有提升，且在 OOD（角色反转/重新编排）下取得非零成功率（如 Stack Bowls OOD 10/20），而 Pi0 全部为 0/20。
5. **独立逐臂模型不可行**：虽然逐臂独立模型在 in-domain 上略好（61% vs 53%），但在 OOD 组合泛化上完全失败（0%），且推理/部署开销随臂数线性增长，验证了统一联合建模的必要性。

## 7. 优点

- **方法新颖性**：首次将"原子动作分配"作为多臂 VLA 的显式接口，实现了分层推理（语言层分解 + 控制层执行）的自然解耦，兼顾可解释性与端到端推理能力。
- **训练策略简洁而有效**：Arm Shuffle 仅通过数据层面的角色置换就打破了臂身份绑定，无需修改训练目标或引入额外参数，却带来了从 0% 到非零的组合泛化提升，设计非常巧妙。
- **验证体系完整**：覆盖 2 个仿真基准 + 1 个真实平台，任务类型丰富（堆叠、放置、传递、对齐等），且同时评测 in-domain 与 out-of-domain，实验对比全面。
- **统一的联合推理架构**：单模型同时推理所有臂的动作，共享上下文可以隐式编码臂间依赖，比独立逐臂模型在协作任务上更合理且扩展成本低（单模型无论多少臂均只需一次前向传播）。
- **开源可复现**：代码、模型和数据均公开。

## 8. 不足与局限

- **VLM 规划器依赖外部模型**：规划器使用 GPT-4.1 且未微调，这带来三个问题：（1）推理时依赖外部 API，存在延迟和不可控性；（2）GPT-4.1 的规划能力并未在机器人数据上校准，可能出现提示选择错误；（3）与纯粹端到端学习的基线不够对等，框架级优势未得到单独消融验证。
- **原子提示库需要人工定义**：原子动作集合 `A` 是预定义的人造模板库，依赖人为设计的任务先验。对于开放式任务或更复杂的长时序任务，如何自动构建和扩展该动作词汇表仍是未解决问题。
- **组合泛化绝对水平有限**：虽然远优于基线，但 OOD 任务平均成功率仅 13% 左右；最高的单个 OOD 任务为 28%，仍有巨大的提升空间。论文也承认测试集是"有限数量模式"，尚未探索更广的组合空间。
- **真实实验规模较小**：SO101 每个任务仅 50 个演示、20 个测试 episode，样本量相对有限，统计显著性无法严格保障。
- **某些任务的优势不显著**：如 RoboFactory 的 "Place Food" 和 "Take Photo" 任务，MA-VLA 与 Pi0 几乎持平（59% vs 58%、82% vs 82%），说明原子提示的好处可能只在协调复杂性较高的任务中充分体现。
- **物理干扰的探索不足**：论文仅提到"Reverse Stack Bowls (Reordering + Disturbance)"设置中有干扰，但没有系统评测外力扰动、交互力控制等物理层面的鲁棒性。
- **训练成本未完整披露**：未报告单次训练的实际耗时、总 GPU 小时数、推理延迟等关键工程指标，不便评估其工程可用性。
