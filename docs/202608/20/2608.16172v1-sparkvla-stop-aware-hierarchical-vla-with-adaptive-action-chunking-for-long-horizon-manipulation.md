## 摘要
在分层视觉-语言-动作（VLA）系统的每个重新观察点，必须做出两个接口决策：何时终止当前子任务，以及执行所提议的动作块到什么程度。这些决策相互依赖——最优停止点取决于执行器的计划，而最优执行长度取决于子任务边界的位置——然而现有架构孤立地评估它们，这种不对称性是任何模块都无法单独克服的。我们提出SparkVLA，一种停止感知的分层VLA，通过将两个决策表述为单一排序来解决这种相互依赖：Stop与统一候选集中的每个动作前缀长度竞争，系统选择得分最高的选项，消除了阈值调整，并且只需要离线的顺序偏好。锚定条件上下文编码模块缓存历史感知的子任务锚定编码，结合起始状态记忆和目标语义，引导视觉标记剪枝朝向任务相关区域；停止感知动作前缀选择头在块边界处通过完全自注意力对所有候选进行评分，以提高效率。在RoboCerebra上，SparkVLA实现了47.12%的成功率，超过官方分层基线30.57%，超过最强可复现方法26.83%。在多步任务上的真实机器人实验进一步验证了这些在物理硬件上的收益。

## Abstract
At every re-observation point in a hierarchical Vision-Language-Action (VLA) system, two interface decisions must be made: when to terminate the current subtask and how far to execute the proposed action chunk. These decisions are mutually dependent---the optimal stopping point depends on what the executor plans to do, while the optimal execution length depends on where the subtask boundary lies---yet existing architectures evaluate them in isolation, an asymmetry neither module can overcome alone. We present SparkVLA, a stop-aware hierarchical VLA that resolves this mutual dependency by formulating both decisions as a single ranking: Stop competes against every action-prefix length in a unified candidate set, and the system selects the highest-scoring option, eliminating threshold tuning and requiring only offline ordinal preferences. An Anchor-Conditioned Context Encoding module caches a history-aware subtask anchor encoding onset-state memory and goal semantics, guiding visual-token pruning toward task-relevant regions; a Stop-Aware Action-Prefix Selection head scores all candidates via full self bnattention at chunk boundaries for efficiency. On RoboCerebra, SparkVLA achieves 47.12% success rate, surpassing the official hierarchical baseline by 30.57% and the strongest reproducible method by 26.83% Real-robot experiments on multi-step tasks further validate these gains on physical hardware.

## 1. 核心问题与整体含义（研究动机与背景）

长时程机器人操作任务要求系统将多个技能按顺序组合执行，这对现代VLA模型构成显著挑战——它们大多在短轨迹片段上训练，难以在长时间跨度内组合多种技能。分层VLA架构通过将高层VLM规划器与低层VLA执行器配对来解决这一问题，但系统在规划-执行接口处面临**两个相互依赖的决策**：

- **何时终止当前子任务**（termination condition）
- **执行动作块到何种程度**（execution horizon）

作者指出这两个决策本质上是相互耦合的：最优停止点依赖于执行器后续计划的内容；最优执行长度又依赖于子任务边界的实际位置。然而现有架构存在一个结构性缺陷——每个模块各自孤立地处理其中一个决策：

- **终止侧**：二进制停止检测器、VLM预测长度或进度信号，均在不参考未来计划的情况下决定是否停止；
- **水平侧**：DEHP、ACH、AQC、AAC等自适应动作分块方法只能选择执行长度，无法发出子任务完成的信号。

这种不对称性导致性能受限：过早终止丢弃进度、过迟终止引起过冲、过度承诺导致漂移、承诺不足浪费重规划预算。**本文的核心贡献在于证明这两种决策可以归结为同一个评估问题——"从当前状态出发，所提出的块对当前子任务的适配程度如何"——从而通过统一排序解决这一相互依赖。**

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 核心思想（统一候选集排名）

SparkVLA将两个接口决策合并为一个统一候选集的单一排名问题。候选集定义为：

```
C = {0, 1, ..., H}
```

其中候选0表示Stop，候选n≥1表示使用动作块At中前n个动作（动作前缀）。系统通过同一评分头为所有候选打分，选择得分最高的选项。由于所有候选在**同一个共享表征**下评分，终止决策可以借助提议计划的内容，而水平选择可以借助与子任务边界的接近程度——这正是独立模块缺乏的互信息。

### 2.2 架构细节

SparkVLA从预训练的π0.5 VLA派生两个独立参数分支：

| 分支 | 构成 | 功能 |
|------|------|------|
| 高层分支 | π0.5的VLM主干 | 自回归子任务生成 + 承载选择器 |
| 低层分支 | 完整π0.5 VLA（含动作专家） | 提出动作块 |

系统由两个关键模块构成：

**（1）锚定条件上下文编码（Anchor-Conditioned Context Encoding）**

- **历史感知子任务锚定**：在子任务开始时，从规划器倒数第二层提取原始锚定表征（z = MLP_anchor(h_layer)），经MLP投影后，通过自注意力与锚定历史池融合，得到历史感知锚定αk（在整个子任务期间缓存）。该锚定编码了起始状态记忆和目标语义，并传播跨子任务的上下文——例如"哪些区域在早先子任务中已被操作过"——对记忆依赖型条件至关重要。
- **锚定引导的视觉剪枝**：利用可微分的Grid-Sampler算子，从锚定条件视觉摘要预测K个归一化2D坐标，通过双线性插值采样K个任务相关的视觉token，将视觉序列从N个token缩减到K个/相机。
- **高层隐藏特征编码**：将剪枝后的视觉token与本体感受状态嵌入和子任务命令嵌入拼接，通过高层VLM主干前ℓm层（带LoRA适配器）处理，得到mt。

**（2）停止感知动作前缀选择头（Stop-Aware Action-Prefix Selection）**

- 评分头是一个**完整自注意力Transformer**，让Stop和所有动作前缀候选互相注意，每个候选（来自其前缀的终止动作加长度嵌入）被初始化后，在统一token集上进行全自注意力：
  - 上下文token：eα（锚定）、em（高层特征）
  - 候选token：e0（Stop）和每个动作前缀长度的token
  
- 每个候选的输出通过MLP评分层映射为标量，取最高分者作为最终决策。

### 2.3 训练目标

采用两个互补损失优化同一组候选分数：

**（1）成对排名损失（Lrank）**：基于离线执行结果赋序值优先级ρi。
- 完成前：覆盖前缀（n≥n\*）优于非覆盖前缀；覆盖前缀中，最接近边界者优先
- 完成后：Stop排名最高
- 失败轨迹：所有动作前缀并列高于Stop，鼓励继续探索
- 对边界标注施加均匀随机扰动τ′ = τ + Δ（Δ~U(−2,2)），增强对标注噪声的鲁棒性

**（2）停止感知辅助损失（Lstop）**：对比Stop分数与续行分数的log-sum-exp聚合，强化终止边界的梯度信号。

总损失：L = Lrank + λstop·Lstop，λstop=1。推理时仍使用统一的arg max规则，辅助损失不引入额外的推理路径。

### 2.4 推理调度

- 选择器仅在块边界调用（非每步执行），配合子任务命令缓存实现约4.14 Hz的边界更新频率（41.4动作步/秒），保留独立π0.5约88%的吞吐量。
- 短确认窗口过滤分数波动后才提交停止决策。

## 6. 主要结论与发现

1. **统一排序有效解决相互依赖问题**：将停止与动作前缀长度统一排名后，RoboCerebra的SR从42.53%升至47.12%，停止准确率从80.37%跃升至96.65%（+16.28pp，精确率94.3%，召回率98.1%），证实—终止决策受益于动作前缀上下文，前缀选择受益于准确的终止信号—存在双向收益。

2. **选择器放置位置至关重要**：高层规划器主干比低层执行器主干增益+9.84%，因为规划器保留了更丰富的任务进度和子任务历史上下文，而执行器仅针对动作生成训练，不保留此类信息。

3. **历史感知锚定带来实质性增益**：完整历史感知锚定与原始锚定相比+1.94%，主要来自解析记忆依赖条件下的空间歧义。

4. **跨执行器泛化成立**：将SparkVLA的高层系统与不同低层执行器（OpenVLA-OFT、SmolVLA）配对仍获得一致提升（+22.47%、+22.52%），表明增益源于统一接口设计而非特定模型配对。

5. **真实世界验证**：自适应前缀在接触事件附近缩短、自由空间运输期间延长的行为模式在物理硬件上得到复现，三任务中最大的优势（泡茶+30.0%）出现在最长的12-子任务场景，再次确认长时程条件下统一接口设计的价值。

1. **应用范围有限**：当前评估集中于桌面操作、固定物体类别和离线训练；开放世界、在线适应和更广泛的规划器-执行器组合仍有待拓展。

2. **真实实验存在简化**：真实场景使用白色塑料珠代替水进行"倒水"任务，虽然是安全的干式替代物，但缺乏与液体物理特性（如飞溅、表面张力、流变特性）相关的真实挑战。

3. **物理试验规模较小**：仅3个任务、各50次rollout，且对象位姿仅在任务特定的评估范围内随机化，对系统在更广泛物理变化下的鲁棒性证据不足。

4. **训练复杂度较高**：需要两阶段训练（先规划器子任务生成、后选择器联合训练），且依赖子任务边界标注（尽管有扰动增强，仍需要一定程度的标注质量），对于新任务领域的迁移效率未研究。

5. **基线的完整覆盖有限**：作者承认只关注可公开访问且在RoboCerebra上技术上可复现的基线，一些重要但仍未公开的近期系统未纳入比较。

6. **失败的深层次原因分析不足**：虽然报告了总体SR和停止准确率，但对失败类型的分类（如感知失败、规划失败、执行失败）未做详细拆解，难以定位系统的剩余瓶颈。
