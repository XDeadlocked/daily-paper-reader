## 摘要
视觉-语言-动作（VLA）模型处理长的多模态令牌序列，使得推理在内存和计算上都十分昂贵。现有的效率方法主要减少视觉令牌，但激进的令牌剪枝变得脆弱，因为移除一个令牌会丢弃其整个表示。子令牌压缩提供了一种互补的替代方案，通过保留更多令牌同时减少其值的宽度。然而，直接将子令牌压缩应用于VLA策略效果较差，因为对于感知、语言理解和控制重要的信息在多模态表示中的分布不同。我们引入了角色条件子令牌路由（RoleSub），它学习如何压缩保留令牌的值表示。在视觉令牌减少之后，RoleSub将每个保留的值表示划分为正交空间中的组，并使用轻量级路由器来确定应保留哪些组。路由决策以令牌表示、学习到的潜在角色表示和语言上下文为条件。同样的机制也可以应用于语言值，使得视觉和语言表示可以在不额外移除令牌的情况下被压缩。我们在四个LIBERO套件上评估了OpenVLA-OFT-7B上的RoleSub。在匹配的视觉KV预算下，RoleSub在36个设置中的33个中优于经过训练的仅令牌控制，在激进压缩下收益最大。结合视觉和语言压缩，总KV减少到原始的9.2%–11.3%，同时在大多数任务上保持强大的控制性能。这些结果表明，减少保留令牌内的表示提供了对令牌剪枝的有效补充，用于激进的VLA压缩。

## Abstract
Vision-Language-Action (VLA) models process long multimodal token sequences, making inference expensive in both memory and computation. Existing efficiency methods mainly reduce visual tokens, but aggressive token pruning becomes fragile because removing a token discards its entire representation. Sub-token compression provides a complementary alternative by retaining more tokens while reducing their value width. However, directly applying sub-token compression to VLA policies is less effective because information important for perception, language understanding, and control is distributed differently across the multimodal representation.   We introduce Role-Conditioned Sub-Token Routing (RoleSub), which learns how to compress the value representations of retained tokens. After visual token reduction, RoleSub partitions each retained value representation into groups in an orthogonal space and uses a lightweight router to determine which groups should be preserved. The routing decision is conditioned on the token representation, a learned latent role representation, and language context. The same mechanism can also be applied to language values, allowing visual and language representations to be compressed without removing additional tokens.   We evaluate RoleSub on OpenVLA-OFT-7B across the four LIBERO suites. At matched visual-KV budgets, RoleSub outperforms a trained token-only control in 33 of 36 settings, with the largest gains under aggressive compression. Combining visual and language compression reduces total KV to 9.2--11.3% of the original while retaining strong control performance on most tasks. These results show that reducing the representation within retained tokens provides an effective complement to token pruning for aggressive VLA compression.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：视觉-语言-动作（VLA）模型将视觉观测、语言指令、本体感觉与动作上下文统一输入大规模多模态 Transformer，在机器人操控上表现优异，但每一步控制都需要处理很长的多模态前缀，其中视觉 token 占主导，导致推理时的内存与计算开销很高。
- **已有方法的不足**：现有 VLA 加速主要依赖 token 级剪枝（如 VLA-ADP、VLA-Pruner、FastV、VisionZip 等），即删除“不重要的”视觉 token。但 token 是粗粒度压缩单元：一旦删除，该 token 的全部信息（语义、几何、时序、控制相关信号）同时丢失。在低预算下，这种“全有或全无”的删除方式会显著破坏闭环控制性能，且压缩错误会在控制轨迹中传播。
- **关键观察**：子 token（value 分组）压缩是互补思路——保留更多 token 位置，但压缩每个 token 内 value 表示的宽度。然而，直接将通用子 token 路由移植到 VLA 策略效果很差（如均匀 S=4、K=1 时 LIBERO-Spatial 仅 43.8% 成功率），原因是 VLA 中视觉、语言、控制相关信息在表示上的分布不均匀，且无法预先指定哪些维度对应哪些语义角色。
- **本文目标**：提出 **RoleSub（Role-Conditioned Sub-Token Routing）**，让路由结构本身从控制目标中学习，从而更合理地分配有限的价值容量，实现比单纯 token 剪枝更激进的 VLA 压缩。

## 2. 方法论

### 2.1 总体框架

- RoleSub 在保留 token 序列（可先做 token 级剪枝）的基础上，对每个保留 token 的 **value 表示**进行压缩；
- Query 和 Key 保持不变；token 级缩减与子 token 路由是两个独立维度，可分别按 token 类型配置；
- 对视觉和语言均可应用，语言 token 可以全部保留、只压缩 value 宽度。

### 2.2 正交值空间分解

- 对第 ℓ 层 token i 的 value 向量 \(v_i^{(\ell)} \in \mathbb{R}^{d_v}\)，用固定的正交矩阵 \(R^{(\ell)}\)（\(R^{(\ell)\top}R^{(\ell)}=I\)，随机 Stiefel 矩阵初始化并冻结）做无损基底变换：
  \[
  z_i^{(\ell)} = R^{(\ell)\top} v_i^{(\ell)}
  \]
- 将 \(z_i^{(\ell)}\) 划分为 S 个不重叠的组，每个组维度为 \(d_s = d_v/S\)；
- 路由器选择保留其中 \(K_i\) 个组，形成 mask \(m_i^{(\ell)} \in \{0,1\}^S\)；再将 masked 表示变换回原 value 空间：
  \[
  \tilde{v}_i^{(\ell)} = R^{(\ell)} M_i^{(\ell)} R^{(\ell)\top} v_i^{(\ell)}
  \]
- 正交变换本身无损，信息丢失完全来自组选择；组不预设语义，而是让路由在结构化空间中学习如何分配容量。

### 2.3 学习到的潜在角色表示

- 轻量角色估计网络为每个 token 产生软潜在角色向量：
  \[
  a_i^{(\ell)} = \mathrm{softmax}(f_{\mathrm{role}}^{(\ell)}(h_i^{(\ell)})) \in \mathbb{R}^C
  \]
- C 为潜在角色分量数（实验中 C=6）；这些分量没有预定义语义，而是通过影响路由与动作预测损失联合学习。

### 2.4 角色条件路由分值

- 路由分值由三部分相加：
  \[
  \gamma_i^{(\ell)} = \gamma_{i,\mathrm{token}}^{(\ell)} + \alpha_{\mathrm{role}} \gamma_{i,\mathrm{role}}^{(\ell)} + \alpha_{\mathrm{lang}} \gamma_{\mathrm{lang}}^{(\ell)}
  \]
  - \(\gamma_{i,\mathrm{token}}^{(\ell)}\)：从当前 token 隐藏状态 \(h_i^{(\ell)}\) 得到的组级偏好；
  - \(\gamma_{i,\mathrm{role}}^{(\ell)}\)：由潜在角色 \(a_i^{(\ell)}\) 投影得到；
  - \(\gamma_{\mathrm{lang}}^{(\ell)}\)：由语言 token 隐藏状态汇总后经语言打分函数得到；
  - 实验中 \(\alpha_{\mathrm{role}}=\alpha_{\mathrm{lang}}=0.1\)。
- 保留得分最高的 \(K_i\) 个组；Top-K 不可微，使用直通估计器（straight-through estimator）进行反向传播。

### 2.5 token 类型相关预算与训练

- 不同 token 类型（vis / lang / prop / act）可设置不同的平均 value 组预算 \(K_m\)；
- 在总预算 \(B_m = K_m |I_m^{\mathrm{keep}}|\) 约束下，利用潜在角色表示 \(a_i^{(\ell)}\) 作为 token 级优先级，将组预算在同类 token 间自适应分配（高优先级 token 获得更多组，低优先级获得更少，但保持类型平均预算不变）。
- 训练方式：冻结预训练 VLA 骨干，联合训练 **LoRA 适配器**（rank=32）、路由函数和角色估计器，损失为动作 chunk 的 L1 回归损失：
  \[
  \mathcal{L}_{\mathrm{act}} = \frac{1}{T_a}\sum_t \|\hat{y}_t - y_t\|_1
  \]

## 3. 实验设计

### 3.1 模型与 benchmark

- **模型**：OpenVLA-OFT-7B（基于 OpenVLA，融合 SigLIP + DINOv2 视觉特征、Llama-2-7B 语言模型，支持并行动作解码、动作分块、连续动作预测和本体感觉输入）。
- **数据集/场景**：LIBERO 的四个套件——**Spatial、Object、Goal、LIBERO-10**，每个套件 10 个任务，每任务 50 次试验评估闭环任务成功率。
- **输入规模**：多模态前缀包含 512 个视觉 token（两个相机视角）、语言 token、本体感觉与动作上下文 token；每个控制步预测 8 个动作的 chunk。

### 3.2 压缩配置

- 视觉 token 保留数：\(r_{\mathrm{vis}}\in\{0.015625,0.03125,0.0625\}\)，即 8 / 16 / 32 个视觉 token；
- value 分组数 S=16，每组 256 维；视觉平均保留组数 \(K_{\mathrm{vis}}\in\{1,2,4\}\)；
- 语言实验设置 \(K_{\mathrm{lang}}\in\{1,2,4,8,16\}\)。

### 3.3 对比方法

- **未压缩 VLA**：官方 OpenVLA-OFT 检查点；
- **训练无关 token 剪枝**：直接对微调后模型做视觉 token 剪枝，不训练；
- **匹配预算的训练 token-only 剪枝**：使用与 RoleSub 相同的 LoRA 训练流程，但没有子 token 路由；为匹配相同 KV 预算而保留更少的完整 token（这是主要强基线）；
- **Plain 子 token 路由**：使用相同 token/value 预算，但令 \(R=I\)（原生 value 基）、去掉潜在角色信号、每个 token 固定保留相同组数，用于分离正交空间、角色条件和自适应预算的贡献。

## 6. 主要结论与发现

- **RoleSub 优于匹配预算的 trained token-only pruning**：36 个视觉-KV 配置中 33 个占优，最大提升出现在激进压缩和长时程任务（LIBERO-10 最高提升 10.5 个百分点）。
- **训练无关 token 剪枝在激进预算下失效**：12 个匹配点中有 10 个成功率为 0，说明仅靠增加 token 剪枝无法达到低 KV 预算。
- **Plain 子 token 路由不足以支撑 VLA 压缩**：在 8 个视觉 token 时，RoleSub 将 LIBERO-10 从 59.8% 提升到 74.2%，证明正交空间、角色条件和自适应组分配是关键。
- **token 保留与 value 宽度保留在语言上强烈不对称**：删除语言 token 会迅速损坏性能（保留 53% 语言 token 时成功率降至约 40%），而保留全部语言 token、仅压缩其 value 到 1/16 组时几乎无损（各套件仍接近 dense 水平）。
- **联合压缩可将总 KV 降至 9.2%–11.3%**：Object 和 Spatial 保持很好，Goal 小幅下降（0.8–2.9 点），但 LIBERO-10 显著下降（10.0–11.2 点）。
- **视觉与语言预算存在耦合**：LIBERO-10 上，当视觉信息很少时，提高语言 value 预算带来的收益更大（如 8 视觉 token 时 Klang 从 8 到 16 提升 15.2 点；32 视觉 token 时仅提升 2.8 点）。模型当前未显式建模这种跨模态依赖。

## 7. 优点

- **方法层面**：
  - 提出“token 剪枝 + 子 token value 压缩”两个独立压缩维度的框架，具有较好的通用性，可搭配不同 token 选择规则；
  - 用正交变换提供无损、结构化的路由空间，避免了原生表示上固定分组可能割裂任务相关维度的问题；
  - 通过潜在角色表示和 token 类型相关预算实现自适应容量分配，不依赖预定义语义标签；
  - 只在路由头、角色器和 LoRA 上训练，可训练参数占比小（约 115.5M / 7.65B）。
- **实验设计层面**：
  - 构造“匹配预算 trained token-only control”，比仅对比训练无关剪枝更公平，能更好证明子 token 路由的独立贡献；
  - 同时设置 Plain sub-token 对照组，分离正交空间/角色条件/自适应预算的收益；
  - 系统研究了视觉压缩、语言压缩、联合压缩以及跨模态预算交互，覆盖较全面。
- **结论价值**：首次在 VLA 政策中系统展示“value 内部压缩”作为 token 剪枝补充的有效性，并揭示语言 token 在控制中的特殊敏感性。

## 8. 不足与局限

- **实验范围有限**：仅使用 OpenVLA-OFT 模型和 LIBERO 模拟套件，未在真实机器人或更多 VLA 架构（如 Pi0、RT-2 类模型）上验证；未测试不同训练数据规模对路由学习的影响。
- **缺少统计可靠性信息**：未报告成功率方差、置信区间或多次随机种子的重复结果；LIBERO 任务本身成功率高、区分度有限，可能有天花板效应。
- **缺少实际效率测量**：仅报告 KV 比例，未评估端到端推理延迟、吞吐量或内存占用；稀疏 value 计算需要专门实现才能转化为实际收益。
- **可解释性与语义性不足**：潜在角色表示不保证对应可解释的语义角色，论文也明确承认这一点。
- **跨模态依赖未建模**：视觉与语言压缩存在明显耦合，但 RoleSub 仍按类型独立分配预算，没有显式的联合优化，导致 LIBERO-10 在联合压缩下性能明显下降。
- **语言 token 剪枝实验较弱**：仅报告 Goal 套件上的语言 token 剪枝结果，未扩展到全部套件，说明语言 token 敏感性证据的覆盖面有限。
- **训练数据量少、计算细节缺失**：缺少 GPU 型号、训练时长、收敛曲线等可复现性信息。
