## 摘要
从单个离心视频生成向心视频是AR/VR和物理AI中的一个新兴且重要的课题。与常规的新视角合成相比，离心到向心生成是一项困难得多的任务，因为在极端视角变化和大范围不可观测区域下，标准几何条件变得高度不可靠。我们提出了Grounded-Exo2Ego，一个在架构和数据层面解决这些挑战的原理性框架。在架构上，Grounded-Exo2Ego是一个双分支视频扩散模型，它将几何锚定分支（基于3D重建的渲染来条件化生成）与一种新颖的语义锚定分支耦合，后者超越了当前基于几何的方法，通过基于对象级上下文合成困难区域来提高质量。此外，我们发现相机重建错位这一被忽视的问题严重损害了离心到向心的学习。因此，我们引入了一种相机重定位算法来解决该问题，并在所有指标上大幅提升质量。我们还开发了一个全自动合成数据引擎，在程序化生成的环境中生成和渲染绑定3D角色。在具有挑战性的EgoExo4D数据集上的评估表明，我们的方法在所有指标上大幅优于最近的最先进方法。详细的消融实验验证了我们在数据和架构层面各自贡献带来的改进。

## Abstract
Generating egocentric video from a single exocentric video is an emerging and important topic for AR/VR and physical AI. Compared with conventional novel view synthesis, exo-to-ego generation is a significantly harder task because the standard geometric conditioning becomes highly unreliable under extreme view changes and large unobservable regions. We present Grounded-Exo2Ego, a principled framework that addresses these challenges at both the architectural and data levels. Architecturally, Grounded-Exo2Ego is a dual-branch video diffusion model that couples a geometric anchoring branch, which conditions the generation on the rendering of a 3D reconstruction, with a novel semantic grounding branch, which goes beyond the prevailing geometry-based approach and improves quality by synthesizing challenging regions based on object-level context. Additionally, we found that the overlooked issue of camera-reconstruction misalignment severely undermines exo-to-ego learning. We thus introduce a camera re-localization algorithm that resolves this issue and substantially improves quality across all metrics. We further develop a fully automated synthetic data engine that generates and renders rigged 3D characters in procedurally generated environments. Evaluation on the challenging EgoExo4D dataset shows that our method outperforms recent state-of-the-art approaches by large margins across all metrics. Detailed ablations validate improvements from each of our contributions at both the data and architectural level.

## 2. 论文提出的方法论

### 2.1 核心思想
提出 **Grounded-Exo2Ego** 框架，核心是“双分支视频扩散模型”：
- **几何锚定分支（Geometric Anchoring）**：延续主流思路，将 exo 视频提升为 3D 重建，在目标 ego 相机下渲染出几何锚定视频，为扩散模型提供整体结构和相机运动的空间骨架。
- **语义锚定分支（Semantic Grounding）**：新颖设计。从 exo 视图提取对象级语义（类别、短语、分割掩码），将对象掩码重投影到 ego 视图，并利用这些掩码作为交叉注意力门控，将**对象特有的文本 token** 路由到对应的视频 token 上，从而在几何失效（空洞、畸变）的区域，模型仍知道“该画什么、画在哪里”。

### 2.2 关键技术细节

**几何锚定分支**
- 输入：exo 视频 `V_exo`、exo 深度 `D_exo`、相机内参和外参。
- 通过公式 `X(u,v) = D(u,v)·(K_exo)^{-1}·p` 将像素反投影为 3D 点，构建三角网格，用 nvdiffrast 在 ego 相机下光栅化，得到 ego 渲染 `V_ego_tilde`。
- 与 EgoX 的通道拼接不同，采用 IC-LoRA 风格：将渲染的 latent 作为**独立 token 序列**拼接（sequence concatenation），并与噪声 token 共享相同的 RoPE 坐标。同时利用**占用率掩码**（occupancy mask）屏蔽近空白 token，避免空洞区域误导模型。

**语义锚定分支**
1. **语义提取**：使用 VLM（CapRL-Qwen3VL-4B）生成场景描述（整体描述 + 最多 15 个对象短语 + 空间关系 + 预测 ego 视图描述）；用 LLM（Gemma-3-12B）去重、排序，选出 top-K=10 个对象短语。
2. **对象 token 编码**：每个对象短语经 LLM embedding，填充至固定长度 L=10（含共享的可学习 register token），再经可训练投影器映射至 DiT 交叉注意力空间，得到对象 token 包 `O_k`。
3. **掩码重投影**：在 exo 视图用 SAM3 分割每个对象得到 `M_exo_k`，再利用深度将掩码重投影到 ego 视图 `M_ego_k`。
4. **门控交叉注意力**：在原始交叉注意力中，视觉 query token 只能对其所属对象的 token 包进行注意力，非对象区域注意力分数置为 -∞。这样实现了“语义 + 空间”的结构化锚定。完整场景 caption 的交叉注意力保持不变。
5. 实际实现中仅对第一帧做分割，掩码在整个视频片段中广播（为节省算力）。

**数据层改进**
1. **相机重定位（Camera Re-localization）**：
   - 用 MoGe2 生成 exo 单目重建（用于训练/推理渲染）。
   - 用 Depth-Anything-3 结合地面真值 exo 相机位姿构建度量重建（仅作为坐标桥，不参与训练）。
   - 计算 DA3 深度到 MoGe2 深度的**非刚性对齐**，将 GT ego 相机变换到 MoGe2 坐标系中（只修改相机深度/中心，不修改旋转）。
   - 目的不是修复几何，而是建立坐标一致性，使渲染与 GT ego 视频更好对齐，同时保留 MoGe2 的误差特征，避免 train/test 不匹配。
2. **全自动合成数据引擎**：
   - 用 gpt-image-1 + Meshy.ai 生成角色图与 3D 角色，自定义算法对角色进行绑定（rigging）。
   - 使用 Embody3D 中的真实人际交互动作序列驱动角色。
   - 用 Infinigen 程序化生成 640 个室内场景、550 个绑定的角色、3000 个动画，渲染 20000+ 训练片段（Blender 路径追踪）。
   - 随机组合场景、角色、动画，自动搜索合法 exo 相机位置，ego 相机绑在角色颈部骨骼上，生成同步的 exo/ego 视频及精确深度与相机参数。

## 6. 论文的主要结论与发现

- 在 EgoExo4D 上，Grounded-Exo2Ego 在所有指标上大幅超越此前 SOTA（如 EgoX）：
  - PSNR 提升 +1.67 dB（Unseen）/ +2.59 dB（New Action）。
  - LPIPS 降低 −15.4% / −30.5%。
  - 对象定位误差降低 −83.3% / −76.0%，IoU 提升 +347.8% / +58.7%，轮廓误差降低 −47.0% / −62.0%。
  - FVD 降低 −12.4% / −35.0%，T-LPIPS 降低 −37.5% / −45.9%。
- 定性结果说明：通用 NVS 方法（Vista4D）无法处理 exo-to-ego；EgoX 在视角和内容上经常错位；本方法能较好地恢复场景结构、人物对象与相机运动。
- **消融结论**：
  - 相机重定位能显著改善所有指标，尤其几何和对象指标，是“数据级”关键贡献。
  - 序列拼接优于通道拼接：PSNR 略降但结构、视频时序指标大幅改善。
  - 对象 token 本身有帮助，但配合空间掩码（门控）才能发挥最大作用。
  - 空间掩码的重要性大于对象 token 本身；掩码越准确（如用 GT ego 掩码），效果越好。
  - 合成数据能进一步提升分布内质量。
- 作者还强调：“绝对性能仍有很大提升空间（PSNR 仍低于 20dB）”，说明问题远未解决。

## 7. 优点

- **问题定位准确**：明确指出几何条件不适用于 exo-to-ego 的两个本质原因（单目深度错误 + 大范围不可观区域），以及相机-重建错位这一被忽视的训练数据缺陷。
- **系统性解决方案**：同时从架构（双分支 + 语义门控）和数据（相机重定位 + 合成数据引擎）两个层面解决问题，而非单纯堆砌模型技巧。
- **语义锚定机制设计新颖**：将对象级文本 token 与空间掩码结合，通过交叉注意力门控实现“语义空间化”，比直接注入 DINOv3 特征或空间化为特征图更有效。
- **注意训练/测试一致性**：刻意使用不完美的 MoGe2 重建而非修正后的几何，避免引入 train/test 不匹配。
- **合成数据引擎自动化程度高**：从角色生成、绑定、动画到场景布局、相机搜索全自动，可扩展性强。
- **评估严谨**：报告多次生成的均值和标准差；补充了鲁棒性分析（深度/位姿/掩码扰动）；替换了不可复现的 EgoX Contour 指标，并提出更易复现的 Chamfer 距离。

## 8. 不足与局限

- **资源消耗极大**：需要 64 张 H100 GPU 训练；语义提取（VLM、LLM、SAM3）、单目重建、渲染等环节依赖多种外部模型，复现门槛高。
- **推理限制**：输出分辨率仅 448×448、33 帧，长视频需分段自回归；需要显式给定 ego 相机轨迹（实际应用中需额外估计，精度受限）。
- **掩码时序粗糙**：只使用第一帧分割掩码并广播到全部帧，大运动或相机快速移动时门控可能过时。
- **依赖 off-the-shelf 模型**：深度估计、分割、语言模型的错误会传导到生成结果；尤其是当 ego 视图内容在 exo 中严重遮挡或不可见时，模型需要大量幻觉，质量显著下降。
- **评估范围有限**：仅在 EgoExo4D 子集上定量测试；in-the-wild 结果只有定性展示；对比基线的部分数据来自原文，存在协议一致性风险。
- **Ego-Exo 一致性无法保证**：生成视频与输入 exo 视频的精确跨视角一致性（时间同步、物体外观、动作细节）仍不完善，作者承认该问题并建议未来探索在 3D 空间中生成。
- **潜在社会风险**：可用于伪造第一人称视角视频或欺诈，需要水印等保障措施。
