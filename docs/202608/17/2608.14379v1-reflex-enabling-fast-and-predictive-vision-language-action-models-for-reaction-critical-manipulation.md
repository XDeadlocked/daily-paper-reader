## 摘要
视觉-语言-动作（VLA）模型近年来在机器人操作中取得了显著性能。然而，现有基准主要评估静态操作任务上的泛化能力，很大程度上忽略了动态交互场景。为解决这一空白，我们提出了ReflexBench，一个面向反应关键型操作的基准。ReflexBench包含六个动态任务，并引入了一个评估框架，该框架将模拟器步进与机器人控制解耦，同时支持同步和异步推理下的可配置延迟。基于ReflexBench，我们提出了ReflexVLA，一种专为反应关键型操作设计的高效VLA模型，无需大规模机器人数据预训练。ReflexVLA通过潜在未来预测和视觉骨干网络内的多帧时间融合增强了时间推理能力，同时通过批量视觉编码和CUDA Graph重放降低了部署延迟。实验表明，ReflexVLA持续提升动态操作性能，同时在标准静态操作基准上保持有竞争力的准确性，真实世界实验进一步证明了其在实际部署条件下的有效性。项目网站：https://reflexvla.github.io

## Abstract
Vision-Language-Action (VLA) models have recently achieved promising performance in robotic manipulation. However, existing benchmarks mainly evaluate generalization on static manipulation tasks and largely overlook dynamic interaction scenarios. To address this gap, we present ReflexBench, a benchmark for reaction-critical manipulation. ReflexBench contains six dynamic tasks and introduces an evaluation framework that decouples simulator stepping from robot control while supporting configurable latency under synchronous and asynchronous inference. Building upon ReflexBench, we propose ReflexVLA, an efficient VLA model designed for reaction-critical manipulation without large-scale robot-data pretraining. ReflexVLA enhances temporal reasoning through latent future prediction and multi-frame temporal fusion within the vision backbone, while reducing deployment latency through batched visual encoding and CUDA Graph replay. Experiments show that ReflexVLA consistently improves dynamic manipulation performance while maintaining competitive accuracy on standard static manipulation benchmarks, and real-world experiments further demonstrate its effectiveness under practical deployment conditions. ## 2.2 ReflexVLA：快速且可预测的VLA模型

- **基础架构**：紧凑的VLA-Adapter架构，视觉编码器为融合ViT（DINOv2 + SigLIP，224×224分辨率），语言骨干为Qwen2.5-0.5B因果Transformer；动作通过可学习查询和连续回归头输出动作块。

### 关键设计一：潜在未来预测

- 使用**冻结的DINOv3**编码未来观测，获得1024维语义特征 \( y_{t+i} \)。
- 在输入序列后追加H个可学习“未来token”（H=动作块大小），每个token对应一个未来控制步。
- 通过预测头 \( f_{pred} \) 将token隐藏表示映射到DINOv3特征空间，并用**掩码余弦相似度损失**约束：
  \[
  L_{future} = \frac{\sum_i m_i [1 - \cos(\hat{y}_{t+i}, y_{t+i})]}{\sum_i m_i}
  \]
- 总损失：\( L = L_{act} + \lambda_{future} L_{future} \)。
- 优点：只增加与动作块大小相等的token数，额外计算开销可忽略；使用冻结目标比可训练目标更稳定。

### 关键设计二：多帧时间融合

- 使用T帧历史观测，但**不将多帧视觉token直接送入语言模型**，而是在视觉骨干内部完成时间融合。
- 从ViT**中间层**特征提取每个patch的T帧轨迹，经过归一化、降维、添加时间位置编码后，使用**因果多头注意力**（MHA）建模时序关系，再升维并与当前帧的最终层特征相加。
- 融合后只保留当前帧的视觉token数量不变，从而避免语言模型侧的二次方注意力开销。

### 关键设计三：推理延迟优化

- **批量视觉编码**：将所有视角和帧的图像合并为一次视觉编码器前向，避免多次独立调用。
- **CUDA Graph重放**：将完整推理图（视觉编码、时间融合、投影、语言模型、动作预测）捕获为CUDA Graph，执行时直接重放，消除内核调度和运行时开销。
- 两个优化均不改变网络结构和训练目标，仅在部署阶段降低延迟。

- **主实验结果**：ReflexVLA在ReflexBench上平均成功率达到**50.4%**，优于所有基线（PUMA 50.2%、OpenVLA-OFT 36.0%等），且仅用1B参数。
- **静态基准结论**：ReflexVLA在LIBERO上平均97.2%，与OpenVLA-OFT（97.1%）、π0.5（96.9%）相当，说明动态设计不损害静态操作能力。

# 8. 缺点与局限性

- **未来预测仅使用视觉特征**：DINOv3特征只编码未来帧的语义外观，不包含动作/状态变化信息，可能限制对物体运动轨迹的精确预测。
- **时间融合仅在视觉骨干内部**：语言模型侧无法感知多帧视觉信息，可能影响高层语义推理与动作规划的协同。
- **单一数据集来源**：训练数据全部由本文自建的规划+RL管线生成，未验证不同数据质量、示范来源对模型性能的影响。
- **评估遗憾**：Ball Catching任务成功率极低（最高7.3%），表明当前能力尚不足以应对高动态场景；真实实验任务代表性有限，未能覆盖旋转插销等精密动态操作。
- **未报告训练资源**：缺少训练迭代次数、batch size、GPU数量等关键细节，可复现性存疑。

# 9. 改进建议

- **多模态未来预测**：将本体感受（关节位置、速度）和上下文语言指令也纳入未来预测目标，增强对运动趋势的感知。
- **跨层时间融合**：在语言模型端也加入轻量的时间注意力或状态token，让动作解码器直接利用多帧历史信息。
- **增加数据多样性**：使用多种数据生成策略（模仿学习、多任务RL、真实遥操作）扩充示范库，验证Robustness。
- **细化消融范围**：在全部6个任务上报告逐任务消融结果，并添加标准差；补充训练成本（GPU时数、显存占用）。
- **挑战更高难度任务**：提高Ball Catching的成功率，并在真实机器人上增设旋转插销等精细动态任务，验证实用边界。

# 10. 个人思考与启发

- **动态场景是VLA落地的试金石**：本文表明“快”和“准”需要协同设计，单纯增大模型或增加数据并不能解决延迟问题，系统的延迟感知性应成为设计的一等公民。
- **轻量模型+结构化优化优于暴力堆参**：通过冻结预测目标、中间层时间融合、CUDA Graph等精细化手段，1B模型可达到7B模型的效果，这为边缘端部署提供了可行路径。
- **基准设计需要“延迟感知”**：传统同步评估会高估模型的真实表现；将推理延迟显式纳入仿真环境，可更公平地比较不同模型的实际可部署性。
- **未来方向**：将ReflexBench扩展到多机器人协作、高速运动限制、部分可观测场景；探索预测未来状态与动作规划端到端联合优化；在真实部署中引入动态重新规划与安全机制。

# 11. 结论

本文提出了面向反应关键型操作的延迟感知基准ReflexBench和高效VLA模型ReflexVLA，通过引入潜在未来预测、多帧时间融合和多级推理延迟优化，在动态仿真任务与真实机器人操作中均取得了优异性能。工作为VLA在动态环境中的评估与部署提供了系统方案，但也存在预测模态单一、评估覆盖面有限等问题。整体上，这是一项基准设计、模型创新与工程优化紧密结合的高质量研究，对后续动态机器人学习研究具有重要参考价值。
