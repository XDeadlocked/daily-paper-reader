## 摘要
现代视觉-语言-动作（VLA）策略已具备广泛的操作技能，但通常仅根据当前观测或较短的固定长度历史生成每个动作块。然而，现实世界中的操作往往是非马尔可夫的，要求机器人从长时序交互历史中保留并推理与任务相关的信息，以决定下一步动作。为应对这一挑战，我们提出了HyMeS，一种混合学习框架，利用编码智能体的推理与记忆管理能力来引导马尔可夫VLA策略完成记忆依赖型操作。具体而言，HyMeS通过基于梯度的模仿学习学习底层运动技能，而编码智能体则通过启发式学习，利用从轨迹反馈中迭代更新可执行启发式系统来获得高层记忆管理策略。此外，我们通过多模态阶段完成验证来闭环引导与执行之间的回路，该验证利用本体感觉信号和多帧VLM判断来更新记忆。与端到端的记忆增强VLA相比，HyMeS仅需针对可复用运动技能提供示范数据，而无需覆盖每种历史依赖型任务配置，从而实现了数据高效的组合泛化。在RoboMemArena基准上，相对于pi0.5，HyMeS将平均累积成功率从52.5%提升至66.2%，平均任务成功率从41.3%提升至60.1%，同时在累积成功率上超越PrediMem 4.5个百分点，在任务成功率上超越其14.5个百分点。

## Abstract
Modern vision-language-action (VLA) policies have acquired broad manipulation skills, but typically generate each action chunk from the current observation or a short fixed-length history. However, real-world manipulation is often non-Markovian, requiring robots to retain and reason over task-relevant information from long-horizon interaction histories to determine the next action. To address this challenge, we propose HyMeS, a hybrid learning framework that leverages the reasoning and memory-management capabilities of coding agents to steer a Markovian VLA for memory-dependent manipulation. Specifically, HyMeS learns low-level motor skills through gradient-based imitation learning, while a coding agent acquires high-level memory-management strategies through heuristic learning by iteratively updating an executable heuristic system from rollout feedback. Furthermore, we close the loop between steering and execution through multimodal stage-completion verification, which updates memory using proprioceptive signals and multi-frame VLM judgments. Compared with end-to-end memory-augmented VLAs, HyMeS requires demonstrations only for reusable motor skills rather than for every history-dependent task configuration, enabling data-efficient compositional generalization. On RoboMemArena, HyMeS improves mean cumulative success from 52.5% to 66.2% and mean task success from 41.3% to 60.1% over pi0.5, while outperforming PrediMem by 4.5 points in cumulative success and 14.5 points in task success.

## 1. 论文的核心问题与整体含义

- **背景**：机器人操作中的视觉-语言-动作（VLA）模型（如 π0.5、π0.6）虽然在多样环境中展现出广泛的操作技能，但普遍是**马尔可夫式**的——每次生成动作块时只依赖当前观测或较短固定长度的历史窗口。
- **核心问题**：许多真实世界操作任务本质上是**非马尔可夫**的，需要机器人从长时序交互历史中提取、保留并推理任务相关信息，才能确定下一步动作。例如，需要记住一开始卡片上写明的按压次数，或记住某个物体的原始位置以完成转移任务。
- **挑战**：当历史信息无法从当前观测中恢复时（即观测被“遮蔽/混叠”），马尔可夫策略必须在互不相容的动作模式之间做平均，因此无法匹配最优策略。
- **研究意义**：提出一种新的混合学习范式——**把运动技能和记忆策略分开学习**：技能存放在网络权重中，记忆策略存放在可执行代码中，从而以更高效、更可解释的方式解决记忆依赖型操作任务。

## 2. 方法论

- **核心思想**：利用**编码智能体（Coding Agent）**的推理与记忆管理能力来“引导”一个马尔可夫 VLA 完成记忆依赖任务，而不是把记忆逻辑也塞进网络权重。
- **两阶段学习机制**：
  1. **运动技能学习（权重空间）**：使用流匹配（flow matching）目标和梯度式模仿学习，从专家示范 `D` 中微调 VLA 的权重，学习接触丰富的底层运动技能。微调后权重固定。
  2. **记忆策略学习（代码空间）**：编码智能体通过**启发式学习**，根据当前阶段的滚动（rollout）反馈不断迭代更新可执行启发式程序 `P = (C, V, U)`，其中：
     - `C`：约束选择规则
     - `V`：事件验证规则
     - `U`：记忆更新规则
- **闭环引导执行流程**：
  - 编码智能体根据指令与初始观测初始化符号记忆 `s_t`，包含当前计划、激活阶段、绑定、计数器、持久状态等。
  - 每一控制步，根据当前记忆状态选择可微分约束奖励 `R_t`（如到达目标位置的奖励项）。
  - 该约束的梯度被注入 VLA 的流匹配去噪过程，引导动作生成与当前记忆状态一致，且**不更新任何策略权重**。
  - 通过**多模态阶段完成验证（PACE）**判断当前阶段是否完成：
    - 使用**本体感觉信号**（如关节姿态、运动模式）和**多帧 VLM 判断**（Qwen3-VL-8B 基于最近 5 帧判断完成情况）；
    - 两个证据流取或运算，并在滑动窗口内做多数投票，抑制孤立错误；
    - 接受事件后更新记忆并激活下一阶段约束，实现“引导-执行-验证-更新”的闭环。
- **代表性公式**：
  - 记忆依赖任务形式化：`π*(a_t | h_t, ℓ) = π*(a_t | o_t, z_t, ℓ)`
  - 流匹配损失：`E[||v_θ(a_τ, τ | o, ℓ) - (a - ϵ)||²]`
  - 约束注入：`v̂ = v_θ* + λ_t ∇_aτ R_ρt(a_τ, o_t; s_t)`
  - PACE 事件触发：`e_t = I[Σ_{i=r-w+1}^{r} d_i ≥ k]`，实验中使用 `w=5, k=3`

## 3. 实验设计

- **任务类别**：
  - **转移任务**（Transferring），如将布丁和黄油放入柜子等。
  - **计数任务**（Counting），如按卡片数字按钮、重复倒料等。
  - **序列执行任务**（Sequence），如按顺序放置多个物体。
  - **遮挡任务**（Occlusion），如物体被遮挡后仍需记忆位置。
- **模拟实验**：
  - 对比方法：
    - 基础 π0.5 策略（与 HyMeS 权重相同）
    - PrediMem（RoboMemArena 自带的记忆增强基线）
  - 评价指标：**Task Success Rate (TSR)** 和 **Cumulative Success Rate (CSR)**。
- **真实机器人实验**：
  - 使用 **SO-101** 机器人，在 3 个记忆依赖任务上进行测试（观察-拾取、数字引导的按钮按压、放回积木），每个方法共 35 次试验；HyMeS 与 π0.5 共享相同的示范数据与微调权重。
- **消融实验**：在六任务子集（覆盖四类任务）上进行三种对比：
  - 一次性程序 `P(0)` vs. 滚动优化后的 `P*`（验证启发式学习的作用）；
  - 仅视觉验证 vs. 仅本体感觉验证 vs. 两者结合（验证 PACE 多模态证据的必要性）。

## 6. 论文的主要结论与发现

- **模拟实验**：
  - 在相同策略权重下，HyMeS 将 CSR 从 π0.5 的 52.5% 提升到 66.2%，TSR 从 41.3% 提升到 60.1%。
  - 相较于 PrediMem，HyMeS 的 CSR 提升 4.5 点，TSR 提升 14.5 点，说明其更能将阶段性进展转化为最终任务成功。
  - 在计数任务上，HyMeS 的 TSR 高于 PrediMem（50.0% vs 36.7%），但 CSR 反而更低（60.3% vs 72.2%），失败集中在早期阶段。
  - 遮挡任务对记忆注入而言最具挑战性：PrediMem 甚至低于反应式 π0.5；HyMeS 则保持 CSR 不变但使 TSR 提升了 7.0 点。
- **真实实验**：整体 TSR 从 π0.5 的 25.7% 提升至 57.1%，验证了可执行记忆在真实硬件上的有效性。
- **消融结果**：
  - 使用滚动优化后的程序比一次性程序提高 CSR 8.5 点、TSR 18.4 点；
  - 仅用视觉信号或仅用本体感觉信号均显著降低性能（视觉单模态 CSR/TSR 分别下降 16.0/21.7 点，本体感觉单模态下降 8.8/8.4 点），证明多模态验证的必要性。
- **整体结论**：HyMeS 可以在不改变策略权重、不需要覆盖所有历史依赖配置的示范数据的情况下，通过“代码空间记忆 + 权重空间技能”的混合设计，显著提升记忆依赖任务的表现，且具备可解释性和数据效率。

## 7. 优点

- **创新性强**：明确将运动技能（权重）和记忆策略（代码）分离，打破了端到端记忆增强 VLA 的单一范式，为记忆依赖型操作提供了新的混合学习视角。
- **数据效率高**：示范数据仅需覆盖可复用的运动技能，不需要枚举组合性的历史状态；新的记忆配置可通过编辑代码实现，无需重新收集示范。
- **可解释性好**：符号记忆状态在每一步都可读，失败可以定位到记忆更新、运动执行或阶段验证哪一环节，便于诊断和修正。
- **兼容性广**：基于冻结的预训练 VLA，通过注入约束梯度引导生成，能与现有各类 VLA 模型直接结合。
- **闭环设计完整**：PACE 多模态验证将记忆更新与物理执行衔接起来，减少了错误记忆累积导致的失败。

## 8. 不足与局限

- **任务表示受限**：当前方法专注于可由**紧凑符号状态**表示的记忆依赖任务；对于需要更复杂、开放式或层级化记忆的任务，可扩展性尚未验证。
- **运动技能仍为瓶颈**：即使记忆和约束正确，接触丰富的操作仍可能因预训练 VLA 的执行偏差而失败（如抓取偏移、按压深度不足、额外误触等）。
- **验证机制开销大**：周期性 VLM 查询和编码智能体调用会增加推理延迟和经济成本，不利于实时性要求高的场景。
- **遮挡场景表现不理想**：视觉完成证据在遮挡条件下可靠性低，HyMeS 虽然优于 PrediMem，但整体水平仍与反应式 π0.5 相当，说明视觉记忆验证仍有较大改进空间。
- **实验规模有限**：真实机器人只有单平台、单任务集；模拟任务均为 RoboMemArena 的修正子集，未展示在更多公开基准上的表现。
- **算力与复现信息不足**：论文未披露训练/评估所需的计算资源、迭代运行次数、编码智能体调用成本等，可能影响复现和工程实践上的评估。
