## 摘要
鲁棒的机器人控制受益于显式建模状态转移，但视频生成世界动作模型（WAM）带来了巨大的部署成本。现有的潜在WAM避免了显式的未来生成，但常常压缩预测表示或将预测建模与用于动作生成的表示分离。我们提出了JEPA-WAM，一种构建在预训练V-JEPA空间中的潜在WAM，通过共享预测器将潜在转移预测与连续动作生成耦合。JEPA-WAM预测一个空间结构的联合当前-未来目标，该目标捕获当前和未来观测之间任务共享的视觉时间结构，同时保留密集的补丁级对应关系。通过共享预测器，转移监督直接塑造主干网络，从中提取专用表示用于动作预测。相同的设计也可以实例化到预训练的VLA策略中，同时保留其原始感知和动作通路。在LIBERO-Plus上，JEPA-WAM达到79.2%，是没有大规模机器人策略预训练的最佳结果，而其预训练的π0.5实例达到86.3%，实现了最佳总体性能。在RoboTwin 2.0和真实世界双臂操作上的实验进一步证明了在视觉和空间变化下的强泛化能力。

## Abstract
Robust robot control benefits from explicitly modeling state transitions, but video-generation world action models (WAMs) introduce substantial deployment cost. Existing latent WAMs avoid explicit future generation, but often compress predictive representations or separate predictive modeling from the representations used for action generation. We introduce JEPA-WAM, a latent WAM built in a pretrained V-JEPA space, which couples latent transition prediction with continuous action generation through a shared predictor. JEPA-WAM predicts a spatially structured joint current-future target that captures task-shared visual temporal structure between current and future observations, while preserving dense patch-level correspondence. Through the shared predictor, transition supervision directly shapes the backbone, from which dedicated representations are extracted for action prediction. The same design can also be instantiated in pretrained VLA policies while preserving their original perception and action pathways. On LIBERO-Plus, JEPA-WAM achieves 79.2%, the best result without large-scale robot-policy pretraining, while its pretrained $π_{0.5}$ instantiation reaches 86.3%, achieving the best overall performance. Experiments on RoboTwin 2.0 and real-world bimanual manipulation further demonstrate strong generalization under visual and spatial shifts.

## 2. 论文提出的方法论

### 核心思想

JEPA-WAM 在预训练的 V-JEPA 2.1 表示空间中构建潜在世界模型，通过**共享预测器**将潜在转移预测与连续动作生成耦合。其关键创新在于：

1. **预测目标**：不预测绝对未来状态，而是预测"联合当前-未来目标"（joint current–future target），该目标通过联合编码当前观测与未来观测来捕获它们之间的时间关系，同时保留密集的 patch 级空间结构。
2. **集成方式**：共享预测器同时执行转移预测和动作生成，使转移监督直接优化用于动作生成的同一主干网络。

### 关键技术细节

**（1）V-JEPA 表示空间与联合当前-未来目标**

- 使用冻结的 V-JEPA 2.1 编码器 \(E_J\) 提供密集 patch 级表示，而非全局池化表示。
- 当前视觉表示：\(Z_t = \text{Concat}_{v \in V} E_J(O_v^t) \in \mathbb{R}^{N_{vis} \times d_J}\)，多个视角按固定相机顺序拼接。
- 联合当前-未来目标：\(Y_{t,t+\delta} = \text{Concat}_{v \in V} \text{sg}[E_J(\text{Stack}_{time}(O_v^t, O_v^{t+\delta}))]\)，即在时间维度上堆叠当前与未来观测后联合编码。
  - 由于 V-JEPA 2.1 的 video tokenizer 将每两帧分组为一个时间 tubelet，两帧联合输入产生与单帧图像相同的空间 token 网格，因此目标与当前表示共享相同的相机与空间 token 顺序。
  - 相比未来-only 目标 \(E_J(O_{t+\delta})\)，联合目标使两个时间端点同时可用，强调视觉关系（哪些区域保持稳定、哪些变化、局部物体与空间关系如何演变），而非要求重建完整或唯一的未来观测。

**（2）共享预测器**

- 共享预测器 \(F_\theta\) 用 Qwen2.5-0.5B 实例化，处理投影后的视觉 token、任务指令 \(\ell\) 和专用动作占位符 token \(P_{act}\)：
  \[
  (Q_t^{wm}, C_t) = F_\theta(P_{vis}(Z_t), \ell, P_{act})
  \]
  - \(Q_t^{wm}\)：视觉 token 位置的隐藏状态，用于预测联合当前-未来目标。
  - \(C_t\)：用于动作生成的专用表示。
- 轻量视觉投影器 \(P_{vis}\)（两层 MLP，1024→896→896）桥接冻结的 V-JEPA 编码器与 Qwen 预测器。

**（3）潜在转移预测**

- 预测头 \(G_\phi\)（token-wise MLP，896→2048→1024）将隐藏状态映射回 V-JEPA 空间：
  \[
  \hat{Y}_{t,t+\delta} = G_\phi(Q_t^{wm})
  \]
- 优化目标为平均 patch 级余弦距离：
  \[
  L_{wm} = \frac{1}{BN_{vis}} \sum_{b=1}^{B} \sum_{n=1}^{N_{vis}} \left(1 - \cos(\hat{Y}_{t,t+\delta,n}^{(b)}, Y_{t,t+\delta,n}^{(b)})\right)
  \]

**（4）动作预测与生成**

- 采用 DiT 动作专家 \(A_\psi\)（16 层 DiT-L），基于条件流匹配（conditional flow matching）：
  \[
  L_{act} = \mathbb{E}_{\epsilon,\tau}\left[\|A_\psi(a_\tau, \tau, s_t, C_t) - (a - \epsilon)\|_2^2\right]
  \]
- LIBERO 使用速度预测目标；RoboTwin 2.0 使用 x-prediction（直接预测干净动作轨迹）。

**（5）联合训练**

- 总损失：\(L = L_{act} + \lambda_{wm} L_{wm}\)，其中 \(\lambda_{wm} = 0.5\)。
- 部署时移除目标分支和预测头，仅保留当前观测编码、视觉投影器、共享预测器和动作专家，无额外推理开销。

**（6）迁移到预训练 VLA 策略**

- 在预训练 π0.5 中引入 64 个可学习 future tokens，将其输出隐藏状态重塑为 8×8 粗网格特征图，经轻量投影和双线性上采样至 24×24，与冻结的 V-JEPA 2.1 ViT-G 联合目标进行 patch 级对齐。
- 保留策略原始感知与动作通路，动作 token 被屏蔽了对新引入 query 的注意力。

## 6. 论文的主要结论与发现

1. **JEPA-WAM 在 OOD 泛化上表现突出**：
   - LIBERO-Plus 平均成功率 79.2%，是无机器人策略预训练方法中的最佳结果；同时保持 LIBERO ID 96.7% 的竞争力。
   - RoboTwin 2.0 上 Clean 79.9%、Random 36.9%，Random 性能大幅优于无预训练基线（DP3 仅 8.3%），且与预训练 π0.5（37.2%）相当。

2. **相同的转移监督可提升预训练 VLA 策略**：
   - π0.5+JEPA Obj. 在 LIBERO-Plus 上从 84.5% 提升至 86.3%（最佳总体结果）；LIBERO ID 从 96.9% 提升至 97.8%；RoboTwin Clean 从 75.4% 提升至 84.6%；真实世界 ID 从 77.5% 提升至 90.3%、OOD 从 72.5% 提升至 84.7%。

3. **V-JEPA 潜在空间本身是 OOD 策略学习的强基础**：仅使用 V-JEPA 表示（无转移预测）即将平均成功率从 DINOv2+SigLIP 的 73.2% 提升至 77.0%。

4. **联合当前-未来目标优于未来-only 与端点差分**：未来-only 77.3%，端点差分仅 70.9%，联合目标 79.2%。探针实验表明联合目标编码了超出端点一阶差分的时间关系与区间内轨迹结构。

5. **patch 级空间监督优于局部混合变换**：iREPA 风格卷积变换将性能从 79.2% 降至 74.7%。

6. **最终层监督优于中间层辅助信号**：Lower-16 变体降至 76.5%。

7. **专用动作占位符优于全隐藏状态条件化**：Full-hidden 变体降至 73.1%，表明直接共享转移表示可能造成目标干扰。

8. **部署效率高**：85 ms/次推理（11.76 Hz），优于 ABot-M0，且转移预测分支仅在训练时使用。

## 7. 优点

### 方法亮点

1. **设计思路清晰**：明确回答了两个核心设计问题（预测什么、如何集成），管线逻辑自洽。
2. **联合当前-未来目标具有新意**：不同于未来-only 或紧凑子目标，通过联合编码保留时间关系与 patch 级空间结构，避免压缩信息损失。
3. **共享预测器耦合设计**：让转移监督直接优化

## 7. 优点（续）

3. **共享预测器耦合设计**（续）：让转移监督直接优化用于动作生成的同一主干网络，而非将预测建模作为旁路或辅助上下文，确保了世界模型学习对策略主干的直接影响，这是与 VLA-JEPA（预测与动作生成分离）和 π0.5+JEPA Obj.（仅对齐冻结表示）的关键差异。
4. **不牺牲推理效率**：转移预测分支与预测头仅在训练时存在，部署时零额外开销，解决了视频生成式 WAM 的部署成本痛点。
5. **表示空间选择具有迁移价值**：沿用预训练 V-JEPA 表示而非从零学习潜在空间，既降低了训练难度，又验证了"冻结大规模自监督视频表示 + 轻量学习"范式的可行性。
6. **实验验证体系完整**：从模拟到真实、从无预训练到有预训练、从 ID 到 OOD，并辅以探针分析揭示表示空间的语义特性，证据链较完整。

2. **对比分组合理**：将有/无大规模策略预训练的方法分开对比，避免了对预训练基线的"不公平"贬低，增强结论可信度。
3. **附属分析扎实**：附录中的探针实验（时间间隔解码、轨迹结构分析等）不仅验证设计选择，还深化了对 V-JEPA 潜在空间特性的理解。

## 8. 不足与局限性

### 实验层面的不足

1. **真实世界评测样本量有限**：每个任务/设置仅 10 次 rollout，统计功效较弱，且未报告 95% 置信区间或逐任务方差。
2. **缺少多次随机种子的方差报告**：LIBERO 与 RoboTwin 的关键数值未说明是否取多次重复的平均值，难以判断差异的统计显著性。
3. **OOD 泛化的边界刻画不充分**：LIBERO-Plus 的 7 类扰动均为相对温和的视觉变化，未评估更大程度的外推（如相机视角大幅改变、机械臂动力学变化、未见任务组合）。
4. **真实世界仅对比 4 种策略**：未包含 ABot-M0、Fast-WAM 等论文的主要对比方法，真实世界结论的外部效度有限。

### 方法与理论层面的不足

1. **对 V-JEPA 表示空间的依赖性**：方法核心前提是"V-JEPA 表示在 OOD 下持有足够不变性"，论文未系统分析 V-JEPA 在何种扰动程度下开始失效，以及这种失效如何传导至 JEPA-WAM 的性能。
2. **联合当前-未来目标的机制解释不够深入**：探针实验虽表明该目标编码了额外时间结构，但未从理论上解释为何联合编码比未来-only 更利于 OOD 泛化（是正则化效应、信息瓶颈、还是目标平滑性？）。
3. **λ_wm 加权未细致调节**：固定为 0.5，未报告该超参数的敏感性分析。
4. **动作占位符设计缺乏对长度/位置的系统分析**：64 个 future tokens 的数量与位置（插在视觉 token 之后）是否最优，未给出消融。
5. **预训练 VLA 迁移的适用范围有限**：仅迁移到 π0.5 一个基座模型，未评估对 π0、RDT-1B 等其他预训练 VLA 的通用性。

## 9. 个人思考与潜在改进方向

### 关于方法本身

- **自适应联合目标**：当前联合目标对每个示例等权约束所有 patch。可考虑按 patch 的动态显著性（如运动幅度大的区域）加权，让模型重点预测真正决定任务成败的空间变化。
- **多尺度时间目标**：当前仅预测单一时距 δ 的联合目标。可扩展为多时距（短程与长程）联合预测，帮助模型同时捕捉局部操作与全局任务进度。
- **预测器与动作专家的更深耦合**：目前共享预测器输出的隐藏状态直接供动作专家使用，可探索将动作生成的梯度以自适应的方式回传到转移预测分支（而非简单相加权重）。

### 关于验证

- **更大规模的 OOD 泛化测试**：在 RoboTwin 上加入未见相机角度、未见背景与未见物体组合之外的泛化测试（如未见力控需求、随机化物体物理属性）。
- **跨基座迁移评估**：将相同的"共享预测器监督"框架应用到更多预训练 VLA（如 RDT-1B、Octo），检验其通用性。
- **统计显著性补强**：增加多次随机种子重复与置信区间报告，提升结论可靠性。

### 关于理论基础

- 可进一步从**信息论视角**分析联合目标为何优于未来-only：联合编码相当于对"状态对的共同信息"进行压缩，可能更接近任务相关的不变结构；未来-only 则要求重建概率上不完全可预测的未来，引入不必要的预测噪声。
