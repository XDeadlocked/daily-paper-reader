## 摘要
视觉-语言-动作（VLA）模型是具身策略中广泛采用的范式。它们擅长高效的闭环控制，但并未显式建模任务展开时物理场景如何演变。最近出现的世界-动作模型（WAMs）利用预训练的视频世界模型来捕获时空演变，但在控制回路中保留未来生成或大型视频骨干会大幅增加推理成本。我们引入了World Tokens，一种围绕World Adapter构建的具身策略架构，它桥接了视觉-语言理解、世界动态建模和动作生成。它在训练期间使用世界建模来增强动作策略，同时保持高效的部署。具体来说，World Adapter将VLM特征转换为固定数量的世界令牌（world tokens），这些令牌条件化一个联合微调的未来视频去噪器，并同时作为动作专家唯一的视觉-语言上下文。这种共享条件化使得来自未来视频去噪的梯度能够直接塑造用于动作预测的表征，而独占路由防止策略绕过该表征。在部署时，世界模型分支被移除，仅保留VLM、World Adapter和动作专家，无需在线视频模型推理。采用2B骨干且无需具身动作预训练，World Tokens在LIBERO上极具竞争力，在SIMPLER上取得了报告的最佳平均值，与匹配的仅动作基线相比，显著提高了真实世界R1 Pro的成功率，并以VLA级别的延迟生成每个动作块。

## Abstract
Vision-language-action (VLA) models are a widely adopted paradigm for embodied policies. They excel at efficient closed-loop control but do not explicitly model how physical scenes evolve as a task unfolds. Recently emerging world-action models (WAMs) leverage pretrained video world models to capture spatiotemporal evolution, yet retaining future generation or a large video backbone in the control loop substantially increases inference cost. We introduce World Tokens, an embodied policy architecture built around a World Adapter that bridges visual-language understanding, world-dynamics modeling, and action generation. It uses world modeling during training to enhance the action policy while preserving efficient deployment. Specifically, the World Adapter transforms VLM features into a fixed set of world tokens, which condition a jointly fine-tuned future-video denoiser and simultaneously serve as the action expert's sole visual-language context. This shared conditioning allows gradients from future-video denoising to directly shape the representation used for action prediction, while exclusive routing prevents the policy from bypassing that representation. At deployment, the world-model branch is removed, leaving only the VLM, World Adapter, and action expert, with no online video-model inference. With a 2B backbone and no embodied action pretraining, World Tokens is highly competitive on LIBERO, attains the best reported averages on SIMPLER, substantially improves real-world R1 Pro success over a matched action-only baseline, and generates each action chunk at VLA-level latency.

## 1. 核心问题与研究动机（背景）

- **VLA 模型的优势与缺陷**：Vision-Language-Action (VLA) 模型将预训练视觉-语言模型（VLM）与动作专家结合，实现高效的闭环控制。但 VLM 的图像-文本预训练几乎没有提供动作相关的时序变迁监督（如接触、遮挡、物体位移），而动作选择往往取决于场景"如何演变"而非当前外观，导致 VLA 必须从数量有限的机器人演示中学习这些关键动态。
- **世界-动作模型（WAM）的代价**：WAM（如 Motus、Cosmos Policy、DiT4DiT 等）将视频生成与控制联合建模，能捕捉更好的时空动态，但**将视频生成或大型视频骨干保留在控制回路中**，导致推理延迟大幅增加（如 Cosmos Policy 610ms/块）。
- **关键矛盾**：如何在**训练时获得世界建模带来的表征增益**，同时在**部署时完全移除视频模型**，保持 VLA 级别的推理效率？
- **已有方案的不足**：一些轻量预测方法不保留视频骨干，但预测监督通常只通过并行分支起作用，动作专家仍可访问完整 VLM 上下文——控制器可以**直接忽略**被世界建模塑造的子空间，导致预测与动作在表征空间中脱节。本文的核心问题正是：**如何让世界建模更好地塑造用于具身控制的表征，同时训练后完全移除世界模型？**

## 2. 方法论

### 2.1 总体架构思想

World Tokens 采用**训练和部署采用不同计算图**的设计：

- **部署路径**（保留）：VLM + World Adapter + 动作专家（DiT）
- **训练路径**（额外）：预训练视频扩散世界模型（仅训练用）

核心思想：VLM 特征通过 World Adapter 压缩为固定数量的 **world tokens**，该 tokens 既是动作专家的**唯一**视觉-语言上下文，也作为未来视频去噪器的条件。由此，视频去噪的梯度**直接塑造**动作预测所用的同一表征。

### 2.2 关键技术组件

**(1) World Adapter**

- 采用 Perceiver resampler 设计：维护 $K=256$ 个可学习查询，每个块对 VLM 隐藏状态做交叉注意力、查询间自注意力和 FFN 更新。
- 公式：$h_t = f_\phi(o_t, \ell)$，$q_t = b_\psi(h_t) \in \mathbb{R}^{K \times d}$。
- 将变长的 VLM 序列压缩为定长表征。

**(2) 独占动作路径（Exclusive routing）**

- 动作专家 $g_\theta$ 是 DiT flow-matching 模型，**仅**以世界 tokens $q_t$ 为条件生成动作块：$a_t^H \sim g_\theta(\cdot\,|\,q_t)$。
- 这强制所有视觉-语言上下文必须流经 $q_t$——**杜绝了控制器绕过世界建模表征的直接通路**。

**(3) 训练时世界模型分支**

- 预训练视频扩散模型 $W_\omega$（Cosmos Predict2.5-2B）接收世界 tokens 投影 $q_t^{wm} = p_\rho(q_t)$ 作为交叉注意上下文，去噪演示的未来视频片段。
- **结构锚（Structural anchor）**：用**Canny 边缘图**（灰度化→Canny 阈值 60/140→高斯模糊 σ=2.5→VAE 编码）替代 RGB 首帧作为视频分支的第一帧条件。目的是**抑制外观信息**，迫使世界 tokens 承担传递丰富视觉语义的责任，防止去噪器依赖外观持续性而弱化对 tokens 的依赖。

**(4) 联合训练目标**

$$\mathcal{L} = \mathcal{L}_{act} + \lambda_w \mathcal{L}_{vid}, \quad \lambda_w = 0.5$$

- 动作损失（flow matching，线性插值路径）
- 视频损失（原生扩散公式）
- 两条梯度路径**汇合于 world tokens** $q_t$，实现预测监督对控制表征的直接塑造。

### 2.3 初始化与部署

- VLM 和视频去噪器从预训练 checkpoint 微调；World Adapter、投影层、动作专家从头训练；VAE 编码器冻结。
- **部署时完整移除视频分支**（VAE、投影、去噪器），仅需 VLM + Adapter + 动作专家，4 步流积分生成动作块，未来帧和目标锚均不需要。

## 6. 主要结论与发现

1. **训练时世界建模有效**：World Tokens 在 LIBERO 达到 98.2% 平均成功率（2B 骨干、无具身动作预训练），超越 StarVLA（4B）和 World2Act（3B+PT），与需在线视频推理的 DiT4DiT（98.6%，136ms）和 Cosmos Policy（98.5%，610ms）相当或更优，而推理延迟仅 61.85ms/块，约 π0.5 的 1.1 倍。
2. **SIMPLER 最佳**：WidowX 平均 71.5%、Google Robot 平均 82.1%，均为报告最佳，说明优势可泛化到真实训练数据的仿真评测。
3. **真实世界有效**：R1 Pro 从 59.4% 提升至 76.0%（96 试次池化），草莓和香蕉提升最显著；注意力可视化显示世界模型监督使 tokens 关注与任务阶段相关的目标（抓取前关注目标物、抓取后关注篮子），而未监督的变体保持弥散。
4. **条件性结论（最重要）**：预测监督**并非无条件有益**——当动作专家可以绕过受监督表征（VLM bypass）或提取器缺乏可学习查询（FFN adapter）时，视频目标反而与动作预测竞争（94.1%、93.4%，均低于无视频监督的 95.0%）。**独占路由 + 查询式提取是将训练时世界建模变为有用的机制，而非实现细节。**
5. **Canny 锚的必要性**：用 RGB 首帧替换边缘锚后 Long 成功率从 97.0% 降至 91.5%，证明外观抑制的条件化迫使世界模型真正依赖 tokens 获取任务相关内容。

## 7. 方法亮点

1. **干净的问题切分**：将世界模型的"表征收益"与"推理成本"彻底解耦——训练时用完整视频扩散模型监督，部署时零视频计算，概念上干净且工程上优雅。
2. **独占路由设计是真正的机制创新**：不同于以往并行分支容易被策略忽略的做法，强制动作专家只能消费被世界建模塑造过的表征，从架构上保证预测监督有效传导。
3. **Canny 边缘锚的巧思**：用简单的手工预处理就避免了视频分支代偿（依赖外观持续性），促使世界 tokens 携带更丰富的语义-动态信息，设计精巧且可解释。
4. **统一的训练目标**：动作与视频均使用条件去噪目标，共享梯度路径在 $q_t$ 汇合，无需辅助损失或多阶段训练。
5. **出色的效率-性能平衡**：2B 骨干 + 0.5B Adapter 达成超越更大模型的效果，延迟与 π0.5 相当（61.85 vs 56.32ms），且无需具身预训练。
6. **多维度验证体系**：仿真、仿真-真实混合、真实机器人三线验证 + 机制消融 + 注意力分析 + 延迟公平对比，证据链较为完整。

## 8. 不足与局限

1. **训练成本显著增加**：作者承认世界模型微调带来相当大的训练开销（需联合微调 2B 视频去噪器），限制了训练可扩展性。
2. **Canny 锚为手工设计**：依赖固定阈值和手工参数，可能对域差异敏感；作者也承认未来需要学习式替代方案。
3. **LIBERO 近饱和问题**：除 Long 套件外各套件高度饱和（>97%），消融差异几乎全部集中于 Long，需要依赖单一套件做机制判断，统计敏感性有限。
4. **注意力分析以单集代表性展示为主**：每任务仅取 1 集进行可视化；（32 步的配对检验基于同一集内相邻步，非独立样本），只能作为辅助证据而非因果证明。
5. **真实机器人场景单一**：仅四种果蔬抓放任务、单一机器人平台，未涵盖更复杂的操作类型；芒果任务无提升（头部空间小）也提示增益的不均匀性。
6. **延迟对比的公平性有边界**：部分对比数值引自原文（不同 GPU、不同协议）；同一硬件测量的对比（π0.5）在相同配置下进行，但跨框架（PyTorch vs JAX/XLA）的编译行为差异仍可能存在未显式控制的因素。
7. **SIMPLER 的 Google Robot 部分存在报告口径不一致问题**：部分方法的平均分可能不含 Place 任务，需逐列比较。
8. **应用限制**：世界模型依赖预训练视频模型质量，对超出其分布的场景（如新型接触动力学）的监督能力未验证；tokens 无预定义语义，可解释性有限。
