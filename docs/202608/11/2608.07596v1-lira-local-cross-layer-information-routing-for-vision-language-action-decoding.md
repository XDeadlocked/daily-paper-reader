## 摘要
视觉-语言-动作（VLA）模型将预训练的视觉-语言模型（VLM）的表征转换为机器人动作，然而，将中间VLM特征路由到动作解码器的接口仍未得到充分探索。现有设计要么仅暴露表征层级中狭窄的部分，要么将每个解码器模块严格匹配到一个VLM层，从而限制了对跨深度的互补任务证据的访问。我们提出了LIRA，一种局部跨层动作条件机制，将VLM到动作的条件化表述为深度感知的信息路由。LIRA作用于任务令牌特征和从中间VLM状态导出的LIRA查询特征，然后为每个并行融合块分配一个以其对应VLM层为中心的深度对齐局部窗口。并行融合块聚合邻近的LIRA查询特征，并在动作预测之前将其与任务令牌特征和本体感受输入集成。该路由接口保持主干架构、动作解码器和监督训练方案不变。在LIBERO、LIBERO-Plus、CALVIN ABC→D以及真实世界操作中，在相同的0.5B参数配置下，LIRA相比VLA-Adapter基线提高了主要聚合指标。在到LIBERO-Plus的零样本迁移中，LIRA将平均成功率从59.1%提高到78.0%，提升了18.9个百分点，表明在受控分布偏移下鲁棒性得到改善。

## Abstract
Vision-Language-Action (VLA) models transform representations from pretrained vision-language models (VLMs) into robot actions, yet the interface that routes intermediate VLM features into action decoders remains underexplored. Existing designs either expose only a narrow part of the representation hierarchy or rigidly match each decoder block to one VLM layer, restricting access to complementary task evidence across depths. We introduce LIRA, a local cross-layer action-conditioning mechanism that formulates VLM-to-action conditioning as depth-aware information routing. LIRA operates on task-token features and LIRA Query features derived from intermediate VLM states, then assigns each Parallel Fusion Block a depth-aligned local window centered on its corresponding VLM layer. Parallel Fusion Blocks aggregate neighboring LIRA Query features and integrate them with task-token features and proprioceptive inputs before action prediction. This routing interface leaves the backbone architecture, action decoder, and supervised training recipe unchanged. Across LIBERO, LIBERO-Plus, CALVIN ABC$\rightarrow$D, and real-world manipulation, LIRA improves the principal aggregate metrics over the VLA-Adapter baseline under the same 0.5B-parameter configuration. In zero-shot transfer to LIBERO-Plus, LIRA increases average success from 59.1% to 78.0%, an 18.9-point gain indicating improved robustness under controlled distribution shifts.

## LIRA：面向视觉-语言-动作解码的局部跨层信息路由——论文详细总结

### 1. 核心问题与整体含义

- **研究背景**：视觉-语言-动作（VLA）模型通过复用预训练视觉-语言模型（VLM）的中间表征来将视觉观测和语言指令映射为机器人动作。尽管 VLA 模型在机器人操作领域已取得显著进展，但 **VLM 中间表征到动作解码器的“接口”设计** 仍未被充分研究。
- **已有方案的问题**：
  - 仅使用最终层特征（如 OpenVLA-OFT），暴露的表征层级过于狭窄；
  - 一对一层对齐条件化（如 VLA-Adapter），将每个解码器块严格匹配到一个 VLM 层，限制了跨深度的互补任务证据的获取；
  - 全局聚合所有层特征，则会破坏 VLM 深度的局部结构。
- **本文核心问题**：如何将中间 VLM 表征有效地“路由”到动作解码器？
- **核心假设**：**相邻 VLM 层为给定解码器深度提供互补的任务证据**；即局部跨层信息比单层信息或全局信息更有利于动作预测。
- **整体含义**：LIRA 提出一种深度感知的局部跨层路由机制，在不改变骨干架构、动作解码器和训练方案的前提下，仅通过改进 VLM→动作的接口设计，即可在多个基准和真实机器人上显著提升 VLA 模型的性能与鲁棒性。

### 2. 方法论：核心思想、关键技术细节

#### 核心思想
将 VLM→动作条件化重新表述为 **深度感知的信息路由问题**，并引入 **VLM 深度上的“局部性先验”**：每个并行融合块（Parallel Fusion Block, PFB）应当访问以其对应 VLM 层为中心的一个局部邻域窗口，而不是仅访问单一匹配层，或聚合全部层。

#### 关键技术细节

- **基础架构**：基于 VLA-Adapter 构建。输入包含视觉-语言任务令牌（task tokens）、可学习的 **LIRA Query 令牌**、本体感受（proprioception）输入，以及初始化动作解码器的 Action Query 令牌。
- **深度对齐接口**：从第 ℓ 个 VLM 层提取任务令牌特征 $T_t^{(\ell)}$ 和 LIRA Query 特征 $R_t^{(\ell)} \in \mathbb{R}^{M \times d_v}$。解码器由 L 个 PFB 组成，PFB i 对应 VLM 层 i。
- **局部跨层路由**：对第 i 个 PFB，选取以其匹配层为中心的邻域窗口：
  $$W_r^{(i)} = \{\ell \in \{1,\ldots,L\} \mid |\ell - i| \le r\}$$
  并将窗口内各层的 LIRA Query 特征沿令牌维度拼接：
  $$\tilde{R}_t^{(i)} = \text{Concat}_{\text{tok}}\left(\{R_t^{(\ell)}\}_{\ell \in W_r^{(i)}}\right)$$
  然后输入对应 PFB：
  $$X_t^{(i)} = \text{PFB}_i\left(X_t^{(i-1)};\, T_t^{(i)},\, \tilde{R}_t^{(i)},\, E_t^p\right)$$
- **默认配置**：$r=1$，即内部 PFB 使用中心三层窗口；边界 PFB 使用两层窗口（被裁剪到有效边界）。窗口内特征沿令牌维度拼接，可由现有交叉注意力直接消费，**不引入任何附加投影层或可训练参数**。
- **窗口宽度控制跨层上下文量**：宽度为 1 退化为单层条件化；宽度 3 为默认；更大窗口逐步逼近全局聚合。
- **训练目标**：监督连续动作回归，L1 损失：
  $$\mathcal{L}_{\text{act}} = \mathbb{E}_{D}\left[\frac{1}{H}\sum_{h=0}^{H-1}\|\hat{a}_{t+h} - a_{t+h}\|_1\right]$$
  与 VLA-Adapter 基线完全相同，从而隔离路由机制的贡献。

### 7. 优点

- **方法简洁而优雅**：在既有 VLA-Adapter 架构上仅改变 LIRA Query 特征的来源窗口，不增加参数、不改骨干、不改训练目标。
- **先验清晰且可解释**：深度局部性先验有直观的动机（相邻层表征语义互补），公式化表述简洁明了。
- **消融设计严谨**：
  - 路由拓扑对比证明局部窗口优于其他跨层聚合方式；
  - 窗口宽度实验揭示“三层最优、全局聚合最差”的规律；
  - Query 预算实验排除了“性能提升仅来自更多查询令牌”的混淆解释。
- **评估体系完整**：从标准任务到长时程序列、受控分布偏移、真实机器人，形成多层次验证。
- **零样本鲁棒性增益显著**：+18.9 个百分点的最强提升出现在零样本迁移场景，说明局部跨层信息对分布偏移下的泛化有重要价值。
- **资源高效**：系统级对比表明该设计在保持高性能的同时具有卓越的资源效率。

### 8. 不足与局限

- **骨干模型覆盖面窄**：仅验证了 Prismatic 风格 VLM + Qwen2.5-0.5B 一种紧凑骨干；未验证在 7B、70B 等更大 VLM 或不同 VLM 家族（如 LLaVA、PaliGemma）上是否同样有效。
- **动作解码器泛化性未知**：仅测试了 PFB-based 的并行融合解码器；未验证在 flow matching、diffusion transformer 等其他动作解码架构中，局部跨层路由是否依然成立。
- **真实世界实验强度不足**：单台 Franka 机器人、每任务仅 10 次试验，论文也承认应视为初步结果；无法建立跨具身（cross-embodiment）鲁棒性，也未覆盖接触丰富、力敏感等复杂操作。
- **分布偏移范围有限**：LIBERO-Plus 是受控扰动基准，论文明确指出结果“不意味着无限制的 out-of-distribution 泛化”。
- **与大规模模型的比较不对称**：与 OpenVLA-OFT 等的对比不是受控对比（骨干不同、训练管线不同），只能作为系统级参考。
- **计算细节不完整**：未报告训练时长、总 GPU-hours 等关键算力信息，不利于复现的成本评估。
