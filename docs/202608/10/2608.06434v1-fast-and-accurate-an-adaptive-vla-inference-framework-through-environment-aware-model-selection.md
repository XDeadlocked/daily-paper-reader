## 摘要
具身智能既需要长时程推理，也需要实时的闭环响应。最近的双系统视觉-语言-动作（VLA）架构将快速反应控制与慢速深思推理相结合，以平衡推理速度与任务成功率。然而，现有的双过程VLA将快速模块与慢速模块的中间表示紧密耦合，需要端到端的联合训练，限制了模块性、可扩展性和灵活的系统切换。本文提出环境感知模型选择（EMS），一种自适应VLA推理框架，通过环境感知模型选择在两个完全解耦的不同规模系统之间切换。大规模深思系统提供全局一致的轨迹规划以确保任务成功，而轻量级反应系统则实现高频闭环控制。基于强化学习的切换策略根据实时反馈动态选择调用哪个系统，从而实现对慢速系统的稀疏使用，并在预训练知识利用与运行时效率之间取得平衡。与先前的分层VLA框架相比，我们的设计具有三个关键优势：（1）完全解耦且模块化的双系统架构，支持即插即用的模型替换；（2）自适应的环境感知切换策略；（3）用于响应式闭环控制的高频推理。我们在仿真和真实环境中广泛评估了EMS。在LIBERO基准上，EMS在达到与大尺度基线相当的成功率的同时，将有效动作频率提升至93.4 Hz。该框架还在真实世界的双臂操作任务中展现出强大的可扩展性，在保持稳健性能的同时加速任务完成。

## Abstract
Embodied intelligence demands both long-horizon reasoning and real-time closed-loop responsiveness. Recent dual-system Vision-Language-Action (VLA) architectures combine fast reactive control with slow deliberative reasoning to balance inference speed and task success rate. However, existing dual-process VLAs tightly couple the fast module to intermediate representations of the slow module, necessitating end-to-end joint training and limiting modularity, extensibility and flexible system switching. In this paper, we propose Environment-aware Model Selection (EMS), an adaptive VLA inference framework that switches between two fully decoupled systems of different scales through environment-aware model selection. The large-scale deliberative system provides globally consistent trajectory planning to ensure task success, while a lightweight reactive system enables high-frequency closed-loop control. A reinforcement-learning-based switching policy dynamically selects which system to invoke based on real-time feedback, enabling sparse use of the slow system and thereby balancing pretrained knowledge utilisation with runtime efficiency. Our design offers three key advantages over prior hierarchical VLA frameworks: (1) a fully decoupled and modular dual-system architecture that supports plug-and-play model replacement; (2) an adaptive, environment-aware switching strategy; (3) high-frequency inference for responsive closed-loop control. We extensively evaluate EMS in both simulation and real-world environments. On the LIBERO benchmark, EMS achieves success rates comparable to the large-scale baseline while increasing the effective action frequency to 93.4 Hz. The framework further demonstrates strong extensibility in real-world dual-arm manipulation tasks, where it accelerates task completion while maintaining robust performance.

## 1. 核心问题与整体含义（研究动机与背景）

- 具身智能需要兼顾**长时程推理**与**实时闭环响应**。大规模 VLA 模型（如 RT-2、OpenVLA、PI0）虽然在空间/任务推理上表现优异，但推理延迟高（例如 OpenVLA 仅 6.3 Hz、RT-2 仅 1-3 Hz），难以支撑动态、接触丰富的操作任务。
- 已有研究借鉴 Kahneman 的“快慢思维”理论，提出双系统 VLA（如 DP-VLA、FiS-VLA），用轻量 System 1 做高频反应、用大规模 System 2 做深思规划。但这些方法将 System 1 **紧耦合到 System 2 的中间表示**上，需要端到端联合训练，导致三个问题：
  - 快模块无法独立端到端推理；
  - 模块升级困难（更换任一模型需重新联合训练）；
  - 无法按需灵活切换系统。
- 本文提出 **EMS（Environment-aware Model Selection）**，核心思想：将 System 1（快速反应）与 System 2（慢速深思）**完全解耦**，仅在动作层交互；用一个轻量级强化学习切换策略，根据实时环境反馈动态选择调用哪个系统，实现“稀疏使用慢系统、默认快系统高频执行”的推理框架。

## 2. 方法论：核心思想、关键技术细节与公式/流程

### 2.1 整体架构
- **System 2（深思系统）**：大规模预训练 VLA（实验中为 PI0），输出动作块（chunk），负责全局轨迹规划，低频约 10 Hz。
- **System 1（反应系统）**：轻量级策略（实验中为 BCVILT 或 ACT），支持单步高频端到端推理，约 100 Hz，负责实时闭环控制。
- **切换模块**：轻量级网络（全连接网络），输入为机器人状态 $s_t$（而非完整多模态观测），输出离散动作 $\hat{a}_t \in \{0,1\}$，0 表示选快系统，1 表示选慢系统。
- 两系统共享观测空间（图像 + 语言指令）和动作接口，**仅通过动作级交互**，实现架构无关（architecture-agnostic）的即插即用。

### 2.2 系统选择与执行流程
- 在每个决策边界：
  1. **切换决策**：切换模块根据 $s_t$ 选择系统；
  2. **策略推理**：被选中的系统基于当前观测 $o_t$ 生成单个动作或动作块；
  3. **动作执行**：执行完当前输出序列后，进入下一决策边界。
- **动作融合（Action Fusion）**：在切换时刻，为避免控制不连续，将快慢两个系统的动作平均：
  $$a_t = \frac{a^{fast}_t + a^{slow}_t}{2}$$
  从慢切到快时，利用慢系统动作块中重叠的动作；从快切到慢时，快系统多做一次推理。

### 2.3 三阶段训练流程
- **Stage I — System 2 微调**：在遥操作数据 $D_{tele}$ 上通过模仿学习微调预训练模型：
  $$\max_{\theta_2} \mathbb{E}_{(a_t,o_t,l)\sim D_{tele}}[\log \pi_{slow}(a_t|o_t,l)]$$
- **Stage II — System 1 蒸馏**：用微调后的 System 2 生成轨迹 $D_{distill}$，从零训练 System 1：
  $$\max_{\theta_1} \mathbb{E}_{(a_t,o_t,l)\sim D_{distill}}[\log \pi_{fast}(a_t|o_t,l)]$$
  这样做使快系统的轨迹分布与慢系统对齐，减少切换时的突兀行为。
- **Stage III — 切换模块强化学习**：
  - **在线 RL（DQN 变体）**：采用 prioritized experience replay、Double Q-learning、dueling architecture、NoisyNet 探索。
  - **离线 RL（IQL）**：用 Implicit Q-Learning 避免外推误差，通过 expectile regression 学习价值函数，用 advantage-weighted regression 隐式改进策略。
  - 切换问题建模为**两动作 MDP**，状态为机器人状态，奖励为：
    $$r_t = \frac{R_{total}}{T}$$
    （总奖励按时间步均匀分配，以缓解稀疏奖励问题。）

## 6. 主要结论与发现

- **LIBERO 基准**：EMS 平均成功率 92.40%，比 BCVILT 高 5.45%；显著优于 Fixed Switching（90.35%），切换比从 0.33 降到 0.153，**动作频率达 93.37 Hz**；在最难的 LIBERO-10 套件上甚至略高于单独使用 System 2（85.40% vs 85.20%）。
- **自适应切换行为**：慢系统集中在**初始规划、抓取等关键精细操作、子目标阶段切换、错误检测后的重新规划**时被调用；快系统主导日常轨迹执行。说明切换策略是**环境/状态感知**的，而非固定调度。
- **消融结果**：
  - 用蒸馏轨迹训练 System 1 显著优于直接用遥操作数据（平均成功率提升 4.80%）；
  - 先遥操作再蒸馏再微调的提升有限，说明初始训练分布影响主导；
  - 移除动作融合使成功率下降 1.1%，在长时程任务中下降 3%。
- **Realman 仿真**：简单任务中 EMS 超过 System 2（84% vs 83%），切换比 0.34；困难任务中接近 System 2（50% vs 56%），但需要更高切换比（1.68）；双臂任务 EMS 优于 System 2（94% vs 93%）。
- **真实双臂任务**：EMS 成功率（70%）低于 System 2（100%），但高于 System 1（60%），**任务完成时间从 System 2 的 29 秒缩短到 23 秒**；System 1 虽理论更快（18 秒），但因轨迹质量低常需重新规划，实际可达 30 秒以上。

## 7. 优点

- **完全解耦的双系统设计**：两个系统仅通过动作级接口交互，支持即插即用模型替换，无需昂贵的联合训练。
- **环境感知的自适应切换**：将系统选择建模为两动作 MDP，用 RL 学到的策略能在正确时机（关键操作、阶段切换、错误修正）稀疏调用慢系统，兼顾成功率与效率。
- **三阶段训练管线设计逻辑清晰**：先微调慢系统保证全局一致性，再用慢系统轨迹蒸馏快系统保证轨迹分布对齐，最后用 RL 训练切换策略，每一步都有明确目标。
- **动作融合**简单有效，能显著减少切换时的不连续性，在长时程任务中效果更明显。
- **实验场景丰富**：覆盖标准仿真基准（LIBERO）、不同机械臂（Realman）、不同快系统（BCVILT/ACT）、单臂/双臂、仿真/真实世界，验证了框架的**可移植性和可扩展性**。

## 8. 不足与局限

- **真实实验样本量小**：每组仅 10 次测试，统计显著性有限，成功率数据（如 60%、70%、100%）存在较大方差风险。
- **切换策略输入受限**：切换模块仅基于机器人状态 $s_t$，未使用完整多模态观测（图像/语言），可能遗漏对状态切换有帮助的视觉信息（虽然论文称这是为降低开销，但可能损失部分决策信息）。
- **System 1 与 System 2 性能差距大时效率退化**：在困难任务中，EMS 需要频繁调用慢系统（切换比 1.68），此时速度优势明显下降。
- **未见多保真度/不同规模模型组合的充分研究**：论文只验证了 PI0+BCVILT（单臂）和 PI0+ACT（双臂），对“架构无关”的宣称支撑有限。
- **算力信息缺失**：无法评估训练成本，不便于复现。
- **真实世界中慢系统性能远优于快系统**时，EMS 的成功率受快系统瓶颈限制（70% vs 100%），说明在快系统较弱时，框架不能充分弥补其不足。
- **固定切换基线设定可能过于简单**：仅有“每 4 个 chunk 调一次慢系统”一种固定策略，未与其他自适应基线（如基于规则或基于置信度）比较。
