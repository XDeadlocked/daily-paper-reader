## 摘要
人类通过保留对先前动作已建立之物的知识，同时不断调整正在进行的动作，来执行长程操控。相比之下，动作分块的视觉-语言-动作（VLA）策略在每次查询时从当前输入反复重新规划。现有方法要么通过记忆保留长期任务证据，要么通过动作重用和集成保留短期运动，导致跨查询交接不完整。我们引入了ChainVLA，一个1.2B参数的VLA策略，通过一个联合且可修改的执行状态来链接连续查询。进度上下文将循环工作状态与稀疏事件记忆相结合，以携带源自观测的任务进度，而运动尾部则将先前预测的未执行延续部分馈送到状态构建和动作生成中。这两个组件共同调节一个解码器，该解码器在最新观测下重新生成每个动作范围，允许携带的状态指导下一次预测而不固定它。ChainVLA在RMBench上达到62.8%的平均成功率，在四个LIBERO套件上达到98.8%，而去除运动尾部或进度上下文分别将RMBench成功率降至11.2%和3.0%。这些不对称的消融实验与运动连续性有助于保留任务进度推断所依据的观测流这一观点一致。

## Abstract
Humans perform long-horizon manipulation by retaining knowledge of what earlier actions have established while continuously adapting the motion underway. By contrast, action-chunked vision-language-action (VLA) policies repeatedly replan from the current input at each query. Existing methods preserve either long-term task evidence through memory or short-term motion through action reuse and ensembling, leaving the cross-query handoff incomplete. We introduce ChainVLA, a 1.2B-parameter VLA policy that chains successive queries through a joint and revisable execution state. Progress Context combines a recurrent Working State with sparse event memory to carry observation-derived task progress, while Motion Tail feeds the preceding prediction's unexecuted continuation into state construction and action generation. Together, the two components condition a decoder that regenerates each action horizon under the latest observation, allowing the carried state to guide the next prediction without fixing it. ChainVLA reaches 62.8% average success on RMBench and 98.8% across four LIBERO suites, while removing Motion Tail or Progress Context reduces RMBench success to 11.2% and 3.0%, respectively. These asymmetric ablations are consistent with motion continuity helping preserve the observation stream from which task progress is inferred.

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：长时程机器人操控（Long-Horizon Manipulation）要求策略既能够“记住”此前动作已建立的任务进度，又能够“延续并调整”当前正在进行的运动。然而，基于动作分块（Action Chunking）的主流VLA（Vision-Language-Action）策略在每个查询点都从当前观测、本体感受和指令出发，独立地重新预测整个动作视界（Action Horizon），执行严格前缀（Strict Prefix）后再次重新规划，导致**跨查询（Cross-Query）交接不完整**。
- **核心问题**：跨查询交接存在两个层面的信息缺失：
  - **任务层面**：先前的任务证据可能已不在当前视野中（如RMBench的Put Back Block任务中，同一观测和指令可能对应不同历史，需要不同的下一步决策）。
  - **运动层面**：重新规划丢弃了前一次预测中尚未执行的动作延续（Unexecuted Continuation），导致新旧命令在边界处可能出现明显不一致，影响后续观测流。
- **现有方法的不足**：
  - 记忆增强类方法（Memory-Augmented）保留了观测衍生的历史，但未携带前一次预测的未执行延续。
  - 时间集成（Temporal Ensemble）、实时执行或原生延续类方法保留了短期运动，但无法保留更早的任务证据。
- **研究意义**：该论文提出一种新的方法范式，将“任务进度”与“运动延续”同时作为跨查询的执行状态进行传递，使VLA策略能够在长时程操控中兼顾二者的需求，弥补现有方法的割裂。

### 2. 论文提出的方法论

- **核心思想**：ChainVLA提出一个**联合且可修改（Joint and Revisable）的执行状态** `s_k = (g_k, u_k)`，在连续查询之间递归传递，使每次新的预测既有历史任务进度的引导，又有前一次运动延续的参考，同时保持对新观测的响应性。
- **执行状态组成**：
  - **进度上下文（Progress Context, `g_k`）**：由循环工作状态（Recurrent Working State）与稀疏事件记忆（Sparse Event Memory）检索结果融合而成，携带观测衍生的任务进度。
  - **运动尾部（Motion Tail, `u_k`）**：上一次预测中未执行的后缀动作序列，直接跨越查询边界传递。
- **查询转移公式**：`(A_k, W_k, C_{k+1}) = F_θ(x_k, D_k, W_{k-1}, C_k, u_k)`，其中`u_{k+1} = Tail(A_k) = (a_{k,h_exec+1}, ..., a_{k,H})`表示预测但未执行的后缀。
- **工作机制**：
  - **循环工作状态（Working State）**：通过跨注意力机制将当前输入、执行历史、运动尾部与上一时刻的循环状态融合，生成“实时令牌”（Live Tokens）`L_k`和检索摘要`W̄_k`；同时维护一个有界缓存保留更早的实时令牌。
  - **稀疏事件记忆（Sparse Event Memory）**：仅在特定条件触发时写入事件（64视觉+8阶段+8时间特征令牌），检索时基于当前执行摘要和查询时间编码进行年龄感知的余弦相似度评分，读取锚点（anchor）与最高分非锚点记录，经跨注意力融合为读出令牌`Z_k^e`。
  - **运动尾部（Motion Tail）的两条模型侧路径**：其一，尾令牌（Tail Tokens）输入工作状态的构建；其二，对齐的轨迹初始化（Tail-aligned Initialization）为解码器提供初始状态，即`A^{(0)}_{k+1} | u_{k+1} ~ N(μ_{k+1}, σ_u²I)`。
  - **动作生成**：使用条件流解码器（Conditional Flow Decoder，DiT骨干）在最新的观测、进度上下文和运动尾部条件输入下，重新生成整个动作视界的每一条动作，确保携带的状态仅是“可修改的先验”而非固定计划。
  - **训练方式**：训练过程与推理保持一致，按情节顺序展开；每个查询以50%的概率使用前一个查询的分离（detached）运动尾部，否则屏蔽尾部路径；训练目标包含条件流动作损失、阶段监督（有标注时）和重叠一致性正则化。
- **运行流程**（Algorithm 1）：观察→更新工作状态→检索事件记忆→融合进度上下文→采样动作→重叠混合（执行侧交接）→执行前缀→追加执行历史→条件写入事件→传递尾部。

### 6. 论文的主要结论与发现

- **整体性能**：ChainVLA（1.2B）在RMBench上平均成功率62.8%，在四个LIBERO套件上平均98.8%（其中LIBERO-Long为98.2%），超越至少明显优于最强的、具有完整5任务覆盖率的外部对比方法（Mem-0, 52.8%, 8B+2B）。
- **消融的不对称性**：移除运动尾部使RMBench成功率从62.8%降至11.2%；移除进度上下文则降至3.0%；两者都移除为1.6%。这表明两部分并非独立的线性增益，而是系统相互依赖的组件。
- **运动连续性对任务进度推断的保护作用**：运动尾部的去除会导致边界处命令位移显著增大（配对场景中Put Back Block位置CD为17.32mm vs 0.66mm），引发冗余的重新规划动作，使机械臂访问的视角偏离训练分布，从而破坏任务进度推断所依赖的观测流。这解释了为何运动侧（而非任务进度侧）的移除对整体性能（包括记忆依赖任务）影响更大。
- **替代方案的不足**：固定长度观测历史+时间集成（FIFO Hist. + TE）仅达到35.6%；线性延续（Linear Continuation）和时间集成可以将边界指标降低到低于Full的水平，但任务成功率仍仅0-2%，表明“何时使用”后缀比“是否使用”更重要——在解码前进行状态构建和条件生成才能真正改善任务效果，仅靠解码后平滑无法恢复成功率。

- **性能显著**：在参数规模（1.2B）远小于许多对比模型（如MemoryVLA 7B、Mem-0 8B+2B）的情况下，在RMBench和LIBERO上取得领先结果，展示出良好的参数效率。
