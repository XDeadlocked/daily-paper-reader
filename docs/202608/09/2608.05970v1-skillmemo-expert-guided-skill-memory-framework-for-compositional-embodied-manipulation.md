## 摘要
具身视觉运动模型，包括扩散策略（DP）和视觉-语言-动作（VLA）模型，在机器人操作基准测试中展现了有前景的性能。然而，其潜力仍受限于大规模具身轨迹数据的稀缺性，导致在分布外（OOD）场景中的组合泛化能力不足，且难以捕获可复用的技能结构。为解决这一局限，我们提出了基于技能的记忆（SkillMemo）框架，该框架将长时程演示隐式分解为潜在原子技能，并将技能级特征集成到动态情景记忆库中，以解决组合任务。具体而言，我们首先引入了一个基于专家混合（MoE）架构的专家引导轨迹分割模块，该模块通过学习到的门控系数将轨迹隐式划分为不同的技能原语。我们进一步设计了一种技能级情景记忆架构，将紧凑的技能表示存储为可检索的键值对。在推理时，记忆库检索最相关的技能原语，并将其与模型当前的门控分布融合，提供稳健的上下文先验以细化动作预测。在仿真基准和真实世界操作任务上的大量实验表明，SkillMemo持续增强了DP和VLA骨干网络，实现了最先进的性能并超越了$π_{0.5}$，同时展现出对未见任务配置的强组合泛化能力。

## Abstract
Embodied visuomotor models, including Diffusion Policy (DP) and Vision-Language-Action (VLA) models, have demonstrated promising performance on robotic manipulation benchmarks. However, their potential remains fundamentally constrained by the scarcity of large-scale embodied trajectory datasets, leading to insufficient compositional generalization in out-of-distribution (OOD) scenarios with limited capability to capture reusable skill structures. To address this limitation, we propose Skill-Based Memory (SkillMemo) framework that implicitly decomposes long-horizon demonstrations into latent atomic skills and integrates skill-level features into a dynamic episodic memory bank for solving compositional tasks. Specifically, we first introduce an expert-guided trajectory segmentation module built upon a Mixture-of-Experts (MoE) architecture, which implicitly partitions trajectories into distinct skill primitives represented by learned gating coefficients. We further design a skill-level episodic memory architecture that stores compact skill representations as retrievable key-value pairs. During inference, the memory bank retrieves the most relevant skill primitives which are subsequently fused with the model's current gating distribution, providing a robust contextual prior to refine action predictions. Extensive experiments on the simulation benchmark and real-world manipulation tasks demonstrate that SkillMemo consistently enhances both DP and VLA backbones, achieving state-of-the-art performance and outperforming $π_{0.5}$, while exhibiting strong compositional generalization to unseen task configurations.

## 2. 方法论

### 2.1 核心思想

与直接将整段轨迹输入单一网络的做法不同，SkillMemo 通过 **MoE 架构的门控路由隐式发现技能边界**，将行为解耦为多个可复用的原子技能原语；然后把这些技能以**键-值对形式**存入一个动态记忆库；推理时，模型检索与当前观测最相关的历史技能，将历史门控分布与当前门控分布融合，为动作生成提供上下文先验。

### 2.2 模块一：专家引导轨迹分割（EGTS，Expert-Guided Trajectory Segmentation）

- **输入/输出**：完整轨迹 \(\tau = \{(x_t, a_t)\}_{t=1}^T\) 被引入 MoE 层计算：  
  \[
  y_t = \sum_{i=1}^{N} g_i(h_t) \cdot E_i(h_t)
  \]
  其中 \(N\) 个专家网络各捕获一种局部运动原语，门控网络 \(g\) 通过随时间变化的门控权重天然形成隐式的、数据驱动的“技能边界”。
- **显式 vs. 隐式分割**：显式分割（固定 chunk 边界）难以捕捉所有潜在地技能切换点，而隐式方式让分割边界根据任务结构自适应涌现。
- **协同信息正则（PID 损失）**：对任一对专家 (A,B)，定义  
  \[
  L_{PID} = -[I(\{A,B\};G) - I(A;G) - I(B;G)]
  \]
  最小化该损失鼓励专家间产生互补和协同信息，使每个专家专门学习不同技能，同时保持高阶协作。
- **辅助机制**：采用负载均衡损失和 top-k 路由策略，防止“专家坍缩”（所有样本倾向路由到少数专家）。

### 2.3 模块二：技能级记忆架构（SLMA，Skill-Level Memory Architecture）

- **存储（Storage）**：
  - 记忆库 \(M = \{(k_m, v_m)\}_{m=1}^M\) 按键-值对组织；
  - **记忆键**：每个技能段 \(\tau_m\) 的潜在特征做时间聚合得到紧凑质心特征：
    \[
    k_m = \frac{1}{L} \sum_{t \in \tau_m} h_t
    \]
  - **记忆值**：该技能段内完整时间序列的门控权重 \(v_m = \{g(h_t)\}_{t \in \tau_m}\)，即保留关键的行为“知识”。
- **检索（Retrieval）**：
  - 用余弦相似度 \(s(q_t, k_m)\) 计算当前观测特征与各记忆键的相似度，取 top-N；
  - 引入**可靠性检查**：当平均相似度低于置信阈值 \(\delta\) 时，放弃使用记忆；
  - 融合公式：
    \[
    g'(q_t) = \lambda g(q_t) + (1-\lambda) \frac{1}{N} \sum_{n=1}^{N} v_n[t']
    \]
    以 \(\lambda\) 控制记忆干预强度，通过组合已知技能原语合成新行为。
- **更新与修剪（Update）**：
  - 记忆库容量有限（\(M_{\max}\)）；
  - 淘汰三类低价值记忆：时间戳最久远的；长期未被成功检索的；检索时反复达不到可信阈值的；
  - 动态平衡记忆多样性和质量，模拟人类认知中的遗忘机制。

## 6. 主要结论与发现

1. **主结论**：SkillMemo 通过隐式技能分解 + 技能级动态记忆，可一致增强 DP 与 VLA 骨干，在组合操作任务上获得最先进性能。
2. **相对最优性能**：π0.5-SkillMemo 平均成功率 98.0%，领先 π0.5（96.8%）1.2%，领先 MemoryVLA（96.5%）1.5%。
3. **技能分解有效**：加入 EGTS 即带来一致提升，说明 MoE 隐式分割确实捕获了任务级可复用结构。
4. **记忆模块增益明显**：SLMA 的加入进一步改善性能，尤其在需要组合推理的任务上；跨套件零样本测试中有记忆模型甚至优于在目标套件上分布内训练的基线，说明记忆实现了部分“技能迁移”能力。
5. **专家专业化涌现**：门控系数在“抓起碗”“打开炉子”等关键语义动作时间段出现显著激活峰，证明无需显式标签即可涌现语义技能单元。
6. **真实世界迁移可信**：SkillMemo 在真实未知组合任务（如“草莓上盘”“柠檬入碗”）中显著优于 DP 基线，说明组合式技能复用思想可落地到物理环境。

## 7. 优点与亮点

- **方法论新颖**：将 MoE 门控分布同时作为“技能定义”和“记忆内容”，把技能分割、存储、检索三者统一到同一表征空间，设计简洁且内聚。
- **无需显式分割标签**：技能发现完全由门控路由自监督涌现，避免了显式分段标注的高成本。
- **骨干无关性**：框架以即插即用方式挂载在 DP 和多种 VLA（从 0.5B 到 8.5B）之上，可扩展性强。
- **理论支撑**：引入部分信息分解（PID）作为正则，从信息论角度促进专家互补协同，比简单负载均衡更“智能”。
- **记忆库设计工程化**：质心键 + 门控序列值兼顾检索效率和动态细节；可信度阈值防止错误记忆干扰；使用频率驱动的修剪策略避免记忆无限膨胀，考虑了终身学习场景。
- **实验设计较完整**：从小到大（DP→0.5B→7B→8.5B）、从仿真到真实、从分布内到零样本 OOD、从定量到可视化，形成立体的证据链。

- **门控分布作为技能语义的可解释性有限**：虽然可视化显示门控激活峰与语义动作相关，但论文未提供定量指标（如与人为标注段落的对齐度、跨任务技能迁移成功率）证明“专家”确实对应可迁移的原子技能；门控序列值本身是高维连续的，如何将其解读为离散技能仍依赖人工观察。
- **记忆检索的时序对齐方式未充分论证**：融合公式中直接以当前时间步在历史技能段内的相对位置 \(t'\) 索引记忆值，未考虑不同演示中同技能的执行速度、节奏差异，对时间轴变形的鲁棒性仅在数据中隐式缓解，缺乏显式对齐机制（如动态时间规整）。
- **技能库构建成本依然存在**：尽管技能发现是隐式的，但记忆库中的条目来自大量人工示教轨迹，训练仍需充足数据；对于训练时未出现的新技能，记忆检索退化为普通门控输出，此时 \(\lambda\) 的固定取值可能无益甚至有害。
- **统计严谨性有待加强**：所有仿真和真实世界结果均未报告多次随机种子的均值与标准差，也没有显著性检验，使得部分微小区间差异（如 98.2 vs 98.0）难以判断是否来自随机波动。

## 9. 总结与展望

### 9.1 总体评价

SkillMemo 是一项视角新颖、实现完整、实验覆盖面较广的具身技能记忆框架研究。其核心贡献在于将 **Mixture-of-Experts 的门控分布**同时作为技能发现、技能表示与记忆检索的统一载体，在无需显式分段标注的前提下实现了隐式技能分解与动态记忆增强，并证明了该机制在 DP 和多种 VLA 骨干上的通用增强效果。相较于 MemoryVLA、HAMLET 等侧重“感知/语义记忆”的同类方法，SkillMemo 更聚焦于行为层面的可复用结构，在组合泛化任务上展现出明显优势。

### 9.2 对领域的启示

- **“记忆什么”比“记忆多少”更重要**：实验表明，存储技能级门控分布比存储高维视觉特征或语言摘要更利于下游动作生成，这提示后续记忆增强策略研究可在抽象表示层面寻求更紧凑、更可操作的经验载体。
- **自监督技能涌现是可行方向**：MoE 路由的隐式分段效果接近语义动作边界，说明无需昂贵的人工标签也能从数据中挖掘行为结构，这对扩大演示数据利用率具有积极意义。
- **即插即用的记忆范式**：SkillMemo 可作为轻量插件叠加于现有策略，这一设计降低了使用门槛，为社区在各类 VLA 模型上复用技能记忆提供了便利。

### 9.3 未来工作建议

1. **扩展至更复杂真实任务**：在 VLA 骨干上部署 SkillMemo，并覆盖多步装配、可变形物体、双手协作等任务，以验证其跨任务类型泛化能力。
2. **自适应超参数调节**：研究基于任务难度、检索置信度的动态 \(\lambda\) 调节机制，使记忆干预强度随上下文自动变化。
3. **引入显式技能对齐**：结合时序对齐方法（如 DTPW）提高记忆检索对执行节奏差异的鲁棒性。
4. **更严谨的统计验证**：报告多次种子的方差并做显著性检验，或提供跨不同演示规模的学习曲线，增加结论的可靠性。
5. **探索终身学习整合**：将技能记忆库的增量式更新与在线强化学习结合，实现机器人在真实环境中持续积累和修正技能。

总体而言，SkillMemo 在技能记忆的表示与利用方式上提供了一个富有启发性的新解，尽管在评估广度和统计严谨性上仍有改进空间，但其“隐式技能分解 + 门控记忆融合”的思想有望成为具身智能体实现组合泛化的重要基础设施之一。
