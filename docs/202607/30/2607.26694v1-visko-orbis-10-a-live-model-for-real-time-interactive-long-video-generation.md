## 摘要
我们提出了Visko Orbis 1.0，一种用于实时交互式长视频生成的实时模型。用户可以在生成过程中的任意时刻更改提示词，更新内容会实时可见。Visko Orbis 1.0支持长文本到视频、图像到视频以及视频续写，支持多语言提示词和生成过程中的提示词切换。一种有界多尺度记忆机制在各片段间保留主题、场景和风格，支持小时级别的持续生成，无明显质量或色彩漂移。基于蒸馏的逐块流式生成器和流式视频升频器，Visko Orbis 1.0通过优化的GPU服务引擎实现了24 FPS的实时4K视频生成。在长格式竞技场对比中，Visko Orbis 1.0在现有最先进的实时交互式视频生成系统中获得了最高的总体偏好和时域稳定性评分。

## Abstract
We present Visko Orbis 1.0, a Live Model for real-time, interactive long-video generation. Users can change the prompt at any moment during generation, and the update becomes visible in real time. Visko Orbis 1.0 supports long-form text-to-video, image-to-video, and video continuation, with multilingual prompts and prompt switching while generation is in progress. A bounded multi-scale memory preserves subjects, scenes, and style across chunks, sustaining hour-scale rollouts without evident quality or color drift. Built on a distilled chunk-wise streaming generator and a streaming video upscaler, Visko Orbis 1.0 delivers real-time 4K video generation at 24 FPS using an optimized GPU serving engine. In long-form Arena comparisons, Visko Orbis 1.0 obtains the highest overall-preference and temporal-stability ratings among state-of-the-art real-time interactive video-generation systems.

## 1. 核心问题与整体含义（研究动机和背景）

- **现有局限**：主流视频生成模型（如Sora、Veo、Kling等）生成高质量短视频，但采用离线模式——用户提交提示后等待完整视频生成，一旦生成无法修改。这种范式不适用于需要实时反馈和持续互动的应用场景（直播、游戏、虚拟角色、交互式故事等）。
- **缺失的能力**：现有工作分别解决了部分需求（因果流式生成、交互性、长时稳定性、高效推理），但没有一个系统能同时满足：实时生成、长时间跨度、持续用户控制。
- **论文动机**：提出“Live Model”概念——视频生成应如同一个持续运行的进程，接受实时输入、维护状态、渐进式输出。Visko Orbis 1.0是该概念的首个实现，旨在实现实时、交互式、长视频生成，支持生成过程中的任意时刻切换提示词，并立即生效。

## 2. 方法论：核心思想与关键技术细节

### 2.1 整体框架
- **模型类型**：条件潜变量视频模型，采用分块（chunk-wise）自回归流式生成。
- **核心公式**：生成每个潜变量块 \(z_k\) 依赖于历史 \(H_k\)、当前文本指令 \(c_k\) 和可选的视觉上下文 \(r_k\)，即从分布 \(p_\theta(z_k | H_k, c_k, r_k)\) 采样。
- **统一入口**：文本到视频（T2V）、图像到视频（I2V）、视频续写（V2V）均使用同一因果延续接口，仅通过初始状态区分。

### 2.2 数据管道
- **多阶段数据筛选**：原始视频集合 → 镜头感知裁剪 → 安全过滤 → 质量过滤 → 分布重平衡 → 人类偏好挑选。
- **多阶段字幕**：短片段（≤10秒）生成单事件摘要；长片段（3-240秒）进行事件检测，生成事件对齐的时间字幕（含事件边界、局部描述、跨事件持久属性）。
- **数据层级**：广覆盖预训练（安全过滤后）、分布平衡中训练（质量过滤+重平衡）、高质量微调（人类验证）。

### 2.3 模型训练阶段（渐进式）
1. **双向预训练**：1-5秒短视频，全时空注意力，使用线性整流流目标。
2. **流式适应**：初始化于双向权重，在3-10秒有序块上训练，加入历史条件。
3. **中训练**：使用高质量单事件和事件对齐多事件数据，平衡多种场景。
4. **高质量微调**：人类筛选的顶级质量片段。
5. **后训练**：
   - **蒸馏**：固定CFG尺度蒸馏为条件模型 → 一致性蒸馏（减少步数） → 自强迫分布匹配（DMD）适应自动生成历史。
   - **强化学习**：使用GRPO优化视觉质量、运动质量、文本对齐奖励；额外使用潜世界模型（WMReward）进行物理感知对齐。

### 2.4 有界多尺度记忆
- **设计**：最近历史保留高潜分辨率，较早历史渐进压缩，超出固定预算的信息被整合到固定容量的学习状态中。
- **训练改进**：混合干净历史和两种增强分支（历史扰动 + 从生成轨迹估计的漂移统计），使模型学会从错误中恢复。

### 2.5 推理与系统设计
- **实时控制**：滚动提示摘要、异步编码、版本化状态失效，使新提示影响未来块而不重设会话。
- **编译与执行**：整体编译Transformer、融合核（QKV、AdaLN等）、序列分片多GPU并行（Ulysses-style）、渐进式解码和上采样（FIFO队列）。
