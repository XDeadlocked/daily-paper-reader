## 摘要
视频扩散变换器处理长时空序列，使得自注意力成为高分辨率视频生成的主要瓶颈。免训练的稀疏注意力降低了这一成本，但在多GPU序列并行下，自适应Top-p路由会导致每头工作负载不均。由此产生的工作负载异质性将稀疏注意力转化为层级瓶颈问题。我们提出FVAttn，一个免训练的稀疏注意力系统，提升了多GPU序列并行下自适应稀疏注意力的分布式执行效率。FVAttn采用Top-p路由、Top-k安全下限及视频感知的块组织作为稀疏路由前端，并在运行时修复已具化的掩码。运行时负载均衡通过P2P通信迁移少量重负载头，以缩短当前关键路径。松弛感知的稀疏增强用额外的高价值块填充非关键秩的剩余松弛，而重叠技术将调度与迁移开销隐藏在已有计算之后。在步进蒸馏的Wan2.2 I2V上，FVAttn将平均负载不均衡从1.34降至1.08，实现相对于FlashAttention的4.41倍注意力加速，并在保持竞争性视频质量的同时，获得2.02至2.11倍的DiT推理加速。

## Abstract
Video Diffusion Transformers process long spatio-temporal sequences, making self-attention the main bottleneck in high-resolution video generation. Training-free sparse attention reduces this cost, but adaptive Top-$p$ routing creates uneven per-head workloads under multi-GPU sequence parallelism. The resulting workload heterogeneity turns sparse attention into a rank-level straggler problem. We present \method{}, a training-free sparse-attention system that improves the distributed execution efficiency of adaptive sparse attention under multi-GPU sequence parallelism. \method{} uses Top-$p$ routing, a Top-$k$ safety floor, and video-aware block organization as the sparse-routing frontend, then repairs the materialized mask at runtime. Runtime Load Balancing migrates a small number of heavy heads via P2P communication to shorten the current critical path. Slack-Aware Sparse Augmentation fills residual non-critical-rank slack with additional high-value blocks, while overlap hides scheduling and migration overhead behind existing computation. On step-distilled Wan2.2 I2V, \method{} reduces average load imbalance from 1.34 to 1.08 and delivers a $4.41\times$ attention speedup over FlashAttention, while achieving a $2.02$--$2.11\times$ DiT inference speedup with competitive video quality.

# FVAttn: 面向视频生成的自适应稀疏注意力与运行时负载均衡

## 1. 核心问题与整体含义

视频扩散变换器（Video DiTs）处理长时空序列时，自注意力计算是主要瓶颈。免训练的稀疏注意力（如Top-p路由）可降低计算量，但在多GPU序列并行（Ulysses风格）下，不同注意力头的工作负载因自适应预算分配而差异显著，导致某些GPU rank成为滞后节点（straggler），其他GPU空闲等待，抵消了稀疏注意力带来的理论加速。本文旨在解决自适应稀疏注意力在分布式执行中的负载不均问题，提出一种免训练、运行时修复的系统。

## 2. 方法论：核心思想与关键技术

- **核心思想**：负载不均主要由少量重负载头（dense heads）引起，通过轻量的P2P迁移修复关键路径，并利用非关键层的剩余松弛增加稀疏掩码覆盖，整体开销通过重叠隐藏。
- **关键技术细节**：
  - **稀疏路由前端**：使用Top-p路由（自适应保留累积重要性达到p的key块）加上Top-k安全下限（保证最小保留数），并采用希尔伯特曲线重排块以增强空间局部性。
  - **运行时负载均衡（Runtime Load Balancing, RLB）**：在稀疏掩码具化后，基于实际每头工作负载 \(L_h\)，通过约束P2P头迁移（默认每rank最多迁移1个头，约20%局部头）最小化关键路径最大负载。公式：\( \sigma^* = \arg\min_{\sigma \in \mathcal{S}_{20\%}} (\max_r L_r^{\text{new}}, \text{Var}_r(L_r^{\text{new}})) \)。
  - **松弛感知稀疏增强（Slack-Aware Sparse Augmentation, SASA）**：对平衡后仍有剩余松弛的非关键rank，根据松弛量 \(\Delta L_r\) 分配额外块预算 \(B_r = n_1 \Delta L_r\)，仅添加高价值key块，确保不延长关键路径。
  - **重叠调度**：CPU规划与GPU量化重叠，P2P通信与非迁移头计算重叠，将RLB和SASA的可见开销降至~0.7ms（占总注意力时间1.87%）。
- **流程**：序列到头的All-to-All → 构建稀疏掩码 → 计算实际每头负载 → 若负载不均衡因子 \(\rho \ge k_2\)（如1.10），启用RLB（P2P头迁移）→ 对剩余松弛启用SASA → 执行块稀疏注意力 → 反向All-to-All恢复头顺序。

## 6. 主要结论与发现

- FVAttn在保持或提升视频质量（PSNR/SSIM/LPIPS/CLIP-Sim）的同时，显著降低推理延迟：
  - I2V：负载不均衡因子从1.34降至1.08；注意力延迟加速4.41×；DiT推理加速2.05×（Top-p=0.95）或2.11×（Top-p=0.90），VBench得分为88.8%（优于SpargeAttention的88.2%）。
  - Animate：PSNR提升0.46 dB，LPIPS降低13.9%，DL加速2.43×。
  - T2V：DiT加速2.32×，同时质量指标优于所有稀疏基线。
- RLB比基于历史布局的db-SP更优（因为当前步骤负载变化大）；SASA在几乎不增加延迟的情况下提升质量。

## 7. 优点

- **方法创新**：针对自适应稀疏注意力的分布式负载不均提出运行时修复策略，而非离线规划，适应性强。
- **轻量高效**：采用约束P2P迁移（每rank最多1个头），通信开销极小；松弛增强将空闲时间转化为质量提升。
- **系统优化**：通过CPU-GPU和计算-通信重叠，将运行时开销限制在2%以内。
- **实验全面**：在多个主流视频生成模型和蒸馏设置下验证，消融充分，对比基线丰富。
- **实用性**：免训练、即插即用，可应用于多种任务。

## 8. 不足与局限

- **适用范围有限**：主要针对长时空序列视频生成；对于短序列或注意力稀疏性弱的任务（如图像生成），加速和负载均衡收益会显著下降。
- **硬件依赖**：效果依赖于GPU间通信带宽（NVLink），在PCIe连接或低带宽环境下，P2P迁移和重叠效果可能受限，需重新校准参数。
- **并行策略单一**：仅验证Ulysses序列并行，未考虑Ring Attention或更通用的USP下表现，拓展性待验证。
- **安全阈值主观**：SASA的触发阈值（\(k_1,k_2\)）和增强系数 \(n_1\) 需根据硬件和负载手动设定，可能影响泛化。
- **实验偏差风险**：所有实验在相同蒸馏模型和固定帧数下进行，未测试不同蒸馏步骤、不同分辨率或更广范围的工作负载。
