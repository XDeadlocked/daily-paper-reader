## 摘要
多智能体交互世界模型不仅应生成一致的观测，还应在智能体之间持续存在并随视角演化的世界状态。现有的自回归视频扩散管道会将观测历史作为条件上下文传递，这使得在多智能体和多视角设置中难以维护共享状态。我们提出了WorldWeaver (W^2)，一种流式多智能体视频扩散模型，通过跨智能体的世界状态寄存器增强模型展开：这些可学习令牌存储共享世界信息、追踪个体智能体状态，并在每个生成块后动态更新。我们通过涵盖个体智能体状态、全局状态视图（包括鸟瞰图）和场景文本的监督信号来锚定这些寄存器。我们还通过混合变换器设计改进了架构，该设计使用独立的权重进行世界状态建模和视觉帧建模。在两个智能体的Minecraft视频生成实验中，显式世界状态建模提高了逻辑一致性和生成质量。

## Abstract
Multi-agent interactive world models should not only generate consistent observations, but also maintain world states that persist across agents and evolve across views. Existing autoregressive video diffusion pipelines carry forward observation history as conditioning context, which makes shared state difficult to maintain in multi-agent and multi-view settings. We present WorldWeaver (W^2), a streaming multi-agent video diffusion model that augments rollout with cross-agent world state registers: learnable tokens that store shared world information, track individual agent status, and are dynamically updated after each generated chunk. We ground these registers with supervision signals spanning individual agent status, global state views including bird's-eye views, and scene text. We further improve the architecture with a Mixture-of-Transformers design that uses separate weights for world state modeling and visual frame modeling. Extensive experiments in two-agent Minecraft video generation show that explicit world-state modeling improves logical consistency and generation quality.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题**：多智能体交互世界模型不仅需要生成每个智能体视角下的视觉连贯帧，还必须维护一个跨智能体、持续演化且与所有观测兼容的**共享世界状态**。现有自回归视频扩散模型仅传递局部观测历史，在多智能体和多视角设置中难以保持逻辑和几何一致性。
- **背景**：以Minecraft双智能体场景为测试平台，每个智能体只看到部分2D投影，世界状态无论是否有观察者都会变化。现有方法（如Frame concat、Solaris）缺乏显式状态建模，导致交叉智能体一致性和长期逻辑连贯性不足。
- **核心动机**：直接建模底层世界状态，而非仅依赖帧历史推断，从而提升生成质量和逻辑一致性。

## 2. 方法论

### 核心思想
- 引入**世界状态寄存器（World State Registers, WSR）**：一组可学习令牌（默认256个），存储共享世界信息，在生成展开过程中由所有智能体共同贡献并动态更新。
- 寄存器具有两个关键性质：①跨智能体和时间步持久；②随着新观测到达可动态更新。寄存器与帧令牌因果交错排列，寄存器先于下一帧，起到条件作用。

### 关键技术细节
- **三阶段训练策略**：
  1. **Stage 1 – 双向训练**：在同步多智能体片段上训练双向注意力教师模型，学习交叉智能体场景结构。
  2. **Stage 2 – 因果训练**：将教师转换为因果学生，加入寄存器令牌及局部注意力窗口（窗口大小W=6），训练流匹配损失 + 寄存器监督损失。
  3. **Stage 3 – 自强制训练**：模拟推理时的自回归展开，将学生生成的帧和寄存器暴露给自身，使用DMD风格分布匹配损失 + 状态监督损失，缓解训练-测试不匹配。

- **寄存器监督信号**（仅训练时使用，推理时丢弃）：
  - 智能体状态：预测位置、速度、朝向（MSE损失）。
  - 鸟瞰图特征：预测DINOv2特征（余弦相似度损失）。
  - 场景文本：通过冻结Llama-3.2-1B预测文本描述（交叉熵损失）。
- **Mixture-of-Transformers (MoT) 架构**：对寄存器令牌和视觉帧令牌使用不同权重（投影层、FFN、归一化等），但共享注意力机制，减少任务冲突。

- **推断流程**（Algorithm 1）：维护帧KV缓存和寄存器KV缓存，每步去噪新帧，提交更新寄存器，循环生成多帧。

## 6. 主要结论与发现

1. **显式世界状态寄存器显著提升多智能体生成一致性和视觉质量**：与Solaris相比，世界得分从81.0提升至105.1，Grounding VLM准确率从81.3%升至93.8%，Building从9.4%升至28.1%。
2. **多种监督信号互补**：综合三种监督（agent stats + BEV + scene text）效果最佳；单独场景文本贡献最大（世界得分103.2）。
3. **MoT架构在有监督时优于密集Transformer**：当寄存器携带丰富语义时，MoT（世界得分103.2）远胜Dense（91.3），说明分离参数减少任务冲突。
4. **半监督训练可行**：仅用1K标注+10K未标注数据，世界得分从63.2提升至90.3，表明无标签数据有助于生成质量提升。
5. **自强制训练进一步提升稳定性**：Stage 3中MoT冻结视觉分支、仅更新寄存器分支，VLM准确率从63.8%升至68.1%。

## 7. 优点

- **创新性**：首次在流式多智能体视频扩散中引入可学习的显式世界状态寄存器，解决了共享状态维护难题。
- **系统方法论**：三阶段训练策略（双向→因果→自强制）合理结合了监督学习和强化学习风格的自强制训练，缓解训练-测试不匹配。
- **多模态监督设计**：利用智能体状态（局部动力学）、鸟瞰图（全局几何）、场景文本（跨模态语义）互补地锚定寄存器，且监督头推理时丢弃，不增加推理成本。
- **架构创新**：MoT设计有效分离世界状态建模与视觉帧建模，减少任务冲突，提升监督学习效果。
- **半监督探索**：展示了寄存器方法在标签稀缺场景下的潜力，具有实际部署意义。
- **可解释性**：寄存器可解码出智能体轨迹、鸟瞰图、场景描述，使世界状态透明可检查（图3）。
