## 摘要
潜在世界模型通过学习条件于动作的预测动态，并将其用作内部模拟器来想象和评估候选动作序列，已成为一种强大的规划范式。然而，随着规划视野的增长，性能越来越受到候选质量的影响：固定的候选预算必须在指数级增长的动作空间中进行搜索，这使得世界模型难以接触到高质量的候选未来进行评估。在本文中，我们引入了一种基于先验条件的规划器，用结构化引导替代随机候选初始化。在每个规划阶段，一个目标条件生成器预测指定时长内下一个可达的潜在子目标，然后用于条件化候选动作序列的生成。为了捕捉跨时间尺度的语义信息，我们使用不同时长的子目标作为先验，平衡细粒度的局部控制与更高层次的长期进展。然后，冻结的世界模型在执行前评估并优化这些子目标条件化的候选方案。在PushT和OGBench Cube上的实验表明，将潜在子目标分解与先验条件动作生成相结合，显著改善了长期规划，同时保持了强大的短期性能。具体而言，当目标偏移为150时，PushT的成功率从12.7%提升至64.7%，OGBench Cube的成功率从26.7%提升至67.3%。

## Abstract
Latent world models have emerged as a powerful planning paradigm by learning action-conditioned predictive dynamics and using them as internal simulators to imagine and evaluate candidate action sequences. However, as the planning horizon grows, performance becomes increasingly constrained by proposal quality: a fixed candidate budget must search an exponentially larger action space, making it difficult to expose the world model to high-quality candidate futures for evaluation. In this paper, we introduce a prior-conditioned planner that replaces random proposal initialization with structured guidance. At each planning stage, a goal-conditioned generator predicts the next reachable latent subgoal for a specified duration, which is then used to condition the generation of candidate action sequences. To capture semantic information across temporal scales, we use subgoals of varying durations as priors, balancing fine-grained local control with higher-level long-horizon progress. Then the frozen world model evaluates and refines these subgoal-conditioned proposals before execution. Experiments on PushT and OGBench Cube show that coupling latent subgoal decomposition with prior-conditioned action generation substantially improves long-horizon planning while preserving strong short-horizon performance. To be specific, when the target offset is $150$, it raises PushT success from $12.7\%$ to $64.7\%$ and OGBench Cube success from $26.7\%$ to $67.3\%$.

-   **整体含义**：该论文旨在解决长时程规划中候选方案质量低下的问题。其核心思路是，与其依赖盲目的随机搜索，不如为规划器提供一个**结构化的先验知识**，引导它更智能地探索动作空间。

### 2. 论文提出的方法论

-   **核心思想**：提出 **SAGE (Subgoal-Conditioned Action Generation)** 框架，将长时程规划分解为两个紧密耦合的决策阶段：
    1.  **生成可到达的子目标**：预测在当前规划阶段（τ步）内，一个可达的、中间状态的潜在表示（子目标）。
    2.  **基于子目标生成动作**：根据预测的子目标，生成一系列旨在达到该子目标的候选动作序列。
-   **关键技术细节**：
    -   **多时长子目标生成器 (Goal-conditioned Subgoal Generator)**:
        -   输入：当前观测历史、当前低维状态、最终远距离目标、剩余偏移量δ、请求的局部规划时长τ。
        -   架构：一个四层Transformer解码器。
        -   输出：预测的下一子目标潜在状态 `ẑ_{t+τ}`。该预测采用残差形式 `ẑ_{t+τ} = z_{gt+δ} + Dψ(...)`，使其锚定在最终目标附近。
        -   **关键亮点**：一个生成器能处理多种时长τ（如15、20、25步），通过`τ`作为输入来控制预测的子目标粒度。
    -   **子目标条件动作生成器 (Subgoal-conditioned Action Generator)**:
        -   输入：当前观测历史、当前状态、生成的子目标、最终目标、以及时间变量(δ, τ)。
        -   架构：一个三层Transformer解码器，使用可学习的“动作查询”。
        -   输出：一个**轨迹级的混合高斯分布 (Gaussian Mixture Model, GMM)**，直接生成长度为τ的完整动作序列。其公式为：
            `q_ϕ(a_{t:t+τ-1}|...) = Σ_{m=1}^{M} π_m N(a_{t:t+τ-1}; μ_m, Σ_m)`
            -   多个高斯模式（M=8）可以保留不同的接触点和接近方向。
    -   **训练与规划流程**:
        -   **训练**：使用**专家轨迹**中的对齐窗口数据。先训练子目标生成器，使其预测的潜在状态与真实未来状态接近；然后冻结子目标生成器，训练动作生成器，使其根据生成的子目标（而非真实子目标）最大可能地生成专家动作序列。
        -   **在线规划**：将一个总时长为H的任务分解为一系列较短时长τ的子阶段。在每个阶段，使用训练好的SAGE模型生成子目标和候选动作，然后用**冻结的潜在世界模型（如LeWM）** 来评估和优化这些候选方案（通过交叉熵方法CEM），最后执行最优的动作序列。

-   **解决核心瓶颈**：直接针对长时程规划的核心瓶颈——“候选方案质量”，解决方案优雅且效果显著。
-   **模块化设计**：保持冻结的底层世界模型不变，只在上层优化“目标”和“动作候选”的生成策略，使得该方法可以轻松集成到现有的潜在世界模型（如LeWM）中，无需重新训练整个系统。
-   **灵活性高**：使用变量时长（τ）控制子目标粒度，使得同一个框架能处理不同时间尺度的规划需求，从局部精细控制到全局高层进度。
-   **实验设计严谨**：通过控制变量，公平客观地证明了各个组件的贡献。

### 8. 不足与局限

-   **依赖专家数据**：SAGE的两个核心组件（子目标生成器和动作生成器）都需要大量**专家轨迹数据**进行监督学习。在没有或难以获得专家演示的任务中，其适用性会受限。
-   **计算成本**：虽然提升了规划效率，但SAGE本身包含了两个Transformer解码器（生成子目标和生成动作候选），这增加了**模型复杂度**和**训练阶段的计算成本**。
-   **手动设计时间调度**：规划时长H的分解（如`15 x 5`）是**手动预设的**。论文也发现不同的调度对结果有影响，这表明存在一个寻找最优调度的优化问题，这可能成为未来的一个研究瓶颈。
-   **子目标误差累积**：SAGE使用生成的子目标（而非真实子目标）来训练动作生成器，虽然增加了鲁棒性，但子目标生成器的预测误差仍可能在前向推理过程中累积，影响最终性能。
-   **场景覆盖有限**：实验仅在两个模拟器任务（PushT和Cube）上验证。在更复杂、动态或包含部分可观测性的真实场景中的泛化能力，仍有待探索。
