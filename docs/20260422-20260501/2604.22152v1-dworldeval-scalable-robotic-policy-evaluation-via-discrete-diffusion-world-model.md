## 摘要
使用现有方法在数千个环境和数千个任务中评估机器人策略是不可行的。这促使我们需要一种可扩展的机器人策略评估新方法。在本文中，我们提出了dWorldEval，它使用离散扩散世界模型作为机器人策略的可扩展评估代理。具体来说，dWorldEval将所有模态（包括视觉、语言和机器人动作）映射到一个统一的标记空间，并通过一个基于Transformer的去噪网络对其进行建模。基于此架构，我们采用稀疏关键帧记忆来保持时空一致性。我们还引入了一个指示任务完成度的进度标记。在推理时，模型联合预测未来观测和进度标记，当进度达到1时自动判定成功。大量实验表明，在LIBERO、RoboTwin和多个真实机器人任务上，dWorldEval显著优于先前的方法，即WorldEval、Ctrl-World和WorldGym。它为大规模机器人评估的世界模拟器构建开辟了新的架构范式。

## Abstract
Evaluating robotics policies across thousands of environments and thousands of tasks is infeasible with existing approaches. This motivates the need for a new methodology for scalable robotics policy evaluation. In this paper, we propose dWorldEval, which uses a discrete diffusion world model as a scalable evaluation proxy for robotics policies. Specifically, dWorldEval maps all modalities - including vision, language, and robotic actions - into a unified token space, modeling them via a single transformer-based denoising network. In this paper, we propose dWorldEval, using a discrete diffusion world model as a scalable evaluation proxy for robotics policy. Specifically, it maps all modalities, including vision, language, and robotics action into a unified token space, then denoises them with a single transformer network. Building on this architecture, we employ a sparse keyframe memory to maintain spatiotemporal consistency. We also introduce a progress token that indicates the degree of task completion. At inference, the model jointly predicts future observations and progress token, allowing automatically determine success when the progress reaches 1. Extensive experiments demonstrate that dWorldEval significantly outperforms previous approaches, i.e., WorldEval, Ctrl-World, and WorldGym, on LIBERO, RoboTwin, and multiple real-robot tasks. It paves the way for a new architectural paradigm in building world simulators for robotics evaluation at scale.

*   **研究背景**：通用机器人操作策略发展迅速，但对其进行大规模、可靠的评估成本高昂（依赖真实执行或重型物理仿真）。生成式世界模型被视为一种有潜力的、数据驱动的替代方案。
*   **核心问题**：现有的基于视频扩散的世界模型（如WorldEval, Ctrl-World, WorldGym）作为策略评估代理**不可靠**。其根本原因在于**架构缺陷**：它们通常基于为视频生成设计的预训练骨干网络，将机器人动作作为次要的辅助条件（如通过交叉注意力或AdaLN调制）注入。这导致强大的视觉先验经常覆盖微弱的动作信号，从而产生**“动作不可控”**（例如，对失败动作产生成功幻觉）和**“时空不一致”**（例如，物体扭曲或消失）的问题。
*   **整体含义**：本文提出dWorldEval，旨在通过一种**全新的、为机器人评估量身定制的离散扩散世界模型架构**，从根本上解决上述问题，实现**可扩展、高保真、自动化**的机器人策略评估。

#### **2. 方法论**
*   **核心思想**：构建一个基于**掩码离散扩散**的世界模型，将所有模态（视觉观测、语言指令、机器人动作）**平等地**映射到统一的离散令牌空间，并通过单一的Transformer去噪网络进行联合建模，从而确保动作信号能直接、强有力地影响视觉生成。
*   **关键技术细节**：
    1.  **统一令牌序列实现动作控制**：使用专用分词器（MAGVIT-v2 for 视觉， LLaDA for 语言， FAST for 动作）将所有输入转换为离散令牌，并展平为单一序列。这使得Transformer可以通过自注意力机制，让视觉令牌直接关注动作令牌，实现细粒度的动作控制。
    2.  **稀疏关键帧记忆保证时空一致性**：维护一个由最近K个低分辨率关键帧（如俯视图）组成的滑动窗口记忆。这些关键帧被令牌化后与当前观测序列拼接，为模型提供长期的时空上下文锚点，防止长时程推演中的场景漂移。
    3.  **离散进度令牌实现自动成功检测**：在训练时，使用视觉语言模型为每一帧标注任务完成进度（如0.2， 0.4， 1.0），并将其转换为离散文本令牌作为训练目标。在推理时，模型**联合生成**未来的视觉观测和进度令牌，当最终进度令牌为“1.0”时即判定任务成功，无需外部奖励函数或VLM进行事后评估。
*   **训练与推理流程**：
    *   **训练**：采用掩码离散扩散目标。给定上下文（历史、当前状态、动作、指令）和目标（未来状态、进度令牌），随机掩码目标部分令牌，训练模型重建被掩码的部分。
    *   **推理**：给定初始状态和策略产生的动作序列，模型通过迭代并行解码，自回归地生成未来的多视角视觉序列和对应的进度分数，从而完成整个轨迹的“想象”并自动给出成功率评估。

#### **3. 实验设计**
*   **数据集/场景**：

*   dWorldEval在**动作可控性**上显著优于基线模型，特别是在处理分布外（OOD）或失败动作时，能忠实生成失败结果而非产生成功幻觉。

*   提出的 **Δ-LPIPS指标** 能有效量化动作可控性，是比静态LPIPS更优的动态保真度诊断指标。

#### **7. 优点**
*   **架构创新**：摒弃了将动作作为辅助条件的传统思路，采用**统一令牌化**，使动作成为模型的一等公民，从根本上提升了动作可控性。
*   **设计精巧**：**稀疏关键帧记忆**以较低计算成本解决了长时程一致性难题；**进度令牌**将成功检测内化于生成过程，实现了评估的端到端自动化。
*   **评估全面**：在模拟和真实机器人、多视角、多任务、异构策略上进行了广泛验证，结论可信度高。
*   **诊断工具**：提出的Δ-LPIPS指标为世界模型的“动作忠实度”提供了一个可量化的评估标准。
