## 摘要
动作分块是现代视觉-语言-动作（VLA）框架中的一种标准执行策略，但固定的执行视野会在效率和准确性之间产生权衡。短分块需要频繁推理，可能导致振荡行为；而长分块则可能与新观察到的状态不一致。我们通过一种基于动作专家中内部交叉注意力动态的自适应动作分块方法来解决这一局限。我们观察到，随着预测视野的延长，动作到观察的交叉注意力变得越来越分散，其熵趋于平稳。这种模式与较高的动作预测误差相关，并提供了一个在线信号，表明当前观察对进一步开环执行的支撑有限。基于这一观察，我们引入了一种无需训练的截断机制，该机制检测持续的高熵平台，并在推理过程中动态选择执行视野。该方法利用策略已计算的注意力权重，且引入的额外开销可忽略不计。在RoboTwin 2.0、LIBERO以及三个真实世界操作任务上对π_{0.5}和X-VLA的评估表明，与固定视野和自适应分块基线相比，平均任务成功率有所提高，同时保持了高效的闭环控制。这些结果表明，交叉注意力动态可以为VLA中的自适应动作执行提供实用的内部信号。

## Abstract
Action chunking is a standard execution strategy in modern Vision-Language-Action (VLA) frameworks, but fixed execution horizons impose a trade-off between efficiency and accuracy. Short chunks require frequent inference and may cause oscillatory behavior, whereas long chunks can become misaligned with newly observed states. We address this limitation with an adaptive action chunking approach based on internal cross-attention dynamics in the action expert. We observe that, as the prediction horizon extends, action-to-observation cross-attention becomes increasingly dispersed and its entropy rises toward a plateau. This pattern is associated with higher action prediction error and provides an online signal that the current observation offers limited grounding for further open-loop execution. Based on this observation, we introduce a training-free truncation mechanism that detects sustained high-entropy plateaus and dynamically selects the execution horizon during inference. The method uses attention weights already computed by the policy and introduces negligible additional overhead. Evaluations on $π_{0.5}$ and X-VLA across RoboTwin 2.0, LIBERO, and three real-world manipulation tasks show improved average task success over fixed-horizon and adaptive chunking baselines, while preserving efficient closed-loop control. These results show that cross-attention dynamics can provide a practical internal signal for adaptive action execution in VLAs.

### 1. 核心问题与整体含义（研究动机与背景）

动作分块（Action Chunking）是现代 VLA（Vision-Language-Action）框架中的标准执行策略。它将多个连续动作打包为一个序列一次性预测与执行，以抑制单步执行时的误差累积，并提升对复杂时间模式的建模能力。然而，现有框架通常采用**固定的执行视野（execution horizon, H_e）**，由此产生根本性的两难：

- **分块过短**：需要频繁调用大模型做推理，计算成本高，且可能产生振荡行为；
- **分块过长**：预测的未来动作可能因环境变化而丧失时效性，视觉反馈减弱导致预测精度崩塌。

此外，最优执行时长不仅在不同任务间有差异，甚至在**同一任务的不同阶段**（如快速接近 vs. 精细抓握）也不同，传统的静态启发式调参无法有效适配。因此，如何让 VLA 在执行中**动态决定"何时停止"开环执行、及时把控制权交还给人或新观测**，是一个具有重要实践意义的核心问题。

### 2. 方法论：核心思想、技术细节与算法流程

#### 2.1 核心思想

论文提出的核心假设是：**动作专家内部的交叉注意力动态（cross-attention dynamics）可以作为预测风险的在线内部信号**。具体而言，在流匹配/扩散型的 VLA 动作专家中，注意力权重会系统性呈现一种模式——序列**早期动作**的注意力集中于少量视觉/语言特征（高聚焦、低熵）；而**后期动作**的注意力逐渐分散到几乎整个视觉场（高弥散、高熵）。这种持续的高熵状态对应着"当前观测已不足以支撑后续开环执行"的风险信号。

#### 2.2 关键技术细节

**（1）统一的交互建模形式。** 
不同 VLA 架构（如解耦式 π_{0.5}、耦合式 X-VLA）虽结构各异，但动作生成本质可统一为"动作查询从感知键值中做跨模态检索"，即得到注意力权重矩阵 W ∈ R^{H_p×N}。这为提取统一内部信号提供了可行基础。

**（2）交叉注意力熵的计算。**

- p_{i,j} = Norm(Σ_{l=1}^{L} α_{l,j,i})（在 N 个 VLM token 上归一化）
- E_j = -Σ_{i=1}^{N} p_{i,j} log p_{i,j}

边界满足 0 ≤ E_j ≤ log N，提供了归一化参考。

**（3）熵作为精度代理的验证。** 
论文将交叉注意力熵与动作预测 MSE 关联，发现两者呈显著正相关（Pearson r = 0.187，Spearman ρ = 0.432，均 p < 10^{-120}），且在控制"动作索引位置"变量后偏相关仍显著（r = 0.214），证明高熵并非只是"预测更远动作本身更难"的副产品。进一步的分箱分析表明，高熵区（接近理论上限 log(968) 的约 95%）存在 MSE 的急剧上升——熵最高的十分位内，MSE 最高四分位样本的平均误差是其余样本的 10.4 倍，标准差高 12.1 倍。

**（4）自适应截断规则（训练无关，无需额外采样）。**

给定最终去噪步骤的熵序列 E = {E_1, ..., E_{H_p}}，算法流程为：

1. **滑动平均平滑**（窗口 k，公式 3）：得到 Ē_j；
2. **计算一阶差分** ΔĒ_j（公式 4）；
3. **高熵平台检测**（公式 5）：候选位置 C 需同时满足——k 步窗口内所有平滑熵值均 ≥ η·log N（高熵条件）；窗口内平均熵变化 < τ（稳定性条件）；
4. **执行视野确定**（公式 6）：取最早满足平台条件的位置并偏移 +k 作为执行视野 H_e；若不存在这样的平台，则执行完整预测视野 H_p。

该机制的低熵稳定期不会触发截断（保证高置信阶段的执行效率）；只有"持续高熵平台"（即预测信心持续低迷）才触发提前终止。

### 6. 主要结论与发现

1. **发现了一种 VLA 中存在的普遍现象**：动作 token 与观测 token 之间的交叉注意力，随着预测视界延伸会系统地变得发散，熵增大并趋于饱和平台。
2. **高熵平台可作为经验风险指标**：持续高熵与更高的动作预测误差强关联，且该关系不能仅由"动作序列位置越靠后越难预测"解释。
3. **熵的模式具有任务阶段依赖性**：精细交互前熵升急、平台早；粗放接近时期熵升缓、平台晚。这解释了为何固定视界无法适配不同操作阶段。
4. **训练无关的动态截断机制有效且高效**：在 π_{0.5} 与 X-VLA 两种架构、仿真与真实世界中均持续提升成功率，额外延迟在 7ms 以内，显著优于需要多次采样的方法。
5. 本质上，该方法利用"模型内部固有的认知不确定性信号"来增强闭环控制，无需重训、架构改动或额外采样。

### 7. 优点

- **方法简洁、物理直觉清晰**：核心想法朴素有力——从已计算的注意力权重中提取风险信号，不改变模型结构、不需训练、不需采样，工程落地成本极低
- **几乎零额外开销**：引入的平均延迟约 6.4ms/推理周期，远优于 MS 的 ~30ms，适合高频闭环控制

- **对"预测不确定性来源"的分析有深度**：通过偏相关分析排除了"高熵只因预测更远"的混淆解释，论证具有一定说服力
- **实验覆盖面广**：从长短不一的仿真任务到真实双臂/单臂操作，从任务级成功率到系统时延，形成了相对完整的多方位验证

### 8. 不足与局限

- **依赖可辨识的交叉注意力路径**：论文在 Limitations 中坦承，对于高度交织或层级结构复杂的架构（某些深层耦合 VLA），难以分离出统一的 action→VLM 注意力信号，方法可能失效
