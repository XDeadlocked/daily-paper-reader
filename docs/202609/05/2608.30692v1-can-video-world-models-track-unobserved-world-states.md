## 摘要
视频世界模型越来越多地被用作模拟器，然而视觉保真度本身并不能说明模型是否维持了世界的隐藏状态。我们通过一个动作条件下的视频壳游戏（Shell Game）来检验这一差距，这是一种视觉模拟的$S_5$状态追踪任务，将视觉渲染与底层隐藏状态的合成分离开来。双向和自回归Transformer、Mamba以及限制为非负转移特征值的线性注意力都能拟合5次交换的训练范围，但在更长的交换链（外推）上表现降至随机水平，同时仍能渲染出看似合理的视频，额外的去噪步骤也无济于事。基于像素的扩散目标从未监督看不见的隐藏状态，因此生成的帧无法承载该状态，状态必须驻留在架构内部而非token中。对于Transformer而言，这种架构状态仅是一种只追加的KV缓存，因此模型必须在每个块中从整个历史重新推导隐藏排列。我们发现两种能够外推的机制，两者都在块间携带状态并在原位修改。线性注意力在其转移特征值允许为负时成功，而具有非线性快速权重的TTT则通过更新其读取自身状态的特征图来成功。我们进一步考察了动态世界探索任务中更困难的情况，并讨论了构建有状态的视频世界模型的更广泛意义。

## Abstract
Video world models are increasingly used as simulators, yet visual fidelity alone does not show that a model maintains the hidden state of the world. We examine this gap with an action-conditioned video Shell Game, a visual analog of $S_5$ state tracking that decouples visual rendering from compositing the hidden state underneath. Bidirectional and autoregressive Transformers, Mamba, and linear attention restricted to nonnegative transition eigenvalues all fit the training horizon of 5 swaps and then fall toward chance on longer swap chains (extrapolation) while still rendering plausible video with additional denoising steps providing no benefit. The pixel-based diffusion target never supervises the unseen hidden state, so the generated frames cannot carry it and the state has to live inside the architecture rather than in the tokens. For a Transformer, that architectural state is only an append-only KV cache, so the model has to re-derive the hidden arrangement from the whole history at every chunk. We find two mechanisms that do extrapolate, and both carry a state across chunks and revise it in place. Linear attention succeeds once its transition eigenvalues may be negative, and TTT with a nonlinear fast weight succeeds by updating the feature map through which it reads its own state. We further examine harder cases in dynamic world exploration tasks, and discuss the broader implications for building stateful video world models.

## 2. 方法论

### 2.1 核心思想
将视频世界模型的状态追踪能力从视觉生成质量中解耦出来。作者以 S5 群上的“仅交换”词问题为基础，构建了动作条件的视觉壳游戏：观察者看到小球初始位置、杯子落下、然后经历一串遮挡下的两两交换，最终要求模型在杯子重新举起时判断小球所在位置。该过程虽然视觉上简单（每帧渲染容易），但正确输出必须由隐藏状态的复合更新决定，无法从当前帧直接推断。

### 2.2 关键技术细节
- **理论框架**：利用电路复杂度理论。固定深度 Transformer、SSM、线性注意力属于 TC0 类并行模型，无法对非交换群长链进行序列化状态合成；S5 词问题是 NC1 完全问题。视频扩散的迭代去噪仅用固定深度骨干重复调用，不增加串行深度，因此无法赋予模型状态追踪能力。
- **视觉壳游戏设计**：5 个相同杯子、1 个小球；动作包括 lift、lower、10 种两两 swap、no-op。每个序列先揭示小球并放下杯子，经历 N 次交换后再揭示。将每次交换对应一个自回归 chunk（5 帧潜在视频），渲染通过冻结的 Wan VAE 处理，训练采用流匹配与 diffusion forcing。
- **架构家族**：
  - 双向 DiT、因果 DiT（SWA 窗口可变，如 SWA1、SWA7）
  - 非线性 RNN/GRU/LSTM
  - 线性注意力：Mamba2、Gated DeltaNet (GDN)、GDN2、GDP3、KDA；并设置“-neg”变体，将 DeltaNet 风格更新中的 β 范围从 [0,1] 扩到 [0,2]（即转移特征值范围扩展到 [-1,1]）
  - TTT：LaCT（大块 TTT），状态为内部小型 SwiGLU 网络的权重，采用负点积 KV-binding 损失进行在线更新
  - 显式 scratchpad token：每层附加 M 个可读写记忆 token，以 M ← M + ΔM 方式跨 chunk 传递
- **关键公式**：
  - DeltaNet-style 状态更新：
    $S_t = (I - \beta_t k_t k_t^\top) S_{t-1} + \beta_t k_t v_t^\top$
    其中 β ∈ [0,1] 只支持非负特征值（不可反射），β ∈ [0,2] 时特征值可达到 [-1,1]（能实现反射/交换）。
  - LaCT 的 SwiGLU 快速权重：
    $f_W(x) = W_1 [\text{silu}(W_0 x) \odot (W_2 x)]$
    每 chunk 结束时通过点积 KV-binding 损失梯度更新 W0、W1、W2 三个矩阵，其中 W0、W2 决定特征图，W1 负责读出。更新特征图使内核变成历史依赖，超越普通线性注意力。
  - 对比消融：单层线性内部模型 TTT 退化为普通线性注意力；MSE 损失退化为 DeltaNet 规则；只更新 W1（冻结 W0、W2）则特征图固定，外推失败。

## 6. 主要结论与发现

1. **视觉保真不能保证状态追踪**：多数模型能渲染流畅视频，但隐藏球位置准确率随链长上升快速滑落到 chance；扩散步数增加完全无效（4 步与 50 步精度几乎相同）。
2. **标准架构失败的原因**：
   - 自回归 Transformer 的 KV cache 本质是“只读/只追加”的视觉历史，无法原位更新状态，每块都要用固定深度从完整历史重推导状态，因而窗口加大只能延后失败。
   - 非负特征值的线性注意力虽然存在跨块矩阵状态，但转移只能压缩/覆盖，无法实现交换所需的反射型变换，因此表达力不足。
3. **成功的外推机制只有两类**：
   - 允许负特征值（β∈[0,2]）的线性注意力，能执行反射操作，可组合出置换链。
   - LaCT 这一类 TTT-fast-weight 方法：使用 SwiGLU 作为内部状态，通过更新 W0、W2 让特征图历史化，状态演进不再局限于固定核的线性注意力；而且在线更新 W1 本身并不起作用，更新特征图才是关键。多快速权重头数对追踪有帮助，更多头数即使参数更少也超过单头。
   - 显式 scratchpad token 只能实现加法式更新，最长可到 N=10，但其状态范数发散，无法支撑 N=20 外推。
4. **探测结果支持诱导机制**：能外推的模型（LaCT 和 GDN-neg）在固定 bank 读取中保留了解码隐藏球位置的信息，而失败模型内部几乎没有可用的隐藏状态。
5. **更一般的世界模型具有更高的状态追踪要求**：Memory Maze 和 Block World 中，状态不只是动作的函数，还受观测纠正、动作碰撞或无人驱动动态影响。这些场景中 LaCT 仍是最强之一，但负特征值不再带来重要增益，说明更广义的状态追踪可能需要新的抽象和机制。

## 7. 优点

- **问题选取新颖且深刻**：直接攻击“视频生成质量 vs 世界状态理解”的脱节，弥补了世界模型评估中的关键盲点。
- **理论照应**：将复杂度理论（TC0 vs NC1）与可视化任务结合，预测了哪些架构能或不能外推，实验证据与理论一致，增强结论的可信度。
- **任务设计精巧**：壳游戏视觉简单但状态追踪困难，不同架构只需改变混合模块，条件控制干净，能清晰地隔离“渲染”和“状态更新”。
- **深度消融**：包括特征值范围扩展、快速权重头数、更新哪些权重矩阵、内部损失选择、scratchpad 数量、注意力窗口大小，能精准定位哪些机制真正提供了状态追踪能力。
- **机制探测**：用固定向量探测 KV 缓存 / 快速权重中的隐藏信息，提供“状态是否真的被编码在架构中”的直接证据。
- **关注更广适用性**：扩展到 Memory Maze 和动态 Block World，考虑观测校正、碰撞、视线外运动，避免停留在玩具任务上。

## 8. 不足与局限

- **规模与泛化有限**：所有视频模型均在约 200M 参数规模、单一流匹配配方上训练，未测试更大参数、真实世界视频、多模态输入下的迁移。
- **统计稳健性不足**：主要状态准确率只基于 64 条 episode，未报告多次重复的方差或置信区间。
- **训练细节稀缺**：GPU 类型与数量、总耗时、长链外推时的显存 / 时间开销、LaCT 和 scratchpad 的额外训练成本均未量化。
- **对 LaCT 的行为仍理解有限**：为何点积损失配合权重归一化工作良好而 MSE 失败、为什么头数增加比状态大小更重要，论文提供了推测性解释但未给出严格数学证明。
- **更复杂场景中的结论较为模糊**：Memory Maze / Block World 上没有明确计算状态准确率，只以生成视频的 PSNR/SSIM/LPIPS 代替，难以推断模型是否真正跟踪了隐藏位姿或物体，与壳游戏中的精确评测不对称。
- **评测任务本身的可推广性受限**：壳游戏刻意去除了视觉歧义，只留单纯代换组合，实际应用中视觉观察与状态更新之间存在噪声与耦合，该基准可能低估了视频模型纠正状态所需的能力。
- **领域知识有限制**：作者未讨论 RL 式奖励信号、语言模型式 scratchpad 监督以及更大的时间 chunk 上训练成本对状态追踪的影响，这些在真实应用中可能非常重要。
