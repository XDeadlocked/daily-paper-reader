## 摘要
预训练的生成式机器人策略能够从演示中学习富有表现力的动作先验。然而，现有强化学习方法仅引导噪声空间，而无法在生成过程中调节中间动作表示，导致性能下降和效率低下。为解决这一局限，我们提出了一种新颖的双潜在空间强化学习（DLSRL）框架，其在冻结生成器内部以表示级控制来补充初始噪声引导。具体而言，我们的 Actor 网络预测两个不同的潜在变量：一个用于引导行为生成的初始噪声潜在变量，以及一个用于中间特征调制的动作表示潜在变量。此外，该表示潜在变量被映射为适配器特征，并通过残差连接巧妙地注入到中间动作 token 的隐藏状态中。我们的双控制设计能够在不更新基础策略的情况下直接调整动作表示。在生成式策略架构和机器人操作任务上的实验表明，DLSRL 有效加速了在线机器人策略自适应，并取得了有竞争力的性能。我们的代码可在 https://github.com/xianchaoxiu/DLSRL 获取。

## Abstract
Pretrained generative robot policies learn expressive action priors from demonstrations. However, existing reinforcement learning methods only steer the noisy space but fail to modulate intermediate action representations during the generation process, resulting in performance degradation and inefficiency. To address this limitation, we propose a novel Dual-Latent Space Reinforcement Learning (DLSRL) framework, which complements initial-noise steering with representation-level control inside the frozen generator. Specifically, our actor network predicts two distinct latent variables: an initial-noise latent variable that steers behavior generation, and an action-representation latent variable for intermediate feature modulation. Moreover, this representation latent variable is mapped to adapter features and ingeniously injected into the hidden states of intermediate action tokens via residual connections. Our dual-control design enables direct adjustment of action representations without updating the base policy. Experiments across generative policy architectures and robotic manipulation tasks show that DLSRL effectively accelerates online robot policy adaptation and achieves competitive performance. Our code is available at \href{https://github.com/xianchaoxiu/DLSRL}{https://github.com/xianchaoxiu/DLSRL}.

## 2. 方法论
- **核心思想**：
  - 将机器人操作建模为 MDP，策略输入观测 \(o_t=(I_t,q_t,\ell)\)，输出动作 chunk \(a_t\in\mathbb{R}^{H\times d_a}\)。
  - 基座生成策略 \(G_\phi\) 预训练后参数 \(\phi\) **完全冻结**，仅训练轻量外部控制模块。
  - 双潜在 Actor 同时预测两个变量：
    - **初始噪声潜变量 \(z_t\)**：控制生成起点，影响整体行为模式；
    - **动作表示潜变量 \(u_t\)**：用于中间动作表示调制。
- **关键技术细节**：
  - 双潜在策略：\((z_t,u_t)\sim \pi_\theta(\cdot|o_t)\)。
  - 适配器特征映射：\(f_t=A_\omega(u_t)\)，将 \(u_t\) 映射为与动作 token 隐藏状态同形状的适配器特征。
  - 冻结生成器执行：\(a_t=G_\phi(o_t,z_t,f_t)\)。
  - **残差注入**：在第 \(l\) 个冻结 Transformer 块输出的动作 token 隐藏状态 \(H^{(l)}_{t,k}\) 上注入：
    - \(\tilde{H}^{(l)}_{t,k}=H^{(l)}_{t,k}+\delta_t\)；
    - \(\delta_t=\lambda_{\text{inj}}f_t\)，其中 \(\lambda_{\text{inj}}\) 为全局注入强度。
  - 注入仅作用于动作 token 位置，不修改视觉、语言、本体感觉等上下文 token；同一适配器特征可跨选定 Transformer 块和生成更新步共享。
- **训练算法（Dual-Latent Policy Optimization）**：
  - 使用动作空间 critic \(Q^{\text{act}}_\psi(o_t,a_t)\) 通过离策略 TD 学习估计动作 chunk 回报。
  - 将动作价值蒸馏到潜在空间 critic \(Q^{\text{lat}}_\nu(o_t,z_t,f_t)\)：
    - \(L_{\text{distill}}=\mathbb{E}[(Q^{\text{lat}}_\nu(o_t,\hat z_t,\hat f_t)-\text{sg}[Q^{\text{act}}_\psi(o_t,\hat a_t)])^2]\)。
  - Actor 与适配器映射器通过熵正则目标更新：
    - \(L_{\text{actor}}=\mathbb{E}[\alpha\log\pi^z_\theta(z_t|o_t)-Q^{\text{lat}}_\nu(o_t,z_t,f_t)]\)。
  - 训练时动作 critic、潜在 critic、Actor 与适配器映射器交替更新；部署时仅保留 Actor 与适配器映射器，丢弃两个 critic。
  - 基座生成器参数始终冻结，无需反向传播通过生成过程。
