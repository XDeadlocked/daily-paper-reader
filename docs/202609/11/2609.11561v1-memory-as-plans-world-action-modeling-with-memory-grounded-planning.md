## 摘要
主流机器人策略通常采用马尔可夫形式化，但许多复杂的真实世界操作任务本质上是非马尔可夫的，需要超越当前观测的长时程记忆。现有记忆机制往往依赖语言摘要、不断增长的视觉窗口或二者的组合，因此可能丢失细粒度视觉证据，或面临历史覆盖与执行效率之间的权衡。我们提出 MaP-WAM，一种记忆即规划（Memory-as-Plans）框架，将依赖记忆的世界-动作建模分解为基于记忆接地的规划与以规划为条件的执行，并使用长期多模态情节上下文作为规划时证据，而不是反复让执行器以完整历史为条件。MaP-WAM 将记忆表示为包含语言指令和稀疏视觉上下文的已完成片段记录，并将这种情节记忆转换为紧凑规划，其中包括下一片段级语言规划和相应的视觉引导。世界-动作-进度（WAP）模型在未知时长内执行每个规划，在推理时联合预测动作块和相应的执行进度，并通过规划-观测对齐校准预测进度，以实现自适应片段切换和闭环上下文更新。MaP-WAM 保持执行器上下文长度固定，同时结构化注意力进一步在规划和执行中支持键值缓存。MaP-WAM 在 RMBench 上以 83.3% 的成功率取得最先进性能，并在真实机器人任务上达到 78.0% 的成功率，同时随着任务历史增长，执行器推理延迟保持近似恒定。

## Abstract
Mainstream robotic policies often adopt a Markovian formulation, but many complex real-world manipulation tasks are inherently non-Markovian, requiring long-horizon memory beyond the current observation. Existing memory mechanisms often rely on language summaries, growing visual windows, or their combinations, and may therefore lose fine-grained visual evidence or face a trade-off between history coverage and execution efficiency. We introduce MaP-WAM, a Memory-as-Plans framework that decomposes memory-dependent world-action modeling into memory-grounded planning and plan-conditioned execution, and uses long-term multimodal episodic context as planning-time evidence rather than repeatedly conditioning the executor on the full history. MaP-WAM represents memory as completed segment records containing language instructions and sparse visual context, and converts this episodic memory into compact plans comprising the next segment-level language plan and corresponding visual guidance. A World-Action-Progress (WAP) model executes each plan over an unknown duration by jointly predicting action chunks and corresponding execution progress at inference time, calibrating predicted progress through plan-observation alignment for adaptive segment transitions and closed-loop context updates. MaP-WAM keeps the executor context length fixed, while structured attention further enables key-value caching in both planning and execution. MaP-WAM achieves state-of-the-art performance on RMBench with an 83.3% success rate and attains 78.0% success on real-robot tasks, while maintaining approximately constant executor inference latency as task history grows.

## 1. 核心问题与研究动机

- **背景**：VLA（视觉-语言-动作）模型与 WAM（世界-动作模型）在机器人操作上进展显著，但主流做法采用**马尔可夫式**形式化——只以当前观测或固定短历史为条件。
- **核心矛盾**：真实世界中许多长时程操作任务本质是**非马尔可夫**的（部分可观测），决策所需信息可能已不在当前视野内（如物体初始位置、被遮挡按钮颜色、需回忆的数字序列）。
- **现有记忆机制的不足**：
  - *语言记忆*（语言摘要/子任务指令）：紧凑可解释，但**丢失细粒度视觉与空间证据**。
  - *增长式视觉窗口 / 因果 WAM*（如 LingBot-VA）：保留丰富感知证据，但逐帧条件化导致**推理延迟与显存随历史增长**，形成"历史覆盖 vs 执行效率"的权衡。
  - *持续更新式记忆*（潜状态、记忆库）：早期证据易被压缩或覆盖。
- **论文主张**：长时程视觉历史**不必在每个控制步直接输入执行器**——它主要用于确定下一段级规划与期望的视觉演化；执行只需跟随"记忆接地的规划"。由此提出 **MaP-WAM**，将记忆依赖的世界-动作建模**解耦为记忆接地规划 + 规划条件化执行**。

## 2. 方法论

### 2.1 核心思想与问题形式化

- 一般记忆依赖策略：`π(a_{t+1:t+h} | f_{≤t}, s_t, l)`，难点在于关键信息位于历史观测 `f_{<t}`。
- MaP-WAM 的两阶段分解：
  - **规划**：`π_P(C_k | C_{<k}, l)`，从情节上下文推断第 k 段的多模态规划；
  - **执行**：`π_E(a_{t+1:t+h} | C_k, f_t, s_t, l)`，`[t, t+h] ⊆ H(C_k)`，执行器输入**与历史长度无关**，故上下文长度固定。

### 2.2 记忆接地规划（Memory-Grounded Planning）

- **结构化多模态情节上下文**：每个已完成片段 i 记为 `C_i = {l_i, G_i}`——语言指令 + 稀疏视觉上下文 `G_i`（在该段真实执行轨迹中按 8 个等时窗各取末帧，N=8）；初始观测记为 `G_0 = f_0`。避免处理稠密、无限增长的帧序列。
- **语言规划器**：微调 Qwen3.5-4B，输入全局指令、已完成片段指令、紧凑关键帧集 `f*`（初始帧 + 各完成段末帧），输出下一段级语言规划 `l_k`：`π^l_P(l_k | l_{<k}, l, f*)`。
- **视觉规划器（CWM，因果世界模型）**：以 WAN-2.2-5B 初始化，条件为 `(G_{<k}, l_k, l)`，用标准 flow-matching 目标 `L^v_P = L_FM(G_k, (G_{<k}, l_k, l))` 生成视觉规划 `G_k`，提供细粒度执行引导。
- **因果注意力与 KV 缓存**：token 按段分块，施加**块因果掩码**防止跨段未来泄漏；已完成段的证据成为**静态可缓存前缀**，跨注意力中完成段只关注全局指令、目标块关注段级语言规划，使前缀 KV 可一次计算多次复用。

### 2.3 世界-动作-进度（WAP）模型

- **动机**：规划所需的执行时长事前未知（取决于任务复杂度与随机动力学），需要显式的时间对齐信号。
- **进度定义**：对训练片段 `f_{i:j}`，归一化进度 `p_t = (t−i)/(j−i)`，`t ∈ [i, j]`，为执行状态与视觉规划提供连续坐标。
- **架构**：以预训练视频 DiT（WAN-2.2）为骨干，按 **Mixture-of-Transformers (MoT)** 扩展出动作专家（1.02B 参数，hidden 1024）与进度专家（207M 参数，hidden 256），**联合建模未来视觉动态、动作块、进度序列**。
- **条件与掩码**：条件 `c = (G_k, l_k, f_t, s_t, p_t)`；视觉规划编码为静态干净前缀，当前观测为干净状态 token，未来视觉/动作/进度为噪声目标 token；动作与进度 token 不关注未来视觉 token（反之亦然，遵循 FastWAM），未来视觉预测仅作辅助训练目标、推理时可省略；跨注意力中所有 token 关注语言规划，动态 token 额外条件化于本体状态 `s_t` 与当前进度 `p_t`。
- **训练目标**：对三个模态分别施加条件 flow matching `L^m_E = L_FM(y_m, c)`，`m ∈ {v, a, p}`；总损失 `L_E = λ_v L^v_E + λ_a L^a_E + λ_p L^p_E`（实验中 λ 均为 1.0）。
- 进度作为**一等模态**，与动作联合生成并作为条件反馈（区别于以往将进度用作事后验证器或奖励信号）。

### 2.4 闭环规划与执行

- **计划-观测对齐的进度校准**：部署时无真值进度，递归预测会累积漂移；视觉规划按归一化进度索引，故在预测进度附近检索若干规划帧，用 RGB 空间**平均绝对像素差**选出与执行后观测最相似的帧，将进度条件向该帧索引更新（轻量、免训练）。
- **进度门控的片段切换**：对最近动作上的预测进度取平均，超过阈值 `τ = 0.95` 即判定当前段完成，终止当前规划、更新情节上下文、触发下一段规划。
- **上下文更新接地**：真实执行观测被均匀重采样为稀疏视觉上下文 `G_k`，替换生成的视觉规划后追加为 `{l_k, G_k}`，保证记忆基于**真实观测**而非生成预测。
- **推理流程**（附录 Algorithm 1）：生成语言规划 → 生成视觉规划 → 预填充并缓存 WAP 规划前缀 → 循环（校准进度 → 联合预测动作/进度 → 执行 h 步 → 计算完成分数）→ 重采样更新情节上下文 → k ← k+1。

### 2.5 关键实现细节

- 每完成段重采样 N=8 帧；前缀含 `1 + 8(k−1)` 帧，经 WAN-VAE 时间压缩为 `1 + 2(k−1)` 个潜时间步。
- 训练用 1000 步 flow-matching 时间步，噪声时间表 shift 系数 5.0（训练与推理一致）；推理 10 步去噪。
- 动作视界 h=32（训练），推理仅执行前 8 个动作。
- 训练时进度条件加均匀 `[−0.1, 0.1]` 偏移并裁剪到 `[0,1]`；动作与进度分支共享 flow 时间步，未来视频分支独立采样。
- 动作/进度专家由视频专家权重插值并按输出方差重缩放初始化；VLM 使用 LoRA（rank 32, alpha 64）。
