## 摘要
模仿学习在机器人操作中已取得显著成果，但大多数现有方法假设背景干净，且缺乏显式的障碍物感知运动生成机制。将此类策略扩展到具有非结构化障碍物的杂乱真实场景仍是一个关键的泛化挑战。我们提出 ObstaDiff，一种分解式扩散策略框架，配备轻量级障碍物感知视觉编码器。ObstaDiff 提取结构化的目标-障碍物-背景表征，使下游对齐策略能够生成朝向以目标为中心的瓶颈位姿的末端执行器轨迹，同时推理周围障碍物。我们在每种方法的 61 次真实机器人温室试验（总共 366 次执行）上评估 ObstaDiff。ObstaDiff 取得 75.41% 的平均任务成功率和 8.20% 的平均障碍物碰撞率，优于代表性的模仿学习基线，并提升了在杂乱农业场景中的泛化能力。

## Abstract
Imitation learning has achieved impressive results in robotic manipulation, yet most existing approaches assume clean backgrounds and lack explicit mechanisms for obstacle-aware motion generation. Extending such policies to cluttered, real-world scenes with unstructured obstacles remains a key generalization challenge. We present ObstaDiff, a decomposed diffusion-policy framework with a lightweight obstacle-aware visual encoder. ObstaDiff extracts a structured target-obstacle-background representation, enabling the downstream alignment policy to generate end-effector trajectories toward a target-centered bottleneck pose while reasoning about surrounding obstacles. We evaluate ObstaDiff on 61 real-robot greenhouse trials per method (366 executions in total). ObstaDiff achieves 75.41% average task success and 8.20% average obstacle collision rate, outperforming representative imitation-learning baselines and improving generalization in cluttered agricultural scenes.

## 2. 方法论

### 2.1 核心思想

- 将 RGB-D 观测转换为显式语义结构：**目标（target）**、**障碍物（obstacle）**、**背景（background）** 三类掩码加深度通道。
- 用轻量级 **StructuredObsEncoder** 编码该结构化观测，而非使用通用 ResNet 图像骨干。
- 将任务分解为两个阶段：
  - **对齐阶段**：扩散策略生成避障接近轨迹，到达以目标为中心的“瓶颈位姿”。
  - **交互阶段**：通过 replay 库回放演示轨迹，完成近距离接触式操作。

### 2.2 TOB 观测构建

- 使用眼在手 RGB-D 相机获取 RGB 与对齐深度图。
- 用微调的 **YOLOv8s-Worldv2** 开放词汇检测器预测目标与障碍区域，再用 **MobileSAM** 细化障碍掩码。
- 生成三类二值掩码：背景 `mbg`、障碍 `mobs`、目标 `mtar`，并与归一化深度 `d̄` 拼接：
  - 输入张量：`x_t = [mbg; mobs; mtar; d̄] ∈ [0,1]^(4×240×320)`。
- 该表示显式保留目标–障碍空间关系，同时抑制背景外观变化。

### 2.3 结构化观测编码器

- 将四通道 TOB 输入拆分为：
  - **语义分支**：前 3 通道掩码，输出 `32×60×80` 特征，经 spatial softmax 得到 32 个 2D 坐标，即 64 维特征 `z_seg`。
  - **深度分支**：第 4 通道深度，输出 `16×60×80` 特征，经 spatial softmax 得到 16 个 2D 坐标，即 32 维特征 `z_dep`。
- 每个分支由 4 个 `Conv2D → GroupNorm → ReLU` 块组成，卷积核/步幅为 `(5×5,s2) → (3×3,s2) → (3×3,s1) → (3×3,s1)`。
- 与 7 维末端位姿 `e_t` 拼接，得到 103 维条件向量：
  - `c_t = [z_seg; z_dep; e_t] ∈ R^103`。
- 使用两个观测步时，扩散策略条件输入为 206 维。

### 2.4 对齐阶段扩散策略

- 条件扩散策略预测末端动作序列 `A_0 = {a_1, ..., a_Ta}`。
- 训练时对干净动作序列加高斯噪声：
  - `q(A_k | A_0) = N(A_k; √ᾱ_k A_0, (1-ᾱ_k)I)`。
- 噪声预测网络 `ε_θ` 以结构化观测条件 `c_1:n` 和扩散步 `k` 为条件，优化均方误差：
  - `L = E[ ||ε - ε_θ(A_k, c_1:n, k)||² ]`。
- 推理时迭代去噪，使用 DDIM 调度器，`K=100` 步；预测 16 步动作，执行前 8 步，滚动时域重规划。

### 2.5 瓶颈切换与交互阶段

- 训练 90 条专家对齐演示，构建包含 26 条交互轨迹的 replay 库。
- 目标状态表示为 `g_t = [u_tar, v_tar, d_tar]`，即目标框中心图像坐标与目标深度。
- 切换规则：
  - 计算当前目标与 replay 条目的归一化图像误差 `e_u, e_v`。
  - 计算单边深度误差 `e_d = max(0, (d_tar_t - d_i0)/D)`，允许当前目标比 replay 参考更近。
  - 每个 replay 条目有深度就绪标志；在深度就绪条目中选择图像误差最小者。
  - 当图像平面误差之和 `e_u + e_v ≤ ε_uv = 0.2` 时切换到交互阶段。
  - 深度门限 `ε_d = 0.005`，对应 5 mm；图像归一化尺寸 `W=640, H=480`。
- 交互阶段直接回放对应动作序列，避免近距离深度不可靠问题。

## 3. 实验设计

- **场景与硬件**：
  - 室内温室测试台，7-DoF Sawyer 机械臂，眼在手 Intel RealSense D455 RGB-D 相机。
  - 任务：机器人到达目标区域内的辣椒目标并避开周围植物障碍；任务完成定义为触碰目标。
- **数据与演示**：
  - 收集 90 条专家对齐演示，使用重力补偿示教模式。
  - 所有演示目标为紫色辣椒，绿色辣椒在训练中完全未见。
  - 演示均匀分布在三种障碍配置中，每种 30 条目标位姿演示。
  - 交互阶段使用 26 条 replay 轨迹。
- **Benchmark 设置**：
  - **TPG（目标位姿泛化）**：10 个目标位置 × 2 个朝向 = 20 次试验。
  - **OLG（障碍布局泛化）**：固定目标，3 种障碍排序 × 7 个障碍位置 = 21 次试验；障碍物种与训练相同，但空间布局和位置未见。
  - **TAG（目标外观泛化）**：目标从训练紫色辣椒变为两种未见绿色辣椒品种，每种 10 个位姿 = 20 次试验。
  - 合计每方法 61 次真机试验，6 种方法共 366 次执行。
- **对比方法**：
  - `ACT (RGB)`：标准 RGB 输入的 ACT 策略。
  - `ACT (TOB)`：ACT 使用 TOB 观测，评估 TOB 是否也利于非扩散策略。
  - `DP (RGB)`：标准 Diffusion Policy，ResNet-18 编码 RGB。
  - `DP (RGB-D)`：在 DP 中增加对齐深度第四通道，隔离深度作用。
  - `DP (TOB)`：同一 DP 编码器直接输入四通道 TOB，隔离观测表示作用。
  - `ObstaDiff`：TOB 观测 + 结构化编码器 + 扩散对齐策略。
- **指标**：
  - 任务成功率 TSR（越高越好）。
  - 障碍碰撞率 OCR（越低越好）。
  - 任务完成时间
