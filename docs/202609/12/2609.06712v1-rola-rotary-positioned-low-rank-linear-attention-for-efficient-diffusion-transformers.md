## 摘要
扩散 Transformer（DiT）实现了强大的视频生成质量，但其密集时空自注意力随序列长度呈二次方增长，并迅速成为推理的主要瓶颈。稀疏低秩混合方法通过将局部稀疏分支与全局压缩分支相结合来缓解这一开销。在配备 3D 旋转位置嵌入（RoPE）的视频 DiT 中，全局分支面临结构兼容性问题：当 RoPE 施加于非线性特征映射之前时，旋转与非线性通常不可交换，从而难以在保持相对旋转几何的同时，维持一个与查询无关的线性汇总。现有工作通常通过用坐标条件化的替代物或可学习绝对位置模块来取代真正的跨 token 全局聚合，从而回避这一问题。这些折中方案可能有效，但它们从绝对坐标近似相对衰减，并引入额外的位置参数。我们提出 RoLA，一种旋转定位的低秩线性注意力分支，它在保持真正的跨 token 聚合的同时，仍与可复用的线性汇总兼容。该设计将 RoPE 施加在非线性低秩特征映射之外，并复用与低秩瓶颈匹配的预训练旋转调度的截断子集。这产生了一个线性时间的低秩全局分支，其设计上具有相对位置行为且无需额外位置参数；完整的稀疏--低秩模块仍包含固定稀疏度的稀疏分支。在开源视频 DiT 上的实验表明，所得方法在 90% 稀疏度下仍保持有竞争力的生成质量，同时在 Wan2.1-14B（720p，81 帧，在 NVIDIA H100 GPU 上测量）上实现了 2.63× 的端到端推理加速。

## Abstract
Diffusion Transformers (DiTs) achieve strong video generation quality, but their dense spatiotemporal self-attention scales quadratically with sequence length and quickly becomes the dominant inference bottleneck. Sparse low-rank hybrids alleviate this cost by combining a local sparse branch with a global compressed branch. In video DiTs equipped with 3D Rotary Position Embeddings (RoPE), the global branch faces a structural compatibility issue: when RoPE is applied before a nonlinear feature map, the rotation and nonlinearity generally do not commute, making it difficult to keep a query-independent linear summary while preserving relative rotary geometry. Existing work often sidesteps this issue by replacing genuine cross-token global aggregation with coordinate-conditioned surrogates or learnable absolute positional modules. These compromises can be effective, but they approximate relative decay from absolute coordinates and introduce extra positional parameters. We propose \textbf{RoLA}, a rotary-positioned low-rank linear-attention branch that keeps genuine cross-token aggregation while remaining compatible with a reusable linear summary. The design applies RoPE \emph{outside} the nonlinear low-rank feature map and reuses a truncated subset of the pre-trained rotary schedule matched to the low-rank bottleneck.   This yields a linear-time low-rank global branch with relative positional behavior by design and no additional positional parameters; the full sparse--low-rank module still includes the fixed-sparsity sparse branch. Experiments on open-source video DiTs show that the resulting method remains competitive in generation quality at 90\% sparsity while achieving 2.63$\times$ end-to-end inference speedup on Wan2.1-14B (720p, 81 frames, measured on an NVIDIA H100 GPU).

# RoLA：用于高效扩散 Transformer 的旋转定位低秩线性注意力 —— 论文深度总结

## 1. 核心问题与研究动机

- **背景瓶颈**：扩散 Transformer（DiT）已成为高保真视频生成的主流骨干，但其稠密时空自注意力随序列长度呈**二次方增长**（O(L²)）。在超高分辨率、长时长视频（L ≳ 10⁴）下，注意力迅速成为推理的主导瓶颈。
- **现有缓解思路**：稀疏注意力仅计算部分 query–key 交互，但在高稀疏度下会丢弃长程全局上下文，损害语义一致性、运动连贯性与场景布局稳定性。为此，**稀疏–线性混合**方法在局部稀疏分支之外增加一个廉价的全局压缩分支。
- **结构性矛盾（RoPE Dilemma）**：视频 DiT 使用 **3D 旋转位置嵌入（RoPE）**，通过位置相关旋转编码相对几何。而线性注意力依赖**与查询无关、可跨 token 复用的全局摘要**。若按常规做法把 RoPE 推入非线性特征映射之前，旋转与非线性**不可交换**，导致摘要与绝对位置纠缠，无法同时保持相对旋转几何与可复用线性摘要。
- **现有折中的代价**：RoPeSLR 等工作用**坐标条件化的替代物 + 可学习绝对位置模块**回避该问题，但（1）相对衰减是从绝对坐标近似而来的，而非由全局分支本身表示；（2）放弃了可复用线性注意力视角，并引入额外位置参数。
- **核心追问**：能否构建一个**真正的线性全局分支**，同时与 3D 相对位置结构兼容？RoLA 给出的答案是：**在非线性之后对已压缩的低秩特征施加旋转**，并复用预训练旋转调度的截断子集。

## 2. 方法论

### 2.1 核心思想
- 将注意力分解为两个互补分支：**块稀疏分支**（捕获高能量语义尖峰）与**低秩线性分支**（重建平滑全局背景连续体）。稀疏分支沿用标准块稀疏注意力（如 SLA/VMoBA），非本文贡献。
- 本文贡献聚焦于**低秩分支的形式**：不做坐标替代，而是保留真正的跨 token 线性聚合，通过"**RoPE 置于激活之外**"+"**秩截断复用预训练旋转调度**"使其与相对旋转几何兼容。

### 2.2 关键技术细节

- **低秩分支计算（式 2–3）**：
  - 先对主干归一化后的 query/key 做低秩投影并施加非线性：`SiLU(Pq·qⁿ_p)`、`SiLU(Pk·kⁿ_q)`；
  - **之后**才施加截断 3D RoPE 旋转 `R_r(p)`、`R_r(q)`；
  - 全局上下文 `C = Σ_q k̃_q v_qᵀ ∈ R^{r×d_h}` 每头只算一次，复杂度 O(Lrd_h)，线性于 L；
  - 输出 `O_lr_p = RMSNorm(q̃_pᵀ C)`。
- **维度截断（第 4.2 节）**：低秩空间维度 r ≪ d_h（默认 **r = 64**），只能承载 r/2 个完整旋转对，故按主干原生坐标顺序**截取前 r 个坐标**，直接复用主干的 (freqs_cos, freqs_sin)，**不重排、不重学频率、不新增位置参数**。
- **RoPE 位置（第 4.3 节）**：非线性低秩映射负责提取"无位置"内容特征，RoPE 仅作为相对位置算子。旋转后置使全局上下文仍可累积一次并被所有查询复用；位置效应仅在查询读取上下文时出现。若旋转前置，旋转与逐点激活不可交换，位置信息在聚合前即与内容纠缠，键侧摘要会依赖绝对位置。
- **特征对齐与门控融合（第 4.4 节）**：用逐 token 标量门 `g = σ(XW_g + b_g)` 调节低秩分支幅度；以稀疏输出的逐 token RMS 作为尺度参考做归一化融合（式 4）。门偏置 `b_g` 初始化为负值，使模块初始接近稀疏基线，再逐步引入低秩贡献。
- **训练策略（第 4.5 节）**：单阶段全量微调。新增参数 `Θ_new = {Pq, Pk, Wg, bg}` 用 Kaiming 初始化，与主干在标准 flow-matching 目标下联合优化；主干用小学习率。相比 RoPeSLR 的两阶段方案，因新增参数直接位于最终低秩注意力路径上，单阶段更自然。
- **工程实现**：两个融合 Triton 核。将投影权重离线拆分为偶数/奇数行，按 2D matmul 处理 RoPE 的偶奇坐标对，避免不规则索引；Kernel 1 累加 `C_even`、`C_odd`，Kernel 2 完成读出并施加 RMSNorm，精确复现式 (2)(3)。
- **理论支撑（附录 B）**：B.1 证明外部激活分支满足平移不变性与 O(L) 复用（结构性自检）；B.2 给出理想化嵌套设定下的截断误差上界（设计直觉，非训练保证）；B.3 证明内部激活 SiLU **不存在精确的相对分解**（结构障碍论证，排除精确性而非近似可学习性）。

## 6. 主要结论与发现

- **机制层面**：只有"RoPE 置于激活之外"同时满足位置感知（偏移范围 0.47）与近平移不变（残差 1.8e-5）；内部激活虽位置感知但平移残差大（3.7e-1），证实绝对位置泄漏；无 RoPE 则完全位置盲（偏移范围 0.0）。
- **截断充分性**：算子保真度在 r = 64 处饱和（时间轴余弦 0.55→0.80→0.93，高度轴 0.19→0.60→0.93），归一化 L2 误差同步趋零；下游质量在 r = 64 处增益明显，之后趋于平缓。
- **生成质量**：在 90% 稀疏度下，RoLA 在 Wan2.1-1.3B 上 VBench 五维均优于或持平于 VSA、SLA、RoPeSLR；在 Wan2.1-14B 上 SC 达 0.9629，优于 RoPeSLR 的 0.9601，PSNR 28.65、SSIM 0.891、LPIPS 0.108 均为最优。
- **效率**：Wan2.1-14B（720p, 81 帧, H100）去噪延迟从全注意力 1075.7s 降至 409.3s，实现 **2.63× 端到端加速**；Wan2.2-A14B-T2V 从 1584.6s 降至 548s。
- **复杂度**：低秩分支相对纯稀疏基线的额外 FLOPs 占比 η = (2r+0.5)/(L(1−S))，随 L→∞ 趋于 0，即在固定稀疏度下渐近可忽略。
- **训练策略**：单阶段微调与两阶段（RoPeSLR 式）质量相当甚至略优，说明新增参数直接位于最终路径上时无需分阶段预热。

## 7. 优点

- **问题定位精准**：清晰识别并形式化了 3D-RoPE 视频 DiT 中"可复用线性摘要"与"相对旋转几何"的结构性矛盾（RoPE Dilemma），并给出可验证的机制性预测。

- **工程落地性强**：提供融合 Triton 核，将偶/奇坐标对拆为纯 2D matmul，避免不规则索引，保证硬件友好。
- **验证体系完整**：机制级（位置核、排序、秩保真度）与生成级（多模型、多基准、多消融）结合，且设置了多重对照实验（全注意力微调对照、受控全局分支替换）以排除混淆因素。
- **理论自检克制**：明确区分"结构性自检"与"理论保证"，不夸大命题作用，学术表述诚实。
- **泛化性初步验证**：除 Wan2.1 外，还扩展至 Wan2.2 MoE 架构与 VBench 2.0 维度。

## 8. 不足与局限

- **模型覆盖有限**：论文自述当前评估仅聚焦于两个 Wan 模型（Wan2.1-1.3B/14B），外加 Wan2.2 扩展，未在 HunyuanVideo、CogVideoX、LTX-Video 等其他主流视频 DiT 上验证泛化性。
- **理论保证缺失**：附录中的命题（B.1、B.3、B.4）是结构性自检与理想化直觉，**不构成端到端生成保证**；截断误差分析依赖"保留子空间集中"假设，而实际 Pq/Pk 是直接在低秩空间学习的，理想化嵌套假设不严格成立，作者明确以经验保真度扫描作为操作证据。
- **延迟测量口径不完全统一**：主基准在 H100 上测 DiT 去噪延迟，而图 1 的部署延迟在 RTX 5090 上测，作者已说明两者不可直接对比，但这削弱了效率结论的横向一致性。
- **算力报告不完整**：未披露 GPU 数量、总训练时长/GPU 小时，难以评估适配成本的可复现性与实际部署门槛。
- **单阶段策略适用范围**：作者强调单阶段配方是"架构匹配的训练策略"，而非对所有稀疏–低秩设计的普适结论。
- **r = d_h/2 时的成本特性**：当 r 接近 d_h/2 时，低秩分支的 matmul 成本与全宽线性分支相当（式 10），此时优势主要在于相对位置结构而非常数级降本，需明确应用前提。
- **消融基数限制**：激活函数消融仅在 1.3B 模型上进行，稀疏度扫描也仅在 1.3B 上完成，14B 模型上的消融覆盖不足。
