## 摘要
世界模型让机器人能够想象可能的未来，但利用这一能力进行实时控制却受制于表示错位问题：生成模型与规划器在解耦的流形上运行，因此规划器没有共享结构可供搜索，而必须将每个候选解码回高维像素空间进行评估。这一解码步骤是物理硬件上实时控制的主要障碍。在本文中，我们提出了Hydra，一种离散的世界动作模型，通过将规划器（包括采样器和评估器）置于模型内部来弥合这一差距。Hydra在视觉状态、物理姿态和控制动作上建立一个统一的潜在流形，然后通过特定模态的向量量化瓶颈将该流形压缩为运动动力学意图和视觉状态的离散词汇表。由于候选现在直接从这一共享流形中抽取，采样由模型自身对观测的理解所引导，而不是盲目提出，并且评估在离散空间内原生进行：候选通过运动学-感知成本进行排序，而无需解码到像素。我们将此称为离散潜在规划（DLP）。由于仅对离散意图进行规划无法提供物理驱动所需的平滑连续命令，Hydra将DLP与条件流匹配相结合，将每个选定的意图映射到用于执行的连续轨迹。在两个物理机器人平台上的评估中，Hydra在目标导向规划方面优于最先进的世界模型，同时在闭环执行能力上匹配或超越领先的反应式基础策略。

## Abstract
World models let robots imagine possible futures, but exploiting this capability for real-time control is bottlenecked by a representation misalignment: the generative model and the planner operate on decoupled manifolds, so the planner has no shared structure to search over and must instead decode every candidate back into high-dimensional pixel space to evaluate it. This decoding step is a major obstacle to real-time control on physical hardware. In this paper, we present Hydra, a discrete World Action Model that closes this gap by moving the planner, both the sampler and the evaluator, inside the model. Hydra establishes a unified latent manifold over visual states, physical poses, and control actions, then compresses this manifold through modality-specific Vector-Quantized bottlenecks into discrete vocabularies of kinodynamic intents and visual states. Because candidates are now drawn directly from this shared manifold, sampling is informed by the model's own understanding of the observation rather than proposed blind, and evaluation happens natively within the discrete space: candidates are ranked by a Kinematic-Perceptual Cost, without ever decoding to pixels. We term this Discrete Latent Planning (DLP). Because planning over discrete intents alone cannot supply the smooth, continuous commands physical actuation requires, Hydra pairs DLP with conditional Flow Matching, which maps each selected intent to a continuous trajectory for execution. Evaluated on two physical robotic platforms, Hydra outperforms state-of-the-art world models in goal-directed planning, while matching or exceeding the closed-loop execution capabilities of leading reactive foundation policies.

## 2. 方法论：核心思想、关键技术细节

### 核心思想
- **统一潜在流形（Unified Latent Manifold）**：Hydra 在视觉状态、物理位姿与控制动作之间建立联合学习的单一潜在流形，使动作引起世界变化与潜在表示中的位移保持一致。
- **离散化意图瓶颈**：通过模态特定的向量量化（VQ）码本，将连续动作空间压缩为**有限、可枚举的物理可行意图词表**——即宏观级运动动力学原语（如“左转”），从根本上改变了搜索空间的性质：从无界连续空间中的盲目优化变为有限行为集合上的拓扑搜索。
- **规划器内嵌**：采样基于模型自身对观测的理解，评估在离散空间内原生完成，无需逐候选解码像素。

### 关键技术细节

**（1）统一多模态早期融合编码**
- 视觉隐状态经冻结的 Stable Diffusion VAE 提取；
- 位姿与动作经傅里叶特征映射后升维，与视觉潜在表示按长度广播相加，形成统一 token 流——采用**早期对齐**而非上下文对齐，将全部自回归容量用于时域动力学建模；
- 训练中使用余弦退火的模态掩蔽课程策略，增强对部分可观测性的鲁棒性。

**（2）非对称矢量量化瓶颈**
- 视觉码本大小 |V_i| = 2048，保持视觉表示容量；
- 位姿码本 |V_p| = 64，动作码本 |V_a| = 64，严格约束以支持快速检索；
- 引入**确定性线性锚定**（deterministic linear anchoring），防止码本维度膨胀与优化不稳定。

**（3）多模态生成性流匹配**
- 对视觉、位姿、动作三个模态分别使用条件 Rectified Flow Matching，将离散意图 token 映射回复连续轨迹；
- 视觉头使用完整 DiT 块（50 NFEs），位姿/动作头使用纯逐点 AdaLN-Zero MLP（10 NFEs），兼顾精度与延迟；
- 损失函数为矢量场损失：\( L_{flow} = E[\|v_\theta(\psi_s, s, e_c) - (\psi_1 - \psi_0)\|_2^2] \)。

**（4）离散潜在规划（DLP）**
- **无偏初始化**：以掩蔽未来状态查询模型的“无偏专家先验”作为搜索种子；
- **两层随机性**：① 对连续意图查询施加指数平滑的高斯噪声（站点1，生成不同轨迹形状）；② 使用 Top-K 限制的 Gumbel-Max 离散化（站点2，对每个候选的离散化进行鲁棒化），两层噪声各自独立平滑与退火。
- **运动学-感知成本（KPC）**：
  \[
  J_{KPC}(\tau) = C_{geo} + \sum_{t=1}^{T} \gamma^t \left( \lambda_{img} C_{img}^{(t)} + \lambda_{prior} C_{prior}^{(t)} + \lambda_{ent} C_{ent}^{(t)} + \lambda_{vq} C_{vq}^{(t)} \right)
  \]
  - \(C_{geo}\)：几何目标（L2 偏差，唯一的 O(1) 解码项）；
  - \(C_{img}\)：视觉目标（MSE 对目标潜在嵌入）；
  - \(C_{prior}\)：无偏专家先验的负对数似然——示教数据仅含无碰撞轨迹，故碰撞轨迹天然偏离先验分布；
  - \(C_{ent}\)：视觉 token 预测分布的 Shannon 熵——在遮挡/模糊区域升高，惩罚不确定性高的未来；
  - \(C_{vq}\)：量化误差（余弦距离）——候选嵌入若与码本无近邻匹配，即为分布外（OOD）状态，产生“流形拒绝”尖峰。

**（5）路径跟随模式**
- **分类器自由引导（CFG）**：对无条件先验 \(z_\emptyset\) 与有条件的刚性几何意图 \(z_g\) 做线性外推 \(\tilde{z}_g = z_\emptyset + \omega(z_g - z_\emptyset)\)；
- **子目标采样**：仅从专家先验和码本词汇表生成候选，依据几何跟踪成本 \(J_{track}\) 选择最优轨迹，避免流形偏离风险。

**（6）执行策略**
- 使用 Action Chunking with Temporal Ensembling 融合重叠时域预测，保证闭环执行平滑性；
- 迭代细化搜索框架呈 CEM 风格：早期广泛探索、后期局部细化。

## 6. 主要结论与发现

- **生成基础**：Hydra 在 16 秒长时域视频生成上 FVD 为 19.16，优于 NWM/B（22.11）与 VertiFormer（81.03），验证了早期融合+离散瓶颈能维持甚至增强时序一致性。
- **实时规划**：离散潜在规划（DLP）将规划时间从 NWM 的 >500 秒压缩至约 0.9 秒（>500×加速），成功率达：无遮挡 10/10、遮挡与盲角 8/10，而连续基线 VertiFormer 在障碍场景中成功率 0%。
- **潜在碰撞检测**：量化误差（\(C_{vq}\)）与预测熵（\(C_{ent}\)）在逼近障碍时同步上升、在模型“幻觉”出可通行路径后同步下降——两个独立信号在碰撞关键时刻收敛，可提前拒绝危险轨迹，且无需任何像素解码。但存在将复杂但可穿越的枝叶误判为障碍的假阳性。
- **局部路径跟随**：Hydra 在稀疏路点引导下，成功率和干预次数匹配或优于使用稠密目标图像的 GNM/ViNT/NoMaD；其中 Sampling 模式在长距离场景中最可靠（100% 成功率），CFG 受流形偏离影响在长距离场景性能下降（138±7.7s）。
- **消融发现**：
  - 移除 \(C_{prior}\)、\(C_{vq}\)、\(C_{ent}\) 中任意一项均在两个平台上增加碰撞率（碰撞次数从 0.20 上升到最高 0.80），表明三项安全信号各自独立、不可互相替代；
  - \(C_{img}\) 在目标可见时有效（80% 成功率），目标不可见时反而有害（20% 成功率），应基于目标可见性有条件启用。

## 7. 优点

- **问题定位准确**：清晰刻画了世界模型规划中的“表示错位”核心矛盾，并给出了系统性解决方案。
- **方法论创新性强**：
  - 将规划器从“外部查询”转为“内嵌于模型”，概念上具有突破性；
  - 非对称 VQ 码本、T KPC 成本分析、两层随机性搜索（高斯扰动 + Top-K Gumbel）设计较为精巧；
  - KPC 将障碍物检测转化为潜空间的量化误差与信息熵信号，避免像素解码，理论优雅且计算高效。
- **物理部署验证扎实**：在两个不同运动学特性的物理机器人上验证，超越了大多仅在仿真中评估的世界模型类工作。
- **消融全面**：对成本函数各个项、架构组件（线性投影/确定性锚定）、目标可见性条件均有系统验证。
- **负面结果坦诚**：明确报告假阳性（枝叶误判）、行人消失、长距离目标盲种子失败等限制，并对失败机制给出了合理的因果分析。
- **计算效率与可扩展性**：143M 参数规模显著小于近期 14B 参数级 WAM（如 DreamZero）但具备实际搜索能力，定位务实。

## 8. 不足与局限

- **流形拒绝信号的歧义性**：\(C_{vq}\) 无法区分“结构新颖的危险障碍”与“视觉复杂但安全的环境”的量化困难，对均质平面墙等较易重建的危险障碍可能漏报。
- **语义缺失与动态智能体擦除**：视觉码本（|V_i|=2048）等效于随机低通滤波器，行人等小面积高频细节在量化中被抹除，使 Hydra 更适用于静态环境导航，社交导航安全性受限。
- **离散化表达容量与搜索延迟存在根本矛盾**：码本规模增大能提升泛化但线性增加检索成本，固定码本大小无法同时满足表达性与实时性；论文提出自适应或层次化码本作为未来方向。
- **规划延迟带来的决策响应问题**：在长距离不可逆的分支决策点（如走廊分叉），逐重建的规划模式（40% 成功率）因延迟而劣于快速反应式的 CFG/Sampling（100%），说明当前 DLP 在极端时序敏感场景中存在效率-安全性权衡。
- **目标盲种子初始化的局限**：种子分布不包含目标信息，目标信息仅通过迭代间 KPC 的欧氏距离间接传播，在 N=3 迭代的实时预算下可能错过近起点转弯。
- **对比公平性存疑处**：NWM 物理部署实验虽说明了计算瓶颈的现实性，但 500 秒 vs 0.9 秒的比较也包含实现层面的差距；离线 ADE/FDE 中 Hydra（0.24/0.42）不及 VertiFormer（0.21/0.39），说明生成式能力在纯跟踪精度上未超越确定性回归。
- **训练资源信息缺失**：未报告训练 GPU 型号、数量与时长，影响可复现性评估。
