## 摘要
比较当前与过去的观测有助于机器人在操作过程中理解场景变化并选择后续动作。然而，当物体或相机移动时，比较同一图像位置处的视觉特征会混入不同的场景内容。我们提出 CoRe-WAM，一种通过参数高效的时序接口引入对应关系对齐视觉变化的世界-动作模型。其 TraceDelta 模块利用来自冻结跟踪模型的对应关系，将历史视觉特征搬运到当前位置，然后在共享的预训练特征空间中计算有符号差异。因此，对应关系决定了哪些历史内容与当前内容进行比较，而不是作为单独的轨迹表示进入策略。轻量级适配器将这些差异转换为有效性门控残差，以补充当前视觉条件，使策略能够在利用当前场景信息的同时利用近期变化。CoRe-WAM 构建于 Motus 之上，保持预训练主干网络权重冻结，并优化 159 万个参数。在 5,000 次更新的自适应预算下，CoRe-WAM 在 50 个 RoboTwin 2.0 任务上达到 92.22% 的干净成功率，比 Motus 高 3.56 个百分点；在随机化评估中，达到 89.60% 的成功率，提升 2.58 个百分点。将 TraceDelta 集成到基于 StarVLA 的策略中，可将干净成功率从 58.10% 提升至 67.62%，支持该时序接口迁移到 Motus 之外。

## Abstract
Comparing current and past observations helps robots understand scene changes and select subsequent actions during manipulation. However, comparing visual features at the same image location can mix different scene content when objects or the camera move. We introduce CoRe-WAM, a world-action model that incorporates correspondence-aligned visual changes through a parameter-efficient temporal interface. Its TraceDelta module uses correspondences from a frozen tracking model to transport historical visual features to current locations before computing signed differences in a shared pretrained feature space. Correspondence thus determines which historical content is compared with the present, rather than entering the policy as a separate trajectory representation. A lightweight adapter converts these differences into validity-gated residuals that supplement current visual conditioning, allowing the policy to use recent changes alongside current-scene information. Built on Motus, CoRe-WAM keeps the pretrained backbone weights frozen and optimizes 1.59 million parameters. With a 5,000-update adaptation budget, CoRe-WAM achieves 92.22% clean success across 50 RoboTwin 2.0 tasks, 3.56 percentage points above Motus; on randomized evaluation, it achieves 89.60% success, a 2.58-point gain. Integrating TraceDelta into a StarVLA-based policy improves clean success from 58.10% to 67.62%, supporting transfer of the temporal interface beyond Motus.

## 1. 核心问题与整体含义

- **研究动机**：机器人操作中，当前观测描述现在，历史观测揭示场景如何随交互演化；利用这种变化有助于工具使用、交接、铰接物体操作和多阶段放置等任务。
- **核心问题**：直接比较当前与历史观测中“同一图像位置”的预训练视觉特征，在物体或相机运动时会混入不同场景内容。也就是说，同一坐标处的特征差异可能同时包含“内容自身变化”和“不同内容占据该位置”的混淆。
- **整体含义**：论文主张，历史信息本身不等于有意义的时序比较；应先建立当前区域与历史区域之间的**对应关系**，再在匹配内容上计算特征变化。CoRe-WAM 将这一原则引入世界-动作模型的动作生成条件中，而非把轨迹本身作为额外 token 或单独融合模块。

## 2. 方法论：核心思想与关键技术细节

- **核心思想**：先对齐历史，再比较特征，最后把对齐后的变化作为有效性门控残差注入当前视觉条件。
- **TraceDelta 三步流程**：
  - **对齐历史 / 特征搬运**：使用冻结的 Trace Anything 跟踪模型，为当前头相机 token 中心 \(p_i\) 找到历史对应点 \(q_i = C_{t\to h}(p_i)\)，并用双线性采样 \(W(F_h, q_i)\) 将历史特征搬运到当前空间位置。
  - **比较特征 / 有符号差分**：计算当前特征与对齐历史特征之差：
    \[
    \Delta_i^{trace}=F_t(p_i)-\bar f_{h,i}=F_t(p_i)-W(F_h,C_{t\to h}(p_i))
    \]
    保留符号以表示预训练特征空间中的变化方向。
  - **注入变化 / 门控残差**：轻量适配器 \(g_\psi\) 将差异映射到 Motus 理解维度，结构为 \(2048\to256\to512\)，含 LayerNorm、GELU 和线性层；再经学习标量 \(\alpha\) 与有效性掩码 \(m_i\) 门控：
    \[
    r_i=\alpha m_i g_\psi(\Delta_i^{trace})
    \]
    最后散布到原生头相机 token 位置 \(\Omega\)，并加到投影后的当前观测 token 上：
    \[
    U'_t=P(Z_t)+\mathrm{Scatter}_\Omega(\{r_i\}_{i\in\Omega})
    \]
- **实现细节**：
  - 基于 Motus 世界-动作模型，保留理解、视频生成、动作专家及联合注意力结构。
  - 当前观测路径 \(P(Z_t)\) 保持完整，时序残差仅补充头相机 token；在评估配置中 \(\Omega\) 为 6×10 共 60 个 token，位于 packed visual-token 序列索引 10–69。
  - 预训练主干与对应关系估计器均冻结；仅优化时序适配器、动作侧 LoRA 和现有动作解码器。
  - 无历史观测时，时序分支旁路，策略仅使用当前视觉条件。
- **与 Raw Delta 的区别**：Raw Delta 直接计算 \(F_t(p_i)-F_h(p_i)\)，即固定网格位置差分；TraceDelta 先用对应关系搬运历史特征，因此比较的是“匹配内容”，而非“同一坐标”。
