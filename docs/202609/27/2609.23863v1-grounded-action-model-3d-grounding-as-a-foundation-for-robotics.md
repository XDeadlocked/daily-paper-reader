## 摘要
操作策略必须知道哪些物体重要以及它们在哪里，然而当前机器人基础模型所依赖的预训练主干网络——从视觉-语言-动作模型（VLA）中的语言到世界-动作模型（WAM）中的视频生成——并不直接要求这种度量 Grounding，从而将其留给从机器人演示中隐式学习。我们提出 Grounded Action Models（GAM），一种以 3D Grounding 构建的机器人基础模型新范式。GAM 可以以语言、点或框提示为条件，这些提示首先被转换为所选对象的共享的以对象为中心的表示。该表示捕捉以目标为中心的视觉特征和度量对象几何，并通过多流 Transformer 与机器人状态历史混合，以预测动作块。尽管 GAM 可以自主运行，它们也可以作为低级控制器，由高级规划器使用其各种输入模态进行控制，从而实现长时程和依赖记忆的操作。在 RoboTwin 2.0 上，GAM 在 50 个任务上取得 55.3% 的平均成功率（Spatial Forcing 为 52.0%），其中在场景随机化下为 47.6%（Abot-M0 为 30.4%），而其动作策略仅在干净场景演示上训练。在 LIBERO-PRO 上，它在 16 种扰动设置中取得 61% 的最先进平均成功率（$π_{0.5}$ 为 53%），当目标被重新放置或新指定时增益最大。在两台真实机器人上，GAM 在双臂 YAM 上于视觉偏移下保持 17/20 的成功率，而 $π_{0.5}$ 为 4/20；同时，其在 Franka 上与 Molmo2 规划器组合后，在长时程和依赖记忆的任务上达到 64.7% 的 ID 和 49.8% 的 OOD 步骤完成率。

## Abstract
Manipulation policies must know which objects matter and where they are, yet the pretrained backbones that current robot foundation models build on, from language in vision-language-action models (VLAs) to video generation in world-action models (WAMs), do not directly require this metric grounding, leaving it to be learned implicitly from robot demonstrations. We propose Grounded Action Models (GAMs), a new paradigm of robot foundation models built with 3D grounding. GAM can be conditioned using language, points, or box prompts, which are first transformed into a shared object-centric representation of the selected objects. This representation captures target-focused visual features and metric object geometry, which is mixed with robot state history through a multi-stream transformer to predict action chunks. Although GAMs can be run autonomously, they can also serve as a low-level controller that a high-level planner controls using its various input modalities, allowing for long-horizon and memory-dependent manipulation. On RoboTwin 2.0, GAM achieves an average success rate of 55.3% across 50 tasks (vs. 52.0% for Spatial Forcing), including 47.6% under scene randomization (vs. 30.4% for Abot-M0), with its action policy trained only on clean-scene demonstrations. On LIBERO-PRO, it achieves a state-of-the-art average success rate of 61% (vs. 53% for $π_{0.5}$) across 16 perturbation settings, with the largest gains when targets are relocated or newly designated. On two real robots, GAM retains 17/20 successes under visual shift on a bimanual YAM versus 4/20 for $π_{0.5}$, while its composition with a Molmo2 planner on a Franka achieves 64.7% ID and 49.8% OOD step completion on long-horizon and memory-dependent tasks.

# 《Grounded Action Model: 3D Grounding as a Foundation for Robotics》论文总结

## 1. 核心问题与研究动机

- **核心问题**：机器人基础模型的性能上限很大程度上取决于"预训练骨干（backbone）在学动作之前知道什么"。当前两条主流路线——VLA（基于视觉-语言预训练）与 WAM（基于视频生成预训练）——其预训练目标都**不显式要求度量层面的 3D grounding**。
- **具体缺陷**：
  - 语言生成目标只需识别物体并描述关系，不需要精确的 3D 位置与范围；
  - 视频生成目标偏向外观、纹理、背景变化，未必与操作任务相关；
  - 因此"哪些物体重要、它们在哪里"只能由机器人示教**隐式学习**。当示教覆盖的环境与布局有限时，策略会依赖视觉相关性，在物体移动、背景改变或更换目标时失效。
- **整体含义**：作者提出以 **3D grounding 作为机器人动作学习的基础**，构建新范式 **Grounded Action Model（GAM）**，其核心假设是：一个被预训练来把"视觉观测 + 任务提示"连接到"度量 3D 空间中物体"的骨干，能为操作策略提供更直接的起点。

## 2. 方法论

### 2.1 核心思想
- 使用**可提示（promptable）的 3D grounding 模型（WildDet3D）作为冻结骨干**，不依赖语言生成或视频生成骨干。
- 提示模态统一为**语言 / 2D 点 / 2D 框**，全部映射到共享的**物体中心表示**：图像 token（外观）+ 检测 token（度量几何）+ 状态历史 token。
- 仅训练**动作头**，骨干保持冻结，从而将"grounding 能力获取"与"如何在已 grounding 物体上动作"解耦。

### 2.2 关键技术细节
- **从提示到检测**：
  - 语言输入经冻结 Flan-T5 编码器上的 span-tagging head 抽取任务相关物体短语（如"pick up the sponge and place it in the bowl"→ sponge、bowl），作为独立 grounding 查询；点/框直接指定物体。
  - WildDet3D 对每个物体输出 2D 框 `u_i`、度量 3D 框 `b_i`、稠密度量深度图 `D̂_t` 以及视觉骨干特征 `F_t`。
- **图像 token**：将 `F_t` 平均池化为 G×G 网格（G=16），仅保留与任务物体 2D 框重叠（覆盖该格面积 ≥30%）或与机械臂轮廓重叠（>10%）的格子，其余置零；机械臂轮廓由 URDF 网格经前向运动学与相机标定投影得到；经共享线性适配器得到 G² 个图像 token。
- **检测 token**：
  - 用相机内参将深度图反投影并变换到机器人基座坐标系得到场景点云，裁剪略微膨胀的 `b_i` 内点，采样 P=512 点；
  - 点云编码器 φ：逐点 MLP + 全局最大池化、全局平均池化、以及围绕质心 8 个八分区的最大池化，得到 512 维形状特征；
  - 物体描述子 `z_i = [ũ_i, c_i, γ(c_i), φ(P_i), e_i, r_i]`，其中 `ũ_i` 为归一化 2D 框，`γ(c_i)` 为 8 个频率的傅里叶中心特征，`r_i` 为 6D 旋转表示；
  - 线性适配器映射为每个物体 M=8 个检测 token，共 N×M 个；未检测到的槽位使用可学习 null token 保持 token 预算。
- **状态历史 token 与融合**：拼接当前与前一帧关节位置投影为单 token；三类 token 加模态嵌入后经共享自注意力层融合，得到条件序列 `C ∈ R^{L×d}`，`L = G² + MN + 1`。
- **动作头（MM-DiT）**：12 层多流 Transformer，四条流为图像 / 检测 / 状态历史 / 加噪动作块；每层对各流使用独立的 QKV、输出投影、FFN 与自适应层归一化参数，时间步与语言条件经 adaLN 注入，通过联合注意力实现跨流交互；最后经 RMSNorm + 小 MLP 输出预测速度。
- **语言条件**：`h_{τ,s} = TimeEmbed(τ) + W_ℓ e_s + b_ℓ`（`W_ℓ ∈ R^{576×768}`，`b_ℓ ∈ R^{576}`），二者零初始化以保持初始等价；不引入额外 token。
- **训练**：仅优化动作头（图像适配器、检测适配器含点云编码器、条件融合层、语言投影、MM-DiT），骨干冻结；采用 flow matching 目标 `L = E‖v_θ(A_τ | τ, C, e_s) − (A_t − ε)‖²`；推理时从高斯噪声出发用 K 步 Euler 积分。
- **部署**：用 CoTracker3 在初始检测框内跟踪点并作为提示回馈给 grounding 模型以维持跨帧物体关联；每次策略查询重建 grounded 观测并预测动作块，执行若干步后重新查询。长时程/依赖记忆任务中，VLM 规划器（Molmo2）在子任务切换时用当前图像与情节记忆选择新目标，通过点提示重新初始化跟踪器，动作策略在各子任务间保持不变。

## 6. 主要结论与贡献

- **核心结论**：以可提示 3D grounding 模型作为冻结骨干、仅训练动作头，能够在多种操作任务中取得有竞争力的性能，尤其在场景随机化、物体位置/外观变化、指令改写和新目标等 OOD 条件下优势明显。
- **RoboTwin 2.0**：GAM 在 Easy/Hard 平均成功率上达到 62.96%，高于多数 VLA 与 WAM 基线；其中 Hard 场景表现突出，说明 3D grounding 提供的度量几何先验有助于应对布局与外观扰动。但在 Easy 干净场景上低于 Spatial Forcing（77.20%）与 FastWAM（77.80%），表明视频生成类先验在理想条件下仍有独特优势。
- **LIBERO-PRO**：单一 GAM 策略在四个扰动轴共 16 种设置下总体优于所列基线，说明其泛化能力并非仅来自单任务过拟合，而可能来自物体中心 3D 表示的复用性。
- **真实机器人**：在双臂 YAM 与单臂 Franka 上，GAM 在 ID 与 OOD 试验中均取得较好步骤完成率，长时程与记忆依赖任务中结合规划器与跟踪器可维持跨子任务一致性。
- **方法贡献**：
  - 提出以 3D grounding 为机器人动作学习基础的 GAM 范式；
  - 设计语言/点/框统一提示到物体中心 token 的接口，将度量 3D 信息显式注入策略条件；
  - 采用冻结骨干 + 轻量动作头的解耦训练，降低对大规模机器人示教的依赖；
  - 通过 MM-DiT 多流架构实现图像、检测、状态历史与动作块之间的跨流交互。
- **消融结论**：物体中心过滤（图像掩码与点云裁剪）和检测/图像双流互补性对性能均有贡献；仅检测或仅图像均不及完整模型，支持"外观 + 度量几何"联合表示的必要性。

## 7. 局限与未来方向

- **性能上限**：在干净、固定布局场景中，GAM 未超过最强 WAM 基线，说明 3D grounding 先验并不能完全替代大规模视频生成预训练所提供的外观与动力学先验。
- **对 grounding 骨干的依赖**：冻结 WildDet3D 意味着策略性能受限于其检测、深度与提示理解能力；若骨干在真实域出现漏检、误检或深度偏差，动作头难以纠正。
- **域适配成本**：RoboTwin 中需先在渲染域微调 grounding 骨干，真实场景是否也需要类似适配、代价多大，文中未系统讨论。
- **系统复杂度**：真实长时程任务依赖外部 VLM 规划器、CoTracker3 跟踪与情节记忆，端到端自主性与部署复杂度之间的权衡未充分展开。
- **评估缺口**：缺少 grounding 精度、推理延迟、失败模式与统计显著性的系统分析；真实试验次数偏少。
- **未来方向**：可探索 grounding 骨干与动作头的联合微调、将 3D grounding 与视频生成先验结合、引入更丰富的触觉/力觉 grounding、以及面向实时控制的轻量化设计。

## 8. 总体评价

- **创新性**：将"3D grounding"从感知模块提升为机器人基础模型的预训练基础，视角清晰且与 VLA/WAM 形成有意义的第三条路线。
- **方法严谨性**：物体中心 token 化、冻结骨干与 MM-DiT 动作头的设计逻辑自洽，消融实验对关键组件有针对性验证。
- **实验覆盖**：仿真与真实、ID 与 OOD、多提示接口、长时程与记忆任务均有涉及，覆盖面较广；但公平性、统计显著性与系统归因方面存在可改进之处。
- **可复现性**：未报告算力、训练步数、超参与随机种子，复现难度较高；若补充这些信息，论文说服力会进一步增强。
- **总体判断**：GAM 为"以 3D grounding 作为机器人动作学习基础"提供了有前景的实证支持，尤其在 OOD 与随机化场景中表现突出；但其相对 WAM/VLA 的优势是条件性的，未来需在干净场景性能、grounding 质量评估与系统简化上继续推进。
