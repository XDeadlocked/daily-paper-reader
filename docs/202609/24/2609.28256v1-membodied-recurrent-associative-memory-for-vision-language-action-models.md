## 摘要
视觉-语言-动作模型为通用机器人控制提供了坚实基础，然而绝大多数策略并不会保留和利用当前观测之外的回合级信息。这一局限在依赖仅存在于过去观测中的信息的历史相关操作任务中后果显著。在上下文中保留过去观测有助于恢复这些信息，但代价显著：上下文不断增长且臃肿，推理延迟也增加。因此，我们提出 MemBodied，一种固定大小的情景记忆，包含两个互补组件：记录跨策略调用交互的联想状态，以及保存初始场景紧凑表示作为参考的情景锚点。在每次策略调用时，模型以当前输入和记忆组件为条件进行动作生成，而不是直接使用过去观测。在五个需要记忆的 RMBench 评估任务上，MemBodied 的平均成功率是无状态策略的 7.81 倍，是普通循环记忆的 2.98 倍，并在附加参数少 10 倍的情况下，性能达到最强记忆增强基线的 1.3 倍。在完全可观测的 LIBERO-Long 套件上，它达到 90.6%，相比无状态的 π_0 策略提升了 5.4%。这些发现支持 MemBodied 作为面向历史相关操作任务、扩展策略上下文的一种实用替代方案。

## Abstract
Vision-Language-Action models provide a strong foundation for general-purpose robot control, yet a vast majority of policies do not preserve and leverage episode-level information beyond the current observation. This limitation is consequential in history-dependent manipulation tasks that depend on information available only in past observations. Retaining past observations in context can aid in recovering this information, but at the significant cost of ever-growing, bloated context and inference latency. We thus introduce MemBodied, a fixed-size episodic memory with two complementary components: an associative state that records interactions across policy calls and an episode anchor that preserves a compact representation of the initial scene as a reference. At each policy call, the model conditions action generation on the current input and the memory components, rather than directly using past observations. Across five evaluated RMBench tasks requiring memory, MemBodied achieves $7.81\times$ the mean success rate of a stateless policy and $2.98\times$ of vanilla recurrent memory, while outperforming the strongest memory-augmented baseline by $1.3\times$ with $10\times$ fewer added parameters. On the fully observable LIBERO-Long suite, it reached 90.6%, a 5.4% improvement over the stateless $π_0$ policy. These findings support MemBodied as a practical alternative to expanding the policy context for history-dependent manipulation.

# MemBodied 论文结构化总结

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：当前绝大多数视觉-语言-动作（VLA）策略在每次策略调用时仅以**当前观测**和语言指令为条件预测动作块，丢弃了回合级（episode-level）历史信息，导致在**历史依赖操作任务**中表现受限。
- **关键矛盾**：
  - 历史依赖任务（如"把物体放回原位"）所需信息可能只存在于过去观测中，当前观测已无法揭示正确目标，形成**时间状态混叠（temporal state aliasing）**——相似当前观测可能要求不同动作。
  - 直接保留历史观测虽能恢复信息，但会导致上下文长度、显存和推理成本随回合增长；固定观测窗口虽能限制成本，却可能丢弃任务关键证据。
- **设计需求**：一种**在线更新、尺寸固定、按当前策略状态检索**的记忆机制。
- **整体含义**：MemBodied 提出一种固定大小的情景记忆，无需扩展策略上下文即可支持历史依赖操作，为 VLA 控制提供实用且高效的替代方案。

## 2. 方法论

### 核心思想
采用两条互补记忆通路：**循环联想状态**（记录跨策略调用的交互）与**情景锚点**（保存初始场景的紧凑表示）。动作生成以当前输入 + 记忆读数为条件，而非直接使用历史观测。

### 关键技术细节

- **递归 VLA 形式化**：回合记忆 $E_t = (M_t, A)$，策略为 $a_t \sim p_\theta(\cdot | I_t, s_t, \ell, E_{t-1})$；$M_{t-1}$ 跨调用持续，回合开始时重置为学习到的初始状态；锚点 $A$ 由首帧构建且回合内不变。

- **联想记忆状态**：每层一个联想矩阵 $S^{(l)}_t \in \mathbb{R}^{B\times r\times r}$，实验用 $r=128$，状态大小固定不随回合增长。

- **写值构建**：由执行后的机器人状态 $s_{t+1}$ 生成查询，对下一帧视觉 patch token 做注意力，各摄像头编码池化后取平均，再与其因果动作块求和拼接，得到 $y_t$，经层特定投影 $v^{(l)}_t = W^{(l)}_v y_t$ 作为写入值。**视觉 patch token 处停止梯度**。

- **门控 delta 规则写入**：
  $$S^{(l)}_t = \mathrm{Diag}(\alpha^{(l)}_t)S^{(l)}_{t-1} + \mathrm{Diag}(\beta^{(l)}_t)\big(v^{(l)}_t - \mathrm{Diag}(\alpha^{(l)}_t)S^{(l)}_{t-1}k^{(l)}_t\big)(k^{(l)}_t)^\top$$
  第一项保留旧状态，第二项通过比较新值与已关联值进行 delta 修正；$\alpha$ 控制保留、$\beta$ 控制写入强度。

- **联想检索与记忆变体**：查询 $q^{(l)}_t$ 由进入层的状态 token 表示构造，$r^{(l)}_t = S^{(l)}_{t-1}q^{(l)}_t$。比较三种读出方式：
  - **Attention steering（AS）**：对注意力 query 和输出做加性修正。
  - **Hierarchical memory（H）**：增加 LSTM 式慢速循环单元。
  - **Memory-token readout（最终方案）**：将读出投影后加到专门上下文 token，再参与自注意力，使检索内容作为上下文内容而非仅修改现有注意力。

- **固定情景锚点**：将冻结视觉 token 的 $16\times16$ patch 网格平均池化为 $4\times4$，跨摄像头拼接得 $A$；当前机器人状态对当前视觉 token 池化后经 rank-$r_A=64$ 的交叉注意力查询锚点，再投影并沿动作视界重复，融入动作表示。不改变前缀长度与注意力掩码结构。

- **因果读写协调**：采用**延迟写入**——先用 $M_{t-1}$ 读并生成 $a_t$，执行后得到 $I_{t+1}$，再将 $t$ 时刻隐状态与动作块同 $I_{t+1}$ 关联写入 $M_t$，保证不把未来观测泄露给导致它的动作。

- **序列训练**：因延迟写入需序列级训练，每个样本含 $N$ 个观测-动作对，相邻对间隔一个动作视界 $H$；图像编码与输入构造并行，记忆状态顺序传播，梯度贯穿全序列；记忆参数仅通过策略原生动作目标学习，无独立记忆预测损失。

## 3. 实验设计

### 数据集 / 场景与 Benchmark

  - $M^{(1)}$：Put Back Block、Rearrange Blocks、Swap Blocks
  - $M^{(n)}$：Battery Try、Block Ranking Try
  - 每任务 50 次 rollout。
- **LIBERO**（完全可观测的通用操作）：Spatial、Object、Goal、Long 四套件，每套件 10 任务 × 50 rollout = 500 次，每检查点共 2000 次。

## 6. 主要结论与发现

- **记忆依赖操作（RQ1）**：RMBench 五任务平均成功率 **50.0%**，超 π0-Stateless 43.6 个百分点、π0-FrameStack 35.2 点、π0-Vanilla Recurrent Memory 33.2 点；相对无状态策略为 7.81×，相对普通循环记忆为 2.98×。
- **对比压缩历史**：超 NativeMEM 11.6 个百分点，且参数少约 10 倍（40M vs 415M）；NativeMEM + MemBodied 组合反而不如单独 MemBodied（45.2% vs 50.0%），提示历史 token 可能分散注意力。
- **主干迁移**：π0.5 上达 48.0% vs 基线 12.4%，五个任务全面提升。
- **真实机器人**：平均成功率从 3.33% 提升到 26.67%，每个任务均有改善。
- **效率（RQ2）**：推理延迟降低 **91.9%**（129.2 ms vs 1593.7 ms），峰值显存降低 9.5%（18.61 vs 20.57 GiB）。
- **完全可观测操作（RQ3）**：LIBERO 四套件平均 95.1%（π0 为 94.2%），LIBERO-Long 达 **90.6%**，超 π0 的 85.2% 达 5.4 个百分点；Spatial/Object 略有下降（0.6/1.0 点），Goal 持平。
- **机制发现**：
  - Memory-token 注入优于 attention steering 与 hierarchical 变体（37.6% vs 23.2% / 20.8%）。
  - 锚点总体提升（37.6%→50.0%），但效果任务相关（Swap Blocks 增益最大，Block Ranking 反而下降）。
  - 写值中视觉与动作互补，结合最强。
  - 记忆秩越大性能越好（32/64/128 对应两任务均值 27.0%/42.0%/55.0%）。
  - 跨回合携带记忆会降低性能（50.0%→36.8%），支持回合内重置。
  - 定性分析显示收益集中于需要历史信息的决策点，而非早期运动阶段。

## 7. 优点

- **问题定位精准**：清晰刻画了时间状态混叠问题，并明确区分"保留历史"与"按需检索"两种范式。
- **方法设计巧妙**：
  - 固定大小联想状态 + 固定情景锚点双通路，兼顾交互历史与初始场景，且存储/访问成本与回合长度无关。
  - 采用门控 delta 规则实现可修正的关联写入，而非无差别累积。
  - **延迟写入**调度保证训练与推理共享同一因果语义，避免未来信息泄露。
  - 锚点通过交叉注意力选择性检索，不改变前缀长度与注意力掩码。
- **工程实用性**：新增参数仅 40M（π0 的 1.26%），延迟与显存均低于对比方法。
- **实验严谨性**：多主干、仿真+真机、消融维度丰富；本地基线共享训练配方；定性分析使用同种子配对 rollout 并做统计显著性校正。
- **可复现性**：提供代码与项目网站。

## 8. 不足与局限

- **训练算力信息缺失**：未报告训练使用的 GPU 数量、型号与时长，难以评估完整算力成本。
- **训练预算对部分基线不利**：π0-μVLA 在共享预算下得 0%，作者自述可能需更长训练；NativeMEM 使用独立分阶段流程，比较的公平性存在一定不确定性。
- **锚点效果任务相关**：在 Block Ranking 上反而降低性能（32%→22%），说明固定首帧参考并非对所有任务有益。
- **长程记忆仍有不足**：定性分析显示多更新累积场景下仍存在长期记忆错误（如 Block Ranking 中重建并测试新顺序仅 10/28）；残余失败多来自执行层（抓取不稳、按键不准、放置卡顿），非记忆本身。
- **应用限制**：真实机器人实验规模较小（每任务 20 次 rollout、三任务、单一平台），统计置信区间较宽（如 2/20 vs 7/20），泛化性证据有限。
- **组合方案未优**：NativeMEM + MemBodied 未超过单独 MemBodied，如何有效结合显式视频历史与联想记忆仍是开放问题。
- **记忆内容可解释性有限**：联想矩阵为隐式表示，缺少对存储内容语义的直接分析。
