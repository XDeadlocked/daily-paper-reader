## 摘要
随着AI智能体能力日益增强，由智能体驱动的机器人控制正成为一种颇具吸引力的范式。然而，主流的视觉-语言-动作（VLA）模型和世界动作模型（WAM）仍依赖自然语言指令来指定操作任务，这种接口并不适合智能体驱动的控制：存在指代歧义、空间不精确、与智能体固有的语言理解冗余，并且将意图与执行纠缠在一起。我们提出AR-WAM，一种视觉条件化、智能体就绪的世界动作模型，它用两个互补条件替代语言：一个视觉定位提示（目标边界框），用于表示交互对象和位置；以及一个可学习操作token，用于指定要执行的原子技能。我们的紧凑型0.5B参数模型采用冻结的预训练视觉编码器且不含语言编码器，在紧凑潜在状态中预测场景演化并同时解码动作，通过显式、可监督的推理信号暴露策略意图。一个模型无关的兼容层提供三个原语（检测、执行和查询），使本地VLM或在线智能体API能够直接驱动该策略，而长时程记忆和闭环错误恢复则交由智能体侧处理。在RoboTwin 2.0、RMBench以及真实的Astribot S1双臂平台上，AR-WAM在标准操作任务上与最强基线相当（平均成功率87.2%），并在依赖记忆的任务和真实机器人长时程任务上优于它们，成功率分别提升5.9%和36.7%，同时保持最低推理延迟（14.1 ms）。

## Abstract
As AI agents become increasingly capable, agent-driven robotic control is emerging as a compelling paradigm. However, prevailing vision-language-action (VLA) models and world action models (WAMs) still rely on natural-language instructions to specify manipulation tasks, an ill-suited interface for agent-driven control: referentially ambiguous, spatially imprecise, redundant with the agent's inherent language understanding, and entangling intent with execution. We present AR-WAM, a visual-conditioned, agent-ready world action model that replaces language with two complementary conditions: a visual grounding prompt (a bounding box of the target) denoting the interaction object and location, and a learnable operation token dictating the atomic skill to execute. Our compact 0.5B-parameter model, with a frozen pretrained visual encoder and no language encoder, predicts scene evolution within compact latent states while decoding actions, exposing the policy's intent through explicit, supervisable reasoning signals. A model-agnostic compatibility layer provides three primitives (detect, execute, and query) so that local VLMs or online agent APIs can drive the policy directly, with long-horizon memory and closed-loop error recovery delegated to the agent side. On RoboTwin 2.0, RMBench, and a real Astribot S1 dual-arm platform, AR-WAM matches the strongest baselines on standard manipulation (87.2% average success) and outperforms them on memory-dependent and real-robot long-horizon tasks, improving success rates by 5.9% and 36.7%, respectively, while maintaining the lowest inference latency (14.1 ms).

## 一、核心问题与研究动机

- **背景**：随着 AI Agent 能力增强，"智能体做大脑、策略模型做小脑"的分层机器人控制成为有吸引力的范式——Agent 负责语言理解、任务分解与记忆，策略负责精确动作生成。
- **现有接口的痛点**：主流 VLA（如 RT-2、OpenVLA、π 系列、X-VLA）与世界动作模型 WAM（如 UniPi、GR-1/2、Fast-WAM、LiLa-WAM）几乎都以**自然语言指令**作为任务条件。作者认为在 Agent 驱动场景下这是不合适的接口，理由有四：
  - **指代歧义**：桌面上有多个相似物体时，文本难以唯一确定目标。
  - **冗余**：语言理解本是 Agent 的强项，在策略内部重新学习它浪费训练算力。
  - **空间不精确**：指令需经过策略自身的语言编码器，定位误差会妨碍精确操控。
  - **黑箱纠缠**：把理解、规划、记忆、动作生成塞进一个不可解释的模型，导致失败无法归因于"意图错误"还是"执行不当"。
- **核心命题**：Agent 时代策略真正需要的条件信号应是**空间化**而非语言化的——用视觉定位框表示"在哪里做"，用原子操作 token 表示"做什么"。
- **整体含义**：AR-WAM 主张建立"视觉、Agent 原生"的 Agent–策略契约，让 Agent 保留语言/规划/记忆/纠错，策略专注可靠执行。

## 二、方法论

### 2.1 核心思想
用两个互补条件取代自然语言指令：
- **视觉定位提示** `g = (x1,y1,x2,y2) ∈ [0,1]^4`（归一化图像坐标的边界框），指定交互对象与位置；双臂任务可扩展为两个框。
- **可学习原子操作 token** `e_s`，`s ∈ S = {pick, place, handover, click, pull, …}`，代表短时程技能。
- 可选辅助属性：`participants u`（左臂/右臂/双臂）与 `style w`（交互方式，如置于上方或旁边），各有可学习嵌入 `e_u, e_w`。
- 技能边界由**执行级事件**界定（如夹爪张开标志 place 完成），而非固定时长的动作块；这些事件同时是触发 Agent 调用的条件。

### 2.2 形式化与条件注入
- 策略在时刻 `t` 接收视觉观测 `o_t`（单主视角图像）与本体状态 `p_t`，输出长度 H 的动作块：
  `â_{t→t+H-1} ~ π_θ(· | o_t, p_t, φ(g), e_s, e_u, e_w)`，参数 θ 在所有原子操作间共享，保证单一可部署产物与共享视运动表征。
- Agent 决策经**条件调制（AdaLN）**注入：`e_s, e_u, e_w` 与轻量 MLP 产生的框嵌入 `φ(g)` 融合为 task condition token。
- 无需学习的辅助运动（如回零 homing）由系统级经典轨迹规划处理。

### 2.3 推理专家（Reasoning Expert）与可监督意图
- 一组可学习 reasoning query token `q_reas` 探测观测与任务条件，产生推理 token：
  `q_t = f_reas_θ(E(o_t), p_t, φ(g), e_s, e_u, e_w, q_reas)`，其中 `E(·)` 为**冻结的 DINOv3 视觉编码器**。
- 轻量 reason head 解码出三类显式、可监督的预测：
  1. 框内物体的**掩码** `m̂_t`（把粗框细化到像素级）；
  2. 技能终止时双臂**末端位姿** `T̂_t`；
  3. **任务摘要** `ĉ_t`（结构化 one-hot，描述用哪只臂、如何抓取/放置）。
- 损失：`L_reas = BCE(m̂_t, m_t) + CE(ĉ_t, c_t) + ‖T̂_t − T_t‖²`，同时充当失败诊断信号。

### 2.4 前瞻要点（Foresight Gist）提取
- 离线预训练提取器：冻结编码器把一段演示的起止帧 `o_{t0}, o_{t1}` 映射为潜帧，潜逆动力学模块压缩为前瞻要点：`f_{t0→t1} = G_IDM(E(o_t0), E(o_t1))`。
- 潜前向动力学模块从当前帧与要点重建未来潜帧：`ê_{t1} = G_FDM(E(o_t0), f_{t0→t1})`，以潜重建损失 `L_recon` 训练。
- 要点仅作为**训练期目标**，推理时不使用（不做测试时想象）。

- 用单一去噪器 `f_wam_θ` 以 **flow matching** 联合去噪三类模态（各模态独立采样噪声 `z0`，共享同一流时间 τ）：动作块 `a`、视觉前瞻 `f`、语义前瞻 `q`。
