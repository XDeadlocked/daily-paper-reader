## 摘要
世界动作模型（WAMs）联合生成机器人动作并预测未来世界状态，将视频预训练中的先验迁移至机器人控制。然而，未来视觉预测计算开销高昂，因此现有 WAM 往往依赖长动作块来摊薄跨控制步的推理成本，代价是闭环响应性下降。我们提出 \method，一种双系统 WAM，通过解耦全局规划与局部细化，在保留更广时域的世界-动作生成的同时，实现高频闭环动作更新。\systwo 周期性地在更广的世界-动作块上进行高噪声双向去噪，以建立全局规划；而仅使用腕部观测的 \sysone 从中间去噪状态中提取时间对齐的短窗口，并利用最新的腕部观测完成低噪声细化，这些观测在交互过程中提供与动作对齐的局部几何、运动和接触线索。两个系统沿共享的去噪轨迹异步运行：每个全局规划被复用于多次局部更新，而 \sysone 则反复融入新的交互反馈。在 Franka 和 Galbot 上的零样本操作任务中，\method 相比评估的最强基线平均将成功率提升 4.5 个百分点，同时实现 16.6$\times$ 的关键路径加速。进一步研究表明，角色匹配的第一人称视角与 UMI 数据可将成功率提升 14 个百分点，并且这种解耦设计自然支持边缘-云部署，其通信开销显著低于基线。

## Abstract
World Action Models (WAMs) jointly generate robot actions and predict future world states, transferring priors from video pretraining to robot control. However, future visual prediction is computationally expensive, so existing WAMs often rely on long action chunks to amortize inference cost across control steps, at the cost of closed-loop responsiveness. We present \method, a dual-system WAM that preserves broader-horizon world-action generation while enabling high-frequency closed-loop action updates by decoupling global planning and local refinement. \systwo periodically performs high-noise bidirectional denoising over a broader world-action chunk to establish a global plan, while wrist-only \sysone extracts a temporally aligned short window from the intermediate denoising state and completes low-noise refinement using the latest wrist observations, which provide action-aligned cues about local geometry, motion, and contact during interaction. The two systems operate asynchronously along a shared denoising trajectory: each global plan is reused across multiple local updates, while \sysone repeatedly incorporates fresh interaction feedback. Across zero-shot manipulation tasks on Franka and Galbot, \method improves success over the strongest evaluated baseline by 4.5 percentage points on average, while achieving a 16.6$\times$ critical-path speedup. Further studies show that role-matched egocentric and UMI data improve success by 14 percentage points, and that the decoupled design naturally supports edge--cloud deployment with substantially lower communication overhead than the baseline.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：世界动作模型（World Action Models, WAMs）将动作生成与未来世界状态预测耦合，从而把大规模视频预训练中学到的语义与物理先验迁移到机器人控制中，在零样本泛化上展现出潜力。
- **核心矛盾**：未来视觉预测计算开销极高。现有 WAM 普遍采用**长动作块（long action chunk）**来把一次推理成本摊薄到多个控制步上，但这直接牺牲了闭环响应性——两次模型更新之间执行的动作越多，新交互反馈能影响后续动作的机会就越少。
- **反向困境**：简单缩短动作块又会导致世界-动作生成频率过高，并诱发"近视"的下一块预测，使模型偏向局部外观捷径而非更长时间尺度的动力学。
- **已有方案的不足**：现有工作通过缩减/压缩/异步解码未来预测来缓解该矛盾，但**未能在同一个世界-动作生成过程内，对去噪阶段、视觉上下文与更新频率三者进行联合专门化**。
- **论文整体含义**：提出 DualWAM，把世界-动作生成本身拆分为**低频全局规划**与**高频局部细化**两个互补阶段，沿一条**共享去噪轨迹**异步协作，从而同时获得宽时域全局一致性与高频闭环修正能力。

## 2. 方法论

### 2.1 核心思想
- 将一条整流流（rectified flow）世界-动作去噪轨迹按噪声阈值 τ 切分为互补区间：
  - **System 2（全局规划）**：负责高噪声区间 `[τ, 1]`，低频、双向去噪、使用全局+腕部多视角观测。
  - **System 1（局部细化）**：负责低噪声区间 `[0, τ)`，高频、仅用腕部观测、因果时序注意力、短窗口。
- 两个系统在同一噪声坐标系下异步运行：**每个全局规划被复用于多次局部更新**，而 System 1 每次更新都融入最新交互反馈。

### 2.2 关键公式与流程
- 干净全局世界-动作目标：`X0 = [Zg0, Zw0, A0]`（全局视角视频隐变量、腕部视频隐变量、时间对齐动作序列）；
  加噪：`Xσ = (1−σ)X0 + σϵ`，`ϵ ~ N(0, I)`，`σ ∈ [0,1]`；目标速度 `V = ϵ − X0`。
- System 2 从 `σ = 1` 去噪到中间阈值 `τ`，得到部分去噪的 `Xτ`（粗但连贯的联合假设，**不作为最终可执行动作序列独立解码**）。
- 第 k 个执行窗口的交接：`U_kτ = C_sk(Xτ; H1) = [Z_w,k_τ, A^k_τ]`，其中 `s_k` 为相对全局轨迹的起始视频帧偏移（由执行进度决定），`C_sk` 选取覆盖 `H1` 帧的腕部隐变量与对应时间区间的动作（考虑时间压缩与动作采样率）。
- 训练损失（模态加权速度回归）：
  `L_i = E[ Σ_{m∈M_i} λ_m^{(i)} ||V_m^{(i)} − V̂_m^{(i)}(S_σ^{(i)}, σ, c_i)||² ]`，
  其中 `I2 = [τ_train, 1], M2 = {g, w, a}`；`I1 = (0, τ_train], M1 = {w, a}`。

### 2.3 角色专门化（三个对齐维度）
- **时间**：System 2 低频更新（刷新间隔 32 个控制帧），System 1 每个局部更新都响应。
- **生成**：System 2 在高噪声下组织更广的世界-动作状态；System 1 在短窗口内完成低噪声细化。
- **感知**：System 2 用多视角观测；System 1 **仅用腕部观测**——腕部相机刚性固定在末端执行器上，腕部视频中的运动是末端运动的"动作对齐"视觉痕迹，同时近距离视角能揭示全局视角难以分辨的几何、遮挡与接触线索。
- **时序注意力差异**：System 2 用双向注意力（全时域互相约束）；System 1 用因果时序注意力（每个位置只能看当前及之前位置），窗口内并行去噪。
- **训练增强**：保持第一个局部窗口对齐，对后续窗口的腕部-动作输入做随机时序偏移（监督仍与当前执行窗口对齐），偏移概率随执行进度增加，以模拟 System 2 预测轨迹与真实执行状态的不对齐，提升异步执行鲁棒性。
- **阈值设置**：`τ_train = 0.7`；System 1 在整个低噪声区间学习，推理时可在此区间内选取交接点 τ。

### 2.4 异步闭环执行与工程优化
- **执行调度**：System 2 在后台更新部分去噪的全局轨迹，System 1 立即用最新有效状态与新鲜腕部观测细化局部窗口；对执行窗口已过期的动作块跳过低噪声细化，保证动作与真实执行时间戳对齐。
- **系统级优化**：
  - 三 GPU CFG 并行（条件/无条件分支数据并行分置两块 GPU）；
  - 异步模型执行（避免高噪声生成阻塞动作生成与执行）。
- **实现级优化**：cuDNN 矩阵乘后端；注意力融合与 MLP epilogue 激活融合；输入与可复用中间态常驻 GPU、批量化/向量化减少同步与 H2D/D2H 拷贝；CUDA Graph 把固定文本 KV 与整个 28 层生成栈捕获为单一端到端图；Edge 解码器数值稳定投影层用 W8A8 量化，精度敏感层保留 BF16。
- **算法级改进（共享轨迹去噪）**：传统两阶段双去噪各自维护独立时间步与采样轨迹，System 1 需在在线控制路径上重复完整去噪链，带来冗余计算与状态分布失配。DualWAM 在共同整流流噪声坐标下切分共享轨迹，把在线路径上 System 1 的去噪前向次数**从 4 次降到 1 次**，带来 2.27× 端到端加速。

## 6. 主要结果与结论

- **零样本泛化**：在 20 个训练中完全未出现的真机任务上，DualWAM 在任务进度与成功率上均优于 π0.5、Cosmos3-Nano-Policy、Fast-WAM 与 AHA-WAM；优势在需要长时域连贯（多阶段、物体状态依赖）与需要接触精细调整（插拔、抓取后微调）的两类任务上同时出现。
- **视频共训的有效性**：Fast-WAM（推理时去掉未来预测）弱于完整 WAM 类方法，支持"未来视觉预测作为训练期表征正则/动力学先验"确有增益，而非仅是推理时的额外开销。
- **异步配对的价值**：AHA-WAM 已采用低频视频 + 高频动作的异步结构，DualWAM 进一步在同一去噪轨迹上做联合专门化后仍取得提升，说明收益并非仅来自"异步"本身，而来自**共享轨迹 + 感知/注意力角色划分**。
- **延迟与响应性**：关键路径延迟显著低于同频对照的 AHA-WAM，端到端取得约 **2.27× 加速**，且 System 1 在线去噪前向次数由 4 次降至 1 次；在边缘-云部署设定下通信开销亦更低。
- **任务完成时间**：成功 rollout 的物理执行时间更短，说明高频局部细化不仅提升成功率，也减少了无效/纠错动作。
- **消融结论**：
  - 去掉 System 1 的局部细化（退化为纯低频全局规划）→ 闭环修正能力下降，接触类任务退化最明显；
  - 去掉 System 2 的全局规划（退化为纯高频短窗口）→ 长时域一致性下降，多阶段任务退化最明显；
  - 局部世界-动作建模（而非仅动作预测）被移除 → 细化质量下降；
  - 同步执行 → 延迟升高且响应性变差；
  - 角色匹配的辅助数据（全局视角人类视频训练 System 2、腕部 UMI 示范训练 System 1）替换为不匹配数据 → 性能下降，验证"感知角色—数据角色"对齐是有效性的组成部分。

## 7. 局限与未来方向

- **局限**：
  - 训练成本极高（64×H200），未公开墙钟时间与 GPU 小时，复现门槛与能耗评估困难；
  - 辅助数据约 3,000 小时视频的采集、标注与清洗成本未量化；
  - 系统复杂度高（双系统、异步调度、多 GPU CFG、CUDA Graph、W8A8 量化），工程收益与实现细节强耦合，难以判断哪一部分收益可迁移到其他硬件；
  - 阈值 τ 与刷新间隔等关键超参缺少敏感性分析；
  - 评测集中于操作类真机任务，未涉及移动、双臂协同之外的更长时域或动态环境；
  - 真机评测无多训练种子方差，统计显著性证据偏弱。
- **未来方向**（由论文结构可合理推断）：自适应 τ 或自适应刷新间隔、将双系统专门化推广到更多模态（力/触觉）、进一步压缩全局规划开销、以及在更多本体上验证角色匹配数据的通用性。

## 8. 总体评价

- **贡献定位**：DualWAM 的核心贡献不是"用视频模型做策略"这一范式本身，而是指出 WAM 的关键瓶颈是**闭环响应性与长时域一致性之间的结构性矛盾**，并提出在同一去噪轨迹上按噪声区间、感知模态与注意力结构做联合专门化的解法。
- **方法亮点**：共享整流流轨迹的切分使 System 1 的在线去噪前向从 4 次降至 1 次，是"算法层面而非仅工程层面"的加速，同时缓解了两阶段独立去噪带来的状态分布失配问题；腕部视角作为 System 1 的专属感知通道，在物理上对应"动作对齐的视觉痕迹"，动机清晰。
- **证据强度**：真机零样本评测规模（20 任务 / 每策略 200 次 rollout 量级）与消融覆盖面对核心主张支撑较强；但训练预算不对齐、缺少阈值敏感性分析与多种子方差，是主要可质疑之处。
- **实践意义**：为"世界模型驱动控制"提供了一条在现有算力下可部署（3×RTX 4090）的路线，尤其适合需要高频接触修正且同时要求多阶段任务连贯性的操作场景。
