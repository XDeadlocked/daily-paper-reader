## 摘要
低比特视觉-语言-动作推理必须在保持机器人行为的同时降低从观测到动作的延迟。我们提出 FoldQuantVLA，一种训练后量化框架，在校准、权重舍入和原生整数执行过程中保持一致的激活表示。它结合通道缩放、块 Hadamard 变换与动态逐 token 量化，无需策略重训练。自定义 TensorRT 插件在 Ada GPU 和 Jetson AGX Orin 上以四位权重和激活（W4A4）执行语言主干与迭代动作专家中的投影。评估涵盖 LIBERO、SimplerEnv 和两个机器人平台。在三个 GR00T 检查点和 π_{0.5} 上，W4A4 在 Orin 上相比浮点 TensorRT 实现 1.20 到 1.33 倍加速，在桌面端实现 1.25 到 1.52 倍加速。将语言注意力输出投影和前馈下投影保留为八位（W8A8）可提升所有四个检查点上的留出动作保真度。在四个真实机器人任务中，该配置将观测到的 GR00T N1.7 成功率从统一 W4A4 的 80.0% 提高到 92.5%，每个配置进行 80 次试验，同时实测 Orin 额外延迟为 1 ms。

## Abstract
Low-bit vision-language-action inference must reduce observation-to-action latency while preserving robot behavior. We present FoldQuantVLA, a post-training quantization framework that carries a consistent activation representation through calibration, weight rounding, and native integer execution. It combines channel scaling and block Hadamard transforms with dynamic per-token quantization, without policy retraining. Custom TensorRT plugins execute projections in both the language backbone and iterative action expert with four-bit weights and activations (W4A4) on Ada GPUs and Jetson AGX Orin. Evaluation spans LIBERO, SimplerEnv, and two robot platforms. Across three GR00T checkpoints and $π_{0.5}$, W4A4 achieves $1.20$ to $1.33\times$ speedups over floating-point TensorRT on Orin and $1.25$ to $1.52\times$ on desktop. Retaining language attention-output and feed-forward down projections at eight bits (W8A8) improves held-out action fidelity on all four checkpoints. Across four real-robot tasks, this configuration raises observed GR00T N1.7 success from $80.0\%$ with uniform W4A4 to $92.5\%$ over 80 trials per configuration, with a measured additional Orin latency of 1 ms.

## 一、核心问题与整体含义（研究动机与背景）

- **应用背景**：视觉-语言-动作（VLA）策略由视觉编码器、语言主干和迭代去噪动作专家组成。语言主干与动作专家都位于延迟关键路径上，低比特推理必须同时降低"观测→动作"延迟并保持机器人闭环行为。
- **闭环特殊性**：动作误差会改变后续观测，因此量化误差会在策略闭环中被放大，不能只看单步重建误差。
- **量化难点**：训练后量化（PTQ）无需重训练，但现有方法（通道缩放 SmoothQuant、旋转 QuaRot/SpinQuant、激活感知舍入 AWQ/GPTQ）虽能处理大激活值，却要求**校准坐标与执行坐标一致**，否则共享激活在多个消费者之间会产生舍入前误差。
- **整体含义**：作者提出一个"一致性折叠"（consistent folding）契约，为每个共享激活站点固定唯一变换基，并把其逆折叠进所有消费权重，从而让校准、权重舍入与原生整数执行处在同一坐标系中。目标是给出可部署到 Ada GPU 与 Jetson AGX Orin 的原生 W4A4 引擎。

## 二、方法论

### 1. 核心思想：一致性折叠契约
- 对单个投影 $y=Wx+b$，取可逆变换 $T$，令 $z=Tx$、$\tilde{W}=WT^{-1}$，则在量化前严格有 $\tilde{W}z+b=Wx+b$。
- **Proposition 1（一致性折叠）**：把策略调用展开为有向无环图，站点 $v$ 的激活 $x_v$ 被其所有消费者共享。定义变换后图 $\tilde f_v((z_u)) = T_v f_v((T_u^{-1}z_u))$，则精确算术下外部函数不变；仿射算子变为 $\tilde W_{vu}=T_vW_{vu}T_u^{-1}$、$\tilde b_v=T_vb_v$。
- **消费者必须共用同一 $T_v$**：若某消费者使用 $T_i\neq T_v$，会引入舍入前误差 $W_i(T_i^{-1}T_v-I)x_v$。文中实测该不匹配使 N1.6 动作模块余弦从 0.9997 降至 0.9923。

### 2. 受运行时约束的变换族
- 形式限定为 $T_v = D_v^{o} R_v D_v^{i}$，$R_v^TR_v=I$，$D^i,D^o$ 为正对角阵；投影输出保持 $T=I$，因此残差相加、RoPE、注意力点积均不受影响。
- **fold-before**（默认）：$(D^i,D^o)=(S_v^{-1},I)$，$\tilde W=WS_vR_v^T$；缩放直接融合进 load loop。
- **fold-after**：$(D^i,D^o)=(I,P_v^{-1})$，$\tilde W=WR_v^TP_v$；需要额外一趟处理。
- **SmoothQuant 式通道缩放**：$s_{v,c}=a_{v,c}^{\alpha}/w_{v,c}^{1-\alpha}$，$\alpha\in[0,1]$，含数值下限与有界正缩放。
- **块 Hadamard 旋转**：$R_v = I_{d_v/\beta}\otimes\beta^{-1/2}H_\beta$，$\beta=64$，用 FWHT 实现，代价 $O(d_v\log\beta)$；归一化保证 $R_v^{-1}=R_v^T$。
- **归一化增益吸收**：若投影前有 RMSNorm，$x_v=\Gamma_v\bar h_v$，则 $z_v=D_v^oR_v(D_v^i\Gamma_v)\bar h_v$，即用 $D^i\Gamma$ 替代学习增益而不穿越 RMS 分母；但该吸收要求前置增益存在（o_proj 与 down_proj 输入处不存在）。

### 3. 动态逐 token 量化与不变性
- 量化重建：$\hat z_t=\delta_t\,\mathrm{clip}(\mathrm{round}(z_t/\delta_t),-q,q)$，$\delta_t=r\|z_t\|_\infty/q$，$q=2^{b_a-1}-1$，$r\in(0,1]$ 仅在语言 INT4 站点校准；零 token 置零。
- **Proposition 2（幅度不变性）**：该量化正齐次，$\widehat{\lambda z_t}=\lambda\hat z_t$；在固定变换与固定折叠权重下残差 $e_T(\lambda u)=\lambda e_T(u)$。若各去噪步的输入方向分布 $\nu$ 相同，则归一化风险 $L_\tau(T)=\mathbb{E}[\|e_T(u_\tau)\|_2^2/\|u_\tau\|_2^2]$ 与步数 $\tau$ 无关，故最优解可跨步共享——**无需按时间步索引的 scale 表**。
- 作者明确指出该性质只消除幅度变化，不处理通道分布漂移与误差累积，也不保证解码动作或闭环最优。

### 4. 权重舍入与原生执行
- 在校准 token 构成的变换坐标 $Z_v=T_vU_v$ 下做 GPTQ：$\min_{Q}\|\tilde W-Q)Z_v\|_F^2$，二阶矩 $G_v=Z_vZ_v^T$；4-bit 用 GPTQ，8-bit 用 RTN。
- 输出计算 $\hat y_{jt}=s_j^W\delta_t\sum_c q^W_{jc}q^A_{ct}+b_j$，即权重/激活整数码 + INT32 累加 + 浮点重缩放与偏置。
- 自定义 TensorRT 插件（CUTLASS v3.6.0）：INT4 用 m16n8k64 MMA，INT8 用 m16n8k32；TensorRT 10.3 内置 INT4 仅支持权重量化，激活 INT4 路径由插件提供。

### 5. 选择性 INT8 配置
- FQ W4A4 + o/d INT8：语言注意力的 **o_proj** 与 FFN 的 **down_proj** 保持 W8A8，其余量化投影维持 W4A4，全部仍走整数 GEMM。
- 动机：这两类投影把特征送回残差流，其输入缺少可用于吸收缩放的归一化增益，且 down_proj 在审计中激活离散度最大。
