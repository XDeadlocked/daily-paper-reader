## 摘要
反应式视觉—语言—动作（VLA）模型在长时程操作中表现不佳，因为视觉上相似的观测可能因任务阶段或交互历史不同而对应不同动作。我们将这种歧义称为任务状态混叠，并提出 TaskAnchor，一种轻量级适配器，用于将预训练 VLA 锚定在执行历史中。TaskAnchor 将历史条件化的视觉细化与里程碑监督的任务状态坐标相结合，后者是一个表示执行语义阶段的标量。这些信号分别通过原生视觉和语言接口注入，无需引入显式规划器，也不修改动作生成机制。在 RMBench 上，TaskAnchor 的平均成功率约为已发表 π_{0.5} 和 X-VLA 基线的 4.9–5.5 倍，并在 RoboMemArena 和真实机器人上取得一致增益。对于 π_{0.5}，每个动作块仅增加 2.08 ms 延迟。

## Abstract
Reactive vision--language--action (VLA) models struggle with long-horizon manipulation when visually similar observations can correspond to different actions depending on the task stage or interaction history. We refer to this ambiguity as task-state aliasing and introduce TaskAnchor, a lightweight adapter that grounds pretrained VLAs in execution history. TaskAnchor combines history-conditioned visual refinement with a milestone-supervised task-state coordinate, a scalar representing the semantic stage of execution. These signals are injected through the native visual and language interfaces, respectively, without introducing an explicit planner or modifying the action-generation mechanism. On RMBench, TaskAnchor achieves approximately 4.9--5.5$\times$ the average success rates of the published $π_{0.5}$ and X-VLA baselines, with consistent gains on RoboMemArena and real robots. The added latency is only 2.08\,ms per action chunk for $π_{0.5}$.

## 1. 核心问题与整体含义（研究动机与背景）

- **核心问题：任务状态混叠（task-state aliasing）**。反应式 VLA 模型以「当前观测 + 语言指令 → 短动作块」的方式工作，当视觉上相似的观测在不同任务阶段或不同交互历史下需要不同动作时，模型无法判别，导致重复已完成操作、遗漏步骤或提前终止。
- **两类互补的混叠形式**：
  - **子任务阶段识别（subtask-stage identification）**：相似场景在不同阶段复现，但需要不同的后续动作，缺乏阶段信息会使策略行为错乱。
  - **阶段内动作分支选择（intra-stage action-branch selection）**：即使已知阶段，仍需早期证据（初始物体配置、上次交互结果）来区分动作分支，而这些证据当前已不可见。
- **现有方法的不足**：
  - 历史感知策略（MemoryVLA、HAMLET 等）保留了细粒度证据，但只把执行阶段**隐式**编码在高维时序特征中；
  - 规划 / 语义分解方法（π0.5、LoHoVLA、VLA-OS 等）提供了显式阶段结构，但把历史**压缩成粗糙语义摘要**。
- **核心假设**：预训练 VLA 本身已在时序连贯的轨迹上训练，具备长时程执行所需的大量行为先验；瓶颈不在于「缺少行为」，而在于「在歧义观测下难以选择合适行为」。因此只需一个**轻量的任务状态接口**即可激活既有行为，无需显式规划或子任务分解。
- **整体含义**：论文主张用极低开销把「执行历史 + 语义进度」注入预训练 VLA 的原生视觉与语言接口，从而在长时程操作中恢复任务一致性，同时保持反应式策略的简洁性与推理效率。

## 2. 方法论：核心思想与关键技术细节

### 2.1 任务状态策略形式化

- 基础 VLA 在视觉 token 接口上工作：`Xt = Evis(Ot)`，动作块 `At:t+H-1 ~ pθ(· | Xt, ℓ)`，其中 `ℓ` 为任务指令，`H` 为动作时域。
- TaskAnchor 用历史记忆 `Mt`（t 时刻之前观测特征的紧凑表示）推断任务状态表示：`Ct = Gψ(Xt, Mt) = (X̃t, pt)`。
  - `X̃t`：历史条件化的视觉 token（经残差修正）；
  - `pt`：标量任务状态坐标，表示执行语义阶段，监督目标归一化到 `[0,1]`。
- 坐标被序列化进原指令，得到坐标感知指令 `ℓ+t`，最终动作生成：`At:t+H-1 ~ pθ(· | X̃t, ℓ+t)`。
- 联合分布按「反应式 VLA × TaskAnchor」分解（式 4），**保持预训练 VLA 的视觉、语言、动作接口不变**。

### 2.2 上下文自适应视觉条件化（CA-TTT）

- **记忆库构造**：`Mt = [m1; …; mt-1]`，其中 `mi = Φ(Xi)`，`Φ(·)` 压缩每个观测的空间 token；新特征在 episode 内持续追加，时序位置用旋转位置编码（RoPE）表示。
- **查询流初始化**：`Q(0)t = [qp; fq(Xt)]`，即「可学习的任务状态查询 token + 投影后的当前视觉特征」。
- **Test-Time Training 机制**：每个 CA-TTT 层用自己的 key/value 投影处理共享记忆 `Mt`；用轻量 MLP `g(·; ω)` 作为联想映射，构造内层目标
  `L(m)TTT,t(ω) = (1/Nt) Σ_j || g(K(m)t,j; ω) − V(m)t,j ||²`。
- **一步快速权重更新**：从离线学得的慢权重初始化 `ω(m)` 出发，做一次梯度下降得到 `ω̂(m)t = ω(m) − η_ttt ∇ω L(m)TTT,t`，随后查询流通过 `Q(m)t = Q(m−1)t + g(Q(m−1)t; ω̂(m)t)` 读出联想信息（相当于用 fast weights 替代显式注意力权重，**不对查询流做自注意力**）。
- **关键性质**：快速权重在读出后即丢弃，不修改慢权重 `ω(m)`；只有记忆库在 episode 内传递。因此**不会扩展下游动作模型的视觉上下文长度**，避免长历史带来的计算膨胀。

### 2.3 双通道输出与注入

- 最终查询序列划分为 `Q(L)t = [qp,t; QO,t]`。
- **视觉偏移头**：`X̃t = Xt + Hψo(QO,t)`，偏移量与 `Xt` 同形状，经 VLA 的**视觉特征接口**注入。
- **坐标头**：`pt = Cψc(qp,t)`，`Lcoord = || pt − p⋆t ||²`。
- **里程碑定义**：把任务分解为 M 个有序里程碑，`p⋆t = mt / M`（mt 为已完成里程碑数）。这是**语义进度而非时间进度**，只在里程碑边界变化，因此对执行速度和阶段时长不敏感。RMBench 与 RoboMemArena 直接使用基准定义的子任务作为里程碑；无标注时可用离线时序分割（变化点检测、时序一致交互阶段聚类）生成伪里程碑。
- 坐标被序列化为归一化小数，按固定模板前置到指令 `ℓ` 中（训练用 `p⋆t`，推理用 `pt`）。

### 2.4 训练与推理流程

- **离线训练**：`L = Lact + λcoord Lcoord`，新模块与基础 VLA 的微调参数联合优化。由于训练时指令中使用的是真值 `p⋆t`，`Lact` 不会经语言路径回传到坐标头。内层 `L(m)TTT,t` 只用于构造快速权重，**不加入外层目标**。
- **在线推理**：所有慢参数固定；每个当前观测由记忆产生一步快速权重，预测下一动作后丢弃；`Φ(Xt)` 追加进记忆供后续使用；记忆为空时跳过更新；episode 之间清空记忆库。

## 6. 主要结论与发现

- **RMBench（M(1) 平均 SR）**：TaskAnchor-π0.5 达 **0.68**，较 π0.5（0.14）提升 0.53，较 Mem-0（0.53）提升 0.15；TaskAnchor-XVLA 达 **0.66**

，较其 X-VLA 主干基线亦有大幅提升，说明该接口并非绑定某一特定 VLA，而是可迁移的通用适配器设计。

- **消融结论（双通道互补性）**：coordinate only 与 history visual only 均明显低于 full model，说明「语义阶段坐标」与「历史条件化视觉 token」承担**不可互相替代**的功能——前者负责阶段级切换，后者负责阶段内的细粒度分支判别。这直接支持了论文第 1 节提出的两类混叠形式的划分。
- **RoboMemArena 结论**：在 26 个长时程任务（平均 1076 步）上，TSR（全阶段完成率）与 CSR（阶段完成百分比）均取得一致提升；增益在**需要历史信息的 104 个子任务**上尤为显著，而在纯反应式可解的子任务上提升有限，说明收益来源确实是「恢复被观测歧义抹掉的任务状态」，而非泛化的动作能力提升。
- **坐标干预结论**：对预测坐标做受控偏移会系统性改变策略行为（如提前进入下一阶段或回退到上一阶段），表明标量坐标 `pt` 被策略当作**可读写的阶段控制信号**使用，而非仅作为训练时的辅助回归目标。
- **效率结论**：27.80M 新增参数（主干 0.84%）与 +2.08 ms（+3.35%）的每块延迟，说明「任务状态接口」的代价接近可忽略，且不随历史长度扩展下游动作模型的视觉上下文。

## 8. 总体评价与启示

- **核心贡献的定位**：TaskAnchor 的价值不在于提出新的 VLA 架构，而在于给出一个**极简接口假设**——预训练 VLA 已具备长时程行为先验，缺的只是「在歧义观测下选对行为」的判据。这一视角把长时程操作问题从「能力不足」重述为「状态不可观测」，方法论上具有启发性。
- **方法上的巧思**：用 fast weights 替代显式注意力、在读出后即丢弃，使历史信息注入不改变下游上下文长度；用语义里程碑而非时间进度做监督，使坐标对执行速度鲁棒。这两点是其低开销与可迁移性的关键。
- **与主流路线的对比**：相较于 π0.5 / LoHoVLA 等显式规划路线，TaskAnchor 走「隐式先验 + 轻量显式接口」的中间路线，避开了子任务分解的工程复杂度与误差累积；相较于 MemoryVLA / HAMLET 等纯历史感知路线，它额外提供了**可解释、可干预**的阶段坐标。三种路线的取舍仍是开放问题。
- **可信度判断**：方法设计与消融逻辑自洽，双主干验证增强了泛化性证据；但训练预算不对等、缺少统计检验、真实机器人无定量、伪里程碑未验证这四点，使结论的**强度应被适度打折**。最需要补的实验是：等预算对照 + 伪里程碑方案验证 + 长 episode 下的记忆/延迟曲线。
