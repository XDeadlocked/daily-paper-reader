## 摘要
在接触丰富的操作中，可靠的动作评估需要超越当前观测，关注未来的视觉与接触后果。现有的噪声空间强化学习能够高效地引导冻结的视觉-语言-动作（VLA）策略，但其评论器在很大程度上忽略了这些后果。我们提出 Imagine-RL，它通过动作条件化的视觉-力矩想象来增强噪声空间 VLA 后训练。对于每个候选动作块，一个冻结的视觉-力矩潜世界模型（VTLWM）自回归地预测紧凑的未来表示，而无需像素重建。当前图像-状态-动作查询关注观测历史和预测未来，而前窗口预测残差提供逐 token 置信度先验，以抑制不可靠的未来 token。通过将当前证据与预测后果相结合，动作评论器能更好地评估候选动作并监督 actor，同时 VLA 和 VTLWM 保持冻结。在四个真实机器人任务上（每个任务 50 次评估试验），Imagine-RL 仅使用 100 条 RL 轨迹，就将平均成功率相较于 DSRL 提升了（23.6%），相较于 VLA 基线提升了（60%）。

## Abstract
Reliable action evaluation in contact-rich manipulation requires looking beyond the current observation to future visual and contact consequences. Existing noise-space reinforcement learning efficiently steers a frozen Vision-Language-Action (VLA) policy, but its critics largely ignore these consequences. We present Imagine-RL, which augments noise-space VLA post-training with action-conditioned visual-torque imagination. For each candidate action chunk, a frozen visual-torque latent world model (VTLWM) autoregressively predicts compact future representations without pixel reconstruction. A current image-state-action query attends to observed histories and predicted futures, while previous-window prediction residuals provide token-wise confidence priors that suppress unreliable future tokens. By combining current evidence with predicted consequences, the action critic better evaluates candidate actions and supervises the actor, while the VLA and VTLWM remain frozen. Across four real-robot tasks with 50 evaluation trials per task, Imagine-RL uses only 100 RL trajectories and improves the average success rate by (23.6%) over DSRL and by (60%) over VLA baselines.

- **背景**：VLA（Vision-Language-Action）模型可将语言、图像与机器人状态映射为动作，具备跨任务、跨本体泛化能力（如 Octo、OpenVLA、π0）。但其观测以视觉为主，在接触丰富操作中，阻力、滑动、卡滞等接触现象只能被间接观测。
- **现有方案的两点不足**：
  - ForceVLA、TA-VLA 等力/力矩感知 VLA 虽引入力矩，但仅用于**动作生成**，未用于**价值估计**。
  - 噪声空间 RL（如 DSRL）能以轻量方式引导冻结 VLA，但 critic 主要依赖当前观测与候选动作；当两个视觉上相似的动作分别导致成功或失败时，评价不可靠。而 latent-noise VLA-RL 中动作 critic 还负责监督噪声 critic 与 actor，因此**后果感知的动作排序尤为关键**。
- **世界模型的机会与空白**：世界模型可提供前瞻证据（LeWorldModel 已能预测紧凑物理表示而不做像素重建），但**力/力矩条件化的想象用于 critic 学习仍未被充分探索**。
- **整体含义**：Imagine-RL 将动作条件化的视觉–力矩想象注入轻量噪声空间 VLA 后训练，使 critic 同时依据"当前证据"与"预测后果"评估动作，在冻结 VLA 与世界模型的前提下提升接触丰富任务的成功率与样本效率。

## 2. 方法论

### 核心思想
- 不直接学习机器人动作，而是在**冻结 flow-matching VLA 的 latent-noise 空间**中学习轻量噪声 actor；用一个冻结的**视觉–力矩潜世界模型（VTLWM）**为每个候选动作块预测未来视觉与力矩表示；动作 critic 通过**残差置信度引导的交叉注意力**融合历史、预测未来与当前图像–状态–动作特征；再用动作 critic 蒸馏出噪声 critic 并监督噪声 actor。VLA 与 VTLWM 全程冻结，无需像素级规划。

### 关键技术细节

- **潜噪声 VLA-RL 与双 critic**
  - 冻结 VLA：`ā_t = π0(o_t, w_t)`，输出动作块长度 `H_a = 30`，实际执行前 `H_q = 10` 步后重规划。
  - 噪声 actor：`w_t ∼ πθ(w | o_t)`，仅在噪声空间学习。
  - 动作 critic `Qa(o, ā; h_ā)`：评估解码后的动作块，条件于世界模型生成的历史/未来视觉–力矩特征。
  - 噪声 critic `Qw(o, w)`：由动作 critic 蒸馏，`Qw(o, w̃) ← Qa(o, π0(o, w̃); h_ã)`，保持部署策略轻量。
  - 使用 **10 个 Q 函数集成**与均值目标降低偏差；Bellman 目标为 `y_t = r_t + γ^{H_q} · (1/n)Σ Q̄_{a,i}(o_{t+1}, ā'_{t+1}; h'_{t+1})`；噪声 actor 以最大化 `Qw(o, πθ(o))` 并带熵正则（SAC 框架）更新。
  - 奖励设计：每个非终止查询步 `-1`，成功终止 `+5`，普通失败截断 `-1`，严重吸收失败 `-50`。

- **VTLWM（力感知潜世界模型）**
  - 扩展 LeWorldModel，JEPA 风格联合预测视觉与力矩表示，**不做像素重建**。
  - 输入：多视角图像经共享编码器得 `z_t`，力矩归一化为 `τ̂_t`，动作嵌入为 `E_a(a_t)`；状态为 `x_t = [z_t, τ̂_t]`。
  - 固定一步预测器：历史长度 `H = 15`，用前 H 个状态–动作对预测 H+1 状态；rollout 时把最终预测追加进上下文并滑窗，实现自回归未来序列，未来有效长度 `H_f = 10`（30 Hz）。
  - 损失：`L_WM = MSE(P_z, Z) + λ_τ·SmoothL1(P_τ, T) + λ_sig·L_SIGReg`，即视觉 MSE + 力矩 SmoothL1 + 高斯潜正则。
  - RL 训练期间 VTLWM 冻结，仅用于生成 critic 特征。

- **残差置信度引导的交叉注意力 critic**
  - **特征构造**：对模态 `m ∈ {z, τ}`，取当前历史 `X^{m,hist}`、动作条件未来预测 `X^{m,fut}(a)`、上一窗口预测 `P^{m,prev}`；残差 `R = X^{m,hist} − P^{m,prev}`（同时间戳，反映世界模型生成可靠性在相邻窗口间的持续性）。
  - **预测可靠性**：用均方特征幅值 `E_m(x)=‖x‖²/D_m` 计算相对误差 `ρ`，置信度 `α = max(α_min, e^{−βρ})`，其中 `β = 1`、`α_min = 0.05`、`ε = 1e−6`；误差越小置信度越高；不可用残差取 `α_min`、`ρ = 4`。
  - **查询与 token**：当前观测与候选动作块构成 `ζ_t = (o_t, a_t)`，经查询映射 `f_q` 得 256 维查询 `q_t`；历史与未来特征加位置/动作嵌入后作为注意力 token（视觉 192 维、力矩 14 维）。
  - **注意力**：每模态独立投影 Q/K/V，宽度 256、4 头、每头 64 维；偏置向量 `B` 对有效历史 token 取 0、对有效未来第 j 步取 `log α_{t,j}`、对无效槽取 `−∞`。softmax 后加权求和，拼接 4 头、输出投影 + LayerNorm 得上下文 `c^m_t ∈ R^256`。加 `log α` 等价于按置信度对未归一化权重打折，把"相关性"与"可靠性"结合。
  - **价值融合**：`h_a = [c^z_t, c^τ_t, g^z_t, g^τ_t]`，其中 `g` 为未来有效槽的置信度均值/最小/最大值与平均相对误差（无有效槽时置零）；最终 `Qa(o_t, a_t; h_a) = Q([ζ_t, h_a])`，`Q` 为 MLP critic。整体特征构造记为 `Φ_ψ`。

- **算法流程（每步循环）**
  1. **动作 critic 更新**：从回放缓冲采样 `(o_t, w_t, ā_t, r_t, o_{t+1})`；采样 `w'_{t+1} ∼ πθ(o_{t+1})` 解码 `ā'_{t+1}`；计算动作对齐特征 `h_ā`、`h_ā'`；最小化 Bellman 残差平方。
  2. **噪声 critic 蒸馏**：采样 `w̃ ∼ N(0, I)`，解码 `ã = π0(o_t, w̃)`，计算候选对齐特征 `h_ã`；最小化 `(Qw(o_t, w̃) − Qa(o_t, ã; h_ã))²`。
  3. **噪声 actor 更新**：最大化 `E[Qw(o, πθ(o))]`。
