## 摘要
视频世界模型支持对动态环境的交互式探索，但难以在长时程与跨视角条件下保持对先前观测的遵循。我们提出 WorldCrafter，一种为此目的学习可相机查询的隐式3D感知记忆的视频世界模型。关键洞见是让所请求的视角决定多视角证据如何压缩到视频生成器有限的 token 预算中。记忆编码器与姿态条件化的读出模块和视频生成器联合训练，在去噪前将历史观测整合为一组固定的目标视角特定 token，无需显式的基于深度的对应关系。通过将该记忆与近期时间上下文和少步蒸馏相结合，WorldCrafter 能够从单张输入图像或文本提示出发进行流式场景探索。在静态和动态场景上的实验表明，在分钟级探索过程中，长时程一致性和相机控制精度均有显著提升，同时保持视觉质量。

## Abstract
Video world models enable interactive exploration of dynamic environments, yet struggle to respect prior observations over long horizons and across viewpoints. We present WorldCrafter, a video world model that learns a camera-queryable implicit 3D-aware memory for this purpose. The key insight is to let the requested viewpoint shape how multi-view evidence is compressed into the video generator's limited token budget. Trained jointly with the video generator, a memory encoder and pose-conditioned readout module integrate historical observations into a fixed set of target view-specific tokens before denoising, without explicit depth-based correspondences. By combining this memory with recent temporal context and few-step distillation, WorldCrafter enables streaming scene exploration from a single input image or text prompt. Experiments across static and dynamic scenes show substantial gains in long-horizon consistency and camera-control accuracy while preserving visual quality during minute-scale exploration.

# WorldCrafter 论文总结

## 一、核心问题与整体含义

- **研究背景**：视频世界模型（Video World Models）让用户通过移动相机来交互式探索动态环境，是生成式模型向"可交互模拟器"演进的重要方向。然而，现有方法在**长时程（minute-scale）与跨视角**条件下难以忠实回忆先前观测到的场景内容。
- **核心问题**：如何在有限的 token 预算与计算成本下，为视频生成器提供一种能够跨视角、跨时间保留场景内容（几何 + 外观）的**持久记忆**，使重访（revisit）时生成的画面与首次观测一致。
- **现有方案的三类局限**：
  - **上下文记忆（context memory）**：全历史注意力计算昂贵，选择性检索则牺牲视角覆盖。
  - **显式空间记忆（spatial memory）**：依赖精确几何与深度估计，对动态场景鲁棒性差，且深度估计与 warp 成本高。
  - **隐式记忆（implicit memory）**：多为几何预测导向，对外观保真度重视不足，难以复现曾观测到的画面。
- **整体含义**：论文提出 WorldCrafter，把"隐式 3D 感知记忆"引入相机可控的自回归视频世界模型，实现分钟级流式探索下的一致性与精确相机控制，为交互式长时程世界建模提供新范式。

## 二、方法论

### 核心思想

- 让**请求的目标视角**决定多视角历史证据如何被压缩到视频生成器有限的 token 预算中；记忆在去噪之前被读出为固定大小的、与目标视角相关的 token，直接通过自注意力条件化 DiT，**无需显式深度对应或目标视角图像重建**。

### 关键技术细节

- **记忆写入（Memory Writing）**：
  - 记忆编码器 Φ 将累积的历史 latent 帧 $z_h$ 及其相机参数 $C_h$ 映射为隐式 3D 感知表示 $R = \Phi(z_h, C_h)$，每帧产生 $L$ 个 $d$ 维 token。
  - 编码器从预训练的 **LagerNVS** 编码器初始化（保留其 3D 归纳偏置），丢弃浅层图像处理层，新增 patch embedding 直接处理 VAE latent；历史相机位姿以最新帧为参考注入。
  - 编码器输入限制为 $k$ 帧：保留最新帧，其余 $k-1$ 帧按**最大联合视场覆盖（max-coverage）**贪心选择，而非逐帧相似度排序。
- **记忆读出（Memory Readout）**：
  - 对比**无姿态读出**（$M = \text{Readout}(\Phi(z_s, C_s))$）与**姿态引导读出**（$M = \text{Readout}(\Phi(z_s, C_s), C_q)$，用目标轨迹上采样的查询位姿 $C_q$ 查询表示）。
  - 读出模块用 LagerNVS 浅层解码器初始化，并加投影层映射到 DiT token 空间；实验采用**姿态引导读出**，因其更有效地分配固定记忆预算。
- **条件生成与自回归流**：
  - 将标准自回归流扩展为 $dz_t/dt = v_\theta(z_t, t \mid M, z_r, C, y)$，DiT 处理拼接序列 $[M; z_r; z_t]$，保持 chunk 级因果性。
  - **相机条件**：采用 UCPE 的并行相机注意力分支（基于 PRoPE 的相对位姿编码），零初始化投影加回自注意力，且仅作用于噪声部分 $z_t$，记忆与近期上下文不注入相机信息。
- **训练流程（4 阶段）**：
  1. 微调 Helios-base 适配修改后的推理窗口（移除 16 帧压缩段，前置相当于 4 帧未压缩历史 token 的记忆槽）。
  2. 冻结 DiT 主干，训练 UCPE 相机控制分支。
  3. 用 VAE latent 适配记忆编码器（替换 DINO 浅层为 latent patch embedding，固定 9 帧输入）。
  4. 联合训练记忆读出模块、记忆编码器、视频 DiT 与相机分支，使记忆表示与 DiT token 空间协同适配。
- **实时蒸馏**：
  - 采用 Helios 的**金字塔去噪**（3 个空间分辨率、每级 2 步）配合分布匹配蒸馏。
  - **混合蒸馏模型**：低噪声模型（自然外观数据）负责最后一步，高噪声模型（含合成数据）负责其余步骤，兼顾视觉保真与主体跟随能力，蒸馏后可达 **16 fps（4 GPU）**。

## 六、主要结论与发现

- **记忆一致性显著领先**：WorldCrafter 在 MEt3R/LPIPS/PSNR/SSIM 四项上均居前二，WorldCrafter-fast 最优（LPIPS 0.186、PSNR 20.868、SSIM 0.616），相比最强基线（Lyra 2.0，LPIPS 0.487）改善约 **47.6%**。
- **相机控制最精确**：WorldCrafter 在 RotErr（13.536）、TransErr（1.475）、CamMC（1.546）上均最低。
- **视觉质量不降反升**：WorldCrafter 取得最高 VBench Overall（81.910），并在 8 个维度中的 5 个上最优；WorldCrafter-fast 在 Temporal Flickering 上最佳。
- **效率优势**：记忆处理仅需 0.062 s/chunk（编码 0.049 + 读出 0.013），相比深度估计 + warp 的 1.346 s/chunk **快 21.7 倍**，且无需显式深度。
- **消融结论**：隐式 3D 记忆优于上下文记忆（且重访间隔越长优势越大）；联合优化优于冻结编码器；姿态引导读出优于无姿态读出；最大覆盖检索优于相似度排序。

## 七、优点

- **方法亮点**：
  - 将记忆写入/读出与 DiT token 空间**端到端联合优化**，让记忆表示与生成器协同适配，而非消费固定表示。
  - 以"目标视角查询"驱动记忆压缩，在固定 token 预算下把容量分配给与当前生成最相关的信息。
  - 完全**避免显式深度估计与 3D warp**，直接作用于历史 latent，兼顾动态场景鲁棒性与计算效率。
  - 最大联合视场覆盖的贪心检索，比逐帧相似度排序更稳健、覆盖更广。
- **系统亮点**：
  - 与相机条件、自回归 chunk 生成、金字塔蒸馏完整集成，实现 **16 fps 实时流式交互**。
  - 低/高噪声混合蒸馏策略，在保留自然纹理与主体跟随能力之间取得平衡。
- **实验亮点**：
  - 同时评测记忆、相机控制与视觉质量三类目标，避免单一指标偏置。
  - 消融不仅看最终指标，还给出随时间/迭代变化的曲线与延迟分解，论证更扎实。

## 八、不足与局限

- **作者自述局限**：
  - 在特别复杂或超长轨迹下，一致性仍可能被破坏。
  - 每个 chunk 都重新编码历史会带来额外延迟；未来方向是**自回归流式记忆编码器**，增量更新记忆状态以减少重复计算。
- **实验覆盖与偏差风险**：
  - Benchmark 为**自建**（145 张图、725 视频），非公开标准集，绝对数值的可比性受限。
  - 对比方法中部分使用蒸馏模型、部分使用全步模型，训练数据与算力规模未必对齐，横向比较存在潜在不公平。
  - 相机控制评测依赖 VGGT-Ω 估计轨迹，本身引入估计误差。
  - 训练数据以 OSP/DL3DV/MIND 为主，对极端动态、强遮挡、镜面/透明材质等场景的泛化性未做专门评估。
- **应用限制**：
  - 需要 4 GPU 才能达到 16 fps，实时交互对硬件仍有要求。
  - 记忆编码器从 LagerNVS 初始化，受限于该预训练表示的能力边界；记忆容量固定为约 4 帧 token，超长历史仍靠检索而非全量保留。
  - 未报告 GPU 型号与总训练时长，复现成本与可重复性信息不完整。
