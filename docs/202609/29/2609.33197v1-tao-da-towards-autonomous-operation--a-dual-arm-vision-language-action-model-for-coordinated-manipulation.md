## 摘要
视觉-语言-动作（VLA）模型提供了一个统一框架，可将高层语义信息落地为底层机器人动作，从而支持跨多样化任务的可扩展机器人操作。然而，现有 VLA 模型缺乏显式机制来解耦双臂的状态与意图，导致非预期的跨臂干扰，进而降低任务执行成功率。为解决这一问题，我们提出一种对称双臂专家（DAE）架构，该架构构建于共享的视觉-语言模型（VLM）主干之上，并配有解耦的、针对各臂的专家塔。专家选择通过两阶段双臂意图路由方案完成：第一阶段由显式语言指令路由专家，第二阶段则由隐式视觉语义路由专家。此外，我们引入一个轻量级任务进度预测模块，利用分块前时序特征与本体感觉及视觉观测的语义表示之间的交叉注意力，准确估计逐帧任务完成进度。该模块促进任务进度同步，以支持多机器人协作任务的协调调度。实验结果表明，我们的模型在双臂意图路由和跨臂干扰解耦方面有效，并进一步为从单臂任务到双臂任务（以及反向）的涌现技能泛化提供了初步证据，同时展示了跨臂运动域技能迁移。

## Abstract
Vision-Language-Action (VLA) models provide a unified framework for grounding high-level semantic information into low-level robot actions, enabling scalable robotic manipulation across diverse tasks. However, existing VLA models lack explicit mechanisms to disentangle the states and intents of the two arms, leading to unintended cross-arm interference that degrades task execution success. To address this issue, we propose a symmetric Dual-Arm Expert (DAE) architecture built upon a shared Vision-Language Model (VLM) backbone with decoupled, arm-specific expert towers. Expert selection is carried out through a two-stage dual-arm intent routing scheme, in which experts are routed either by explicit language instructions in the first stage or by implicit visual semantics in the second stage. Moreover, we introduce a lightweight task progress prediction module that leverages cross-attention between the pre-chunk temporal features and semantic representations of proprioceptive and visual observations to accurately estimate frame-wise task completion progress. This module facilitates task progress synchronization to support coordinated scheduling for collaborative multi-robot tasks. Experimental results demonstrate the effectiveness of our model in dual-arm intent routing and the disentanglement of cross-arm interference, and further provide preliminary evidence of emergent skill generalization from single- to dual-arm tasks (as well as the reverse), together with cross-arm motion-domain skill transfer.

## 1. 核心问题与整体含义

- **研究背景**：视觉–语言–动作（VLA）模型将语言、视觉和机器人状态统一映射为动作，已在多样化操作任务中展现可扩展性。但现有双臂 VLA 多采用统一动作生成器，把左右臂状态与动作耦合在同一动作空间中。
- **核心问题**：统一生成器容易把执行臂与另一臂的无关状态、视觉变化耦合起来，造成**跨臂干扰**。这在以下场景尤其严重：只需单臂执行、双臂顺序执行子任务、示范中左右臂角色不对称。
- **整体含义**：双臂策略应保留共享任务语义，同时选择性控制臂级动作生成。论文提出 **TAO-DA**，核心是“共享多模态表示 + 臂专属动作通路”，并用双臂意图路由决定当前激活臂集合，从而抑制非活动臂干扰。
- **主要贡献**：
  - 将非活动臂干扰形式化为动作生成问题，比较统一、掩码弱解耦、独立双臂塔三类 DAE 变体。
  - 提出 **DAIR（Dual-Arm Intent Routing）**，结合规则语言解析与学习式多模态分类，预测左臂、右臂或双臂执行。

## 2. 方法论

### 2.1 总体架构

- **TAO-DA 输入**：多视角视觉观测、语言指令、本体感觉状态。视觉包括 1 个第一视角图像和左右腕部两个可选末端视角图像。
- **编码与融合**：每张图像由预训练 **SigLIP** 编码；视觉 token 与语言 token 拼接后送入冻结的 **Eagle-2.5-VL** 主干，得到融合多模态表示 \(E_{VL}\)。
- **核心流程**：
  - **DAIR** 根据语言和视觉上下文推断激活臂集合 \(r=[r_L,r_R]\)。
  - **DAE** 根据路由结果，通过被选中的臂专属通路生成动作。
  - 动作条件构造时，非活动臂的末端视角 token 在进入 VLM 前被掩码。
  - 任务进度模块估计逐帧完成度，用于路由保持机制和部署级调度。
- **完整 TAO-DA**：默认指 DAIR + 任务进度模块 + **Dual-Tower DAE** 变体。

### 2.2 DAIR：双臂意图路由

- **意图表示**：用二值向量 \(r=[r_L,r_R]\in\{0,1\}^2\) 表示激活臂。有效类别为：
  - 左臂：\(\phi(0)=[1,0]\)
  - 右臂：\(\phi(1)=[0,1]\)
  - 双臂：\(\phi(2)=[1,1]\)
  - 三分类设计避免产生无效的 \([0,0]\)。
- **路由损失**：交叉熵 \(L_{route}=-\log p_c\)，其中 \(c\) 为目标类别。
- **两阶段推理**：
  - **Stage 1 规则语言解析**：识别“left arm”“right arm”“both arms”“left hand”“right hand”等显式表达，映射为 \(\hat r_{rule}\)。若同时出现双臂表达，双臂优先返回 \([1,1]\)。若没有显式臂相关表达，返回内部无匹配码 \([0,0]\)，表示转入 Stage 2。
  - **Stage 2 模型多模态预测**：对 \(E_{VL}\) 做 LayerNorm，并用可学习 query 做多头注意力池化，再经 MLP 输出三类 logits，取 argmax 后映射为 \(\hat r_{model}\)。
- **进度保持机制**：推理时若已有足够任务进度，可保持上一时刻意图。规则匹配优先；否则使用模型预测；若已有上一意图且预测进度 \(\hat p_t\) 超过阈值 \(\tau_{hold}\)，则保持 \(\hat r_{t-1}\)
