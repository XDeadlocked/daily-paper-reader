## 摘要
视觉-语言-动作（VLA）模型在机器人操作上表现出强大性能，但往往难以泛化到未见任务、配置和长时程场景。一个关键挑战是，VLA 会过拟合训练场景，无法遵循新颖的语言指令。现成的视觉-语言模型（VLM）通常具有更强的泛化能力，但无法直接控制机器人动作。为了将 VLM 的常识与 VLA 控制相结合，我们提出 Guided Trace VLA（GT-VLA），一个可引导框架，通过轨迹条件化的动作生成接受来自外部通用 VLM 的引导。GT-VLA 使用通用模型识别当前技能的语义引导，将该引导转换为二维视觉轨迹，并使其动作策略以生成的轨迹渲染观测为条件。该设计将语义目标获取、轨迹生成和底层动作执行分离，使高层引导能够传递到机器人动作。GT-VLA 采用混合专家架构，并配备技能特定的轨迹模块和动作模块，以实现稳健执行。我们在 LIBERO 和物理机器人平台上评估 GT-VLA，表明在两种设置下均比近期 VLA 基线具有更好的泛化能力。代码和额外补充材料可在我们的项目网站 https://ivaniz.github.io/gt-vla/ 获取。

## Abstract
Vision-Language-Action (VLA) models have shown strong performance on robotic manipulation, but they often struggle to generalize to unseen tasks, configurations, and long-horizon settings. A key challenge is that VLAs overfit to training scenes and fail to follow novel language instructions. Off-the-shelf vision-language models (VLMs) often provide stronger generalization, but cannot directly control robot actions. To combine the common sense of VLMs with VLA control, we propose Guided Trace VLA (GT-VLA), a steerable framework that accepts guidance from an external generalist VLM through trace-conditioned action generation. GT-VLA uses a generalist model to identify semantic guidance for the current skill, converts this guidance into a 2D visual trace, and conditions its action policy on the resulting trace-rendered observation. This design separates semantic target acquisition, trace generation, and low-level action execution, allowing high-level guidance to propagate to robot actions. GT-VLA uses a Mixture-of-Experts architecture with skill-specific trace and action modules for robust execution. We evaluate GT-VLA on LIBERO and a physical robot platform, showing improved generalization over recent VLA baselines in both settings. The code and additional supplemental materials are available on our project website at https://ivaniz.github.io/gt-vla/.

## 一、核心问题与研究动机

- **背景**：视觉-语言-动作（VLA）模型将感知、规划、控制统一到单一策略中，在分布内操作任务上表现出色。
- **核心痛点**：
  - VLA 容易过拟合训练场景，倾向于重复记忆中的行为，无法适应新颖语言指令或未见配置。
  - 长时程（long-horizon）任务组合下泛化能力显著下降。
  - 通用视觉-语言模型（VLM）泛化能力强、常识丰富，但无法直接输出机器人动作。
- **现有方案的不足**：
  - 任务分解为原子子任务或调用通用 VLM 做运行时引导，虽能提升鲁棒性，但高层语义信号常被底层控制器忽略。
  - 分层设计（如 embodied chain-of-thought）有用但不充分，缺乏将引导传递到动作生成层的机制。
  - 部分方法需微调高层 VLM（如 LoHo-Manip），成本高且绑定单一模型。
- **整体含义**：需要一条**可引导的执行流水线**，把外部语义引导真正传播到机器人动作生成中，从而在保留 VLA 底层控制能力的同时提升泛化性与可解释性。

## 二、方法论

### 2.1 核心思想
- 将系统拆为三层：**语义目标获取 → 2D 视觉轨迹生成 → 轨迹条件化动作执行**，实现高层意图与底层控制的解耦。
- 用现成通用 VLM 提供稀疏语义引导，再转成稠密的图像空间轨迹，作为动作策略的可视化条件信号。

### 2.2 关键技术细节

**（1）技能接口与语义目标获取**
- 定义有限技能库 S，每个技能为半结构化算子（如 `PLACE(bowl, table)`）。
- 查询通用 VLM Φ 得到技能规划：P = Φ_plan(ℓ, o_t) = (s^(1), …, s^(k))。
- 每个技能开始时，再查询 VLM 得到归一化图像坐标下的语义目标：g^(i) = Φ_target(ℓ, o_t, s^(i)) ∈ [0,1]²。

**（2）目标条件轨迹生成**
- 定义真值剩余轨迹 τ*_t = (x_t, x_{t+1}, …, x_{t_end})，沿弧长线性重采样为固定长度 H。
- 轨迹预测模型 π_τ(τ_t | o_t, x_t, g^(i), ℓ^(i))，语言输入 ℓ^(i) 拼接全局指令与技能指令。
- 用**条件流匹配（conditional flow-matching）**实现，损失为预测速度场与噪声-真值差之间的 L2：
  - L_trace = E[‖v̂ − (ϵ − τ̄*_t)‖²₂]，其中 v̂ = v_θ(τ̄*_t(1−λ)+ϵλ, λ, o_t, x_t, g^(i), ℓ^(i))。
- 两个约束：以**图像修复（inpainting）**方式钳制轨迹起点为当前末端执行器位置 x_t；通过 **AdaRMS 条件化**注入语义目标。

**（3）鲁棒轨迹条件动作学习**
- 动作专家为流匹配模型：π_act(A_t | overlay(o_t, τ_t), ℓ^(i))。
- 三种数据增强（互补而非冗余）：
  - **随机场景丢弃**：随机遮罩场景观测但保留轨迹，迫使策略从轨迹引导中行动，降低对训练场景的记忆依赖。
  - **随机轨迹丢弃**：随机移除轨迹叠加，保留从原始图像与机器人状态推理的能力，缓解 2D 轨迹在深度/遮挡/接触几何上的误导。
  - **低频轨迹扰动**：对训练轨迹施加平滑低频噪声，弥合训练真值轨迹与推理生成轨迹之间的分布差距。

**（4）Trace-Action Mixture-of-Experts（TA-MoE）**
- 基于 Gemma 2B 预训练检查点作为共享 VLM 骨干。
- π_τ 与 π_act 均为小专家 Transformer，通过确定性路由选择当前技能对应的专家（技能专属 MoE）。
- 参数规模：动作专家每个约 300M，轨迹专家约 60M；另接轻量 MLP 头预测技能进度 p_c ∈ [0,1]。
- 动机：PICK 与 PLACE 轨迹相似但动作不同，需技能专属专家消除歧义。

**（5）推理流程（Algorithm 1）**
- 输入：指令 ℓ、初始观测、轨迹更新频率 f_upd、技能完成阈值 η_c。
- 步骤：规划技能序列 → 对每个技能构造技能指令并获取语义目标 → 内循环中投影末端执行器位置、生成轨迹、叠加轨迹、预测技能进度 → 若 p_c ≥ η_c 则进入下一技能，否则采样并执行动作、更新观测。
- 当前实现为**开环技能规划**，未来可扩展为闭环重规划以增强失败恢复。

## 六、主要结论与发现

- **主结果**：GT-VLA 在 LIBERO 三个 OOD 套件上均最优，平均成功率 **43.8%**，比 π0.5 高 **28.0** 个百分点、比 AtomicVLA 高 **9.9** 个百分点、比 SEAL 高 **16.5** 个百分点；在 LIBERO-Object 上优势尤为明显（41.8%）。
- **真实世界**：GT-VLA 在全部 5 个套件上优于基线，且随任务时程增加，相对 AtomicVLA 的优势扩大。
- **外部引导不足以保证可引导性**：SEAL 同样使用外部 VLM，但性能显著低于 GT-VLA，说明 VLA 本身必须被设计成能有效接受引导。
- **轨迹

条件化是引导落地的关键**：移除轨迹模块的 G-VLA 性能明显下降，说明仅把语义目标以 AdaRMS 注入动作头，并不足以把高层意图真正传递到控制层；显式的图像空间轨迹作为中间表示，充当了"可执行的语义接口"。
- **技能专属专家设计有效**：GT-VLA-single 的性能退化表明，PICK 与 PLACE 在图像轨迹上高度相似、但在动作语义上差异显著，共享动作头容易产生歧义；技能路由 MoE 能有效消除这种歧义。
- **三种数据增强互补而非冗余**：逐一移除均带来性能下降。其中随机场景丢弃影响最明显，印证了"降低对训练场景记忆依赖"的假设；轨迹丢弃提升了策略在轨迹错误或不可用时的回退能力；低频轨迹扰动则缩小了训练真值轨迹与推理生成轨迹之间的分布差距。
- **对语义目标噪声具有一定鲁棒性**：随着注入噪声半径增大，性能呈缓慢下降趋势，说明轨迹生成器对目标点定位误差存在容忍度；但当误差超过一定范围后，性能会加速退化，反映语义目标的准确性仍是流水线的关键瓶颈。
- **对高层 VLM 的替换较为稳健**：更换不同 VLM 后性能波动有限，说明 GT-VLA 的收益主要来自"可引导执行流水线"本身，而非绑定某个特定 VLM 的常识能力，方法具备较好的模型无关性与可迁移性。
- **失败模式呈现阶段性特征**：失败可归因于技能规划错误、语义目标定位错误、轨迹生成偏差以及接触密集阶段的动作执行失败。随着任务时程增加，高层规划与技能切换相关错误的占比上升，说明长时程组合场景中"语义层"仍是主要短板。

## 七、局限性与未来工作

- **开环技能规划**：当前实现一次性规划技能序列，缺乏运行时闭环重规划与失败恢复机制，一旦高层规划出错难以纠正。作者指出未来可扩展为闭环重规划。
- **依赖预定义技能库**：技能为半结构化算子，需人工定义与标注，对开放词汇、全新技能或非桌面场景的扩展能力受限。
- **2D 轨迹表示的固有局限**：图像空间轨迹不直接编码深度、遮挡与接触几何信息，在精细接触操作中可能产生误导；随机轨迹丢弃虽可缓解，但未从根本上解决。
- **推理延迟较高**：VLM 规划与引导分别约 7 s 与 5 s，且经网络调用，绝对延迟受模型、平台与网络条件影响，对实时性要求高的场景不友好。
- **真实世界评估规模有限**：仅 299 个训练回合、每套件 10 个任务 5 次试验，样本量偏小，部分消融仅 20 次试验，置信区间较宽。
- **资源报告不完整**：未说明总训练时长、总 GPU 小时数、能耗与成本，也未汇总不同实验的总训练次数。
- **对比公平性受限**：LoHo-Manip 无官方实现，为作者尽力复现；SEAL 因需高保真世界模型而未在真实平台对比，方法间并非完全对等。

## 八、总体评价与启发

- **主要贡献**：
  1. 提出"语义目标 → 2D 视觉轨迹 → 轨迹条件化动作"的可引导执行流水线，将外部 VLM 的稀疏语义引导转化为稠密的、可作用于动作生成的条件信号。
  2. 设计 TA-MoE，用技能专属的轨迹专家与动作专家消除相似轨迹下的动作歧义。
  3. 提出三种互补的数据增强，分别针对场景记忆、轨迹依赖与训练-推理分布差距。
  4. 在仿真与真实平台上系统验证组合泛化与 OOD 泛化能力。
- **方法论启发**：
  - **可引导性应作为 VLA 的一等设计目标**：外部引导的存在并不自动保证被底层策略采纳，必须设计显式机制将引导传递到动作层。
  - **中间表示的选择至关重要**：相比直接向动作头注入语义特征，图像空间轨迹更接近控制、更易被策略利用，也更可解释。
  - **解耦高层语义与底层控制**便于组件替换与独立升级，例如推理时更换 VLM 而不影响已学习组件。
- **适用场景**：需要组合泛化、可解释性与可替换高层模型的桌面操作任务；对推理实时性要求不苛刻、可接受秒级 VLM 调用的场景。
- **总体判断**：论文问题定义清晰、方法设计有针对性、实验维度较丰富且统计报告相对规范，核心论点"外部引导必须配合可引导的执行架构"得到较好支撑；主要不足在于真实评估规模、开环规划限制与 2D 轨迹表示的固有瓶颈。
