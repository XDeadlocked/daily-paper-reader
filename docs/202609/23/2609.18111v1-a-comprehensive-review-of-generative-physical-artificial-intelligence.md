## 摘要
大规模基础模型与物理实体的融合，推动了机器人学的重要进展，即生成式物理人工智能（GPAI）。这些智能体式人工智能系统能够在复杂现实场景中自主感知、推理和行动。本综述全面分析了GPAI系统，重点关注其体系结构基础、当前应用和关键局限。我们提出了五类不同方法的分类体系：用于跨平台技能迁移的机器人基础模型（RFM）；用于端到端多模态感知与控制的视觉-语言-动作（VLA）模型；用于类人运动生成的大型行为模型（LBM）；用于基于扩散模型生成时间连贯动作的扩散策略模型（DPM）；以及用于符合物理规律的仿真和数据生成的世界基础模型（WFM）。我们考察了这些方法如何互补：WFM为VLA和DPM生成训练数据，RFM实现所学策略的跨平台部署，而LBM为自然行为提供运动先验。通过自动驾驶、工业自动化、医疗机器人和人形系统等领域的实例，我们识别出显著的性能提升，并总结了在数据高效学习、仿真到现实迁移、边缘兼容架构和安全框架方面有前景的研究方向。这些见解推动了面向物联网连接环境的具身AI发展，在该环境中智能体与联网传感器、执行器和边缘设备交互。

## Abstract
The integration of large-scale foundation models with physical embodiments has led to significant advancements in robotics known as Generative Physical Artificial Intelligence (GPAI). These agentic AI systems autonomously perceive, reason, and act in complex real-world situations. This survey comprehensively analyzes GPAI systems, focusing on their architectural foundations, current applications, and key limitations. We introduce a taxonomy of five distinct approaches: Robot Foundation Models (RFMs) for cross-platform skill transfer; Vision-Language Action (VLA) models for end-to-end multi-modal perception and control; Large Behavior Models (LBMs) for human-like movement generation; Diffusion Policy Models (DPMs) for diffusion model-based temporally coherent action generation; and World Foundation Models (WFMs) for physics-compliant simulation and data generation. We examine how these approaches complement each other: WFMs generate training data for VLAs and DPMs, RFMs enable cross-platform deployment of learned policies, while LBMs provide motion priors for natural behavior. Through examples across autonomous vehicles, industrial automation, healthcare robotics, and humanoid systems, we identify significant performance improvements and summarize promising research directions in data-efficient learning, sim-to-real transfer, edge-compatible architectures, and safety frameworks. These insights advance embodied AI for IoT-connected environments where intelligent agents interact with networked sensors, actuators, and edge devices.

## 2. 论文提出的方法论

### 2.1 核心思想：按"功能角色"划分的五类分类体系

论文的核心方法论贡献是提出一个**统一分类法（taxonomy）**，把 GPAI 模型按在机器人控制流水线中的功能角色分为三大族、五小类：

| 功能族 | 模型类型 | 核心功能 |
|---|---|---|
| 生成式控制模型 | **RFM**（机器人基础模型） | 跨平台/跨任务泛化与规划，认知底座 |
| 生成式控制模型 | **VLA**（视觉–语言–动作模型） | 端到端多模态感知→动作映射 |
| 生成式控制模型 | **LBM**（大型行为模型） | 模仿学习、零样本全身控制、类人行为 |
| 生成式动作策略模型 | **DPM**（扩散策略模型） | 奖励引导、迭代去噪、时间连贯动作序列 |
| 生成式数据模型 | **WFM**（世界基础模型） | 环境建模、合成数据生成、边缘案例构造 |

**互补关系（本文强调的关键论点）**：WFM 为 VLA 与 DPM 生成训练数据；RFM 实现所学策略的跨平台部署；LBM 为自然行为提供运动先验；DPM 提供底层鲁棒控制。

### 2.2 GPAI 系统的四组件框架

- **具身（Embodiment）**：认知 + 感知 + 执行 + 连续反馈闭环；形态涵盖机械臂/夹爪、移动平台（自动驾驶、无人机）、人形机器人。
- **认知与推理**：LLM 负责高层推理与自然语言理解；VLM 将抽象推理锚定到视觉感知；VLA 实现端到端推理；扩散模型用于迭代式规划精炼。文中以"做咖啡"为例描述了从语言解析、空间推理、导航避障到精细操作与失败恢复的完整工作流。
- **执行（Actuation）**：高层计划 → 轨迹生成（考虑工作空间约束、避碰、平滑性与能效）→ 逆运动学求解（关节限位、奇异点规避）→ 底层实时控制器（位置/速度/力矩指令）。
- **感知（Perception）**：IMU、相机、LiDAR、RADAR、本体感受编码器、触觉传感器构成多模态反馈；触觉用于调节抓握力，视觉用于补偿物体位移。

### 2.3 数据基础与学习范式

- **数据类型**：传感器数据（RGB-D、音频、力/力矩、触觉、本体感受）、演示轨迹（人类或遥操作的状态–动作对）、合成数据（仿真与数字孪生）、多模态数据（文本/图像/视频/动作标签）。
- **两种数据格式**：结构化（标注轨迹，教具体技能）、非结构化（原始视频流、自然语言指令）、实时流（持续自适应）。
- **学习范式**：
  - **强化学习**：PPO、SAC（连续任务，训练稳定）；HRL（高层元控制器 + 底层控制器分层）；RLHF（人类偏好对齐）；RLAIF（用辅助模型生成偏好标签，可扩展）。
  - **监督学习**：从专家演示直接学技能，但对未见过场景适应性差、标注成本高。
  - **无监督学习**：学习物体/表面/空间关系表征，发现可供性（affordance）。
  - **自监督学习**：从数据自身生成监督信号（如预测未来感官状态、跨模态预测触觉属性），适合终身学习。
- **仿真与迁移**：MuJoCo、PyBullet、Isaac Sim；数字孪生（DT）用于部署前验证；域随机化与渐进训练缓解 sim2real 差距。

### 2.4 五类模型的架构与关键技术细节

**（1）RFM**
- 多模态编码器系统并行处理：动作输入（轨迹日志、末端位姿）、文本指令（BERT/GPT）、传感器输入（力/力矩、本体感受）、视觉输入（RGB、深度图，ViT/CNN/ResNet/EfficientNet）。
- 融合编码器（时序融合与对齐、特征对齐与投影、交叉注意力）生成统一 token 序列 → Transformer 层跨模态注意力 → 动作解码器（时序 CONV、LSTM/GRU、MLP/RNN）输出跨形态动作命令。
- **两类模型**：任务专用型（如 GraspClutter6D，精度高但不可迁移）vs 通用型（如 PaLM-E，可跨形态零样本迁移但算力与数据需求大）。
- **代表模型**：PaLM-E（语言中心式，把连续具身观测嵌入 LLM 的 embedding 空间，输出自然语言规划需外部解释执行）；Gato（统一 token 化，文本子词 / ResNet 16×16 patch / 连续动作离散化分箱 / 传感器序列化，单一 Transformer 自回归交叉熵，无需模态专用编码器）；GPT-4 作为高层规划与代码生成的认知引擎。

**（2）VLA**
- **定义特征：双模型结构**——VLM 组件负责多模态推理 + 动作生成模块（Transformer 解码器或扩散策略）。
- **处理流水线**：图像经 ViT 分块 token 化；语言经 USE 编码；本体感受状态编码器转换关节角/速度/力为时序一致 token；三路投影到共享嵌入空间 → 拼接为离散 token 序列送入 LLM 核心 → 多模态注意力层跨模态融合 → 动作解码器输出低层电机指令或高层策略原语（grasp/move/release）。
- **与 RFM 的关键区别**：VLA 将动作解码器**内置于核心架构并联合训练**，梯度可从控制目标回传至视觉编码器与语言模型；RFM 则通过后置的辅助控制头或外部策略层适配。
- **RT-1**：3500 万参数 decoder-only Transformer；USE 文本嵌入 + EfficientNet-B3 视觉 token；**FiLM 层**实现语言对视觉特征的动态调制；**TokenLearner** 基于注意力与可学习权重把 81 个视觉 token 压缩至 8 个；动作离散化为 11 维 × 256 bins（ΔPos X/Y/Z、ΔRot X/Y/Z、夹爪状态、终止信号）；700+ 任务上 67% 成功率。
- **RT-2**：把动作视为"语言"，统一 token 表示；参数规模从 RT-1 的 35M 扩至 **55B**；集成 PaLI-X（视觉理解与物体 grounding）与 PaLM-E（语言与传感器融合），通过**co-fine-tuning**（机器人数据 + 网页级多模态语料联合微调）保留通用推理能力。
- **OpenVLA**：Prismatic-7B 视觉语言骨干 + Llama 2；双视觉编码器融合 DINOv2 与 SigLIP 特征；7-DoF 动作离散为 256 bins 并在 Llama 词表中预留专用动作 token；在 29 项基准上超越 RT-2-X 且参数量少 7 倍。
- **Gemini Robotics VLA**：结合 Gemini 2.0 与 ALOHA 遥操作平台，实现双臂协同操作。

**（3）LBM**
- 定义：学习、复现并生成复杂物理动作序列，是 LLM 范式在物理行为上的延伸；训练于文本、图像、视频、传感器流的多模态数据；核心机制含 RL 以支持实时自适应。
- **架构分两阶段**：
  - **预训练阶段**：专家演示数据 + 行为嵌入（Z）引导 Actor Network 与仿真/真实环境交互生成状态–动作；**Feedback Network 提供两类奖励**——① 真实性反馈（判别器 + 判别 critic 评估动作是否"像真的"，奖励 Q_d）；② 合理性反馈（FB critic + FB 表征学习评估状态–动作转移是否物理自洽，奖励 Q_fb）；组合奖励精炼 actor 策略；Replay Buffer 存储经验迭代更新。
  - **推理阶段**：状态输入经 Embedding Neural Network 生成状态与潜在行为嵌入；Policy Network 结合潜在变量输出动作命令、预测状态、价值估计与判别器反馈。
- **Meta Motivo**：基于 **FBCPR**（Forward Backward Representations with Conditional Policy Regularization）算法的零样本全身控制；五网络架构：Forward（预测未来状态）、Actor（输出高斯分布均值，保证动作平滑）、Critic（RL 反馈）、Backward（状态→潜在表征）、Discriminator（对照无标注运动数据强制生物合理性）。

**（4）DPM**
- **核心机制：迭代去噪**——从高斯噪声 A^K_T 出发，经 N−K 步去噪循环，每步由 CNN 或 Transformer 策略网络预测噪声 ε，逐步精炼出动作序列（A_T, A_{T+1}, …），而非直接预测动作。
- **条件化**：多模态观测（本体感受 + 点云/RGB-D）经多模态 Transformer 编码器生成观测嵌入 O_t，用于条件化扩散策略；**FiLM 层**在去噪网络各层做通道级调制，使视觉观测与文本目标影响所有层的注意力权重；交叉注意力整合历史相机帧与本体感受信号。
- **关键优势**：
  - 生成 **4–8
