## 摘要
近年来，视频生成模型的进展使得高保真、时间连贯的视频生成成为可能。然而，这些模型往往难以满足需要专业知识、特定身份、物理一致性或有序事件的提示。本文提出 VideoGen-Agent，一种通过多任务智能体强化学习训练的多模态智能体，用于利用外部工具进行视频生成。该智能体通过多轮交互协调增强、生成和验证工具，并利用提示和中间观测来指导其决策。我们在涵盖六类任务的类别均衡数据集上训练一个共享策略。在教师生成的轨迹上进行监督微调，以建立工具使用行为，随后通过强化学习对其进行优化。一种类别感知的混合奖励用于评估工具调用的有效性、任务适宜的工具使用以及生成视频的质量。我们进一步提出 VABench，一个包含 600 个提示的留出基准，涵盖程序性知识、单实体和多实体身份保持、物理一致性、场景构图以及多镜头时序结构。在 VABench 上，VideoGen-Agent 相比其基础文本到视频生成器提升了 19.1 分，从 56.5 提升至 75.6。升级生成工具后，无需额外训练智能体，分数可进一步提升至 86.1。在 84.3% 的比较中，人类评分者更偏好升级后的配置，而非最强的独立基线。这些结果支持在各类视频生成任务中学习工具使用，并表明训练后的智能体能够受益于生成工具的后续进展。

## Abstract
Recent advances in video generative models have enabled high-fidelity, temporally coherent video generation. However, these models often struggle to satisfy prompts requiring specialized knowledge, specific identities, physical consistency, or ordered events. In this paper, we present VideoGen-Agent, a multimodal agent trained through multitask agentic reinforcement learning to use external tools for video generation. The agent coordinates augmentation, generation, and verification tools through multi-turn interactions, using the prompt and intermediate observations to guide its decisions. We train a shared policy on a category-balanced dataset spanning six tasks. Supervised fine-tuning on teacher-generated trajectories establishes tool-use behavior, which is then refined through reinforcement learning. A category-aware hybrid reward evaluates tool-call validity, task-appropriate tool use, and generated video quality. We further introduce VABench, a held-out benchmark of 600 prompts covering procedural knowledge, single- and multi-entity identity preservation, physical consistency, scene composition, and multi-shot temporal structure. On VABench, VideoGen-Agent improves over its base text-to-video generator by 19.1 points, from 56.5 to 75.6. Upgrading the generation tools further raises the score to 86.1 without additional agent training. Human raters prefer the upgraded configuration over the strongest standalone baseline in 84.3% of comparisons. These results support learning tool use across video-generation tasks and show that the trained agent can benefit from subsequent advances in generation tools.

## 一、核心问题与研究动机

- **背景**：扩散式与自回归式视频生成模型（CogVideoX、Wan、Seedance 等）已能生成高保真、时序连贯的视频，视觉质量接近实拍。
- **核心痛点**：视觉质量 ≠ 提示忠实度。现有文生视频（T2V）模型依赖预训练知识，在以下场景系统性失败：
  - **专业知识**：无法准确呈现具名动作/工艺（如太极拳“白鹤亮翅”的具体招式）；
  - **身份保持**：无法还原具名人物、角色、地标、品牌物体的外观，多实体共现更难；
  - **物理一致性**：碰撞、自由落体等运动违反基本物理规律；
  - **有序事件**：多阶段时序提示常出现阶段缺失或顺序错乱。
- **动机**：单一生成模型难以覆盖异构能力需求，需引入**外部工具与反馈**。已有智能体式方案（如 VISTA 的测试时自改进、Newton 的物理规划）多针对**单一目标**，缺乏跨异构任务统一学习工具使用的范式。
- **整体含义**：论文主张以**多任务智能体强化学习**训练一个共享策略，统一协调“增强—生成—验证”三类工具，并验证该策略可**无缝受益于后续生成工具的升级**（无需重新训练），为工具增强视频生成提供可扩展范式。

## 二、方法论

### 2.1 核心思想
- 给定提示 $x$，共享多模态策略 $\pi_\theta$ 通过多轮 **推理—行动—观察**（reasoning–action–observation）循环生成视频：推理历史 $H_t$ → 选择工具及参数 → 执行得观察 $o_t$ → 更新历史 $H_{t+1}$。
- 工具箱分三类：
  - **增强（Augmentation）**：文本检索、图像检索、代码物理仿真；
  - **生成（Generation）**：T2V、I2V（首帧）、R2V（多参考图）、M2V（运动/光流条件）；
  - **验证（Verification）**：Grounding DINO 目标检测、Depth Anything V2 深度估计。
- 终止条件：所有阶段均已生成且验证分数达阈值 $\eta$；否则拼接（Assemble）各段为最终视频。

### 2.2 六类任务与默认工作流（Table 1）
| 任务 | 工具 | 默认工作流 |
|---|---|---|
| 程序性知识 PK | Search-Text, T2V | 检索→T2V |
| 单实体身份 SI | Search-Image, R2V/I2V | 检索→R2V 或 I2V |
| 多实体身份 MI | Search-Image, R2V | 检索×N→R2V |
| 物理仿真 PS | Code, M2V | 仿真→M2V |
| 构图场景 CS | T2V, ObjDet, Depth | T2V→验证→（必要时）重生成 |
| 多镜头 MS | T2V, ELF, I2V | T2V→（抽末帧→I2V）×（K−1） |

### 2.3 数据构建
- 用 Claude Opus 4.7 批量生成六类训练提示，并补充公开数据集样本；刻意简化非目标维度以突出目标能力。
- 教师智能体（Gemini 3.1 Pro 或 Claude Opus 4.7）生成完整工具使用轨迹（推理、工具调用、观察、最终视频）。
- 共 **24K 条轨迹**：**16K 用于 SFT**，**8K 提示留给 RL**（RL 时由策略自行采样新轨迹）。

### 2.4 两阶段训练
- **阶段一 SFT**：标准下一 token 预测，学习工具使用行为；失败动作片段从 loss 中掩码但保留在上下文中，使恢复行为也能被监督。得初始策略 $\pi_{\theta_0}$。
- **阶段二 Agentic RL（GRPO）**：每个提示采样 $n$ 条 rollout，仅 agent 自身生成的 token 参与策略目标，工具返回 token 掩码；因外部工具错误而彻底失败的轨迹被排除。

### 2.5 关键公式与机制
- **混合奖励**（式 1）：
$$R(\tau,x,c)=\lambda_f R_{\text{format}}+\lambda_v R_{\text{vlm}}+\lambda_t R_{\text{tool}},\quad (\lambda_f,\lambda_v,\lambda_t)=(0.1,0.5,0.4)$$
  - $R_{\text{format}}$：`<think>` + 单个合法 JSON `<tool_call>` 或 `<answer>` 格式校验；
  - $R_{\text{vlm}}$：按类别专属 rubric 的 VLM 打分加权和（见 A.5，PS 类别另含 0.20 权重的代码量化检查）；
  - $R_{\text{tool}}$：类别相关的工具选择与**输出利用度**检查（如检索证据是否写入 T2V 提示、仿真光流是否传给 M2V、验证反馈是否触发接受/重生成）。
- **组相对优势**（式 2）：$\hat A_i = (R_i-\text{mean})/(\text{std}+\epsilon)$。
- **任务级优势归一化**（式 3，借鉴 AgentRL）：按类别 $c$ 在全局 batch 内对 token 优势再次标准化，$\tilde A_{i,k}=(\hat A_i-\mu_c)/(\sigma_c+\epsilon)$，使不同任务的优势尺度可比（跨数据并行 worker 聚合统计）。
- **Token 级 GRPO 目标**（式 5）：非对称裁剪 $\epsilon_{lo}=0.2,\ \epsilon_{hi}=0.28$，KL 正则 $\beta_{KL}=10^{-3}$ 指向固定 SFT 参考策略 $\pi_{\text{ref}}=\pi_{\theta_0}$。

### 2.6 自定义物理仿真器（附录 A.4）
- Python 库 `collision_sim` / `freefall_sim` / `bottle_sim`：平面刚体运动，支持球、立方体、长方体、三棱柱；惯性矩按形状解析计算；圆—凸多边形接触检测 + 冲量法响应（含恢复系数 $e$、切向旋转耦合）；前向欧拉积分；输出 832×480、5 s、24 fps 的纯运动视频与光流视频。

## 六、主要结论与发现

- **核心增益**：Toolset 1 下总体 **56.5 → 75.6（+19.1）**，超过最强独立基线 Seedance 2.0（73.2）2.4 分；Toolset 2 下达 **86.1**，六类**全部第一**。
- **工具升级的免费红利**：策略冻结、仅替换生成工具（未在训练中出现过），分数从 75.6 → 86.1，多实体身份提升最大（65.3 → 86.7），证明学习到的工具使用策略与生成模型进步**互补**。
- **类别差异**：相对 Seedance 2.0，增益最大的是多镜头（+25.7）、多实体身份（+17.7）、程序性知识（+14.1）；构图场景增益最小（+2.9），因基线已达 87.8，说明**工具增益取决于提示所需能力**。
- **消融结论**：
  - 提示重写仅 +0.8，零样本工具使用仅 +3.0 → 单纯“给工具”不足以解决；
  - SFT 提升至 69.2，RL 再 +6.4 → 两阶段均有贡献；
  - 移除 VLM 奖励降至 73.3，移除工具奖励降至 71.2 → 工具奖励贡献更大；
  - 单任务 RL 76.3 略高于多任务 75.6（+0.7），但多任务以**单策略**达成相近总体性能，且在后三类上更优。
- **人类偏好**：升级配置相对 Seedance 2.0 的总体偏好率 **84.3%**，程序性知识与多镜头优势最大。
- **泛化与扩展**：agent 在未见任务组合（具名角色 + 专门动作）上自发组合文本检索与图像检索；中途接入 π0.5 + Ctrl-World 的机器人操作流程亦可行。

## 七、优点与亮点

- **统一的多任务智能体框架**：首次将六类异构视频生成能力统一到单一共享策略中，用工作流指引而非硬编码分支协调三类工具。
- **类别感知混合奖励设计精巧**：格式、工具利用、视频质量三维解耦；工具奖励检查的是**输出是否被真正使用**（如检索证据写入提示、光流传给 M2V），而非简单计数工具调用，抑制了“刷工具”行为。
- **任务级优势归一化**：在组相对优势之上再做类别标准化，解决六类奖励尺度不一致导致的多任务学习信号失衡，工程价值高。
- **工具接口抽象带来的可插拔性**：训练与评测使用不同工具集，验证了“策略与生成模型解耦”的实用主张。
- **严谨的评测闭环**：自建留出基准 + 类别专属 rubric + 人类偏好 + judge 对齐分析 + 定性对比，多层验证。
- **物理仿真器开源式给出**：附录提供完整冲量法碰撞代码，可复现性强。
- **系统提示工程详尽**：附录 A.3 给出完整工具协议、坐标约定、速度量级建议与各工作流重试规则，对后续研究有直接参考价值。

## 八、不足与局限

- **工具依赖与成本**：性能受生成工具质量与延迟制约；迭代式多轮交互（含检索、仿真、验证、重生成）推理成本高，论文未量化端到端时延与费用，实际部署可行性存疑。
- **验证

- **验证工具能力有限**：仅用目标检测（Grounding DINO）与深度估计（Depth Anything V2）做构图类验证，缺乏对时序连贯性、物理合理性、身份一致性的细粒度自动校验；验证器一旦误判（假阳性）会过早接受劣质片段，假阴性则触发无谓重生成，论文未分析验证器的精度—收益曲线。
- **教师模型与评测器同源**：训练轨迹由 Gemini 3.1 Pro / Claude Opus 4.7 生成，主评测器又是 Gemini 3.1 Pro，存在教师偏好被策略内化、再被同源评测器“奖励”的循环风险，跨评测器（如 Qwen3-VL、GPT-4o 做 judge）的主结果缺失。
- **VABench 的构建偏差**：提示由 LLM 批量生成并“刻意简化非目标维度”，可能使基准比真实用户请求更“干净”，弱化了多能力耦合场景下的难度；且仅 600 条、每类 100 条，统计功效有限，未报告题目难度分布或与人类创作提示的分布对齐分析。
- **多任务未显著超越单任务**：单任务 RL 在总体指标上略高（76.3 vs 75.6），论文以“单策略、部署成本低”作为辩护，但缺少参数效率、推理开销、跨任务迁移增益的量化对比，多任务学习在该设定下的净收益尚不牢固。
- **工具选择空间偏窄**：工具箱规模小（约 8 个工具），每个任务类别有近乎固定的默认工作流，策略的“自主规划”更多体现在参数填充与重试决策上；对真正开放的工具发现、组合搜索、失败归因等智能体核心能力考验不足。
- **泛化实验为“可行性演示”而非系统评估**：机器人操作（π0.5 + Ctrl-World）与未见任务组合仅给出少量定性示例，没有在统一基准上量化成功率、样本量或失败模式统计。
- **训练细节与成本报告不全**：未披露总训练时长、能耗、工具服务调用成本（检索/仿真/生成 API 次数与费用），使复现与工业落地的性价比评估受限。
- **长视频与细粒度时序未深入**：多镜头任务仅覆盖有限镜头数，未讨论分钟级长视频、镜头间一致性漂移、音画同步等更困难的问题。

## 九、方法层面的可迁移启示

- **“工作流即先验”**：用少量任务类别—默认工作流的映射为 RL 提供结构化搜索空间，既降低探索难度，又保留策略在重试与参数选择上的自由度，适合其他多工具智能体场景（如文档处理、科研自动化）。
- **奖励解耦 + 使用度检查**：将“格式合规”“工具被真正利用”“最终产物质量”分开建模，尤其把工具奖励设计为**输出被下游消费**的证据，可有效抑制工具刷量与无效调用。
- **跨任务优势归一化**：当不同子任务奖励量纲/难度差异大时，在组相对优势之上做类别级再标准化，是稳定多任务 GRPO 的实用技巧。
- **策略—工具解耦的工程价值**：把生成模型封装为可替换工具，使策略能“免费”吃到基座模型迭代红利，这对快速演进的生成模型生态尤为关键。

## 十、总体评价

论文的核心贡献不在单个生成模型，而在**范式层面**：把文生视频从“一个模型解决所有提示”转变为“一个共享策略调度增强—生成—验证工具链”，并用多任务智能体 RL 把这一流程训练成可复用、可升级、可扩展的能力。其最强证据是**策略冻结、仅换更强生成工具即从 75.6 涨到 86.1**，这为“工具增强生成”提供了清晰的可扩展性论证。奖励设计（三维混合 + 使用度检查）与任务级优势归一化是两个可直接借鉴的技术点。

主要短板集中在**评测可信度与成本透明度**：教师模型与主评测器同源、基准自建且规模有限、缺乏方差与显著性检验、人类偏好样本偏小、端到端延迟与费用未量化。因此，结论方向（工具链 + agentic RL 有效）可信，但**增益幅度的精确性与泛化边界的稳健性仍需独立第三方评测验证**。
