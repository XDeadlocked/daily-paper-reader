## 摘要
世界动作模型（World Action Models, WAMs）利用视频生成模型预测机器人操作中的未来视觉动力学，但迭代去噪会为闭环控制引入额外延迟。我们通过实验发现，视觉内容在去噪过程中以不同速率收敛。静态背景结构较早形成，而夹爪与被操作物体在第一步之后仍然模糊，其交互动力学只有通过后续去噪才逐渐显现。因此，简单地将多步视频模型截断为一步虽能保留场景结构，却会丢失对操作最为关键的以交互为中心的动力学。为解决这一问题，我们提出 DIDO，它将多步视频模型收敛后的动力学蒸馏到单步去噪中。DIDO 将分布匹配蒸馏与以交互为中心的表征引导相结合。除了将多步生成压缩为一次前向传播外，DIDO 还利用有监督的边界框视觉推理 token 显式建模夹爪、被操作物体及其交互。此外，DIDO 将目标物体在多个模型层中的表征与预训练 DINOv3 编码器的特征对齐。这种以交互为中心的引导有助于蒸馏模型在单步中同时保留相关实体及其未来动力学，同时显著降低推理延迟。DIDO 在 LIBERO 上达到 99.0% 的平均成功率，在 LIBERO-Plus 上达到 76.6%，在 RoboTwin 上达到 92.0%，并展示了向真实机器人操作中的长时程任务与泛化任务的有效迁移。

## Abstract
World Action Models (WAMs) use video generation models to predict future visual dynamics for robotic manipulation, but iterative denoising introduces additional latency for closed-loop control. We empirically find that visual content converges at different rates during denoising. Static background structure forms early, whereas the gripper and manipulated object remain blurry after the first step, with their interaction dynamics emerging only through subsequent denoising. Consequently, naively truncating a multi-step video model to one step preserves scene structure but loses the interaction-centric dynamics most critical for manipulation. To address this issue, we propose DIDO, which distills the converged dynamics of a multi-step video model into a single denoising step. DIDO combines distribution matching distillation with interaction-centric representation guidance. Beyond compressing multi-step generation into one forward pass, DIDO explicitly models the gripper, manipulated object, and their interaction using supervised bounding-box visual reasoning tokens. Additionally, DIDO aligns the target object's representations across multiple model layers with features from a pretrained DINOv3 encoder. This interaction-centric guidance helps the distilled model preserve both the relevant entities and their future dynamics in a single step, while substantially reducing inference latency. DIDO achieves an average success rate of 99.0\% on LIBERO, 76.6\% on LIBERO-Plus, and 92.0\% on RoboTwin, while also demonstrating effective transfer to long-horizon and generalization tasks in real-world robotic manipulation.

## 一、核心问题与整体含义（研究动机与背景）

- **背景**：视觉-语言-动作模型（VLA）已能根据当前观测与语言指令直接预测动作，但大多不显式建模环境在机器人动作下的演化。世界动作模型（WAM）通过视频生成模型预测未来视觉动力学，为策略提供显式“预知”能力。
- **核心矛盾**：WAM 依赖迭代去噪生成未来帧，这为闭环控制引入了显著的推理延迟。一个自然的加速思路是截断去噪、仅用一步或几步的早期表征，但这一步究竟保留了多少动力学信息尚不明确。
- **关键实证发现**：作者对去噪轨迹（解码视频与潜表征）进行观察，发现明显的时空不对称性——
  - 静态背景结构在第一步后已基本成形；
  - 夹爪与被操作物体在第一步后仍模糊，其**交互动力学**只有在后续去噪步骤中才逐步锐化并空间局部化。
- **问题定义**：朴素地将多步视频模型截断为一步，会保留场景结构却丢失对操作最关键的“交互中心动力学”（interaction-centric dynamics）。
- **整体含义**：DIDO 旨在将多步视频模型**收敛后的动力学蒸馏进单步去噪**，并显式引导模型关注夹爪—物体交互，从而在保持低延迟的同时恢复操作关键动态。

## 二、方法论

### 2.1 核心思想

- 将四步视频教师模型的收敛输出分布蒸馏为单步生成器，同时通过**交互中心视觉推理**（显式建模物体、夹爪及二者交互）和**多层视觉对齐**（DINOv3 特征）补偿早期去噪丢失的交互动态。
- 整体为两阶段训练：Stage I 学习单步交互中心动力学；Stage II 将单步世界模型与动作专家耦合进行联合策略学习。

### 2.2 关键技术细节

- **单步世界动力学蒸馏（Stage I 核心之一）**
  - 基于 Wan2.2-TI2V-5B，先微调为机器人域四步教师，再用分布匹配蒸馏（DMD）蒸馏为单步生成器。
  - 优化目标为最小化学生与教师扰动分布之间的 KL 散度：`L_DMD = E_t [D_KL(p_θ,t ∥ p_T,t)]`。
  - 梯度通过真实/虚假分数网络之差估计，无需对抗判别器；教师分数在 `{1000, 750, 500, 250}` 时间步上采样对齐。
  - 推理时丢弃分数网络，仅保留单步生成器。

- **交互中心视觉推理**
  - 引入四组 token：`T_inter = [T_obj; T_int; T_grip; T_align]`，分别表示目标物体、夹爪—物体交互、夹爪、物体中心视觉对齐。
  - **轨迹监督**：夹爪分支 `[T_grip; T_int]` 与物体分支 `[T_obj; T_int]` 共享交互 token，分别预测未来 `H_a` 步边界框；损失为 smooth-L1 + GIoU 加权和，`L_inter = λ_obj L_box(b_obj) + λ_grip L_box(b_grip)`。
  - **多层视觉对齐**：用冻结 DINOv3 编码目标物体裁剪区域的特征，在若干视频 Transformer 层上将 `T_align` 的表征投影后与之对齐，`L_align` 为多层 L1 损失。
  - 标注自动从演示中生成，无需人工标注。

- **交互感知动作预测（Stage II）**
  - 通过 mixture-of-transformers 架构将动作专家与视频模型耦合，动作专家直接访问视频模型内部表征，无需解码未来视频再编码。
  - **动态 token 精炼**：将空间特征图划分为 4×5 网格（每区域 2×2 细粒度单元），按当前帧与未来帧 value 特征的差异计算动态分数，保留动态最强的 top-3 区域全分辨率 token，其余区域 2×2 平均池化，减少冗余。
  - **流匹配动作生成**：在视频模型表征条件下，动作专家用流匹配生成 `H_a` 长度动作块，损失为 `L_act = E ∥v_θ(a_τ, τ) − u∥²`。

- **训练策略**
  - Stage I：`L_stage1 = L_DMD + L_inter + λ_align L_align`。
  - Stage II：`L_stage2 = λ_video L_video + λ_act L_act + L_inter + λ_align L_align`，视频生成目标保留以维持预测能力，DMD 仅在 Stage I 使用。
  - 语言 tokenizer、VAE、DINOv3 编码器冻结。

## 六、主要结论与发现

- **去噪过程存在渐进式动力学涌现**：后几步去噪暴露更多动作相关动态，LIBERO 上从 97.7% 提升至 98.4%，LIBERO-Plus 上从 71.4% 提升至 72.6%。
- **单步蒸馏 + 交互引导有效恢复关键动态**：累积消融显示，单步蒸馏将 LIBERO/LIBERO-Plus 提升至 98.3%/72.3%，加入交互推理达 98.9%/75.9%，再加动态精炼达 99.0%/76.6%。
- **主要结果**：LIBERO 平均成功率 **99.0%**（SOTA），LIBERO-Plus **76.6%**（最优），RoboTwin **92.0%**（无 embodied pretraining 方法中最优，仅比 LingBot-VA 低 0.2 个百分点）。
- **真实世界泛化**：基础协议 80.8 分，高级协议（含视觉干扰）66.0 分，均优于 π0.5 与 Fast-WAM，且从基础到高级的退化更小（14.8 vs 21.2/20.8）。
- **效率优势**：相比四步教师延迟降低 32%，相比 Fast-WAM 仅多 28 ms，但在 LIBERO-Plus 上高出 25.1 个百分点。
- **交互 token 被高效利用**：交互中心 token 仅占缓存 token 的 5.74%，却贡献 33.9% 的动作归因，单 token 富集度约 5.9×。

## 七、优点

- **问题洞察清晰**：通过解码视频与潜表征的实证观察，揭示去噪过程中“静态结构早成、交互动态晚成”的不对称性，为单步蒸馏提供了明确动机。
- **方法设计有针对性**：不是简单压缩，而是用交互中心 token（物体/交互/夹爪/对齐）与轨迹监督、DINOv3 多层对齐显式补偿早期去噪丢失的信息。
- **效率与性能兼顾**：单步推理在保持接近 imagination-free 方法效率的同时，显著提升分布偏移下的鲁棒性。
- **动态 token 精炼**：基于 value 特征差异自适应保留高动态区域、压缩近静态区域，在减少 132 个条件 token 的同时提升性能，尤其利于分布偏移场景。
- **实验覆盖全面**：仿真单臂/双臂、系统扰动、真实机器人长时程与泛化，并配有组件消融与 token 归因分析。
- **标注自动化**：边界框轨迹与视觉对齐目标均从原始演示自动生成，降低人工成本。

## 八、不足与局限

- **监督粒度较粗**：依赖夹爪与目标物体的边界框监督，对多物体交互、可变形物体、精细接触几何可能不足。
- **标注噪声风险**：自动检测/跟踪在严重遮挡或物体指代模糊时可能失败，引入噪声监督（LIBERO 物体框 95/100 正确，RoboTwin 181/200 正确）。
- **训练流程复杂**：包含教师准备、单步蒸馏、联合策略学习三个阶段，整体 pipeline 比直接训练动作策略更繁琐、算力开销更大。
- **依赖教师质量**：单步世界模型的预测能力受限于机器人域四步教师的质量与覆盖范围，教师未覆盖的场景可能难以泛化。
- **算力细节不完整**：未明确报告 GPU 数量，复现成本评估受限。
- **真实世界评估规模有限**：仅 4 个任务、每任务 10 次 rollout，且 Stage II 每任务单独训练策略，跨任务/跨具身的通用性仍需更大规模验证。
- **基线条件不完全对等**：部分强基线使用 embodied pretraining，而 DIDO 未使用，虽然论文明确标注，但横向比较时仍需注意条件差异。
