## 摘要
视频扩散模型具有随机性且难以控制：精确内容通常需要反复采样，且不保证成功；长时程场景在外观、交互和时间连贯性上会出现漂移。智能体视觉创作为稳定控制提供了显式参考、可编辑3D场景或可执行游戏状态，但其本身并不能保证高物体或角色保真度。将二者结合可实现稳定、高质量的生成。为实现这一结合，我们提出LynnReal-Omni，一个原生多模态视频生成框架，构建于一个32B共享多模态扩散Transformer之上，统一了文本到视频、图像条件生成、参考引导生成、结构控制、编辑、退化视频修复和长视频生成。它接受异构视觉输入，包括外观参考、可编辑3D渲染和游戏录制，使智能体能够在统一模型中组合视觉条件。我们还训练了一个专用的27B Flash共享多模态扩散Transformer，用于实时渲染。我们构建了系统化数据流水线，用于视频清洗、主体关联、多模态标注和对齐控制构建，从而得到经过整理的多镜头音视频片段语料库，并提出了MSAVP，一种包含100个提示、20项指标的评估设计，将指令遵循、生成合理性、视觉质量、时序行为和音频协调分离开来。LynnReal-Omni-Flash通过模型与解码加速进一步降低推理成本，包括轻量级VAE解码器；在单块H100上，对22帧540p视频进行预热后的生成与解码，LynnReal-Omni耗时843 ms，Flash耗时377 ms。这些结果为实时流式视频生成提供了基础，使LynnReal-Omni成为智能体视觉创作的一个统一、可控且高效的基础。

## Abstract
Video diffusion models are stochastic and hard to control: precise content often requires repeated sampling without guaranteed success, and long-horizon scenes drift in appearance, interactions, and temporal coherence. Agentic visual creation provides explicit references, editable 3D scenes, or executable game states for stable control, but does not by itself guarantee high object or character fidelity. Combining the two can enable stable, high-quality generation. To realize this combination, we present LynnReal-Omni, a native multimodal video generation framework built on a 32B shared multimodal diffusion transformer that unifies text-to-video, image-conditioned generation, reference-guided generation, structural control, editing, degraded video restoration, and long-video generation. It accepts heterogeneous visual inputs, including appearance references, editable 3D renders, and game recordings, allowing agents to compose visual conditions within a unified model. We also train a dedicated 27B Flash shared multimodal diffusion transformer for real-time rendering. We build a systematic data pipeline for video cleaning, subject association, multimodal annotation, and aligned control construction, yielding a curated corpus of multi-shot audiovisual segments, and introduce MSAVP, a 100-prompt, 20-metric evaluation design that separates instruction following, generating plausibility, visual quality, temporal behavior, and audio coordination. LynnReal-Omni-Flash further reduces inference cost through model and decoding acceleration, including a lightweight VAE decoder; on one H100, warm generation and decoding of a 22-frame 540p video take 843 ms with LynnReal-Omni and 377 ms with Flash. These results provide a foundation for real-time streaming video generation, making LynnReal-Omni a unified, controllable, and efficient basis for agentic visual creation.

## 2. 方法论

### 2.1 总体架构

- **共享多模态 DiT 主干**：50 个 Transformer 块，残差宽度 5,376，56 个注意力头（维度 128），FFN 宽度 14,336；视频隐变量 24 通道、1×2×2 patch；音频 32 输入通道；文本条件维度 5,120。实现直接建立在 MiniMax-H3（联合视频–音频 Transformer）之上。
- **统一任务**：文生视频、图像条件生成、参考引导生成、结构控制、编辑、退化视频修复、长视频生成共用同一去噪器，仅输入布局不同。
- **原生任务表示**：每个任务打包「模态标签 + 模态专属行索引 + 3D 旋转位置 + 逐行噪声时间」，一次前向同时预测视频速度与（可选）音频速度。
- **图像条件的两种接口**：统一参考布局（有序图片参考段 + 语义化的首帧指令）与原生关键帧布局（首帧/可选末帧编码进目标关键帧分区）。
- **参考与目标的时间关系**：τ_target,i − τ_control,i = Δ，Δ > 0，即参考与控制 token 保持恒定正时间偏移、共享同一隐空间几何与空间网格。

### 2.2 多任务训练与少步蒸馏

- **干净时间约定**：z_t = t·z + (1−t)·ε，速度目标 v* = z − ε。
- **噪声调度**：视频噪声水平 s_v = 3u/(1+2u)，u = Sigmoid(g)，g∼N(0,1)，t_v = 1−s_v；音频经中间水平 s_b = s_v/(12−11 s_v) 再映射为 s_a = 3s_b/(1+2s_b)，t_a = 1−s_a。二者共享同一随机抽样 g，但使用独立高斯噪声。
- **损失**：L = MSE_V(e_v, z_v−ε_v) + 0.1·I_valid_audio·MSE_A(...)；缺失音频不当作「静音监督」。
- **引导感知拟合**：e_v = [v_c + (w−1)·sg(v_∅)]/w，w = 3，仅条件分支回传梯度；推理直接用条件预测，不额外增加无条件前向。
- **四步推理**：视频干净时间步约为 (0, 0.0270, 0.0769, 0.2000)，音频为 (0, 0.1000, 0.2500, 0.5000)，由模态专属行–时间映射决定，而非共享时间向量；第四次更新后直接推进到干净端点，无需第五次网络评估。
- **蒸馏方法**：采用低秩轨迹分布匹配（TDM）与 DMD 思路，引入冻结教师 + 全深度 fake-score critic，critic 用重要性加权、裁剪信噪比加权的干净目标回归；生成器用归一化 pseudo-Huber 代理目标；并引入 Reward Forcing 的动态视觉奖励（仅重加权视频项，音频项固定权重）。

### 2.3 Flash 变体与推理加速

- **深度削减**：保留 50 块中的 42 块，仅需 **3 次去噪评估**。
- **空间 token 压缩**：前 2 块在全 token 序列上运行以早期融合视频/文本/音频；中间 26 块对视频 token 做空间 stride=2 下采样（约降至 1/4），保留边界行/列，文本与音频 token 不压缩，保留原始时空旋转位置。
- **残差重建**：H_out = H + U(F_mid(P·H) − P·H)，U 将省略 token 的特征更新赋为同帧最近保留 token 的更新，末 14 块再全分辨率联合精修。
- **训练目标**：L_DM = mean[ρ_c(z_G − sg(z_G − d))]·sg(a)，d = ẑ_F − ẑ_T，a = max(mean|z_G − ẑ_T|, 1e-6)，ρ_c(e) = √(e²+c²) − c，c = 1e-3；另加真实数据流回归与音频区间监督（RMS 归一化 smooth-L1，双声道独立有效掩码）。
- **部署优化**：W4A8 量化（INT4 权重 + FP8 激活，精度敏感模块保持高精度）、算子融合、FA3、Triton INT8 GEMM、时间调制缓存、GPU 端 RGB 转换。

### 2.4 长视频生成（有界历史）

- **分块生成**：每块以上一块为条件生成 17 帧新画面；复用上块最后一帧 RGB 作为共享边界帧，其隐变量固定，模型预测 5 个未来隐变量并联合解码（共 18 帧 RGB），随后去掉重复边界帧；每块 4 次去噪评估，无帧插值、无曝光校正。
- **紧凑时序上下文**：最早 1 个隐帧全分辨率、最近 2 帧空间 stride=2、更早至多 8 帧 stride=4；上下文 token 总量不超过 2 个全分辨率隐帧，使注意力开销与视频长度无关；存储同样有界（满容量后保留首帧与最近帧，丢弃中间项）。

### 2.5 轻量解码器蒸馏

- **结构**：36 块教师解码器 → 26 块学生解码器，隐藏维 2048、MLP 扩展比 4，逐块从对应教师块初始化；隐变量接口（编码器、维度、空间缩放、时间结构）完全不变，可直接替换。
- **训练分布**：以 0.6 概率用编码数据隐变量、0.4 概率用生成模型隐变量；数据分支中 native-HD 与高运动样本各 0.2 概率；每片段 2–33 帧，预算 400 万像素帧；0.25 概率施加相对标准差 0.03 的高斯扰动；0.1 概率采样单帧切片；图像样本另用冻结的图像专用解码器 D_I（按重构 L1 更低者自适应选择教师）。
- **损失组成**：L = αL_rec + L_reg + λ_feat L_feat + λ_perc L_perc + m_cyc λ_cyc L_cycle + λ_src L_src + m_img λ_LPIPS L_LPIPS。
  - L_rec：L1 + 5×MSE 匹配教师重构；
  - L_reg：多尺度金字塔、梯度、高通残差、Haar 小波、小波能量、patch/瓦片边界、SSIM、时域一阶/二阶差分、空域/时域相位（默认权重见表 1，其中瓦片边界 1.50、多尺度 0.25、时域差分 0.20、patch 边界 0.20、解码器特征 0.20）；
  - L_feat：对末 3 个学生块与对应教师块做 L1，最后一块 4× 权重；
  - L_perc：冻结 DINOv2 ViT-S/14 特征；
  - L_cycle：对教师/学生重构再编码后的后验做 KL，并做 log(1+max(k,0)) 压缩，800 步后启用、每 8 次更新评估一次；
  - L_src：有配对像素时用 Charbonnier 损失直接监督（α=0.25、λ_src=2）。
- **优化**：AdamW，lr 3e-6，betas (0.9, 0.95)，eps 1e-8，无权重衰减，梯度裁剪 1；每 worker 累积 2 个单样本微批；参数与梯度 FP32、前向 BF16 autocast；100 步 warmup；训练用 272×208 矩形瓦片（重叠 0 与 16）、瓦片批 2，图像用 256×256 瓦片与 5 隐帧上下文。

### 2.6 其他组件

- **生成视频伪影的时序修复**：通过共享图像编辑接口逐帧修复，同一 seed、每帧 4 次去噪评估（T 帧共 4T 次），保持帧序与播放时序，但帧间编辑相互独立、无显式跨帧一致性约束。
- **智能体生成的 3D

- 智能体生成的 3D 场景与游戏状态作为结构条件：将可编辑 3D 场景的相机轨迹、深度/法线/分割等几何缓冲，以及游戏引擎输出的碰撞规则、角色状态与动作绑定，统一编码为结构控制 token，与视频隐变量在同一去噪器中联合建模，使显式几何与运动约束直接进入生成过程。
- **音频-视频联合生成**：视频与音频共享同一主干与噪声调度（音频为可选分支），在需要时一次前向同时输出视频速度与音频速度；缺失音频时不施加静音监督，避免模型将「无音频」误学为「静音」。
- **退化视频修复**：复用统一编辑接口，对压缩、噪声、模糊等退化输入进行条件重建，保持与生成任务相同的 token 布局，无需专用修复网络。

## 3. 评测与实验设计

### 3.1 统一评测协议

- **协议动机**：针对现有基准（VBench、VideoPhy 等）任务割裂、跨尺度聚合掩盖单维失败的问题，提出在**单一协议**下同时覆盖：多镜头连续性、动作绑定、物理合理性、可控性与音频质量。
- **评测维度**：
  - 视觉保真度与美学质量；
  - 身份/外观一致性（跨镜头、跨长时程）；
  - 动作绑定与指令遵循（含相机与角色运动）；
  - 物理合理性（物体交互、碰撞、重力等）；
  - 结构/参考可控性（3D 场景、关键帧、参考图）；
  - 音频质量与音画同步；
  - 长视频时序稳定性（漂移、伪影）。
- **聚合方式**：强调分维度报告而非单一总分，避免某一维度严重失败被其他维度高分掩盖；对长视频按时间窗口分段统计漂移曲线。

### 3.2 消融与对比

- **去噪步数与解码开销的联合评估**：对比少步蒸馏（4 步）与 Flash 变体（3 步）下，去噪与 VAE 解码各自耗时占比，验证解码器蒸馏的必要性——在去噪成本大幅下降后，解码成为主导瓶颈。
- **共享主干 vs 任务专用模型**：验证统一去噪器在多任务（T2V、I2V、参考引导、结构控制、编辑、修复、长视频）上的性能是否接近或优于专用模型，检验任务碎片化是否被有效消除。
- **参考布局消融**：对比统一参考布局与原生关键帧布局在图像条件任务上的效果。
- **Flash 压缩消融**：对比空间 token 压缩（stride=2、保留边界行列、残差重建）与不压缩版本的画质-速度权衡。
- **长视频上下文消融**：对比全历史注意力与有界历史（首帧 + 最近帧、分级 stride）在注意力开销、显存与漂移上的表现。
- **解码器蒸馏消融**：逐项验证 L_reg（瓦片边界、多尺度、时域差分、patch 边界等）、L_feat、L_perc、L_cycle、L_src 的贡献。
- **量化消融**：对比 W4A8 与全精度在画质与时延上的差异，验证精度敏感模块保持高精度的必要性。

### 3.3 预期结论（基于方法设计）

- 共享多模态 DiT 主干可在不牺牲单任务质量的前提下统一多任务；
- 少步蒸馏 + 解码器蒸馏 + W4A8 量化 + 算子融合可显著降低端到端时延，支撑实时渲染目标；
- 有界历史长视频生成可在注意力开销与视频长度解耦的条件下保持时序一致性；
- 智能体提供的显式几何/运动约束可减少重复采样、提升可控性与可重复性。

## 4. 主要贡献与意义

- **统一性**：以单一 32B 共享多模态 DiT 统一 T2V、I2V、参考引导、结构控制、编辑、修复、长视频与音频生成，消除多模型拼接与临时接口。
- **可控性**：原生任务表示（模态标签 + 行索引 + 3D 旋转位置 + 逐行噪声时间）与参考/目标恒定正时间偏移 Δ，使智能体提供的参考图、3D 场景、游戏状态可直接作为条件注入，实现显式、可重复的控制。
- **高效性**：27B Flash 变体通过深度削减（42/50 块）、3 步去噪、空间 token 压缩与残差重建、W4A8 量化、算子融合与时间调制缓存，面向实时渲染；同时指出解码瓶颈并给出轻量解码器蒸馏方案。
- **长时程一致性**：分块生成 + 有界历史紧凑时序上下文，使注意力与存储开销与视频长度无关，缓解外观漂移与光度伪影。
- **评测完整性**：提出在单一协议下覆盖多镜头连续性、动作绑定、物理合理性、可控性与音频质量的评测思路，强调分维度报告以避免掩盖单维失败。
- **定位**：作为智能体视觉创作的统一、可控、高效基座，将智能体的显式几何/运动控制与扩散模型的高保真外观生成互补结合。

## 5. 局限与展望

- **时序修复的跨帧一致性**：共享图像编辑接口逐帧修复时，帧间编辑相互独立、无显式跨帧一致性约束，可能引入闪烁；未来可引入跨帧一致性约束或时序编辑模型。
- **音频分支的可选性**：音频为可选分支，缺失音频时不施加静音监督，但音频质量与音画同步的细粒度控制仍待进一步验证。
- **有界历史的记忆取舍**：满容量后丢弃中间帧，可能在极长视频中丢失中程依赖；分级 stride 与首帧保留是折中，未来可探索可学习的记忆压缩。
- **评测协议的落地**：统一协议与分维度报告需在社区形成共识，指标定义与人工/自动评估的结合仍需完善。
- **实时渲染目标**：27B Flash 虽面向实时，但在高分辨率、长时程与多任务并发下的端到端时延仍需实测验证。
- **智能体接口标准化**：3D 场景、游戏状态、参考图等异构条件的统一编码与语义对齐，仍需与具体智能体系统协同设计。

## 6. 一句话总结

LynnReal-Omni 以 32B 共享多模态扩散 Transformer 为统一基座、27B Flash 变体为实时渲染方案，通过原生多模态任务表示、少步蒸馏、解码器蒸馏、有界历史长视频生成与统一评测协议，将智能体视觉创作的显式可控性与扩散模型的高保真生成能力结合，试图成为统一、可控、高效的智能体视觉创作基座。
