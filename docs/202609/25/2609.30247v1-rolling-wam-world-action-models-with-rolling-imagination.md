## 摘要
世界动作模型（WAMs）将动作生成与面向机器人操作的未来视觉预测耦合起来。然而，在每个重新规划周期完成联合视频-动作去噪过程会带来显著延迟，推迟动作更新并限制闭环响应能力。我们提出 Rolling-WAM，一种将联合去噪分配到连续重新规划周期中的方案。我们的方法维护一个处于交错噪声水平的视频-动作块滑动窗口。在每一步，滚动噪声调度将即将执行的动作块完全去噪以用于执行，同时部分细化更远未来的块。随着窗口随新的相机观测推进，保留的未来块继续其去噪过程。这在一段时间内分配计算成本，同时跨块边界携带不断演化的视觉-动作上下文。在 LIBERO、RoboTwin 以及真实世界的 Unitree G1 人形机器人上的评估表明，Rolling-WAM 实现了具有竞争力的操作性能。通过消除从头对整个预测时域进行去噪的需要，它相较于标准联合 WAM 实现了 4.5 倍的稳态重新规划加速。

## Abstract
World Action Models (WAMs) couple action generation with future visual prediction for robotic manipulation. However, completing the joint video-action denoising process at each replanning cycle incurs substantial latency, delaying action updates and limiting closed-loop responsiveness. We present Rolling-WAM, a formulation that distributes joint denoising across successive replanning cycles. Our method maintains a sliding window of video-action chunks at staggered noise levels. At each step, a rolling noise schedule fully denoises the imminent action chunk for execution, while partially refining farther-future chunks. As the window advances with new camera observations, the retained future chunks continue their denoising process. This distributes the computational cost over time while carrying an evolving visual-action context across chunk boundaries. Evaluations on LIBERO, RoboTwin, and a real-world Unitree G1 humanoid show that Rolling-WAM achieves competitive manipulation performance. By removing the need to denoise the entire prediction horizon from scratch, it delivers a 4.5x steady-state replanning speedup over standard joint WAMs.

# Rolling-WAM 论文深度总结

## 1. 核心问题与研究动机

- **背景**：世界动作模型（World Action Models, WAMs）将动作生成与未来视觉预测联合建模，为机器人操作提供"想象"出的视觉上下文，帮助策略预判场景演化。
- **核心痛点**：闭环控制需要机器人以最新观测反复重规划（replanning），但标准联合 WAM 在每个重规划周期都要把**整个预测时域**从纯高斯噪声去噪到干净数据，每个去噪步都要处理完整视频-动作序列，计算代价高、推理延迟大，导致动作更新滞后、闭环响应受限。
- **已有方案的不足**：
  - 测试时直接省略未来视频生成（如 Fast-WAM），牺牲了可指导动作生成的显式视觉预测；
  - 传统分块采样器在每个重规划都完整去噪新时域，而滚动时域控制只执行开头一小段，未执行的尾部被丢弃而非跨周期复用。
- **核心直觉**：借鉴 Rolling Diffusion（滚动扩散）思想，把去噪计算**分摊到连续的重规划周期**中——近期动作具体确定，远期计划保持"暂定"并随新观测不断精修，类似人类规划方式。

## 2. 方法论

### 2.1 核心思想
维护一个**交错噪声水平**的视频-动作块滑动窗口：每个周期只把即将执行的动作块完全去噪，更远的块保持部分去噪；执行后窗口前移，保留的未来块继续去噪，并追加一个高斯噪声初始化的新块。

### 2.2 问题形式化
- 预测分布：`p_θ(a_{t:t+H-1}, v_{t+1:t+H} | c_t)`，其中 `c_t = (o_t, s_t, ℓ)`（观测、状态、语言指令）。
- 将预测窗口划分为 W 个时间对齐的块 `X_j = (v^(j), a^(j))`，每块含 K 个动作，总时域 `H = WK`。

### 2.3 滚动噪声调度（关键公式）
- **滚动模式**（稳态）：`σ_j^rolling(τ) = σ((j-1+τ)/W)`，τ 从 1 降到 0。
  - 第 1 块变为干净，后续块噪声逐级升高；
  - 关键自洽条件：`σ_{j+1}^rolling(0) = σ_j^rolling(1)`，即窗口前移后每个保留块恰好处于新位置的起始噪声水平，无需重新加噪。
- **初始化模式**（episode 开始）：`σ_j^init(τ) = σ(min(1, τ + (j-1)/W))`，所有块从纯噪声起步，近端块更早开始去噪；完成时 `σ_j^init(0) = σ_j^rolling(0)`，随后转入滚动模式。
- 视频与动作在同一块内共享相同去噪步与噪声水平。

### 2.4 采样与执行流程
- 每块共 N 个去噪步（N 为 W 的倍数）；初始化阶段每步 `Δτ = -1/N`，需 N 步；稳态每周期仅需 `N/W` 步，`Δτ = -W/N`。
- 每步用 Euler 更新：`X̃_j ← X̃_j + [σ_j(τ+Δτ) − σ_j(τ)] · f_θ,j(X̃_{1:W}, σ; c_t)`，即用模型预测的流速度联合更新窗口内所有视频与动作预测。
- 第 1 块干净后执行其 K 个动作，窗口滑动：移除已执行块、保留其余预测、追加高斯噪声新块，并以最新相机观测与状态作为新条件。

### 2.5 架构与训练
- **架构**：Mixture-of-Transformers（MoT），预训练视频 Diffusion Transformer（Wan2.2-TI2V-5B）+ 轻量动作 Transformer（30 层，hidden dim 1024，约 1B 参数，权重由视频专家插值初始化）；通过掩码联合注意力在每层耦合两个专家，语言与本体感受嵌入经交叉注意力调制双方；各 token 按其块级噪声水平调制。
- **注意力掩码**：每个动作块可关注整个预测窗口的视觉特征；动作-动作注意力仅限块内；视频 token 不关注动作 token。
- **训练目标**：Flow Matching。每步采样 `τ ~ U(0,1)`，以概率 β=0.8 选滚动模式、0.2 选初始化模式；构造带噪目标 `X̃_j = (1-σ_j)X_j + σ_j ε_j`，网络预测速度，目标为 `ε_j − X_j`；总损失为各块各模态（λ_v = λ_a = 1）加权和，并用活动掩码 `b_j` 排除停留在纯噪声的初始化块。
- **默认超参**：N=10 去噪步、W=5 块、K=16 动作（稳态每周期 2 步）；移位噪声调度 `σ(τ) = ρτ/[1+(ρ-1)τ]`，ρ=5；CFG 尺度为 1。

- **性能（续）**：真机 Unitree G1 平均 85.0%，高于 Joint-WAM（78.3%）与 Fast-WAM 等基线，说明滚动去噪带来的连续重规划在真实闭环场景中确有增益。
- **效率**：相比在每个重规划周期完整去噪整段时域的标准联合 WAM，Rolling-WAM 的稳态每周期去噪步数由 N 降为 N/W（默认 N=10、W=5 时从 10 步降至 2 步），在同等执行动作数下显著降低单周期推理延迟，且动作更新更频繁、闭环更及时；效率提升以"分摊而非削减"去噪计算的方式获得，因此没有像 Fast-WAM 那样牺牲视觉预测能力。
- **窗口规模**：W 的扫描显示性能随窗口增大先升后趋平/略降，过小的 W 使未来规划过短、前瞻不足，过大的 W 则让远端块在有限的滚动预算内难以被充分去噪、并增加窗口内联合注意力的开销；存在一个较优的中间区间（默认 W=5 落在此区间）。
- **消融结论**：
  - 训练时混合滚动模式与初始化模式（β=0.8/0.2）优于单一模式，说明初始化阶段的显式监督对首个周期生成干净动作块是必要的；
  - 允许动作块关注整个预测窗口的视觉特征（跨块视觉可见）优于仅限块内，验证了"未来视觉预测指导当前动作"的建模假设；
  - 跨块动作-动作注意力（A2A）的加入收益有限甚至带来噪声，印证了块内动作一致性已足够、动作间过度耦合反而有害的设计选择。
- **总体判断**：滚动时域的思想把"丢弃未执行尾部"的浪费转化为"跨周期复用与精修"，在保持甚至提升成功率的同时改善闭环响应，是 WAM 走向实时机器人控制的一条有前景的路径。

- **误差传播**：滚动机制依赖"保留块无需重新加噪"的自洽条件，一旦条件（如观测突变、执行偏差）被破坏，暂定计划能否及时纠正、是否会累积误差，论文未做深入分析。
