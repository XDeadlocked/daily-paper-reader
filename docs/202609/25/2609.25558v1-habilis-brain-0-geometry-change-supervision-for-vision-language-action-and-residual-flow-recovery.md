## 摘要
视觉-语言-动作策略受益于几何监督，但仅凭当前帧几何并不能显式描述与操作相关的变化。这一设计源于以下目标：学习一种与具身无关的视觉接口，使其能够在机器人特定动作对齐之前，跨机器人视频和第一人称视频进行预训练。我们提出几何变化 VLA（Geometry-Change VLA，GC-VLA），它学习从当前观测预测多视角的未来-当前几何变化 token。离线帧对定义了名义上的 0.5 秒预测时域；未来观测仅用于构建训练目标。阶段 1 训练几何变化视觉-语言模型（GC-VLM）。阶段 2 引入连续 ActionExpert，并将其与机器人动作对齐，同时在 VLM 接口处停止动作流梯度。阶段 3 使这些梯度能够与 ActionExpert 联合更新可训练的 VLM 组件。阶段 4 冻结 GC-VLA 并应用几何条件残差流（Geometry-Conditioned Residual Flow，GCRF），使用二元干预路由器以及从闭环反馈中学习得到的单一有界残差速度策略。GC-VLA 在 LIBERO 上达到 95.20% 的成功率，GC-VLA 结合 GCRF 达到 99.55%。推理时使用当前观测和学到的 GC 表示，无需执行离线目标编码器。

## Abstract
Vision-language-action policies benefit from geometric supervision, but current-frame geometry alone does not explicitly describe the changes associated with manipulation. This design is motivated by the goal of learning an embodiment-agnostic visual interface that can be pretrained across robot and egocentric video before robot-specific action alignment. We introduce Geometry-Change VLA (GC-VLA), which learns to predict multiview future-current geometry-change tokens from current observations. Offline frame pairs define a nominal 0.5-second prediction horizon; future observations are used only to construct training targets. Stage 1 trains a geometry-change vision-language model (GC-VLM). Stage 2 introduces a continuous ActionExpert and aligns it with robot actions while stopping action-flow gradients at the VLM interface. Stage 3 enables these gradients to update the trainable VLM components jointly with the ActionExpert. Stage 4 freezes GC-VLA and applies Geometry-Conditioned Residual Flow (GCRF), using a binary intervention router and a single bounded residual velocity policy learned from closed-loop feedback. GC-VLA achieves 95.20% success on LIBERO, and GC-VLA with GCRF achieves 99.55%. Inference uses current observations and the learned GC representation without executing the offline target encoders.

## 2. 方法论

- **核心思想**：不重建未来观测，也不预测完整未来潜状态，而是预测**当前与未来空间表示之间的变化**：
  - \(\Delta E_{t,H}=E_{t+H}-E_t\)。
  - 该目标强调操作时域内发生变化的区域，削弱未变化场景内容的贡献。
- **几何变化目标构造**：
  - 使用离线冻结模型 **Depth Anything 3（DA3-BASE）** 生成伪深度，再用 **DINOv2-small** 提取几何表示。
  - 深度图缩放到 \(16\times16\) 网格并归一化，复制为三通道后送入 DINOv2；去掉 class token，将 patch token 调整为 \(10\times10\)，得到每视角 100 个空间位置。
  - 对当前帧与未来帧分别提取特征并作差，得到连续几何变化特征，再量化为 \(K\) 个离散码。
  - 三视角固定槽位：头部/全局、左腕、右腕，共 **300 个几何 token**；缺失视角用有效性掩码处理。
  - 预测时域为 \(H_{GC}=\text{round}(0.5f)\)，即名义 0.5 秒。
- **架构**：
  - GC-VLM 基于 **Molmo2-ER 36 层**，额外增加 **12 层 transformer block**，初始化时复制前 12 层预训练块。
  - 共享 VLM 产生多模态隐状态 \(h_t\)，GC 头预测几何变化 token。
  - **GeometryReader** 用可学习 query 池化 GC 隐状态，并通过交叉注意力残差注入部分 ActionExpert 块；输出投影零初始化，初始为 no-op。
  - ActionExpert 以流匹配方式预测连续动作流速度，条件包括隐状态、几何感知隐状态和机器人状态。
- **四阶段训练流程**：
  - **Stage 1：GC-VLM 几何预训练**。仅用当前–未来帧对和几何变化目标，不需要机器人动作。
  - **Stage 2：分离式动作对齐**。引入连续 ActionExpert，在统一双机械臂末端执行器 delta 表示上训练；动作流梯度在 VLM–ActionExpert 接口处停止。
  - **Stage 3：耦合式 VLA 适配**。移除 detach 边界，动作流梯度可更新可训练 VLM 组件与 ActionExpert。
  - **Stage 4：GCRF 残差后训练**。冻结 GC-VLA，用二元干预路由器和单一有界残差速度策略，从闭环反馈中学习选择性修正。
- **GCRF 关键公式**：
  - 上下文 \(c_t=[\bar v_{base}; g_{GC}; h_{flow}]\in\mathbb{R}^{96}\)。
  - 路由器输出 \(b_t\in\{0,1\}\)，残差修正 \(d_t=\epsilon\tanh(z_t)\)。
  - 基础动作流积分：\(x_{t,k+1}=x_{t,k}+\Delta\tau_k[v_{base}+b_t d_t]\)，\(k=0,\dots,9\)。
  - 残差在一个重规划周期内的 10 个积分步中保持恒定；后续重规划可产生新修正。
- **泄漏预防**：所有 rollout 仅使用当前观测 \(x_t\)；未来帧只是标签，不是输入。部署时不执行 DA3/DINOv2 等离线目标编码器。
