## 摘要
基于流匹配的视觉-语言-动作（VLA）策略通过反复评估动作专家来生成动作块。增加积分步数会提高推理成本，却不一定能提升闭环成功率。我们提出 Coda，将这部分积分预算的一部分重新分配给一次学习得到的端点校正。冻结策略首先完成少步的噪声到动作轨迹；随后，一个轻量级 Transformer 利用候选动作、源噪声和共享观测前缀缓存来预测一个由示范监督的残差。只有校正器需要训练。在 50 个 RoboTwin Easy 任务上，五步 Coda 相比匹配的五步基线将成功率从 71.64% 提升到 74.68%，同时相对默认十步策略将前向延迟降低 30.2%。两步配置在 2.12 倍加速下达到 71.88% 的成功率。一个独立的 13 任务对照实验在延迟几乎相同的情况下取得 5.69 个百分点的提升，表明校正可以成为额外积分步骤的有效替代。同一设计也改进了冻结的官方 SmolVLA，将两步成功率从 60.8% 提升到 69.4%。这些结果表明，端点校正改善了冻结流匹配策略的质量-延迟权衡。

## Abstract
Vision-language-action (VLA) policies based on flow matching generate action chunks through repeated evaluations of an action expert. Increasing the number of integration steps raises inference cost, but does not necessarily improve closed-loop success. We propose Coda, which reallocates part of this integration budget to a single learned endpoint correction. A frozen policy first completes a few-step noise-to-action trajectory; a lightweight Transformer then predicts a demonstration-supervised residual using the candidate action, source noise, and shared observation-prefix cache. Only the corrector is trained. On 50 RoboTwin Easy tasks, five-step Coda improves success from 71.64% to 74.68% over the matched five-step baseline, while reducing forward latency by 30.2% relative to the default ten-step policy. A two-step configuration achieves 71.88% success with a 2.12$\times$ speedup. An independent 13-task control shows a 5.69-percentage-point gain at nearly equal latency, supporting correction as an effective alternative to additional integration. The same design also improves frozen official SmolVLA, raising two-step success from 60.8% to 69.4%. These results show that endpoint correction improves the quality-latency trade-off of frozen flow-matching policies.

## 1. 核心问题与研究动机

- **背景**：基于流匹配（flow matching）的视觉-语言-动作（VLA）策略（如 π0.5、SmolVLA）通过反复调用动作专家（Action Expert, AE）将噪声逐步积分为动作块。每一步依赖上一步输出，形成串行计算链，函数评估次数（NFE）直接决定推理成本。
- **痛点**：
  - 在 A100 实测中，AE 阶段约占默认十步前向计算的 **3/4**。
  - 增加积分步数能提升成功率，但收益递减：1→5 步成功率由 59.76% 升至 71.64%，而 5→10 步仅从 71.64% 变为 71.52%（几乎停滞），延迟却上升 **61.0%**（144.7 ms → 233.0 ms）。
- **核心问题**：既然继续串行积分的收益有限，能否将部分时间与算力预算**重新分配**给一次学习得到的端点校正？
- **整体含义**：论文主张把推理计算在"候选动作生成"与"端点校正"之间重新分配，从而改善冻结流匹配策略的质量-延迟权衡，而非一味增加积分步数。

## 2. 方法论：Coda

### 2.1 核心思想

- 将**动作生成**与**端点校正**解耦：冻结策略先完成少步噪声到动作的轨迹，再由一个轻量级 Transformer 预测残差。
- 执行动作：`aexec = aθ + c∆a`，其中 `aθ` 为少步生成的候选动作，`c∆a` 为学习到的残差。
- 命名" Coda"取自乐曲的尾声段落——在完整轨迹之后附加一次校正。

### 2.2 关键技术细节

- **少步生成**：冻结 π0.5 用 N 步 Euler 积分，插值式为 `xt = tε + (1−t)a⋆`，目标速度为 `ε − a⋆`，递推为 `x[i+1] = x[i] − (1/N)·vθ(x[i], 1−i/N, zo)`，最终候选 `aθ = x[N]`。减少 N 会增大步长，节省时间但可能改变最终动作。
- **校正器条件**：`c∆a = rφ(zo, aθ, ε, tres)`，即同时利用冻结观测前缀表示 `zo`、候选动作 `aθ`、源噪声 `ε` 与固定时间条件 `tres`。
- **结构设计**：
  - 残差 Transformer 后缀读取 VLM 前缀的 KV 缓存，但前缀不读取后缀（单向桥接）。
  - 候选动作与噪声分别投影后相加作为后缀输入。
  - `tres = 0.1` 通过 AdaRMS 调制固定（与 GT-mix 近端点时间一致）；SmolVLA 实现省略该时间条件。
  - 残差后缀从冻结 AE 权重初始化，输出层**零初始化**，使初始校正为零，训练从 `aexec = aθ` 开始。
- **训练目标**：仅训练残差参数 φ，VLM 与 AE 全程冻结。监督目标为 `∆a⋆ = a⋆ − sg(aθ)`，损失为 `Lres = ||rφ(zo, sg(aθ), ε, tres) − ∆a⋆||₁`，即学习从生成候选到示范动作的总位移（包含策略偏差与粗积分效应）。
- **跨 NFE 复用**：π0.5 校正器在 Ntrain = 5 下训练，可在不同测试 NFE 下复用；SmolVLA 校正器在 Ntrain = 10 下训练，复用于 1/2/5/10 步。
- **推理成本**：`TCoda(N) ≈ Tprefix + N·TAE + Tres`，从十步降到五步 Coda 的净节省约为 `5·TAE − Tres`。

## 6. 主要结果与发现

### 6.1 主结果：质量-延迟权衡被整体推前

- 在 RoboTwin 50 个 Easy 任务上，Coda 在 **N = 5** 时即可达到甚至略优于冻结 π0.5-FT 十步积分的成功率水平，而端到端延迟显著下降；换言之，论文把原本"5→10 步几乎无收益却多付 61% 延迟"的那段预算，替换成了一次轻量残差前向。
- 在 N = 1/2/3 等更激进的操作点上，Coda 的退化速度明显慢于纯少步基线：少步积分带来的系统性偏差被残差校正部分吸收，使得低 NFE 区间的成功率曲线更平坦。这说明残差学习到的并非单纯噪声，而是与积分步长强相关的**粗积分偏差**。
- 净收益的边界由 `5·T_AE − T_res` 决定：当残差后缀成本远小于单次 AE 调用时，把 N 从 10 降到 5 几乎总是划算的；论文的延迟拆解正是为这一判据提供实证支撑。

### 6.2 近等延迟下的关键对照（13 任务面板）

- 这是全文最有说服力的实验：在 218.59 ms vs. 218.14 ms 的近等延迟条件下，"少步 + 校正"对比"多步积分"，排除了延迟差异这一混淆变量，直接检验**计算该如何分配**这一问题。
- 结果支持论文的核心主张：在相同时间预算下，把一部分计算投向学习式端点校正，比继续串行积分更有效。这构成对"NFE 越多越好"这一默认直觉的反例。

### 6.3 跨模型迁移（SmolVLA）

- 在完全冻结的官方 SmolVLA 上训练独立校正器，可在 1/2/5/10 步上复用同一组残差参数，说明方法不依赖 π0.5 的特定架构或权重。
- 跨 NFE 复用是实用层面的重要性质：训练一次校正器即可覆盖多个部署档位，无需为每个 NFE 单独训练，降低了部署侧的调参负担。

### 6.4 鲁棒性（Hard 协议）

- 在 demo_randomized_50（最小 shader、视觉随机化）下，方法仍保持相对基线的优势，说明残差校正并非只拟合干净视觉条件下的策略偏差，对观测扰动具有一定鲁棒性。

### 6.5 消融与诊断的关键信息

- **Transformer vs. MLP 校正器**：Coda-MLP 作为更廉价的中间方案，能挽回部分收益，但残差容量下降会限制可达上限，二者构成成本-质量的连续谱。
- **源噪声 ε 的输入**：+ε 与 no ε 的对比用于判断校正器是否真正在"条件于轨迹起点"，而非仅做动作空间的后处理回归。
- **Mix-AE**：把校正后动作再送一次冻结 AE，相当于"校正 + 额外积分"的混合方案；其结果用于区分"残差本身有效"与"只是多算了一次"。
- **AE-cont**：在匹配训练预算下继续训练 AE，是"把同样算力用于改策略本身"的替代路径，用于论证收益来自**推理期计算重分配**而非训练期容量增加。
- **GT-mix（特权诊断）**：使用测试时专家参考，给出方法在理想端点信息下的上界，用于估计当前校正器与"完美校正"之间的差距，属于非可部署的诊断工具。
- **开环动作误差**（128 帧 mix50）：提供不依赖闭环交互的细粒度度量，用于观察少步候选与示范动作的偏差如何被残差压缩。

## 7. 结论与启示

- **结论**：对于冻结的流匹配 VLA 策略，推理计算不应被默认为"全部投入串行积分"。将部分预算分配给一次学习得到的端点校正，能在同等延迟下获得更好的动作质量，或在同等质量下显著降低延迟。
- **方法层面的启示**：
  - 冻结主干 + 轻量后缀是一种低成本的策略增强范式：只训练极少参数（残差后缀），无需触碰 VLM 与 AE，避免了灾难性遗忘与大规模重训。
  - 零初始化输出层使训练从恒等映射出发，是让残差模块"不破坏原策略"的实用技巧。
  - 单向 KV 桥接（后缀读前缀、前缀不读后缀）在保留预训练表示的同时控制了额外计算。
- **评测层面的启示**：
  - 报告"近等延迟对照"比单纯报告"同 NFE 对比"更能回答方法是否值得部署的问题，建议成为该类工作的常规实验设置。
  - 分阶段延迟拆解（前缀 / AE / 残差）使收益来源可追溯，比只给端到端时延更有信息量。

## 8. 局限性与未来方向

- **未解耦的耦合项**：残差监督目标 `∆a⋆ = a⋆ − sg(aθ)` 同时包含策略固有偏差与粗积分效应，二者未被分离，难以判断校正器在何种情况下会学到哪一类修正。
- **时间条件的敏感性**：`t_res` 取固定值 0.1（与 GT-mix 近端点时间一致），SmolVLA 实现甚至省略该条件，说明该超参的作用机制尚缺乏系统分析。
- **训练分布依赖**：校正器需要与冻结策略候选分布匹配的数据；当部署场景偏离训练分布时，残差可能失效甚至有害，论文未给出分布外评估。
- **潜在方向**：自适应 NFE 选择、残差与积分步长的联合优化、把校正器扩展到多步递归校正、以及在真机上验证质量-延迟权衡是否依然成立。

## 9. 总体评价

- **贡献定位**：论文的贡献不在于提出新的生成模型，而在于提出一个清晰的**计算分配视角**，并用近等延迟对照等严谨实验把这一视角坐实。
- **方法简洁性**：Coda 结构轻、训练成本低、可跨 NFE 复用、可跨模型迁移，工程可行性较高。
- **证据强度**：主实验规模大（50 任务 × 6 档 NFE × 每配置 2500 episode）、配对评测、含多种替代方案与特权上界，说服力较强；主要短板在于缺少真机验证与分布外测试。
- **可复现性**：训练超参、延迟测量协议（batch size、SDPA、不编译、预热与中位数）报告较为完整，有利于复现；GPU 小时数报告不完整是小的减分项。
