## 摘要
从多具身数据集中学习大规模视觉-语言-动作（VLA）模型仍然具有挑战性，因为不同末端执行器之间的动作空间是异质的。尽管潜在动作模型（LAM）能够从多样化的视频数据中学习与具身无关的动作表示，但现有的基于图像的 LAM 往往无法捕捉细粒度的末端执行器关节运动，尤其是人类手和灵巧机器人手中的手指级几何变化。为了解决这一局限，我们提出了 GALA，一种几何感知的潜在动作建模框架，它利用 3D 末端执行器几何运动来增强基于图像的潜在动作。然而，简单地引入点云会产生细粒度动作表示，但其共享语义有限，从而阻碍跨具身预训练。为了解决这一问题，我们引入了统一末端执行器运动表示（UEMR），它在保留细粒度运动信息的同时，提高了潜在动作的跨具身泛化能力。基于 UEMR，GALA 将捕捉场景级动态的视觉潜在动作与捕捉共享细粒度末端执行器关节运动的几何潜在动作相结合，为从多具身数据（包括无动作标签的自我中心人类视频）进行 VLA 预训练提供有效监督。在细粒度运动探测、跨具身检索和下游 VLA 评估上的实验表明，GALA 能够有效建模跨具身的可泛化细粒度运动，在 RoboCasa-GR1 上达到 68.3% 的成功率，在真实世界中达到 75.5% 的成功率。代码、附录和演示见 https://puzhenyuan.github.io/GALA-website/。

## Abstract
Learning large-scale vision-language-action (VLA) models from multi-embodiment datasets remains challenging due to heterogeneous action spaces across end effectors. Although latent action models (LAMs) can learn embodiment-agnostic action representations from diverse video data, existing image-based LAMs often fail to capture fine-grained end-effector articulation, particularly finger-level geometric changes in human and dexterous robot hands. To address this limitation, we propose GALA, a Geometry-Aware Latent-Action modeling framework that augments image-based latent actions with 3D end-effector geometric motion. However, naively incorporating point clouds yields fine-grained action representations with limited shared semantics, hindering cross-embodiment pretraining. To address this issue, we introduce the Unified End-effector Motion Representation (UEMR), which preserves fine-grained motion information while improving the cross-embodiment generalizability of latent actions. Building upon UEMR, GALA combines visual latent actions that capture scene-level dynamics with geometric latent actions that capture shared fine-grained end-effector articulation, providing effective supervision for VLA pretraining from multi-embodiment data, including action-free ego-centric human videos. Experiments on fine-grained motion probing, cross-embodiment retrieval, and downstream VLA evaluation demonstrate GALA's effectiveness in modeling generalizable fine-grained motions across embodiments, achieving 68.3% RoboCasa-GR1 success rate and 75.5% real-world success rate. Code, appendix, and demos are available at https://puzhenyuan.github.io/GALA-website/.

## 1. 核心问题与研究背景

- **大背景**：视觉-语言-动作（VLA）模型（OpenVLA、π0、GR00T 等）已展现多任务、多机器人操作能力，但大规模机器人示范数据采集成本高昂。人类视频（尤其是自我中心视频）提供了互补的、高度灵巧的交互数据来源，因此联合学习人机异构数据成为重要方向。
- **核心障碍**：不同具身在运动学结构、自由度、控制参数化上差异巨大，原生动作空间难以直接共享，通常需要具身特定的对齐或重定向（retargeting），代价高且易引入误差。
- **潜在动作模型（LAM）的思路**：直接从视觉转移中推断动作表示，从而为异构机器人与无动作标签人类视频提供共享监督。但现有**基于图像的 LAM 主要捕捉场景级末端位移**，在动作幅度小、被遮挡或视角变化时，往往忽略手指级细粒度关节运动——即"只刻画末端执行器**移到哪**，而不足以刻画它**如何操作物体**"。
- **引入几何的新问题**：用点云表示末端运动虽能捕捉细粒度关节/构型变化，但直接跨具身共享几何会编码**形态与坐标系特异的线索**（形状、尺度、绝对位姿），导致潜码在不同手型与夹爪之间不共享，反而损害跨具身预训练。
- **整体含义**：GALA 旨在同时解决"细粒度运动捕捉"与"跨具身语义共享"这一对矛盾，为利用多具身数据（含无动作人类视频）预训练通用 VLA 提供可扩展基础。

## 2. 方法论

### 2.1 总体框架（两阶段）

1. **第一阶段：几何感知潜在动作学习**——从 RGB 与末端几何转移中联合学习视觉潜动作与几何潜动作。
2. **第二阶段：几何感知 VLA 协同训练**——用两类潜码通过专用 bridge token 监督 VLM，再由共享 flow-matching 动作专家配合具身特定动作头输出连续动作。

### 2.2 点云生成

- 对具身 e、手侧 h∈{L,R}、时刻 t，末端几何表示为无序点云 **P = {p_i}，N = 1024**，统一表达在**腕部/根部为中心的局部坐标系**与统一轴约定下，从对应表面几何采样。
- **人手**：用 WiLoR 从每帧 RGB 估计左右 MANO mesh 与手部关键点，变换到掌对齐的腕中心局部系后采样 MANO 表面。
- **机器人**：由 URDF/MJCF 模型取得末端几何，结合记录的关节构型经正运动学将表面采样点变换到当前位姿，聚合后重采样为 N 点；灵巧手与平行夹爪同流程。
- 关键点：**不要求跨具身的点、关节或网格拓扑对应**。

### 2.3 视觉与几何动作编码

- 输入：起止区间 (s, g) 的 RGB 观测 (I_s, I_g)、语言指令 ℓ、左右手点云对 (P^L_s, P^L_g)、(P^R_s, P^R_g)。
- 起止点云用**共享的中心与尺度归一化**，以减少跨数据集尺度差异，同时保留相对几何运动；缺失手由有效性掩码排除。
- 冻结 **DINOv2 + SigLIP** 编码 RGB，冻结 **Point Transformer V3 (PTv3)** 编码点云，特征经**共享时空 Transformer** 与语言条件融合。
- 输出两类互补潜动作：**视觉 token**（场景级动态）与**几何潜 token**（双臂 3D 几何转移）。
- 几何潜码经**共享 EMA-VQ 码本**量化：对每个 token 取最近邻码字（argmin L2），编码器与码本在人类手、灵巧机器人手、平行夹爪间共享，形成统一离散潜空间。

### 2.4 UEMR（统一末端执行器运动表示）三大设计

- **(a) 统一双臂运动潜变量**：几何潜 token 联合表示整个区间的**双臂几何转移**，而非左右手分别编码；解码时把同一潜表示分别与左右手初始几何组合，由共享几何解码器 D_G 重建各自目标几何，损失用 Chamfer Distance 并按左右手有效性掩码加权。单臂夹爪数据则把同一点云输入两个分支，便于不同臂数数据的联合建模。
- **(b) 成对一致的几何增强**：对每对起止点云施加**同一随机 3D 变换**（缩放 a、旋转 R、平移 t），使绝对坐标系被扰动而**相对几何运动保持不变**，抑制对数据集特定坐标的敏感性。
- **(c) 双向转移学习**：同时建模正向 s→g 与反向 g→s，共享编码器、码本、解码器；反向目标提供额外转移监督，但**不显式约束正反向潜码之间的关系**。
- **效果**：三者共同促使潜码编码可泛化的末端运动，而非静态形态、绝对位姿或数据集特定坐标捷径。
- **第一阶段总损失**：L_LAM = L_forward + L_backward，其中每个方向 = 视觉分支的 VQ 三项（重建 / 码本 / commitment）+ λ_G·几何重建（Chamfer）+ βλ_G·几何 commitment。
