## 摘要
具身规划日益依赖视觉-语言模型(VLM)将指令和视觉观察转化为可执行的动作序列。然而，流畅的规划并不总是可执行的。VLM可能引用未在视觉上观察到的对象，选择所需功能不可用的动作，或违反语法和动作约束。我们提出CLAMP，一种多模态约束锚定框架，将场景证据转化为冻结的VLM规划器的解码时约束。CLAMP利用初始观察将对象引用限制为场景支持的对象，同时提供的符号动作模型指定状态转换和目标。在解码过程中，硬掩码消除无效的下一个Token候选，而基于隐马尔可夫模型(HMM)的世界状态前视模块根据动作前置条件和目标可达性对剩余可行候选的概率进行重新加权。这使得规划器能够保留VLM的语言先验，同时防止视觉上不支持、不安全或不可行的候选进入规划。对于未见过的任务和环境，CLAMP通过从冻结的VLM中采样无标签续接，在测试时调整HMM。在VLABench、SafeAgentBench和TaPA上的实验表明，场景锚定的约束改善了对象锚定和安全性，而大多数剩余失败源于感知错误或约束规格不对齐。

## Abstract
Embodied planning increasingly relies on vision-language models (VLMs) to translate instructions and visual observations into executable action sequences. However, fluent plans are not always executable. A VLM may refer to objects that are not visually observed, select actions whose required affordances are unavailable, or violate syntax and action constraints. We introduce CLAMP, a multimodal constraint-grounding framework that turns scene evidence into decoding-time constraints for a frozen VLM planner. CLAMP uses the initial observation to restrict object references to those supported by the scene, while a provided symbolic action model specifies state transitions and goals. During decoding, hard masks eliminate invalid next-token candidates, while a Hidden Markov Model (HMM)-based world-state lookahead module reweights the probabilities of the remaining feasible candidates based on action preconditions and goal reachability. This allows the planner to retain the VLM's language prior while preventing visually unsupported, unsafe, or infeasible candidates from entering the plan. For unseen tasks and environments, CLAMP adapts the HMM at test time using label-free continuations sampled from the frozen VLM. Experiments on VLABench, SafeAgentBench, and TaPA show that scene-grounded constraints improve object grounding and safety, while most remaining failures stem from perception errors or misaligned constraint specifications.

## 1. 论文的核心问题与整体含义

- **研究动机**：在具身规划（Embodied Planning）中，视觉语言模型（VLM）常被用来把自然语言指令与视觉观察转换成可执行的动作序列。然而 VLM 生成的“流畅”规划并不天然可执行：模型可能引用场景中不可见的物体，选择当前环境不具备“affordance”的动作，或者违反任务规定的动作语法格式。
- **现有方法不足**：过去的方案大多采用生成后验证/修复（post-hoc verification / repair），无效决策可能已产生后再纠正；而约束解码（constrained decoding）虽能在生成时施加限制，但大多只针对纯语言任务或专用策略输出，难以自然融合多模态场景证据并跟踪动态世界状态。
- **核心思路/整体含义**：本文提出 CLAMP，一种多模态约束解码框架：将视觉场景证据与任务提供的符号动作模型转化为解码期约束，在**冻结的 VLM**上直接屏蔽不符合语法、视觉锚定和状态可达性的 token，再通过 HMM 做目标可达性前瞻。其关键含义是：不更新 VLM 参数，也能显著提升规划的可执行性、物体接地（grounding）与安全性。

## 2. 论文提出的方法论

- **三类核心约束**：
  - `Csyn`：语法约束，要求动作序列符合任务动作模式（schema），动作属于 `Aγ`。
  - `Cvis`：可见性约束，要求动作引用的实体均支持于初始多模态观测 `o0` 中的场景证据 `Eseen`。
  - `Crch`：可达性约束，要求序列在动作前置条件/状态转移下可执行，能在预算 `Kmax` 内到达目标任务给定的目标状态。
- **解码期 logit 组成**：下一个 token 的最终得分形如
  `ℓ̃_n(v)=ℓ_n(v)+log m_syn,n(v)+log m_vis,n(v)+log m_rch,n(v)+λG_rch,n(v)`。
  其中：
  - `m_syn`、`m_vis` 由语法 DFA 和可见性 DFA 生成前缀局部硬掩码，不符合者 logit 置为 `−∞`；
  - `m_rch` 是状态条件可执行性掩码，检查当前不完整动作前缀是否能补全成当前状态下可执行的动作；
  - `G_rch` 是 HMM 辅助的未来目标可达性得分，即从当前 token 对应的可执行动作出发、在剩余预算内到达目标状态的概率质量加权值；
  - `λ` 控制该“软”前瞻项强度，`λ=0` 时退化为纯硬约束。
- **HMM 与符号模型结合**：
  - 使用 HMM（隐状态数 H=128）对 VLM 解码中已生成 token 做前向概率估计；
  - 动作级 DFA 指定状态转移 `Δ(z,a)`、初始状态 `z0` 和目标状态 `F_rch`；
  - 通过“动作分段 HMM 对数概率” `F_a[h,h']` 与后向动态规划表 `R[K,z,h]`，计算不超出动作预算时到达目标的可能性；
  - 该方法将 token 层面的语法识别与动作层面的状态演化保持分离，而不构造二者乘积自动机，避免状态爆炸。
- **测试时适应（Test-Time Adaptation, TTA）**：
  - 在目标域或新任务上采样冻结 VLM 的无标注续接，仅更新 HMM 的发射矩阵 `B`，保持初始分布 `μ` 和转移矩阵 `A` 不变；
  - 三种层次：离线域适应（TTDA）、在线会话适应（OTTA）、逐实例小批量适应（TTBA），每个层次使用发射矩阵的局部 Baum–Welch 更新与锚定插值以避免漂移；
  - 由于 LLM token 空间可能不匹配，论文还实现了 Llama→Qwen3 的发射矩阵重映射，避免 token ID 错位导致空输出。

## 6. 论文的主要结论与发现

- **硬约束与软前瞻互相补充**：在 Qwen3-VL-8B 上，VLABench 宏平均由 baseline 28.7 提升至 +语法/可见性 DFA 的 34.1，加文本 HMM 后到 37.1，加监督视觉 HMM 后到 38.7；说明语法/可见性掩码与 HMM 目标前瞻贡献各自独立。
- **物体接地改善明显**：InternVL3.5-8B 上，实体 ID 有效性从 1.9 升到 100.0，实体 F1 从 0.9 升到 55.7，精确匹配从 0.0 升到 25.1，而技能 F1 仅小幅提升（72.0→74.3），说明增益主要来自实体层面，而非新增视觉知识。
- **安全约束执行显著减少规则违反**：SafeAgentBench 长时程任务中，符号规则违规率由 baseline 的 0.41 降至 policy+recovery 的 0.05。
- **测试时适应并非普遍有效**：TTA 的主要提升集中在 VLABench 的 Physical Laws 维度；OTTA 没有观测到额外收益；域外 HMM 甚至可能出现“单技能分布崩溃”（如全输出 open_door/press）。
- **剩余失败原因**：更多来自感知误差、任务类型不匹配、符号规格不完整或与 benchmark 不对齐，而不是解码框架本身；CLAMP 不引入新的视觉知识。
- **总体主张**：将场景证据与符号约束直接放入解码过程，可以在**不更新或缩放 VLM**的前提下，提升规划可行性、物体接地和约束满足度。

## 7. 优点

- **无需微调 VLM**：保持 planner 完全冻结，只通过解码机制施加约束，有利于迁移与持续部署。
- **多模态与场景接地一致**：将视觉观测作为约束的一部分，处理对象级可见性，而不仅仅依赖模型“看图”的隐式行为。
- **token 层与状态层分离**：不构造 token×world-state 的乘积自动机，而是让语法/可见性 DFA 作用于 token，动作级状态转移与 HMM 前视分离，兼顾表达能力与复杂度。
- **轻量、可组合的测试时适应**：只调整 HMM 发射矩阵，避免更新 VLM；对象/安全约束保持符号层面不变，有利于消融与审计。
- **系统性基准覆盖**：同时评估操作规划、视觉接地、安全、文本规划与长期任务，并使用多骨干和多种评估口径，能够较清晰地暴露“哪种约束带来哪类增益”。
- **诚实的实证边界**：论文明确区分“计划符号可执行”与“物理可执行”，讨论评分口径不一致、接口误设和 judge 敏感度，增强了结果的可解释性。

## 8. 不足与局限

- **适用范围有限**：CLAMP 只适用于能输出离散符号技能调用的 VLM 规划器；对连续动作/视觉-语言-动作模型（如 RT-2、OpenVLA、π0）不能直接使用，需要可检查的离散接口。
- **场景/感知限制**：可见性约束只基于初始观测静态建立，不具备观察记忆、主动视角选择或遮挡下软可见性建模；可能拒绝在部分遮挡下实际可行的规划。
- **符号规格与模型错误的传导**：若任务提供的 PDDL/affordance/过渡模型有错误或与 benchmark 错位，CLAMP 会强化错误内容，甚至“有信心地执行一个错误的动作模式”；BEHAVIOR GI/SD 实验中即观察到接口不匹配带来的负效果。
- **约束前瞻的独立性局限**：可达性后向 DP 在枚举未来动作时没有把未来动作的可见性 `Cvis` 纳入枚举，因此可能高估联合可行性，直至生成时可见性掩码才拒绝，造成后续 F AIL。
- **HMM 训练分布敏感**：跨域 HMM 可能近似均匀分布，对 token 选择没有帮助；in-domain HMM 也可能编码不合适的序列长度先验；最终只对某个任务维度有明显收益。
- **TTA 改进不稳定**：OTTA 无测量收益，且自生成续接可能自强化模型已错误的模式；TTBA 让全模型在 Physical Laws 上由全 open_door 变为全 press，仍然“单技能崩溃”，而非恢复任务相关动作选择。
- **安全与闭环方面**：SafeAgentBench 的长时程效果好依赖“回滚/重试/强制动作”策略，这部分不是纯解码行为；机制仅保证符号约束，不包含物理级安全；随机动力学、部分可观测或连续控制都需要额外闭环重规划与感知机制。
- **计算与统计层面**：部分资源估计来自单次运行，缺少重复与方差报告；HF 回调路径与 vLLM 批量路径混在一起，无法严格分离 HMM 开销；跨不同评分协议的数字不能直接比较。
