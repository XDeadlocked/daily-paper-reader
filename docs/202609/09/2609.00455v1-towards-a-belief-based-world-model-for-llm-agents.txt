## Abstract 

Large language models (LLMs) are being used as policies for autonomous decision-making and planning in many domains. Despite their strong reasoning capabilities, LLMs struggle with long-horizon tasks, especially under partial observability. World models are a promising way to enhance policy performance, both during training and inference. During inference, agents currently use world models to simulate the consequences of candidate actions before committing to an action, which can improve decision-making. However, we argue that simulation alone is an incomplete interface for decision-making under partial observability: simulation doesn’t adequately capture uncertainty about the current state, which agents may need for accurate decision-making. We address this limitation with Belief-Based World Models (BB-WMs), which model and maintain a belief that LLMs can query to access information on what is known and uncertain about the current state. Before developing methods to learn accurate BB-WMs, we first ask a more fundamental question: does exposing a world model’s belief directly to an LLM policy improve decision-making? Our results show that giving LLM agents access to world model beliefs improves task performance under partial observability, while remaining complementary to existing simulation-based world models. Code is released: https://github.com/skumar-ml/belief-world-models. 

## 1 Introduction 

“I told you so”. It’s a phrase we say when an earlier prediction comes to pass. But how are we capable of predicting the future? It’s hypothesized [27, 36] that humans use an internal model of the world (or 

world model ) to anticipate the outcomes of possible actions, which may have been an evolutionary advantage (anticipating locations of prey is beneficial for hunting) and is likely important for modern planning and exploration [23, 36]. Given the benefits to humans, methods have explored integrating world models with autonomous policies , which determine what actions the agent should take given the available information. Instead of needing costly real-world interactions, a policy can be trained on the imagined future trajectories from a world model [7, 9]. World modeling training objectives can also be used alongside RL to improve the policy itself [32, 37, 45]. At test time, simulated futures from the world model can help the policy evaluate candidate actions, thereby improving long-horizon planning and generalization to novel situations [11, 17, 26, 31, 47]. This work examines the use of world models at test time. In many recent methods, the policy interacts with the world model through a simulation interface: given a representation of the current state and a candidate action (or action sequence), what future trajectory follows? We raise a broader question: 

is simulation the only interface that a world model should expose to a policy? We argue no; different types of actions require different information from a world model. Consider pragmatic 

actions, which primarily advance the agent toward its goal (e.g., picking up a mug in order to drink coffee). Simulation is well suited to these actions because it helps evaluate the consequences of acting.

Before changing lanes, a simulation-based world model may sample futures where the lane change is safe (i.e., there is no car in the blind spot). The policy may then policy execute the action, only to encounter a car in its blind spot. With Belief-Based World Models, the policy can query for the current belief over the blind spot, and if there is uncertainty, it can take an appropriate epistemic action (e.g., checking the blind spot) before choosing the appropriate pragmatic action. In contrast, epistemic actions are information-gathering actions that primarily reduce uncertainty about the current state of the environment [19, 22]. In this setting, the policy additionally benefits from a belief —what is known and what is uncertain—about the current state to reason about whether epistemic actions are needed. A simulation interface may communicate current-state uncertainty only indirectly through variation across predicted futures. Such variation may conflate uncertainty about the current state with stochasticity in future transitions, leaving the policy to infer which aspects of the present remain uncertain. Moreover, recovering this uncertainty via predicted futures becomes increasingly sample-inefficient as the number of plausible futures grows with the planning horizon. Thus, we argue that current-state belief should be exposed directly rather than reconstructed indirectly from future simulations (exemplified in Fig. 1). Recently, large language model (LLM) agents have emerged as general-purpose policies in open-ended environments, spanning software engineering and enterprise automation [4, 42] as well as embodied AI and robotics [14, 15]. This motivates a modular setting in which a pretrained LLM provides general reasoning and action selection, while environment-specific knowledge are delegated to a decoupled world model used by the LLM at test time. Such a decomposition preserves the capabilities of the pretrained LLM agent and allows the world model to be improved (say, with continual learning) or replaced without needing to retrain the agent. However, despite their strong reasoning capabilities, LLMs are known to struggle with maintaining and updating beliefs in complex, long-horizon partially observable tasks [18, 29, 48]. Recent world models for LLM agents predominantly expose action-conditioned foresight while leaving belief tracking to the agent. The agent must therefore implicitly maintain uncertainty about the current state while simultaneously 

reasoning about action selection, which is likely a suboptimal division of responsibilities. Separating these responsibilities has a long precedent in decision-making under partial observability [19] and was subsequently explored in deep reinforcement learning (RL), with substantial evidence that dedicated belief estimation can improve decision-making [3, 9, 16, 34, 38]. However, such approaches generally pair the belief representation with a downstream policy that is specifically designed or trained to consume it. This differs from the modular setting considered here: an arbitrary learned latent belief is not natively compatible with the natural-language interface of a pretrained LLM. Instead, LLMs offer us a different possibility. If the world model can expose its belief through natural-language, the LLM agent can access information about the current state without being retrained around a particular belief representation. We argue that the simulation interface of current world models for LLM agents should be augmented to explicitly expose beliefs over the current state. To achieve this, we introduce Belief-Based World Models (BB-WMs), which should maintain a belief over the current state, update it as new observations arrive, and propagate it forward during action-conditioned simulation. This affords an LLM agent two completementary interface: natural language queries ask about the world model’s 2current belief when reasoning about epistemic actions, while simulation evaluates the consequences of pragmatic actions. Before asking how to learn scalable Belief-Based World Models, we first ask a more fundamental question: if a world model represents a belief over the state, does exposing this belief to the LLM agent improve decision-making? Motivated by prior results in partially observable RL, we hypothesize that offloading belief modeling to the world modeling and exposing beliefs to the agent allows it to focus on reasoning and action selection, resulting in improved decision-making. 

## 2 Related Works 

World Models for LLMs: There have been efforts to equip LLM agents with decoupled, or separate, world models that provide foresight into the consequences of candidate actions. WMA [2] finds that out-of-the-box LLMs cannot accurately simulate the outcome of actions in web interaction tasks, so they learn a separate, decoupled world model to evaluate the consequences of an LLM agent’s actions before it acts. WALL-E [47] replaces generative world models with a neurosymbolic world model, where an LLM planner queries the world model about the validity of an action in the environment before acting; if the action is predicted to be invalid, the LLM is asked to replan with feedback from the world model. DreamPhase [10] learns a latent world model that generates imagined futures by decoding future state latents into future observations, scores them via a learned value function, and distills feedback into natural language to condition a frozen LLM policy. These methods predominantly expose an action-conditioned simulation or foresight interface to the policy. Interestingly, recent work by Qian et al. [28] shows that providing an LLM agent with a ground-truth simulator alone does not translate into improved decision-making at test-time; agents often fail to invoke simulation when useful, misuse its outputs, or even degrade when simulation is enforced. Their analysis suggests that a key challenge is in when an agent decides to query a world model and how it integrates the resulting information into its reasoning. These findings motivate examining the world-model-to-agent interface, instead of focusing on improving simulation fidelity. 

Belief Representation in LLM Agents: Some works have sought to improve LLM agents by maintaining estimates of the current environment state rather than relying solely on an agent’s ability to reason over the interaction history. Approaches such as Statler, QuBE, StateAct, and ABBEL [21, 25, 30, 44] maintain compact textual or structured representations of task-relevant state that are updated as new observations become available. These representations emphasize a single estimate or summary of the current state rather than explicitly preserving uncertainty over many possible states. Some recent work has begun to model this uncertainty directly. BeliefMem [24] retains multiple candidate conclusions together with probabilities, allowing competing interpretations of past evidence to coexist and updating them as additional evidence is observed. Agent-BRACE [35] more directly adopts the POMDP notion of belief for LLM agents, representing the current state with levels of certainty and conditioning the policy on this structured belief. These works demonstrate growing interest in explicitly representing uncertainty about the current state and making this information available to the agent during decision making. However, these approaches are not world models. They focus on estimating and maintaining the environment’s current state but do not provide an action-conditioned simulation interface for reasoning about the future. BB-WMs seek to bridge simulation with belief tracking: the policy can directly access the world model’s belief when reasoning about what is currently known or uncertain, while continuing to simulate the consequences of candidate actions when reasoning about the future.

## 4 Method 

Recall our research question: “if a world model represents a belief over the state, does exposing this belief to the LLM agent improve decision-making?" To isolate the effect of exposing the belief to the agent, we deliberately abstract away the separate challenge of learning an accurate BB-WM by studying simple text-based environments where we can hand-specify the task-relevant state space, the prior belief prediction P redict (.), and the posterior belief update U pdate (.). Because the hand-4designed state space is semantic and interpretable, we can define a natural-language belief readout 

Rbel (bt, q ), allowing a pretrained LLM policy to query the BB-WM without finetuning. Our goal is not to propose hand-crafted world models as a scalable solution, but to establish whether explicit belief access is useful in the first place. We describe our benchmark-specific instantiations next. 

4.1 ALFWorld ALFWorld [33] is a text-based game where an agent completes household instructions in a simulated home. The agent must locate one or more target objects among a set of receptacles (cabinets, drawers, fridge, etc.), manipulate the objects (take, clean, heat, cool, etc), and place them at a specified receptacle. The environment is partially observed: objects are randomly initialized to specific receptacles, and receptacle contents are hidden until the agent navigates to them. 

Prompt: An LLM agent is used as the policy. In the initial prompt, we provide environment-specific details, the agentic framework instructions, available actions, the WM query interface, and an in-context learning (ICL) example. The ICL example show the agent an end-to-end example of completing a task from the task-type and involves a WM belief query. Then, the goal task and initial observation are provided. Details and examples are in Appendix A.1. 

State Space: The state space contains deterministic components and probabilistic components. Deterministic components include things like agent location and inventory. The only probabilistic component is a belief over object locations. It is represented as a categorical distribution over all receptacles in the environment. More details on the state space construction are in Appendix A.4. 

Belief Update: Deterministic components are updated using rule-based logic, parsed from ALFWorld environment observations. The probabilistic component is seeded from a uniform prior over possible receptacles for each object, which are specified by ALFWorld’s game engine (see Appendix A.4.2 for more). Our belief update follows simple presence/absence renormalization: finding an object in a receptacle collapses the belief to a point mass; if not found, we zero that receptacle’s belief and renormalize the belief over the remaining unsearched receptacles. 

Simulation interface: We use WALL-E [47], which implements a rule-based mechanism to check if the contemplated action is valid (given the current static state) and responds to the agent in natural language (either valid or invalid with feedback). If WALL-E returns the action is valid, the agent executes it. Else, the agent re-plans the action conditioned on the feedback. Note that WALL-E is an incomplete next-state predictor. It does not actually predict the complete next state, and it does not represent a belief. Regardless, we intentionally adopt it because it is simple and allows us to test the benefits of the belief-query interface in the BB-WM. 

Belief-query interface: The world model’s belief is exposed to the agent through a query action. To access the probabilistic state, the agent can ask where is <object> , and the WM responds with a list of receptacles with non-zero probabilities (ranked by their belief). The agent can also access the static state through other queries. See Appendix A.5 for more details on the interface. 

4.2 ScienceWorld ScienceWorld [39] is a text-based game in which an agent performs elementary-science experiments in a fixed ten-room house. We evaluate on 24 test task types (e.g., change state of matter, growing a plant, chemistry mixing). Relative to ALFWorld, ScienceWorld involves more common-sense reasoning from the agent. Similar to ALFWorld, uncertainty is limited to the location of task-relevant objects, which are randomly initialized into a subset of rooms. However, we observe that the possible locations of task-relevant objects is generally less varied when compared to ALFWorld. 

Prompt: We follow ALFWorld’s prompt structure; details and examples are in Appendix B.1. 

State Space: The deterministic components are detailed in Appendix A.4.1. The probabilistic component operates similarly to what was done for ALFWorld (see Appendix A.4.2). 

Belief Update: Observations from the ScienceWorld environment are parsed to update the static components of the state space. Similar to ALFWorld, belief over object locations is updated using prescence/absence renormalization. 5Simulation Interface: Since there is no publicly available implementation of WALL-E for Science-World, we opt for an Oracle version of WALL-E. We use the environment to check if the action is valid or invalid. If valid, the action is executed, and if invalid, the agent is given generic feedback and asked to retry (up to the same retry budget used in WALL-E). We refer to this as an Oracle because we are guaranteed to always get the valid/invalid action prediction correct, but our Oracle does not give failure-specific feedback to the agent, as in the case of WALL-E. 

Belief-query interface: To access the probabilistic state, the agent can ask where is <object> , and the WM responds with a list of rooms ranked by their belief, and the container of the object if known. The agent can also query the deterministic state. See Appendix B.5 for more specifics. 

## 5 Experiments 

For each benchmark, we evaluate each LLM (Llama-3.1-8B-Instruct [5], Qwen3-14B [41], and Sonnet 4.6) on two agentic frameworks (ReAct [43] and ReflAct [20]). 

5.1 ALFWorld Methods Evaluated: For each agent, we evaluate several different world models. In Belief , we allow the agent to only ask queries about the current belief state (no simulation). In WALL-E , we pair the agent with WALL-E’s action-conditioned next-state predictor (no belief state, and just a valid/invalid action prediction). In BB-WM , we compose the belief modeling with WALL-E, allowing the agent to both do simulation and ask questions on the current belief state. 

Evaluation Budget: Following [40], we allow the agent to take at most 30 actions in the environment to solve the task. We terminate execution early if the agent seems to be derailed; specifically if it issues 10 consecutive invalid actions or 10 consecutive WM queries. 

Metrics: Success Rate on the first attempt (SR@1) measures how many tasks the agent successfully completed. We measure efficiency as the average steps needed to accomplish the goal. Critically, we only measure efficiency on solved tasks. An effective world model should help an agent successfully complete the task efficiently.

5.3 Results 

We report results on the unseen split of ALFWorld and ScienceWorld in Table 1 and 2, respectively. 

Adding BB-WM helps the base agent in nearly all cases , both in performance and efficiency. Furthermore, enabling belief queries (represented by Belief ) and simulation queries (represented by 

WALL-E and WALL-E Oracle ) have a complementary effect: they address different shortcomings in the base agent. For example, on ALFWorld the Llama+ReAct agent enjoys significant performance gains under each method individually, which compound when they are combined in the BB-WM . In other cases, WALL-E actually hurts the base agent performance (observe, Qwen3-14B+ReflAct on ALFWorld), but when integrated into the BB-WM , the agent outperforms the Belief case. Sonnet saturates both benchmarks. On ALFWorld, Sonnet enjoys minor performance gains with the world modeling methods, and on ScienceWorld, there is no meaningful change in performance, but there are modest efficiency gains. We believe that for easier tasks, an LLM of sufficient scale can implicitly track state (even with uncertainty) and rarely performs invalid actions, which constrains the benefits of any world modeling efforts. 

5.4 Memory vs. Belief 

Our world model’s state space is composed of deterministic and probabilistic components. The deterministic components can also be referred to as memory , retaining information acquired from prior observations. Existing work has shown that explicitly maintaining memory can lead to performance gains in LLM agents [13, 44]. Thus, one may argue that the our BB-WMs benefit the agent because of memory tracking, rather than representing uncertainty through the probabilistic component. To evaluate if the performance gains primarily result from the deterministic memory or the belief, we perform an ablation on ALFWorld for the Llama and Qwen models. Specifically, we create a 

Memory -only variant of the Belief world model from Sec. 5.1, which tracks only the deterministic components of the state. This means we drop the belief over unobserved object locations but still maintain a memory of observed object locations. The query interface is mostly unchanged: when the agent issues a where is <object> query for an unobserved object, the world model replaces the belief-based response with a generic response that the object has not yet been observed. 7Results are presented in Table 3. Without beliefs, performance and efficiency drop, and in certain cases the Memory variant has very similar performance to the base agent. Based on the results from Tables 1, 2, and 3, we conclude that maintaining a belief is a critical component of a world model, with demonstrated benefits when beliefs are exposed to a decoupled LLM agent.

## 6 Conclusion 

We show that LLM agents acting as policies benefit from having access to an accurate belief over the current state. Our finding motivates using Belief-Based World Models to model, maintain, and expose this belief to LLM agents through a natural language interface. While this paper built benchmark-specific instantiations of BB-WMs, we are excited to pursue scalable, domain-agnostic methods for learning accurate BB-WMs in future work. We believe that there is a natural connection between BB-WMs and continual world models , or world models that continually evolve their model of the world as new observations or experiences are encountered. We see belief updating and continual learning as addressing complementary forms of adaptation: new observations can reduce uncertainty about the current state, while observations that are unexpected under the predicted belief—i.e., high surprise—can signal that the world model itself may need to be revised. BB-WMs can therefore support both active sensing, by revealing when more information is needed, and continual learning, by revealing when existing world model predictions fail to explain new observations. These capabilities may be particularly important for autonomous decision-making in partially observable and open-ended environments such as robotics, financial markets, and information technology.

A.2 World Model Prompt Instructions 

WALL-E World Model Instructions 

A world model checks each action you propose before it is executed. If the action is infeasible in the current state, the world model will not execute it; instead it returns an observation beginning with "[World model]" that explains why the action would fail and suggests how to fix it. This check does not change the environment and does not consume a step. When you receive a "[World model]" observation, do not repeat the same action – read the reason, address it (for example by first moving to the right location or freeing your hand), and propose a different action. 

Belief-Based World Model Instructions 

Below are the instructions used for the Belief variant. For BB-WM, we compose both the WALL-E and these instructions. 

You are assisted by a world model that tracks the environment state and where objects are likely to be. You can consult it for free (a query does not change the environment) using the query action below. 

14 The available queries are: 1. query where is {obj}: returns the receptacles where {obj} is most likely to be, ranked by probability (already-searched receptacles are excluded). 2. query what is in {recep}: returns the objects observed in {recep}, or tells you it has not been searched yet. 3. query searched {recep}: tells you whether you have already looked inside {recep}. 4. query state: returns a summary of the current state: where you are, what you are holding, the objects you have seen, and which receptacles you have searched. The world model only provides information; it does not tell you what to do. When searching for an object, you may "query where is {obj}" to see which receptacles are more likely to contain it (already-searched receptacles are excluded), then decide your own action using that information together with the task. Whenever you feel stuck or uncertain about what to do next – for example, you cannot find an object, you keep getting "Nothing happened", or you are unsure of the current state – query the world model before acting. A query is free and never changes the environment, so use it to reorient yourself instead of guessing.
