## 摘要
视觉-语言-动作（VLA）策略利用预训练的视觉-语言模型（VLM）来指导机器人控制中的动作生成。VLM提供跨层演化的层次化视觉-语义表示，从局部视觉几何到抽象的、与语言对齐的语义；因此，不同的操作任务可能需要不同的层表示混合。同时，动作模块维护着在动作计算过程中演化的中间表示，并可能为后续决策提供有用信息。然而，现有的VLA接口在表示访问方面提供的灵活性有限：VLM信息通过每个动作层的固定层分配来暴露，而中间动作状态仅通过残差流隐式传播，没有显式重用。我们引入了LayerRoute，一种动作条件的表示路由接口，支持对VLM层和动作表示的适应性访问。层混合路由器动态形成缓存VLM表示的混合，而动作状态重读则重用早期的动作表示。在多种仿真和真实世界基准测试中，LayerRoute持续改进了StarVLA-$\pi$和$\pi_{0.5}$，在LIBERO Long上仅以0.31% / 3.87%的额外参数获得了高达7.2的提升。消融研究验证了动作条件层路由的益处，而路由分析揭示了跨动作层和任务设置的结构化分配模式。

## Abstract
Vision-Language-Action (VLA) policies leverage pretrained vision-language models (VLMs) to guide action generation for robot control. VLMs provide hierarchical visual-semantic representations that evolve across layers, from local visual geometry to abstract, language-aligned semantics; different manipulation tasks may therefore require different mixtures of layer representations. Meanwhile, the action module maintains intermediate representations that evolve throughout action computation and may provide useful information for subsequent decisions. However, existing VLA interfaces offer limited flexibility in representation access: VLM information is exposed through fixed layer assignments for each action layer, while intermediate action states are only propagated implicitly through residual streams without explicit reuse. We introduce LayerRoute, an action-conditioned representation routing interface that enables adaptive access to VLM layers and action representations. The Layer Mixture Router dynamically forms mixtures of cached VLM representations, while Action-State Reread reuses earlier action representations. Across diverse simulation and real-world benchmarks, LayerRoute consistently improves StarVLA-$π$ and $π_{0.5}$, achieving up to 7.2 gains on LIBERO Long with only 0.31% / 3.87% additional parameters. Ablation studies validate the benefit of action-conditioned layer routing, while routing analyses reveal structured allocation patterns across action layers and task settings.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **总体领域**：本文研究 Vision-Language-Action (VLA) 策略，该类策略将预训练视觉-语言模型 (VLM) 的视觉与语义先验转化为机器人闭环行为，典型架构包括多模态分词 (RT-2)、扩散动作头 (Octo)、流匹配专家 (π0/π0.5) 及模块化架构 (StarVLA) 等。
- **核心问题与技术动机**：
  1. **VLM-动作接口固定不灵活**：现有 VLA 系统将每个动作层暴露给预先固定的 VLM 层，缺乏依据动作计算演化和多样化操作需求进行逐层自适应调整的能力。VLM 内部表示随层深而有显著差异——浅层与局部纹理、几何、空间模式相关，深层与语言对齐的抽象语义相关；不同任务需要不同的表示组合（例如抓取定位依赖细粒度视觉证据，而指令理解与子目标选择更依赖抽象语义），固定层分配难以满足这一动态需求。
  2. **动作模块内部状态利用不充分**：在标准残差传播中，先前动作状态被逐渐转化并整合入当前表示，后续模块无法直接重新访问早期中间状态，这可能阻碍长程操作中后期决策所需的信息回溯。
- **核心关注点（重新定位研究视角）**：本文侧重研究 VLA 中"动作层如何跨深度访问预训练 VLM 表示"这一表示访问 (representation access) 机制，并提出 LayerRoute 作为解决方案。LayerRoute 允许两层面的自适应访问：跨 VLM 深度的动态路由，以及在动作模块内部对早期动作状态的直接重用。

## 2. 论文提出的方法论

- **整体架构思路**：在 VLA 的每个动作块，用两个模块参与构建更灵活的表示通路：Layer Mixture Router（自适应构造当前动作层可用的 VLM 上下文）与 Action-State Reread（将早期动作状态引入当前计算）。两个模块均以极小参数量集成至现有 VLA（StarVLA-π、π0.5），不需要修改动作目标任务或添加辅助损失。
- **动作条件的层混合路由（Action-Conditioned Layer Mixture Router）**：
  1. 对当前动作状态 a(s) 与各候选 VLM 层状态 {Vn}分别进行池化（由有效 token 位置计算），得到紧凑摘要。
  2. 各自经过归一化与层专属线性映射，投影至共享路由空间（维度 dsel=256）中作为 query 与 key。
  3. 经缩放点积相似度与 softmax 得到一个基于样本的、跨可用 VLM 深度（该动作层内）的归一化分布，并用该分布对候选 VLM 状态做加权求和，得到路由后的 VLM 上下文。
  4. 该路由在单个动作层的全部 token 位置上共享同一种深度权重，仅在动作层间与样本间动态可变化。
- **内部动作状态重读（Internal Action-State Reread）**：
  1. 每个动作层维护一个可学习 query。动作 token 在 token 级依据该 query 对各可用源状态（初始状态 A0、所选早期层状态 Aj1…Ajk、当前状态 Acur）做 RMSNorm 后的表示进行相似度对比。
  2. 每种源状态上的加权 softmax 结果用于对 token 表示做加权相加，得到 token 级 reread 状态。query 在层内共享，但不同 token 具有不同权重，从而比 VLM 层路由更具 token 特异性。
- **集成于具体架构**：
  - **StarVLA-π**：36 层 DiT、18 层交叉注意力，缓存 6 个离散 Qwen3-VL 层状态（层 5/11/17/23/29/35）。在 18 个交叉注意力层用路由后的 VLM 表示替换原始编码器上下文；36 个 DiT 块全部使用 Action-State Reread（注意输出作为当前状态源），重读结果输入 FFN。
  - **π0.5**：在原生前缀/后缀联合注意力之前，经独立"动作到 VLM"八头交叉注意力适配器读取可在线读取的 token 对齐缓存（因果可用性基于层计算顺序），同样实现重读。
- **设计选择**：使用 6 个 VLM 层候选（而非 18 个更细粒度候选），因为更细粒度会造成路由优化不稳定、无稳定性能增益，且带来额外计算与延迟；6-depth 选用被证实是准确率-效率性价比较高的配置。

## 6. 论文的主要结论与发现

- **主结果与性能提升**：
  - **LIBERO**：在 StarVLA-π 上，Avg 4 从 95.7% 提升至 98.0%，Long 套件从 88.4% 大幅提升至 95.6%（+7.2 pp）；在 π0.5 上，Avg 4 从 96.9% 到 98.2%、Long 从 92.4% 到 96.0%（+3.6 pp）。
  - **SimplerEnv**：StarVLA-π Overall/WidowX 分别增长 1.6/2.5 pp；π0.5 为 2.1/5.6 pp。
  - **RoboCasa-GR1**：宏观平均成功率在两种骨干上分别增长 1.2 pp（StarVLA-π）与 5.5 pp（π0.5）。
  - 性能提升伴随极低的参数开销（StarVLA-π 为 0.31%，π0.5 为 3.87%）与约 10%–25% 的推理延迟增幅。
- **跨骨干与跨 VLM 泛化性**：
  - LayerRoute 在四个不同 VLM backbone（Qwen3-VL、Qwen2.5-VL、MiMo-Embodied、Cosmos-Reason2-2B）上均一致提升增益（+1.2~+3.3 pp）。
- **消融与稳健性结论**：
  - 双模块联合（VLM 层路由 + 动作状态重读）显著优于任一单模块，证明二者相互补充。
  - 当前动作状态引导的路由明显强于动作无关 query 或固定深度路由；固定路由仅是均匀路由的对照已有可观增强，但动作条件化仍能进一步提升效果。
- **路由分析发现**：
  - 训练中路由逐渐变得更具有选择性（归一化熵下降），约 20K 步后稳定，而未崩溃为单深度的点分配。
  - 路由权重在动作 DiT 间存在明显的结构变化：早期动作层更偏向浅层 VLM 状态，中层/深层的动作层更倾向于更深 VLM 表示。
  - 任务套件对 VLM 深度有不同偏好：空间任务偏向浅层（细粒度几何），物体任务偏向中层，目标条件任务倾向于更深语义，而长程任务需要跨层的更均衡表示混合物。
- **真实世界**：π0.5 + LayerRoute 在 PnP、擦白板、清桌三项任务上分别比基线高出 +8.0、+4.0、+6.0 个百分点。

## 7. 优点

- **问题定位准确、角度新颖**：不将 VLA 改进归因到动作表征或解码，而聚焦于"表示接口"（VLM 层-动作层中间界面）这一先前较被忽视、机制性重要的问题。
- **轻量设计、即插即用**：总体新增参数占比极小（StarVLA-π 仅 0.31%），与主方法正交性强，能自然地以最小干预集成进多种主流架构（交叉注意力、流匹配、联合注意力均可适配）。
- **实验广度与严谨性**：
  - 同时使用了真实世界实验与 3 种仿真基准，并报告了任务级结果；
  - 针对"是否能改成静态/固定路由"做了良好对照，排除了仅增加计算或参数所能带来的混淆解释；
  - 路由分配的分析将实验结果与可解释性桥接：不仅在数值上有增益，更在机理上阐明"哪些深度被哪些任务/计算阶段利用"。
- **关于延迟和参数开销的透明报告**：提供参数增幅与推理延迟数据，便于领域部署参考。
- **完整性与复现细节**：提供了控制变量的数学化定义（初始态路由、动作无关 query、静态混合等）、数据级来源、seed 控制策略及硬件环境锁文件等。

## 8. 不足与局限

- **骨干覆盖有限**：LayerRoute 仅在 StarVLA-π 和 π0.5 上评估；扩展到其他 VLA 家族（如基于离散 token 的 RT-2/OpenVLA、基于通用扩散的 Octo 等）是否同样有效尚未验证。
- **VLM 组件深层微调带来的适配问题**：所有实验在联合微调（VLM 参数一同更新）下进行；如果在冻结 VLM 或在"仅动作层可训练"的情境下使用，其有效性与稳定路由尚不清晰。
- **计算开销与扩展瓶颈**：尽管参数占比很低，但 π0.5 上的延迟上升约 25.04%，在需要高频控制的部署环境中可能是一个较大的实际约束。细粒度路由（18-VLM 层候选）失败也说明路由维度增大时稳定性是一个额外挑战。
- **深度选择的启发式成分**：现有 6 个 VLM 层的间距与数量是基于来自 Block Attention Residuals 的块级设定而制定的，缺少一套自动选择层位置的准则。
- **真实世界实验范围有限**：真实实验仅涵盖一台 Franka 臂与 3 项桌面任务，每项 50 次试验；因此泛化效果（尤其涉及多机器人、跨场景视觉扰动）在物理域仍有不确定性，仍需更多环境下的验证。
- **超参选择成本与调参刻意避免**：论文明确表示不进行超参调优，在跨骨干、任务域变化大时是否存在不同最优设计（如层数、维度、状态缓存网格）仍值得进一步探索。
- **路由训练稳定性问题**：路由权重分布虽最终收敛并在多种任务上稳定，但训练开始阶段路由熵下降较慢；对更深的层组合或更复杂的任务集，路由动态是否总能保持稳定并无充分的理论保证。
