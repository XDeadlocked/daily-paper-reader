## 摘要
基于模型的强化学习（MBRL）是一类学习方法，通过学习环境模型并利用该模型进行动作选择，因其样本效率而非常适合机器人技术。将学习模型与在线规划相结合可以进一步改善动作选择，因为规划器可以利用模型找到比单独学习策略更好的动作。近期结合学习策略与在线规划的方法通常学习策略的价值，而非更强的规划引导行为。我们提出CAST（带交替状态值目标的评论家），利用规划引导行为改进价值学习，同时用当前策略对价值估计进行正则化。CAST用状态值评论家替代动作价值评论家，训练时使用一个目标，该目标结合了真实规划引导转换和当前策略下的想象转换。所得价值函数对应规划引导行为与当前策略之间的交替过程，使其能够从更强的规划行为中获益，同时受正在学习的策略正则化。我们在DeepMind Control和HumanoidBench套件上评估了CAST，与几种最先进方法比较，并展示了成功迁移到执行动态倒立的物理Unitree Go2四足机器人。

## Abstract
Model-based reinforcement learning (MBRL) is a family of RL methods that learn a model of the environment and use it for action selection, making it well suited to robotics due to its sample efficiency. Combining learned models with online planning can further improve action selection, as the planner can exploit the model to find better actions than the learned policy alone. Recent methods combining learned policies with online planning typically learn the value of the policy rather than the stronger planner-guided behavior. We present CAST (Critic with Alternating State-value Target), which uses planner-guided behavior to improve value learning while regularizing the value estimate with the current policy. CAST replaces the action-value critic with a state-value critic, trained using a target that combines a real planner-guided transition and an imagined transition under the current policy. The resulting value function corresponds to an alternating process between planner-guided behavior and the current policy, allowing it to benefit from the stronger planner behavior while being regularised by the policy being learned. We evaluate CAST on the DeepMind Control and HumanoidBench Suites against several state-of-the-art methods, and demonstrate successful transfer to a physical Unitree Go2 quadruped performing a dynamic handstand.

## 1. 论文的核心问题与整体含义（研究动机与背景）

- **研究动机**：基于模型的强化学习（MBRL）通过习得环境模型来减少真实交互次数，但因学习模型存在误差，其策略质量通常受限。在线规划（如 MPPI）可利用模型搜索出比当前学习策略更强的动作序列，因而能显著提升决策性能。然而，现有结合“学习策略 + 在线规划”的方法（如 TD-MPC2、BOOM、BMPC）通常让评论家学习**当前参数化策略**（πθ）的价值，而非学习**更强的规划引导行为策略**（β）的价值。作者认为，这浪费了规划器提供的更强监督信号。
- **核心问题**：如何让价值函数更准确地反映规划器β的优越行为，同时避免因直接学习β价值而引发的策略更新过猛、训练不稳定？
- **整体含义**：论文提出一种新的评论家训练范式——用“真实β转移”与“想象πθ转移”交替构造状态值目标，使评论家学习一个介于Vβ与Vπθ之间的交替过程价值函数。该方法以状态值函数替代动作值函数，既提升了价值学习的质量，也改善了策略优化的稳定性和样本效率。
- **实践意义**：除仿真验证外，作者还成功地将训练好的策略迁移到真实的 Unitree Go2 四足机器人上完成动态倒立任务，表明 CAST 具备较强的 sim-to-real 部署潜力。

## 2. 论文提出的方法论

### 2.1 总体框架
- 以 **TD-MPC2** 为基础框架，保留其潜空间世界模型（编码器 hξ、动力学 dξ、奖励 Rξ）和 MPPI 规划器；主要修改为：
  1. 用**集成状态值评论家**（Vψ）替换原动作值评论家（Qψ）；
  2. 修改价值学习目标为**交替式混合目标**（真实β转移 + 想象πθ转移）；
  3. 用**基于模型的扩展策略梯度**进行策略优化。

### 2.2 基于模型的状态值重构
- 由于状态值 V(z) 不依赖动作，策略优化无法直接对 V 关于策略动作求导。因此论文从学习到的奖励与动力学模型及目标状态值网络重构单步动作值：
  \[
  \hat{Q}(z,a)=R_\xi(z,a)+\gamma \bar{V}_\psi(d_\xi(z,a))
  \]
- 规划器的终端评价也由原来的“采样终端动作并用 Q 评价”改为**直接使用状态值**：
  \[
  \hat{G}(z_t,a_{t:t+H})=\sum_{h=0}^{H-1}\gamma^h R_\xi(z_{t+h},a_{t+h})+\gamma^H \bar{V}_\psi(z_{t+H})
  \]
  好处：无需在规划时额外查询策略分布，降低计算开销。

### 2.3 交替式混合价值目标（核心创新）
- 从回放缓冲中取一条真实转移 \( (s_t,a_t,r_t,s_{t+1}) \)，其中动作来自规划器β。构造两步式 TD 目标：
  \[
  y_t = r_t + \gamma\left[R_\xi(z_{t+1},\tilde{a}_{t+1})+\gamma \bar{V}_\psi(\tilde{z}_{t+2})\right],
  \]
  其中：
  - \(z_{t+1}=h_\xi(s_{t+1})\)；
  - \(\tilde{a}_{t+1}\sim\pi_\theta(\cdot|z_{t+1})\)；
  - \(\tilde{z}_{t+2}=d_\xi(z_{t+1},\tilde{a}_{t+1})\)。
- 该目标将**一步真实β转换**与**一步想象πθ转换**交替拼接，对应策略序列：
  \[
  \beta \to \pi_\theta \to \beta \to \pi_\theta \to \cdots
  \]
- 因此评论家学习的是交替过程 \(T_{\text{CAST}} = T_\beta T_\pi\) 的不动点，而非单独 Vβ 或 Vπθ。

### 2.4 理论性质
- 论文证明了在策略固定、动力学确定、价值函数可精确表示的前提下：
  - \(T_\beta\) 与 \(T_\pi\) 均为 γ-压缩算子；
  - 其复合算子 \(T_\beta T_\pi\) 是 γ²-压缩算子，因此存在唯一不动点 \(V_{\text{CAST}}\)。
- 价值函数展开式显示奖励按 β、πθ 交替折扣累加，从理论上解释了 CAST 的价值函数位于 Vβ 与 Vπθ 之间。

### 2.5 扩展策略梯度（Expanded Policy Gradient）
- 策略优化目标用重构的一步 Q 估计作为基础，并可沿学习模型展开 k 步后再用目标状态值引导：
  \[
  J_k(z_0;\theta)=\sum_{i=0}^{H_\pi-1}\gamma^i R_\xi(z^{(i)},a^{(i)})+\gamma^{H_\pi}\bar{V}_\psi(z^{(H_\pi)})
  \]
- 默认配置 \(H_\pi=1\)，也可取更大值以研究扩展规模的影响。
- 整体训练流程：模型与评论家联合更新时使用混合目标，策略更新时对世界模型展开反向传播（单步或 k 步），目标网络通过 Polyak 平均更新。

## 7. 优点

- **问题定位准确且具有新意**：指出规划型 MBRL 评论家应学习行为策略 β 的价值，而不是仅学习当前策略πθ的价值，并设计了一种正则化方式避免直接学习 Vβ 造成的不稳定。
- **理论分析简洁而扎实**：从算子压缩性质证明了混合目标的唯一不动点，并给出交替策略序列的概率解释，为算法设计提供了清晰的理论依据。
- **状态值评论家的设计巧妙**：避免了对 β 逐状态查询动作分布导致的巨大计算开销；同时与规划器天然契合——规划器不依赖评论家的动作输入即可完成终端值评估。
- **算法改动集中、相对优雅**：CAST 保留 TD-MPC2 的绝大多数结构，仅修改评论家类型、TD目标与策略目标，易于复现与集成。
- **实验评价扎实**：对比 5 个代表性基线、跨 14 个高维控制任务；并进行了 3 组针对性消融，验证核心设计合理。
- **领域科学价值较强**：首次以“交替价值目标”作为规划-策略中介的框架，为后续结合更强规划器与学习策略提供了新思路。
- **真实机器人演示增强说服力**：不仅局限在仿真曲线，还展示了从仿真到真实四足机器人的倒立技能迁移，证明方法在真实控制任务中的潜力。
