## 摘要
行为克隆的视觉运动策略在其训练分布附近可以保持准确，但当物体位置和相机视角同时改变时会失败。一条成功的参考轨迹包含了迁移相同交互所需的几何信息，但策略必须将该几何信息与当前场景对齐，并在去噪过程中保持对其敏感。为应对这些挑战，我们提出了MemCorr-DP，一种扩散策略，它将冻结的RoMa v2匹配提升为当前场景与参考轨迹之间的显式三维关系。一种反事实配对目标为相同物理状态和噪声动作赋予相反行为，同时保留特定于参考的去噪目标。混合条件微调随后使策略从真实几何适应到测量的对应误差。我们最强的评估将门放置在训练支持范围之外的最外侧位置带，并将查询相机改变±15°。在这种组合偏移下，MemCorr-DP实现了96.67%的闭环成功率，而采用相同动作架构的视觉Transformer为88.00%。目标消融和参考干预表明，行为响应于所选参考，而匹配对照组则有利于完整的关系集，而非仅未来运动或质心几何。这些结果支持显式三维参考关系作为在评估任务中空间和视角变化复合情况下的稳健条件化接口。

## Abstract
Behavior-cloned visuomotor policies can remain accurate near their training distribution yet fail when object position and camera viewpoint change together. A successful reference trajectory contains the geometry needed to transfer the same interaction, but the policy must align that geometry with the current scene and remain sensitive to it during denoising. To address these challenges, we present MemCorr-DP, a diffusion policy that lifts frozen RoMa v2 matches into explicit 3D relations between the current scene and the reference trajectory. A counterfactual paired objective assigns opposite behaviors the same physical state and noisy action while retaining reference-specific denoising targets. Mixed-condition fine-tuning then adapts the policy from ground-truth geometry to measured correspondence errors. Our strongest evaluation places the Door in the outermost position bands beyond the training support and changes the query camera by $\pm15^\circ$. Under this combined shift, MemCorr-DP achieves 96.67% closed-loop success, compared with 88.00% for a visual Transformer with the same action architecture. Objective ablations and reference interventions show that behavior responds to the selected reference, while matched controls favor the complete relation set over future motion or centroid geometry alone. These results support explicit 3D reference relations as a robust conditioning interface when spatial and viewpoint changes are compounded in the evaluated task.

# MemCorr-DP 论文总结

## 1. 核心问题与研究动机

- **背景**：行为克隆的视觉运动策略（visuomotor policy）在训练分布附近可以表现良好，但当 **物体位置改变** 和 **相机视角改变** 同时发生时，策略容易失效。因为策略可能过度依赖训练中见过的像素布局与空间相关性，而非任务本身的几何交互关系。
- **核心挑战**：给定一段成功执行的参考轨迹（包含 RGB-D 观测和夹爪运动），策略需要：
  1. 建立参考轨迹与当前场景之间的**空间对应关系**；
  2. 在扩散策略去噪过程中**保持对参考几何信息的敏感**，避免完全依赖含噪动作内部泄露的任务线索；
  3. 弥合**训练时使用的几何条件（如真值对应）与执行时实际视觉匹配误差**之间的差距。

## 2. 方法论：MemCorr-DP

### 2.1 整体思路
提出 MemCorr-DP，一种以扩散策略为动作生成器的行为克隆方法。它将参考轨迹中的交互几何通过**显式 3D 关系**与当前场景绑定，在每个重规划步骤中利用该 3D 关系条件化动作去噪。

### 2.2 关键步骤与技术细节

1. **观测与参考轨迹**
   - 当前观测：RGB 图像、深度、物体 mask、机器人 9D 状态、夹爪 3D 位置。
   - 参考轨迹：给定一次成功执行的 RGB-D + 夹爪运动序列，用于提供目标技能演示。

2. **物体中心匹配与 3D 提升**
   - 使用**冻结的 RoMa v2** 对参考与查询的物体裁剪图进行稀疏点匹配，均匀选择 16 个可见参考像素。
   - 匹配点的深度被反投影到**共享的仿真器世界坐标系**，保证当前场景与参考场景中的点坐标可比。

3. **关系条件 tokens**
   - 对每个匹配点和 4 个未来时间偏移（\(\tau=0,5,10,15\)）构造 18 维 token，包含：
     - 当前夹爪位置与当前场景点的 3D 差；
     - 参考夹爪与参考场景点的 3D 差；
     - 参考夹爪未来运动与参考点的 3D 差；
     - 当前场景与参考场景的点位移；
     - 匹配置信度、归一化偏移索引；
   - 16 点 × 4 偏移 = **64 个 token**，无效位置被 mask。

4. **动作扩散 Transformer**
   - 对 16 步动作序列（3D 末端位移 + 1 维夹爪命令）进行扩散去噪。
   - 4 层 Transformer action blocks，对动作间 self-attention，再 cross-attention 到状态与关系 token。
   - 推理使用 20 步确定性 DDIM 采样，并采用 classifier-free guidance。

5. **反事实配对去噪目标**
   - 问题：标准扩散中，不同行为的干净动作不同，导致即使共享随机噪声，含噪动作也会泄漏行为身份，使模型可以“绕过”参考。
   - 方法：对打开/关闭配对动作共享物理初始状态，定义平均动作 \(m\)，构造**相同的含噪输入 \(z_t\)** 和相同的噪声水平 \(t\)，但使用各自的行为参考 \(r_b\) 以及对应的去噪目标 \(\epsilon_b\)。
   - 损失为两种方向上的噪声预测误差之和，强制模型依赖参考信息区分相反行为。
   - 训练中标准扩散目标与配对目标交替使用。

6. **混合条件微调**
   - 阶段一：使用**真值几何关系**训练 20,000 步，学习精确几何到动作的映射。
   - 阶段二：使用混合条件微调 10,000 步，包含 25% 真值、50% 缓存 RoMa v2 匹配结果、25% 从实测匹配残差中采样的损坏条件。
   - 该过程让策略适应执行阶段测量的视觉匹配误差，避免训练/执行分布不一致。

## 3. 实验设计

### 3.1 任务与基准
- **任务场景**：Meta-World 中的单个铰接 Door 实例，包含 **打开（open）** 和 **关闭（close）** 两个相反方向。
- 物理配置：随机门的位置、初始关节角、初始机器人状态；同一个物理配置可产生“打开”和“关闭”两个动作相反的演示轨迹。
- 训练数据：80 个物理配对配置 ⇒ 160 条轨迹 / 29,600 个动作窗口；验证 20 个配置。
- 参考选择：训练中，每个轨迹使用下一个训练配置的同类参考轨迹；测试中使用训练配置 0 的固定成功轨迹作为参考，参考相位根据已执行步数推进。

### 3.2 评测条件
- **训练分布**：门位置归一化坐标在 \([0.2,0.8]^2\)，相机视角固定。
- **边界外推**：一个坐标在 \([0.05,0.15]\cup[0.85,0.95]\)。
- **极端位置**：一个坐标在 \([0,0.05]\cup[0.95,1]\)。
- **相机偏移**：查询相机在 \(\pm 15^\circ\) 内变化。
- **组合偏移（最强）**：极端位置 + \(\pm 15^\circ\) 相机偏移。

条件规模：
- 边界外推 50 个物理配置 × 2 任务 × 3 种子 = 300 次 rollout；
- 其他更强条件 25 个配置 × 2 任务 × 3 种子 = 150 次 rollout。

### 3.3 基线对比
- **Visual-DP-Transformer**：主系统基线，使用 RGB + depth + mask + 显式 open/close 编码，动作去噪器、训练预算等与 MemCorr-DP 相同，参数数仅差 +0.36%。
- **Visual-DP-U-Net**：传统 U-Net 形式的 Diffusion Policy。
- **匹配控制**：
  - Motion only：只提供参考未来运动，不含点几何；
  - Object centroid：将所有有效点替换为质心；
  - 与 MemCorr-DP 使用相同 transformer 骨干和训练协议。

### 3.4 消融与诊断实验
- 训练目标消融：标准条件扩散 vs 反事实配对训练；
- 参考干预：正确 / 空 / 相反参考；
- 条件输入：真值对应 vs RoMa v2 匹配；
- 表示消融：Full relations vs Motion only vs Object centroid；
- 参考相位敏感性：相位偏移与速度不匹配。

## 6. 主要结论

- 在**位置与视角同时改变的组合偏移**下，MemCorr-DP 达到 **96.67%（145/150）** 的闭环成功率，明显优于同动作架构的视觉 Transformer（88.00%，132/150），且主要提升来自更难的“打开”方向。
- 在纯边界外推（视角不变）中，MemCorr-DP（97.33%）略低于视觉 Transformer（100%），说明其优势集中在**复合分布偏移**情景，而非所有泛化场景。
- 完整 3D 关系条件比“仅未来运动”或“点质心”显著更好；
- 反事实配对训练能够抑制噪声动作对行为身份的泄漏，使策略真正响应参考选择；相反参考下，原有任务成功率从标准扩散下的 55% 降至 8.67%，说明参考具有因果作用；
- 混合微调后的模型在 RoMa v2 匹配下比使用真值几何更成功，表明该模型已内化对视觉匹配误差的鲁棒性。

## 7. 方法优点

- **表示灵活**：将参考轨迹与当前场景转换成交叉的 3D 位移场，动作扩散模型可在统一几何坐标系中直接利用演示几何；
- **反事实条件化设计巧妙**：通过让相反行为共享含噪动作，阻断“含噪动作→行为身份”的捷径，提升对参考的依赖；
- **两阶段训练务实**：先学干净几何，再适应测量匹配误差，缓解 simulation-to-matching 的分布鸿沟；
- **实验控制细致**：对架构、参数规模、训练预算和随机因素进行大量对齐，构建针对训练目标和条件表示的匹配化消融；
- **统计报告规范**：以物理配置为单位进行 bootstrap，重视跨配置方差而非只报告计数值。

## 8. 不足与局限

- **场景覆盖窄**：仅单一的仿真铰接门、开/关两类动作，不涉及跨实例、跨类别、物体旋转、连续操作或真实机器人；
- **部署假设强**：需要已知任务身份、固定参考轨迹、可用的物体 mask、准确的深度 / 相机标定，参考相位需人为调度（默认按执行步数时间推进），这些在实际系统中不一定可得；
- **视觉匹配模块黑盒化**：RoMa v2 被冻结且未计入参数量，缓存和残差扰动是对匹配误差的近似模拟，可能与真实在线匹配分布不完全一致；
- **系统间信息不对等**：MemCorr-DP 需要参考视频/轨迹和在线语义匹配，而视觉基线只使用图像+任务码，输入信息带宽差异值得注意；
- **未公开算力与延迟资源**，训练成本、推理实时性未知，对实际机器人控制应用的可落地性评估不足；
- **优势边界有待澄清**：在边界外推中反而弱于纯视觉 Transformer，说明 3D 参考条件并非在所有分布偏移下都始终占优，但论文对该机制性差异的解释不够深入。
