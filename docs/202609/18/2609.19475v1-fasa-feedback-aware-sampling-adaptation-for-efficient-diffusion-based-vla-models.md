## 摘要
基于扩散的视觉-语言-动作（VLA）模型在具身任务中取得了强劲性能，但其迭代采样带来了沉重的计算与内存访问开销，阻碍了在边缘平台上的实时部署。现有加速方法要么需要昂贵的训练（例如蒸馏、流匹配），要么通过静态调度的剪枝与缓存降低感知性能，忽视了机器人交互中动态变化的工作负载。本文提出 FASA（反馈感知采样自适应），一种免训练的运行时框架，将实时多模态反馈视为去噪流程的控制信号：交互驱动的范围适配器根据视觉与夹爪力反馈调节全局采样步预算，而本体感觉感知的步数适配器在自适应范围内精准定位最优步。这一协同设计的框架使底层硬件架构能够自适应地匹配不同执行阶段的工作负载需求。在多个基准上的对比评估表明，推理速度最高可提升 1.45 倍，同时保持有竞争力的成功率，为将繁重的生成式具身 AI 工作负载部署到资源受限的计算平台上提供了一种新颖的动态运行时架构范式。

## Abstract
Diffusion-based Vision-Language-Action (VLA) models achieve strong performance in embodied tasks, but their iterative sampling imposes heavy computational and memory-access cost, blocking real-time deployment on edge platforms. Existing acceleration methods either require expensive training (e.g., distillation, flow matching) or degrade perception via statically scheduled pruning and caching, ignoring the dynamic workload variance of robotic interactions. This paper presents FASA (Feedback-Aware Sampling Adaptation), a training-free runtime framework that treats real-time multimodal feedback as a control signal for the denoising pipeline: an interaction-driven range adaptor modulates the global sampling-step budget based on visual and gripper-force feedback, and a proprioception-aware step adaptor pinpoints the optimized step within the adapted range. This co-designed framework allows the underlying hardware architecture to adaptively match the workload demands of different execution phases. Comparative evaluations across several benchmarks show that the inference speed can be increased by up to 1.45$\times$ while maintaining competitive success rates, providing a novel dynamic runtime architecture paradigm for deploying heavy generative embodied AI workloads onto resource-constrained computing platforms.

## 1. 论文核心问题与整体含义

- **研究背景**：扩散式视觉-语言-动作（VLA）模型在具身操作中表现强，但其动作头通常需要在每个控制步执行数百次去噪迭代，带来高延迟、高能耗和高访存开销，难以在边缘平台实时部署。
- **核心问题**：现有加速路线存在两类局限：
  - **训练型方法**：如一致性蒸馏、流匹配等，需要昂贵重训练，且跨策略迁移差。
  - **免训练方法**：如视觉 token 剪枝、感知特征缓存、语言模型层早退等，多依赖固定调度或输入级统计，忽略机器人交互过程中工作负载的动态变化，可能在精度关键阶段削弱感知，同时在简单运动阶段仍过度计算。
- **论文含义**：FASA 提出一种免训练、即插即用的运行时框架，把具身平台特有的实时反馈流——视觉变化、夹爪力、本体感知——作为去噪流程的控制信号，动态分配去噪步数。其目标是在不修改模型权重的前提下，让计算预算匹配不同执行阶段的实际精度需求，为资源受限平台部署重型生成式具身 AI 提供动态运行时新范式。

## 2. 方法论：核心思想与关键技术

- **核心思想**：用反馈信号控制扩散采样步预算。机器人任务在“精度关键阶段”（如接触丰富操作）和“计算容忍阶段”（如粗略接近）之间交替，固定采样预算无法匹配；FASA 动态调整每个执行步的去噪步数。
- **整体流程**：FASA 拦截策略推理循环，不训练、不改权重。它由两个模块协同组成：
  - **交互驱动采样范围自适应**：根据视觉与夹爪力反馈，调节全局采样步范围 \([s_{\min}, s_{\max}]\)。
  - **本体感知采样步自适应**：根据关节位置与速度，在自适应范围内定位最优采样步 \(s_{\text{opt}}\)。

- **交互驱动范围自适应细节**：
  - 计算相邻执行步的时序变化：
    - 力变化：\(\delta_t^{\text{force}} = -\cos(F_t, F_{t-1})\)
    - 视觉变化：\(\delta_t^{\text{vision}} = -\cos(f_{v,t}, f_{v,t-1})\)
  - 融合为调制因子：
    - \(\alpha_t = \frac{1}{2}\delta_t^{\text{vision}} + \frac{1}{2}\delta_t^{\text{force}} + \beta\)
    - 其中 \(\beta=1.5\) 作为线性整流，保证稳定运动时 \(\alpha_t\) 仍有正下限约 0.5，防止生成崩溃。
  - 更新范围：
    - \(s_{\min}^t = s_{\min}^{t-1}\cdot \alpha_t\)
    - \(s_{\max}^t = s_{\max}^{t-1}\cdot \alpha_t\)
    - 初始化满足 \(s_{\max}^0 = 2s_{\min}^0\)。
  - 实际实现中使用指数移动平均平滑边界，并裁剪到合法范围，避免剧烈振荡。
  - 当 \(\alpha_t<1\) 时压缩采样路径，节省计算；当 \(\alpha_t>1\) 时为动态交互分配更大预算。

- **本体感知步自适应细节**：
  - 定义运动活跃度指标：
    - \(\text{MotionIndex}_t = \|\dot{q}_t\| + \|q_t - q_{t-1}\|\)
    - 其中 \(\dot{q}_t\) 为关节瞬时速度，\(\|q_t-q_{t-1}\|\) 为实际位置位移；二者来自策略已使用的归一化本体状态，量纲一致。
  - 通过非线性门控映射到最优采样步：
    - \(s_{\text{opt}}^t = s_{\min}^t + (s_{\max}^t - s_{\min}^t)\cdot \sigma(\text{MotionIndex}_t)\)
    - 高运动活跃度对应更大 \(\sigma\)，即靠近 \(s_{\max}\)，提供更细时间分辨率；低活跃度则靠近 \(s_{\min}\)，节省计算。

- **运行时开销**：每步额外开销包括一次策略原视觉编码器调用、两次余弦相似度计算，以及 MotionIndex 范数计算。所需本体感知信号可通过标准物理引擎 API 或机器人控制接口获取，无需修改机器人控制栈。
