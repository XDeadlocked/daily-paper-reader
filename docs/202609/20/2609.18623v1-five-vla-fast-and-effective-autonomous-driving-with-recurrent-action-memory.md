## 摘要
用于自动驾驶的最先进视觉-语言-动作模型（VLA）面临关键局限：参数量过大、高分辨率图像处理效率低，以及缺乏时间记忆。我们提出快速且高效的 VLA（FIVE-VLA），通过两项关键贡献解决这些问题。首先，我们采用高效视觉编码器，处理高分辨率（$448 \times 896$）图像时仅生成 98 个 token，不到现有方法的五分之一，并完全绕过文本生成以实现单遍轨迹预测。其次，我们提出循环动作记忆（Recurrent Action Memory, RAM），这是一个轻量级模块，以先前的动作 token 为条件进行动作预测，为超车和紧急制动等机动操作提供关键的时间上下文。仅有 641M 参数，在具有挑战性的 Bench2Drive 闭环驾驶基准上，FIVE-VLA 比先前最先进的 VLA 多完成约 10% 的无交通规则违规路线。在大规模真实世界 NVIDIA Physical AI AV 数据集上的非反应式开环仿真显示，在单视图和四视图设置下，其碰撞违规率分别比 SimLingo 低 10.2% 和 7.7%。此外，FIVE-VLA 在 A100 上以约 30 fps 运行，在 T4 GPU（作为边缘设备的代理）上以约 4 fps 运行，相比先前方法实现了 8-30 倍加速。

## Abstract
State-of-the-art vision-language-action models (VLA) for autonomous driving face critical limitations: excessive parameter counts, inefficient high-resolution image processing, and lack of temporal memory. We introduce Fast and EffectIVE VLA (FIVE-VLA) to address these through two key contributions. First, we employ an efficient vision encoder that processes high-resolution ($448 \times 896$) images while generating only 98 tokens, over $5\times$ fewer than existing approaches, and bypass text generation entirely for single-pass trajectory prediction. Second, we propose Recurrent Action Memory (RAM), a lightweight module that conditions action prediction on previous action tokens, providing temporal context critical for manoeuvres such as overtaking and emergency braking. With only 641M parameters, FIVE-VLA completes $\sim$10% more routes without traffic rule infractions than the previous state-of-the-art VLA on the challenging Bench2Drive closed-loop driving benchmark. Non-reactive open-loop simulation on the large-scale real-world NVIDIA Physical AI AV dataset shows 10.2% and 7.7% lower collision-violation rates than SimLingo in single- and four-view settings, respectively. Additionally, FIVE-VLA runs at $\sim$30 fps on an A100 and $\sim$4 fps on a T4 GPU (proxy to an edge device), representing an 8-30$\times$ speedup over previous methods.

# FIVE-VLA 论文详细总结

## 1. 核心问题与整体含义

- **研究背景**：视觉-语言-动作模型（VLA）在自动驾驶中展现出语义理解与泛化潜力，但现有 SOTA VLA 存在三大瓶颈：
  - **参数量过大**：如 ORION 达 7B，在 A100 上仅约 1 fps，难以部署于车载边缘设备。
  - **高分辨率图像处理低效**：多数视觉编码器预训练分辨率仅为 224×224 至 448×448；SimLingo 将 448×896 图像切成两块 448×448 tile，每块 256 token，共 512 token，且无法跨 tile 交互。
  - **缺乏时序记忆**：多数 VLA 无记忆机制；简单输入历史 ego waypoints 会鼓励模型外推专家轨迹（copycat 捷径），在闭环中因协变量偏移而失效；视觉域记忆方法（滑动窗口、Flex、QT-Former）偏离 VLM 预训练设计，损害迁移学习。
- **核心动机**：设计一个既高效（单遍预测、少量 token、小参数）又能捕捉时序上下文、且与预训练 VLM 架构对齐的自动驾驶 VLA。

## 2. 方法论

### 2.1 整体架构
- **VLM 骨干**：采用 FastVLM（FastViTHD 视觉编码器 + Qwen2 LLM），总参数约 620M，微调后 FIVE-VLA 共 **641M** 参数。
- **输入**：448×896 前视图像、文本格式 ego 速度、两个后续目标点、文本指令。
- **输出**：路径 waypoints（1 米间隔，N_path×2）与速度 waypoints（固定时间间隔，N_speed×2）。

### 2.2 高效视觉编码
- FastViTHD 混合卷积与注意力，部分卷积层 stride=2 逐步降采样，448×896 图像仅生成 **98 个视觉 token**（约为 ViT 的 1/21、InternViT-300M 的 1/5），且无需 tile 分区，保留全局 token 交互。

### 2.3 高效驾驶模式（Efficient Driving）
- SimLingo 需自回归生成固定前缀 “Waypoints:” + EOS（4 个 token），增加延迟。
- FIVE-VLA 识别该输出不变，直接将 4 个 token 追加到输入序列，**完全跳过文本生成**，单次前向完成轨迹预测，O_text = ∅。

### 2.4 循环动作记忆（RAM）
- **核心思想**：在**动作域**而非视觉域建模时序，条件化于上一时刻的动作 token，保持 VLM 完整性。
- **模块组成**（共 2 个 transformer block，17M 参数）：
  - **Memory Encoder**（1 个自注意力 block）：编码上一时刻动作 token，得到 RAM 状态：
    - `Q^{t-1}_RAM = RAMEncoder(ˆQ^{t-1}_action)`
  - **Memory Decoder**（1 个交叉注意力 block）：当前可学习动作查询 `Q_action` 交叉注意 RAM 状态：
    - `Q^{t}_RAMaction = RAMDecoder(Q_action, Q^{t-1}_RAM)`
  - t=0 时无历史，直接 `RAM(Q_action, ˆQ^{t-1}_action) = Q_action`。
- 交叉注意力前对 `Q_action` 做 LayerNorm，输出前不归一化以保留原始特性。

### 2.5 训练策略（两阶段）
- **为何两阶段**：流式数据破坏 IID 假设，降低 batch 内多样性；实验显示 stream length T>2 时性能显著下降。故先无 RAM 微调，再加入 RAM 微调。
- **RAM 初始化**：将 memory decoder 的交叉注意力、自注意力输出投影层及 MLP 第二层置零，保证初始时 `Q^{t}_RAMaction = Q_action`，仅通过 skip connection 传播。
- **优化范围**：仅优化动作解码器、LLM 与 RAM 模块；使用梯度累积，跨时间步停止梯度。

### 2.6 推理策略：RAM Accumulation
- 训练序列长度受 GPU 限制（T=4），但驾驶场景远长于 T。
- **Naïve Reset**：每 T 步重置 RAM，导致记忆频繁清空。
- **RAM Accumulation**：维护主、次两个实例；次实例从空 RAM 开始累积信息，每 T/2 步替换主实例，兼顾训练长度约束与长时记忆。
