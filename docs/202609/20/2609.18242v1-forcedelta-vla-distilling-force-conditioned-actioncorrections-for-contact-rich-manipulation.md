## 摘要
具备力感知能力的视觉-语言-动作（VLA）策略可提升富接触操作性能，但通常将任务级运动与依赖接触的调整结合在单次动作预测中。演示数据不提供显式标签，以将该预测分解为可复用的参考动作和修正量。我们提出 ForceDelta-VLA，一种修正蒸馏框架，利用冻结教师模型的力条件模式与学习得到的与力无关模式所产生的配对预测，构建显式的力修正目标。另设一个延迟修正目标，用于补偿参考动作不匹配以及参考状态的变化。训练采用异步调度回放，并利用执行期间可用的缓存任务上下文。所得轻量策略利用近期力历史与机器人状态调整参考动作，在参考动作更新之间对接触变化做出响应，而无需重新生成完整动作块。在九项单臂与双臂富接触任务中，ForceDelta-VLA 达到 82.2% 的平均成功率，而原始 ForceVLA 基线为 54.4%。直接执行我们的第一阶段时序教师模型达到 70.6%。相对于 ForceVLA，完整系统在两个平台上均将成功试验中的平均峰值接触力降低约 26%。

## Abstract
Force-aware Vision-Language-Action (VLA) policies improve contact-rich manipulation, but typically combine task-level motion and contact-dependent adjustment in a single action prediction. Demonstrations provide no explicit labels for decomposing that prediction into a reusable reference action and a correction. We present ForceDelta-VLA, a correction-distillation framework that constructs an explicit force-correction target using paired predictions from a frozen teacher's force-conditioned and learned force-agnostic modes. A separate delay-correction target accounts for reference-action mismatch and the change in reference state. Training uses asynchronous schedule replay with the cached task context available during execution. The resulting lightweight policy adjusts the reference actions using recent force history and robot state, responding to contact changes between reference-action updates without regenerating complete action chunks. Across nine single-arm and bimanual contact-rich tasks, ForceDelta-VLA achieves an 82.2% mean success rate, compared with 54.4% for the original ForceVLA baseline. Direct execution of our Stage-1 Temporal Teacher achieves 70.6%. Relative to ForceVLA, the complete system reduces mean peak contact force over successful trials by approximately 26% on both platforms.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：富接触操作（如 USB 插入、插头插入、按钮按压、抽屉拉开等）要求机器人动作随接触状态的演化而实时调整。力感知的视觉-语言-动作（VLA）策略已被证明能提升此类任务表现。
- **核心痛点**：
  - 现有力感知 VLA 通常将**任务级运动**与**依赖接触的局部调整**耦合在**单次动作预测**中，导致接触反馈无法在两次完整动作块生成之间快速生效。
  - 若能将动作分解为「慢速通路生成的参考动作」+「快速更新的修正量」，就可让接触反馈在不等待新动作块的情况下影响执行。
  - 然而，**演示数据只记录最终动作，不提供参考动作与修正量的分解标签**；不同的参考动作与修正量组合可得到相同的演示动作，因此修正通路缺乏明确的监督目标。
- **整体含义**：论文试图在**仅使用原始演示数据**、不依赖额外奖励或在线人类纠正的前提下，构造显式的修正监督信号，同时保留异步执行架构，从而兼顾接触响应速度与动作生成质量。

## 2. 方法论

### 2.1 核心思想
- 将指令位姿分解为三部分：
  - **参考动作** `P(Aref)`：由慢速生成通路预测、可复用的动作块；
  - **力修正** `ΔÂforce`：由冻结教师模型的「力条件预测」与「与力无关预测」之差蒸馏得到；
  - **延迟修正** `ΔÂdelay`：补偿参考动作不匹配与参考状态变化。
- 公式：`P(Acmd) = P(Aref) + ΔÂforce + ΔÂdelay`。修正仅作用于位姿，夹爪命令来自参考动作；位姿采用平移 + 连续 6D 旋转表示，修正后经 Gram–Schmidt 投影得到合法旋转。

### 2.2 三阶段训练流程
- **阶段 1：时序力条件教师**  
  - 基于 ForceVLA，将其瞬时力嵌入替换为 FAVLA 风格的**因果时序卷积网络（TCN）**，编码 100 ms 的力/力矩历史 `zFt = EFT(Ft)`；
  - 教师 `Tθ` 将 `(Vt, L, St, Ft)` 映射为 H=50 步动作块，训练后冻结。
- **阶段 2：与力无关的参考动作模式**  
  - 区分「力不可用」与「实测零力」：用可学习 token `z∅F` 替代力历史输入；
  - 通过秩-ρ 适配器 `(Win, Wout)` 修改动作专家的位姿输出：`vp ← vp + Wout σ(Win h)`；
  - 冻结 θ，仅训练 `ϕ = {z∅F, Win, Wout}`，使用原 flow-matching 目标。
- **阶段 3：配对修正目标与修正策略训练**  
  - **力修正目标**：在同一缓存视觉-语言前缀 `Ek`、同一状态 `St`、同一噪声 `ϵk` 下，取力条件预测与无力感知预测的位姿差：  
    `ΔAforce_T,t|k,j = P(Acond_T,t|k,j) − P(Aref_T,t|k,j)`。
  - **延迟修正目标**：  
    `ΔAdelay_T,k→t,j = P(Aref_T,t|k,j) − P(Aref_k(tj)) + Γ(St, Sk)`，其中 `Γ` 将状态差转换为归一化动作坐标，涵盖参考动作不匹配与参考状态对齐。
  - **修正策略网络**：输入条件集 `Ct` 包含缓存的上下文 token、力编码、当前状态、插值后的参考动作段、时序特征（缓存年龄与插值相位）；共享注意力模块 `Φ` 用同一组参数、同一个可学习查询 `qcorr` 评估两次——一次用全部条件输出力修正，一次**掩蔽力 token** 输出延迟修正；两个独立输出头分别预测 K=5 步修正。
  - **异步调度回放**：训练前采样查询周期与推理延迟，回放固定调度，选取「最近开始且推理已完成」的参考查询，构造学生输入与配对目标。
  - **蒸馏损失**：带归一化时间权重 `wj ∝ β^(j−1)` 的位姿 MSE 之和，力修正项与延迟修正项以 `λdelay` 加权。

### 2.3 异步部署
- 教师周期性用无力感知模式刷新缓存参考；学生查询持续进行，每次读取最近完成的参考更新并与其修正量配对；
- 执行器选取「最近开始、结果完整且仍有效」的学生查询，插值参考动作、分别裁剪两个修正量、按公式合成归一化位姿，再转换为绝对命令；
- 过期步骤跳过，有效修正步保持到下一个时间戳或更新的有效结果出现。

## 6. 主要结论与发现

- **成功率**：ForceDelta-VLA 平均 **82.2%**，显著高于 ForceVLA 的 54.4%、TA-VLA 的 57.2%、π0.5 的 47.2%、ImplicitRDP 的 45.0%，也高于阶段 1 教师直接执行的 70.6%（提升约 11.7 个百分点）。
- **接触力**：相比 ForceVLA，成功试验平均峰值接触力在单臂与双臂平台各降低约 4.2 N / 4.3 N（约 **26%**）。
- **完成时间**：相比 ForceVLA 分别减少 5.2 s（单臂）与 5.9 s（双臂）。
- **异步更新有效性**：参考动作延迟从 0 增至 200 ms 时，ForceDelta-VLA 成功率下降 15 个百分点，教师下降 25 个百分点，说明在参考更新之间更新修正量确有价值。
- **消融结论**：
  - 用「演示动作减去无力感知预测」作为监督，成功率下降 12.5/17.5 个百分点，说明**教师配对预测定义的力修正目标更优**；
  - 去掉力修正、去掉延迟修正、力历史置零、单一合并修正头、快速全动作蒸馏均导致性能下降；
  - 关闭调度回放也显著降低成功率（7.5/12.5 个百分点），说明**异步训练回放必要**。
- **泛化**：未见物体上成功率 66.7%，高于教师的 40.0% 与 ImplicitRDP 的 16.7%，峰值力降低 8.2 N。
- **失败模式**：插入任务中易卡在边缘或姿态小误差导致卡死，修正不足以回退重试；拉拽类任务在未建立稳定接触前就施力；擦拭/翻转任务接触几何错误。

## 7. 优点

- **监督构造巧妙**：仅用原始演示数据，通过冻结教师的「力条件/无力感知」配对预测构造显式力修正目标，避免了对额外奖励或在线交互的依赖，属于对分类器无关引导（CFG）思想的迁移创新。
- **延迟修正设计完整**：显式建模参考动作不匹配与参考状态对齐，弥补了「力目标在时间上超前于实际复用参考动作」的缺口。
