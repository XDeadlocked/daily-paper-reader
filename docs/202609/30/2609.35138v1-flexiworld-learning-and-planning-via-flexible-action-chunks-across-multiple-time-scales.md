## 摘要
潜在世界模型利用跨越多个基元步骤的动作块来预测未来状态，以进行目标导向规划。现有方法通常使用固定长度动作块，并且要么忽略目标条件动作生成，要么将其监督限制在短目标跨度上。我们提出了 FlexiWorld，一种基于 JEPA 的世界模型，它将混合跨度目标监督与可变长度动作块相结合，以改善长时程控制。在训练期间，我们采样不同的目标跨度，并将动作随机划分为可变长度动作块。我们将世界模型与因果动作编码器以及自回归 actor 联合训练，其中因果动作编码器嵌入可变长度动作块，自回归 actor 按顺序生成基元动作。Student Forcing 通过在生成的动作前缀上进行训练来减少暴露偏差。在规划方面，Actor-Residual Cross-Entropy Method（ARCEM）将动作残差搜索与块内自回归反馈和块边界潜在预测相结合。在四个基准和不同目标距离上，FlexiWorld 与 ARCEM 结合取得了 89.29% 的平均成功率，而最强基线为 83.98%。PushT 消融实验表明，混合跨度监督、可变长度动作块和 Student Forcing 改善了直接控制。无需重新训练，FlexiWorld 支持不同的规划块长度：更长的块使 ARCEM 平均加速约 $1.3\times$，同时保持相当的平均成功率。

## Abstract
Latent world models predict future states for goal-directed planning using action chunks spanning multiple primitive steps. Existing methods typically use fixed-length chunks and either omit goal-conditioned action generation or limit their supervision to short goal spans. We introduce FlexiWorld, a JEPA-based world model that combines mixed-span goal supervision with variable-length action chunks to improve long-horizon control. During training, we sample varying goal spans and randomly partition the actions into variable-length chunks. We jointly train the world model with a causal action encoder that embeds variable-length chunks and an autoregressive actor that generates primitive actions sequentially. Student Forcing reduces exposure bias by training on generated action prefixes. For planning, Actor-Residual Cross-Entropy Method (ARCEM) combines action-residual search with within-chunk autoregressive feedback and chunk-boundary latent prediction. Across four benchmarks and goal distances, FlexiWorld with ARCEM achieves 89.29% mean success, compared with 83.98% for the strongest baseline. PushT ablations show improved direct control from mixed-span supervision, variable-length chunks, and Student Forcing. Without retraining, FlexiWorld supports different planning chunk lengths: longer chunks accelerate ARCEM by approximately $1.3\times$ on average while maintaining comparable average success.

## 1. 核心问题与研究动机

- **背景**：基于 JEPA（Joint Embedding Predictive Architecture）的潜在世界模型在表征空间中预测未来状态，避免重建像素图像。将多个基元动作（primitive action）打包成 **action chunk** 后，一次转移即可预测若干环境步之后的状态，规划器通过比较预测潜在状态与目标潜在状态来选动作。
- **现有方法的两个缺口**：
  - **目标条件动作生成不足**：LeWM 仅依赖 CEM 搜索、不学习如何生成动作；INTACT 虽训练共享 actor，但目标监督只覆盖短跨度，对远距离目标缺少直接监督。
  - **动作块长度固定**：LeWM、INTACT 使用固定长度块，每次预测转移跨越的基元步数恒定，规划器无法通过调整块长在"预测器调用次数"与"时间分辨率"之间权衡。
- **相关工作的局限**：VLWM 通过变预测时域、Fast-LeWM 通过并行前缀预测把预测扩展到多个动作块，但它们仍保留固定大小的基础动作块，灵活性体现在"跨越几个块"而非"块的基元动作边界"；二者均使用 CEM 而未联合训练目标条件 actor。
- **论文目标**：提出 **FlexiWorld**，将**混合跨度目标监督（mixed-span goal supervision）**与**可变长度动作块（variable-length action chunks）**结合，同时提升远距离目标下的动作学习与规划粒度，实现长时程控制。

## 2. 方法论

### 2.1 核心思想

- 训练时对同一轨迹窗口采样不同目标跨度，并随机把动作划分为变长块；世界模型、变长动作编码器、自回归 actor **联合训练**，参数在不同块长间共享。
- 部署时同一个模型可切换规划块长（如 5 或 10），无需重训练，从而调节规划开销与控制性能的权衡。

### 2.2 多时间尺度训练与变长块采样

- 从离线轨迹采样起点 s 与目标跨度 S ∈ {35, 55, 75} 基元步，窗口起点观测 o_s，目标为 o_{s+S}。
- 窗口内动作划分为 N = N(S) 个块（对应 7、11、15 块，使平均块长为 5），块长序列 k_i 满足 k_min ≤ k_i ≤ k_max、Σk_i = S，并**排除全等分（全为 5）的划分**；实验中 k ∈ {1,…,10}。
- 每个块 A_i = (a_{t_i},…,a_{t_i+k_i−1}) 连同起止观测构成一条监督转移，因此不同划分提供不同的中间转移但共享同一最终目标。

### 2.3 变长动作编码器与自回归 actor

- **动作编码**：观测编码器给出边界潜在状态 z_i = E_θ(o_{t_i})；变长因果 Transformer 动作编码器 A^VL_ω 处理块动作加位置编码，取最后一个有效隐状态，并加上学习到的块长嵌入，得到固定维嵌入 u_i，用于条件化预测器 ẑ_{i+1} = F_φ(H_i, u_i)；同一编码器还提供 actor 的前一块上下文 b_i。
- **动作生成**：自回归 actor G^AR_ψ 逐基元动作解码，条件分布按块内位置分解为对角高斯乘积：π^AR_ψ(A_i | c^q_i) = Π_{j=0}^{k_i−1} π^AR_ψ(a_{t_i+j} | c^q_i, A_{i<j})。块长 k_i 直接决定解码步数，不需要长度 token 或专门的长度头。
- **意图条件**：沿用 INTACT 的局部意图 m^local_i = z_{i+1} − z_i 与最终目标意图 m^goal_i = sg(z_N) − z_i（sg 为停止梯度）；Intent Context Builder 构造上下文 c^q_i = [z_i; m^q_i; z_i ⊙ m^q_i; b_i]。

### 2.4 Student Forcing（SF）

- 训练用专家前缀（Teacher Forcing），规划用自身生成前缀，存在**暴露偏差**。
- SF 以概率 p_SF（实验中 0.5）在每个块、每种意图上做一次**序列级**伯努利选择：以生成序列（停止梯度）或专家序列作为块内条件前缀；位置 j 只接收前 j 个动作，目标始终是专家动作 a_{t_i+j}。生成前缀不反传梯度，上下文 c^q_i 在两次前向间保持不变。
- 归一化使不同长度的块权重相同，避免长块被过度加权。

### 2.5 训练目标

- 总损失：L = L_pred + λ_act·L_NLL + λ_reg·L_SIGReg；其中 L_pred 为边界潜在状态的均方预测误差（更新预测分支与目标分支），L_NLL 为局部与目标两种意图的动作负对数似然（归一化到块长与动作维度），L_SIGReg 为 SIGReg 正则（把边界潜在拉向各向同性高斯，防止表征塌缩）。
- 权重：预测项权重 1，SIGReg 0.02，动作项 λ_act = 0.10（局部意图 0.10、目标意图 0.05）。所有模块从随机初始化联合训练，无预训练视觉骨干、无目标 EMA、无辅助时序损失。

### 2.6 规划：Direct 与 ARCEM

- **Direct 规划**：初始化 ẑ_0 = E_θ(o_s)、z_g = E_θ(o_g)，actor 与预测器交替；在第 i 个边界用目标意图 z_g − ẑ_i 与前一动作块上下文解码 k_i 个条件均值，块嵌入同时条件化下一步预测与下一次 actor 调用。D 步计划由 H 个转移组成，Σk_i = D。
- **ARCEM（Actor-Residual Cross-Entropy Method）**：把 POPLIN 的动作残差递推推广到自回归块——对 actor 均值加残差 a_{i,j} = μ_ψ(c_{i,j}) + T·ε_{i,j}；**块内**扰动动作会条件化后续生成，**潜在状态只在块边界更新**（每 ⌈D/k⌉ 次预测器调用）。代价取候选轨迹中距目标最近的边界潜在距离：C(ε) = min_{1≤i≤H} ‖ẑ_i(ε) − z_g‖²₂。残差分布从标准高斯起步，用精英均值与对角协方差更新；每轮候选池包含精确 Direct 计划并保留历史最优；k = 1 时退化为 POPLIN。主设置 T = 0.2、128 候选 × 3 轮、16 精英。
