## 摘要
奖励最大化强化学习（RL）被广泛用于对文本到图像（T2I）生成中的随机扩散与流策略进行后训练。然而，即使采用参考KL或熵正则化，奖励最大化RL仍会导致策略模式崩溃，使策略退化为单一高奖励模式。在T2I中，这会产生相似图像和奖励攻击。当扩展到视觉-语言-动作（VLA）模型时，同样的崩溃会消除其他成功策略，并削弱任务与场景泛化能力。为解决这一局限，我们提出统一轨迹匹配策略优化（Uni-TMPO），一个用于扩散与流策略的统一RL后训练框架。首先，Uni-TMPO将标准化奖励转换为每个轨迹组内的目标分布，并从轨迹对数概率中推导策略分布。然后，前向Kullback-Leibler优化匹配这两个分布，而不是最大化期望奖励。一种进度条件化的由粗到细调度器高效构建T2I轨迹。在该统一框架内，反馈条件化采样利用更新后的观测构建VLA轨迹。大量实验表明，Uni-TMPO相比最强基线取得了更高的T2I奖励和VLA ID成功率。更重要的是，它在T2I奖励-多样性-效率权衡以及VLA对留出任务和场景的泛化方面取得了最佳表现，同时真实机器人评估证明了当更高奖励目标被阻挡时多种动作策略的价值。

## Abstract
Reward-maximizing reinforcement learning (RL) is widely used to post-train stochastic diffusion and flow policies for text-to-image (T2I) generation. However, reward-maximizing RL causes policy mode collapse even under reference KL or entropy regularization, reducing the policy to a single high-reward mode. In T2I, this produces similar images and reward hacking. When extended to vision-language-action (VLA) models, the same collapse removes alternative successful strategies and weakens task and scene generalization. To address this limitation, we introduce Unified Trajectory Matching Policy Optimization (Uni-TMPO), a unified RL post-training framework for diffusion and flow policies. First, Uni-TMPO converts standardized rewards into a target distribution within each trajectory group and derives the policy distribution from trajectory log probabilities. Then, forward Kullback-Leibler optimization matches the two distributions instead of maximizing expected reward. A progress-conditioned coarse-to-fine scheduler efficiently constructs T2I trajectories. Within the unified framework, feedback-conditioned sampling uses updated observations to construct VLA trajectories. Extensive experiments show that Uni-TMPO achieves higher T2I rewards and VLA ID success rates than the strongest baselines. More importantly, it achieves the best T2I reward-diversity-efficiency trade-off and VLA generalization to held-out tasks and scenes, while real-robot evaluation demonstrates the value of multiple action strategies when the higher-reward target is blocked.

  - T2I 中：不同噪声初始化生成相似图像，出现奖励黑客（reward hacking），代理奖励上升但感知质量与多样性下降；

- **整体含义**：论文指出，采样独立高斯噪声看似带来随机性，但在奖励最大化后训练后并不能保留不同模式。作者提出一个**统一框架**，用分布匹配替代奖励最大化，以同时支撑 T2I 多样生成与 VLA 多策略泛化。核心研究问题是：如何在统一框架内实现图像与动作生成的 RL 后训练，同时保留多样解模式并支持 OOD 泛化？

## 二、方法论：核心思想、关键技术细节与算法流程

### 2.1 核心思想

- **统一接口**：将 T2I 和 VLA 输出统一表示为**上下文条件化的随机轨迹**。每个轨迹 τ 提供：上下文 c、终端/回合奖励 R、可微轨迹分数 s_θ（由随机转移对数概率累加得到）。
- **关键转换**：不再最大化期望标量奖励，而是将**标准化奖励转换为组内目标分布 q**，将**轨迹对数概率转换为策略分布 p_θ**，通过**组内前向 KL** 匹配二者。

### 2.2 关键技术细节与公式

1. **轨迹组构建**：对每个上下文 c，策略采样 K 条轨迹 G(c) = {τ_i}，每条轨迹给出奖励 R_i 和轨迹分数 s_{θ,i}。
2. **奖励诱导目标分布（Boltzmann 目标）**：组内标准化奖励后，
   - q_i = exp(β·ẽR_i) / Σ_j exp(β·ẽR_j)，q ∈ Δ^{K−1}
   - β 为逆温度，控制对高奖励轨迹的偏好强度；β 较小时多个高奖励轨迹均保留概率。
3. **组内轨迹概率**：
   - p_{θ,i} = exp(s_{θ,i}) / Σ_j exp(s_{θ,j})，p_θ ∈ Δ^{K−1}
4. **前向 KL 匹配损失**：
   - 仅优化奖励有差异的有效组（max R_i − min R_i > ε_R）；
   - L_TM(θ) = (1/|B_valid|) Σ_{G∈B_valid} KL(q_G ‖ p_{θ,G})；
   - 单组 KL(q‖p_θ) = −Σ_i q_i log p_{θ,i} + C_q。
5. **梯度与信用分配**：
   - ∇_θ L_G = Σ_i (p_{θ,i} − q_i) ∇_θ s_{θ,i}
   - 若 p_{θ,i} < q_i，则提高该轨迹相对概率；若 p_{θ,i} > q_i，则降低；系数有界且和为 0，分布一致时梯度消失。
   - 当轨迹分数可分解为 s_{θ,i} = Σ_u w_{i,u} ℓ_{θ,i,u} 时，转移级信用为 ∂L_G/∂ℓ_{θ,i,u} = w_{i,u}(p_{θ,i} − q_i)。
6. **域特定轨迹构造**：
   - **T2I：进度条件化由粗到细采样**。共享前缀分支，使用有界 Beta 调度器；早期训练在较早去噪步分支以探索全局结构，训练推进后移到较晚步以精修局部细节；轨迹分数为完整去噪 rollout 中随机转移对数密度之和（各叶节点随机转移数相同，无需长度归一化）。
   - **VLA：反馈条件化动作块采样**。每个有效查询 t 下动作专家生成一个动作块，执行其前缀后获得新观测再规划；轨迹分数为各动作块随机流转移对数概率的**长度归一化平均**（几何平均的对数），以比较不同查询数的轨迹；掩码排除填充查询、确定性流步和填充动作条目。

### 2.3 算法流程（Alg. 1 文字说明）

- 输入：策略 π_θ、上下文集合 C、组大小 K、温度 β、阈值 ε_R；
- 对每个上下文采样 K 条轨迹，记录分离梯度后的奖励和轨迹分数；
- 若组内奖励差异大于 ε_R，则计算目标分布 q_c 与策略分布 p_c，累加 KL 损失；
- 对有效组平均后执行梯度下降更新 θ；
- 奖励与环境转移保持不可微；VLA 中梯度仅穿过可训练的动作专家，视觉-语言骨干冻结。

## 六、主要结论与发现

1. **T2I 结果**：
   - Uni-TMPO 在 GenEval 达 0.954、OCR 达 0.951，均为最高；偏好优化中 ImageReward 和 PickScore 最高，HPS 第二；
   - 相比 Flow-GRPO/TreeGRPO（会降低 LGMD 和余弦多样性），Uni-TMPO 同时提升任务指标与两项多样性指标；
   - LGMD 比最强基线最高提升 28.4%；迭代时间比 DGFS 低 42–49%，比 TreeGRPO 调度减少 10.2%；
   - 多奖励设置下（OCR+PickScore），Uni-TMPO 达 0.932 OCR / 23.897 PickScore / LGMD 0.155 / 余弦 0.248，优于 Flow-GRPO（0.928 / 23.081 / −0.049 / 0.209）。
2. **VLA ID 结果**：
   - π0：LIBERO 97.8%、MT50 88.6%、CALVIN-D 63.9%，分别超最强 πRL 基线 0.2、2.8、2.2 个百分点；
   - π0.5：98.6%、72.8%、89.2%，分别超 0.3、2.1、2.2 个百分点。
3. **VLA OOD 结果**：
   - MetaWorld ML45：π0 达 69.9%（超 SFT +20.0，超基线 +4.4）；π0.5 达 59.3%（超 SFT +18.1，超基线 +11.5）；
   - CALVIN ABC→D：π0 达 61.9%（超 SFT +4.4，超基线 +6.6）；π0.5 达 82.1%（超 SFT +20.8，超基线 +3.0）。
4. **多策略保留**：
   - WallDetour 中奖励最大化将 LEFT/RIGHT 质量集中于 0.95/0.05（归一化熵 0.29），Uni-TMPO 保持 0.55/0.45（熵 0.99）；LEFT 被阻挡后仅 Uni-TMPO 能经 RIGHT 完成任务；
   - 真机双目标放置中，奖励最大化两条 rollout 均选左目标，左侧被阻挡后失败；Uni-TMPO 可切换到右目标成功。
5. **总体结论**：组内前向 KL 轨迹匹配为随机扩散与流策略提供了统一的 RL 后训练框架，保留多样解模式并支持 OOD 泛化；未来可扩展到视频、音频、3D 生成、分子/蛋白质设计和基于扩散的规划。

## 七、优点

- **方法层面**：
  - 用**组内分布匹配替代奖励最大化**，从原理上缓解模式坍塌，而非依赖领域特定多样性评估器或显式多样性奖励；
  - 组内标准化使共享归一化项相消，**无需像 FlowRL 那样学习 prompt 条件归一化器 Z_ϕ**；
  - 前向 KL 在采样轨迹上**可精确计算**，梯度形式简洁（p−q 加权），系数有界且和为 0，训练稳定；
  - 提供转移级信用分配公式，能将轨迹级修正传播到记录的随机决策；
  - **统一框架 + 域特定轨迹构造**的设计兼顾通用性与适配性。
- **实验层面**：
  - 同时覆盖 T2I 与 VLA，且在两领域都做了 ID 与 OOD 评测；
  - 多样性指标采用 LGMD（VAE 潜空间近重复检测）与 DINOv2 余弦多样性，较有针对性；
  - 包含 WallDetour 与真机实验，直接验证“多策略在高奖励目标受阻时的价值”这一核心动机；
  - 声明所有对比方法共享提示、种子、组大小、环境与交互预算，公平性较好。
