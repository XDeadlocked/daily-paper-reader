## 摘要
近年来，视觉-语言-动作模型（VLA）通过将大语言模型（LLM）的语义理解与流匹配策略的精确控制相结合，改变了机器人操作领域。优势条件化是一种近期技术，它通过在部署数据上训练价值函数，并利用该价值函数训练优势条件化策略，从而迭代地改进 VLA。先前工作仅使用了简单、信息量低的成功/失败奖励，这使得价值函数只能根据状态在任务中的进展程度来区分，而无法区分质量不同的状态。受对分布外（OOD）检测方法的探索启发，我们提出了基于距离的优势学习（DistAL）。该方法通过使用嵌入空间距离作为奖励，产生信息量更大的价值函数，并随之获得更高的下游任务成功率。我们在系列仿真基准和真实硬件上的灵巧双臂操作任务中验证了我们的方法。

## Abstract
Vision-language-action models (VLAs) have trans- formed the field of robotic manipulation in recent years by combining the semantic understanding of LLMs with the precise control of flow-matching policies. Advantage conditioning is a recent technique that iteratively improves VLAs by training a value function on deployment data and using this to train an advantage-conditioned policy. Previous works have only applied simple, low-information success/failure rewards, which leave the value function unable to distinguish states of differing quality beyond how far along the task they appear. Motivated by an exploration of out-of-distribution (OOD) detection methods, we introduce Distance-based Advantage Learning (DistAL), which, by using an embedding space distance as a reward, produces a more informative value function and subsequently a higher downstream task success rate. We validate our method on a series of simulation benchmarks and dexterous bi-manual manipulation tasks on real hardware.

## 1. 核心问题与研究动机

- **背景**：VLA（视觉-语言-动作模型）结合 LLM 语义理解与流匹配（flow-matching）精确控制，已显著推进机器人操作，但接触密集、灵巧操作任务的成功率仍不足以支撑真实部署。
- **现有改进路线的痛点**：
  - 干预数据（intervention）方法需要专家遥操作员全程待命，硬件与运营成本高。
  - 在线 RL 微调 VLA 存在样本效率低、不稳定、算力开销大等问题。
  - 优势条件化（advantage conditioning）作为离线 RL 式方案，无需专家干预，但**此前仅使用稀疏的成功/失败二值奖励**。
- **核心缺陷**：二值奖励下每步惩罚恒定，价值函数只能按"任务进展程度"排序状态，无法区分质量不同的状态。例如"勉强抓住物体的不稳定抓取"与"牢固抓取"价值相同，尽管成功率差异巨大。自定义任务奖励则牺牲可扩展性。
- **核心假设**：失败轨迹相对于成功参考数据集应属于分布外（OOD）。作者通过探索 OOD 检测方法，发现**图像嵌入空间中的 kNN 距离**最能预测失败，遂将其用作奖励。

## 2. 方法论

### 核心思想
DistAL 是优势条件化流程中**奖励信号的即插即用替换**：策略、价值函数、训练流程均保持不变，仅将稀疏成功/失败奖励替换为基于 kNN 嵌入距离的稠密奖励，从而隔离奖励设计这一单一变量。

### 关键技术细节
- **kNN 特征距离奖励**：
  - 使用冻结的图像编码器 f（基础 VLA 的**微调版 SigLIP** 视觉编码器，非原始 SigLIP）。
  - 对基础 VLA 训练集 D_train 的观测建立嵌入索引 I。
  - 对部署观测 o，计算其到 I 中 k 个最近邻的平均欧氏距离 s_k(o)（k=10）。
  - 每步奖励 r_t = −s_k(o_t)，归一化到 [−1, 0]：接近训练分布得低分（高奖励），偏离得高分（低奖励）。
  - 保留失败回合的**大终端惩罚**，防止策略通过停留在熟悉的早期状态"刷奖励"。

### 架构

## 6. 主要结论与发现

- **OOD 检测**：kNN-SigLIP 距离在轨迹级（均值 0.82）与逐步级（均值 0.67）均为最强失败预测器，优于 VAE 似然（0.79/0.65）、Mahalanobis（0.71/0.58）、post-LM token（0.57/0.51）和动作块方差（0.58/0.51）。语言模型上下文化反而冲淡信号。
- **仿真性能**：DistAL 在 LIBERO-10 达 96.2%，总体均值 78.4%（较 base +3.3）；优势条件化本身贡献主要增益，稠密距离奖励额外贡献 +1.2。SFT 与 base 几乎无差别（−0.3），说明增益来自价值函数而非数据子集。
- **扰动类型差异**：两种优势条件化方法在 base 最差的扰动上收益最大（Camera +25.2、Noise +14.1、Texture +10.7）；DistAL 在 Camera 和 Texture 上达到 100%。但在 Layout 和 Language 上两者均显著回退（77.8→64.0、76.6→65.6），作者归因于这些扰动视觉上接近训练分布但改变了正确行为，属优势条件化本身的性质。
- **真机性能**：拔网线任务 DistAL 达 87%（base 46%、二值奖励 72%），为全文最强单项结果；笔帽任务 52%（base 42%、二值奖励 48%），与二值奖励在 50 回合下无统计显著差异。
- **核心条件性结论**：**DistAL 的收益取决于失败模式是否在视觉上可与成功区分**——网线失败（线未拔、手臂错过端口）逐步 AUROC 0.94，收益显著；笔帽失败是图像看不到的接触滑脱，逐步 AUROC 仅 0.56，收益退化为二值奖励加噪声。

## 7. 优点

- **变量隔离干净**：奖励信号是唯一被替换的组件，策略、价值函数、训练流程完全固定，使对比结论归因明确。
- **奖励设计有实证依据**：先系统比较 5 种 OOD 检测器对失败的预测能力（含轨迹级与逐步级），再据此选定 kNN 距离，而非凭直觉设定。
- **奖励稠密且具时序梯度**：Fig.3 显示 kNN 分数在成功/失败轨迹间的差距随回合推进逐步拉开，为价值函数提供分级的局部信用分配信号，而非延迟的终局信号。
- **零额外人工成本**：无需专家干预、无需任务特定奖励工程或逐帧标注，仅需基础 VLA 的训练集嵌入索引。
- **诚实的结果报告**：明确指出方法在 Layout/Language 扰动和笔帽任务上无优势甚至回退，并给出可检验的解释，而非只报喜。
- **仿真 + 真机双重验证**：真机结果（网线任务 +41 点）比仿真结果更具说服力。

## 8. 不足与局限

- **奖励信号单一模态**：纯图像驱动，忽略力、接触稳定性、机器人状态与语言；直接导致笔帽任务（视觉不可见的滑脱）表现受限。
