## 摘要
动作条件世界模型是具身智能的关键组成部分，可作为可扩展的策略评估器，减少对昂贵的真实世界 rollout 的依赖。为了准确捕获由不同动作引发的动态变化，这类模型应满足三个关键目标——物理合理性（P）、动作遵循（A）和视觉保真度（V），统称为 PAV ——同时保持对分布内（ID）专家演示和分布外（OOD）动作的鲁棒性。然而，现有方法主要依赖 ID 动作-视频对和像素级重建损失，并未显式优化 PAV 目标，且在专家数据之外的泛化能力较差。为解决这一问题，我们提出 PAVXploreRL，一种基于预训练潜在世界模型的强化学习框架，通过奖励驱动训练显式优化 PAV 目标。为提升动作泛化能力，我们的方法联合利用 ID 轨迹和噪声驱动的 OOD 动作探索，无需配对视频监督。实验表明，PAVXploreRL 持续优于预训练基线，在多个基准上平均提升 5.6%，并生成更高质量的 PAV 属性。作为策略评估器，它还能提供更可靠的性能估计，并减少如 Ctrl-World 等先前仅使用专家数据的世界模型的过估计偏差。代码：https://github.com/Social-AI-Studio/PAVXploreRL

## Abstract
Action-conditioned world models are a key component of embodied AI, serving as scalable policy evaluators that reduce reliance on expensive real-world rollouts. To accurately capture diverse action-induced dynamics, such models should satisfy three key objectives-Physical Plausibility (P), Action Adherence (A), and Visual Fidelity (V), collectively referred to as PAV-while remaining robust to both in-distribution (ID) expert demonstrations and out-of-distribution (OOD) actions. However, existing methods primarily rely on ID action-video pairs and pixel-level reconstruction losses, which do not explicitly optimize PAV objectives and generalize poorly beyond expert data. To address this, we propose PAVXploreRL, a reinforcement learning framework built on a pretrained latent world model that explicitly optimizes PAV objectives through reward-driven training. To improve action generalization, our method jointly leverages ID trajectories and noise-driven OOD action exploration, without paired video supervision. Experiments show that PAVXploreRL consistently outperforms pretrained baselines, achieving a 5.6% average gain across benchmarks and producing higher-quality PAV properties. As a policy evaluator, it also yields more reliable performance estimates and reduces the overestimation bias of prior expert-only world models such as Ctrl-World. - **问题**：现有方法主要依赖专家演示的分布内（ID）动作-视频对和像素级重建损失（如 MSE、SSIM），未显式优化 PAV 目标，导致：
  - 对分布外（OOD）动作（如次优策略产生的动作）泛化能力差；
  - 作为策略评估器时，容易高估 OOD 动作的成功率，产生过估计偏差。
- **动机**：需要一种能同时利用 ID 动作和 OOD 动作、无需配对视频监督的训练范式，显式优化 PAV 目标，提升世界模型的通用性和评估可靠性。

## 2. 提出的方法论

### 2.1 核心思想
- 基于预训练的潜空间世界模型 VJEPA-2（具有强物理理解能力），通过强化学习（RL）驱动训练，设计一组互补奖励函数显式优化 PAV 目标。
- 同时利用 ID 轨迹（具有 GT 视频）和对 ID 动作施加控制噪声生成的 OOD 动作（无 GT 视频），实现动作探索。

### 2.2 关键技术细节
- **世界模型架构**：基于 Wan2.2-TI2V-5B（视频扩散模型），添加动作条件注入（AdaLN + 时间嵌入）和 Framepack 历史帧压缩策略。先 SFT 训练，再 RL 微调（仅更新动作编码器和 LoRA 参数）。
- **RL 训练框架**：采用 Diffusion-NFT（前向过程强化学习），生成 G 组未来帧，由奖励函数得到评分 r，构建隐式正负去噪目标，优化 reward-weighted denoising loss：
  ```math
  L(θ) = E[ r ∥x̂⁺₀ - x₀∥² + (1-r) ∥x̂⁻₀ - x₀∥² ]
  ```
- **奖励函数设计**：
  - **ID 分支**（有 GT 视频）：组合像素级奖励（MSE/SSIM/LPIPS）、VJEPA 编码器奖励（rVJEPA-E, 度量预测帧与 GT 帧在潜空间的差异）、视觉保真度奖励 rVF（包含拉普拉斯锐度、NIQE、光流分布、时间一致性等无参考指标）。最终 rID = λpixel rpixel + λVJEPA rVJEPA-E + λVF rVF。
  - **OOD 分支**（无 GT 视频）：使用 VJEPA 预测器奖励 rVJEPA-P（比较世界模型预测帧与 VJEPA-2 预测的潜表示），加上静态-运动正则化（减去零动作序列的奖励），以及视觉保真度奖励 rVF。最终 rOOD = (1-λVF) rVJEPA-P + λVF rVF。
  - 通过伯努利采样选择使用 ID 或 OOD 分支（超参数 αOOD 控制 OOD 比例）。
- **OOD 动作生成**：对非静态 GT 动作段施加三种扰动：时间偏移（±0.6s）、结构化幅度偏置（±0.15）、平滑时间噪声（高斯噪声+时间累积）。
- **VJEPA-2 训练**：两阶段训练。Stage1：标准单步预测；Stage2：累积多步预测（整个动作块 T），并使用原始帧和具身分割帧（通过 GroundingDINO + SAM 提取机器人区域）两种输入，增强对动作的敏感性。

## 6. 主要结论与发现
- PAVXploreRL 在 Agibot 和 DROID 上均持续优于 SFT 预训练基线，平均提升 5.6%（PSNR、SSIM、LPIPS、EPE 等指标）。
- 定性结果表明，RL 后模型在物理合理性（物体恒存性）、动作遵循性（准确执行精细动作）、视觉保真度（减少运动模糊）上显著提升。
- 作为策略评估器，PAVXploreRL 给出的成功率估计比 Ctrl-World 更接近真实世界结果，减少了对 OOD 次优策略的过估计偏差。
- 消融显示，OOD 分支（VJEPA 预测器奖励）、静态正则化、具身帧奖励、视觉保真度奖励均贡献增益，缺一不可。

## 7. 优点
- **首次用 RL 直接优化 PAV 三目标**：通过精心设计的奖励函数，同时监督物理合理性、动作遵循性和视觉保真度。
- **无需配对视频即可利用 OOD 动作**：创新地使用 VJEPA-2 的潜预测能力构造无参考奖励，实现真实动作探索，提升泛化性。
- **模型无关的通用框架**：可应用于任意动作条件世界模型（本文以视频扩散模型为例），只需修改动作编码和 LoRA 参数。
- **实验完整、消融彻底**：同时考察了分布内和分布外情况，并进行了 VLA 下游评估，验证了作为策略评估器的实用性。

## 8. 不足与局限
- **未显式建模多视角一致性**：当前仅使用单视角观测，无法处理多视角场景下的空间一致性。
- **训练时间长**：尽管采用 Diffusion-NFT 高效 RL 框架，但 rollout 和奖励计算仍造成较大计算开销，仅适合作为后训练阶段。
- **OOD 动作生成方法依赖初始 ID 动作**：通过扰动 GT 动作生成 OOD 样本，可能无法覆盖所有真实次优模式。
- **视觉保真度奖励依赖无参考指标**：这些指标（如 NIQE）的物理意义有限，可能无法完美捕捉所有视觉缺陷。
- **VLA 评估规模有限**：仅测试 5 个任务、每任务 10 个 episode，统计显著性有待进一步验证。
