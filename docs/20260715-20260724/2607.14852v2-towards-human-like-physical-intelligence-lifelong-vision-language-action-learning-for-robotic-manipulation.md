## 摘要
与人类逐步学习新任务的自然能力类似，配备视觉-语言-动作（VLA）模型的机器人在部署于开放世界环境时应具备终身学习能力，以学习新任务。然而，近期提出的大多数终身学习模型旨在有效学习当前任务（可塑性）或保持先前任务的高准确率（稳定性），而在机器人操作模型中，可塑性-稳定性权衡问题仍未得到充分解决。为应对这一基本挑战，我们提出了一种用于机器人操作的缓存高效终身视觉-语言-动作学习框架（即LifelongVLA），该框架通过双时间尺度自适应机制缓解可塑性-稳定性权衡，同时利用缓存高效的重放策略实现低成本机器人部署。具体而言，我们提出了一种双时间尺度LoRA门控模块，将VLA自适应分解为两个轻量级通路：用于可塑性的短期适配器和用于稳定巩固的长期适配器。这些通路通过任务感知门控集成，能够显式控制可塑性-稳定性权衡。在技能重放阶段，我们提出了一种缓存高效的随机重放策略，无需存储完整轨迹即可保留更平衡的保留信号。最后，实验表明LifelongVLA优于现有基线，展示了高效的技能扩展、对已学习操作行为的稳健保留，以及在xArm机器人上实际部署时减少对重新训练的依赖。

## Abstract
Similar to the natural capabilities of humans to sequentially learn new tasks, robots with Vision-Language-Action (VLA) models should possess lifelong learning ability to learn a new task when deployed in open-world environments. However, most recently proposed lifelong learning models aim to effectively learn the current task (plasticity) or maintain high accuracy on previous tasks (stability), while the plasticity-stability trade-off remains largely unsolved in robotic manipulation models. To address this fundamental challenge, we propose a cache-efficient lifelong Vision-Language-Action learning framework for robotic manipulation (i.e., LifelongVLA), which alleviates the plasticity-stability trade-off with a dual-timescale adaptation mechanism while achieving low-cost robotic deployment with a cache-efficient replay strategy. More concretely, we propose a dual-timescale LoRA gating module to decompose VLA adaptation into two lightweight pathways: a short-term adapter for plasticity and a long-term adapter for stable consolidation. These pathways are integrated via a task-aware gate, enabling explicit control of the plasticity-stability trade-off. In the skill replay phase, a cache-efficient stochastic replay strategy is proposed to preserve more balanced retention signals without full-trajectory storage. Finally, experiments show that LifelongVLA outperforms existing baselines, demonstrating efficient skill expansion, robust retention of learned manipulation behaviors, and reduced reliance on retraining for real-world deployment on an xArm robot.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：当前大多数视觉-语言-动作（VLA）模型采用静态离线训练范式，在固定技能集上训练后部署，无法适应开放世界中持续出现的新物体、指令和场景。面临的主要挑战是**灾难性遗忘**——学习新技能时覆盖旧知识，导致先前任务性能严重下降。
- **基本矛盾**：终身学习中存在**塑性（plasticity）与稳定性（stability）的权衡**——高塑性使模型快速适应新技能，但可能破坏旧知识；高稳定性保留旧技能，但限制未来学习。现有方法（如经验重放、参数隔离等）未能充分解决此权衡。
- **研究意义**：实现机器人**类人物理智能**，使其能像人类一样持续积累技能，同时低成本部署，是开放世界机器人操作的关键需求。

## 2. 论文提出的方法论

### 核心思想
提出 **LifelongVLA** 框架，通过**双时间尺度LoRA门控模块** 分离塑性（短期）与稳定（长期）更新通路，并用**任务感知门控**动态组合，实现显式控制塑性-稳定性。同时设计**缓存高效随机重放模块**，仅存储紧凑的停止梯度前缀令牌，避免完整轨迹重放，降低存储和计算开销。

### 关键技术细节
- **双时间尺度LoRA门控**：
  - 对每个适配层，定义两个LoRA通路：
    - **短期适配器** (`∆W^ℓ_sh,t`)：由当前任务损失 (`L_new`) 更新，用于快速学习新技能（高塑性）。
    - **长期适配器** (`∆W^ℓ_lg,t`)：仅由重放损失 (`L_rep`) 和蒸馏损失 (`L_dist`) 更新，学习率较小 (`η_lg < η_sh`)，用于稳定巩固旧技能。
  - **任务感知门控**：利用冻结前缀特征计算门控上下文 `c`，预测长期通路的贡献系数 `α^ℓ_t(c) ∈ [0,1]`（通过sigmoid激活）。门控参数跨样本共享，但上下文依赖具体样本。
  - **权重级组合**：最终LoRA更新为 `∆W^ℓ_t(c) = (1-α)∆W^ℓ_sh,t + α·∆W^ℓ_lg,t`，单一前向传播即可完成。

- **缓存高效随机重放**：
  - **技能级前缀缓存**：每个新任务随机选择至多 `c_t` 个样本，仅缓存停止梯度的前缀令牌 `h̄_pre` 和紧凑的状态-动作监督 `(s, y)`，不存储原始图像、语言令牌、扩散噪声等。
  - **随机重放**：从缓存中取出样本后，重新采样扩散变量和时间步，使用当前模型重新计算后缀令牌，生成多样化的去噪实例。每次重放可生成多个随机实例，避免缓存特征过时。
  - **掩码新-重放目标**：当前样本和重放样本混洗在同一批次，分别计算归一化的 `L_new` 和 `L_rep`，并引入蒸馏损失 `L_dist`（使用前一个任务的冻结快照作为教师）。最终损失 `L_t = L_new + λ·L_rep + β·L_dist`。

## 3. 实验设计

- **数据集与场景**：
  - 主要实验在 **LIBERO 基准** 上进行，选取 **10 个操作任务** 进行增量式技能学习。每个增量步骤引入一个新任务，训练后评估所有已见任务。
  - 额外在 **真实世界的 xArm 机器人** 上进行了 **5 任务** 流评估，每个任务收集 50 个训练回合和 50 个测试回合。

- **基准对比方法**：
  - **SFT**（序列微调）：直接在新任务上微调所有参数。
  - **LwF-LoRA**：使用输出蒸馏的“无遗忘学习”变体。
  - **ER**：经验重放，存储过去轨迹。
  - **Info-VLA**：基于信息论约束的正则化方法。
  - **AtomicVLA**：面向技能级专家特化的方法。
  - **联合训练（Joint）**：所有任务数据同时训练，作为性能上限（不参与排名比较）。

- **评价指标**：
  - **平均成功率（SR, %）**：所有任务最终性能的平均值。
  - **遗忘率（FOR, %）**：对于每个旧任务，从历史最高性能下降的程度，取平均。
  - **过程级增量准确率（ACC_t）**：前 t 个任务的平均成功率。

- **实现细节**：使用冻结的 PaliGemma（Gemma 2B）骨干，Gemma 300M 连续动作解码器；每个任务训练 10,000 步，联合训练 40,000 步；LoRA 秩 r=16，缩放因子 γ=16；缓存大小 M=500，每任务配额 c_t=50；损失权重 λ=1.0, β=0.1。
