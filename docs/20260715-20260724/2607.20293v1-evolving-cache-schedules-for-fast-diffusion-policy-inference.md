## 摘要
扩散策略通过迭代去噪动作块实现强大的视觉运动控制，但重复去噪使得实时部署计算需求高。基于缓存的方法通过重用中间激活来降低推理成本，但现有的免训练调度通常均匀分配计算到各块，忽略了块间的异构冗余，导致性能-效率权衡次优。为弥合这一差距，我们引入了演化式缓存调度（EVO），一种免训练加速框架，通过演化搜索全局调度缓存刷新。EVO将每个候选表示为块-时间步网格上的完整调度。因此，迭代去噪期间冗余的Transformer计算可以通过缓存重用跳过，同时保持闭环展开性能。为使搜索实用，EVO引入了冗余感知初始化（用有前景的调度初始化种群）和目标条件早停（一旦达到期望性能目标即验证并终止）。离线优化的调度可直接插入预训练扩散策略，无需重新训练。广泛的操作基准表明，EVO在保持接近完整性能的同时大幅减少计算，实现高达8.05倍的动作生成加速，并将FLOPs从15.77G降至低至1.96G。源代码见https://github.com/pillom/EVO。

## Abstract
Diffusion policies achieve strong visuomotor control by iteratively denoising action chunks, but repeated denoising makes real-time deployment computationally demanding. Cache-based methods reduce inference cost by reusing intermediate activations, but existing training-free schedules typically allocate computation uniformly across blocks, ignoring heterogeneous redundancy across blocks and leading to a suboptimal performance-efficiency trade-off. To bridge this gap, we introduce Evolving Cache Schedules (EVO), a training-free acceleration framework that globally schedules cache refreshes via evolutionary search. EVO represents each candidate as a complete schedule over the block-timestep lattice. Thus, redundant transformer computations during iterative denoising can be skipped through cache reuse while preserving closed-loop rollout performance. To make the search practical, EVO introduces redundancy-aware initialization, which seeds the population with promising schedules, and target-conditioned early stopping, which verifies and terminates once a desired performance target is reached. The offline-optimized schedule can be directly plugged into pretrained diffusion policies without retraining. Extensive manipulation benchmarks show that EVO preserves near-full performance while substantially reducing computation, achieving up to 8.05x action-generation speedup and reducing FLOPs from 15.77G to as low as 1.96G. Source code is available at https://github.com/pillom/EVO.

- **背景**：扩散策略（Diffusion Policy）通过迭代去噪动作块来实现强大的视觉运动控制，但重复的Transformer推理导致计算开销巨大，难以满足实时机器人控制对低延迟的要求。
- **已有工作**：基于缓存的加速方法通过重用中间激活来减少计算（如EfficientVLA、BAC），但现有调度策略通常均匀分配计算资源到各Transformer块，忽略了不同块在去噪过程中的异构冗余（即某些块的特征变化大、需频繁刷新，而另一些块冗余高、可重用）。
- **核心问题**：如何在不重训练、不改变采样器的情况下，自动搜索一个全局最优的缓存刷新调度，在固定计算预算下最大化闭环任务性能？
- **整体含义**：首次将缓存调度视为在块-时间步网格上的全局资源分配问题，并通过进化搜索直接优化下游成功率，实现了接近完整的策略性能且大幅加速（最高8.05倍）。该方法为扩散策略的实时部署提供了一种有效的训练无关加速方案。

## 2. 方法论：核心思想、关键技术细节

- **核心思想**：将预训练扩散策略的推理加速建模为**固定预算的全局缓存调度问题**。在由B个可缓存模块（每个Transformer层的自注意力、交叉注意力、前馈网络）和T个去噪时间步构成的二维网格上，选择K个位置执行原始计算（刷新缓存），其余位置重用最近缓存的残差；通过进化算法搜索最优子集S。
- **关键技术细节**：
  1. **全局缓存调度公式**：每个候选调度S ⊆ B × T，|S| = K。执行时，被选中的位置(b,t)计算残差并更新缓存cb，未选中的位置直接返回当前cb。
  2. **进化搜索流程**（图2a）：
     - **个体表示**：包含K个唯一刷新位置（块-步对）的集合。
     - **适应度函数**：直接使用加速策略在模拟环境中的闭环**成功率**（20个episodes快速评估）。
     - **遗传操作**：锦标赛选择、集合级交叉、变异（重采样部分位置）、修复（确保K个唯一位置）、精英保留。
     - **去重**：已评估的调度通过规范签名存储，避免重复展开。
  3. **冗余感知初始化（RI）**（图2b）：使用激活余弦不相似度估计每个块-步位置的冗余程度，将较低冗余（高不相似度）的位置以更高概率采样，生成部分初始个体（同时保留随机个体以保持探索）。
  4. **目标条件早停（TCES）**（图2c）：快速评估中若某调度达到全精度策略性能qbase，则触发正式评估（50个独立种子）；若正式结果满足qbase - δacc，则终止搜索并输出该调度，否则继续。
- **算法流程**（文字描述）：
  - 离线阶段：收集少量无缓存策略的激活，计算各位置的不相似度分布 → 使用RI生成初始种群（含引导个体和随机个体） → 迭代进行适应度评估、选择、交叉、变异、修复、早停检查 → 输出最佳验证调度。
  - 部署阶段：加载离线调度，在推理时按式(1)决定每个块-步位置刷新或重用缓存，不修改策略权重、观察编码器、采样器或动作接口。

- **对比方法**：

  - **EfficientVLA**：固定间隔刷新所有模块（M=8, M=10）。

## 6. 主要结论与发现

1. **全局调度优于均匀/块级调度**：通过进化搜索全局缓存调度，EVO在相同总预算下保持更高成功率（如PH任务平均0.78 vs. BAC 0.72~0.75，EfficientVLA 0.37~0.70），证明了非均匀分配的有效性。
2. **显著加速**：最高实现8.05倍动作生成加速（M=8），FLOPs从15.77G降至1.96G；推理频率从2.23Hz提升至7.57Hz。
3. **鲁棒性**：在不同任务和演示质量（PH、MH）下均保持接近全精度的成功率（平均下降不超过0.02）。
4. **冗余感知初始化有效**：基于余弦不相似度引导初始种群，可降低搜索成本（GPU-days从1.00降至0.96，搜索步数从242降至222），并提升最终性能。
5. **目标条件早停有效**：避免不必要的搜索，同时防止过早终止（被噪声快速评估误导）。

## 7. 优点

- **免训练、即插即用**：无需修改策略参数、采样器或动作接口，离线搜索的调度可直接用于任何已训练好的Transformer扩散策略。
- **全局视角**：首次将缓存调度建模为块-时间步网格上的全局资源分配，突破了先前方法中“每块固定预算”的限制。
- **适应度驱动**：直接优化闭环任务成功率（而非代理指标），比基于特征相似度的优化更贴近最终部署目标。
- **实用性强**：通过冗余感知初始化和目标条件早停，使昂贵的展开搜索变得可负担（离线成本约1 GPU天），并对不同任务和环境分布泛化良好。
- **详尽实验**：在多个基准、多种任务难度、不同演示质量上验证，消融全面，并提供了计算成本和推理延迟分析。
