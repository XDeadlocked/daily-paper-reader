## 摘要
视觉-语言-动作（VLA）策略提供了强大的通用操作先验，但在高公差、接触密集的装配任务中常常失败，原因在于长时域信用分配和子任务耦合：当前技能在几何上成功的状态可能对下游技能是脆弱的。我们在冻结的VLA基础策略上展示了残差强化学习（RL）中的这种失败模式：恒定的稀疏成功奖励在孤立情况下改进了每个子任务，但当技能链式执行时几乎没有增益，因为终端状态质量不受控制。我们提出远视残差强化学习，通过用离线估计的远视价值（即当前子任务终端状态下未来子任务成功的概率）来增强每个子任务的稀疏成功奖励，从而优化交接质量。具体来说，我们（i）从基础策略终端状态的图像中训练一个视觉远视预测器，使用下游 rollout 统计数据进行标注，以及（ii）通过后向远视归纳训练残差策略，将预测器输出作为奖励乘数。在Isaac Gym中的三阶段扳手式螺母拧紧装配任务（抓取、移动-插入、旋转）上，我们的方法实现了85.6%的全任务成功率，优于标准子任务残差RL（54.5%）和VLA基线，同时保持每个子任务的成功率不变。这些结果强调，提高长时域性能需要塑造每个子任务产生的成功状态，而不仅仅是是否发生成功。

## Abstract
Vision-Language-Action (VLA) policies offer strong general-purpose manipulation priors, but often fail on tight-tolerance, contact-rich assembly due to long-horizon credit assignment and subtask coupling: a state that is geometrically successful for the current skill can be brittle for downstream skills. We show this failure mode in residual reinforcement learning (RL) over a frozen VLA base policy: constant sparse success rewards improve each subtask in isolation yet yield little or no gain when skills are chained, because terminal state quality is uncontrolled. We propose Foresight Residual RL, which optimizes handoff quality by augmenting each subtask's sparse success reward with an offline-estimated foresight value -- the probability of future subtask success conditioned on the terminal state of the current subtask. Concretely, we (i) train a visual foresight predictor from images of terminal states of the base policy, labeled using downstream rollout statistics, and (ii) train residual policies via backward foresight induction, using the predictor output as a reward multiplier. On a three-phase wrench-based nut-tightening assembly task in Isaac Gym (grasp, move-insert, rotate), our method achieves 85.6% full-task success, outperforming standard subtask residual RL (54.5%) and VLA baselines, while leaving per-subtask success unchanged. These results highlight that improving long-horizon performance requires shaping which successful states are produced at each sub-task, not only whether success occurs.

## 1. 核心问题与整体含义（研究动机与背景）
- **核心问题**：长时域、高公差、接触密集的机器人装配任务中，子任务之间存在因果耦合。当前子任务的成功状态（几何上满足成功标准）可能对后续子任务非常脆弱，但标准独立子任务训练和恒定成功奖励完全忽略这种差异，导致链式执行时失败率极高。
- **背景**：VLA 策略能提供通用操作先验，但直接端到端训练面临长时域信用分配困难；分解成子任务训练又面临子任务耦合问题。标准残差 RL 虽然提高了单个子任务成功率，但因终端状态质量未受控，在技能链式组合中几乎没有增益。
- **研究含义**：必须优化“哪些成功状态被生成”，而非仅仅“是否成功”，才能有效组合接触丰富型技能。

## 2. 方法论：核心思想、关键技术细节
### 核心思想
- 提出 **Foresight Residual RL**：在子任务的稀疏成功奖励上乘以离线估计的“远视价值”——即当前子任务终端状态下未来子任务成功的概率。通过逆向归纳训练残差策略，使每个子任务倾向于产生有利于下游任务的高质量终端状态。
### 关键技术细节
1. **问题形式化**：将任务分解为 K 个顺序阶段，每个阶段有终止谓词 βₖ。标准做法最大化局部价值 Vₖ(s)=E[∑γᵗβₖ(sₜ₊₁)]，忽略下游依赖。本文定义远视价值 V_{k+1:K}(s) 为从状态 s 开始由未来策略执行所获得的期望最终阶段成功回报。
2. **局部远视价值函数**：V°ₖ(s)=E[∑γᵗ βₖ(sₜ₊₁) · V_{k+1:K}(sₜ₊₁)]，仅修改终端奖励。
3. **算法流程（Alg.1 反向归纳）**：
   - 从最后一个阶段 k=K 开始，使用标准奖励训练残差策略。
   - 对于 k < K，先冻结已训练好的下游策略，离线收集基础策略的终端状态，执行 K_rep 次下游 rollout 得到每个状态的成功计数，训练视觉远视预测器 p_φ: O→[0,1]（使用二项负对数似然损失）。
   - 用预测器输出作为奖励乘数 r_t = βₖ(sₜ₊₁)·p_φ(oₜ₊₁)，训练当前阶段的残差策略。
   - 残差策略修正：a_t = π⁰_k(o_t) + α·π^{res}_k(o_t)，α≪1。
4. **远视预测器训练（Alg.2）**：从基础 VLA 策略采样 N 个终端状态，每个执行 K_rep=5 次下游 rollout，记录成功计数 κᵢ，使用 DINOv2+LoRA 微调，二项 NLL 损失训练。

## 6. 主要结论与发现
1. **标准残差 RL 失效**：尽管单子任务成功率大幅提高（如插入从 45.7%→92.2%），但全任务成功率（54.5%）与端到端 π₀（54.9%）几乎持平，说明单纯提高子任务成功率不能改善长链组合。
2. **远视残差 RL 大幅提升**：全任务成功率 85.6%，较标准残差 RL 提升 +31.1%，比链式 π₀（41.4%）翻倍。
3. **增益集中在前端边界**：Grasp→Insert 连续成功率从 55.5% 升至 87.3%（+31.8%），预测器在该边界判别力更强（准确率 86.2% vs 基线 73.9%）。
4. **终端状态质量改善**：标准残差 RL 实际上降低了终端状态的平均预测器分数（Grasp 终端从 0.64 降至 0.32），而远视方法提升至 0.73，证明其引导残差策略选择更有利于下游的状态。

## 7. 优点
- **方法设计**：
  - 将 MAXQ 完成函数与现代 VLA 残差 RL 结合，提出离线预测+反向归纳的实用训练范式，避免联合训练的复杂性。
  - 用预测器输出作为奖励乘数，而非二值分类，保留连续信号。
  - 残差策略保持在基础策略附近，限制分布偏移，保证预测器有效性。
- **实验设计**：

## 8. 不足与局限
- **实验覆盖面窄**：仅在一个模拟装配任务上验证，缺少多任务、多阶段分解类型、不同 VLA 骨干（如 Octo、RT-2）的对比。
- **模拟局限**：全部在 Isaac Gym 中完成，未在真实机器人上实验。作者承认真实部署主要障碍是残差策略的在线 RL 成本，而非接触动力学差距。
- **预测器近似**：采用一步远视近似（仅预测下一阶段成功概率），当更深层依赖存在时可能不够精确。虽可扩展至链式 rollout，但代价增加。

- **假设阶段顺序固定且无循环**：不适用于任务图更复杂（如条件分支、循环）的操纵任务。
