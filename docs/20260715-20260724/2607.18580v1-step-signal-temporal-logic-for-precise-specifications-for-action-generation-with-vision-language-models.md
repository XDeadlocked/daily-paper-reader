## 摘要
视觉-语言-动作模型展现了令人印象深刻的泛化能力，但往往缺乏可解释性，并且难以遵循编码了空间、时间和逻辑需求的精确自然语言指令。我们提出了一种分层框架，使用信号时序逻辑作为连接高层语言理解与低层机器人执行的共享表示。高层策略利用视觉语言模型将语言指令分解为高层子任务，为每个子任务生成信号时序逻辑规范，并选择低层策略来执行每个子任务。信号时序逻辑规范将语言导出的意图转化为精确约束，低层策略选择决定了这些约束是直接通过信号时序逻辑引导的模型预测控制来强制执行，还是在执行针对感知复杂或接触丰富行为的学习策略时进行监控。通过将信号时序逻辑集成到计划验证、低层策略、子任务监控和重新规划中，我们的框架使得语言导出的计划能够在运行时使用公共形式结构进行检查、优化和修订。我们在真实桌面领域评估了该方法，展示了形式化规范如何提高语言条件机器人规划的精确性、可靠性和可解释性。

## Abstract
Vision-language-action (VLA) models have shown impressive generalization, but often lack interpretability and can struggle to follow precise natural language instructions that encode spatial, temporal, and logical requirements. We propose a hierarchical framework that uses Signal Temporal Logic (STL) as a shared representation connecting high-level language understanding with low-level robot execution. A high-level policy leverages a VLM to decompose language instructions into high-level subtasks, generate STL specifications for each subtask, and choose a low-level policy for executing each subtask. The STL specifications translate language-derived intent into precise constraints, and the low-level policy selection determines whether those constraints are enforced directly through STL-guided model-predictive control or monitored during execution of a learned policy for perceptually complex, or contact-rich behaviors. By integrating STL into plan validation, low-level policy, subtask monitoring, and replanning, our framework enables language-derived plans to be checked, optimized, and revised at runtime using a common formal structure. We evaluate the approach on a real-world tabletop domain, demonstrating how formal specifications can improve the precision, reliability, and interpretability of language-conditioned robot planning.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究动机**：视觉-语言-动作（VLA）模型虽然在多种操作任务上表现优异，但缺乏可解释性，且难以严格遵循自然语言指令中编码的空间（如“放在粉红杯子左边8cm”）、时间（如“5到8秒内拿起锅”）和逻辑（如“避免炉子”）约束。现有VLA模型将语言视为非正式提示，隐含地学习约束，无法显式表示、监控或强制执行这些要求。
- **背景**：近期双系统VLA架构（System 2慢速推理 / System 1快速执行）取得了进展，但System 2仅产生高级指导，未将精确约束形式化。作者认为System 2应充当“形式化者”，将任务需求编译成形式化表示，供System 1监控和强制。
- **整体含义**：提出STeP框架，以信号时序逻辑（STL）作为高层语言理解与低层机器人执行的共享形式化接口，实现可解释、可靠的语言条件机器人规划。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

- **核心思想**：将STL嵌入双系统架构的四个环节：
  1. **计划验证（Validation）**：System 2生成子任务及STL规范后，进行静态检查（JSON模式、技能存在性、参数类型、对象存在、约束支持），不合格则回传VLM修正。
  2. **低层控制（Control）**：对于需要精确约束满足的子任务，使用STL引导的MPC，其优化目标为最小化状态-动作成本加上负的STL鲁棒性（robustness）项；对于感知复杂或接触丰富的子任务，使用学习策略（如行为克隆）。
  3. **运行时监控（Monitoring）**：STL监视器持续计算当前信号轨迹的鲁棒性值，当鲁棒性低于阈值时触发故障召回（recall）；鲁棒性为正表示满足，为负表示违反。
  4. **重规划（Replanning）**：召回时，历史日志（包含观测、状态、STL鲁棒性轨迹等）与当前STL规范一起传给System 2，使VLM能基于结构化反馈进行针对性修正。

- **关键技术细节**：
  - **STL语法**：包含原子谓词 μ、布尔运算、时态算子（Eventually F、Always G、Until U），支持时间区间 [a,b]。
  - **鲁棒性计算**：采用定量语义，通过softmax光滑近似max/min，使可微以用于梯度优化。
  - **信号谓词库**：预定义多个谓词（如Safe、Grasp、Place、GoalPosition等），VLM从中选择。
  - **MPC公式**：
    \[
    \arg\min_{a_{t:t+H-1}} \sum_{k=t}^{t+H-1} c(s_{k|t},a_k) - \lambda \rho(z_{t:t+H|t}, \varphi)
    \]
    受动态模型约束，其中λ为鲁棒性加权系数。
  - **策略切换机制**：STL监视器检测学习策略违反安全约束时，将子任务切换到MPC；待进入预定区域后再切回学习策略完成接触操作。
  - **历史日志**：固定长度L的滑动窗口，记录近期观测、状态、子任务描述、执行器类型、STL鲁棒性值及完成/失败事件。

- **算法流程**（文字说明）：
  1. 用户输入自然语言指令 + 当前观测（RGB-D感知生成场景图）。
  2. System 2（VLM，如GPT-4o）根据指令、技能库、谓词库、历史日志输出子任务序列（每个子任务包含技能名、参数、约束、自然语言描述）。
  3. 静态检查通过后，STL编译器将子任务映射为STL公式（含全局安全、时间窗口等）。
  4. System 1根据子任务类型选择执行器：MPC（STL鲁棒性作为目标）或学习策略（仅监控）。
  5. 每个时间步，STL监视器计算鲁棒性；若低于阈值 → 触发召回，System 2基于历史日志重规划；若公式满足 → 进入下一子任务。
  6. 若子任务完成或全部结束，输出最终执行结果。

## 7. 优点

- **创新性**：将STL作为形式化接口贯穿VLA规划全流程（分解、验证、控制、监控、重规划），系统性解决VLA精确约束满足问题。
- **可解释性**：STL规范提供显式的约束表示，鲁棒性值量化进度和偏离程度，便于人类理解和调试。
- **模块化与灵活性**：支持MPC与学习策略混合执行，适应不同子任务特性；STL监视器触发重规划连接高层推理与低层反馈。
- **实际验证**：在真实机器人（UR3e）上完成物理实验，论证了从语言到执行的可行闭环。
- **消融对比严谨**：通过移除STL组件的消融实验直接证明其贡献。
