## 摘要
视觉-语言-动作（VLA）模型在通用机器人操作方面展现出强大前景，但将其适配到新任务和新领域仍然效率低下：现有方法往往依赖参数调优，带来高昂成本，并存在对先前学习任务发生灾难性遗忘的风险。为解决这一问题，我们提出 Optimus-R，一个以记忆为中心的 VLA 框架，将机器人适配表述为显式的查询-技能记忆调优。Optimus-R 引入：(i) 用于技能提取的内联记忆接口。它向 VLA 前缀流中插入可学习记忆 token，使主干网络能够在原生动作条件化路径中推导出控制感知的查询和技能表示。(ii) 用于技能学习的查询-技能记忆库。它将技能外化为用于决定检索什么的查询原型，以及用于指定如何行动的技能值，从而在有限参数更新下支持技能复用与扩展。(iii) 一种轻量级的用于技能更新的桥接与适配机制。它通过轻量级适配器和残差记忆更新，将目标域查询和技能与现有记忆空间对齐。在域内适配、跨域适配和终身学习上的实验表明，Optimus-R 能够实现数据高效的技能学习，同时缓解灾难性遗忘。

## Abstract
Vision-Language-Action (VLA) models have shown strong promise for general-purpose robotic manipulation, yet adapting them to new tasks and domains remains inefficient: existing methods often rely on parameter tuning, incurring substantial costs and risking catastrophic forgetting of previously learned tasks. To address this, we propose \textbf{Optimus-R}, a memory-centric VLA framework that formulates robotic adaptation as explicit query-skill memory tuning. Optimus-R introduces: (i) An \textbf{Inline Memory Interface for skill extraction}. It inserts learnable memory tokens into the VLA prefix stream, allowing the backbone to derive control-aware query and skill representations within the native action-conditioning pathway. (ii) A \textbf{Query-Skill Memory Bank for skill learning}. It externalizes skills into query prototypes for deciding \emph{what} to retrieve and skill values for specifying \emph{how} to act, supporting skill reuse and expansion with limited parameter updates. (iii) A lightweight \textbf{Bridge-and-Adapt mechanism for skill updating}. It aligns target-domain queries and skills with the existing memory space through a lightweight adapter and residual memory updates. Experiments on in-domain adaptation, cross-domain adaptation, and lifelong learning show that Optimus-R enables data-efficient skill learning while mitigating catastrophic forgetting.

## 2. 方法论：核心思想与关键技术

### 2.1 核心思想

- 将 VLA 适配视为**显式查询-技能记忆调优**：
  - 查询用于决定“检索什么”；
  - 技能值用于决定“如何行动”；
  - 新任务通过复用、更新或追加记忆条目来学习，而非反复全局调参。

### 2.2 内联记忆接口（Inline Memory Interface）

- 向 VLA 前缀流中插入可学习记忆 token \(E_{mem}\)：
  - 输入观测 \(O_t\) 和语言指令 \(L\)，主干 \(F_\theta\) 输出多模态状态 \(H^{vl}_t\) 与记忆状态 \(M_t\)。
- 用两个独立注意力池化从 \(M_t\) 中读出：
  - 查询池化得到 \(\bar m^q_t\)，再经 Query Encoder 得到查询 \(q_t\)；
  - 技能池化得到 \(\bar m^s_t\)，再经 Skill Encoder 得到技能 \(s_t\)。
- 查询 \(q_t\) 仅用于记忆检索；技能 \(s_t\) 用于表示动作相关行为。
- 训练时用轻量 Skill Decoder \(D_s\) 从 \(s_t\) 重建未来动作块，使技能空间与可执行行为对齐。
- 通过 Token Projector \(T_\psi\) 将技能嵌入映射为 VLA 兼容的 skill tokens，用于条件化 Flow Policy 生成动作块。

### 2.3 查询-技能记忆库（Query-Skill Memory Bank）

- 记忆库定义为：
  - \(B=\{(p^q_j, p^s_j, n_j, E_j)\}_{j=1}^K\)
  - 其中 \(p^q_j\) 为查询原型，\(p^s_j\) 为技能原型，\(n_j\) 为支持计数，\(E_j\) 为用于回放的潜在查询-技能对。
- 初始记忆库构建流程：
  - 运动感知下采样：保留动作变化较大的样本，减少静态冗余；
  - 归一化进度分层采样：覆盖轨迹不同执行阶段；
  - 技能聚类：先在查询空间聚类，再对技能方差高的簇在技能空间二次划分。
- 检索流程：
  - 查询先经对齐矩阵 \(A_{mem}\) 映射到记忆坐标系；
  - 计算与查询原型的相似度，取 top-\(K_r\) 原型；
  - 用 softmax 权重聚合技能原型与残差，得到检索技能 \(\hat s_t\)。
- 技能更新：
  - 不覆盖基础原型，而是学习局部残差 \(\Delta p^q_j\)、\(\Delta p^s_j\)；
  - 从而在保留可复用技能的同时，对局部记忆坐标进行适配。

### 2.4 Bridge-and-Adapt 训练机制

- **Stage A：接口预训练**
  - 训练记忆 token、查询/技能编码器、技能解码器、Token Projector 以及 VLA 主干最后若干层；
  - 损失包括：
    - 原始 VLA flow-matching 损失 \(L_{fm}\)；
    - 查询对比损失 \(L_{nce}^q\)，正样本来自同任务且进度接近的样本，以及同轨迹邻近状态；
    - 技能重建损失 \(L_{skill}\)，用 Huber 损失监督技能解码器重建动作块。
  - 之后冻结接口、Token Projector、技能解码器和主干，构建初始记忆库。

- **Stage B：桥接适配**
  - 面向跨域流，如仿真到真实迁移；
  - 解冻主干，并更新 \(A_{mem}\)、检索温度 \(\tau_{mem}\) 和活跃原型残差；
  - 保持接口模块、Token Projector、基础原型固定；
  - 可选低秩 Skill Adapter：
    - \(\tilde s_t = A_s(\hat s_t) = \hat s_t + U_s V_s^\top \hat s_t\)，其中 \(r \ll d_s\)；
    - 零初始化，初始不改变检索技能；
    - 用于技能空间不匹配较大时进一步校正。

- **Stage C：记忆适配**
  - 面向域内终身学习；
  - 冻结 VLA 主干和内联记忆接口；
  - 只更新 \(A_{mem}\)、\(\tau_{mem}\)、活跃原型残差和记忆库条目/统计量；
  - 若新样本查询接近已有原型，则更新对应残差和支持统计；
  - 否则进入候选缓冲，当簇满足支持数、查询方差和技能方差条件时追加新原型。
  - 回放使用存储的潜在查询-技能对，不存储原始图像、动作或轨迹。

- **适配目标**：
  - \(L_{life}=L_{fm}+\lambda_{align}\|\tilde s_t - sg(s_t)\|_2^2+\lambda_{reg}\sum_{j\in A_t}(\|\Delta p^q_j\|_2^2+\|\Delta p^s_j\|_2^2)\)
  - flow-matching 监督动作生成，对齐项监督检索技能，残差正则限制原型漂移。

### 2.5 关键超参数

- 记忆 token 数 \(m=4\)；
- 查询/技能维度 \(d_q=d_s=256\)；
- 每个检索原型对应技能 token 数 \(n_s=4\)；
- top-2 检索；
- 初始记忆库大小 \(K_0=128\)；
- 复用阈值 \(\tau_{reuse}=0.75\)；
- 最小簇大小 \(N_{min}=50\)；
- Skill Adapter 秩 \(r=8\)。
