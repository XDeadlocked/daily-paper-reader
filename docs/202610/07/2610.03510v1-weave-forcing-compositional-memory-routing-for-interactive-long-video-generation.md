## 摘要
近期自回归视频生成的发展提升了长时段内的时间一致性，但交互式叙事所需的不止是连续场景扩展：新镜头可能组合来自不同历史镜头的角色与背景。整段提示检索可能忽略各组成部分不同的参考需求，而直接组合所有历史记忆可能引入无关视觉内容。为解决这些问题，我们提出 Weave Forcing，一个用于交互式长视频生成中组合式记忆复用的免训练框架。首先，我们使用 LLM 进行语义槽路由，将用户提示分解为角色与背景描述，并为每个组成部分显式选择合适的历史参考。为隔离所需内容，掩码记忆编织利用以语义槽为条件的对比注意力图构建精细语义掩码，选择性地暴露压缩历史 KV 记忆中的相关 token，以引导当前镜头的生成。我们进一步提出覆盖率自适应 RoPE，根据无、部分或完整参考覆盖来调整时间偏移与记忆保留，解决当不完整历史参考被置于当前生成附近时观察到的视觉伪影。大量实验表明，Weave Forcing 提升了跨镜头主体与背景一致性，同时保持有竞争力的视觉质量与文本对齐。

## Abstract
Recent advances in autoregressive video generation have improved temporal consistency over extended durations, yet interactive storytelling requires more than continuous scene extension: a new shot may combine characters and backgrounds from different historical shots. Whole prompt retrieval can overlook the distinct reference needs of individual components, while directly combining all historical memories may introduce unrelated visual content. To address these problems, we present Weave Forcing, a training-free framework for compositional memory reuse in interactive long video generation. First, we use an LLM for semantic slot routing to decompose user prompts into character and background descriptions and explicitly select suitable historical references for each component. To isolate the required content, masked memory weaving uses contrasting attention maps conditioned on semantic slots to construct refined semantic masks, selectively exposing relevant tokens from compressed historical KV memories to guide the generation of the current shot. We further introduce coverage adaptive RoPE to adjust temporal offsets and memory retention according to no, partial, or full reference coverage, addressing visual artifacts observed when incomplete historical references are positioned close to the current generation. Extensive experiments demonstrate that Weave Forcing improves cross-shot subject and background consistency while maintaining competitive visual quality and text alignment.

# Weave Forcing 论文总结

## 1. 核心问题与研究动机

- **背景**：自回归视频扩散模型已能实现长时段的时间一致性与流式生成，但交互式叙事（interactive storytelling）的要求更高——用户会中途修改指令、切换镜头、召回早期角色或场景。
- **核心痛点**：新镜头的提示可能组合来自**不同历史镜头**的角色与背景（例如把此前出现过的女孩和男孩放进一个图书馆，三者分别来自不同镜头）。此时存在两个问题：
  - **参考过载/不足**：复用整段历史记忆会带入无关内容（too much）；而按全局提示相似度只选单个最相似镜头，又会漏掉必需组件（too little）。
  - **统一参考策略失效**：有历史参考支撑的内容需要强条件以保持一致性，而无参考的新内容需要弱条件以自由生成；均匀的参考使用策略难以兼顾。
- **整体含义**：论文主张历史记忆不应被视为不可分割的整体视觉参考，而应按语义组件（角色/背景）分别路由与隔离复用，从而在保持跨镜头一致性的同时支持新内容生成。

## 2. 方法论

- **总体定位**：Weave Forcing 是一个**免训练（training-free）**的推理期框架，建立在 Self Forcing 自回归骨干之上，核心由三个模块组成。

### 2.1 语义槽路由（Semantic Slot Routing）
- **槽提示拆分**：用 LLM 将第 $t$ 个镜头的提示 $P_t$ 独立拆分为角色槽 $\{p_{t,c_i}\}$ 与背景槽 $p_{t,b}$，保留身份/外观属性，剔除动作与姿态。
- **跨镜头路由**：LLM 将每个槽独立匹配到更早的历史镜头源 $j_{t,s}$（$s \in \{c_1,\dots,c_{N_t},b\}$），并指定源中的对应槽作为目标槽提示；若无合适源则 $j_{t,s}=\varnothing$。源与目标的槽索引**不要求一致**（如 target character1 可对应 source character2）。

### 2.2 掩码记忆编织（Masked Memory Weaving）
- **记忆压缩（query 加权）**：对已完成镜头 $j$，用该镜头的均值 query $\bar{Q}_j$ 与各候选帧 key 的相似度做 softmax 归一化权重 $\alpha_{j,f,u}$，对各空间 token 的 K/V 做加权聚合成紧凑记忆。
- **对比槽注意力（CSA）**：对每个槽用两个互补文本条件——目标提示 $P^{tar}_{t,s}$（要保留）与其它提示 $P^{oth}_{t,s}$（要抑制）——在同一历史记忆上生成对齐的注意力图，做差并阈值化得到初始二值掩码：
  $$M_{t,s,u} = \mathbb{I}\left[(A^{tar}_{t,s,u} - A^{oth}_{t,s,u}) > \tau_s\right]$$
  再经形态学开/闭运算细化得到最终语义 KV 掩码 $\tilde{M}_{t,s}$。该对比在推理时进行，**无对比训练目标**。
- **带语义掩码的缓存初始化**：上下文分为 sink（初始放历史参考，后转为滚动锚点）、compressed（压缩的镜头内历史）、recent（上一完成块）、current（当前去噪块）四个窗口。跨镜头参考作为临时内容而非独立窗口。在自注意力中对被加载的参考 token 施加语义偏置 $B_{sem}$（掩码内为 0，掩码外为 $-\infty$），当前镜头 token 的偏置恒为 0。

### 2.3 覆盖率自适应 RoPE（Coverage Adaptive RoPE）
- 按角色与背景参考是否可用，分三种情形：
  - **无覆盖**：无任何参考时，把上一镜头的完整压缩记忆作为临时风格参考（**不施加语义掩码**），时间 RoPE 偏移设为 **45**，生成第 1 个块后即移除。
  - **部分覆盖**：仅一类语义有参考时，插入对应掩码记忆，RoPE 偏移 **45**，随后渐进衰减直至淘汰，避免不均衡参考导致漂移。
  - **完全覆盖**：两类都有参考时，按参考与当前提示嵌入的相似度在 **[1, 6]** 内设置偏移，使位置紧密耦合以联合复用，并在淘汰前渐进衰减过渡到当前镜头自身上下文。
- **淘汰策略**：跨镜头参考在固定数量完成块后被移除（无覆盖 1 块，部分/完全覆盖 5 块），而非等到窗口满。
- **相似度自适应衰减**：逐 token 计算当前 key 与历史 key 的余弦距离，归一化后线性插值为衰减率 $\gamma_u \in [\gamma_{min},\gamma_{max}]$，相似者衰减慢、差异大者衰减快。

- Weave Forcing 在**镜头间主体一致性（0.513）与背景一致性（0.811）上取得最优**，明显优于所有对比方法。
- 在视觉质量上具备竞争力：Imaging Quality 0.750（与 Rolling Forcing、Reward Forcing 并列最高）、Aesthetic Quality 0.611（最高）、Text Alignment 0.237（与 Rolling Forcing 0.239 接近，高于多数基线）。

## 7. 优点

- **组合式记忆复用视角新颖**：把历史记忆按角色/背景语义组件解耦路由，而非整段复用或单一相似度检索，直击交互式叙事的真实需求。
- **完全免训练**：所有模块（LLM 路由、CSA 掩码、RoPE 调整）均在推理期完成，不需要额外训练或微调，部署成本低、可与现有自回归骨干即插即用。
- **CSA 设计巧妙**：用目标提示与其它提示的注意力图做差来隔离内容，无需对比训练目标，也不需要额外标注。
- **覆盖率自适应策略有针对性**：区分无/部分/完全覆盖并匹配不同 RoPE 偏移（45 vs [1,6]）与淘汰时机，直接回应"参考不全时靠近当前生成会产生伪影"的问题。
- **评估维度较全面**：同时考察镜头内/镜头间一致性、美学与成像质量、文本对齐，并补充单主体、镜头内一致性、失败案例等多角度定性分析。
- **可复现性说明较充分**：附录提供了 LLM 提示模板、实现细节与评估流程。

## 8. 不足与局限

- **镜头内一致性偏弱**：在 Intra-shot Sub./Bg. 上不及双向模型，甚至低于部分自回归基线（如 Rolling Forcing 0.814/0.941），说明引入跨镜头参考可能对短时一致性有轻微代价。
- **多主体属性纠缠**：语义掩码不完美时相邻主体的 token 会被误保留，且新提示要求过多属性时注意力竞争会削弱槽路由信号，导致属性绑定错误。
- **强依赖 LLM**：路由与槽拆分完全由 Gemini 2.5 Pro 完成，带来约 30 秒/次的调用延迟，与"实时交互"目标存在张力；LLM 错误会直接传播到生成结果。
- **实验覆盖有限**：仅 100 条合成叙事、6 镜头、单一骨干与单一随机种子；缺乏跨骨干（如更大模型）、跨语言提示、更长镜头数的验证。
- **公平性风险**：数据集与部分提示由 AI 生成，可能带有生成模型自身偏置；各基线的实现与超参未完全公开，横向对比的公平性需谨慎看待。
- **算力透明度不足**：未报告 GPU 数量、总推理时间、LLM 调用总次数与总开销，难以评估实际部署成本。
- **应用限制**：方法面向交互式多镜头叙事，对单镜头长视频、非叙事类视频或需精确物理一致性的场景可能收益有限。
