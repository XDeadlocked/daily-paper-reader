## 摘要
视觉-语言-动作（VLA）模型越来越多地依赖基于扩散或流匹配的动作头来生成连续的机器人动作。这些动作头通常以基本统一的方式处理去噪轨迹。然而，我们观察到，条件关注点会随着去噪阶段自然发生转移：早期阶段结合语言指令和视觉观测来建立粗略的动作轨迹，而后期阶段则更强调当前视觉观测以实现动作对齐。基于这一洞察，我们提出了 StairVLA，一种阶段感知的分层动作生成框架，它将部分去噪后的动作作为粗粒度长时程动作生成与局部细化之间的自然接口。高层 VLA 执行早期去噪，以生成可复用的长时程部分去噪动作轨迹，而轻量级细化器则以更高频率运行，利用最新观测来细化局部动作块。该设计摊销了昂贵的高层 VLA 计算，同时保留了频繁的闭环校正。在 LIBERO 上，我们 GR00T 风格的实例化将平均成功率从 96.5% 提升到 97.8%，同时将每个动作块的摊销推理延迟从 115.0 ms 降低到 44.2 ms。更广泛地，在两个 VLA 主干、仿真基准和真实机器人任务上，StairVLA 在保持强任务性能的同时持续降低了推理成本。

## Abstract
Vision-language-action (VLA) models increasingly rely on diffusion- or flow-matching-based action heads to generate continuous robot actions. These action heads typically process the denoising trajectory in a largely uniform manner. However, we observe that the conditioning focus naturally shifts across denoising stages: early stages combine language instructions and visual observations to establish a coarse action trajectory, whereas later stages place greater emphasis on current visual observations for action alignment. Based on this insight, we introduce StairVLA, a stage-aware hierarchical action generation framework that uses partially denoised actions as a natural interface between coarse long-horizon action generation and local refinement. A high-level VLA performs early denoising to produce a reusable long-horizon partially denoised action trajectory, while a lightweight refiner operates at a higher frequency to refine local action chunks using the latest observations. This design amortizes expensive high-level VLA computation while preserving frequent closed-loop correction. On LIBERO, our GR00T-style instantiation improves average success from 96.5% to 97.8% while reducing amortized inference latency from 115.0 ms to 44.2 ms per action chunk. More broadly, across two VLA backbones, simulation benchmarks, and real-robot tasks, StairVLA consistently reduces inference cost while maintaining strong task performance.

## 1. 核心问题与整体含义

- **研究背景**：视觉-语言-动作（VLA）模型普遍采用扩散或流匹配（flow matching）动作头，将语言指令、视觉观测与机器人状态作为条件，通过多步去噪从噪声逐步生成连续动作轨迹。现有实现通常在整个去噪过程中**均匀地**施加多模态条件。
- **核心观察（动机）**：作者发现去噪过程存在**阶段依赖性**——早期阶段需要联合语言指令与视觉观测建立粗略动作结构；后期阶段则更依赖当前视觉观测完成动作对齐与精修。Fig.1 显示，在 π0 上图像 token 的相对注意力随去噪推进上升；GR00T 的部分去噪动作在去噪未完成时已具备相当的任务能力。
- **中心问题**：现有分层 VLA 的分层结构（子目标、路点、宏动作、学习表征）大多是**外部设计**的，能否让分层**直接从生成式动作过程本身涌现**？
- **整体含义**：若早期去噪可承担昂贵的任务条件计算并被多次复用，后期仅用轻量模块结合最新观测做局部精修，就能在保持闭环修正的同时大幅摊销高层 VLA 推理成本。

## 2. 方法论

### 2.1 核心思想
以**部分去噪动作**作为高层粗粒度长时程生成与低层局部精修之间的**天然接口**：高层 VLA 低频执行早期去噪，产出并缓存长时程部分去噪轨迹；轻量精修器高频地取其中局部片段，结合最新观测完成剩余去噪。

### 2.2 高层意图轨迹生成
- 沿用原 VLA 架构与流匹配目标，仅将动作时域扩展至 H（默认 H=32）。
- 训练路径：`a_γ = (1-γ)ε + γ·a_gt`，目标速度 `v* = a_gt - ε`，损失 `L_FM = E||v_θ(a_γ, γ, z_t) - v*||²`。
- 推理时从纯噪声开始按 Euler 步更新：`a_{γ_{n+1}} = a_{γ_n} + (γ_{n+1}-γ_n)·v_θ(...)`。
- **关键区别**：不在 γ=1 终止，而是停在 γ_N = α < 1，把 `a_{t:t+H-1}^α` 作为高层输出缓存复用。

### 2.3 观测条件化的低层精修
- **精修器结构**：GR00T 风格 DiT，16 个 Transformer block，hidden 768，12 头，FFN 3072，交叉注意力与自注意力交替。
- **输入**：动作侧（机器人状态 token、可学习 future token、当前查询动作块）；条件侧（SigLIP-B/16 编码的最新观测、经自适应平均池化压缩为 8 个 token 的高层 VLM 末层隐状态、从缓存轨迹提取的时序动作上下文）。
- **训练路径重建（关键设计）**：由于预测误差，高层部分去噪动作未必落在理想生成路径上，因此对每个局部查询块重建一条通向真值的流路径：
  - 反投影虚拟起点：`ε_ref = (a_α - α·a_gt)/(1-α)`
  - 目标速度：`v_ref = (a_gt - a_α)/(1-α)`
  - 采样 τ ~ U(α, 1)，构造 `a^τ_ref = (1-τ)ε_ref + τ·a_gt`
  - 损失：`L_ref = E||v_φ(a^τ_ref, τ, c_ref) - v_ref||²`
- 高层冻结，精修器单独训练，两阶段训练策略。

### 2.4 多速率推理与复用
- 每次高层调用生成并缓存时域 H 的部分去噪轨迹，供后续 M 个精修周期复用。
- 平均每块推理成本：`T(M) = T_ref + T_high/M`。
- 精修结果**不回写**缓存轨迹，每个局部块均从原始高层粗轨迹精修；M 控制效率与高层信息新鲜度的权衡。

## 6. 主要结论与发现

- **性能与效率双赢**：LIBERO 上 GR00T 实例平均成功率 96.5% → 97.8%，摊销延迟 115.0 ms → 44.2 ms/块；π 主干 97.8% → 98.3%，183.3 ms → 44.5 ms。
- **去噪确实存在阶段依赖**：速度预测误差在去噪末期急剧上升；遮蔽图像对后期误差影响更大；π0 后期对图像 token 注意力上升，GR00T 则转向 grounding/模板等已语境化的视觉-空间表征；GR00T 自注意力中动作 key 的注意力随去噪递增。
- **迁移点 α 的规律**：训练时 α 在 0.6–0.9 内较鲁棒；推理时性能随迁移轨迹接近完全去噪而提升，在 α=0.97 附近达峰，兼顾已编码的任务信息与剩余精修空间。
- **精修器有效性**：在 oracle 路径与自回归 rollout（误差累积）两种设定下均保持低而稳定的最终动作误差，而 GR00T 在累积误差下显著退化。
- **额外指令条件并非必要**：补充完整未池化指令 token 只在高噪声段有帮助，但不提升精修器性能上限，轻量任务条件反而使精修更专注观测对齐。
- **复用范围存在上限**：M 增大可持续降低延迟，但过长的复用时域会因动作误差、观测变化与环境交互累积不确定性，导致缓存轨迹与实际闭环状态失配；H 从 48 增至 64 也未带来长复用优势。
- **真机验证**：Fruit25 81.2% vs GR00T 76.5%、π 75.9%；PushBlock 60% vs 30%、20%；运动更平滑、停顿更少。

## 7. 优点

- **洞察新颖且自洽**：把分层结构从"外部设计"转为"生成过程内蕴"，用部分去噪动作充当高层—低层接口，避免引入额外抽象或人工监督。
- **训练路径构造严谨**：通过反投影重建精修流路径，使精修器训练分布与推理时"带误差的中间状态"更匹配，缓解误差累积。
- **架构轻量、工程可落地**：精修器仅需当前观测 + 压缩后的高层 token + 局部动作上下文，复用高层 VLM 隐状态，显著摊销昂贵计算。
- **验证维度丰富**：两种 VLA 主干、仿真基准（含扰动鲁棒性）、真机多任务，且效率与成功率同时报告，并配有大量机制性分析（注意力、误差、条件消融）。
- **诚实性较好**：主动声明延迟不可严格跨论文比较、明确区分诊断性注意力分析与因果归因，并在附录坦陈长复用下性能下降的局限。

## 8. 不足与局限

- **零样本视觉鲁棒性偏弱**：LIBERO-Plus 零样本中相机扰动仅 43.7%（Libra-VLA 为 68.9%），因低层精修主要依赖视觉观测，对视觉分布偏移敏感，需目标域微调才能恢复（微调后 83.7%）。
- **复用时域受限**：高层轨迹的有效复用范围有限，长时域复用会因闭环状态漂移而明显掉性能；论文未提出自适应/事件触发的高层刷新机制，仅作为未来方向。
- **接口依赖固定超参**：迁移点 α=0.97 在多个基准与主干上直接沿用而未重新调参，缺乏对 α 的自适应选择机制。
