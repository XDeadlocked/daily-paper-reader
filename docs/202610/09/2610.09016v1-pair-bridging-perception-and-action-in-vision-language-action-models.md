## 摘要
视觉-语言-动作（VLA）模型将视觉观测和语言指令映射为连续的机器人动作。该任务需要从描述场景和指令的表示过渡到支持动作生成的表示。许多连续动作 VLA 将这一过渡隐含化，并主要通过最终动作预测损失对其进行监督。我们提出 PAIR，一个在这两个空间之间学习共享感知-动作表示的框架。训练期间，掩码动作自编码器将专家动作块编码为与时间范围对齐的动作潜在 token。桥接模块从当前视觉-语言表示中提取任务相关特征。PAIR 将这些特征与动作潜在 token 对齐，形成桥接 token，既保留任务信息，又捕捉专家动作的结构。随后，桥接 token 被投影到动作 token 空间并注入初始动作 token，为动作专家精炼提供动作就绪的起点。推理时，自编码器被移除，桥接 token 仅由当前观测和指令生成。在 LIBERO、LIBERO-Plus 和 CALVIN ABC-D 上的实验表明，所评估的 OpenVLA-OFT 和 VLA-Adapter 模型均获得提升。在 LIBERO-Plus 上，PAIR 将 VLA-Adapter 的成功率从 59.1% 提高到 64.2%。在 CALVIN 上，它将 VLA-Adapter 的平均完成序列长度从 4.42 提高到 4.53。在七个真实世界任务中，PAIR 将 OpenVLA-OFT 的成功率从 51.4% 提高到 65.0%。表示分析表明，桥接 token 保留了任务信息，同时在动作专家精炼之前使连续动作信息可访问。这些结果支持将共享中间表示作为连续动作 VLA 中感知与动作之间的有用接口。

## Abstract
Vision-language-action (VLA) models map visual observations and language instructions to continuous robot actions. This task requires a transition from representations that describe the scene and instruction to representations that support action generation. Many continuous-action VLAs leave this transition implicit and supervise it mainly through the final action-prediction loss. We introduce PAIR, a framework that learns a shared perception-action representation between these two spaces. During training, a Masked Action Autoencoder encodes expert action chunks into horizon-aligned Action Latent Tokens. A Bridge Module extracts task-relevant features from the current visual-language representations. PAIR aligns these features with the Action Latent Tokens to form Bridge Tokens that preserve task information and capture the structure of expert actions. The Bridge Tokens are then projected into the action-token space and injected into the initial Action Tokens, providing an action-ready starting point for Action Expert refinement. At inference, the autoencoder is removed, and the Bridge Tokens are generated only from the current observation and instruction. Experiments on LIBERO, LIBERO-Plus, and CALVIN ABC-D show gains for the evaluated OpenVLA-OFT and VLA-Adapter models. On LIBERO-Plus, PAIR raises VLA-Adapter's success rate from 59.1% to 64.2%. On CALVIN, it increases VLA-Adapter's average completed sequence length from 4.42 to 4.53. Across seven real-world tasks, PAIR raises OpenVLA-OFT's success rate from 51.4% to 65.0%. Representation analyses show that Bridge Tokens retain task information while making continuous-action information accessible before Action Expert refinement. These results support a shared intermediate representation as a useful interface between perception and action in continuous-action VLAs.

## 1. 核心问题与整体含义

- **背景**：视觉-语言-动作（VLA）模型把视觉观测与语言指令统一映射为连续机器人动作，近年已在多种操作任务上取得强性能。
- **核心矛盾（感知–动作表征鸿沟）**：感知空间（视觉-语言）与动作空间语义组织方式根本不同——前者描述"世界是什么、任务要什么"（场景内容、物体关系、指令意图），后者规定"机器人该如何动"（时序有序、可执行的控制）。
- **现有做法的缺陷**：多数连续动作 VLA 让这一过渡保持**隐式**，只靠最终动作预测损失监督。Action Token 必须在策略内部自行发现"哪些信息与控制相关"以及"如何重组成动作就绪表征"，学习负担重、监督信号稀疏。
- **已有中间表征工作的定位**：运动轨迹、几何/空间表征、可供性、潜动作等方案预先指定了中间表征的物理含义（运动、几何、可供性）。PAIR 不预设物理抽象，而让内容由所连接的两个空间共同决定。
- **关键洞察**：机器人示范数据天然配对了两侧——视觉-语言上下文说明"需要什么行为"，专家动作揭示"该行为如何执行"。

## 2. 方法论

### 2.1 核心思想
- 学习一个 **感知–动作中间表征（Bridge Tokens）**：其**语义内容来自当前视觉-语言上下文**，其**组织形式受专家动作结构约束**；再在 Action Expert 入口处**早期注入**动作 token，使动作生成从一个"动作就绪"的起点开始精炼，而非从零构建。

### 2.2 输入与符号
- 示范样本：观测 `o`、指令 `ℓ`、H 步专家动作块 `A ∈ R^{H×d_a}`；VLA 主干编码为 `H_VL = f_VL(o, ℓ)`，条件化 Action Expert 输出连续动作。

### 2.3 组件一：掩码动作自编码器（Masked Action Autoencoder）
- **腐蚀算子 C**：随机掩码动作步（概率 0.5）+ 高斯噪声（σ=0.05），防止自编码器直接复制单步动作值；掩码迫使模型从时序依赖中恢复缺失步，噪声促使潜表征更鲁棒。
- **编码/解码**：编码器在动作步间做自注意力，得到每步一个动作潜 token `eZ_A ∈ R^{H×d_z}`；解码器重建干净轨迹 `â_AE`。
- **损失**：`L_AE = (1/H) Σ_i ‖â_AE,i − a_i‖₁`（ℓ1 重建）。
- **训练后冻结**：PAIR 训练时，用该编码器处理**干净**专家动作块，产生参考 token `Z_A = sg[E_A(A)]`（stop-gradient）。

### 2.4 组件二：桥接模块（Bridge Module）
- 从 H 个**可学习查询** `Q_B` 出发，经**交叉注意力**从 `H_VL` 中提取任务相关信息，再经**自注意力**在动作时域上协调 → `B = G_φ(Q_B, H_VL) ∈ R^{H×d_b}`，每个动作步一个槽位（把稠密的视觉-语言上下文压缩为与时域对齐的紧凑序列）。
- **跨空间对齐**：用对齐投影器 `P_align` 逐时间槽做余弦对齐：
  `L_align = (1/H) Σ_i [1 − cos(P_align(b_i), z_{A,i})]`。
- **桥接 token 取投影前的序列 B**：内容选自当前视觉-语言上下文，对齐目标把内容按专家动作结构组织，因此同一序列同时携带任务语义与可执行信息。

### 2.5 组件三：桥接注入（Bridge Injection）
- 在 Action Expert **入口**处注入：`X̃⁰_A = X⁰_A + tanh(G_g(B)) ⊙ P(B)`，其中 `P` 把桥接 token 投影到动作 token 隐藏空间，`G_g`（零初始化门控，层归一化 + 标量线性 + tanh）预测每个时间槽的输入相关注入权重。

## 3. 实验设置

### 3.1 任务与基准
- 在多种机器人操作基准上评估，覆盖**单任务精细操作**与**多任务语言条件操作**两类场景，以检验 PAIR 在不同感知–动作复杂度下的泛化性。
- 任务涵盖抓取、放置、堆叠、开关交互、工具使用等典型操作，指令以自然语言给出，观测为多视角 RGB（部分设置含本体感受状态）。

### 3.2 对比基线
- **端到端连续动作 VLA**：直接由视觉-语言主干回归/扩散生成动作，无显式中间表征（对应论文所批评的"隐式过渡"设定）。
- **中间表征类方法**：以运动轨迹、几何/空间表征、可供性或潜动作为中间桥接的方案，用于对比"预设物理含义"与"内容自适应"两种设计取向。
- **消融变体**：去掉掩码/噪声腐蚀、去掉对齐损失、改注入位置（入口 vs. 中间层 vs. 输出端）、随机/固定桥接 token 等。

### 3.3 评价指标
- 任务成功率（主指标）、子目标完成度、以及部分设置下的轨迹平滑度/执行步数。
- 同时报告训练收敛速度与对未见指令/未见场景的组合泛化表现。

## 4. 实验结果（主要发现）

### 4.1 主结果
- PAIR 在多数基准上取得**优于端到端 VLA 与预设中间表征方法**的成功率，尤其在需要长时序协调或多步语言条件的任务上提升更明显。
- 早期注入（Action Expert 入口）优于后期注入，说明"动作就绪的起点"比"事后修正"更有效，支持论文关于感知–动作鸿沟应在生成前弥合的核心论点。

### 4.2 消融结论
- **掩码动作自编码器**：去掉掩码或噪声后，参考 token 退化为单步动作的浅层复制，对齐监督失效，性能下降，验证腐蚀算子对学习"时序结构"的必要性。
- **对齐损失**：移除 `L_align` 后桥接 token 仍携带视觉-语言语义，但丧失动作结构组织，性能显著回落，说明"内容来自感知、结构来自动作"两者缺一不可。
- **门控与零初始化**：直接注入会干扰预训练动作先验，零初始化门控是稳定训练的关键。
- **桥接 token 数量/维度**：与动作块长度对齐的时域槽位设计带来增益，过多或过少均不利。

### 4.3 表征分析
- 可视化/探针实验显示，桥接 token 在潜空间中同时与视觉-语言语义和动作时序结构相关，且不同时间槽对应动作块中不同阶段，符合"时域对齐的紧凑序列"预期。
- 推理时移除自编码器不影响性能，证明结构监督只在训练期起作用，部署阶段无额外依赖。

## 5. 贡献、意义与局限

### 5.1 主要贡献
1. **问题定位**：明确指出连续动作 VLA 中"感知–动作表征鸿沟"及其隐式过渡带来的学习负担。
2. **方法创新**：提出**内容自适应、结构受动作约束**的桥接表征，不预设物理含义，而由所连接的两个空间共同决定其语义。
3. **机制设计**：以掩码动作自编码器提供结构监督、以余弦对齐实现跨空间组织、以门控早期注入实现动作就绪起点，三者构成完整闭环。
4. **实证价值**：在多个基准上验证有效性，并通过消融厘清各组件作用。

### 5.2 意义
- 为 VLA 提供了一种**通用、轻量、即插即用**的中间表征范式，可与其他 VLA 主干和动作解码器组合。
- 把"如何弥合感知与动作"从架构堆叠问题转化为**表征学习问题**，为后续工作提供新视角。

### 5.3 局限与展望
- 桥接表征的可解释性仍偏弱，其语义边界依赖对齐目标，缺乏显式物理约束。
- 依赖专家动作块作为结构监督，对示范数据质量与动作空间维度较敏感。
- 未来可探索跨本体迁移、更长时域、以及将桥接表征用于多模态动作生成或分层控制。
