## 摘要
使用视觉-语言-动作（VLA）模型作为骨干的机器人操控系统通常仅使用一个 VLA 来执行任务。然而，单个 VLA 在不同任务状态和环境中的表现并不理想。我们提出一个在执行过程中动态组合多个 VLA 策略的框架：分步动作策略路由（SWAP）。SWAP 将策略路由建模为离线强化学习问题，学习一个路由评价器，其根据当前观测在每个决策步骤选择最合适的策略。SWAP 使机器人能够在线选择新策略来执行，而不是在一个回合的整个持续时间内固定采用单一策略。我们在真实世界的 DROID 操作任务和 LIBERO 仿真实验中评估 SWAP。SWAP 优于固定策略执行和路由基线，在真实世界任务成功率上带来最高 33% 的绝对提升，同时将成功轨迹的机器人动作步长减少 28.3%。

## Abstract
Robot manipulation systems using Vision-Language-Action (VLA) model backbones typically use just one VLA for task execution. However, individual VLAs do not perform well across different task states and environments. We introduce a framework for dynamically composing multiple VLA policies during execution: StepWise Action Policy Routing (SWAP). SWAP formulates policy routing as an offline reinforcement learning problem, learning a routing critic that selects the most appropriate policy at each decision step given the current observation. SWAP enables robots to select new policies to execute online rather than committing to a single policy for the duration of an episode. We evaluate SWAP on both real-world DROID manipulation tasks and LIBERO simulation experiments. SWAP improves over fixed-policy execution and routing baselines, giving absolute improvements in real-world task success up to 33% while reducing successful trajectory robot action step length by 28.3%.

# SWAP: Stepwise Action Policy Routing for Vision-Language-Action Models 论文总结

## 1. 核心问题与研究背景

- **研究动机**：当前机器人操控系统通常以单个 VLA（Vision-Language-Action）模型作为骨干，并假设"一个策略可以从头到尾控制整段任务执行"。但作者指出这一假设在现实中非常受限：
  - 没有任何单一策略能在所有回合、所有场景配置下表现一致；
  - 分布偏移、误差累积、需要恢复行为等都会使执行轨迹偏离训练分布；
  - 即使手头有多个策略，若在回合开始时只选一个，就相当于"锁定"了固定行为，无法随执行演化而调整。
- **核心问题**：作者把"策略路由"（policy routing）形式化为机器人操控中的新问题——不是为整个回合选一个策略，而是在**每个决策步骤**动态决定由哪个候选策略来产生动作。
- **关键挑战**：路由决策必须考虑长时程的下游后果。一个局部看似合理的选择可能导致最终失败，而另一个选择可能带来恢复或成功。
- **整体含义**：论文主张"稳健的机器人执行能力不仅来自构建更强的单策略，也来自学会如何在多个策略之间有效路由"，为组合异构 VLA 策略提供了一条可扩展的离线 RL 路径。

## 2. 方法论

### 核心思想
- 将策略路由建模为**离散动作空间上的离线强化学习问题**，动作空间是"策略身份"（policy index）而非底层电机控制。
- 学习一个**路由评价器（routing critic）**，在给定当前观测时估计选择每个候选策略的长期回报，从而在线选择最优策略。
- 候选策略被视为**固定黑盒**，只训练路由器，因此新增策略无需重训任何专家（与 MoE 联合训练门控网络不同）。

### 问题形式化
- MDP 定义 $M = (S, A, P, r, \gamma)$，机器人观测 $s_t$，执行动作 $a_t$。
- 候选策略库 $P = \{\pi_1, \pi_2, \dots, \pi_K\}$，每个 $\pi_k(a_t|s_t)$ 为预训练控制器。
- 路由策略 $\varphi(z_t|s_t)$，其中 $z_t \in \{1,\dots,K\}$ 为所选策略索引；实际动作 $a_t \sim \pi_{z_t}(\cdot|s_t)$。
- 优化目标：$\arg\max_{\varphi} \mathbb{E}_{\varphi,P}[\sum_{t=1}^{T}\gamma^{t-1} r(s_t,a_t)]$。

### 关键技术细节

1. **离线数据集构建**
   - 用每个候选策略在目标任务上收集轨迹，包含成功与失败两类执行。
   - **按 chunk 路由**：VLA 通常一次预测并执行 $c$ 个低层动作，SWAP 在每个 chunk 之后才做一次路由，既对齐 VLA 自身的推理节奏（不引入额外策略查询），又避免打断 chunk 内部无意义的中间动作。
   - 路由转移元组为 $(o_t, z_t, r_t, o_{t+c}, d_t)$：chunk 起始观测、所选策略、稀疏奖励、chunk 执行后观测、终止标志。
   - 奖励为**稀疏二值信号**（成功完成给终端奖励，否则为 0），不引入中间奖励塑形。

2. **离线评价器学习（IQL）**
   - 采用 Implicit Q-Learning 拟合评价器，适合混合质量离线数据的稳定价值学习。
   - 学习两个评价器 $Q_1, Q_2$ 和一个状态价值函数 $V$，TD 目标为：
     - $L_Q = \mathbb{E}_{(o_t,z_t,r_t,o_{t+c},d_t)\sim D}\left[\sum_{i=1}^{2}\left(Q_i(o_t,z_t) - (r_t + \gamma(1-d_t)V(o_{t+c}))\right)^2\right]$
   - $V$ 通过 expectile 回归在学到的 Q 值上单独优化。
   - 训练与推理均取 $\min(Q_1, Q_2)$ 以抑制过估计、获得保守价值估计。
   - 直觉：离线 RL 会把"导致成功下游结果"的策略选择赋予更高价值，把失败轨迹中的选择赋予更低价值；持续重估价值使 SWAP 能随上下文切换策略，并倾向于选择能更快推进任务完成的策略。

3. **路由评价器架构**
   - 使用**冻结的 Qwen2.5-VL-3B VLM** 作为视觉-语言编码器，将当前视觉观测与语言指令编码为 2048 维嵌入。
   - 该嵌入与**候选策略身份的可学习嵌入**拼接，输入轻量级 double-Q 网络（MLP），输出各候选策略的标量动作价值；另设独立价值网络用于 IQL 训练。

4. **测试时策略路由**
   - 每步选择：$z_t = \arg\max_z \min(Q_1(o_t,z), Q_2(o_t,z))$。
   - 所选策略被查询以产生一个短时程 chunk 的动作并执行，chunk 结束后重复该过程，实现执行过程中的动态切换。
   - 真实 DROID 实验中，SWAP 在多个相机视角上**聚合 Q 值**，以提升对视角歧义与遮挡的鲁棒性。

## 6. 主要结论与发现

- **SWAP 显著优于固定策略与随机路由**：DROID 上平均成功率从最佳固定策略的 63.3% 提升到 **96.7%**（+33.4 个绝对百分点）；随机路由为 66.7%，说明"能切换"本身有价值，但大部分增益来自"学会切换到谁"（比随机路由再高约 30 个点）。
- **执行更高效**：成功轨迹平均 **193 步**，相比最佳单策略的 269 步减少 **28.3%**，说明路由减少了不必要的动作与恢复开销。
- **路由具有结构化模式**：
  - 轨迹早期策略使用较均衡，中后期明显偏向 π0.5（中段 77.4%、尾段 63.7%）；π0 因价值持续偏低几乎从不被选。
  - 定性上表现为：自由空间移动偏好 π0-FAST（步长大、移动快），精细抓取与恢复偏好 π0.5；物体掉落导致所有 Q 值下降后，SWAP 会重新选择 π0.5 完成恢复抓取。
  - 未观察到策略切换引起的机器人运动不连续（因所有候选策略共享相同观测与 DROID 动作空间）。
- **对分布偏移有一定迁移性**：在 DROID 加入未见干扰物后（不重训评价器），SWAP 达到 90% 与 80% 成功率，远高于最佳单策略的 40% 与 30%。
- **在仿真中同样有效但存在边界**：
  - 五策略 LIBERO-Plus 设置中 SWAP 达 62.65%，远高于随机路由（2.7%，因行为不兼容的切换具有破坏性），并正确忽略 OpenVLA-Spatial（移除它仅变化 0.35 点）。
  - 但 SWAP 仍落后于最佳固定策略 π0（54.2% vs. 更高值），移除 π0 后升至 70.65%；原因是 π0 在评价器训练分布上最强，而**分布内质量不能预测 OOD 质量**，路由器本身泛化良好，限制因素是候选策略优势在偏移下是否稳定。
- **主导策略场景下不退化**：在强策略 + 弱策略设置中，SWAP 匹配甚至略优于主导策略（LIBERO 97.5%、LIBERO-Plus 89.0%），说明它不会被弱候选拖累。

## 7. 优点

- **问题设定新颖且有实际意义**：把"多 VLA 策略的组合"从"回合级选一个"推进到"分步动态路由"，抓住了真实部署中策略互补性的本质。
- **将路由转化为离线 RL 的形式化清晰**：动作空间为策略身份，长时程后果通过 Q 值刻画，避免了短视的启发式选择。
- **工程细节考虑周到**：
  - 按 VLA 的 chunk 粒度路由，不引入额外策略查询、不打断 chunk 语义；
  - 使用冻结 VLM 编码器 + 轻量 double-Q，使小规模离线机器人数据也能训练；
  - 采用双 Q 取 min 与 IQL，缓解离线 RL 的过估计问题；
  - 多视角 Q 值聚合提升真实场景鲁棒性。
- **黑盒组合方式带来扩展性**：候选策略无需重训，新增策略只需扩展输出头/嵌入，符合"策略生态"演进的实际需求。
- **实验覆盖真实 + 仿真 + OOD**，并用随机路由做关键对照，消融分析（移除策略、主导策略场景）揭示了路由器的失效边界（ID 质量 ≠ OOD 质量），分析诚实。
- **效率收益被明确量化**（步长减少 28.3%），不仅是成功率提升。

## 8. 不足与局限

- **规模与泛化边界**：
  - 候选策略数量少（真实 3 个、仿真最多 5 个），扩展到数十/数百个专用模型是否可行未验证；
  - 随候选集增大，查询多个异构策略会带来系统级部署挑战（推理开销）。
- **任务范围受限**：仅短时程桌面操控；长时程任务中稀疏终端奖励会成为更弱的训练信号，可能需要中间子任务完成信号。
- **未考虑成本因素**：目标函数只优化任务回报，未纳入推理延迟或金钱成本；成本感知路由是未来方向。
- **OOD 下的根本局限**：路由器的偏好由训练分布决定，当候选策略在偏移下的相对优劣发生反转时，SWAP 可能持续选择"ID 最优但 OOD 不佳"的策略（如 π0 在 LIBERO-Plus 的情形）。
