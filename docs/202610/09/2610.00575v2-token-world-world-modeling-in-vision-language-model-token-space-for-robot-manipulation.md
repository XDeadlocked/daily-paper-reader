## 摘要
面向视觉-语言-动作（VLA）系统的世界模型仿真的一种常见方法是预测未来的 RGB 观测，然后将其重新编码为策略输入，从而在仿真与下游策略执行之间引入间接接口。相反，我们研究是否可以在由 VLM 视觉 Token 导出的紧凑、面向策略的状态中对世界动力学建模。一个关键挑战是，原始 VLM 视觉 Token 是高维的，这使得高效且准确的自回归动力学建模颇具挑战性。为解决这一问题，我们提出 Token-World，一种动作条件世界模型，它将 VLM 特征压缩为紧凑的 Token 状态，在这一降维空间中学习未来动力学，并将预测状态映射回原本面向策略的表示以供下游使用。在多个操作基准上，Token-World 相较于近期世界模型仿真器提升了开环特征保真度和策略-动作一致性，并且在长推演时域上退化更慢。在闭环评估中，其仿真策略性能与参考策略性能的相关性比 Ctrl-World 更强（$r=0.794$ 对比 $0.583$），同时所需仿真延迟更低。消融实验进一步表明，紧凑表示的设计与维度会显著影响未来状态预测。代码将发布于 https://chuyaofu.github.io/Token-World/。

## Abstract
A common approach to world-model simulation for vision-language-action (VLA) systems is to predict future RGB observations and then re-encode them into policy inputs, introducing an indirect interface between simulation and downstream policy execution. We instead investigate whether world dynamics can be modeled in a compact, policy-oriented state derived from VLM visual tokens. A key challenge is that raw VLM visual tokens are high-dimensional, making efficient and accurate autoregressive dynamics modeling challenging. To address this, we introduce Token-World, an action-conditioned world model that compresses VLM features into a compact token state, learns future dynamics in this reduced space, and maps predicted states back to the original policy-facing representation for downstream use. Across manipulation benchmarks, Token-World improves open-loop feature fidelity and policy-action consistency over recent world-model simulators, with slower degradation over long rollout horizons. In closed-loop evaluation, its simulated policy performance correlates more strongly with reference policy performance than Ctrl-World ($r=0.794$ vs.\ $0.583$), while requiring lower simulation latency. Ablations further show that compact-representation design and dimensionality substantially affect future-state prediction. Code will be available at https://chuyaofu.github.io/Token-World/.

# Token-World 论文中文总结

## 1. 论文的核心问题与整体含义

- **研究背景**：世界模型作为可学习的仿真器，被广泛用于 VLA（视觉-语言-动作）系统的策略评估、数据合成与策略优化，以避免代价高昂的真实世界交互。
- **核心痛点**：现有 VLA 世界模型普遍采用**间接仿真接口**——先预测未来 RGB 观测，再重新编码为 VLM 视觉 token 供下游策略消费。这带来两个问题：
  - **表征错配**：仿真器预测的是"人类可看的像素"，而策略真正消费的是"面向策略的视觉 token"；RGB 重建会迫使模型把容量浪费在与策略无关的视觉细节上。
  - **计算冗余**：每步推演都要重复"生成 RGB → 重新编码"的往返过程。
- **核心研究问题**：能否直接在由 VLM 视觉 token 导出的、**紧凑且面向策略的状态**中建模世界动力学？
- **关键挑战**：面向策略的原始 VLM 视觉 token 是高维表示（如 108×2560），主要针对感知与动作优化，而非生成式动力学建模，直接预测其时间演化建模负担大、计算成本高。

## 2. 方法论

### 核心思想
将"策略消费的表示"与"世界模型建模的状态空间"分离：先把高维 VLM 特征压缩为紧凑 token 状态，在该低维空间中学习动作条件动力学，仅在需要时才映射回原始策略表示。**整个推演过程不涉及任何 RGB 生成**。

### 关键技术细节

- **紧凑 VLM 世界状态（S-VAE）**
  - 用单独训练的语义 VAE（S-VAE）构建紧凑状态：$c_t = C_\phi(z_t) \in \mathbb{R}^{N \times d}$，$d \ll D_0$。
  - 编码器参数化对角高斯后验 $q_\phi(c_t|z_t) = \mathcal{N}(\mu_\phi(z_t), \text{diag}\,\sigma^2_\phi(z_t))$。
  - 训练时采样 $c_t = \mu_\phi(z_t) + \sigma_\phi(z_t) \odot \epsilon$；导出时使用后验均值。
  - **仅沿特征维度压缩，不做空间池化或 token 融合**，保留原始空间布局（主配置：108×2560 → 108×16）。
  - 编解码器损失：$L_{codec} = L_{MSE} + L_{cos} + \lambda_{KL} D_{KL}(q_\phi \| \mathcal{N}(0,I))$。
  - 训练完成后冻结 $C_\phi$ 与 $G_\phi$。

- **动作条件动力学模型**
  - 紧凑世界状态 $x_t = (c_t, p_t)$，其中 $p_t$ 为机器人本体感知状态。
  - 建模转移 $p_\theta(x_{t+1} | x_{\leq t}, a_t)$。
  - 采用**时空 Transformer**：空间注意力（同一时刻 token 间交互）+ 因果时间注意力（跨时间演化），两轴因式分解以避免全时空稠密注意力。
  - 因时间注意力窗口有限，额外维护**固定大小 GRU 状态**，跨 rollout 窗口传递早期交互上下文。

- **训练目标（Flow-Matching + Shortcut Forcing）**
  - x0 参数化流目标：$x_\tau = (1-\tau)\epsilon + \tau x$，模型预测干净端点 $\hat{x} = f_\theta(x_\tau, \tau, C)$。
  - 诱导流 $v_\theta = (\hat{x} - x_\tau)/(1-\tau)$，损失 $L_{flow} = \mathbb{E}[w(\tau)\|v_\theta - v^*\|_2^2]$，权重 $w(\tau)=0.9\tau+0.1$。
  - 采用 shortcut forcing，支持少步生成（推理用 16 步）。
  - VLM 编码器与语义 VAE 在世界模型训练全程冻结。

- **自回归推演**
  - 观测到的紧凑状态初始化上下文，逐步去噪生成未来状态并追加到历史：$\hat{x}_{t+k+1} \sim p_\theta(\cdot | \hat{x}_{\leq t+k}, a_{t+k})$。
  - 有界 KV Cache + 跨窗口 GRU 状态保持长期上下文。
  - 需要策略特征时通过冻结解码器 $\hat{z}_{t+k} = G_\phi(\hat{c}_{t+k})$ 映射回 VLM 表示，**无 RGB 重建参与策略反馈回路**。
  - 仅用于可视化/人工评估时，才用独立冻结的卷积解码器 $D_{rgb}$ 渲染 224×224 RGB。

## 3. 实验设计

- **仿真**：RoboTwin 的 50 个操作任务，每任务 100 条轨迹（50 成功 + 50 失败），共 5000 条轨迹。
- **真实世界**：自采集 Franka 操作数据集，6 个任务（hang on M、hang on cup、stack jenga、stack ring、put jenga in drawer、put chili in drawer），600 条成功轨迹。使用 Franka Research 3 机械臂 + Robotiq 夹爪 + 两个 Intel RealSense 435 相机。
- 两个数据集均采用 9:1 训练/验证划分，所有对比方法共享相同数据。

### 对比方法（Baselines）
- IRASim（ICCV 2025）
- Ctrl-World（ICLR 2026）
- WorldGym（ICLR 2026）

### 评估维度
- **开环评估**：固定动作重放预测未来状态，用 NMSE 与余弦相似度评估 VLM 特征保真度；并将预测/真值表示分别输入同一冻结策略比较输出动作（策略-动作一致性）。指标先任务内平均再跨任务宏平均。
- **闭环评估**：使用三个共享 Qwen3-VL 骨干但动作头不同的 StarVLA 变体（StarVLA-OFT、StarVLA-PIv3、StarVLA-GR00T），从与参考环境相同的记录状态初始化，用 Pearson 相关性比较仿真与参考成功率（人工基于解码 RGB 评估成功）。

## 6. 主要结论与发现

- **开环保真度提升**：RoboTwin 上特征余弦相似度 0.7714、NMSE 0.4892，优于 IRASim（0.7372/0.5685）与 Ctrl-World（0.7097/0.6437）；策略-动作一致性同样最优（余弦 0.9439、NMSE 0.1145）。真实 Franka 上趋势一致。
- **长时域退化更慢**：在 chunk 0/5/10/15 上，Token-World 的 VLM 特征与动作相似度衰减明显慢于 Ctrl-World。
- **闭环评估更可靠**：仿真成功率与参考成功率的相关性 $r=0.794$（Ctrl-World 仅 0.583），回归线更接近 oracle $y=x$。
- **仿真效率更高**：每步 0.359 s，相对 IRASim/Ctrl-World/WorldGym 分别提速 2.0×/5.3×/6.1×。
- **表示设计至关重要**：
  - 重建保真度与扩散可建模性存在**权衡**：维度从 8 增至 128，重建 NMSE 0.1026→0.0409，但 SEC 上升（0.3511→0.4740）、LDS 下降（0.3100→0.1182）。
  - 动力学性能随维度**非单调**，$d=16$ 为最佳工作点（特征 NMSE 0.1517、动作余弦 0.9641）。
  - 紧凑 S-VAE 显著优于原始 VLM 特征与 SDXL-VAE 潜变量（特征 NMSE 0.7851→0.4892，动作余弦 0.8948→0.9439）。

## 7. 优点

- **表征对齐的创新视角**：提出直接在策略消费的 VLM token 空间中仿真，从根源上消除"RGB 生成 → 重编码"的间接接口，理念简洁且动机清晰。
- **仅沿特征维压缩、保留空间布局**：区别于把整帧/整视角聚合为少量 token 的做法，保留了空间结构，便于下游策略消费。
- **不依赖预训练视频生成模型**：仅用 flow-matching DiT 建模动力学，降低了对外部大模型的依赖。
- **系统性的表示可建模性分析**：引入 SEC/LDS 指标刻画潜在表示的扩散友好度，并进一步验证其对实际动力学性能的影响，超出单纯重建指标的层面。
- **评估体系完整**：同时覆盖仿真与真实、开环与闭环、保真度与效率，并做了控制变量的表示消融，结论可信度较高。
- **效率优势显著**：在保证甚至提升保真度的同时实现 2–6× 加速，工程价值明显。

## 8. 不足与局限

- **策略骨干覆盖有限**：闭环评估仅使用共享同一 Qwen3-VL 骨干的 StarVLA 变体，未验证跨不同策略骨干的泛化性。
- **表示设计缺乏理论刻画**：作者自述尚未系统回答"什么样的语义表示适合世界建模"，$d=16$ 等超参的最优性缺少更普适的指导原则。
- **真实数据规模与多样性有限**：仅 6 个真实任务、600 条成功轨迹，且缺少失败样本，可能引入偏差，难以充分反映真实场景的复杂分布。
- **闭环评估主观性**：任务成功率依赖人工从解码 RGB 判定，存在标注偏差风险。
- **算力信息缺失**：未报告训练硬件、时长与规模，影响可复现性与成本评估。
- **长时域验证范围有限**：长时域退化分析主要与 Ctrl-World 对比、chunk 至 15，未覆盖更长推演或更多基线。
- **应用限制**：方法强依赖特定的 VLM 视觉 token 空间与冻结编码器，迁移到其他 VLM 或非操作任务时需重新设计压缩与映射。
