## 摘要
从有限示教中学习面向多样化、长时域任务的稳健操作策略，仍是机器人学的一项根本挑战。我们提出 DROM，一种语言引导的扩散框架，使机器人能够在单一生成式策略中学习、表示和组合多种操作技能。DROM 利用动态运动基元（DMPs）将少量专家示教扩展为富有表现力的多技能数据集，在显著减少数据采集的同时，提升超出示教工作空间的空间泛化能力。基于运动规划扩散（MPD），我们扩展扩散架构，通过交叉注意力支持语言条件化的多技能轨迹生成，使单一模型能够为多样化的操作基元生成技能一致的运动，包括使用传统运动规划或硬编码控制器难以设计的对方向敏感的行为。对于长时域操作，大型语言模型将高层操作员请求分解为可执行的技能序列，从而实现自然语言交互和自主任务执行。我们在 Franka Emika Panda 机器人、FANUC CRX25ia 机器人以及 MuJoCo 仿真中，在广泛的多种操作任务上验证了 DROM。实验结果表明，DROM 优于运动规划扩散和行为克隆基线，实现了稳健的多技能泛化，并且仅使用少量人类示教即可组合已学习技能，从自然语言指令可靠执行长时域操作任务。数据集、仿真环境及更多内容见 https://github.com/automation-robotics-machines/drom。

## Abstract
Learning robust manipulation policies for diverse, long-horizon tasks from limited demonstrations remains a fundamental challenge in robotics. We present DROM, a language-guided diffusion framework that enables robots to learn, represent, and compose multiple manipulation skills within a single generative policy. DROM leverages Dynamic Movement Primitives (DMPs) to augment a small set of expert demonstrations into expressive multi-skill datasets, substantially reducing data collection while improving spatial generalization beyond the demonstrated workspace. Building upon Motion Planning Diffusion (MPD), we extend the diffusion architecture to support language-conditioned multi-skill trajectory generation through cross-attention, allowing a single model to generate skill-consistent motions for a diverse set of manipulation primitives, including orientation-sensitive behaviors that are difficult to design using conventional motion planning or hard-coded controllers. For long-horizon manipulation, a large language model decomposes high-level operator requests into executable sequences of skills, enabling natural language interaction and autonomous task execution. We validate DROM on a Franka Emika Panda robot, a FANUC CRX25ia robot, and in MuJoCo simulation across a wide range of manipulation tasks. Experimental results demonstrate that DROM outperforms Motion Planning Diffusion and Behavior Cloning baselines, achieves robust multi-skill generalization, and composes learned skills to reliably execute long-horizon manipulation tasks from natural language instructions using only a limited number of human demonstrations. Datasets, simulation environments, and more at https://github.com/automation-robotics-machines/drom.

- **研究动机**：在非结构化环境中学习稳健的机器人操作策略是操作学习的核心难题。传统模仿学习需要大规模、任务特定的数据集，通常局限于单一技能，难以跨工作流复用，且在工作空间与物体配置显著偏离训练分布时泛化能力差。
- **现有路线的问题**：
  - **基础模型 / VLA 模型**：虽能从高层指令直接执行长时域任务，但依赖互联网规模数据与重计算推理管线，延迟高，难以满足物理硬件上的实时与反应式控制。
  - **扩散 / 流匹配模型**：能捕捉复杂多模态运动分布，但现有基于扩散的操作策略多局限于单一技能，每个子任务都需专门的数据采集管线，从原始人类示教从头训练时样本效率低。
- **关键空白（gap）**：如何在不进行大规模人类示教采集的前提下，满足富有表现力的扩散模型对密集数据的需求；同时在不把语言模型延迟引入底层控制回路的情况下执行语言引导的长时域任务。
- **整体含义**：DROM（Diffusion for RObotic Manipulation）提出一个语言引导的多技能扩散框架，将**数据高效训练管线**与**分层任务推理**结合，作为可扩展的机器人编程桥梁——新增操作能力只需少量示教，无需重训任务特定规划器或手工设计运动策略。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 总体框架（四阶段）

- **(i) 专家示教采集**：通过动觉示教（真实平台）或 SpaceMouse 接口（MuJoCo 仿真）采集，频率 30 Hz。
- **(ii) DMP 合成数据增强**：将少量示教扩展为大规模、多样化的多技能轨迹数据集。
- **(iii) 技能条件扩散模型训练**：在增强数据集上训练语言条件化扩散模型。
- **(iv) 部署**：在仿真与真实机器人平台上执行单技能或长时域任务。

### 2.2 轨迹表示

- 固定视界 **H = 64**；每个路点包含末端位置 **(Px, Py, Pz)**、四元数姿态 **(Qx, Qy, Qz, Qw)** 以及二值夹爪命令 **G ∈ {−1, +1}**。
- 示教集合 **D_demo = {d_1, …, d_L}**，其中 L ≥ K（K 为技能总数）。对方向敏感或接近策略多变的技能（如抓瓶、抓杯），需提供多条示教以覆盖多种有效操作模式。

### 2.3 DMP 数据增强（关键创新之一）

- **DMP 形式**：二阶动力系统 `ÿ = αy(βy(g − y) − ẏ) + f(x)`，其中 `f(x)` 为归一化高斯基函数加权和，用于编码示教运动；相位变量 `ẋ = αx·x` 单调衰减。
- **超参数**：N = 200 个高斯 RBF，αy = 25，βy = αy/4 = 6.25（临界阻尼，保证平滑收敛），权重 ωi 用**局部加权回归（LWR）**从示教轨迹反解的目标力项中学习。
- **增强方式**：对每个示教学习一个 DMP，通过扰动初始与目标状态生成轨迹变化，同时保持底层运动模式。
- **数据规模**：每个技能固定生成 **M = 300 条**合成轨迹；当某技能有 Lk > 1 条示教时，轨迹预算在对应 DMP 间均分。所有合成轨迹回放、按任务成功准则验证、重采样至固定 H，并与对应语言嵌入配对。

### 2.4 技能条件扩散模型

- **前向过程**：`q(τt|τt−1,t) = N(τt; √(1−βt)τt−1, βtI)`，闭式边缘分布 `q(τt|τ0,t) = N(τt; √ᾱt·τ0, (1−ᾱt)I)`。
- **反向过程**：学习去噪模型 `pθ(τt−1|τt,t)`，协方差固定为 `β̃t = βt(1−ᾱt−1)/(1−ᾱt)`。
- **训练目标**：预测噪声项 `εθ(τt, t)`，最小化 `L(θ) = E[‖ε − εθ(τt,t)‖²₂]`。
- **技能条件化**：`εθ(τt, t, fθ(p))`，其中 `fθ(p)` 是基元 p 的技能嵌入。
- **架构**：采用 MPD 的 **Temporal U-Net**（4 个时间下采样层，通道 32→256，瓶颈层 + 对称上采样 + 跳跃连接，约 **6000 万参数**），并在**每一层/每个反向扩散步**引入**交叉注意力层**注入技能嵌入，从而在保持时序结构的同时关注技能语义。
- **与 MPD 的区别**：MPD 为单任务规划器，DROM 扩展为单一统一的多技能生成模型，可区分几何构型相似但运动策略与物体交互根本不同的行为。

### 2.5 语言条件化（双通道）

- **轻量语言编码器**：`all-MiniLM-L6-v2`（6 层 Transformer，384 维嵌入），将指令映射到语义空间，支持基于相似度的技能检索，延迟低。
- **聚类共形预测（Clustered Conformal Prediction）**：
  - 离线为每个技能采集 Utterance 集合 Uk，计算同技能样本间最大余弦相似度作为共形分数；按分数分布将技能聚类为 h 组，取组的分位数作为阈值 λk（显著性水平 α）。
  - 运行时三种情形：**(i) OOD**——所有技能分数均高于阈值，视为脚本外任务，转交 LLM；**(ii) 分类不确定**——多个技能分数低于阈值，转交 LLM 消歧；**(iii) 唯一匹配**——仅一个技能 p* 分数低于阈值，直接选中该技能驱动扩散模型。
- **LLM 任务分解**：`gpt-oss-120b` 接收可用动作、物体、参数列表与 few-shot 示例，采用**思维链（chain-of-thought）**结构生成有序技能序列 `s = [p1, p2, …, pn]`，或输出预定义 token 表示不可完成；应用**约束解码**（采样时屏蔽不在技能库中的技能）以降低幻觉风险。

### 2.6 训练配置

- 500 epochs，DDIM 调度器 25 步去噪，Adam 优化器，batch size 32 条轨迹，初始学习率 1e-5，指数方差调度，基于验证损失早停。
