## 摘要
世界动作模型（WAMs）利用预训练视频模型，通过联合预测未来视觉状态与动作来提升机器人控制的泛化能力。但这种能力带来了巨大的推理成本，因为去噪过程中会反复处理密集的未来帧 token。已有方法通过 token 剪枝来优先保证视觉保真度，从而降低视频扩散模型中的去噪成本。然而，这些方法在 WAM 的联合去噪过程中并未利用动作相关性来决定应保留哪些未来帧 token。本文提出 Sparse-WAM，一个无需训练的、动作引导的稀疏想象框架，通过有选择地处理未来帧 token 来加速 WAM 推理。我们观察到，尽管未来表示不断更新，在相邻去噪步之间，动作 token 对未来帧 token 的注意力（动作到未来注意力）在空间分布上存在显著重叠。受此启发，我们提出动作引导的 token 选择，以保留帧特定的动作相关区域以及跨帧上下文。然而，朴素实现会带来注意力打分和 token 打包开销，从而抵消剪枝带来的计算节省。因此，我们提出 Pilot，一种高效引擎，通过轻量级打分和跨步复用 token 选择来降低稀疏推理开销。在搭载 FastWAM-Joint 的 LIBERO 和搭载 Cosmos 3 Edge 的 RoboLab-120 上，Sparse-WAM 在 NVIDIA RTX 4090 上相较于密集 eager 推理分别实现了约 2.0× 和 1.8× 的推理加速，同时基本保持任务性能。

## Abstract
World-action models (WAMs) leverage pretrained video models to improve generalization in robot control by jointly predicting future visual states and actions. This capability comes at a substantial inference cost, as dense future-frame tokens are repeatedly processed during denoising. Prior methods address this by token pruning that prioritizes visual fidelity to reduce denoising costs in video diffusion models. However, these methods do not use action relevance to determine which future-frame tokens to retain during joint denoising in WAMs. In this paper, we propose Sparse-WAM, a training-free framework for action-guided sparse imagination that selectively processes future-frame tokens to accelerate WAM inference. We observe substantial overlap in the spatial distribution of attention from action tokens to future-frame tokens (action-to-future attention) between consecutive denoising steps, despite continued updates to the future representations. Motivated by this, we develop Action-Guided Token Selection to retain frame-specific action-relevant regions together with cross-frame context. However, a naive implementation can incur attention-scoring and token-packing overhead that offsets the computational savings from pruning. We therefore introduce Pilot, an efficient engine that reduces sparse inference overhead through lightweight scoring and cross-step reuse of token selections. On LIBERO with FastWAM-Joint and RoboLab-120 with Cosmos 3 Edge, Sparse-WAM achieves inference speedups of approximately $2.0\times$ and $1.8\times$, respectively, over dense eager inference on an NVIDIA RTX 4090, while largely preserving task performance.

## 1. 核心问题与研究动机

- **背景**：世界动作模型（World Action Models, WAMs）借鉴预训练视频模型的时空先验，在机器人控制中**联合去噪未来视觉状态与动作**，从而提升泛化性与鲁棒性（如 DreamZero、Cosmos 3）。
- **代价**：为显式生成高分辨率未来帧，每一步去噪都要处理大量未来帧视觉 token；去噪步耗时随 token 数显著增长，导致推理延迟高、控制频率受限。
- **现有路线的不足**：
  - 一类方法在推理时**直接放弃未来想象**（训练时用、推理时不用），牺牲了 WAM 的核心优势；
  - 另一类通过潜变量子目标、低分辨率表示、非对称去噪等**压缩未来帧 token**，但仍把算力花在与动作无关的区域；
  - 视频扩散模型与 VLA 中的 token 剪枝/缓存方法以**视觉保真度**或**观测输入相关性**为准，而 WAM 中未来帧 token 是从噪声初始化并与动作 token 联合去噪的，**动作相关区域无法事先确定**。
- **核心矛盾**：如何在不训练的前提下，识别"对动作预测真正有用的未来区域"，同时让选择与稀疏执行的额外开销低到不抵消剪枝收益。

## 2. 方法论

### 2.1 关键实证观察（动机来源）

论文首先刻画了**动作 token 对未来帧 token 的注意力**（action-to-future attention），定义为跨头平均的注意力权重 $U^{(\tau)}_{\ell}(i,f,j)$，并得到四条观察：

- **Insight 1(a) 时间对齐**：帧级注意力图呈近似对角带，每个未来帧主要接收约 $H/F$ 个连续动作 query 的关注；边界处的 query 还会关注相邻帧。
- **Insight 1(b) 空间漂移**：注意力热点在不同未来帧之间空间位置会移动 → 需要**逐帧独立选择**。
- **Insight 2 跨帧上下文一致**：剔除热点后，相邻帧的注意力重叠度上升，说明存在跨帧共享的稳定上下文区域 → 需要**共享锚点**。
- **Insight 3 跨步一致性**：相邻去噪步的空间注意力分布高度重叠（Cosmos 3 Edge 平均 81.11%，FastWAM-Joint 97.97%），而跨帧重叠更低（68.89% / 81.85%）→ 支持**跨去噪步复用选择**，但不支持跨帧复用。

### 2.2 动作引导的在线 Token 选择（免训练）

每帧保留 $K_c$ 个**帧特定核心 token** + $K_s$ 个**共享空间锚点**，$K_c + K_s \le N_s$，序列长度固定。

- **打分**：将 $H$ 个动作 query 均分为 $F$ 组 $I_f$，用中心权重更高的非负权重 $\alpha_{f,i}$ 加权聚合得到空间分数
  $S_\ell(f,j)=\sum_{i\in I_f}\alpha_{f,i}U_\ell(i,f,j)$。
- **层质量**：为每层定义 $Q_\ell = R_\ell(1-E_\ell)$，其中 $R_\ell$ 是帧对齐注意力质量、$E_\ell$ 是归一化空间熵；取质量最高的 $K_{\text{layer}}$ 层构成 $L_{\text{core}}$，加权聚合得 $V(f,j)$。
- **核心 token**：先在全部空间位置上按 $\max_f V(f,j)$ 取 top-$(N_s-K_s)$ 组成公共候选池 $P$，再在每个帧内按 $V(f,j)$ 从 $P$ 中取 top-$K_c$，得到 $C_f$。
- **共享锚点**：从**未被任何帧选为核心**的剩余位置 $E$ 中，按跨帧均值与变异系数打分 $\mu_j/(1+CV_j)$ 取 top-$K_s$（奖励强且跨帧稳定的注意力）。锚点位置共享，但表示仍逐帧独立更新。
- 两组集合互斥，恰好保证每帧 $K_c+K_s$ 个 token。

### 2.3 Pilot 高效执行引擎

- **低开销注意力剖析**：不额外做一次网络前向，而是在稠密条件前向中直接计算动作 query 与其对齐帧 key 的 query–key 乘积，**复用原始 log-sum-exp 归一化因子**（避免只对未来 key 归一化而破坏注意力质量 $R_\ell$），只需存 $S_\ell(f,j)$，无需物化完整注意力矩阵或 value 加权输出。
- **跨步复用与紧凑执行**：在初始完整步（$\tau_d=0$）完成选择并缓存视觉速度预测，后续稀疏步复用两者；选择与缓存按动作块刷新。被选 token 与全部观测、动作 token 一起作为紧凑序列处理，跨层、跨步复用原位置索引与打包元数据，保持恒定序列长度以支持编译执行。
- **被丢弃区域的采样更新**：被省略的未来 token 仍参与采样，用掩码混合当前预测与缓存预测
  $\tilde{v}^{(\tau)}_v = M_v \odot v^{(\tau)}_v + (1-M_v)\odot v^{(\tau_d)}_v,\ \tau>\tau_d$，
  动作预测则在每步都重算。

- **消融结论（续）**：core + stable 组合效果最佳；仅保留 core（帧特定核心 token）或仅保留 stable（共享锚点）均出现明显掉点，random-only 变体掉点最严重，说明增益来自**动作引导的选择**而非单纯减少 token 数。剪枝率消融显示，在 28.89%–68.89% 的保留区间内，Sparse-WAM 的成功率曲线相对平坦，直到极端稀疏（接近下界）才出现可察觉退化，说明存在较宽的"安全稀疏区间"。

## 7. 局限性

**作者明确承认的**：
- 评测主要在单一 GPU 平台（RTX 4090）上完成，未验证在其它硬件（如车载/边缘 SoC、不同显存带宽的加速器）上的加速比是否保持；
- 未报告训练总耗时、GPU 小时数或能耗，因此难以评估"免训练"在端到端成本上的完整优势；
- 跨步复用策略的评估范围有限，只覆盖了"每动作块刷新一次"及少量替代调度。

**从方法本身可推断的局限**：
- **依赖动作-未来注意力可解释性**：整套打分建立在"动作 query 对未来帧 key 的注意力具有时空结构"这一假设上；若某个 WAM 骨干的注意力弥散、多峰或与动作弱相关（例如动作分支与视觉分支耦合较松的架构），层质量 $Q_\ell$ 与空间分数 $V(f,j)$ 可能不再可靠。
- **超参敏感但未充分扫**：$K_c$、$K_s$、$K_{\text{layer}}$、$\tau_d$ 等引入了新的超参组合，论文只给出了部分消融，缺少跨骨干的超参迁移性分析。
- **固定序列长度的代价**：为支持编译执行而保持恒定 token 数，意味着在"简单帧"上无法进一步稀疏化，可能牺牲了自适应效率上限。
- **采样更新的近似性**：被丢弃区域用缓存速度预测做掩码混合，属于**有偏的近似**；在长去噪轨迹或高动态场景下，缓存与真实速度的偏差可能累积，论文未量化这一误差随步数的增长。
- **真实世界样本量偏小**：3 个任务、成功率的绝对差异（75.00% vs 77.78%）在少量 rollout 下可能落在噪声范围内。

## 8. 批判性评价

**方法层面的贡献**：
- 论文最有价值的部分是**用实证观察反推设计**：先量化 action-to-future attention 的时间对齐、空间漂移、跨帧一致与跨步一致，再据此构造"逐帧核心 + 跨帧锚点 + 跨步复用"的三层结构。这种"先诊断、再设计"的路径比直接套用视觉 token 剪枝更具说服力。
- **低开销注意力剖析**是工程上的亮点：复用原始 log-sum-exp 归一化因子、不物化完整注意力矩阵、不额外前向，使选择开销真正可控——这正是很多剪枝方法"省了算力却输在开销"的痛点所在。
- **同后端对比**（Table 5）主动回应了"加速比是否来自编译优化"的质疑，是较为严谨的做法。

**可疑或需进一步检验之处**：
- LIBERO 上各方法成功率集中在 97–99%，**天花板效应**使该基准难以区分方法优劣；此时真正的判别力应来自 RoboLab-120 与真实世界，而这两处的绝对成功率（23%、35.5%、75%）方差可能较大。
- RoboLab 上 ToCa/C³ache/SpecPrune-VLA 的**性能崩塌**（如 Edge 上 9–10%）值得警惕：这既可能说明这些方法确实不适配 WAM 的联合去噪范式，也可能反映**超参未针对新骨干调优**。论文若能在这些基线上做一次公平的调参搜索，结论会更强。
- **FLOPs 与延迟解耦**的观察（Edge 上 FLOPs 更高却更快）很有启发，但也提示：论文的加速比高度依赖实现细节（打包、索引复用、编译），其可复现性取决于代码与工程成熟度。
- "免训练"是卖点，但**打分与选择逻辑本身仍是人工设计的归纳偏置**，并非完全无先验；其泛化性依赖注意力结构的稳定性，这一点在论文中未做跨架构的鲁棒性检验。

## 9. 可改进方向

- **跨硬件与跨架构验证**：在多种加速器、多种 WAM 骨干（含注意力结构差异较大的模型）上复现，检验选择准则的迁移性。
- **误差累积分析**：量化被丢弃区域缓存混合带来的速度预测偏差随去噪步数的增长，必要时引入自适应刷新阈值而非固定刷新周期。
- **自适应稀疏度**：放宽固定序列长度约束，按帧的注意力集中度动态分配 $K_c$，在保持编译友好的前提下进一步压缩。
- **公平基线**：对 ToCa、WorldCache、SpecPrune-VLA、C³ache 在新骨干上进行超参搜索后再比较，区分"方法不适配"与"未调优"。
- **端到端成本核算**：补充训练/微调的总 GPU 小时与能耗，使"免训练 + 推理加速"的整体收益可量化。
- **统计严谨性**：对成功率差异做置信区间或显著性检验，尤其在小样本的真实世界任务上。

---

**一句话总结**：Sparse-WAM 通过"动作引导的在线 token 选择 + 跨步复用 + 紧凑稀疏执行"，在免训练前提下把 WAM 的推理加速到约 1.8–2.1× 而几乎不掉点，其核心洞见——**WAM 中该保留哪些未来 token 应由动作注意力决定，而非视觉保真度或观测相关性**——为世界动作模型的高效推理提供了一条清晰且工程可行的路径；其主要待补强之处在于评测平台的单一性、基线调参的公平性与近似采样误差的量化。
