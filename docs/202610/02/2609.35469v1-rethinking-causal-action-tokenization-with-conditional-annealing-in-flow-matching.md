## 摘要
自回归视觉-语言-动作（VLA）模型为机器人学习提供了一条可扩展路径，但现有动作标记器将标记化视为压缩问题，产生的表示与自回归主干在语义上不对齐。我们提出 CATok，一种因果动作标记器，将标记化重新表述为具有因果结构的生成过程。CATok 引入条件退火机制，通过逐步退火流匹配过程来提取动作标记：每个标记以所有前序标记为条件，并编码特定噪声水平下的残差重建信号，从而建立从粗到细的因果标记空间，其生成语义在结构上与自回归建模对齐。基于多模态扩散 Transformer（MMDiT）构建的以标记为条件的流匹配解码器，能以混合扩散头架构的精度从这些离散标记重建连续动作块。这种离散瓶颈在设计上实现了知识隔离，干净地将高层语义推理与低层运动执行分离，而无需显式注意力掩码。在三个仿真基准和真实世界机器人操作任务上的广泛评估表明，CATok 在重建保真度-压缩权衡和推理效率上均持续超越现有标记化方法，同时提升 VLA 任务成功率和训练效率，为纯自回归 VLA 系统建立了高性能、可扩展的基础。

## Abstract
Autoregressive Vision-Language-Action (VLA) models offer a scalable path to robot learning, yet existing action tokenizers treat tokenization as a compression problem, producing representations that are semantically misaligned with the autoregressive backbone. We propose CATok, a causal action tokenizer that reframes tokenization as a causally structured generative process. CATok introduces a conditional annealing mechanism that extracts action tokens by progressively annealing a flow-matching process: each token is conditioned on all preceding tokens and encodes the residual reconstruction signal at a specific noise level, establishing a coarse-to-fine causal token space whose generative semantics are structurally aligned with autoregressive modeling. A token-conditioned flow-matching decoder built on Multimodal Diffusion Transformer (MMDiT) reconstructs continuous action chunks from these discrete tokens with the precision of hybrid diffusion-head architectures. This discrete bottleneck enforces knowledge insulation by design, cleanly separating high-level semantic reasoning from low-level motor execution without requiring explicit attention masking. Extensive evaluations across three simulation benchmarks and real-world robotic manipulation tasks demonstrate that CATok consistently surpasses existing tokenization methods in both reconstruction fidelity-compression tradeoff and inference efficiency, while improving VLA task success rate and training efficiency, establishing a high-performance, scalable foundation for purely autoregressive VLA systems.

# 论文总结：Rethinking Causal Action Tokenization with Conditional Annealing in Flow Matching（CATok）

## 1. 核心问题与研究背景

- **研究动机**：纯自回归 VLA 模型（用同一套 next-token 目标预测离散动作 token）具有可扩展、可复用 LLM 训练基础设施的优势，但其核心瓶颈在于**如何对连续机器人动作进行标记化**。
- **现有方法的问题**：
  - 逐维均匀分箱（BIN）：产生 O(D×H) 长序列，忽略动作维度间相关性，缺乏因果结构。
  - FAST：DCT 压缩 + BPE，频率序系数与从左到右的自回归生成不自然对齐，且变长输出解码脆弱。
  - FASTer：RVQ 固定长度、重建保真度高，但仅面向重建优化，未考虑与语言模型骨干的兼容性。
  - OAT：嵌套 dropout 强制从左到右顺序，但 token 位置缺乏语义根基，不对应信息粒度或生成阶段。
- **核心洞见**：现有分词器只编码"动作应被重建为什么"，而**未编码"动作应如何被生成"**。去噪过程天然暴露从粗到细的抽象层级（高噪声→全局结构，低噪声→精细细节），若将 token 与该层级对齐，即可获得与自回归生成结构匹配的因果有序表示。
- **整体含义**：提出 CATok，将动作标记化重新表述为**因果结构化生成过程**，为纯自回归 VLA 提供高性能、可扩展的离散接口。

## 2. 方法论

### 2.1 核心思想
将流匹配去噪轨迹的时间因果结构迁移到 token 空间：每个 token 条件于所有前序 token，并编码特定噪声水平下的**残差重建信号**，形成粗到细（coarse-to-fine）的因果 token 序列。

### 2.2 关键技术细节

- **双流动作编码器（Dual-Stream Action Encoder）**
  - 对原始动作块做分位数归一化。
  - 用 2D CNN（权重归一化）沿时间与动作维度提取局部相关性，加可学习 2D 位置嵌入，得 Eact。
  - 并行初始化 K 个可学习 query 嵌入 Q(0)。
  - 二者送入 MMDiT 风格的对称多模态 Transformer，通过 co-attention 双向交互，经 L 层后保留 query 流 Q=(q1,…,qK) 作为动作块表示。

- **瓶颈向量量化器（Bottleneck VQ）**
  - 采用 ViT-VQGAN 的因子化码本设计：qk 经线性瓶颈 ψ: R^D → R^D′（D′<D）降维。
  - 在码本 C={e1,…,e|C|} 中按欧氏距离取最近邻得索引 ck = argmin ‖ej − ψ(qk)‖²。
  - 再经后投影 φ: R^D′ → R^D 恢复维度，ˆqk = φ(e_ck)。因子化设计显著提升码本利用率。

- **带条件退火的流匹配解码器**
  - 设 x0 ~ N(0,I) 为高斯噪声，x1 = A 为目标动作块，rectified flow 路径 xt = (1−t)x0 + t·x1，目标速度为 x1 − x0。
  - **条件退火机制**：按 κ(t) = ⌊tK⌋ 逐步掩蔽前 κ(t) 个 token 嵌入，仅将活跃子集 ˆQ>κ(t) 作为时刻 t 的条件。
  - 流匹配目标：L_FM = E[‖vθ(xt, t, ˆQ>κ(t)) − (x1−x0)‖₁]。
  - **机理**：早期高噪声阶段活跃 token 提供粗粒度全局引导；随 t 增大、轨迹逼近目标，活跃 token 减少，后续 token 专门负责残差精细化。由此每个 token 嵌入成为相邻流匹配阶段之间的**离散信息增量**。

- **训练目标**：L = L_FM + α·L_smooth + β·L_VQ
  - L_smooth 为 DCT 频域损失，惩罚频谱差异，促进长时程平滑与时序一致。
  - L_VQ 为标准承诺损失（stop-gradient），码本用 EMA 更新，低使用率条目周期性从当前批次重初始化。

- **解码（Detokenization）**：由 token 映射得 ˆQ，通过求解 ODE 单步还原连续动作：
  x1 = x0 + ∫₀¹ vθ(xt, t | ˜Qt) dt，其中 ˜Qt 仅保留最后 K−κ(t) 个嵌入。

- **VLA-CATok 集成**：VLM 骨干（输入图像 It、语言 l、本体状态 st）自回归预测 token 序列；冻结的 MMDiT 流匹配解码器单步生成连续动作块。训练时 tokenizer 与 decoder 冻结，仅更新 VLA 骨干，用 teacher-forcing 交叉熵损失。离散瓶颈天然实现**知识隔离**，无需显式注意力掩码。

## 6. 主要结论与发现

- **下游 VLA 性能**：CATok 在三个仿真基准上均取得最佳平均成功率；长时程任务提升最显著，SimplerEnv 的 StackGreenCubeOnYellowCube 相对最强基线提升 >16.7%；RoboTwin 2.0 clean 48.9% / randomized 53.1%，优于 FAST 的 47.8% / 47.8%。

- **推理效率**：综合考虑自回归生成与解码开销，CATok 端到端推理延迟接近最低，VLA 推理速度较 FAST 快约 **1.7×**。
- **真实世界**：在空间、颜色、长时程三类任务上均比 FAST 提升约 **20 个百分点**，证明优势可迁移到真实机器人。
- **内在属性**：CATok 8 取得最高 VRR×CR（16.85），重建保真度-压缩权衡优于所有同压缩水平基线；编码/解码延迟显著低于 FAST。
- **因果性证据**：
  - 熵在正向顺序下递减、逆序下递增，证明 token 顺序具有方向性（FAST 近乎平坦，Bin 略升）。
  - t-SNE 显示 token 嵌入按槽位组织：早期槽位平滑延展，中期扩散，后期紧凑分离。
  - 前缀重建显示增加 token 带来连贯的轨迹更新（先结构后残差）。
  - donor-swap 与单 token 移除呈现清晰的**位置依赖三角支撑结构**，早期 token 影响粗粒度动作与早期生成阶段，后期 token 影响精细细节。

## 7. 优点

- **视角新颖**：将动作标记化从"压缩问题"重构为"因果生成过程"，从生成建模的去噪层级中自然导出 token 的粗到细语义，而非事后强加顺序。
- **机制优雅**：条件退火 κ(t)=⌊tK⌋ 用极简的单调掩蔽调度，将 token 与流匹配阶段一一绑定，无需额外监督或复杂正则。
- **架构兼容性好**：基于 MMDiT 的流匹配解码器兼顾连续生成头的高控制精度与纯自回归 VLA 的训练兼容性；离散瓶颈天然实现知识隔离，无需显式注意力掩码。
- **验证体系完整**：不仅有下游成功率，还从熵、嵌入几何、前缀重建、干预实验四个互补角度直接验证"因果语义"，说服力强。
- **消融设计严谨**：通过 C、D 两组同架构同容量对照，有效排除了"增益来自 MMDiT 或模型容量"的替代解释。
