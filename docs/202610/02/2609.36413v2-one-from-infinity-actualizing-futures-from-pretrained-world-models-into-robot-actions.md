## 摘要
预训练视频世界模型能为一个场景承认许多合理的未来，但机器人必须实现与任务条件相符的那个确切未来。为将世界模型转化为可执行的机器人策略，现有方法利用大规模机器人数据和计算资源对笨重的世界模型骨干进行微调。我们质疑这一现状，认为昂贵的部分已在世界模型预训练中支付，因为视频世界模型的表示空间已经铺陈出多样的潜在未来。在这种情况下，剩下的只是选择能够完成任务的未来，并读出实现该未来的动作。我们将这一任务形式化为“实现化”，即在冻结世界模型提供的先验之上学习任务条件的选择与实现。这可以由一个微型 actualizer 模型解决。我们在冻结的世界模型编码器之上实现了仅有 60M 参数的 RoboActualizer。该 actualizer 由两个轻量级 DiT 专家组成，通过流匹配联合预测未来潜变量和动作。该模型可以完全在单张 GPU 上训练，峰值内存 32 GB。与现有 WAM 和 VLA 相比，RoboActualizer 的可训练参数最多少 100 倍，在包括 LIBERO、LIBERO-Plus、RoboTwin 2.0 的仿真基准以及两个真实平台上的五个任务上取得了出色性能，并具有 39 ms 的低延迟，可实现实时控制。

## Abstract
A pretrained video world model admits many plausible futures for a scene, but a robot must realize the exact task-conditioned one. To turn world models into executable robot policies, existing methods fine-tune the heavy world model backbone using large-scale robot data and computational resources. Challenging this status quo, we argue that the expensive part has already been paid in the world model pretraining since the representation space of a video world model lays out the diverse potential futures. In this case, what remains is to select the future that accomplishes the task and to read out the actions that realize it. We formalize this task as actualization, which learns a task-conditioned selection and realization on top of a prior supplied by a frozen world model. This can be solved by a tiny actualizer model. We implement RoboActualizer with as few as 60M parameters on top of a frozen world model encoder. The actualizer is composed of two lightweight DiT experts that jointly predict future latents and actions by flow matching. The model can be trained entirely on a single GPU with 32 GB peak memory. With up to 100x fewer trainable parameters than existing WAMs and VLAs, RoboActualizer reaches great performance on simulation benchmarks including LIBERO, LIBERO-Plus, RoboTwin 2.0 and five tasks on two real-world platforms, with a low latency of 39 ms that allows real-time control.

- **矛盾**：机器人最终必须完成**一个具体任务**，并输出精确动作，因此需要从"无限可能"中挑出**任务条件下的那一个未来**并执行。
- **现有两条路线的代价**：
  - **规划类（MPC）**：保持世界模型冻结，但在测试时对候选动作做大量想象 rollout 搜索，控制频率受限；且目标通常是目标图像或手工设计代价函数，而非语言指令。
  - **世界-动作模型（WAM）**：微调重型世界模型骨干，把动作预测吸收进世界模型，需要大规模机器人数据与大量算力。
- **核心论点（挑战现状）**：昂贵的部分（动力学与未来先验）**已在世界模型预训练中支付**；下游真正剩下的只是"**选择**任务对应的未来"与"**读出**实现该未来的动作"。选择问题远比动力学建模廉价。
- **形式化任务**：作者将这一任务命名为 **actualization（实现化）**——在冻结世界模型提供的先验上，学习任务条件的选择（selection）与实现（realization）。

## 2. 方法论

### 2.1 核心思想：分工与贝叶斯分解

- **世界模型负责什么**：视频世界模型 $g_\phi$ 将一段 RGB 观测片段编码为潜表示 $z_t = g_\phi(x_{t-\Delta:t}) \in \mathbb{R}^{N\times D}$，由于跨帧注意力，$z_t$ 已内含运动与"接下来可能发生什么"的先验。
- **世界模型不决定什么**：未来服从混合分布
  $$p(z^+_{t:t+H}\mid z_t)=\sum_{\ell\in L}p(\ell\mid z_t)\,p(z^+_{t:t+H}\mid z_t,\ell),$$
  每个任务 $\ell$ 对应一个分量，占据区域 $F_\ell(z_t)$，并集 $F(z_t)$ 是场景"能变成的一切"。
- **实际化要学的部分**（贝叶斯分解，式 3）：
  $$p(z^+_{t:t+H},a_{t:t+H}\mid z_t,\ell)=\underbrace{p(z^+_{t:t+H}\mid z_t)}_{\text{先验：由 }g_\phi\text{ 给定}}\cdot\underbrace{\frac{p(\ell\mid z^+_{t:t+H},z_t)}{p(\ell\mid z_t)}}_{\text{选择：待学}}\cdot\underbrace{p(a_{t:t+H}\mid z^+_{t:t+H},z_t,\ell)}_{\text{实现：待学}}$$
- **训练目标**：在冻结 $\phi$ 的前提下最大化似然（式 4），只需拟合选择与实现，而不必重塑先验几何，因此模型可以极小。

### 2.2 关键技术细节

- **冻结世界模型**：V-JEPA 2.1（ViT-L/16-384，约 300M），float32、eval 模式，始终不更新；取其视频分支（tubelet=2），用片段 $\{t-6,t-4,t-2,t\}$（clip len=4，间隔 2）编码并取最后一个时间组作为 $z_t$（392×1024 tokens）。
- **未来监督**：在 $t+4, t+8, t+12, t+16$ 处用同一 $g_\phi$ 编码未来潜变量作为目标；由于编码器冻结，**所有潜变量可离线缓存**，训练不经过视频基础模型前向。
- **为何小模型够用（表示论论证）**：宽为 $d_{model}$ 的实际化器最多只能刻画秩 $\le d_{model}$ 的几何分量；作者在 LIBERO 演示的 V-JEPA 潜变量上做 PCA，发现 $d_{model}=384$（DiT-S 宽度）即可保留 **93.8%** 方差（各 benchmark 稳定），说明表示空间本质低维。
- **x-prediction**：朴素 v-prediction 目标含满秩各向同性高斯噪声，窄网络无法拟合，因此改为**直接预测干净样本** $z^+$（与输入同为低秩结构）。
- **架构**：两个轻量 DiT 专家组成 **Mixture-of-Transformers（MoT）**——**latent expert** 预测任务条件未来潜变量（承担"选择"），**action expert** 生成动作块（承担"实现"）；两专家权重独立，通过共享自注意力交互，各自做交叉注意力条件化；条件包括冻结 UMT5 文本编码的指令与本体感受状态。
- **损失**（式 6/7）：两专家分别预测干净 token $\hat z^+,\hat a$，损失在速度空间以钳位分母计算（等价于 $1/(1-\tau)^2$ 加权的 x-prediction，下限 0.05），$L=L_a+\lambda_z L_z$，$\lambda_z=1$；两分支噪声水平独立采样。
- **实现细节**：每分支 12 个 pre-norm 块、AdaLN-single 条件化、RoPE（图像 3D、动作 1D 对齐步轴）、RMSNorm on q/k、无 dropout、无长跳连；DiT-S 为 $d=384$、6 头，**可训练参数 63.6M**；DiT-B 为 $d=768$、12 头、245.76M。
- **推理**：每个控制步编码器仅前向一次，仅小头部迭代 $K$ 步去噪；部署时可关闭未来潜变量预测（仅动作模式），中间特征可缓存，实现实时控制。

## 4. 资源与算力

- **训练**：在**单张 NVIDIA PRO 6000 GPU（32 GB 峰值显存）**上，LIBERO 训练约 **15 小时**；批大小 32、单卡、无梯度累积、bf16 混合精度、无 EMA。
- **关键节省点**：训练完全在**缓存的 V-JEPA 潜变量**上进行，不需要重复前向世界模型；无任何具身预训练，每个 benchmark 随机初始化。
