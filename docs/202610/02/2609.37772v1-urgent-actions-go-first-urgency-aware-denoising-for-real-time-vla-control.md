## 摘要
扩散与流匹配的视觉-语言-动作（VLA）策略通过迭代去噪生成动作块，导致大量推理延迟，严重限制实时机器人控制。现有加速方法将动作块视为单一计算单元，忽略了滚动时域控制的一个关键物理现实：动作是联合生成但顺序执行的，从而导致执行紧迫性本质异构。我们利用这种不对称性提出紧迫性感知去噪（UAD），一种新颖的推理时框架，根据每个动作实际需要执行的时间来分配去噪计算。UAD在更少的去噪步数后释放时间关键的紧急动作，同时将尾部动作持续的背景细化与物理执行重叠。然而，异构去噪引入两个关键挑战：紧急动作的提前释放误差和尾部动作的轨迹不一致。UAD通过两个核心机制优雅地解决二者：轨迹调和（Trajectory Reconciliation），其重建统一的内部状态演化，以在不增加额外模型评估的情况下恢复联合去噪的一致性；以及幽灵动作校正（Ghost Action Correction），其利用未执行的幽灵延续来动态补偿剩余可执行动作中的提前释放误差。在多种VLA架构、仿真基准和真实世界操作任务上的广泛评估表明，UAD在平均动作可用延迟上实现了高达1.89倍的加速，同时保持与采用最优去噪预算的原始推理相当的成功率，相较于最先进的VLA加速基线，提供了更有利的成功率-延迟权衡。

## Abstract
Diffusion and flow-matching Vision-Language-Action (VLA) policies generate action chunks through iterative denoising, incurring substantial inference latency that severely limits real-time robotic control. Existing acceleration methods treat an action chunk as a monolithic computational unit, ignoring a crucial physical reality of receding-horizon control: actions are generated jointly but consumed sequentially, resulting in inherently heterogeneous execution urgencies. We exploit this asymmetry to introduce Urgency-Aware Denoising (UAD), a novel inference-time framework that allocates denoising computation according to when each action is physically needed. UAD releases time-critical urgent actions after fewer denoising steps while overlapping the continued background refinement of tail actions with physical execution. However, heterogeneous denoising introduces two key challenges: early-release errors in urgent actions and trajectory inconsistency in tail actions. UAD elegantly resolves both through two core mechanisms: Trajectory Reconciliation, which reconstructs unified internal state evolution to restore joint denoising coherence without additional model evaluations, and Ghost Action Correction, which leverages non-executed ghost continuations to dynamically compensate for early-release errors across remaining executable actions. Extensive evaluations across multiple VLA architectures, simulation benchmarks, and real-world manipulation tasks demonstrate that UAD achieves up to a 1.89x speedup in average action availability latency while maintaining comparable success rates to vanilla inference with optimal denoising budget, offering a more favorable success-latency trade-off than state-of-the-art VLA acceleration baselines.

# 论文总结：Urgent Actions Go First: Urgency-Aware Denoising for Real-Time VLA Control

## 1. 核心问题与整体含义

- **研究动机**：扩散与流匹配 VLA（Vision-Language-Action）策略通过迭代去噪生成动作块（action chunk），推理延迟高，严重制约实时机器人控制。典型场景下执行一个动作块需约 500 ms，而生成下一动作块需约 300 ms，导致机器人在每个执行周期中超过 30% 时间处于空闲等待；在资源受限的边缘设备上问题更突出。
- **现有方法的不足**：现有加速方法（量化、剪枝、特征缓存、自适应步数缩减、生成-执行重叠等）将动作块视为单一计算单元，对所有动作 token 均匀分配去噪预算。
- **关键洞察**：滚动时域控制中，动作块内的动作是**联合生成、顺序执行**的，因此存在本质异构的**执行紧迫性**——最前面的动作最紧急（其生成延迟直接决定机器人何时能开始物理执行），尾部动作则有更大的时间缓冲，其细化过程可自然与早期动作的物理执行重叠。
- **整体含义**：论文提出一种新的推理时设计原则——去噪计算应按执行紧迫性而非均匀分配，从而在降低动作可用延迟的同时保持动作质量。

## 2. 方法论

### 核心思想
- 提出 **Urgency-Aware Denoising（UAD）**，一种无需额外训练参数的推理时框架：对紧急动作使用更少去噪步数提前释放，将尾部动作的持续细化与物理执行重叠。
- 异构去噪带来两个挑战：**紧急动作的提前释放误差**，以及因 DiT 共享注意力导致的**尾部动作轨迹不一致**。

### 关键技术细节

- **动作分段**：将动作块分为紧急动作（索引集 $\mathcal{U}=\{0,\dots,U-1\}$，需立即执行）与尾部动作（$\mathcal{T}=\{U,\dots,H-1\}$），其中仅前 $S$ 个动作会被执行（$U < S \le H$）。

- **① Urgency-Aware Early Release（UAER）**：
  - 为紧急动作分配缩减预算 $K < N^*$，尾部动作保留最优预算 $N^*$：$N_i = K\ (i \in \mathcal{U})$，$N_i = N^*\ (i \in \mathcal{T})$。
  - 采用动作特定欧拉步长：$x_k^i = x_{k-1}^i + \frac{1}{N_i} v_k^i$。
  - 紧急动作在 $K$ 步后即释放为可执行动作，其物理执行与剩余尾部去噪重叠，当紧急动作执行时长足以覆盖剩余计算时，尾部去噪延迟被完全掩盖。

- **② Trajectory Reconciliation（TR）**：
  - 因 DiT 共享注意力，紧急动作的大步长（$1/K$）破坏联合状态对齐，误差传播至尾部动作。
  - TR 将已缓存的 velocity 按规范步长 $1/N^*$ 重新积分，重建兼容的内部状态：$x'^i_K = x^i_0 + \frac{1}{N^*}\sum_{k=1}^{K} v^i_k$。
  - **零额外 DiT 评估**（速度向量已计算并缓存）。
  - 当 $K=1$ 时可**精确恢复** vanilla 状态，理论上尾部动作零额外误差。

- **③ Ghost Action Correction（GAC）**：
  - 已释放的紧急动作无法回溯修正，但其经 TR 后的完整去噪延续称为**幽灵状态/幽灵动作** $a'^i \triangleq x'^i_{N^*}$，作为理想参考。
  - 估计累计提前释放误差：$E = \sum_{i=0}^{U-1}(a'^i - a^i) = \sum_{i=0}^{U-1}(x'^i_{N^*} - x^i_K)$。
  - 将误差均匀分摊到剩余 $S-U$ 个可执行尾部动作：$a^i = x^i_{N^*} + \frac{E}{S-U}$，$i=U,\dots,S-1$。
  - 按物理语义选择性施加：加性维度（笛卡尔平移）用式 9，旋转在 $SO(3)$ 上通过复合校正，决策维度（如夹爪开合）被掩蔽。

- **整体状态演化**：$k \le K$ 时紧急动作用步长 $1/K$；$k > K$ 时用调和状态以步长 $1/N^*$；尾部动作始终以 $1/N^*$ 演化。

## 6. 主要结论与发现

- **加速效果**：在 3 个仿真设置中，UAD 相对 Vanilla（$N^*$）实现 **1.30–1.89×** 的 AAL 加速，SR 变化在 **−2.9 至 +1.2 pp** 之间。
- **对比单步去噪**：相比 Vanilla（$N=1$），UAD 在相近 AAL 下分别提升 SR **9.2、7.8、2.6 pp**，说明按紧迫性分配步数可缓解均匀单步推理的性能损失。
- **对比 SOTA 基线**：
  - D3P 步数选择保守，SR 保持但加速有限（0.97–1.23×）。
  - BAC 相比 UAD 在相近或更低 SR 下 AAL 更高。
  - RTC AAL 极低但 SR 大幅下降 **10.7–26.5 pp**。
- **真机结果**：UAD 将 AAL 从 34.3 ms 降至 15.2 ms（**2.26× 加速**），与 $N=1$ 的 14.9 ms 接近，同时保持默认基线的 **84% 成功率**（$N=1$ 仅为 71%）。
- **参数规律**：$K=1$ 配合覆盖剩余计算的中等 $U$ 即可在最小 AAL 下保持稳定 SR；增大 $K$ 未带来一致的 SR 改善。
- **消融结论**：UAER 降延迟但可能损 SR，TR 部分恢复尾部动作误差，GAC 进一步将 SR 恢复至接近 Vanilla；TR 与 GAC 几乎不增加暴露延迟。
- **难度分解**：UAD 在 easy/medium/hard/very hard 各档均保持竞争力，未依赖单一难度组的表现。

## 7. 优点

- **新颖的推理视角**：首次显式利用"动作联合生成但顺序消费"的物理不对称性，将执行紧迫性作为去噪计算分配维度，与现有架构级加速正交、可叠加。
- **零额外开销的纠错机制**：TR 通过重积分已缓存 velocity 恢复联合状态一致性，**不增加任何 DiT 评估**；GAC 利用幽灵动作估计误差并分摊，无需学习组件或额外优化。
- **理论保证**：$K=1$ 时 TR 可精确恢复 vanilla 状态，尾部动作理论上零额外误差，为超参数选择提供了原则性依据。
- **工程实用性**：无需重新训练、不引入可训练参数，直接修改 LeRobot 推理流程；采用独立 CUDA 流异步执行，可与物理执行真实重叠。
- **评估严谨**：多架构、多基准、仿真+真机验证；控制时间对齐防止异步方法被仿真墙钟时间虚假放大；统计置信区间报告完整。
- **物理语义感知的校正**：GAC 按加性/旋转/决策维度分别处理，旋转在 $SO(3)$ 上复合，避免夹爪误切换。

## 8. 不足与局限

- **应用限制**：
  - GAC 依赖动作维度可跨控制步补偿；对于相对固定或块级参考定义的动作表示（如真机部署中的相对变化表示），GAC 不适用，只能退化为 UAER+TR。
  - 需要精心选择 $U$ 与 $K$：$U$ 需使尾部阻塞 < 0.2 ms，$K=1$ 虽优但 $K>1$ 时 TR 的精确性不再成立。
- **实验覆盖局限**：
  - 真机实验仅单一机器人平台（Dobot Nova 2）、5 个任务、100 回合，统计效力有限。
