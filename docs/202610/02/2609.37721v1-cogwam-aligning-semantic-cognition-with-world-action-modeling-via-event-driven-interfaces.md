## 摘要
机器人策略日益融合语义推理与未来世界预测，然而将这些能力简单结合并不能保证局部预测与动作始终与任务进展保持一致。我们提出 CogWAM，一种认知引导的世界-动作模型，它通过持久化的语义状态（Semantic State）在任务推理与世界-动作学习之间建立显式的语义接口，该状态存储已完成的任务事件与当前活跃的子任务。CogWAM 仅在观测指示语义转换时更新该状态，从而使任务级上下文能够跨多个动作块持续存在。为将语义上下文与物理预测和控制相衔接，CogWAM 采用以进展为条件的 WORLD 与 ACTION 查询，有选择地提取任务相关信息，用于未来世界预测与动作生成。在训练期间，语义状态为两个分支提供共享的任务进展上下文；而在推理时则移除未来预测分支，直接根据观测与所维护的状态生成动作。我们进一步引入语义训练策略，以改进转换学习与闭环条件化。在无需额外机器人动作预训练的情况下，CogWAM 在 RoboDojo 上取得 15.56 / 11.70 % 的 Score/SR，并在 BiCoord 上达到当前最优性能；同时，真实世界实验展示了闭环双臂操作，其语义状态重生成次数比逐步更新少 16.4 次。

## Abstract
Robot policies increasingly incorporate semantic reasoning and future-world prediction, yet combining these capabilities does not guarantee that local predictions and actions remain aligned with task progress. We introduce CogWAM, a cognition-guided world-action model that establishes an explicit semantic interface between task reasoning and world-action learning through a persistent Semantic State, which stores completed task events and the active subtask. CogWAM updates this state only when observations indicate semantic transitions, allowing task-level context to persist across multiple action chunks. To bridge semantic context with physical prediction and control, CogWAM employs progress-conditioned WORLD and ACTION queries that selectively extract task-relevant information for future-world prediction and action generation. During training, the Semantic State provides shared task-progress context for both branches, while inference removes the future-prediction branch and directly generates actions from observations and the maintained state. We further introduce semantic training strategies to improve transition learning and closed-loop conditioning. Without additional robot-action pretraining, CogWAM achieves 15.56 / 11.70 % Score/SR on RoboDojo and state-of-the-art performance on BiCoord, while real-world experiments demonstrate closed-loop dual-arm manipulation with 16.4 fewer Semantic State regenerations than step-wise updating.

- **核心问题**：如何显式表示、维护并在语义推理、未来预测与动作生成之间共享“任务进展”？
- **整体含义**：CogWAM 提出一种认知引导的世界-动作模型，通过持久化 Semantic State 和事件驱动更新，把任务级语义认知与底层世界-动作学习对齐，使任务上下文跨多个动作块保持，而不是每一步重新推断。

## 2. 方法论
### 2.1 核心思想
- 维护一个持久化 **Semantic State** \(S_t=(m_t,s_t)\)：\(m_t\) 记录已完成任务事件，\(s_t\) 表示当前活跃子任务。
- 只在观测表明发生语义转换时更新状态，即 KEEP / UPDATE 决策，从而解耦“语义时间尺度”和“控制时间尺度”。
- 通过 **进度条件化的 WORLD 与 ACTION 查询**，让未来世界预测和动作生成共享同一任务进展上下文，但保留各自目标所需的表示。
- 推理时移除未来预测分支，只根据当前观测、指令和维护的 Semantic State 生成动作。

### 2.2 事件触发语义状态
- 给定当前观测 \(O_t\)、任务指令 \(\ell\)、上一状态 \(S_{t^-}\)，VLM 预测决策 \(d_t\in\{\text{KEEP},\text{UPDATE}\}\)。
- 若 \(d_t=\text{KEEP}\)，状态保持不变；若 \(d_t=\text{UPDATE}\)，生成记忆增量 \(\Delta m_t\) 和新子任务 \(s_t\)，并更新状态。
- 该状态可跨多个动作块持续存在，避免每步自回归重生成语义上下文。
- 训练时通过离线标注产生 KEEP / UPDATE 标签、记忆增量和子任务监督；推理时 KEEP 只需单次前向，UPDATE 才解码语义增量。

### 2.3 进度条件化 World-Action 接口
- 在因果序列中加入可学习的 WORLD 查询 \(Q_w\) 和 ACTION 查询 \(Q_a\)，二者均可关注当前观测、指令和 Semantic State。
- WORLD 查询用于条件化未来多视图 DINO 潜特征预测；ACTION 查询用于连续动作块生成。
- 采用 Mixture-of-Transformers 架构，世界流和动作流共享当前视觉锚点，并通过多模态自注意力交互；训练时用结构化注意力掩码阻止动作 token 访问未来潜变量，避免目标泄漏。
- 未来世界预测只作为训练时辅助目标，不参与推理动作生成。

### 2.4 训练目标与策略
- 将条件分布分解为：
  - 任务进展转移：\(p(S_t|O_t,\ell,S_{t^-})\)；
  - 进度条件下的世界预测与动作生成：\(p(Z_{t+H},a_t|O_t,\ell,S_t)\)。
- 动作分支使用 flow matching 目标；世界分支在冻结 DINO 特征空间预测未来表示；语义分支使用决策损失和自回归生成损失。
- 总损失为动作损失、世界损失和语义损失的加权和。
- **边界感知语义采样**：过采样 UPDATE 事件和靠近转换边界的 hard KEEP，缓解 KEEP / UPDATE 类别不平衡。
- **渐进语义条件化**：训练中逐渐用模型预测状态 \(\hat S_t\) 替代标注状态 \(S_t^\star\)，缓解闭环推理时的 exposure bias。
