## 摘要
视觉-语言-动作（VLA）模型近来引入了世界模型，以在稀疏动作标签之外提供更丰富的动态监督。然而，显式预测未来图像或视频可能包含与控制无关的外观，而从整体未来视觉表征和共享全局动作特征中得到的引导，可能无法建立动作与局部视觉变化之间按时间步特定的对应关系。为解决这一问题，我们提出 MotionWeave，一种用于动作分块预测的以运动为中心的未来动态框架，包含两个模块：动作诱导运动定位器（AIMG）和时域残差组合器（HRC）。具体而言，AIMG 以动作和本体感受表征为条件，构建特定于时域的查询，从当前视觉 token 中定位与每个未来动作时间步相关的交互区域。HRC 提取相邻时域交互表征之间的差异，将其编码为时间运动线索，并通过门控残差注入动作 token 中。训练时，使用从未来帧渲染的机械臂掩码构建基于 KL 的运动定位监督，而推理时仅使用当前观测。在六个 MetaWorld 任务上，MotionWeave 达到 75.3% 的平均成功率，相较于 π0（66.7%）取得 8.6% 的绝对提升，尤其在持续交互任务上。我们的代码见 https://github.com/autu-mn/MotionWeave。

## Abstract
Vision-Language-Action (VLA) models have recently incorporated world models to provide richer dynamic supervision beyond sparse action labels. However, explicitly predicting future images or videos may include control-irrelevant appearance, while guidance derived from holistic future visual representations and shared global action features may fail to establish timestep-specific correspondence between actions and local visual changes. To address this issue, we propose MotionWeave, a motion-centric future-dynamics framework for action-chunk prediction with two modules: the Action-Induced Motion Grounder (AIMG) and the Horizon Residual Composer (HRC). Specifically, AIMG conditions on action and proprioceptive representations to construct horizon-specific queries that localize interaction regions associated with each future action timestep from current visual tokens. HRC extracts differences between interaction representations at adjacent horizons, encodes them as temporal motion cues, and injects them into action tokens through a gated residual. During training, robot-arm masks rendered from future frames are used to construct KL-based motion-grounding supervision, while inference uses only the current observation. On six MetaWorld tasks, MotionWeave achieves a 75.3% average success rate, an absolute gain of 8.6% over π0 (66.7%), especially on sustained-interaction tasks. Our code is available at https://github.com/autu-mn/MotionWeave.

## 1. 核心问题与研究动机（背景与整体含义）

- **背景**：VLA（Vision-Language-Action）模型统一视觉感知、语言理解与动作生成，通常基于预训练 VLM，直接从当前观测预测连续控制信号。
- **痛点一：动作监督稀疏**。低维、稀疏的动作标签只约束最终控制输出，难以显式刻画"操作过程中哪些视觉区域发生变化、这些变化如何沿动作序列演化"，导致视觉表征缺乏局部交互信息与时间线索。
- **痛点二：世界模型监督"过度重建"**。WorldVLA、DreamVLA 等显式重建/密集想象完整未来场景，不可避免地把控制无关的静态外观、背景、纹理编码进来；WoG、Fast-WAM 虽放宽为隐式或免测试时想象的引导，但仍监督**整体**未来视觉演化，而非**逐时域（horizon-specific）的局部变化**。
- **痛点三：动作分块的"时序-后果"失配**。Action chunking 通常从共享全局特征解码整段动作，各时间步拿到同质化的视觉证据，缺乏"动作时间步 ↔ 局部视觉变化"的显式对应。
- **核心主张**：VLA 不应冗余地重建完整未来观测，而应**显式定位与动作相关的动态区域，并利用其时间演化引导动作块生成**。论文据此提出以运动为中心的未来动态学习框架 MotionWeave。

## 2. 方法论

### 2.1 核心思想与总体框架

- 在时刻 $t$，策略以当前 RGB 观测 $I_t$、语言指令 $l$、本体状态 $S_t$ 为条件，预测长度 $H=4$ 的动作块 $\hat a_{t:t+H-1}$；未来帧 $I_{t+1:t+H}$ **仅在训练**用于构造时域运动监督，**推理时不可用**。
- 三分支结构：
  - **InternVL3-2B**（Qwen2.5 系列语言解码器）编码 $I_t$ 与 $l$，与可学习的 action-query 占位符 $A_0$ 拼接后联合解码，输出动作 token $A\in\mathbb{R}^{N_a\times D}$ 与空间视觉 token $V=\{v_n\}_{n=1}^{N_v}$（实现中 $N_v=256$，对应 16×16 网格）。
  - **Proprio 编码器**将 $S_t$ 映射为本体嵌入 $P$；$P$ **不进入语言模型**，直接供给后续模块。
- 流程可概括为：$(A,V,P)\xrightarrow{\text{AIMG}}(M,\alpha)\xrightarrow{\text{HRC}}A'\xrightarrow{\text{Action DiT}}\hat a_{t:t+H-1}$。
- 关键设计约束：AIMG 的注意力 $\alpha\in\mathbb{R}^{H\times N_v}$ 与运动监督掩码**共用同一 16×16 网格**，保证二者严格对齐。

### 2.2 Action-Induced Motion Grounder（AIMG）：时域特定的区域定位

- 不重建未来 RGB，而是判断当前 $N_v$ 个视觉 token 位置中**哪些会在未来 H 步内发生变化**。
- 设 $e_h$ 为第 $h$ 个未来时间步的可学习时域嵌入，将动作 token $A$ 与本体嵌入 $P$ 经 LayerNorm + 线性投影到公共运动空间（维度 $d_m$），构造时域查询：
  $$q_h = e_h + \mathrm{Mean}(\mathrm{Proj}_a(A)) + \mathrm{Proj}_p(P)$$
  其中均值项使每个时域查询携带**全局动作引导**，再经轻量残差变换细化。
- 注意力与交互表示：
  $$\alpha_{h,n}=\mathrm{softmax}_n\!\left(\frac{q_h^\top \mathrm{Proj}_v(v_n)}{\sqrt{d_m}}\right),\quad m_h=\mathrm{LN}\!\left(q_h+\sum_{n=1}^{N_v}\alpha_{h,n}\mathrm{Proj}_v(v_n)\right)$$
- 聚合得到 $M=[m_1,\dots,m_H]$ 送入 HRC。所有 $m_h$ 均来自**当前观测**，仅靠 $e_h$ 区分，从而与未来动作时间步对齐。
- **运动监督构造（仅训练）**：对每个 $h$，用 Robot Engine 从 $I_{t+h}$ 渲染机械臂掩码，该掩码标出执行第 $h$ 个未来动作的臂部区域并抑制静态背景/纹理等无关外观；掩码下采样到 16×16 网格、加小常数平滑、归一化后得到目标分布 $\mu_h$。**无需人工标注**，可复用现有专家轨迹与现成掩码生成。

### 2.3 Horizon Residual Composer（HRC）：时序差分与门控注入

- AIMG 产出的交互表示彼此独立、不含场景演化信息，故用**相邻时域差分**编码变化方向与幅度：
  $$\Delta m_h = m_h - m_{h-1},\quad m_0 := m_1 \Rightarrow \Delta m_1 = 0$$
- 以运动差分作 query、动作查询作 key/value 做多头交叉注意力，让每条局部演化线索"探测"需要修正的动作查询：
  $$U=\mathrm{MHA}\big(\mathrm{Proj}_m(\Delta M),\ \mathrm{Proj}_a(A),\ \mathrm{Proj}_a(A)\big)$$
  （HRC 侧动作投影与 AIMG 侧独立。）
- 更新量与本体条件门控：
  $$\Delta A=\mathrm{Proj}_o(U),\qquad g=\sigma(\mathrm{Proj}_g(P))$$
  $$A' = A - g\odot \Delta A$$
- **减法式残差更新**而非直接覆写，使每个动作查询只吸收与其时间步对应的运动增量；门控自适应控制注入强度，保留 $A$ 中原有的控制先验。

### 2.4 训练目标

- Action DiT 以 $A'$、$P$、加噪动作块 $a_\tau$、扩散步 $\tau$ 为条件预测动作块，使用 flow-matching 损失 $\mathcal{L}_{act}$。
- 运动定位损失（对每个时域将 $\alpha_h$ 对齐到掩码分布 $\mu_h$）：
  $$\mathcal{L}_{motion}=\frac{1}{H\log N_v}\sum_{h=1}^{H}\mathrm{KL}(\mu_h\|\alpha_h)$$
  除以 $\log N_v$ 是按视觉 token 上均匀分布的熵做归一化。
- 总目标：$\mathcal{L}_{total}=\mathcal{L}_{act}+\lambda_{motion}\mathcal{L}_{motion}$，实现中 $\lambda_{motion}=0.05$。
- **推理阶段**：仅输入 $I_t,l,S_t$，掩码渲染与 KL 分支全部移除，DiT 去噪直接输出 4 个动作，不重建未来观测、不增加推理开销。

## 6. 主要结论与发现

- **性能**：MotionWeave 在 6 个 MetaWorld 任务上取得 **75.3% 平均成功率**，比最强基线 π0（66.7%）**绝对提升 8.6%**，并在 6 个任务中的 5 个上领先。
- **任务依赖性**：优势在**持续交互类任务**上最大——Disassemble 92.0% vs 68.0%、Shelf Place 76.0% vs 64.0%；而在 Pick Place 上 π0 更好（72.0% vs 60.0%），论文解释为该任务目标位移短、全局特征已足够。
- **对比世界模型路线**：DreamVLA 65.0%、WoG 50.7%、Fast-WAM 49.3%，说明预测完整未来视觉会引入冗余的静态背景/纹理/外观，分散有限模型容量；直接建模动作相关的运动区域、方向与幅度更有效。
- **消融结论**：
  - 仅加 AIMG 架构（无运动监督）从 58.0% → 62.0%，说明时域嵌入与动作条件查询已带来一定时序区分，但动作损失只提供**间接**空间引导；
  - 加运动定位监督后 62.0% → 70.0%，证明"未来机械臂区域目标"对塑造时域查询的注意力至关重要；
  - HRC 再带来 70.0% → 75.3%，说明相邻时域表征差分提供了额外时序信息

，并让每个动作查询按自己的时间步吸收对应的局部运动增量，而非共享同质化的全局视觉证据。

- **超参敏感性结论**：
  - 时域查询数在 1→4 时性能单调上升、在 4 处达到峰值（与动作块长度 $H=4$ 严格一致），继续增至 6/8 后回落，说明查询数与动作时域匹配时才能形成"一对一"的时序对应，过多查询会稀释注意力并引入冗余；
  - 运动损失权重 $\lambda_{motion}$ 在 0.05 处最优，0.10/0.20 时性能反而下降，表明过强的区域定位约束会挤占动作回归所需的表征容量，即"运动定位"是手段而非目的，需与控制损失保持平衡。
- **定性发现**：6 个任务的 rollout 关键帧显示，AIMG 的注意力在任务推进过程中随交互部位迁移（如抓取时集中在夹爪—物体接触区、插入时集中在孔位附近），而非固定在静态场景结构上，为"注意力确实学到了动作相关动态区域"提供了可解释性证据。

## 7. 局限性与未来工作

- **场景与具身覆盖有限**：全部实验在 MetaWorld 仿真、单一机械臂具身上完成，未在真实机器人、多视角、多具身（灵巧手、移动底盘、人形全身）上验证。运动监督依赖 Robot Engine 渲染的**机械臂掩码**，这要求仿真器可提供逐帧臂部分割；在真实场景中需要依赖分割/跟踪模型或人工标注来近似该掩码，其噪声敏感性未被讨论。
- **运动定义的偏窄**：掩码刻画的是"臂部区域变化"，对**被操作物体自身的运动**（物体被推动、旋转、形变）以及非接触性变化（流体、布料、可形变物体）覆盖不足；在物体运动主导的任务上，监督信号可能与真实因果动态不完全一致。
- **时域窗口固定**：$H=4$ 与查询数绑定的设计在实验中被验证为最优，但对更长时域或需要精细亚步骤控制的任务，窗口与查询数的联合扩展策略未做探讨；$H$ 增大后 $\Delta m_h$ 的差分噪声累积也未被分析。
- **定位分辨率较粗**：16×16 网格（256 token）对细小交互区域（如螺纹、狭缝）可能不足以提供精确定位，且 KL 目标由下采样掩码平滑得到，本身带有边界模糊。
- **评测严谨性**：未报告多随机种子下的均值±方差与显著性检验，也未说明基线是否在同一数据、同一训练步数下重训，因此 8.6% 的绝对提升幅度需谨慎解读。
- **成本透明度**：未报告训练总时长、推理延迟与显存占用，难以评估相对世界模型类方法的实际效率收益。

## 8. 总体评价与启示

- **核心贡献**：论文把 VLA 中的"未来监督"从**像素空间的重建**重新表述为**动作条件下的稀疏区域定位 + 时序差分**，用极轻量的监督（训练期 KL 对齐机械臂掩码）替代密集的未来帧预测，在推理期完全不引入额外开销，这一"训练期增监督、推理期零成本"的设计具有较好的工程性价比。
- **方法层面的可迁移性**：AIMG 的"动作 token + 本体嵌入 → 时域查询 → 视觉注意力"与 HRC 的"相邻时域差分 → 交叉注意力 → 门控减法残差"是两个相对独立、可插拔的模块，原则上可嫁接到其他 VLA 骨干（如 OpenVLA、π0）的动作头之前，论文未做此验证，但结构上具备可行性。
- **实证层面的说服力**：消融链条（58.0 → 62.0 → 70.0 → 75.3）清晰地分离了"架构带来的时序区分"与"运动监督带来的空间定位"两部分的贡献，且超参峰值与 $H=4$ 的一致性构成自洽证据；对比 DreamVLA/WoG/Fast-WAM 的结果支持了作者"过度重建有害"的核心论点。
- **主要短板**：证据面偏窄（单基准、单骨干、单视角、无真实机器人、无统计显著性），使得结论的普适性仍属**待验证的合理假设**，而非已被充分确立的结论；此外论文对失败案例（Pick Place 上不如 π0）的解释停留在定性层面，缺少针对"何时不需要运动监督"的定量刻画。
- **对后续研究的启示**：(1) 可探索将运动监督从"臂部掩码"扩展为"任意动态实体掩码"（物体、工具、接触点），以覆盖物体主导的任务；(2) 可研究自适应时域窗口，使查询数随任务复杂度或动作块长度动态调整；(3) 可将该框架与真实机器人上的自监督分割/光流结合，验证其在无仿真器掩码条件下的可行性；(4) 需要更严格的统计协议（多种子、置信区间）来确认此类细粒度监督的实际增益边界。
