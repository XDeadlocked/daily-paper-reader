## 摘要
世界-动作模型（WAMs）通过以预测的未来观测为条件来生成动作，从而提升机器人操作性能，但未来预测会在本已昂贵的迭代动作生成之上进一步增加推理开销。动作分块可以将这一成本摊销到多个动作上，然而在长执行时域中性能会下降，因为后续动作仍以过时的观测为条件。我们提出 STAIRCASE POLICY（阶梯策略），一种流式推理与训练框架，它将基于流匹配的 VLA 转化为 JEPA 风格的 WAM，并将一个大动作块在交错去噪阶段划分为多个子块。近期动作一旦可用就立即执行，而后续动作继续被细化。在每个子块边界，未来潜在表示会根据最新观测重新预测，并用于更新所有未执行动作，从而无需重复进行完整策略推理即可实现长时域执行。由此产生的未来预测误差还可作为自适应分块的信号。S-WAM 在 LIBERO 上达到 97.7%，在 LIBERO-Plus 上达到 87.9%，并在多种策略骨干网络和真实机器人任务上提升了性能。它达到每秒 292.7 个已执行动作，在相当精度下是传统执行吞吐量的 3.62 倍，同时将首动作时间从 123.6 ms 降低到 73.3 ms。结合额外的推理优化，吞吐量进一步提升至每秒 642.9 个动作。

## Abstract
World-Action Models (WAMs) improve robotic manipulation by conditioning action generation on predicted future observations, but future prediction adds further inference overhead to already expensive iterative action generation. Action chunking can amortize this cost over multiple actions, yet performance degrades over long execution horizons because later actions remain conditioned on stale observations. We introduce STAIRCASE POLICY, a streaming inference and training framework that turns a flow-matching VLA into a JEPA-style WAM and partitions a large action chunk into sub-chunks at staggered denoising stages. Near-term actions are executed as soon as they become available, while later actions continue to be refined. At each sub-chunk boundary, the future latent is re-predicted from the latest observation and used to update all unexecuted actions, enabling long-horizon execution without repeated full policy inference. The resulting future-prediction error can further serve as a signal for adaptive chunking. S-WAM achieves 97.7% on LIBERO and 87.9% on LIBERO-Plus, and improves performance across multiple policy backbones and real-robot tasks. It reaches 292.7 executed actions per second, $3.62\times$ the throughput of conventional execution at comparable accuracy, while reducing time-to-first-action from 123.6 to 73.3 ms. With additional inference optimizations, throughput further increases to 642.9 actions per second.

- **核心矛盾**：
  - 未来预测模块在已昂贵的策略推理之上**进一步增加开销**；底层控制器需数百 Hz，而策略推理频率通常低于 10 Hz，边缘设备部署尤为受限。
  - **动作分块**可把一次昂贵推理摊销到多个控制步，但有效吞吐取决于**执行时域 $H_{\text{exec}} \le H$**，而非生成时域 $H$。实际部署通常只执行前 1–20 个动作就重新规划并丢弃剩余动作。
  - 长执行时域下性能退化：跟踪/接触误差累积、不确定性随预测时域上升、执行期间场景变化无法反映在原始条件观测中。文中数据：$H_{\text{exec}}$ 从 10 增到 50，LaWAM 成功率下降 12.8 点，$\pi_{0.5}$ 下降 26.8 点。

- **整体含义**：提出 STAIRCASE POLICY，把"生成—执行"流水线化，使大动作块在长时域下既高效又可靠，为 WAM 的实用化部署提供了一条执行层加速路径。

## 2. 方法论

### 2.1 核心思想
将流匹配 VLA 转化为 JEPA 风格 WAM（称 **S-WAM**），把大动作块在**交错的去噪阶段**切分为多个子块：近期子块尽快读出并执行，远端动作继续去噪；每个子块边界用最新观测**重预测未来隐表示**并更新所有未执行动作。

### 2.2 基础设置
- Host 为流匹配 VLA：backbone 输出语义上下文 $e$ 与紧凑潜在计划 $z$；流匹配专家 $v_\theta$ 在从噪声到数据的线性路径上对动作缓冲 $x \in \mathbb{R}^{H \times d_a}$ 去噪。
- 新增轻量未来预测器：冻结视觉编码器 $h = E(o)$ 与解码器 $g$，预测未来隐特征 $\hat{f} = g(h, z)$。
- 专家条件为 $c = (h, \hat{f}, e)$。仅要求专家能以**单次 Euler 步**针对缓存 backbone 上下文调用，**不修改 host backbone 与 flow expert**。

### 2.3 去噪阶梯（Denoising Staircase）
- 将块长 $H$ 划分为 $K$ 个连续子块，每块 $G$ 个动作，$H = KG$；默认 $H=50, K=5, G=10$。
- 缓冲从纯噪声开始，**所有位置共享同一流时间** $\tau=0$；每次查询对所有位置推进一个 Euler 步，步长 $1/K$，即 $x \leftarrow x + \frac{1}{K} v_\theta(x, \tau \mid c_j)$，$\tau \leftarrow \tau + \frac{1}{K}$。
- 第 $j$ 次更新后，第 $j$ 个子块通过把同一速度估计**外推到 $\tau=1$** 读出：
  $$\hat{A}_j = \left[ x + (1-\tau)\, v_\theta(x, \tau \mid c_j) \right]_{jG:(j+1)G}$$
  并交给控制器，其余缓冲继续去噪。
- 第 $j$ 个子块在 $j+1$ 次 DiT 前向之后发出；所有位置保持同一 $\tau$，保证专家始终收到与训练一致的 **shared-$\tau$ 分布**输入。每 $H$ 个已执行动作仅需 1 次 backbone 前向 + $K$ 次去噪步。

### 2.4 刷新未来预测器
- 每个子块边界都有新观测 $o_j$ 可用，重算：
  $$h_j = E(o_j),\quad \hat{f}_j = g(h_j, z),\quad c_j = (h_j, \hat{f}_j, e)$$
  其中 $z$ 与 $e$ 保持块起始值不变。
- 昂贵的 VLA backbone **每块仅一次前向**；轻量未来预测器**每个子块边界一次**（毫秒级）。
- 刷新后的条件应用于**所有未执行位置**，使边界处的场景变化能影响当前块内后续全部动作，无需完整重规划。

### 2.5 基于未来预测误差的自适应分块
- 由于刷新是链式的，每个边界产生一对"预测—实现"：$\hat{f}_{j-1}$ 与 $h_j$ 对应，其差异
  $$\delta_j = \text{MSE}(\hat{f}_{j-1}, h_j)$$
  在场景偏离规划时预期时增大（如目标被移动）。
- 若 $\delta_j$ 超过阈值，当前块在第 $j$ 个子块后终止，backbone 重新规划，使**执行时域数据依赖**而非固定为 $K$ 个子块。

### 2.6 部署调度下的训练
- 用与推理**完全相同的流式调度**训练，暴露给模型部分去噪缓冲、单步读出、块内条件变化、自预测未来隐等状态。
- 每个演示窗口提供 $K+1$ 个边界观测；每个边界条件使用**自预测** $g(h_j, z)$ 而非真值 $h_{j+1}$，与部署信息一致。
- 前向展开保持顺序，但动作缓冲在边界间 **detach**，避免对整条 $K$ 步链反传；$K$ 个专家图在共享反向传播中优化。
- 监督目标是控制器实际消费的**读出结果**（式 1）而非速度；边界 $j$ 每个缓冲位置权重：位于发出子块内为 1，否则 $\lambda_{ne}=0.25$。
  $$\mathcal{L}_{act} = \frac{\sum_{j,p} w_j(p) \|\hat{A}_j^{full}(p) - A(p)\|_2^2}{d_a \sum_{j,p} w_j(p)},\quad \mathcal{L}_f = \frac{1}{K}\sum_{j=0}^{K-1} \text{MSE}(g(h_j,z), h_{j+1})$$
- 未来隐保持计算图连接：$\mathcal{L}_{act}$ 的梯度经 $\hat{f}_j$ 传回 $g$ 与 $z$，使未来
