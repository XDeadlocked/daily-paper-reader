## 摘要
世界模型学习环境动力学的内部表征以预测未来状态，使智能体无需物理交互即可优化动作规划。然而，开发能够真正内化底层因果物理规律、从而显式推理动作前提条件及后续状态转移的世界模型，仍是一项开放挑战。本文提出 VIDEAS，一种数据蒸馏框架，可将操作视频中的连续物理动力学转化为面向基础模型的显式动作语义。具体而言，它将视觉演示解构为离散动作轨迹，并利用先进的视觉-语言模型（VLM）提取包含动作前提条件和效果的结构化知识。为确保物理一致性，我们引入一种基于文本环境的先验引导轨迹仿真机制，以严格验证所提取的知识。值得注意的是，我们纳入负轨迹以丰富知识完备性，并增强数据多样性以缓解认知偏差。此外，我们提出 VIDEAS-WM，一套 8B/9B 参数规模的基于语言的世界模型，基于从 AgiBot-World 数据集衍生出的 34K 高质量样本训练而成。大量实验表明，VIDEAS-WM 在高层次具身动作语义推理方面达到最先进性能，展现出深刻的物理理解以及对未见场景的稳健泛化能力。

## Abstract
World models learn internal representations of environment dynamics to predict future states, enabling agents to optimize action plans without physical interactions. However, developing world models that genuinely internalize underlying causal physical laws to explicitly reason about action preconditions and subsequent state transitions remains an open challenge. In this paper, we propose VIDEAS, a data distillation framework that transforms continuous physical dynamics from operational videos into explicit action semantics for foundation models. Specifically, it deconstructs visual demonstrations into discrete action trajectories and utilizes advanced vision-language models (VLMs) to extract structured knowledge encapsulating action preconditions and effects. To ensure physical consistency, we introduce a prior-guided trajectory simulation mechanism grounded within a text-based environment to rigorously validate the extracted knowledge. Notably, we incorporate negative trajectories to enrich knowledge completeness and enhance data diversity to mitigate cognitive bias. Furthermore, we present VIDEAS-WM, an 8B/9B-parameter suite of language-based world models trained on 34K high-quality samples derived from AgiBot-World dataset. Extensive experiments demonstrate that VIDEAS-WM establishes state-of-the-art performance in high-level embodied action semantic reasoning, exhibiting profound physical understanding and robust generalization across unseen scenarios.

- **整体含义**：论文提出 VIDEAS，将"在野"操作视频中蕴含的连续物理动力学**蒸馏为显式、可检查的动作语义**（前提条件 + 效果），并训练出具备显式物理因果推理能力的语言式世界模型 VIDEAS-WM，为可验证、可泛化的具身世界模型提供新路径。

## 2. 方法论

### 2.1 核心思想
- 受人类通过观察环境动力学建立物理理解启发，利用大规模在线操作视频（天然编码动作的时序与因果依赖），将视觉演示**解构为离散动作轨迹**，用 VLM 提取结构化动作知识，并用**先验引导的轨迹仿真**严格验证物理一致性。

### 2.2 问题形式化
- 给定文本环境状态 $s_t$ 与动作 $a_t$，模型需：
  - 推断前提条件：$p_t \sim f_\theta(\cdot \mid \text{config}_{pre}, s_t, a_t)$
  - 预测状态转移：$\Delta s_t \sim f_\theta(\cdot \mid \text{config}_{eff}, s_t, a_t)$
  - 下一状态：$s_{t+1} = s_t \oplus \Delta s_t$
  - 前提落地判定：$v \sim f_\theta(\cdot \mid \text{config}_{grd}, s_t, c)$，$v \in \{\text{True}, \text{False}\}$

### 2.3 数据预处理（图 2）
- 基于 **AgiBot-World**（168K 长程操作 episode，含任务级与动作级语言标注）。
- 流程：**语义去重** → **片段质量过滤**（用 FlowNet 剔除运动不清晰片段）→ **片段切分**（依原始帧级动作边界，保证单语义行为）→ **VLM 动作描述重写** → **人在回路校验**。
- 产出离散、逻辑连贯的动作轨迹 $\tau = (a_0, a_1, \ldots, a_{T-1})$。

### 2.4 文本式环境生成
- VLM 从初始帧提取场景描述，再用 **LogicEnvGen** 生成 JSON 环境：房间布局、门窗、实体（机器人/物体）的细粒度属性（文本描述、3D 尺寸、位置、开合状态、读数等），以及空间关系（on/in）与非空间关系（hold/grasp）。

### 2.5 先验引导的轨迹仿真（核心机制）
- 每个原子动作 $a_t$ 通过三阶段细粒度流程建模：
  - **Consider（前提提取）**：$p_t = M_{con}(s_t, a_t, o_t, o_{t+1})$，教师 VLM 采用贪心解码（temperature=0）。
  - **Decide（前提落地）**：$e_t = \bigwedge_{c \in p_t} v_c,\ v_c = M_{dec}(s_t, c)$；$e_t=\text{True}$ 表示动作可行。
  - **Transfer（状态转移）**：$\Delta s_t = M_{tra}(s_t, a_t, o_t, o_{t+1})$。
- **视觉锚定**：仿真以动作前后帧 $o_t, o_{t+1}$ 为视觉证据，抑制文本幻觉。
- **双粒度迭代验证**：
  - **动作级**：若判为不可行（$e_t=\text{False}$），先触发 **re-consider** 修正前提知识；若仍不可行，说明前序状态转移有误，**重启仿真**。
  - **轨迹级**：仿真结束后用 LLM 基于最终状态 $s_T$ 评估任务是否完成；失败则诊断并反馈至下一轮，循环至成功或达到迭代上限。

### 2.6 负轨迹整合（缓解认知偏差）
- 定义依赖类型集合 $D$（如占有依赖、状态依赖），用 LLM 分析动作间因果关系，得到依赖记录：
  - $P_k = \{a_i \in \tau \mid i < k \text{ 且 } \exists d \in D,\ a_i \xrightarrow{d} a_k\}$
- 通过**移除前序动作 $a_i$** 自动生成负轨迹 $\tau^-$，使目标动作 $a_j$（$j = \min\{k \mid a_i \in P_k\}$）不可行。
- 负轨迹在"必须在 $a_j$ 失败"的先验下仿真：正常仿真至 $a_j$，仅执行 consider 与 decide（遮蔽视觉错配帧）；若正确判为不可行则**早停**收集负样本，否则重启。

### 2.7 模型训练
- 三类任务构成训练集 $C = C_{pre} \cup C_{grd} \cup C_{eff}$：前提推断、前提落地、环境动力学预测。
- 统一为序列生成范式，采用自回归目标：$\mathcal{L}(\theta) := -\mathbb{E}_{(x,y)\sim C}\sum_{l=1}^{|y|} \log P(y_l \mid x, y_{<l}; \theta)$。

## 6. 主要结论与发现

- VIDEAS-WM 在高阶具身动作语义推理上取得 **SOTA**，8B/9B 小模型可超越 31B/70B 等更大开源模型。
- **先验引导轨迹仿真机制**是保证知识正确性的关键，去除后性能大幅下降。
- **负轨迹整合**显著提升前提知识完备性，缺失时模型产生严重认知偏差（盲判成功转移），Counterfactuals 类别准确率

- 消融实验表明，**负轨迹整合（NTI）是缓解认知偏差、保证前提知识完备性的关键组件**：一旦移除，模型在 Counterfactuals（反事实）类别上的准确率从 96% 骤降至 48%，说明模型会退化为"只要看到动作就默认成功"的盲目状态转移预测器，丧失对动作可行性的判别能力。
- **数据效率极高**：在数据规模实验中，Llama3.1-8B 仅使用 20% 训练数据即从 28.00% 提升至 76.00%，说明 VIDEAS 蒸馏出的结构化动作知识具有高信息密度，不依赖大规模标注即可获得显著增益。
- **跨基座泛化性强**：在 Llama-3.1-8B、Qwen3-8B、Qwen3.5-9B 三个基座上均观察到一致的性能提升与消融趋势，表明方法并非绑定于特定模型架构或预训练语料。
- **小模型可超越大模型**：VIDEAS-WM 以 8B/9B 规模在多个 benchmark 上超过 31B、70B 级开源模型，甚至在部分指标上优于 Gemini 3.1 Pro，说明**领域化的物理因果知识注入比单纯扩大参数规模更有效**。
- **效率与精度可兼得**：在准确率—仿真耗时的 Pareto 前沿上，VIDEAS-WM 位于最优区域，避免了观测级生成模型的高计算开销，同时保持可解释、可检查的动作语义输出。
- **人工验证佐证知识可靠性**：前提准确率 97.78%、效果准确率 98.52%，表明经先验引导迭代验证后得到的动作知识在物理一致性上具有较高可信度。

## 7. 局限性、风险与未来方向

- **数据来源单一性**：训练语料完全来自 AgiBot-World 单一数据集，虽覆盖 Retail/Domestic/Restaurant/Office/Industrial 五类场景，但其动作类型、物体类别与真实开放世界的长尾分布仍存在差距，跨数据集、跨机器人形态的迁移能力尚待验证。
- **教师模型依赖**：Consider/Decide/Transfer 三阶段均依赖教师 VLM（Gemini 3.1 Pro）生成监督信号，教师自身的幻觉与偏差可能被蒸馏进学生模型，形成"知识天花板"；论文通过视觉锚定与迭代验证缓解，但未做教师模型替换的敏感性分析。
- **文本式环境的表达力边界**：环境状态被离散化为 JSON 文本描述（尺寸、位置、开合状态等），对于连续物理量（形变、流体、柔性物体、精细力控）的刻画能力有限，可能限制其在接触密集型任务上的适用性。
- **评测基准的仿真属性**：BTSIMBENCH、LogicEnvEval 均为构建的评测集，与真实机器人闭环执行之间存在 gap；论文未报告真机部署或 sim-to-real 结果。
- **验证样本规模偏小**：人工验证仅 135 条动作实例，且未报告标注者间一致性指标（如 Cohen's κ），统计效力有限。
- **潜在风险**：将动作前提与效果显式化后，模型可能对训练分布外的动作组合给出过度自信的可行性判断；负轨迹自动生成依赖 LLM 推断的依赖类型集合 $D$，若因果关系识别错误，可能引入错误的负样本。
- **未来方向**：可探索多源视频数据融合、教师模型自蒸馏迭代、连续状态表示与文本语义的混合环境建模，以及将 VIDEAS-WM 接入真实机器人规划闭环进行在线验证。

## 8. 总体评价与学术意义

- **问题定位精准**：论文指出现有世界模型"重预测、轻可行性"的根本缺陷，将动作前提条件（precondition）与效果（effect）的显式建模提升为一等公民，切中具身智能中长期被忽视的"动作可执行性判断"环节。
- **方法设计系统**：从数据预处理、文本环境生成、先验引导三阶段仿真、双粒度迭代验证，到负轨迹自动构造与统一序列生成训练，形成了一条完整且自洽的知识蒸馏流水线，各组件均有明确的动机与消融支撑。
- **核心创新点**：一是**用大规模在野操作视频替代昂贵交互**，把视觉演示转化为可检查的符号化动作语义；二是**以视觉前后帧为锚点的迭代验证机制**，在无人工标注条件下实现物理一致性自校正；三是**基于因果依赖的负轨迹合成**，以极低成本为模型注入反事实判别能力。
- **实验说服力**：3 个 benchmark、十余个基线、3 个基座、消融 + 数据规模 + 人工验证 + 效率分析的多维实验矩阵，整体论证较为充分；不足之处在于人工验证规模与跨基准消融的覆盖度。
- **实践价值**：8B/9B 量级模型即可超越数十 B 级通用模型，且推理以文本序列生成为主、无需视觉解码，具备较强的部署友好性，为具身智能体提供了一种低成本、可解释、可验证的世界模型构建范式。
- **一句话总结**：VIDEAS 通过"视频 → 离散动作轨迹 → 显式前提/效果知识 → 先验引导验证 → 负轨迹增强"的闭环，把物理因果从隐式参数中"挖"出来变成可读、可查、可训的动作语义，使小模型也能获得接近乃至超越大模型的具身物理推理能力。
