## 摘要
我们提出 NUDGE（Nudge Update via Differentiable GEometry，即基于可微几何的微调更新），一种无需训练的避障流程，可集成到任何基于扩散或流匹配的机器人策略中，包括扩散策略和视觉-语言-动作模型。我们的工作在推理时将来自符号距离场（signed distance field，一种返回每个点到最近障碍物距离的函数）的梯度注入策略，以引导其远离障碍物。它通过可微关节轨迹解码器支持任何常见的动作参数化，从绝对或相对关节位姿到末端执行器位姿。实验表明，NUDGE 能保持策略的任务分布，并实时反应式运行。

## Abstract
We propose NUDGE (Nudge Update via Differentiable GEometry), a training-free obstacle-avoidance procedure that can be incorporated in any robot policy based on diffusion or flow matching, including diffusion policies and vision-language-action models. Our work injects gradients from a signed distance field, a function returning each point's distance to the nearest obstacle, into the policy at inference time to steer it away from obstacles. It supports any common action parameterization, from absolute or relative joint poses to end-effector poses, through a differentiable joint-trajectory decoder. Experiments show that NUDGE preserves the policy's task distribution and runs reactively in real time.

## 1. 核心问题与整体含义

- **研究背景**：现代机器人策略（如 Diffusion Policy、π0、π0.5 等）通过示教数据学习闭环视觉运动控制，能够隐式地掌握"保持杯子竖直""维持接触""稳定抓取"等难以解析建模的任务约束。

## 6. 主要结论与发现

- NUDGE 在**不重训、不修改策略参数**的前提下，为扩散/流匹配策略（含 VLA）增加零样本反应式避障，并**保持任务分布**。
- **球面任务**：NUDGE（ρ=0.07）成功率 71.5%、碰撞率 0.21%，显著优于 Vanilla（37.0% / 16.4%）、Post-Projection（25.0% / 4.7%）、RAIL（37.5% / 0%，但 Reach 仅 37.5%）、OmniGuide（39.0% / 15.98%）；且 On-Sphere 与 Sphere Err. 与 Vanilla 相当，说明流形保持良好。
- **LIBERO**：单障碍平均成功率 44%（Unguided 30%、OmniGuide 30%、RAIL 1%），碰撞率 2.30%（Unguided 13.15%、OmniGuide 12.52%）；三障碍下 NUDGE 13% / 14.01%，仍优于 Unguided 的 4% / 38.26%。
- **实时性**：环境表示延迟 NUDGE 3.32 ms vs. OmniGuide 907.44 ms，快约 **273.3×**。
- **真机**：NUDGE 完成率 75.6%（62/82），较基线 16.7%（3/18）提升 **4.5 倍**；引导在 torch.compile 下仅增加 **2.46 ms**（eager 下 5.14 ms）。主要失败源是基础模型（11/19 未完成），而非 NUDGE 本身。
- 将引导修正放在**策略自身去噪循环内部**，比 Post-Projection / RAIL 这类事后修正更能与策略意图对齐，避免振荡与局部极小。

## 7. 优点

- **免训练、模型无关、即插即用**：仅需策略暴露去噪动作块，适用于扩散、流匹配与 VLA 采样器，无需重训或架构修改。
- **动作表示通用**：通过可微关节轨迹解码器统一支持关节/末端、绝对/增量四类动作参数化，适用范围广。
- **全身避障**：相比 OmniGuide 的末端+腕部稀疏探针，NUDGE 用连杆球体分解实现全身碰撞检查，并能纳入夹爪上的被抓物体。
- **尺度重参数化设计**：用 ρ_k∈[0,1) 与中位梯度范数 κ 归一化，使引导强度超参可跨坐标系迁移，工程上很实用。
- **实时性与真机验证扎实**：环境表示快 273×，引导开销毫秒级；真机 82 次动态障碍试验 + 逐阶段延迟分解，说服力强。
- **实验设计的三轴指标**（Goal / Collision / Manifold）能清晰揭示安全控制器的权衡本质，避免"只看成功率"的片面结论。

## 8. 不足与局限

- **适用范围受限**：仅支持扩散/流匹配类策略，明确排除 OpenVLA、RT-2 等自回归策略（无整块中间估计可供引导）。
- **无形式化安全保证**：作者在 Discussion 中自承未来工作才考虑形式化安全保证；当前方法是软引导而非硬约束，理论上仍可能碰撞。
- **代价函数近似**：仅在动作块中的**离散构型**上评估碰撞，不检查连续扫掠体积，快速运动或大步长时可能漏检；被抓物体几何建模较粗糙（单一球体偏移）。
- **障碍物场景较简单**：仿真中障碍物均为球体，未涉及铰接物体、可变形物体；LIBERO 中额外障碍可能使无碰撞抓取本身不可行。
- **基线公平性存疑**：RAIL 在 LIBERO 使用 ground-truth 几何，且大量 episode 因备份搜索耗尽/超时终止，其结果可能被系统性低估；真机基线仅 18 次试验，统计置信度弱于 NUDGE 的 82 次。
- **任务成功率仍偏低**：LIBERO 三障碍下 NUDGE 平均成功率仅 13%，说明在拥挤场景下引导能力有限；真机主要瓶颈来自基础模型本身（13.4% 基础模型失败）。
- **算力信息不完整**：未报告微调 π0/π0.5 所需的 GPU 数量与训练时长，复现成本不易评估。
- **潜在偏差风险**：SDF 构建依赖深度/点云质量与掩码（需排除机器人、目标、篮子、桌面），感知误差可能影响引导稳定性；真机仅 UR5 + 单一任务族，跨本体、跨任务泛化性尚未验证。
