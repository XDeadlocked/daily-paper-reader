## 摘要
预训练世界动作模型（WAMs）为多样化机器人操作任务提供通用能力，但要在不降低预训练技能的前提下将目标任务性能提升至专家水平仍具挑战性。我们探索面向 WAM 的同策略蒸馏（OPD），并提出 WAM-OPD。WAM-OPD 继承了 OPD 方法的优势：在学生模型自身诱导的分布下迁移任务特定教师知识，而非直接将学生模型拟合到狭窄的任务特定数据分布。然而，在闭环操作中，随着学生策略演化，观测历史会发生变化，需要新的环境 rollout 以保持同策略。将 OPD 应用于 WAM 需要重复数据收集，即使在仿真中也代价高昂，在真实机器人上往往不切实际。为避免蒸馏期间重复进行环境 rollout，我们提出前缀加权轨迹回放（PWTR）。PWTR 使用一个固定轨迹池，主要由初始学生模型的 rollout 组成，并辅以任务特定教师模型的 rollout 以扩大轨迹覆盖范围。对于从该轨迹池中回放的每条轨迹，PWTR 将当前策略条件于连续存储的历史上，以生成新的去噪路径，任务特定教师沿这些路径提供监督。尽管这些去噪路径会随着策略演化而刷新，但回放的环境轨迹保持固定。因此，PWTR 使用代理重要性权重对每个决策的蒸馏损失重新加权，这些权重来自每个决策之前轨迹前缀上累积的路径分数，以缓解由此产生的历史分布偏移。仿真和真实世界实验表明，在蒸馏期间无需额外环境交互即可实现任务适应。在两种设置中，WAM-OPD 均提升了目标任务性能，同时在未纳入适应的任务上保持接近初始的性能。

## Abstract
Pretrained world action models (WAMs) provide generalist capabilities across diverse robotic manipulation tasks, yet improving target-task performance to an expert level without degrading pretrained skills remains challenging. We explore on-policy distillation (OPD) for WAMs and introduce WAM-OPD. WAM-OPD inherits the advantage of OPD methods that transfer task-specific teacher knowledge under the student's own induced distribution, rather than directly fitting the student to a narrow task-specific data distribution. However, in closed-loop manipulation, the observation histories change as the student policy evolves, requiring fresh environment rollouts to remain on-policy. Applying OPD to WAMs entails repeated data collection, which is costly even in simulation and often impractical on real robots. To avoid repeated environment rollouts during distillation, we introduce prefix-weighted trajectory replay (PWTR). PWTR uses a fixed trajectory pool composed primarily of initial-student rollouts, supplemented with task-specific teacher rollouts to broaden trajectory coverage. For each trajectory replayed from this pool, PWTR conditions the current policy on successive stored histories to generate fresh denoising paths, along which the task-specific teacher provides supervision. Although these denoising paths are refreshed as the policy evolves, the replayed environment trajectories remain fixed. PWTR therefore reweights per-decision distillation losses using proxy importance weights derived from path scores accumulated over the trajectory prefix preceding each decision to mitigate the resulting shift in the history distribution. Simulated and real-world experiments demonstrate task adaptation without additional environment interaction during distillation. In both settings, WAM-OPD improves target-task performance while retaining near-initial performance on tasks excluded from adaptation.

# WAM-OPD 论文总结

## 一、核心问题与研究动机

- **背景**：预训练世界动作模型（World Action Models, WAMs）将预测性视觉建模与动作生成结合，为通用机器人操作提供了可复用的先验（如 Fast-WAM、Cosmos Policy 等）。但实际部署往往要求某些高频任务达到"专家级"可靠性，因此需要后训练（post-training）来专门化。
- **核心矛盾**：任务专精与技能保持、交互效率三者难以兼得：
  - **SFT**：直接拟合演示数据，计算便宜，但会导致灾难性遗忘（本文实验中 SFT 教师在自己非专精任务上大幅退化，如 Microwave 教师在 Stapler 上仅 31.0%，在 Handover 上仅 2.5%）。
  - **在线 RL**：直接优化任务奖励，但需要反复环境 rollout（真实机器人上受安全与重置成本限制），且稀疏奖励导致样本效率低；同样存在遗忘问题（πRL 保留任务平均仅 29.42%）。
  - **在线策略蒸馏（OPD）**：在 LLM 与视觉生成中已显示出"任务专精 + 缓解遗忘"的潜力，但迁移到闭环 WAM 时出现新问题——**闭环操作中策略决定后续观测，历史分布 d_θ 随策略演化**，因此严格的同策略采样需要不断重新 rollout 环境。
- **论文定位**：作者称这是**首次探索将 OPD 用于预训练 WAM**，提出 WAM-OPD，目标是在**蒸馏阶段完全不需要额外环境交互**的前提下，提升目标任务性能并保持未适配任务的近初始表现。

## 二、方法论

### 1. 整体框架

WAM-OPD = **前缀加权轨迹回放（PWTR）** + **前缀加权同策略蒸馏**，两部分互为补充：

- 历史（观测条件）来自**固定轨迹池**（不新采样环境）；
- 去噪路径（动作生成轨迹）由**当前学生在线刷新**（保持同策略的"半壁"）；
- 用**代理前缀重要性权重**修正固定历史与当前策略历史分布之间的偏移。

### 2. 在线 OPD 目标（作为理论起点）

- 固定条件分布的扩散/流匹配 OPD：`L_OPD(θ) = E_{c~p(c)} E_s E_{x_s~q_θ} ‖v_θ(x_s,s|c) − v_T(x_s,s|c)‖²`，其中同策略性体现在中间状态 x_s 采样自学生自身分布 q_θ。
- 闭环 WAM 中，条件分布本身变成由策略诱导的历史分布 d_θ：
  `L_WAM-OPD(θ) = E_{h~d_θ} E_{s~p_s} E_{x_s~q_θ(·|h,s)} ‖v_θ(x_s,s|h) − v_T(x_s,s|h)‖²`。
- **难点**：去噪路径可由模型推理刷新，但历史 h 必须由闭环执行产生，直接实现在线 OPD 就要反复 rollout。

### 3. 固定轨迹池（Fixed Trajectory Pool）

- `D = D_S ∪ D_T`：以**初始学生 π_θ0 的 rollout 为主**，辅以**任务特定教师 π_T^(j) 的 rollout**。
  - 学生 rollout 覆盖适配前的历史（含失败执行）；
  - 教师 rollout 扩大覆盖学生后期可能遇到的历史。
- 每条记录包含：历史 h_t（含条件输入）、采样的动作 chunk a_t、实际执行长度 ℓ_t、以及产生 a_t 的完整去噪路径；并带有任务标签与来源标签。
- 采样：每个 update 抽一条轨迹，按时间顺序处理 **等间隔子采样 n = 16** 个决策点；**存储的动作 chunk 不作为回归目标**，仅用于路径打分。

### 4. 去噪路径打分 φ_ν(u)

- 对存储路径 `{x_{s_m}}`（s_0 > … > s_K，Δ_m = s_{m+1} − s_m < 0），在打分策略 ν（学生快照 / 初始学生 / 任务教师）下计算：
  `φ_ν(u) = − Σ_m (1/2σ_m²) · ‖ P_u [ x_{s_{m+1}} − x_{s_m} − Δ_m v_ν(x_{s_m}, s_m | h_u) ] ‖²`
  - 残差 = 记录的去噪增量 vs. 策略 ν 在同一存储状态/历史下预测的增量；
  - **投影 P_u 只保留 ℓ_u 个实际执行动作坐标**，并按 d_u 归一化；
  - σ_m = max{σ_min, κ√(−Δ_m)} 提供辅助打分尺度。
- 论文强调 φ_ν 是**路径兼容性代理**，不是精确的动作对数似然。

### 5. 前缀权重构造

- 前缀分数：`Φ_ν(i) = Σ_{r<k} φ_ν(t_{τ,r})`（不含当前点，因为当前历史在生成动作前已知；首点为零）。
- 权重打分：`S_i = λ [ Φ_θ̄(i) − log( η e^{Φ_θ0(i)} + (1−η) e^{Φ_T^{(j)}(i)} ) ]`
  - θ̄ 为学生快照，θ_0 与 T^(j) 为固定参考；分母是"混合参考"（log-sum-exp 数值稳定实现）；
  - **λ ≥ 0 控制重加权强度，λ = 0 时退化为 w_i = 1（无权重混合源蒸馏）**。
- 归一化流程（附录 Eq.10）：按轨迹采样测度在**每个来源条件内**把 exp(S_i) 归一化到单位均值 → 在阈值 C 处截断 → 再次归一化得到 w_i。截断在前、二次归一化在后，故最终权重不必然 ≤ C。
- **固定参考分数只算一次并缓存**；每 **R 次学生更新**刷新一次学生快照、重算前缀权重，两次刷新之间权重固定。

### 6. 前缀加权同策略蒸馏

- 对每个采样决策点 i：以存储历史 h_i 为条件，**当前学生从高斯噪声生成全新去噪路径**；在低噪声时刻 s_i ~ p_s 取状态并 **stop-gradient 得到 x̄_i**。
- 学生与冻结的任务教师在同一 (x̄_i, s_i, h_i) 处求值，教师动作速度作为局部监督目标。
- 损失：`L̂(θ) = (1/|B|) Σ_{i∈B} sg(w_i) · ‖ v_θ(x̄_i, s_i|h_i) − v_T^{(j_i)}(x̄_i, s_i|h_i) ‖²`，查询状态、权重、教师目标均为常数，梯度只经学生速度预测回传；**一条轨迹内累积梯度后做一次学生更新**。
- **只监督动作速度场，视频分支不加蒸馏损失**（动作/视频损失系数 = 10 / 0）。
- 理论依据（附录 A）：在共享初始分布与环境转移核的假设下，全前缀密度比中这些因子相消，只剩动作概率项，得到 `ρ_t(h_t) = exp A_θ(t) / [η exp A_θ0(t) + (1−η) exp A_T(t)]`，从而支持"用前缀累积分数近似在线期望"的做法；同时论文明确该权重是**兼容性代理，而非精确在线重要性比**。
