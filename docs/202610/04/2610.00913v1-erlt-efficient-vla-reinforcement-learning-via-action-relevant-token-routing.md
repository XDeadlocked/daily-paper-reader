## 摘要
视觉-语言-动作（VLA）模型为机器人操作提供了强大的行为先验，但将其高效适配到下游任务仍然具有挑战性。近期工作通过在线强化学习（RL）对冻结的VLA进行适配来应对这一挑战，其样本效率取决于actor和critic所用状态表示的质量。现有方法要么使用与VLA无关的视觉编码器，要么通过对VLA内部表示进行固定压缩来构建此类表示。这两种设计均未显式提取对下游动作细化和动作价值估计最有用的、任务特定的动作相关VLA特征，因此限制了样本效率。为解决这一局限，我们提出eRLT，它通过在冻结VLA的Token和层之间路由任务特定的动作相关信息，构建有效的状态表示。具体而言，学习到的路由Token动态聚合多个深度的视觉-语言特征，而轻量级层路由器将这些汇总信息组合成一个固定维度的RL Token。该路由模块使用专家演示进行初始化，以捕获能够预测专家动作的特征，然后利用在线交互中的critic反馈进行细化，以用于动作价值估计。在七个LIBERO和RoboTwin任务上，eRLT相较于代表性基线将平均归一化学习曲线AUC最高提升23.7%。在USB连接器插入和主板排线插入的真实机器人实验中，相较于最强基线，AUC分别进一步提升108.9%和46.7%。

## Abstract
Vision-Language-Action (VLA) models provide strong behavioral priors for robotic manipulation, yet efficiently adapting them to downstream tasks remains challenging. Recent work addresses this challenge by adapting frozen VLAs through online reinforcement learning (RL), whose sample efficiency depends on the quality of the state representation used by the actor and critic. Existing methods construct such representations either with VLA-independent visual encoders or through fixed compression of internal VLA representations. Neither design explicitly extracts the task-specific action-relevant VLA features most useful for downstream action refinement and action-value estimation, therefore limiting sample efficiency. To address this limitation, we introduce eRLT, which constructs an effective state representation by routing task-specific action-relevant information across both tokens and layers of the frozen VLA. Specifically, learned routing tokens dynamically aggregate visual-language features at multiple depths, while a lightweight layer router combines these summaries into a fixed-dimensional RL token. The routing module is initialized using expert demonstrations to capture features predictive of expert actions and then refined using critic feedback from online interactions for action-value estimation. Across seven LIBERO and RoboTwin tasks, eRLT improves mean normalized learning-curve AUC by up to 23.7% over representative baselines. Real-robot experiments on USB connector insertion and motherboard ribbon-cable insertion further show AUC improvements of 108.9% and 46.7%, respectively, over the strongest baseline.

## 1. 核心问题与整体含义

- **研究背景**：Vision-Language-Action（VLA）模型通过大规模预训练获得强机器人操作先验，但在具体下游任务上仍需适配。监督微调依赖高质量演示，部署状态覆盖有限；在线强化学习（RL）可利用策略自身成功与失败交互进行补充。
- **核心问题**：在“冻结 VLA + 轻量 actor-critic 在线 RL”的框架中，样本效率高度依赖 actor 和 critic 使用的状态表示。现有方法主要有两类：
  - 使用与 VLA 无关的视觉编码器构造状态，如 DSRL/PLD 类方法，无法直接复用 VLA 内部任务相关特征；
  - 对 VLA 内部表示做固定压缩，如 RLT、Mi-DAS，只使用预定层和 token 集，无法适应不同任务中真正有用的特征。
- **关键观察**：论文的动机实验表明，对在线 RL 最有用的 VLA 层和 token 子集因任务而异；固定使用最终层或全部 token 并非最优。
- **整体含义**：eRLT 提出从冻结 VLA 的 token 和层两个维度动态路由任务特定的“动作相关”信息，构造固定维度 RL token，以提升在线 RL 的样本效率。VLA 本身保持冻结，不改变其动作生成过程。

## 2. 方法论

- **核心思想**：
  - 在冻结 VLA 的多模态 prefix 后追加可学习 routing tokens，单独进行一次前向传播；
  - 在多个 VLM 层读取 routing tokens 的隐藏状态，分别聚合为层摘要；
  - 用轻量层路由器学习各层权重，加权组合成固定维度 RL token；
  - 通过“专家动作预测初始化 + critic Bellman 反馈在线微调”两阶段训练路由模块。

- **Token-wise routing**：
  - 给定多模态 prefix embeddings \(E_t\)，追加 \(K\) 个 routing tokens \(\eta_{tok}\)；
  - 对每个选定层 \(\ell_i\)，取 routing token 位置的隐藏状态并做均值池化，得到该层摘要  
    \[
    u_t^{(i)}=\frac{1}{K}\sum_{k=1}^K h\big(F_{VLM}^{(\ell_i)}([E_t;\eta_{tok}])\big)_{route,k}
    \]
  - routing tokens 只用于构造 RL token，不参与 VLA 动作生成，因此不会改变冻结 VLA 的动作提议。

- **Layer-wise routing**：
  - 学习每层共享的层 logits \(\eta_{lay}\)，经 softmax 得到层权重  
    \[
    \alpha=\mathrm{softmax}(\eta_{lay}/\tau)
    \]
  - RL token 为  
    \[
    z_t=\sum_{i=1}^m \alpha_i u_t^{(i)}
    \]
  - token 路由决定“当前输入中取什么信息”，层路由决定“哪些 VLA 深度更重要”。

- **阶段一：任务特定动作相关初始化**：
  - 复用 VLA 的 SFT 演示数据；
  - 用轻量 action probe \(g_\omega\) 从 RL token 预测专家动作 chunk；
  - 损失为动作 MSE：  
    \[
    \mathcal{L}_{proxy}=\mathbb{E}_{(o_t,A_t^E)\sim D_{SFT}}\left[\|g_\omega(z_t)-vec(A_t^E)\|_2^2\right]
    \]
  - 该目标促使 RL token 保留区分不同专家动作所需的信息，而非像重构那样保留全部 token 内容；
  - 训练后按验证动作预测误差选择路由参数，并丢弃 action probe。

- **阶段二：Critic 驱动的在线适应**：
  - 在线 RL 中，critic 的 Bellman 目标可进一步反传到 RL token，使路由参数学习动作价值估计所需线索；
  - critic 损失：  
    \[
    \mathcal{L}_Q=\mathbb{E}_B\left[(Q_\phi(z_t,x_t,\xi_t)-\mathrm{stopgrad}(y_t))^2\right]
    \]
  - 梯度通过 \(z_t\) 更新 routing token embeddings 和 layer logits，同时更新 critic；
  - actor 更新时使用 detach 后的 RL token，不改变路由构造；
  - target actor、critic、routing module 通过 Polyak 平均缓慢更新；
  - 路由参数周期性更新，以限制计算量和表示变化速度。

- **实现细节**：
  - 使用 π0.5 backbone，隐藏维度 \(D=2048\)，prefix 约 968 个 token；
  - 选定层索引为 \(\{0,3,6,9,12,15,18\}\)，默认 \(K=1\)，温度 \(\tau=1.0\)；
  - 路由模块仅增加约 \(KD+m\) 个有效可训练参数，非常轻量。
