## 摘要
大多数视觉-语言-动作（VLA）模型依赖当前观测，一旦任务相关证据离开视野便会丢失，从而限制了其在长时程、依赖记忆的任务上的表现。现有工作会引入压缩的历史特征或稀疏的视觉关键帧。然而，孤立快照可能使策略无法确定过去交互过程中发生了什么变化，以及接下来应采取何种动作。为克服这一局限，我们提出 EvoMem-VLA，它通过显式编码并保留历史状态之间观测到的变化来构建状态演化记忆。这些变化表示保留了交互结果的证据，使策略能够超越孤立快照来跟踪任务进展。具体而言，我们引入条件增量标记化，将有序帧对编码为具有方向性、以源为条件的增量标记，每个标记与其对应的状态证据相关联。一个共享的 VLM 主干网络支持任务自适应路由：普通长时程任务遵循直接动作路由，而多阶段任务使用子任务路由，该路由生成可执行子任务作为动作生成的附加输入。在每个仿真基准上使用单个联合训练的策略，EvoMem-VLA 在 RMBench 上达到 80.7% 的成功率，在 RoboMME 上达到 82.0%，并在涵盖两种机器人本体的四个真实世界任务中达到 83.8%。这些结果在所有三种评估设置中均较先前最先进方法有显著提升。

## Abstract
Most vision-language-action (VLA) models rely on current observations and lose task-relevant evidence once it leaves view, limiting performance on long-horizon, memory-dependent tasks. Existing efforts incorporate compressed historical features or sparse visual keyframes. However, isolated snapshots can leave the policy uncertain about what changed during past interactions and which action should follow. To overcome this limitation, we propose EvoMem-VLA, which constructs state-evolution memory by explicitly encoding and retaining observed changes between historical states. These change representations preserve evidence of interaction outcomes, allowing the policy to track task progress beyond isolated snapshots. Specifically, we introduce conditional delta tokenization to encode ordered frame pairs into directional, source-conditioned delta tokens, each associated with its corresponding state evidence. A shared VLM backbone supports task-adaptive routing: normal long-horizon tasks follow a direct action route, whereas multi-stage tasks use a subtask route that generates an executable subtask as an additional input for action generation. With a single jointly trained policy for each simulation benchmark, EvoMem-VLA achieves success rates of 80.7\% on RMBench, 82.0\% on RoboMME and 83.8\% across four real-world tasks spanning two robot embodiments. These results represent substantial improvements over the previous state of the art in all three evaluation settings.

# EvoMem-VLA 论文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **核心痛点**：主流视觉-语言-动作（VLA）模型仅以当前观测与指令为条件，任务相关证据一旦离开视野即永久丢失，导致在长时程、依赖记忆的任务上难以跟踪任务进度、容易生成错误动作。
- **现有记忆方案的不足**：
  - 一类方法把历史压缩为**离散状态特征**（如 RoboFlamingo 的 LSTM 策略状态、HAMLET 的时刻 token、MemoryVLA 的感知-认知记忆）；
  - 另一类保留**稀疏视觉关键帧**（如 EventVLA 的初始帧+近期窗口+事件关键帧、MemER 的关键帧检索）。
  - 二者共同的问题是：**"发生了什么变化"始终隐含在历史状态中**，孤立快照无法回答"与更早观测相比改变了什么、下一步该做什么"。
- **论文主张**：长时程控制需要的记忆应同时保留"看到了什么"与"相对更早观测如何变化"。为此提出 **EvoMem-VLA**，通过显式编码历史状态之间的观测变化构建**状态演化记忆（state-evolution memory）**，使策略能基于已观测到的交互变化证据（而非从稀疏状态中反推）决定下一步动作。
- **整体含义**：把记忆表征从"状态快照"推进到"状态 + 状态间变化"，为长时程、多阶段、依赖记忆的机器人操作提供一种可统一训练的策略范式。

## 2. 方法论

### 2.1 核心思想
- 用**条件增量标记化（conditional delta tokenization）**把有序帧对编码为"有方向、以源帧为条件"的 delta token，并将其与对应的视觉状态按时间顺序交错排列，构成**多尺度状态演化记忆**。
- 记忆、当前观测、指令一并输入**共享 VLM 主干**，主干支持**任务自适应路由**：普通长时程任务走直接动作路由；多阶段任务先生成可执行子任务，再以子任务为附加上下文生成动作。

### 2.2 条件增量标记化
- 给定有序源-目标图像对 $(I_u, I_v)$，$u \le v$，冻结的 DINOv3 编码器 $\phi$ 产生 patch 特征 $f_u=\phi(I_u)$、$f_v=\phi(I_v)$。
- 配对帧编码器 $g_\Delta$ 将"源无法解释的目标信息"压缩为单 token：
  $z_{u\to v} = g_\Delta(f_u, f_v; q_\Delta)$，$q_\Delta$ 为可学习 query。
- 解码器 $h_\Delta$ 从 $(f_u, z_{u\to v})$ 重建 $\hat{f}_v$，用 log-cosh 重建损失 $L_\Delta$（对 patch 与特征维度取平均）预训练。
- 预训练后冻结 $\phi$ 与 $g_\Delta$，**丢弃 $h_\Delta$**，仅把 delta token 送入 VLA。该瓶颈产生的是**有方向、源条件的变化 token**，而非像素差、光流场或动作码。

### 2.3 状态演化记忆（多尺度）
- **固定锚点**：时刻 $t$ 保留 $0$、$t-30$、$t-15$、$t$ 的观测；初始锚点防止早期信息消失，近期锚点表示最新执行上下文。
- **事件状态库**：$\{(\kappa_i, o_{\kappa_i})\}_{i=1}^{m_t}$，按时间序保留最多 $K$ 个被选中的观测；episode 起始时历史索引 clamp 到 0，复用初始帧。
- **状态关联的变化 token**：
  - 近期变化：每个近期锚点与"15 步之前的观测"配对，得到 3 组 delta token $d_t^{(1)},d_t^{(2)},d_t^{(3)}$（由新到旧），每个观测流一个 token。
  - 事件变化：对每个事件状态编码 $(\kappa_i-\delta_e, \kappa_i)$，$\delta_e$ 为事件局部滞后；事件状态与事件局部变化均使用主视角。
  - 所有 delta token 经可学习线性层投影到 VLM 嵌入空间。
- **记忆组装**：
  $M^{anc}_t = [V_0; d_t^{(3)}; V_{t-30}; d_t^{(2)}; V_{t-15}; d_t^{(1)}; V_t]$
  $M_t = [M^{anc}_t; \{(d^i_e; V_{\kappa_i})\}_{i=1}^{m_t}]$
  **每个 delta token 紧邻其目标状态**，事件条目按采集顺序排列；仅作 tokenizer 源的帧不作为额外 RGB 记忆条目；模型不推断远距离关键帧之间的转移，也不重建未观测的中间状态。

### 2.4 在线事件状态获取（Keyframe Head）
- 从动作 query 状态预测动作时域内每个 offset 的记录概率：
  $\hat{p}_t = \sigma(k_\omega(Z_{A_t})) \in [0,1]^H$
- 仅在概率超过记录阈值时，调度得分最高的合法未来 offset；**只预测"何时记录"而非未来观测本身**，到点才真正写入；库保留最新 $K$ 条。

### 2.5 任务自适应路由
- 设 $C_t = [M_t; L; E_\ell(R_t)]$，$R_t$ 为历史子任务文本。
- **子任务路由**：$\hat{s}_t = \text{Decode}_\theta(C_t)$，$\hat{A}_t = \Pi_{\theta,\psi}([C_t; E_\ell(\hat{s}_t)])$；训练时 $R_t$ 来自前置子任务标注，部署时累积生成的子任务文本（跳过空输出与连续重复，每个 episode 重置）。注意 $R_t$ 记录的是**先前预测而非已验证的任务完成状态**。
- **直接路由**：$R_t$ 为空，$\hat{A}_t = \Pi_{\theta,\psi}(C_t)$。
- 路由由**任务级配置**指定，而非学习到的复杂度分类器；两条路由共享视觉编码器、delta 投影、VLM 主干、动作 query、动作头与 Keyframe Head。

### 2.6 学习与闭环推理
- **两阶段优化**：阶段 1 冻结 $\phi$ 训练 $g_\Delta, h_\Delta$；阶段 2 冻结 $\phi, g_\Delta$，优化 VLA、动作头、delta 投影与 Keyframe Head，损失为
  $L = L_{act} + \lambda_{lang} L_{lang} + \lambda_{kf} L_{kf}$
  - $L_{act}$（动作 chunk 的 L1 误差，对每个样本都施加）；
  - $L_{lang}$（子任务目标位置的 token 级交叉熵，视觉输入/提示/动作 query 被 mask；直接路由样本贡献 0）；
  - $L_{kf}$（监督 offset 上的正类加权 BCE，无有效监督时为 0）；
  - 阶段 2 不含 $L_\Delta$。
- **闭环推理**：每个重规划步执行"读-推理-执行-写"循环：读取固定锚点、当前观测与已提交事件状态 → 编码 3 组近期 delta 与事件局部 delta → 组装 $M_t$ → 按配置路由预测动作 chunk（或先生成子任务再预测）→ Keyframe Head 可能并发调度未来采集（到点才写入）→ 更新近期缓存、有界事件库与子任务历史。所有预测只条件于机器人**已经观测到**的证据。

## 3. 实验设计

### 3.1 仿真基准
- **RMBench**：9 个双臂操作任务，含 5 个 $M(1)$（需保留单次任务相关历史观测）与 4 个 $M(n)$（需多次历史观测信息）；每任务 100 episode，共 900。
- **RoboMME**：16 个任务，覆盖 counting / permanence / reference / imitation 四类记忆；每任务 50 easy + 25 medium + 25 hard，共 1600 episode。
- 实现于 QwenOFT / StarVLA 框架，共享主干初始化自 **Qwen3-VL-4B-Instruct**；每个 benchmark **只联合训练一个策略**。
- 路由配置：RMBench 的 5 个 $M(1)$ 走直接路由，4 个 $M(n)$ 走子任务路由；RoboMME 全部 16 个任务走子任务路由，且启用关键帧记忆（容量 16，阈值 0.55）；RMBench 关闭关键帧记忆。
