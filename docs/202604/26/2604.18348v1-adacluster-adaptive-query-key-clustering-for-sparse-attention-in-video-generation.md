## 摘要
视频扩散变换器（DiTs）由于注意力机制的二次复杂度而在推理阶段面临极高的延迟。现有的稀疏注意力方法要么忽视语义相似性，要么无法适应跨层异质的 token 分布，从而导致模型性能下降。我们提出 AdaCluster，一种无需训练的自适应聚类框架，在保持精度的同时加速 DiTs 的生成。AdaCluster 对查询向量采用保持角度相似性的聚类方法以实现更高压缩，并为键向量设计了保持欧几里得相似性的聚类方法，涵盖聚类数分配、基于阈值的自适应聚类以及高效的关键聚类选择。在一块 A40 GPU 上对 CogVideoX-2B、HunyuanVideo 和 Wan-2.1 的实验表明，AdaCluster 可实现 1.67-4.31 倍的加速，且几乎无质量损失。

## Abstract
Video diffusion transformers (DiTs) suffer from prohibitive inference latency due to quadratic attention complexity. Existing sparse attention methods either overlook semantic similarity or fail to adapt to heterogeneous token distributions across layers, leading to model performance degradation. We propose AdaCluster, a training-free adaptive clustering framework that accelerates the generation of DiTs while preserving accuracy. AdaCluster applies an angle-similarity-preserving clustering method to query vectors for higher compression, and designs a euclidean-similarity-preserving clustering method for keys, covering cluster number assignment, threshold-wise adaptive clustering, and efficient critical cluster selection. Experiments on CogVideoX-2B, HunyuanVideo, and Wan-2.1 on one A40 GPU demonstrate up to 1.67-4.31x speedup with negligible quality degradation.

- **研究目标**：  
  在不重新训练模型的前提下，通过自适应聚类机制降低注意力计算量，实现 **加速与精度兼顾** 的视频生成。

## 二、方法论：AdaCluster 框架

### 1. 核心思想
- 将 **查询 (Query)** 和 **键 (Key)** 向量的聚类方式区分处理，针对二者不同的物理意义和空间分布特点，设计 **角度相似性（查询）+欧氏相似性（键）** 的自适应聚类方案；
- 结合 **阈值自适应聚类** 与 **关键簇选取机制**，实现层级可变的稀疏注意力。

### 2. 查询向量聚类（Angle-based Query Clustering）
- **理论依据**：查询向量长度的变化不影响注意力分数的相对大小；
- 因此先对查询进行 **归一化（单位球投影）**，再基于角度相似性进行 KMeans 聚类；
- 聚集在角度空间的 token 更加紧凑，使压缩比显著提升；
- 实验表明归一化可使每层聚类压缩比提升约 **3.6×**，且几乎不损失精度。

### 3. 键向量聚类（Layer-wise Euclidean Clustering）
- 键向量的方向和长度都会影响注意力得分，因此需要欧氏距离聚类；
- 提出 **多阶段自适应 KMeans（Multi-Stage Clustering）**：
  - 首阶段：使用中等数量的簇；
  - 后续阶段：对离群点（超出阈值 τ 的样本）重新聚类；
  - 若簇数超过上限 Nmax，则标记为“难压缩层”，直接使用全注意力；
- 聚类层数差异跟据“layer compactness score”评估，每层自适应分配簇数量；
- 计算公式：  
  $$MSE_{il} = \frac{1}{N}\sum_i \|k_{il} - c(k_{il})\|^2,\quad Comp_l = 1 / MSE_l$$  
  高紧凑层分较低簇数，稀疏层分较高簇数。

### 4. 关键簇快速选择（TensorQuest）
- 借鉴 LLM 加速方法 Quest，通过估计上界选择潜在关键键；
- 重新设计为 **TensorQuest**：
  - 使用 Tensor Core 并行矩阵计算替代原 Quest 的 CUDA Core 计算；
  - 优化公式：  
    \[
    Quest(q, K) = matmul(q^+, K^+) + matmul(q^-, K^-)
    \]
  - 实现时间较原 Quest 提升约 **5×**。

### 5. 整体算法流程
1. 归一化并聚类 Query；
2. 对 Key 执行多阶段 KMeans 聚类；
3. 若层为“难压缩”，采用全注意力；
4. 否则以 TensorQuest 选取关键簇；
5. 仅在关键簇上执行注意力；  
   → 实现稀疏子集计算。
