## 摘要
我们提出了 LLaDA2.0-Uni，这是一种统一的离散扩散大型语言模型（dLLM），能够在原生整合的框架中支持多模态理解与生成。其架构结合了全语义离散分词器、基于 MoE 的 dLLM 主干网络以及扩散解码器。通过使用 SigLIP-VQ 将连续视觉输入离散化，该模型使主干网络能够在文本和视觉输入上执行块级掩码扩散，而解码器则将视觉 token 重建为高保真图像。推理效率通过主干中的前缀感知优化以及解码器中的少步蒸馏得到了超越并行解码的提升。在精心筛选的大规模数据支撑以及定制的多阶段训练流程下，LLaDA2.0-Uni 在多模态理解方面可比肩专业化的 VLMs，同时在图像生成与编辑任务中表现出色。其对交错生成与推理的原生支持，为下一代统一基础模型奠定了一种有前景且可扩展的范式。代码与模型可访问：https://github.com/inclusionAI/LLaDA2.0-Uni。

## Abstract
We present LLaDA2.0-Uni, a unified discrete diffusion large language model (dLLM) that supports multimodal understanding and generation within a natively integrated framework. Its architecture combines a fully semantic discrete tokenizer, a MoE-based dLLM backbone, and a diffusion decoder. By discretizing continuous visual inputs via SigLIP-VQ, the model enables block-level masked diffusion for both text and vision inputs within the backbone, while the decoder reconstructs visual tokens into high-fidelity images. Inference efficiency is enhanced beyond parallel decoding through prefix-aware optimizations in the backbone and few-step distillation in the decoder. Supported by carefully curated large-scale data and a tailored multi-stage training pipeline, LLaDA2.0-Uni matches specialized VLMs in multimodal understanding while delivering strong performance in image generation and editing. Its native support for interleaved generation and reasoning establishes a promising and scalable paradigm for next-generation unified foundation models. Codes and models are available at https://github.com/inclusionAI/LLaDA2.0-Uni.

- **背景与挑战**  
  当前多模态人工智能模型（如 Qwen-VL、InternVL）多采用**分离式架构**：理解任务（如视觉问答）与生成任务（如图像生成）由不同模型负责。这导致：
  - 模型之间接口不统一，任务切换成本高；

  - 部署与扩展效率低下。

- **研究核心问题**  
  如何构建一个**单一大型模型**，能够在统一的语义空间内同时完成文本和图像的理解与生成，并在推理效率与生成质量之间取得平衡。

- **研究目标**

## 二、方法论综述

### 1. 核心思想
采用 **离散扩散语言建模（Discrete Diffusion Large Language Model, dLLM）**，将文本与视觉信息统一为离散 token 序列，通过掩码扩散预测（masked diffusion prediction）同时建模理解与生成过程。

### 2. 模型三大组件

1. **SigLIP-VQ 语义分词器（Semantic Discrete Tokenizer）**  
   - 基于 SigLIP2-g ViT 特征提取，输出语义 token（非像素重建）；
   - 语义对齐至大语言模型（LLM）词表；
   - 代码簿规模：16,384 × 2048；
   - 具备可变分辨率处理能力。

2. **MoE-based dLLM 主干网络**  
   - 基于 LLaDA2.0-mini（16B 参数）；
   - 通用 Mixture-of-Experts 架构，支持文本与图像 token 的统一输入；
   - 使用 **块级注意力（block-wise attention）** 提高并行性和训练稳定性；
   - 特殊控制 token（如 `<height>`、`<width>`）支持任意分辨率图像。

3. **扩散解码器（Diffusion Decoder）**  
   - 基于 Z-Image-Base 预训练模型；
   - 将生成的语义 token 重建为高保真图像；
   - 通过 **蒸馏（distillation）** 支持 8 步无 CFG 快速采样；
   - 同时完成 2× 超分辨率。

### 3. 推理优化算法 SPRINT

训练无关的加速策略，包含两部分：
- **稀疏前缀保留（Sparse Prefix Retention）**：前缀缓存按 token 置信度稀疏化，减少注意力代价；
- **非均匀掩码恢复（Non-uniform Token Unmasking）**：依据置信度动态恢复 token，节省迭代步数。  
→ 综合提速最高达 **1.6×**，性能损失低于 1%。

### 4. 训练流程

| S0 | 视觉-语言对齐 | 图文对齐、文本 | 100B | 8k |
